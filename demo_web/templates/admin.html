연결 적용은 장치를 움직이지 않습니다. Y 원점 복귀는 모드와 관계없이 실제 STM32에서 실행합니다(rsctl home 1과 동일, 모의 모드에서는 /dev/robot_stage 사용). ±이동 버튼은 선택한 모드에서 실행합니다. 수동 시험은 카메라 없이 가능하며 Trial에는 포함하지 않습니다.

카메라 해상도IMX477

저장된 IMX477 캘리브레이션으로 렌즈 왜곡을 보정합니다. 해상도는 유지하며 SEMES용 크롭·3840×2160 변환은 적용하지 않습니다. 해상도나 보정 설정을 바꾸면 시나리오 검증이 해제됩니다. 파라미터는 RMS 1.68px인 잠정값이며, 렌즈·초점 조건이 달라졌다면 재캘리브레이션이 필요합니다.

STM32 명령 · rsctl과 동일항상 실제 장치

      
터미널의 sudo ./tools/rsctl과 같은 명령을 서버 모드와 관계없이 실제 STM32로 보냅니다. 단위도 같습니다 (Y 1 = 1 µm, T 1 = 0.001°, 속도 0 = 유지). 원점·범위 검사는 STM32가 합니다. 현재 펌웨어는 T 값이 0이 아니면 거부합니다(BAD_PARAM).
