# IMX477 왜곡 보정 데이터

`camera_calib.yml`은 `/home/pi/ye/카메라_정보_전달/camera_calib.yml`의 원본 복사본이다.
동일한 데이터는 `feat/lye/camera-calib:hardware/camera_calib/camera_calib.yml`에 있다.

- 측정: 2026-11-03, IMX477 + 6mm CS 렌즈, 초점 약 28~30cm에서 잠금.
- 전체 센서 영상 4056×3040. 촬영 메타데이터의 ScalerCrop은 (8,16,4056,3040).
- 체커보드 사진 71장, RMS 재투영 오차 1.68px인 잠정값. 정밀도 보장값이 아니다.
- 웹은 원본의 카메라 행렬과 왜곡 계수를 그대로 읽는다. 출력 크기/실제 ScalerCrop에 맞게
  행렬을 변환하고 같은 행렬로 왜곡만 보정한다. 광학 중심 재배치나 SEMES 변환은 하지 않는다.
- 보정 파일 내용 또는 영상 기하 설정 변경 시 기존 시나리오 검증을 해제한다.
- 렌즈나 초점 조건을 바꿨다면 다시 캘리브레이션하고 영상 중앙 기준도 재검증한다.
