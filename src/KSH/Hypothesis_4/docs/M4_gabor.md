# M4 — Gabor 국소 위상으로 늘어남 측정

> 코드 : `code/yt/m4_gabor.hpp/.cpp` · 결과 : `results/verify/M4_gabor/` · 이전 버전 : `backup/m4_gabor.v1.cpp.bak`, `backup/results_M4_gabor_v1/` · 논문 : Miao 2023 (Gabor 위상 DIC)

## 1. 목적
M2 와 **독립된 두 번째 방법**으로 같은 원근 단서(좌·우 QR 의 늘어남 차)를 잽니다. 두 방법이 같은 감도를 내면 측정이 알고리즘의 산물이 아니라 영상에 실제로 있는 신호임이 확인됩니다.

## 2. 수행 방법
1. 가로 방향 복소 Gabor 필터를 씁니다. 파장 λ = 12 px, σx = 4, σy = 6 이고, 실수부의 DC 를 제거했으며 `sepFilter2D` 로 적용합니다. 대상은 QR 띠 (x 1540–2290, y 965–1165) 입니다.
2. 현재 영상을 M1 이동의 정수 부분만큼 미리 옮깁니다 (위상 감김 방지).
3. 위상 차를 위상 기울기로 나눠 화소별 변위를 구합니다.
   - 분모는 기준과 현재 위상 기울기의 평균입니다 (v2 수정).
   - 진폭 하위 40 % 와 위상 기울기가 λ 에서 30 % 넘게 벗어난 화소는 가립니다.
4. 열 중앙값을 낸 뒤 QR 마다 `d = t + s·(x − cx)/100` 로 직선 맞춤을 합니다. t 는 이동(px), s 는 늘어남(px / 100 px) 입니다.
5. 결과 `m4_slopes.csv` : tL·tC·tR, sL·sC·sR, `dS = s_R − s_L`.

## 3. 검증 절차와 기준
| 단계 | 내용 | 통과 기준 |
|---|---|---|
| V4-1 | 푸리에 이동 합성 (정수 사전 이동 포함, 실제 파이프라인과 같음) | t RMS ≤ 0.01 px, 가짜 기울기 s ≤ 0.003 |
| V4-2 | 띠 전체를 (1+ε) 배 늘린 합성 | \|오차\| ≤ 5 % + 0.002 |
| V4-3 | 실제 사진 339장 | 실패 0, Θ 감도가 M2 (0.356 /°) 의 ±20 %, Y 감도 ≤ 0.03 /mm |

## 5. 시행착오
- **v1 가짜 기울기 0.0047** : 기준 0.003 을 넘었습니다. 원인은 두 가지였습니다.
  1. 분모에 기준 영상의 위상 기울기만 써서 비대칭이었습니다.
  2. 합성 시험이 실제 파이프라인과 달리 정수 사전 이동을 하지 않았습니다.
  분모를 두 영상의 평균으로 바꾸고 합성 시험에도 정수 사전 이동을 넣어 0.0011 이 되었습니다. v1 결과는 지우지 않고 `results_M4_gabor_v1` 로 보관했습니다.
