# Hypothesis 4 — Y·Θ 분리 알고리즘 (C++ / OpenCV 3.4.15)

같은 사진 한 장에서 로봇의 Y 이동(mm)과 Θ 회전(°)을 따로 읽어 내는 방법들을 C++ 로 구현했습니다. 각 방법은 정해 둔 절차로 검증했고, 앞 단계가 통과해야 다음 단계로 넘어갔습니다.
목표 사양 : 한 장 기준 Θ ±0.01°, Y ±90 µm.

## 결과 요약 (전체 341장 : 1차 281, 2차 60 — 2026-10-27 실행)
| 순서 | 방법 | 역할 | 구현 검증 | 핵심 수치 | 문서 |
|---|---|---|---|---|---|
| 1 | M1 위상 상관 + ECC | 영역별 이동 (모든 트랙의 바탕) | ✅ | 합성 RMS 0.013 px, Θ 80.06 px/° R² 0.99999 | [M1](M1_phase_ecc.md) |
| 2 | M2 IC-GN 아핀 | QR 별 늘어남 ε (트랙 A 신호) | ✅ | 치우침 0.0006 px, ε 오차 ≤ 1.8e-6 | [M2](M2_icgn.md) |
| 3 | M4 Gabor 위상 | M2 와 독립인 두 번째 늘어남 측정 | ✅ | M2 와 Θ 감도 0.11 % 일치 | [M4](M4_gabor.md) |
| 4 | M3 샘플링 모아레 | 격자법 적용 가능성 | ✅ (구현) | QR 은 격자 아님 → 사용 안 함 | [M3](M3_grid.md) |
| 5 | **트랙 B** QR + 배경 시차 | (Y, Θ) 추정 | ✅ | **사양 달성** : 1차 LOO 280/280, 2차 목표 근처 33/33, 0.01° 계단 0.01006 ± 0.00232° | [B](TrackB_parallax.md) |
| 6 | **트랙 A** QR 만 | (Y, Θ) 추정 | ✅ | **사양 미달** : 1차 LOO Θ RMS 0.025° (84/280). 오차는 위치 의존 체계 오차 | [A](TrackA_pseudo_strain.md) |

결론
- 현재 데이터로 사양을 만족하는 것은 **트랙 B** 입니다.
- 트랙 A 는 구현은 맞지만, 실제 광학계의 위치 의존 오차 때문에 한 장 ±0.01° 에 2.5 배 정도 못 미칩니다. 개선 방향은 트랙 A 문서 5절에 있습니다.

## 다시 검증하는 법
VS 프로젝트 `QR_Image` 에서 (작업 폴더 = 프로젝트 폴더, img/ 가 보이는 곳) :
```
QR_Image.exe verify all                 전체 (M1 → M2 → M4 → M3 → 트랙 B → 트랙 A)
QR_Image.exe verify trackB              한 단계만 (앞 단계 CSV 가 있어야 함)
QR_Image.exe verify all --out 다른폴더 --force   (--force : 미통과여도 다음 단계 진행)
```
- 결과는 `results/verify/<방법>/RESULT.md` 에 생깁니다.
- 같은 입력이면 같은 값이 나옵니다. 단계별 시험 실행과 전체 실행의 CSV 를 비교해 차이 0 을 확인했습니다 (처리 시간 열 제외).
- 소요 시간 : 리눅스 컨테이너 기준 전체 약 2분 50초입니다.

## 원칙
- 라벨(파일명)을 정답으로 씁니다.
- 학습과 평가를 분리했습니다. 1차는 한 장 빼고 학습(LOO)하고, 2차는 1차 모델로 평가하며, teaching 3장은 평가에서 뺍니다.
- 기준을 결과에 맞춰 낮추지 않았습니다. 기준을 바꾼 경우(M1 R²)는 첫 실행 전이었고 문서에 적었습니다.
- 처리 시간을 함께 기록했습니다 (M1 151 ms, M2 81 ms, M4 14 ms / 장).
