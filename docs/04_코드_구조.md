## 1. 폴더

```
(패키지 폴더)/
├── include/     쓰는 사람이 부르는 함수 (이것만 보면 쓸 수 있다)
├── src/         측정 코드. 실사용, 학습, 평가가 모두 이 코드 하나를 쓴다
├── config/      설정 파일
├── data/        모델 파일, 받은 사진, 확인용 예제 사진
├── tools/       실행 프로그램 (써 보기, 계수 만들기, 성능 재기)
└── docs/        문서
```

| 폴더 | 장비에 넣는 것인가 |
|---|---|
| `include/`, `src/`, `config/`, `data/model/` | **예.** 실제로 쓰는 것은 이것뿐이다 |
| `tools/`, `data/new_photos/`, `data/sample/`, `docs/` | 아니오. 확인, 학습, 평가에만 쓴다 |

### 1-1. data

| 폴더 | 내용 | 언제 바뀌나 |
|---|---|---|
| `data/model/` | 측정할 때 읽는 파일. `center.bmp`(기준 사진), `reference.json`(QR, 나사 위치와 학습한 범위), `coefficients/`(계수 16개), `checks/`(점검식 11개) | 계수를 다시 만들었을 때만 |
| `data/new_photos/` | 설비에서 받은 사진. 촬영한 날마다 폴더 하나. `tables/` 는 도구가 만드는 표 | 사진을 받을 때마다. Git 에 올리지 않는다 |
| `data/sample/` | 확인용 예제 사진 5장과 기대값 | 바뀌지 않는다 |
| `data/results/` | 도구가 만든 결과 (`train/`, `eval/`) | 도구를 돌릴 때마다. Git 에 올리지 않는다 |

### 1-2. tools

| 폴더 | 프로그램 | 언제 쓰나 |
|---|---|---|
| `tools/try/` | `measure_one`, `show_steps`, `check_photos`, `check_setup`, `make_figures` | 처음 받았을 때, 옮긴 코드와 값을 비교할 때 |
| `tools/train/` | `train`, `prepare_dataset`, `fit_coefficients` | 계수를 다시 만들 때 |
| `tools/evaluate/` | `score_photos`, `evaluate_accuracy`, `measure_speed`, `compare_far_pose_methods` | 성능을 잴 때 |
| `tools/environment/` | `make_environment_images`, `make_site_images`, `check_new_installation`, `check_qr_blocking` | 화면이 바뀌면 어떻게 되는지 합성 사진으로 볼 때 |
| `tools/common/` | 위 프로그램들이 같이 쓰는 코드 | (직접 실행하지 않는다) |

## 2. 측정 처리 흐름

갈림길, 실패, 경고까지 그린 그림은 [코드 정리 그림](부록_B_코드_그림/README.md)에 있다. 아래는 부르는 순서만 적은 것이다.

```
measure_alignment(사진)
 │
 ├─ 사진 검사, 회색으로 바꾸기           src/common/reference      to_gray
 ├─ 1단계  QR 3개의 가로 이동            src/steps/01_find_qr      QrFinder::find_qr_shift
 │          QR 을 하나도 못 찾으면 → 실패 E_QR_NOT_FOUND
 ├─ 2단계  나사 4개의 가로 이동          src/steps/02_find_screws  ScrewFinder::find_screw_shifts
 │          못 찾은 나사는 빼고 계속
 │          머리 일부 가림 또는 오염 의심 나사가 있으면 → 실패 E_SCREW_PARTIAL
 ├─ 3단계  찾은 나사에 맞는 계수로 Y, T   src/steps/03_compute_yt   choose_coefficient_set, compute_yt
 ├─ 영점 빼기                           src/alignment.cpp         make_result
 ├─ 4단계  값 일치 점검, 범위 점검        src/steps/04_check_result check_values_agree, check_in_trained_range
 └─ 경고 붙이기, 알림 쓰기               src/alignment.cpp         add_notices, report
```

## 3. 파일과 함수

### 3-1. include/

| 파일 | 함수, 자료형 | 하는 일 |
|---|---|---|
| `alignment.hpp` | `enum Status` | 정상, 경고, 실패 |
| | `struct Result` | 결과: `y_mm`, `t_deg`, `status`, `code`, `message`. 확인용: `qr_shift_px`, `screw_shift_px[4]`, `screws_used`, `check_value`, `check_limit` |
| | `initialize(model 폴더, 설정 파일)` | 시작할 때 한 번. 모델 파일을 읽는다 |
| | `measure_alignment(사진)` | 사진 한 장 → Y, T |
| | `set_zero_from_photos(명령 0 사진들)` | 영점 잡기 |
| | `set_zero_value(y, t)`, `clear_zero()` | 적어 둔 영점 넣기, 영점 지우기 |
| | `set_reference_from_photos(센터 사진들)` | 화면이 밀렸을 때 기준 다시 잡기 |
| | `read_photo(경로)` | 사진 파일 읽기 (한글 경로도 됨) |

## 4. 조정 가능한 상수

숫자는 각 파일 맨 위에 상수로 모아 두었다.

| 숫자 | 값 | 위치 | 바꾸면 계수를 다시 만들어야 하나 |
|---|---|---|---|
| QR 띠 세로 여유, 대략 축소 배율 | ±40 px, 1/4 | `src/steps/01_find_qr.hpp` | 아니오 |
| QR 봉우리 문턱, 이웃 간격 허용 오차 | 닮은 정도 0.5, 25 px | `src/steps/01_find_qr.hpp` | 아니오 |
| QR 정밀 탐색 창 | 대략 위치 ±8 px | `src/steps/01_find_qr.hpp` | 아니오 |
| QR 정밀 위치를 인정하는 기준 | 닮은 정도 0.8 | `src/steps/01_find_qr.hpp` | 아니오 |
| QR 흐림 | σ 2 px | `src/steps/01_find_qr.cpp` | **예** (잰 값이 달라진다) |
| 나사 탐색 범위 | ±60 px → ±260 px | `src/steps/02_find_screws.cpp` | 아니오 |
| 나사를 찾았다고 보는 기준 | 닮은 정도 0.6 | `src/steps/02_find_screws.cpp` | 아니오 |
| 나사 조각 크기, 테두리 그림 크기, 원 반지름 | 91 px, 141 px, 45 px | `src/steps/02_find_screws.cpp` | **예** |
| 사진 크기 | 3840×2160 | `src/common/reference.hpp` | **예** (기준 사진부터 다시) |
| 통과 기준 | Y 0.045 mm, T 0.01도 | `tools/common/coefficient_fit.hpp` | 학습에도 쓰이므로 예 |
| 쓸 나사, 불일치를 실패로 볼지, 로그 파일 | | `config/settings.json` | 아니오 |
