제목: 방사 왜곡이 없다 (k1 = 0)
종류: 가정
상태: 대기
출처: A13, A14
값: k1 = 0.12 면 미설명 항이 사라지지만 f 가 15% 변함
영향: M15
막힘: R4
---

A13 의 제약 모형이 설명 못 한 u 의 y^2 항(x^2 의 14%)이 k1 = 0.12 에서 정확히 사라진다. **왜곡이 정체일 가능성이 높다.**

그런데 전체 잔차는 0.4% 밖에 안 줄고 f 가 4730 -> 4000 으로 흔들린다. **f 와 k1 의 상쇄**다.

평면 하나를 작은 각도로만 본 자료로는 분리할 수 없다.
