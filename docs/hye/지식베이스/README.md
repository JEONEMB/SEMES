# 지식베이스

실험에서 알아낸 것을 **사실 하나당 파일 하나**로 모아 두고, 그 관계를 그림(Obsidian Canvas)과 표로 자동 생성한다.

## 어떻게 쓰나

```
갱신.bat
```

이것만 하면 된다. `사실/*.md` 를 읽어 두 가지를 다시 쓴다.

| 산출물 | 위치 |
|---|---|
| 그림 (Obsidian Canvas) | `C:\Users\SSAFY\Desktop\메모\세메스_정리.canvas` |
| 표 색인 | `지식지도.md` |

다른 캔버스에 쓰려면 `갱신.bat "경로.canvas"` 처럼 인자를 준다.

## 캔버스에서 손으로 만든 것은 보존된다

생성기는 **id 가 `kb-` 로 시작하는 노드와 연결만** 관리한다.

- 직접 추가한 노드·연결은 **그대로 둔다.** 자유롭게 글을 쓰고 배치해도 된다.
- 이미 있는 `kb-` 노드는 **위치(x, y)를 유지한다.** 옮겨 둔 배치가 사라지지 않는다.
- 내용·색·연결만 사실 파일에 맞춰 갱신된다.

그래서 **그림을 마음대로 정리해 두고 갱신을 돌려도 안전하다.**

## 색의 뜻

| 색 | 종류 |
|---|---|
| 보라 | 문헌 근거 |
| 청록 | 실측값 |
| 초록 | 결론 |
| 노랑 | 가정 (주의해서 쓸 것) |
| 주황 | 미해결 |
| 빨강 | 촬영 요청 |

## 사실 하나 추가하기

`사실/` 에 파일을 하나 만든다. 파일 맨 위 머리말이 전부다.

```markdown
---
id: M25
제목: 한 줄 요약
종류: 측정
상태: 확정
출처: A13
값: 4492 px
영향: C14, M16
막힘: R4
---

본문 첫 줄이 캔버스 카드에 들어간다.

나머지는 파일을 열어야 보인다.
```

| 칸 | 뜻 |
|---|---|
| `id` | 고유 번호. 종류 머리글자 + 번호 (L 문헌 / M 측정 / C 결론 / G 가정 / U 미해결 / R 요청) |
| `종류` | 문헌 · 측정 · 결론 · 가정 · 미해결 · 요청 |
| `상태` | 확정 · 잠정 · 반증 · 대기 |
| `출처` | 실험 ID 또는 문헌 약칭 |
| `값` | 핵심 수치 한 줄 (없으면 비움) |
| `영향` | **이 사실이 영향을 주는** 다른 사실 (화살표가 여기서 나간다) |
| `막힘` | **이 사실을 확정하려면 풀려야 하는** 것 (빨간 화살표) |

없는 id 를 적으면 `지식지도.md` 의 "고쳐야 할 것" 에 뜬다.
