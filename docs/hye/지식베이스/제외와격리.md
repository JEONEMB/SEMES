# 쓰지 않는 문헌과 그 이유

찾은 114건 중 **쓰지 않거나 조건부로만 쓰는 것**을 모았다. 손으로 쓰는 파일이며 생성기가 캔버스에 그대로 싣는다.

세 종류가 있다. 성격이 다르니 섞지 않는다.

---

## 1. 애초에 폴더를 만들지 않은 것 (검색은 했다)

출처: 각 주제 폴더의 `조사방법론.md` 6절 "선정 기준·관련도".

| 왜 제외했나 | 어디에 적혀 있나 |
|---|---|
| **중복.** 유사연구 논문 01~17, 특허 01~09 와 겹치는 것은 새 폴더를 만들지 않고 결과서에서 번호로만 참조한다 | `03_Y_T_분리/논문/조사방법론.md` 6절 |
| **팀 보고서가 이미 인용한 것.** 팀 보고서 [1]~[32] 에 있는 문헌은 "팀 보고서 [n]에서 이미 인용"으로 표시만 한다 | 같은 곳 |
| **핸드아이 보정 일반론.** 유사연구 16번 하나로 대표하고 더 늘리지 않는다 | 같은 곳 |
| **P1~P5 중 어디에도 해결 방법이나 정량 근거를 주지 않는 것.** 포함 기준을 못 넘은 것 | 각 주제 `조사방법론.md` 6절 |
| **분량 상한.** 주제마다 ◎·○ 6~10편, △ 3~6편으로 끊었다. 그 아래 순위는 폴더를 만들지 않았다 | 같은 곳 |

검색어와 건수는 각 `조사방법론.md` 4~5절에 블록 조합으로 기록돼 있다. **후보 전체 목록은 남기지 않았다.** 건수만 남겼으므로, 어떤 제목이 탈락했는지는 지금 복원할 수 없다. 이것이 이 기록의 한계다.

## 2. 폴더는 있지만 인용을 금지한 것 (7건)

출처: [문헌 종합 v3](../문헌연구/00000_문헌연구_종합_결과보고_v3.md) 2절. 원문이 없거나 다른 논문인데 번역·수치가 붙어 있는 것들이다. **어떤 문서에서도 근거로 인용하지 않는다.** 파일은 지우지 않았다.

| 위치 | 무엇이 문제인가 | 처리 |
|---|---|---|
| `02_QR_분석/논문/09_Pan2013_OLE_렌즈왜곡_2DDIC오차` | PDF 가 07번(Pan IC-GN)과 **같은 파일**인데, 번역에 수치(k=−1.5e-7, 0.25→0.005 px)가 있고 요약 상세 절은 영상 포화 논문 내용이다 | 인용 금지. 올바른 원문 확보 후 재작성 |
| `02_QR_분석/논문/15_Matrox_MIL_GeometricModelFinder_문서` | PDF 없음. "MIL10 문서"라며 1/20~1/40 px 를 제시하지만 요약(MIL 7.5 웹)과 모순된다 | 인용 금지. 공식 MIL10 문서로 대체 |
| `04_Y_T_오차_보정/논문/15_NIST_eHandbook_GaugeRR_측정시스템` | %GRR<10%·ndc≥5 가 NIST 내용처럼 적혀 있고 우리 과제 수치까지 들어 있다 | 인용 금지. 원전은 AIAG MSA |
| `04_Y_T_오차_보정/논문/02_Wang2023_JMNM_비전웨이퍼본딩정렬_오차예산` | 원문 유료·PDF 없음인데 "전문 번역"이라 되어 있고 요약 상세 절은 다른 논문(스튜어트 플랫폼) 내용 | 인용 금지 |
| `04_Y_T_오차_보정/논문/03_LeReun2022_Robotica_열드리프트_백래시_위치성능` | 같은 문제 (케이블 구동 논문 내용이 섞임) | 인용 금지 |
| `03_Y_T_분리/특허/05_US10076842_Cognex_기구_핸드아이_동시보정` | "직접 판독" 부분 번역이라 PDF 대조가 안 됐다 | 등급을 **부분 번역(미대조)** 로 표기하고 쓴다 |
| `04_Y_T_오차_보정/특허/07_US12202151_CXMT_지그웨이퍼_로봇보정` | 같은 문제 | 같은 처리 |

여러 `요약.md` 의 **"상세 요약(번역본 기반)" 절**도 조심해야 한다. 번역에 없는 수치가 들어 있는 경우가 있다. v3 2절이 해당 목록을 적어 두었다. **그 절의 수치는 인용하지 않고 번역 본문 수치만 쓴다.**

## 3. 원문 PDF 를 못 받은 것

출처: [논문 원문 받을 목록](../문헌연구/00000_논문_원문_받을_목록.md)

논문 폴더 75편 중 **50편에 원문 PDF 가 없었다.** 2026-10-30 기준으로 일부를 받았다.

자동으로 못 받은 이유는 출판사·저장소의 봇 차단이다(HAL, MDPI, IEEE Access, Hindawi, IOP, Optica). **차단을 우회하지 않았다.**

이 문헌들은 **초록 기준 요약**이라 정량 수치를 인용할 때 주의해야 한다. v3 보고서가 "초록 기준"이라고 표시한 카드들이 여기 해당한다.

---

## 4. 스노우볼링을 못 한 것

`조사방법론.md` 9절 7번: **◎ 문헌의 원문 대부분이 유료라 참고문헌 추적을 못 했다.** 03번 한 건만 확인했다.

그래서 **◎ 문헌이 인용한 더 중요한 문헌이 빠져 있을 수 있다.** 이것이 이 조사의 가장 큰 구멍이다.
