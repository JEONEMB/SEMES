# 변경 명세: 2026-11-13 ~ 11-14

Y·T 추정 모듈과 실험에서 이틀 동안 바꾼 것을 정리한다. 각 항목에 아래를 적었다.

- 왜 했는지
- 무엇을 바꿨는지
- 효과가 있었는지(숫자)
- 어디에 넣었는지

공통 기준:

- 통과: |eY| ≤ 0.045 mm 그리고 |eT| ≤ 0.01°
- 검증: 미리 고정한 분할(주 검증 80/20 × 10회, 마지막 확인, 처음 보는 회차)

- 모든 숫자는 정지 사진 평가다. 실제 정렬 복귀는 아직 시험하지 않았다.

브랜치는 `feature/hye/ssafy-reference` 다. 커밋은 `git log --since=2026-11-13` 로 본다.

## 2. 우리 장비 사진에 적용, 라벨 보정 (실험 `20261113_0950`, `20261113_1345`)

- 왜: SEMES 측정 기준 자료로는 장비 사진이 측정되지 않았다(화면 위치가 다름).
- 바꾼 것: 장비 센터 사진으로 기준 자료를 만들었다. 라벨 3가지를 비교했다.
  - L0 = 명령
  - L1 = 명령 + 세트 영점
  - L2 = L1 + 이웃 기반 보정
- 효과:
  - 장비 사진 1959장이 모두 측정된다.
  - L2 보정은 다른 날·다른 촬영 순서로 옮겨지지 않는다(역순 사진에서 1280 → 1131 통과). **L2 는 그날 자료 안에서만 의미가 있다.**

## 4. 측정 기준 다시 잡기 (`set_joint_reference`)

- 왜: 팀원이 카메라가 무거워 날마다 화면이 아래로 밀린다고 했다. QR·바가 탐색 범위를 벗어나면 측정이 실패한다.
- 바꾼 것: 그날 센터 사진으로 다음을 C++ 로 다시 찾는다(`src/reference.cpp`).
  - QR 상자, 630점, 나사 중심, 바 칸
- 절대 영점 잇기: 같은 사진을 바꾸기 전 기준으로도 재서, 그 차이(bridge)를 더해 절대 영점을 잇는다.
- 효과:
  - Python 으로 만든 기준 자료와 QR 상자·나사가 같고, 630점은 0.013 px 안에서 같다.
  - 11-13 역순 사진에서 센터 출력이 그대로 이어졌다.

## 5. 측정 속도 (출력은 같음)

- 왜: Pi 에서 사진 한 장이 2.3 초 걸렸다.
- 바꾼 것 (모두 출력이 비트 또는 1e-8 안에서 같음):
  - 쓰지 않던 QR 호모그래피 계산을 뺐다.
  - 나사 시작 위치를 QR 이동 주변 ±60 px 에서만 찾는다(못 찾으면 전체).
  - 나사 ECC 를 마스크 주변으로 줄였다.
  - QR·나사를 병렬로 계산한다.
  - 쓰지 않는 94점은 추적하지 않는다.
- 효과: 장비 사진 한 장 766 ms → 9 ~ 18 ms (노트북 4스레드). Pi 는 약 3배로 예상한다(재지 않음).

## 6. QR 값 NCC 포물선 (실험 `20261113_1700`)

- 바꾼 것: QR 3개를 각각 통째로 NCC 맞춤하고, 정수 봉우리 + 3점 포물선으로 소수 이동을 구한다.
- 효과 (장비 사진):

  |---|---:|---:|
  | 처음 보는 날 통과 | 99.70% | 99.64% |
  | QR 값 시간 | 약 5 ms | 약 23 ms |

## 8. 절대 영점 기본 + 영점 업데이트

- 왜: 영점은 "QR·바·나사가 측정 기준 사진과 같은 상태"다(센터 사진 한 장을 라벨 0 으로 쓰지 않는다). 날마다 카메라·조명이 조금씩 바뀐다.
- 바꾼 것:
  - 기본 = 절대 영점(수치)
  - `set_joint_zero(그날 센터 사진들)` 로 영점 업데이트
  - `set_joint_zero_value` / `clear_joint_zero` / `joint_zero` 로 영점 값 넣기·지우기·읽기
- 효과 (교란 시험):
  - 카메라 0.05° 회전이면 SEMES Y 가 0.27 mm 틀렸다. 가로 2 px 밀림이면 T 가 0.025 틀렸다.
  - 영점 업데이트 뒤에는 이런 화면 전체 변화가 거의 0 이 됐다. **영점 업데이트는 날마다, 카메라·조명·판을 건드린 뒤마다 해야 한다.**

## 10. NCC 전에 가우시안 σ2 흐림 (실험 `20261113_2000`)

- 방법 (과적합 주의):
  - 후보 5개를 미리 정했다.
  - 라벨 없는 지표로 골랐다.
  - 마지막 확인은 한 번만 봤다.
- 효과 (SEMES, NCC):

  | | 흐림 전 | σ2 흐림 뒤 |
  |---|---:|---:|
  | 주 검증 탈락 | 2.6 | 0.2 |
  | 마지막 확인 | 3/142 | 0/142 |
  | 처음 보는 회차 | 97.5% | 98.4% |

  장비 사진에는 해가 없었다(폴드 탈락 8.9 → 5.1).
