# [8] 이동 실험 계획

작성 2026-11-05. 브랜치 feature/hye/pipeline-v2.
근거 문서: [00_단계.md](00_단계.md), [ALGORITHM_RULES.md](../../../../../ALGORITHM_RULES.md), [문헌연구/AGENTS.md](../../../문헌연구/AGENTS.md), [plan.md](../../plan.md).
후보 방법 M1~M7은 00_단계.md "후보 방법 (문헌 기반 재작성)" 절에서 그대로 가져왔다.

> [!warning] 이 단계의 한계
> 575장은 모두 명령한 자리에 멈춰 찍은 정지 사진이고, 파일명은 목표 명령만 담는다.
> **접근 방향 기록이 없고, 외부 기준기가 없다.**
> 그래서 질문 1, 2, 3, 8의 "우리 장비에서 얼마인가"는 오프라인으로 답할 수 없다.
> 아래 오프라인 실험은 답할 수 있는 조각만 다룬다. 나머지는 촬영 요청서로 넘긴다.
> 341/575장은 개발에 노출된 자료다. 시험 정답은 학습에 쓰지 않는다.

## 0. 공통 고정 조건

모든 오프라인 실험에 같이 적용한다.

| 항목 | 값 |
|---|---|
| 자료 | `data/clean/` 정지 사진. 원본과 기존 결과는 고치지 않는다 |
| 점 측정 캐시 | [A0 캐시](../../../../../experiments/hye/20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache)를 먼저 재사용한다. 없는 항목만 새로 잰다 |
| 분할 (control 비교) | `00000_final_Y_T control/validation/splits.json`의 고정 4-fold |
| 분할 (joint 비교) | 341장 외부 4-fold. A0 계층 분할을 따른다 |
| 날짜 평가 | 1014, 1020, 1029를 통째로 나눈 평가를 **반드시** 함께 낸다 |
| 대조군 | `00000_final_Y_T_joint`, `00000_final_Y_T control` |
| 지표 | 축별 평균오차, 축별 최대오차, 통과율(Y 0.045 이내, T 0.01 이내), 처리 시간 ms |
| 구현 | C++17, OpenCV 3.4.15 API 범위. `experiments/hye/YYYYMMDD_HHMMSS_V2_8_<주제>/` |
| 금지 | data 커밋, 기존 final 폴더 수정, 시험 정답의 학습 사용 |

판정 기준은 실험을 돌리기 전에 이 문서에 적은 값으로 고정한다. 결과를 보고 기준을 바꾸지 않는다.

## 1. 오프라인 실험

### V2-8-E1 알려진 탐색 이동 짝 추정 (재사용, 새로 돌리지 않는다)

| 항목 | 내용 |
|---|---|
| 질문 | 알려진 이동을 한 번 주고 다시 찍으면 약한 방향이 풀리는가 (후보 M7) |
| 후보 | M7 알려진 탐색 이동 후 짝 추정 |
| 고정 조건 | 조건 짝 273개, 같은 fold에 드는 150개, 전용 분할 |
| 지표 | 약한 방향 SD 비, Y/T 평균오차, Y/T 최대오차, 통과율 |
| 판정 기준 | 짝의 약한 방향 SD가 단일의 0.5배 이하면 채택 |
| 결과 | 전체 0.808배로 **판정선 미달**. ΔY 짝만 0.413배로 조건부 성립. ΔT 짝 0.83~0.93배로 효과 작음. 최대오차 2.1333 에서 0.9500 으로 55% 감소 |
| 상태 | **같은 조건으로 이미 끝났다.** [A7 보고서](../../../../../experiments/hye/20261102_132128_A7_탐색이동효과_조건쌍오프라인/결과/보고서.md)를 그대로 쓰고 다시 돌리지 않는다 |
| 결론 반영 | M7은 기본 경로가 아니라 **모호 판정 사진에만 쓰는 조건부 수단**, 이동 축은 Y로 고정 |
| 예상 소요 | 0 (문서 인용만) |

주의: M7의 전제는 "그 이동이 실제로 명령대로 된다"이다.
이 전제는 질문 1, 2에 달려 있고 아직 미확인이다.
그래서 A7 수치를 실기 성능으로 인용하지 않는다.

### V2-8-E2 명령 대비 영상 응답의 선형성과 잔차 지도

| 항목 | 내용 |
|---|---|
| 질문 | 질문 1에서 오프라인으로 답할 수 있는 조각. 명령값과 영상 변위의 관계가 한 직선인가, 목표 위치나 날짜에 따라 잔차에 구조가 있는가 |
| 후보 | M6 영상 템플릿 정합을 이동 측정기로. 문헌 L5, L11, L6, L13 |
| 고정 조건 | A0 캐시의 점 측정값. 날짜별로 따로 적합. Y 사진과 T 사진을 따로. 센터 사진은 기준으로만 쓰고 적합에 넣지 않는다. 적합은 1차와 2차(제곱항 추가) 두 모형 |
| 지표 | 축별 기울기(px/mm, px/T)와 95% 구간, 잔차 RMS(px), 잔차 최대(px), 목표값 구간별 잔차 평균, 날짜 간 기울기 차(%), 2차항 AIC 개선, 측정 시간 ms |
| 판정 기준 (고정) | (a) 잔차 RMS 가 0.065 px(허용의 1/10) 이하면 "영상 쪽 선형성은 문제 없음". (b) 목표값 구간별 잔차 평균의 폭이 0.22 px(허용의 1/3)를 넘으면 7단계에 목표별 보정 항을 넣을 후보로 올린다. (c) 날짜 간 기울기 차가 1%를 넘으면 날짜별 배율을 따로 둔다 |
| 대조군 | A16이 쌍 42,463개에서 낸 14.2491 px/mm, 80.0650 px/T와 맞는지 본다. 0.5% 안이면 일치로 본다. 기존 final 두 모듈을 같은 사진에서 같이 돌려 시간과 오차를 나란히 적는다 |
| 한계(미리 적는다) | 이 실험은 **명령 대비 영상**만 본다. 기준기가 없으므로 기울기가 1에서 벗어나도 기계 탓인지 카메라 탓인지 나눌 수 없다. 접근 방향 기록이 없어 백래시는 공통 편향으로 숨는다. ISO 230-2의 B, R, E, M, A는 이 자료로 계산하지 않는다 |
| 예상 소요 | 구현 반나절, 실행 10분 안쪽(캐시 재사용 기준) |

### V2-8-E3 M1, M2의 20턴 예산 회계

| 항목 | 내용 |
|---|---|
| 질문 | 질문 3, 8의 운용 쪽. 단방향 접근(M1)과 지나쳐 돌아오기(M2)가 20턴 예산을 얼마나 먹는가. 데드존 폭이 얼마면 20턴 안에 못 끝나는가 |
| 후보 | M1 단방향 마지막 접근, M2 지나쳐 돌아오기, 비교군은 보정 없음 |
| 고정 조건 | **영상 생성기를 쓰지 않는다.** 명령 수준 회계만 한다. 입력은 (1) 시작 편차 분포, (2) 축별 추정 오차 분포, (3) 데드존 폭 d. 시작 편차는 575장 파일명의 명령값 분포를 그대로 쓴다. 추정 오차는 A10 per_shot 실측 분포를 쓴다. 데드존 폭은 가정값 d = 0, 0.004, 0.01, 0.02 단위(T 환산)로 쓸어 본다. 정책마다 10,000회, seed 고정 |
| 지표 | 정책별 평균 턴 수, 95분위 턴 수, 최대 턴 수, 20턴 안 종료 비율, 추가 이동 횟수, 추가 촬영 횟수 |
| 판정 기준 (고정) | (a) M1이 보정 없음보다 평균 턴 수를 2턴 넘게 더 먹으면 "예산 부담 큼"으로 적는다. (b) d 가 0.01 이상일 때 보정 없음의 20턴 종료 비율이 99% 아래로 떨어지면 데드존 대책(M1 또는 M2)이 필수임을 적는다. (c) M2가 M1 대비 종료 비율을 1%p 넘게 올리지 못하면 M2는 보류한다 |
| 한계(미리 적는다) | 데드존 폭 d는 **가정값**이다. 실측이 없다. 이 실험은 "d가 얼마면 어떻게 되는가"의 민감도 표이지, 복귀 성공률 예측이 아니다. [v1 센터 복귀 시뮬레이션](../../../../../experiments/hye/20261104_140000_v1_센터복귀_시뮬레이션/보고서.md)이 관측 생성기 때문에 복귀율을 인용하지 못한 전례를 따라, 이 실험의 숫자도 실기 성능으로 인용하지 않는다 |
| 예상 소요 | 구현 반나절, 실행 수 분 |

## 2. 실기 촬영 요청서

오프라인으로 답이 안 되는 질문은 전부 여기로 간다. 요청 순서는 R1, R2, R3, R4다.

### R1 정지 대기 시간과 세션 영점 (기존 B1 그대로)

[B1 계획서](../../../../../experiments/hye/20261102_132828_B1_정지대기와날짜영점_촬영설계/계획서.md)를 다시 쓰지 않고 그대로 요청한다.

| 항목 | 값 |
|---|---|
| 자세 | 한 자세(센터)만 |
| 조건 | 복귀 후 대기 0, 0.5, 1, 2, 5초 5수준 |
| 횟수 | 수준마다 10장 연속, 같은 날 3회(오전, 오후, 저녁), 다른 날 1회 |
| 합계 | 5 × 10 × 4 = 200장 |
| 기록 | 촬영 시각, 정지 후 경과 시간, 가능하면 장비 온도. 파일명 명령값 방식은 유지 |
| 답하는 질문 | 4(정지 대기 수준), 7(측정 흩어짐 분리) |
| 먼저 하는 이유 | 촬영이 단순하고, 결과가 바로 "대기 시간 규칙"이 된다. 다른 모든 촬영의 대기 조건을 여기서 정한다 |

### R2 접근 방향 이력 (기존 B2 그대로)

[B2 계획서](../../../../../experiments/hye/20261102_132918_B2_접근방향이력_ISO9283정역30회/계획서.md)를 그대로 요청한다.

| 항목 | 값 |
|---|---|
| 자세 | Y 축 Y=+0.50 (T=0), T 축 T=+0.50 (Y=0) |
| 조건 | 목표마다 +방향 접근과 −방향 접근. 출발은 목표에서 ±1.00 떨어진 곳 |
| 횟수 | 방향마다 30회. 2축 × 2방향 × 30회 = 120회, 회당 1장 |
| 기록 | 접근 방향, 출발 자세, 촬영 시각, 정지 후 대기(R1에서 정한 값으로 고정), 온도 |
| 답하는 질문 | 2(역전값 B), 3(단방향 반복정밀도) |
| 판정 | 방향별 평균 차가 허용의 1/3(Y 0.22 px, T 0.015 단위)을 넘으면 M1 도입. 미만이면 도입하지 않는다 |
| 기준기 | 분해능 0.015 단위 이하의 독립 기준기가 있으면 같이 건다. 없으면 이 시험은 **영상 자기 일관성 시험**이라고 보고서에 먼저 적는다 |

### R3 작은 명령의 데드존 계단 (신규)

| 항목 | 값 |
|---|---|
| 목적 | 질문 8. 0.01~0.05 단위 작은 명령이 실제로 움직임을 만드는가, 반전 직후에 몇 틱이 틈에서 소모되는가 |
| 자세 | 센터 한 곳에서 출발 |
| 조건 A (같은 방향 누적) | +방향으로 0.01 단위씩 10번 누적. 매 걸음마다 1장 |
| 조건 B (반전 직후) | 조건 A 끝에서 −방향으로 0.01 단위씩 10번 누적. 매 걸음마다 1장 |
| 축 | Y와 T 따로. 한 턴에 한 축만 움직인다 |
| 횟수 | 조건 A, B를 축마다 3세트 반복 |
| 합계 | 2축 × 2조건 × 10걸음 × 3세트 = 120장 |
| 대기 | R1에서 정한 값으로 고정 |
| 기록 | 걸음 번호, 누적 명령, 직전 걸음의 방향, 촬영 시각 |
| 지표 | 걸음당 영상 변위(px), 반전 직후 처음 k걸음의 변위 합, 데드존 폭 추정값 d |
| 판정 기준 (고정) | 반전 직후 1틱의 영상 변위가 같은 방향 1틱 변위의 절반 미만이면 데드존 존재로 본다. d 추정값이 0.01 단위를 넘으면 M2(지나쳐 돌아오기)를 후보로 올린다 |
| 답하는 질문 | 8, 그리고 2의 크기 쪽 |

### R4 T 축 방향별 각도 편차 지도 (신규, M4)

| 항목 | 값 |
|---|---|
| 목적 | 질문 5. 목표 각도별, 방향별 T 편차 표를 만든다 |
| 자세 | Y=0 고정, T = −1.0, −0.5, 0, +0.5, +1.0의 5곳 |
| 조건 | 목표마다 +방향 접근과 −방향 접근. 진자 순서(L2에서 12지표 중 8개 최선) |
| 횟수 | 목표마다 방향마다 5회(ISO 230-2 최소) |
| 합계 | 5목표 × 2방향 × 5회 = 50회, 회당 1장 |
| 대기 | R1에서 정한 값으로 고정 |
| 지표 | 목표별 Bi, B, 평균 B, Ri(상향) = 4si, Ri(하향), Ri, E, M, A |
| 판정 기준 (고정) | 방향별 평균 차가 T 1틱(0.01)을 넘는 목표가 하나라도 있으면 7단계에 방향 보정 항을 넣는다. Y 고정이 영상에서 지켜졌는지(Y 환산 변동 0.045 이내) 함께 확인한다 |
| 답하는 질문 | 5, 1(목표별 배율 오차) |
| 순서 | R2에서 방향 효과가 확인된 뒤에 한다. R2에서 효과가 없으면 R4는 취소한다 |

### 요청하지 않는 것

- 보상 이동(Y와 T를 같이 주어 영상 이동을 0으로 만드는 자세) 촬영은 이 단계가 아니라 [B4](../../../../../experiments/hye/20261102_133043_B4_축교정식별성_최대T스윕/계획서.md)에서 다룬다.
- 외부 기준기 도입은 장비 쪽 결정이라 촬영 요청으로 넣지 않고, R2 보고서에 "없으면 영상 자기 일관성 시험"이라는 한계로만 적는다.

- [ ] 모든 촬영에서 접근 방향을 기록한다. 이 기록이 없으면 이 단계는 다시 답할 수 없다.
- [ ] 정지 후 대기 시간을 R1에서 정한 한 값으로 고정한다.
- [ ] 한 턴에 한 축만 움직인다(1차 T, 2차 Y). Y와 T 반응이 cos 0.99999로 거의 평행하다.
- [ ] 같은 세션 안에서 연속으로 찍는다. 날짜 간 세로 +0.44 px는 카메라 이동이고 이 단계 대상이 아니다.
- [ ] 정지 연속 촬영 10장 이상을 같은 세션에 넣어 측정 흩어짐을 따로 잰다. 기계 분산 = 전체 분산 빼기 측정 분산.
- [ ] 촬영 자료는 기존 `data/clean/` 규칙대로 날짜 폴더로 받는다. 커밋하지 않는다.
- [ ] 받은 자료로 오프라인 실험을 다시 돌릴 때 기존 final 모듈을 대조군으로 같이 돌린다.

## 4. 이 단계가 final_v2에 주는 것

지금 상태로 final_v2에 바로 넣을 수 있는 것은 없다. 촬영 전 결론은 다음 세 줄이다.

1. M7은 조건부 수단으로만 남긴다(V2-8-E1 재사용 결과).
2. M1, M2, M3, M4, M5는 전부 문헌 근거는 있으나 우리 장비 미검증이다. R2, R3, R4 전에는 채택으로 적지 않는다.
3. 7단계 명령 만들기는 당분간 방향 보정 항 없이 간다. V2-8-E2의 판정 (b), (c)가 걸리면 그때 목표별 또는 날짜별 보정 항만 올린다.
