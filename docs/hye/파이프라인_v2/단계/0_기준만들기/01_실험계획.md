## 3. 오프라인 실험 (data/clean 정지 사진으로 가능)

### V2-0-E1 기준 장수와 기준 사진 선택의 민감도

| 항목 | 내용 |
|---|---|
| 질문 | 1, 2, 6. 센터를 사진 1장으로 정해도 되는가. 여러 장 평균이 지금 판정선에서 성적을 바꾸는가. 기준 1장을 바꾸면 결과가 얼마나 흔들리는가 |
| 후보 | 후보 방법 1(센터 사진 1장 고정), 후보 방법 2(같은 자세 여러 장, 정렬 뒤 측정값 평균). 근거 L1 전략 1, 3, 4, PT3, PT4, L6, L7 |
| 조건 가지 | (a) 1014 center 1장, 현재 기준. (b) 1020 기준 위치 3장을 각각 단독 기준으로. (c) 1020 3장을 정렬 뒤 측정값 평균. 영상 평균은 쓰지 않는다(재표본화 편향, L1 전략 4) |
| 적용 모듈 | joint 대조군과 v2 joint 특징(QR 평균 가로 이동, 위 아래 선 기울기 차), control 대조군 |
| 고정 조건 | 1절 전부. 기준만 바꾸고 측정기, 특징, 학습식, 분할은 손대지 않는다 |
| 지표 | joint `|eT| <= 0.01` 통과율과 최대오차, control `|eY| <= 0.045` 통과율과 최대오차, 축별 평균 절대오차, 처리 시간 ms 중앙값과 p95. (b) 3개 사이의 퍼짐(표준편차, 전폭)을 따로 낸다 |
| 날짜 분할 | 1014만 학습 후 1029 평가, 날짜별 80/20 5-fold. 두 가지를 다 낸다 |
| 판정 기준 (실험 전 고정) | 1. (c)가 (a)보다 날짜 분할 통과율을 2.0%p 이상 올리고 최대오차가 늘지 않으면 여러 장 평균을 채택한다. 2. 그렇지 않으면 1장 고정을 유지한다. 3. (b) 3개 사이의 통과율 전폭이 2.0%p를 넘으면 기준 1장 선택이 성적을 좌우한다고 보고 기준 선택 절차를 질문 7로 넘긴다. 4. 기준 교체로 늘어난 처리 시간이 장당 중앙값 5 ms를 넘으면 그 사실을 따로 적는다 |
| 한계 (미리 적어 둠) | 같은 날 반복 센터가 1020 3장뿐이다. 평균 효과의 표본이 3이라 작은 차이는 구별하지 못한다. 1014와 1029에는 반복 센터가 없다 |
| 예상 소요 | 구현 3시간, 실행 1시간, 정리 1시간 |

## 4. 체크리스트 (촬영 없이, 자료 확인으로 답하는 것)

질문 3을 위한 확인 항목이다. 실험이 아니라 자료 요청과 도면 확인이다.

| C1 | QR 판의 설계 도면, 인쇄 피치와 허용 공차 | 장비 도면 | 격자 좌표를 mm로 쓸 수 있는지 판단 |
| C2 | QR 부착 위치 공차, 판 평면성 | 같음 | 좌표 정의의 오차 예산 |
| C3 | 팀이 정한 센터 명령 자세를 판 기하로 말할 수 있는 표식이 있는지 | 장비 실물, 도면 | 좌표 정의 가능 여부 |
| C4 | 카메라 장착 사양(초점거리, 판까지 거리, 회전축 위치) | 장비 사양서 | A13 자기보정의 d=0 가정 확인 |

| 촬영 | center 10장, 그리고 Y 5수준(0, ±0.5, ±1.0) 각 3장, T 5수준(0, ±0.5, ±1.0) 각 3장 |
| 합계 | 10 + 30 + 30 = 70장 |
| 같이 기록 | R1과 같은 항목, 그리고 카메라 장착 사양과 판까지 거리 |
| 판정 기준 (촬영 전 고정) | 1. 기존 모델을 그대로 두고 센터만 새로 찍어 넣었을 때 `|eT| <= 0.01` 통과율이 1014 학습 후 1029 성적의 90% 이상이면 모델 고정, 센터 재촬영으로 결론한다. 2. 아니면 감도(px/mm, px/단위)를 2자유도로만 다시 맞춰 보고, 그래도 안 되면 장비마다 재학습으로 결론한다 |
| 왜 필요한가 | 다른 로봇 자료가 하나도 없다. 날짜를 장비 대용으로 쓴 A3, A20은 대용일 뿐이다 |

### 5.3 R3 신규 날짜 외부 시험 (질문 8)

기존 B6 계획(신규 날짜 100장)을 그대로 쓴다. 575장 중 341장이 개발 노출이므로, E1과 E2의 결론은 R3 자료가 오기 전까지 개발 자료 안의 비교로만 적는다.
