# [9] 정지 단계 조사방법론

작성 2026-11-04. 지침은 [문헌연구/AGENTS.md](../../../문헌연구/AGENTS.md)와 [ALGORITHM_RULES.md](../../../../../ALGORITHM_RULES.md)를 따른다.

## 1. 목적

로봇이 이동 명령을 마치고 멈춘 뒤, 흔들림이 가라앉기를 기다렸다가 사진을 찍는다.
이 단계는 "멈춘 뒤 언제 찍을지"와 "멈춘 뒤에도 판이 움직이는지"를 정한다.

정지 판정이 늦으면 턴마다 시간이 낭비된다.
너무 이르면 잔진동이 사진에 남아 측정이 흔들리고, 다음 명령이 틀어진다.

근거 수치 (우리 자료)
- 허용 ±0.045는 Y로 0.65 px이다. T 1단위는 80.3 px이다.
- 점 측정 잡음은 0.009~0.015 px이다. 536점의 유효 독립 정보는 약 19다.
- 하루 안 영점 흔들림은 가로 0.84 px 이하다. 백래시 β는 −0.34 px이다.
- 날짜 간 세로 영점 이동은 +0.44 px이다. 카메라 이동으로 보며, QR에서 가로선을 빼서 상쇄한다(A15).
- 지금 자료는 모두 명령한 자리에 멈춰 찍은 정지 사진이다. 멈춘 직후부터 시간 순으로 찍은 사진은 한 장도 없다.
- 그래서 정착 시간, 잔진동 크기, 정지 후 드리프트는 아직 잰 적이 없다. 캔버스 s9의 빈 것은 "B1 대기 시간별 반복 촬영"이다.

## 2. 해결할 질문

캔버스 노드 s9의 질문 1, 2에 3~6을 더했다.

1. 멈춘 뒤 얼마나 기다려야 하는가? (정착 시간)
2. 기다리는 동안 판이 계속 움직이는가? (정지 후 드리프트. 서보 미세 흔들림, 크리프, 열)
3. 잔진동이 다 가라앉았는지 사진만으로 판정할 수 있는가? 연속 몇 장의 차이를 어떤 임계(px)로 보면 되는가?
4. 정착 시간은 이동량, 가감속, 이동 방향(T 회전, Y 이동)에 따라 달라지는가? 미리 한 번 재서 고정할 수 있는가, 턴마다 판정해야 하는가?
5. 기다리는 시간과 여러 장 평균을 어떻게 나눠 써야 하는가? 어느 시간 길이부터 평균의 이득이 멈추고 드리프트가 커지는가?
6. 컨트롤러의 정지 신호(인포지션)와 실제 카메라 기준의 정지는 어긋나는가? 카메라가 따로 판정해야 하는가?

## 3. 검색어

블록 안은 OR, 블록 사이는 AND로 묶는다.

## 4. 검색 기록

경로 사정
- OpenAlex API는 이날 공용 무료 사용량이 다 떨어져 429(Rate limit)로 막혔다. 키 발급은 사용자 정보가 필요해 하지 않았다.
- arXiv API와 Semantic Scholar API도 429로 막혔다. 기다렸다 다시 해도 같았다.

- 대신 Crossref API로 서지를 확인하고, 웹 검색으로 후보를 찾았다. 특허는 USPTO 공보 PDF(image-ppubs.uspto.gov)를 받아 첫 면의 서지와 초록을 직접 확인했다. arXiv 논문은 arxiv.org 초록 페이지와 PDF로 확인했다.

## 5. 선정 결과와 이유

기존 문헌 중 쓸 것

- [Le Reun 2022](../../../문헌연구/04_Y_T_오차_보정/논문/03_LeReun2022_Robotica_열드리프트_백래시_위치성능/요약.md): 열 드리프트를 시간에 따라 재야 한다는 근거(질문 2).
- [ASM US7248931](../../../문헌연구/01_주제_관련/원인분석/특허/06_US7248931_ASM_고정기준점_드리프트측정/요약.md): 영상 안 고정 기준과의 상대 거리로 드리프트를 잰다(질문 2, 6).
- [Ji 2025](../../../문헌연구/01_주제_관련/유사연구/논문/07_Ji2025_KSME_웨이퍼이송로봇_위치모니터링_자동티칭/요약.md): 웨이퍼 이송 로봇의 진동 변위를 카메라로 실시간 계측(질문 1, 3).
- [NIST Gauge R&R](../../../문헌연구/04_Y_T_오차_보정/논문/15_NIST_eHandbook_GaugeRR_측정시스템/요약.md): 반복성, 안정성, 드리프트를 나눠 재는 절차(질문 2, 5).
- 1단계에서 이미 고른 [Yoon 2023](../1_촬영/논문/03_Yoon2023_Electronics_웨이퍼로봇_비대칭속도_정착시간), [Lavatelli 2017](../1_촬영/논문/04_Lavatelli2017_TIM_모션블러_DIC불확도), [SCREEN US9327488](../1_촬영/특허/02_US9327488_SCREEN_정렬이송_촬영시점)은 중복을 피하려 다시 고르지 않고 링크로 쓴다.

새로 고른 논문
1. Yoshimoto 외 2017, PTEP (arXiv 1704.06814). 스테이지가 엔코더 목표에 닿은 순간부터 30장(0.1 s)을 찍어 프레임 사이 위치 차이로 잔진동을 쟀다. 가속도 5 m/s² 넘으면 0.12 s 안에 가라앉지 않았다. 우리 B1 실험(대기 시간별 반복 촬영)의 방법 그대로다. 질문 1, 3, 4, 6.
2. Njaastad 외 2021, MIC 42(2) 83–98 (오픈액세스). 로봇에 막대로 단 3D 카메라가 이동 뒤 흔들린다. 촬영 전 정착을 입력 성형(ZV, ZVD, EI)으로 줄였다. 고정 대기 대신 이동 궤적으로 정착 시간을 줄이는 길. 질문 1, 4.
3. Huang 외 2022, JAMDSM 16(1) JAMDSM0014 (J-STAGE 오픈액세스). 마커와 고속 카메라로 공작기계 진동과 동적 운동 오차를 잰다. 조명, 에지 검출 방식이 분해능에 주는 영향도 본다. 카메라로 정착을 재는 측정 방법과 분해능의 근거. 질문 3, 5.
4. Czerwinski 외 2009, Optics Express 17, 13255 (오픈액세스). 위치 측정 신호의 앨런 분산으로 평균 시간을 고른다. 짧은 시간은 평균이 잡음을 줄이고, 긴 시간은 드리프트가 다시 키운다. 대기와 평균 장수를 나누는 기준. 질문 2, 5.

새로 고른 특허
1. US8352076 B2, Canon (Someya), 2013 등록. 카메라 속도가 임계 이하이고 예상 정지 위치와의 차이가 임계 이하일 때만 촬영을 허가한다. 고정 대기의 낭비를 문제로 든다. 질문 1, 6.
2. US11534908 B2, Fanuc (Oono, Yamada), 2022 등록. 제어 주기에 맞춰 연속 촬영하고, 연속 두 장의 손 위치 차이를 진동량으로 보아 허용 범위를 넘으면 동작 프로그램을 고친다. 사진만으로 정착을 판정하는 방법. 질문 3, 4.
3. US9718187 B2, Canon (Ishikawa 외), 2017 등록. 입력측 엔코더가 목표에 닿은 때부터 출력측으로 계산한 끝단 진동폭이 수렴 범위에 들 때까지의 시간을 재어 정지 시간으로 정한다. "한 번 재서 고정"하는 방법과 인포지션과 실제 정지의 차이. 질문 1, 4, 6.
4. US7791043 B2, Hitachi High-Technologies (Seya, Nagamatsu), 2010 등록. 위치 결정 뒤 고정 기구로 눌러 정지 강성을 높여 진동과 드리프트를 줄인다. 멈춘 뒤에도 위치가 시간에 따라 흐른다는 문제 정의. 질문 2.

메모
- 정지 후 서보 미세 흔들림(헌팅)을 다룬 원문 공개 논문은 찾지 못했다. 질문 2의 서보 쪽 근거는 비어 있다.
- 모든 선정 문헌은 우리 장비와 다르다. 정착 시간, 진동 크기 같은 수치는 우리 로봇에 그대로 쓰지 않는다. B1 실험으로 직접 재야 한다.
