# 히스테리시스 기반 전환: 전환 횟수 상한과 평균 체류 시간

- 원제: Hysteresis-based switching algorithms for supervisory control of uncertain systems
- 원문 파일: `Hespanha2003_Automatica_hysteresis_switching.pdf` (같은 폴더)
- 전문 번역: [번역.md](번역.md)
- 저자: João P. Hespanha, Daniel Liberzon, A. Stephen Morse
- 서지: Automatica 39(2), 263-272, 2003. Brief Paper. DOI 10.1016/S0005-1098(02)00241-8
- 링크: https://doi.org/10.1016/S0005-1098(02)00241-8 , PDF https://web.ece.ucsb.edu/~hespanha/published/journal-hhs-final.pdf
- 근거 상태: 원문 확인 (본문 전체를 PDF에서 뽑아 읽음)

## 핵심

모르는 파라미터를 가진 공정을, 후보 제어기 여러 개 사이를 오가며 제어하는 틀을 다룬다.
후보마다 감시 신호 μ_p 를 만든다. μ_p 가 작을수록 그 후보가 맞을 가능성이 높다.
전환 규칙은 단순하다.
지금 쓰는 후보 q 의 감시 신호가, 가장 작은 감시 신호의 (1+h) 배를 넘어설 때만 바꾼다.
h 가 히스테리시스 상수다. h 가 없으면 잡음 근처에서 최솟값이 계속 바뀌어 무한히 빠른 전환(채터링)이 난다.

이 논문의 새 내용은 두 가지다.

1. 척도 독립 히스테리시스 전환의 전환 횟수 상한을 닫힌 식으로 준다 (보조정리 1).
   임의 구간 (t_0, t) 에서 전환 횟수는
   N ≤ 1 + m + (m / log(1+h)) * log[ μ_l(t) / min_p μ_p(t_0) ]
   을 넘지 못한다. m 은 후보 개수다.
   즉 전환 횟수는 후보 수에 비례하고, 감시 신호가 자란 배율의 로그에 비례하며, log(1+h) 에 반비례한다.
2. 파라미터가 연속체일 때 쓰는 계층적 히스테리시스 전환을 새로 만든다 (보조정리 2).
   연속체 P 를 유한 개 부분집합 D_i 로 나누고, 최소화를 두 층으로 한다.
   먼저 각 D_i 안의 최솟값을 구하고, 그다음 그중 최솟값을 고른다.
   전환 횟수 상한은 (11)로 같은 꼴을 유지한다.

상한이 있으면 평균 체류 시간이 나온다.
잡음과 외란이 있는 경우 (5.2절)
  τ_AD = log(1+h) / (2 λ m),
  N_0 = 1 + m + (m / log(1+h)) * log[ (μ̃(0) + B_1 + C_1 + ε) / ε ]
이다.
h 를 키우거나 가중 λ 를 줄이면 평균 체류 시간을 원하는 만큼 늘릴 수 있고, 그러면 전환 시스템이 안정하다는 기존 결과(Hespanha and Morse 1999b)를 그대로 쓸 수 있다.

잡음도 외란도 미모형화 동역학도 없으면 전환은 유한 시간 안에 완전히 멈추고, 그 뒤 출력이 지수적으로 0으로 간다 (명제 5).
잡음과 외란이 있으면 전환은 멈추지 않지만 모든 신호가 유계이고, 설계 상수 ε 을 작게 잡을수록 최종 오차 영역이 작아진다 (명제 6).
미모형화 동역학까지 있으면 준전역 의미의 강건성만 보장된다 (정리 7).

## 정량 수치

| 항목 | 값 |
|---|---|
| 전환 횟수 상한 | N ≤ 1 + m + (m / log(1+h)) * log[ μ_l(t) / min_p μ_p(t_0) ] |
| 평균 체류 시간 | τ_AD = log(1+h) / (2 λ m) |
| 전환 조건 | (1+h) min_p μ_p(t) ≤ μ_q(t), q 는 현재 선택 |
| 채터링 회피 조건 | μ_p(t) ≥ ε > 0 가 모든 p, t 에서 성립 |
| 안정 여유 조건 | 모든 i ∈ M, p ∈ D_i 에서 A_{ip} + λ_0 I 가 안정 |
| 최종 오차 영역 | 원점 근방 크기가 g * ε 에 비례, ε → 0 이면 0 |
| 설계 자유도 | h (히스테리시스 폭), λ (가중), ε (바닥값), m (후보 수) |

h 는 "양수"라는 것 말고 구체적 권장값을 주지 않는다. 상한 식에서 h 와 전환 횟수의 맞바꿈만 준다.
h 를 키우면 전환이 줄고 평균 체류 시간이 늘지만, 더 나쁜 후보를 더 오래 쓰게 된다.

## 우리와의 관계

관련도: ◎

답하는 질문: 2 (언제 다음 단계로 넘어가는가), 3 (언제 되돌아가는가), 6 (히스테리시스 폭과 연속 확인 횟수)

- 우리 과제의 "T 모드"와 "Y 모드"는 후보 제어기 두 개(m = 2)로 그대로 대응한다.
  이 논문의 틀에서 전환 논리의 입력은 각 모드의 감시 신호다.
  우리는 추정한 |eT| 와 |eY| 를 각각의 감시 신호로 쓸 수 있다.
- 임계값을 하나만 두면 잡음 근처에서 T 와 Y 를 왔다 갔다 하게 된다.
  우리 허용값은 0.045 이고 Y로는 0.65 px, 점 잡음은 0.009~0.015 px 이다.
  남은 T 가 Y 추정으로 5.6배 번지므로, 경계 근처에서 추정값이 쉽게 뒤집힌다.
  이 논문은 그 뒤집힘을 막는 가장 단순한 장치가 곱셈꼴 여유 (1+h) 임을 보여 준다.
- 전환 횟수 상한 식이 우리에게 직접 쓸모 있다.
  우리는 턴이 20번뿐이다.
  전환에 턴을 쓰면 수정에 쓸 턴이 줄어든다.
  m = 2 를 넣으면 N ≤ 3 + (2/log(1+h)) * log(초기 오차비) 가 되어, h 를 정하면 전환에 쓰는 턴의 상한을 미리 계산할 수 있다.
  예를 들어 h = 0.5 이고 감시 신호 비가 100배면 N ≤ 3 + 2*4.605/0.405 ≈ 26 으로 20턴을 넘는다.
  h = 2 면 N ≤ 3 + 2*4.605/1.099 ≈ 11 이다.
  즉 우리 턴 예산에서는 h 를 크게 잡아야 한다는 방향이 바로 나온다.
- 주의할 차이: 이 논문은 연속 시간 신호를 다루고, 우리는 턴마다 한 장씩 찍는 이산 사건이다.
  적분형 감시 신호 μ_p = ∫ e^{-2λ(t-τ)} e_p^2 dτ 는 우리에게 "최근 몇 턴의 잔차 제곱의 지수 가중 합"으로 옮긴다.
  λ 는 몇 턴 전까지 기억할지를 정한다.
- 이 논문은 "연속 확인 횟수"를 직접 다루지 않는다. 여유는 전부 곱셈꼴 h 하나로 들어간다.
  질문 6의 연속 확인 횟수 부분은 이 문헌만으로는 답이 안 나온다.

## 리뷰 카드

- 어떻게 해결했나: 후보마다 감시 신호를 만들고, 현재 후보의 신호가 최솟값의 (1+h) 배를 넘을 때만 전환한다. 이 곱셈꼴 여유로 전환 횟수의 명시적 상한과 평균 체류 시간을 끌어내고, 그것으로 안정성을 증명한다.
- 같은 점: 모드가 여러 개이고 어느 모드가 지금 맞는지 추정으로만 알며, 잘못된 전환이 성능을 망친다는 구조가 같다. 측정에 잡음이 있어 최솟값이 쉽게 뒤바뀌는 상황도 같다.
- 다른 점: 연속 시간, 선형 공정, 무한 시간 지평이다. 우리는 턴이 20번뿐인 이산 과정이고, 전환 대상은 제어기가 아니라 조작 축(T 또는 Y)이다. 또 이 논문은 후보 제어기의 안정 여유를 가정하는데, 우리 Y 축과 T 축은 cos 0.99999 로 거의 같은 방향이라 축 분리 자체가 약하다.
- 가져올 해결책: 모드 전환에 곱셈꼴 히스테리시스 여유 (1+h) 를 둔다. 임계값을 넘었는지가 아니라, 다른 모드가 지금 모드보다 (1+h) 배 이상 나빠야 바꾼다. h 는 전환 횟수 상한 식에 턴 예산 20을 넣어 역산해 정한다.

## 이 단계 후보 방법으로서

- 방법 이름: 곱셈꼴 히스테리시스 모드 전환 (척도 독립 히스테리시스 전환 논리)
- 전제 조건
  - 모드마다 감시 신호를 정의할 수 있어야 한다. 우리는 추정 |eT|, |eY| 또는 그 잔차 제곱의 가중 합을 쓴다.
  - 감시 신호가 0에서 떨어져 있어야 한다. 잡음 바닥 ε 을 더해 준다. 우리 점 잡음 0.009~0.015 px 를 근거로 ε 을 잡는다.
  - 각 모드가 자기 담당 축을 실제로 줄일 수 있어야 한다 (안정 여유 성질에 대응).
- 장점
  - 규칙이 매우 단순하다. 비교 하나와 곱셈 하나다. 계산 비용이 없다.
  - 전환 횟수 상한이 닫힌 식이다. 20턴 예산에서 전환에 몇 턴을 쓸지 미리 계산할 수 있다.
  - 채터링을 구조적으로 막는다. 잡음 한계를 몰라도 된다 (존재만 요구).
  - 체류 시간 방식과 달리 고정된 대기 시간이 없다. 상태가 나빠지면 바로 바꿀 수 있다.
- 단점
  - h 의 권장값을 주지 않는다. 우리가 자료로 정해야 한다.
  - h 가 크면 나쁜 모드를 오래 유지한다. 우리 경우 남은 T 가 5.6배로 번지므로 T 를 오래 미루면 Y 추정 자체가 틀어진다.
  - 축이 거의 같은 방향(cos 0.99999)인 경우를 다루지 않는다. 모드 분리가 약하면 감시 신호 두 개가 거의 같은 값이 되어 전환 판정이 의미를 잃을 수 있다.
  - 정지 판정(질문 7)과 실패 보고(질문 8)는 다루지 않는다. 이 논리는 멈추는 규칙이 아니라 고르는 규칙이다.
- 우리 적용 조건
  - m = 2 (T 모드, Y 모드)로 두고, 감시 신호를 최근 턴들의 축별 잔차 지수 가중 합으로 정의한다.
  - h 는 전환 횟수 상한 N ≤ 1 + m + (m/log(1+h)) * log(초기 신호비) 에 m = 2, 전환 예산(예: 4턴)을 넣어 역산한다. 위 예시 계산대로면 h 는 1 이상이 되어야 한다.
  - ε 은 점 잡음에서 오는 추정 하한으로 잡는다. Y 0.65 px 허용의 몇 분의 일 수준이다.
  - T 의 5.6배 번짐 때문에, T 모드로의 복귀 판정은 Y 기준보다 더 민감하게 (즉 T 쪽 감시 신호에 가중을 더해) 두어야 한다.
  - 시뮬레이션으로만 검증 가능하다. 실제 이동 후 재촬영 자료가 없다. 정지 사진으로 턴을 합성해 전환 횟수와 최종 오차를 본다.
