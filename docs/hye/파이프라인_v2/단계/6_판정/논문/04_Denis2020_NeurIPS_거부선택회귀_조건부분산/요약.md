## 핵심 (원문 확인)

- 회귀에서 "예측을 포기할 수 있는" 틀을 세웠다. 예측기 Γ_f(x)는 값 하나를 내거나 빈 집합을 낸다.
- 두 성능값을 같이 본다.
  - 거부 비율 r(Γ_f) = P(예측을 안 낸 비율)
  - 예측을 냈을 때의 오차 Err(Γ_f) = E[(Y − f(X))² | 예측을 냄]
- 벌점 위험 R_λ(Γ_f) = E[(Y − f(X))² 1{예측함}] + λ r(Γ_f) 를 최소화하면, **최적 규칙은 조건부 분산 σ²(x) = E[(Y − f\*(X))² | X = x] 에 임계값 λ를 거는 것**이다 (명제 1).
  - Γ\*_λ(x) = {f\*(x)} if σ²(x) ≤ λ, 아니면 ∅
  - 이것이 이 논문의 중심 주장이다. 포기 여부를 정하는 정보는 "입력 x에서의 조건부 분산" 하나에 담긴다.
- λ를 고정하면 거부 비율이 통제되지 않는다 (그림 1). 그래서 **거부 비율을 ε로 고정**하는 제약 문제를 푼다.
  - λ_ε = F_σ²⁻¹(1 − ε) 로 두면 Γ\*_ε = Γ\*_λε 이고, 거부 비율은 정확히 ε 이다 (명제 2).
  - 가정 1: σ²(X)의 누적 분포 F_σ² 가 연속이다.
- 초과 위험이 두 항으로 갈린다 (명제 3).
  - 회귀 오차 항: E[(f\*(X) − f(X))² 1{예측함}]
  - 거부 판정 오차 항: E[|σ²(X) − λ_ε| 1{거부 판정이 최적과 다름}]
  - 즉 "값이 틀리는 손해"와 "판정이 틀리는 손해"를 따로 센다.
- 추정 절차는 **반지도 2단계 대입(plug-in)** 이다.
  1. 정답이 있는 자료 D_n (n개)로 회귀 함수 f̂ 와 조건부 분산 σ̂² 를 추정한다. σ̂² 는 잔차 (Y − f̂(X))² 를 X에 다시 회귀해 얻는다.
  2. **정답이 없는 자료 D_N (N개)** 로 경험 누적 분포 F̂_σ̂² 를 만들어 임계값을 맞춘다(교정).
  - Γ̂_ε(x) = {f̂(x)} if F̂_σ̂²(σ̂²(x)) ≤ 1 − ε, 아니면 ∅ (식 4)
  - 임계값 교정에 정답이 필요 없다는 점이 이 방법의 실무적 이점이다.
- 일치성 (정리 1): f̂ 가 L2에서, σ̂² 가 L1에서 일치하면 초과 위험이 0으로 가고, **거부 비율 오차는 E[|r(Γ̂_ε) − ε|] ≤ C N^{−1/2}** 다. C는 절대 상수다. 이 상한은 Dvoretzky-Kiefer-Wolfowitz 부등식에서 나온다.
  - 중요한 점: 거부 비율 보장은 **f̂ 나 σ̂² 의 품질과 무관하게** N만으로 결정된다. 분산 추정이 나빠도 "거부 비율 ε"은 지켜진다. 다만 "거부한 것이 실제로 어려운 사진인가"는 지켜지지 않는다.
- kNN에 적용한 수렴 속도 (정리 2): k_n ∝ n^{2/(d+2)}, u ≤ n^{−1/(d+2)} 일 때

  E[초과 위험] ≤ C ( n^{−2/(d+2)} + log(n)^{α+1} n^{−(α+1)/(d+2)} + N^{−1/2} )

  - 세 항은 각각 회귀 추정 오차, 분산 추정 오차(상한 노름), 임계값 추정 오차다.
  - 가정 5 (α 지수): P_X(0 < |σ²(X) − λ_ε| ≤ t) ≤ c\* t^α. 임계값 근처에 σ² 값이 몰리지 않아야 빠르다. α = 0 이면 아무 가정도 아니다.
- kNN의 σ̂² 는 이산이라 가정 2(연속)를 어긴다. **U[0, u] 균등 잡음 ζ 를 σ̂² 에 더해** 연속으로 만든다. 실험에서는 u = 10⁻¹⁰ 을 썼다.
- 결론부와 광범위 영향에서 저자가 스스로 적은 약점: **조건부 분산 함수를 잘못 추정하면, 사람이 봤어야 할 경계 사례가 자동 처리된다.**

## 우리와의 관계

- 관련도: ◎
- 답하는 질문: **1** (이 값을 믿어도 되는가, 다시 찍어야 하는가), **6** (재촬영과 보류의 규칙, 거부 비율, 믿는다고 한 값의 정답률 보장). 보조로 7 (측정 품질 지표를 σ̂² 의 입력 특징으로 넣는 통로).
- 지금 상태
  - joint 와 control 두 모듈은 값만 내고 "이 값이 믿을 만한가"는 내지 않는다.
  - A8 결과: 이론 σ(약한 방향 0.0233)는 실제 오차 SD(0.149)의 1/6.4 다. 즉 지금 가진 분산 추정은 구조가 틀렸다기보다 **크기가 틀린** 상태다. 이 논문의 틀은 σ̂² 의 절대 크기를 쓰지 않고 **순위(경험 누적 분포)** 만 쓰므로, 6.4배 낙관이 그대로여도 규칙이 돌아간다. 이것이 우리에게 가장 중요한 점이다.
  - A8 결과: 측정 품질 지표 6개와 실제 오차의 순위 상관은 모두 0.08 이하다. 상위 10%를 고르면 실제 최악 10%의 35%가 들어온다(무작위면 10%). 이 논문 기준으로 보면 "σ̂² 의 순위 정확도가 낮은" 상태이고, 그림 3 왼쪽(aquatic + svm) 같은 실패 구간에 해당한다.
- 우리 추론(검증 전)
  - 이 논문을 그대로 쓰면 "거부 비율 ε = 20%" 같은 예산은 지킬 수 있지만, "거부한 20%가 실제 나쁜 사진인가"는 지금의 σ̂² 품질로는 보장되지 않는다. 그래서 이 논문은 **판정 틀**로 쓰고, 성능은 σ̂² 를 얼마나 잘 만드느냐에 달린다.
  - 우리 과제에서 "거부"는 사람 호출이 아니라 **재촬영 1턴**이다. 비용이 매우 싸다(최대 20턴). 그래서 ε 를 0.2~0.5 처럼 크게 잡아도 손해가 작다. 논문의 airfoil + rf 에서 50% 거부가 오차를 절반으로 줄인 것이 우리가 노리는 모양이다.
  - 정답 없는 자료로 임계값을 맞춘다는 점이 우리에게 특히 맞는다. 우리는 명령한 자리에 멈춰 찍은 정지 사진만 있고 실제 작업 후 도착 사진은 없다. 운용 중 찍히는 사진에는 정답이 없다. 그 사진들을 모아 F̂_σ̂² 를 만들면, 날짜가 바뀌어도 "그날 사진 중 분산 상위 ε"로 임계값이 자동으로 따라간다. 이것은 질문 5(교환 가능성)에도 부분적으로 답한다.

## 리뷰 카드

- 어떻게 해결했나: 포기 여부를 정하는 최적 규칙이 **조건부 분산에 임계값을 거는 것**임을 증명했다(명제 1). 그 다음 임계값을 직접 고르지 않고, 거부 비율 ε 를 먼저 정한 뒤 **정답 없는 자료 N개의 경험 누적 분포에서 ε 분위수를 임계값으로** 삼았다(식 4). 그 결과 거부 비율 오차가 C N^{−1/2} 로 묶이고(정리 1), 실제 실험에서 목표 0.8, 0.5, 0.2 에 대해 실측 0.80, 0.50, 0.19~0.20 을 얻었다(표 1). 분산 추정기는 잔차를 다시 회귀하는 어떤 기성 알고리즘이든 쓸 수 있게 열어 두었다.
- 같은 점: 우리도 사진 한 장마다 "지금 값을 믿고 이동할지" 정해야 하고, 그 판단에 쓸 양은 결국 "이 사진에서의 조건부 분산"이다. 우리는 이미 잔차 기반 분산을 갖고 있다(GLS 잔차, 536점 산포, 가로선 48블록 적합 잔차, NCC). 재촬영 예산도 명시적으로 있다(최대 20턴). 즉 "거부 비율 예산 ε 를 먼저 정한다"는 이 논문의 설정이 우리 운용과 그대로 맞는다. 그리고 우리 σ̂² 는 크기가 6.4배 낙관적인데, 이 방법은 크기가 아니라 순위만 쓰므로 그 결함을 비켜 간다.
- 다른 점: (1) 이 논문은 iid 자료를 가정한다. 우리 사진은 날짜와 자세로 묶여 있고(1020, 1029의 3장 묶음), 날짜가 바뀌면 카메라가 세로 +0.44px 움직이며 하루 안에도 영점이 가로 0.84px 움직인다. F̂_σ̂² 를 전체 자료로 한 번 만들면 날짜 효과가 섞인다. (2) 이 논문의 손실은 L2 제곱 오차지만 우리 판정은 **구간 통과 여부**다(|eY| ≤ 0.045, |eT| ≤ 0.01). "평균 제곱 오차가 반으로 줄었다"가 아니라 "통과율이 몇 %인가"를 봐야 한다. (3) 이 논문의 거부는 사람 개입이라 비싸지만 우리 거부는 재촬영 1턴이라 싸다. 그래서 ε 를 크게 잡는 쪽이 유리하다. (4) 이 논문은 거부한 자료를 버리지만 우리는 **다시 찍어 같은 판정을 반복**한다. 연쇄 거부 확률과 20턴 예산의 관계는 논문에 없다. (5) 341/575장이 개발에 노출돼 있어, F̂_σ̂² 와 ε 를 그 자료로 맞추면 성적이 부풀 수 있다(질문 8).
- 가져올 해결책: 판정 단계를 **2단 구조**로 만든다. 1단은 σ̂²(x) 를 내는 분산 모형이다. 입력은 측정 품질 지표 6개에 GLS 잔차 노름, 536점 잔차 산포, 가로선 48블록 적합 잔차, 세 QR 정수 이동 간격 일치 여부, NCC 최소값을 더해 쓰고, 출력은 (추정 Y 또는 T 오차)² 로 둔다. 학습은 학습 분할의 정답으로만 한다. 2단은 임계값이다. **정답 없이** 그날 찍힌 사진들의 σ̂² 분포에서 1−ε 분위수를 잡는다(식 4 그대로). ε 는 0.2, 0.3, 0.5 를 비교한다. 판정 결과는 세 갈래로 쓴다. σ̂² 가 분위수 아래면 이동, 위면 재촬영(거부), 같은 자리에서 연속 3회 거부면 보류(사람 확인). 평가 지표는 논문의 Êrr 대신 **거부하지 않은 사진의 |eY| ≤ 0.045, |eT| ≤ 0.01 통과율**과 실제 거부율, 그리고 "20턴 안에 정지한 비율"로 바꾼다. F̂_σ̂² 는 날짜 블록 단위로 따로 만들어, 날짜 간 카메라 이동(+0.44px)이 임계값에 섞이지 않게 한다. 검증은 날짜를 나눈 분할(1014만 학습 후 다른 날짜)로 하고, 개발 노출 341장에서 고른 ε 를 새 날짜에 그대로 적용해 통과율이 유지되는지 본다.

## 이 단계 후보 방법으로서

- 방법 이름: **조건부 분산 임계값 거부** (거부 비율 ε 고정, 정답 없는 자료로 분위수 교정). 논문 용어로는 대입 ε 예측기.
- 전제 조건
  - 자료가 iid 다. 학습 자료와 운용 사진이 같은 분포다.
  - σ²(X) 의 누적 분포 F_σ² 가 연속이다(가정 1). 이산 추정기면 작은 균등 잡음 ζ 를 더해 맞춘다.
  - 조건부 분산 σ̂² 를 추정할 잔차 자료가 있다. 즉 정답이 붙은 학습 사진이 필요하다.
  - 임계값 교정용으로 정답 없는 사진 N장이 필요하다. 거부 비율 오차가 N^{−1/2} 이므로 N이 작으면 예산이 흔들린다.
  - 빠른 수렴은 가정 5(임계값 근처에 σ² 값이 몰리지 않음)가 있어야 한다.
- 장점
  - 임계값 교정에 **정답이 필요 없다**. 운용 중 찍히는 사진을 그대로 쓸 수 있다. 도착 사진 정답이 없는 우리 상황에 맞는다.
  - 거부 비율이 설계값대로 나온다(표 1에서 목표 대비 오차 0.01 이내). 재촬영 예산을 미리 계산할 수 있어 20턴 한도를 지키는 설계가 가능하다.
  - σ̂² 의 **절대 크기가 틀려도 순위만 맞으면 작동**한다. A8의 "이론 σ가 6.4배 낙관"이라는 결함을 우회한다.
  - 어떤 분산 추정기와도 붙는다. 지금 쓰는 GLS 잔차나 측정 품질 지표를 그대로 입력으로 넣을 수 있다.
  - 계산이 가볍다. 분위수 하나와 비교 한 번이다. 실시간 판정에 부담이 없다.
  - 이론 보장이 명시적이다(정리 1, 정리 2). 임계값 추정 오차가 N^{−1/2} 로 분리돼 있어 필요한 N을 역산할 수 있다.
- 단점
  - **"거부하지 않은 것의 정답률"을 보장하지 않는다.** 보장하는 것은 거부 비율뿐이다. 질문 6의 뒷부분(믿는다고 한 값의 정답률 보장)은 이 방법만으로 답이 안 된다. 그쪽은 컨포멀 예측(논문 01, 02)이나 Learn-then-Test 가 필요하다.
  - σ̂² 를 잘못 추정하면 경계 사례가 그대로 통과한다(저자가 직접 적은 약점). 측정 품질 지표의 순위 상관이 0.08 이하라는 A8 결과는 이 위험이 지금 실재함을 뜻한다.
  - 오차 곡선이 단조가 아닐 수 있다(aquatic + svm: 거부 80%에서 오차가 오히려 커짐). 분산 추정기를 바꿔 가며 확인해야 한다.
  - iid 가정이 우리 자료와 어긋난다. 날짜 간 카메라 이동과 하루 안 영점 드리프트가 있다.
  - 손실이 L2 제곱 오차다. 우리의 구간 통과 판정과 직접 맞지 않는다.
  - 거부가 반복될 때(재촬영 후 또 거부) 무슨 일이 생기는지 다루지 않는다. 20턴 소진 위험을 따로 계산해야 한다.
  - N^{−1/2} 는 느리다. 거부 비율 오차를 0.01 로 줄이려면 N이 수천 장 규모여야 한다. 우리는 575장뿐이다. 현실적으로 ε 오차 0.03~0.05 를 각오해야 한다.
- 우리 적용 조건
  - σ̂² 학습은 학습 분할 사진의 정답으로만 한다. 시험 사진의 정답을 쓰지 않는다.
  - F̂_σ̂² 는 **날짜 블록 단위**로 따로 만든다. 새 날짜가 들어오면 그날 사진으로 다시 만든다. 이렇게 하면 날짜 간 카메라 이동이 임계값에 섞이지 않고 운용 중 갱신도 된다.
  - joint(T 판정, |eT| ≤ 0.01)와 control(Y 판정, |eY| ≤ 0.045)은 분산 모형과 ε 를 따로 둔다. 특징 차원과 허용 범위가 다르다.
  - ε 후보는 0.2, 0.3, 0.5 로 비교한다. 지표는 거부하지 않은 사진의 통과율, 실제 거부율, 20턴 안 정지 비율, 턴당 평균 촬영 수다.
  - σ̂² 추정기는 두 가지 이상 비교한다(선형 회귀, 비선형 트리 계열). 논문 그림 4처럼 회귀기와 분산 추정기를 다르게 조합해 본다.
  - 이산 σ̂² 를 쓰면 U[0, 10⁻¹⁰] 균등 잡음을 더해 동점을 깬다.
  - 평가는 날짜를 나눈 분할로 한다. 개발 노출 341장에서 고른 ε 와 분산 모형을 새 날짜에 고정 적용해 통과율이 유지되는지 본다. 유지되지 않으면 그 ε 는 개발 자료에 과적합된 것이다(질문 8).
  - 이 방법 하나로 "믿은 값의 정답률"을 주장하지 않는다. 컨포멀 예측 구간(논문 01, 02)과 겹쳐 쓴다. 거부는 예산 통제, 컨포멀은 포함 확률 보장으로 역할을 나눈다.
