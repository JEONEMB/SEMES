### V2-6-E1 구간 교정과 선택적 정확도

**답하는 질문**
- 1 이 값을 믿어도 되는가, 다시 찍어야 하는가
- 4 이론 시그마를 자료로 다시 맞출 수 있는가, 폭이 사진마다 달라지는가
- 5 날짜가 바뀌어 교환 가능성이 깨져도 범위가 맞는가
- 6 믿은 값의 정답률을 보장할 수 있는가
- 7 측정 품질 지표를 어떻게 섞는가
- 8 개발 자료로 고른 규칙이 부풀려졌는가

**후보** (00_단계.md 표에서 고름)
- C1 불확도 스칼라를 컨포멀화한 구간. 점수 s = 오차 절대값 나누기 u(x), 교정 분위수 q. 출처 L1 2.3절, L2 5.2절
- C2 국소 가중 분할 컨포멀. u(x)를 품질 지표로 적합. 출처 L2 5.2절, L9, L10
- C7 측정 품질 단일 임계 게이트. 비교 기준으로만 둔다. 출처 L11, PT1, PT3
- 선택적 정확도 람다 탐색. 이항 CDF 상한으로 "허용 안일 확률이 1 빼기 알파 이상"을 보장. 출처 L1 5.5절
- 대조군: 기존 final 두 모듈(판정 없음, 전부 믿는다)

**고정 조건**
- u(x)의 1안은 A8이 이미 내놓은 GLS 예측 시그마를 그대로 쓴다. 2안(C2)은 품질 지표 7개를 MAD 회귀로 적합한다. 입력은 NCC 최소값, ECC 수렴 반복수, 점 이상치 수, QR 간격 일치, 536점 P12 잔차 RMS, 가로선 48블록 적합 잔차, GLS 잔차 노름이다.
- 알파 0.05, 델타 0.1. 이 값은 우리 제안이며 사용자 확정 전이다. 민감도로 알파 0.01과 0.10도 함께 돌린다.
- 교정과 시험은 항상 다른 날짜 블록이다. 교정 분할 3가지를 각각 돌린다.
  - (가) 무작위 분할. 교환 가능성이 성립한다고 보는 상한 기준선이다.
  - (나) 날짜 블록 분할. 1014와 1020으로 교정하고 1029로 시험한다.
  - (다) 날짜마다 q를 따로 구해 서로 비교한다. 교환 가능성 파손 크기를 재는 가장 싼 실험이다.
- 중첩 CV로 임계값 선택을 바깥 루프 안에 넣는다(L13). q, 람다, C2 가중치를 모두 안쪽 학습 자료에서만 정한다.
- A15(QR에서 가로선 빼기)를 적용한 특징과 적용하지 않은 특징을 둘 다 돌린다.

**지표**
1. 주변 포함률 (목표 1 빼기 알파)
2. 날짜별 포함률, 자세별 포함률
3. 구간 반폭의 히스토그램, 폭 구간별 포함률의 최솟값 (SSC)
4. 선택적 정확도. 믿는다고 한 사진의 허용 초과율
5. 재촬영 비율, 보류 비율
6. q 값과 A8의 6.395의 대조
7. 판정 층을 더해 늘어난 처리 시간 ms

**판정 기준 (실험 전에 고정한다)**

| 후보 | 채택 조건 |
|---|---|
| C1 보장 | (나) 분할에서 주변 포함률이 목표의 ±0.03 안. 동시에 날짜별 포함률 최솟값이 목표 빼기 0.05 이상 |
| C1 쓸모 | 구간 반폭 중앙값이 허용(control 0.045, joint 0.01)의 3배 이하. 3배를 넘으면 거의 모든 사진이 재촬영이 되어 20턴 안에 못 멈춘다. 그때는 "구간은 보장되나 운용 불가"로 보고하고 C5의 N장 평균으로 폭을 줄이는 쪽으로 넘긴다 |
| C2 | C1 대비 폭 중앙값이 10% 이상 줄고 SSC 최솟값이 나빠지지 않을 때만 채택한다. 아니면 버린다. A8의 순위 상관 0.079를 보면 실패 가능성이 크다 |
| C7 | C1과 C2가 C7을 이기지 못하면 복잡한 쪽을 쓰지 않는다 |
| 선택적 정확도 | 조건을 만족하는 람다가 존재하고, 그때 재촬영 비율이 50% 이하 |
| 공통 | 기존 final 대비 통과율과 최대오차가 나빠지지 않을 것 |

**예상 소요**: 구현 4시간, 실행 1시간 미만(캐시를 재사용하므로 영상 처리가 없다), 보고 2시간.

**예상되는 나쁜 결과와 그때의 해석**
A8의 6.4배를 그대로 적용하면 반폭이 0.0233 곱하기 6.4 곱하기 1.96, 약 0.29다. 허용 0.045의 6배가 넘는다(우리 계산, 검증 전). 이 실험의 1순위 목적은 이 숫자를 확정하는 것이다. 크게 나오면 그것 자체가 결론이다. 판정 층이 아니라 추정기나 장수를 고쳐야 한다는 뜻이 된다.

### V2-6-E2 범위 밖 사진 탐지

**답하는 질문**
- 3 학습 범위 밖 사진을 알아챌 수 있는가
- 7 품질 지표를 어떻게 섞는가 (일부)

**후보**
- C4 특징 공간 마할라노비스 분포 밖 점수. 단계 앙상블, Ledoit-Wolf 축소 공분산. 출처 L5, L12
- C3 조건부 분산 임계 거부. 거부 비율 엡실론 고정, 정답 없는 자료로 분위수 교정. 출처 L4 명제 1과 2, 식 4
- C7 단일 임계 게이트 (대조군)
- 대조군: 기존 final. 범위 밖을 알아채지 못하고 값을 그대로 낸다

**고정 조건**
- 특징은 joint 204차원과 control 536점 변위 두 가지를 따로 본다. 536점은 주성분 상위 약 19개로 줄인다. 536점의 유효 독립 정보가 약 19이기 때문이다.
- 공분산은 Ledoit-Wolf 축소를 쓴다. 575장으로 204차원 전체 공분산은 거의 특이 행렬이다.
- 임계는 학습 자료 거리 제곱의 99% 분위수로 정한다. 범위 밖 자료를 보고 정하지 않는다.
- A15 적용 후 특징에 적용한다.
- C3의 엡실론 후보는 0.2, 0.3, 0.5다. 분포 추정은 날짜 블록마다 따로 만든다. joint와 control은 분산 모형과 엡실론을 따로 둔다.
- 범위 밖 라벨 3종을 A0와 A20에서 가져온다. 새로 만들지 않는다.
  - (가) 1020 T+2.00 12장. 명령 범위 밖이다(A0).
  - (나) 1014만 학습했을 때의 1029 전체. 날짜 범위 밖이고 A20에서 joint 0%였다.
  - (다) 1020 혼합 자세. 학습 자료가 한 사분면뿐이다(plan.md).

**지표**
1. 결정적 시험. (나)에서 joint 0% 실패 사진을 임계 초과로 미리 걸러내는 비율
2. (가)와 (다)의 검출율
3. 정상 사진의 오경보율 (목표 1% 근처)
4. 거리 점수와 실제 오차의 순위 상관. A8의 0.079와 비교
5. C3의 설계 엡실론과 실제 거부 비율의 차, 거부 후 남은 사진의 평균오차와 최대오차
6. 점수 계산 시간 ms

**판정 기준 (실험 전에 고정한다)**

| 후보 | 채택 조건 |
|---|---|
| C4 핵심 | (나)의 검출율 0.9 이상, 동시에 정상 사진 오경보율 0.05 이하. 이것이 C4의 결정적 시험이다 |
| C4 제외 | (나)를 못 잡으면 (가)를 잡아도 채택하지 않는다. (가)는 NCC 게이트로 이미 잡히기 때문이다 |
| C3 | 엡실론 0.3에서 실제 거부 비율이 설계값 ±0.05 안이고, 남은 사진의 최대오차가 거부 전보다 30% 이상 줄 것 |
| 공통 | C7 단일 게이트를 이기지 못하면 쓰지 않는다 |

**예상 소요**: 구현 3시간, 실행 30분, 보고 1.5시간.

**한계를 미리 적는다**
우리 범위 밖은 날짜 간 0.44 px 수준으로 작다. 거리 점수가 그 크기를 구분할 만큼 민감하지 않을 수 있다. 자세 격자 변형은 L5가 보장하지 않는 우리 변형이다. 실패하면 그대로 실패로 보고한다.

  - (ㄴ) 고정 알파를 매 턴 쓴다. 누적이 커지는 것을 그대로 보고한다.
  - (ㄷ) 마지막 정지 판정에만 알파를 쓰고, 중간 턴은 판정 없이 이동한다.

**지표**

4. 같은 자세 반복의 Y 전폭과 3시그마, plan.md 보조 기준 (b) 전폭 0.045 이하 통과 여부
5. N 증가에 따른 턴당 처리 시간 ms와 20턴 총 시간
6. 모의 20턴에서 허용 안에 멈춘 비율, 평균 턴 수, 보류 비율, 20턴 소진 비율
7. 연쇄 거부(재촬영 뒤 또 거부) 확률

| 항목 | 채택 조건 |
|---|---|
| N 결정 | 하한이 허용의 1/2 이하일 것. 넘으면 "평균으로는 못 맞춘다"가 결론이고 구조적 상쇄(A15)로 되돌아간다 |
| 턴당 장수 | N 곱하기 턴당 처리 시간이 20턴 시간 예산 안에 들 것 |
| 오류 예산 규칙 | 20턴 소진 비율 5% 이하이면서 선택적 정확도를 지키는 가장 느슨한 규칙을 고른다 |
| C8 대리 | 3장 묶음 안 흩어짐이 실제 오차와 순위 상관 0.3 이상일 때만 신호로 인정한다. A8의 0.079보다 뚜렷해야 한다 |
| 공통 | 기존 final 1장 대비 통과율이 올라갈 것 |

**예상 소요**: 구현 3시간, 실행 30분, 보고 2시간.

**한계를 미리 적는다**
모든 자료가 명령한 자리에 멈춰 찍은 정지 사진이고, 실제 작업 뒤 도착 사진이 없다. 그래서 20턴 모의는 구동계 반복 오차를 포함하지 않는다. 실제 복귀 성공으로 해석하지 않는다.

### 실행 순서

E1, E2, E3 순서로 한다. E3의 재촬영 임계가 E1의 구간 반폭을 입력으로 받기 때문이다. E2는 E1과 독립이라 먼저 돌려도 된다.

## 2. 실기 촬영이 필요한 실험 (촬영 요청서)

아래는 정지 사진으로 답할 수 없다. 로봇을 실제로 움직여 찍어야 한다.

## 3. 보고 때 반드시 적는 문구

- 341/575장은 개발에 노출된 자료다. 여기서 나온 성적은 독립 검증이 아니다.
- 교정 자료가 100장에서 200장이라 여유가 엡실론 약 0.05다. 95% 보장이 실제로는 90%에서 100% 사이에서 흔들린다(L1 표 1).
- 알파 0.05와 델타 0.1은 우리 제안이며 사용자 확정 전이다.
- 모든 오프라인 결과는 정지 사진 평가다. 실제 센터 복귀 성공률이 아니다.
- 20턴 모의는 구동계 반복 오차를 포함하지 않는다.
