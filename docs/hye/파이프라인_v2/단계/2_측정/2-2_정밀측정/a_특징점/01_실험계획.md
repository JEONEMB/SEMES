## 이 계획이 지키는 것

- 후보는 `00_단계.md`의 "후보 방법 (문헌 기반 재작성)" 표에서만 고른다. 표에 없는 방법은 넣지 않는다.
- 같은 자료, 같은 분할을 쓴다.
  - 자료: `data/clean/` 정지 사진, center 제외.
  - 점 측정 캐시: [A0 캐시](../../../../../../../experiments/hye/20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache)를 먼저 재사용한다(`points.csv`, `disp.f32`, `quality.f32`, `lines.f32`). 새 정밀화 방법만 다시 재고, 나머지 단계는 캐시 값을 그대로 쓴다.
  - control 비교 분할: [validation/splits.json](../../../../../../../experiments/hye/20261028_1327_final_Y_T%20control/validation/splits.json) 고정 4-fold.
  - joint 비교 분할: 341장 외부 4-fold.
  - 추가로 날짜를 나눈 평가를 모든 실험에 넣는다(날짜 통째 분할, 그리고 날짜별 80/20 5-fold).
- 대조군은 기존 final 모듈이다.
  - [20261028_1258_final_Y_T_joint](../../../../../../../experiments/hye/20261028_1258_final_Y_T_joint)
  - [20261028_1327_final_Y_T control](../../../../../../../experiments/hye/20261028_1327_final_Y_T%20control)
  - 두 폴더와 기존 결과, 원본은 고치지 않는다. 새 실험은 `experiments/hye/YYYYMMDD_HHMMSS_V2_2-2a_<주제>/`에 C++17로 만든다.
- 지표는 정확도와 시간을 함께 적는다.
  - 정확도: 축별 평균 절대오차, 최대 절대오차, 통과율. joint는 `|eT| ≤ 0.01`, control은 `|eY| ≤ 0.045`.
  - 점 수준: 같은 자리 반복 잡음 σ(px), 부화소 위상별 편향 곡선, 유효 독립 정보 수.
  - 시간: 장당 측정 시간 중앙값과 p95(ms), 초기화 비용 별도.
- 판정 기준은 실험을 돌리기 전에 아래 표에 고정한다. 돌린 뒤에 바꾸지 않는다.
- 시험 정답은 학습, 문턱 결정, 후보 선택에 쓰지 않는다. 문턱은 센터 사진과 반복 묶음 분포로 정한다.
- 341/575장은 개발에 노출된 자료다. 모든 보고에 이 문장을 적는다.

1. E1 → 2. E2 → 3. E3 순으로 한다.
- `00_단계.md`의 판단대로 이 단위가 최종 Y/T를 크게 바꿀 가능성은 낮다. 그래서 E1, E2가 모두 "보류" 또는 "기각"이면 E3는 점 수준 1차 관문까지만 하고 멈춘다.
- 결과는 모두 `02_실험결과.md`에 모은다. 채택하지 못한 것도 수치와 함께 남긴다.

| 답하려는 질문 | Q7, 그리고 control 보조 기준 (b). 지금 점 잡음 0.009~0.015 px는 멈춰 찍은 사진에서 잰 값이다. 실제로 움직여 돌아온 뒤에도 같은가. |
| 자세 | 서로 다른 **5자세**(Y 단독 2, T 단독 2, 혼합 1). |
| 횟수 | 자세마다 **5회** 왕복(자리를 떠났다가 같은 명령으로 돌아와 촬영). 총 25장. |
| 조건 | 같은 날 안에서 연속으로. 세션 중간에 카메라를 건드리지 않는다. 시작과 끝에 센터 사진을 각 1장씩 더 찍어 그날의 영점 이동을 잰다. |
| 보는 값 | 점별 반복 σ, 사진 사이 변위의 전폭, Y 전폭이 0.045 이하인지, 유효 독립 정보 수. |

### 촬영 요청 R3 흐림이 심한 조건에서 정밀화가 버티는가

| 항목 | 내용 |
|---|---|
| 답하려는 질문 | Q4. 1020 자료의 흐림은 약 7 %뿐이다. 더 흐릴 때 어디서 무너지는지 모른다. |
| 자세 | 센터 포함 **3자세**(센터, Y 단독 1, T 단독 1). |
| 횟수 | 자세마다 초점을 **4단계**로 바꿔 각 2장. 총 24장. 초점 단계는 선명, 약간 흐림, 중간 흐림, 심한 흐림. |
| 조건 | 초점만 바꾸고 자리와 조명은 고정. 각 단계의 초점 설정값을 기록한다. |
| 보는 값 | 단계별 점 σ, 맞춤 실패율, 측정 성공 여부, E2에서 고른 흐림 층 선택 규칙이 맞게 고르는지. |

R1, R2, R3는 모두 사용자 승인과 실기 일정이 있어야 한다. 승인 전에는 계획으로만 둔다.
