## 1. 오프라인 실험 (data/clean 정지 사진으로 가능)

### V2-2-2c-E1. 1차원 부화소 방법 비교 (S0 대 erf 대 CIS)

| 항목 | 내용 |
|---|---|
| 질문 | 질문 1, 3, 8. 가로선 블록에서 가장 정확하고 빠른 1차원 부화소 방법은 무엇인가 |
| 후보 | (a) 지금 블록 정합 S0, 대조군. (b) erf 4매개변수 적합, 논문 01. (c) CIS 밝기 합 닫힌 식, 논문 03. (d) 기울기 봉우리 3점 포물선을 64열 평균 프로파일에서 재시험, 논문 02 특허 01 |
| 고정 조건 | 블록 배치, 창 위치, 평활 σ 1, 센터 템플릿을 네 방법에 똑같이 준다. 네 방법 모두 센터 차분값만 쓴다(절대 위치를 쓰지 않는다). 측정 뒤 특징과 회귀는 joint_v2와 똑같이 둔다(선마다 최소제곱 직선, 기울기 차 d). 블록 신뢰 조건(상관 0.9, 대비 5, 이득 0.25~4)도 같게 둔다 |
| 먼저 확인 | 센터 사진에서 블록 프로파일 모양을 그려 단일 에지인지 띠인지 적는다. 띠면 erf 모형을 두 에지로 바꾸거나 후보에서 뺀다. 적합 σ(실효 흐림)도 함께 남긴다 |
| 지표 | 블록 변위 잡음(반복 3장 표준편차, 전폭), 한 장 직선 잔차 RMS, joint `|eT| ≤ 0.01` 통과율과 최대오차(1014만 학습 -> 1020, 1029 / 날짜 층화 5-fold), 선 측정만의 ms 중앙값과 p95 |
| 판정 기준 (실험 전 고정) | 채택: 블록 잡음이 S0보다 10% 이상 작고, 날짜를 나눈 joint 통과율이 S0보다 떨어지지 않으며, 시간이 10 ms 이하. 속도 대안 채택(CIS): 블록 잡음이 S0의 1.1배 이내이고 통과율 차가 1%p 이내이면서 시간이 S0의 1/2 이하. 그 밖에는 S0 유지로 적는다 |
| 예상 소요 | 구현 1일, 575장 4방법 측정과 집계 반나절 |

### V2-2-2c-E2. 창 길이, 평활, 열 평균 번짐 점검

| 항목 | 내용 |
|---|---|
| 질문 | 질문 3, 4, 5. 창과 평활과 표본화가 편향을 만드는가. 흐림 지표로 보정할 수 있는가 |
| 후보 | (a) 창 길이 21, 31, 41표본(논문 01의 창 ≥ 8~10σ 규칙 점검). (b) 평활 없음, σ 1, σ 2(기존 E6 대 논문 01의 반대 방향). (c) 기울기 정렬 표본화(열별 세로 보간 후 평균, 특허 02 + 기존 E5의 3차 이상 보간). (d) 파형 지표 편향 보정 M = M1 - aE(기존 E1), E는 적합 σ, 대비, 좌우 비대칭 |
| 고정 조건 | 측정기는 E1에서 고른 것 하나로 고정한다. 선 기울기 s는 센터 사진에서 정해 고정한다(시험 사진 정답으로 고르지 않는다). a는 학습 fold에서만 정한다. 합성 이동 시험(부화소 0~1 px, 0.1 px 간격)으로 1 px 주기 성분을 따로 본다 |
| 지표 | 1 px 주기 편향의 진폭(합성 이동), 1020 흐린 사진의 블록 편향과 흐림 지표의 상관계수, 센터 대 T = ±1.00 사진의 블록 기울기 차와 번짐 차(px), 날짜를 나눈 joint 통과율과 최대오차, ms |
| 판정 기준 (실험 전 고정) | 창과 평활: 블록 잡음과 1 px 주기 진폭을 함께 가장 낮추는 조합만 바꾼다. 둘이 어긋나면 날짜를 나눈 통과율이 높은 쪽. 기울기 정렬 표본화: 센터와 T ±1의 번짐 차가 블록 잡음보다 클 때만 시험하고, 블록 잡음이 10% 이상 줄 때만 채택. 편향 보정 a: 학습 fold 상관 `|r| ≥ 0.5`이고 시험 fold에서 최대오차가 줄 때만 채택. 조건을 못 넘으면 "효과 없음"으로 적고 지금 설정을 유지한다 |
| 예상 소요 | 구현 1일, 측정과 집계 1일 |

### V2-2-2c-E3. 블록 묶기, 거르기, 점과 선 가중

| 항목 | 내용 |
|---|---|
| 질문 | 질문 2, 6, 7. 블록을 직선으로 묶는 방법과 점, 선 가중을 어떻게 하는가 |
| 후보 | (a) 지금 최소제곱 직선 + d, 대조군(A20, A21). (b) 겹친 블록 32 px 간격, 특허 03. (c) 블록 품질 거르기(SER 일관성 코사인 0.9, 정렬점 밀도, 이중 대비 문턱, 간격 검정: 논문 03, 04, 특허 03, 기존 E2). (d) 불확도 가중 GLS: 블록별 실측 분산 + 공통 세로 이동 항(랭크 1), 논문 05. (e) RANSAC + 내점 재적합, 특허 03, 판정용 안전장치로만 |

| 지표 | 선 블록 잡음이 실제로 독립인지(블록 간 상관 행렬, 공통 성분 비율), 선 2차 항의 유의성(직선 대 2차 적합 잔차), 날짜를 나눈 joint 통과율과 최대오차, control `|eY| ≤ 0.045` 통과율(splits.json 고정 4-fold), 버린 블록 수와 커버리지, ms |

| 예상 소요 | 구현 1.5일, 측정과 집계 1일 |

### 오프라인에서 답할 수 없는 것

- 실제 반사, 그림자, 이물, 부분 가림의 영향. 지금까지는 합성 교란뿐이다(A19).
- 같은 자세로 실제 이동 후 돌아왔을 때의 반복 정밀도. 모든 자료는 명령한 자리에 멈춰 찍은 정지 사진이고 실제 작업 후 도착 사진이 없다([결론 문서](../../../../../../../experiments/hye/20261102_142904_결론_센터복귀_반복정밀도.md)).
- 날짜 간 카메라 틸트가 d에 주는 영향의 크기(A15는 1014와 1029 두 날짜뿐).
- 팀 환경(Windows MSVC v141, OpenCV 3.4.15)의 실제 처리 시간. 지금 수치는 macOS, OpenCV 5.0 기준이다. 이것만 별도 환경에서 재집계한다.

## 3. 실험 순서와 산출물

1. E1 -> 2. E2 -> 3. E3. 뒤 실험은 앞에서 고른 설정을 고정해 쓴다.
각 실험은 `experiments/hye/YYYYMMDD_HHMMSS_V2_2-2c_<주제>/{계획서.md, 실험/, 결과/}`에 남기고, 결과 요약을 [02_실험결과.md](02_실험결과.md)와 캔버스 노드 `s2_2`에 올린다.
원본, 기존 결과, 기존 final 폴더는 고치지 않는다. data는 커밋하지 않는다.
