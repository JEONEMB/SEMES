# Cognex US6408109B1, 기울기 봉우리 3점 보간과 방향별 편향 보정으로 부화소 에지 찾기

- 원제: Apparatus and method for detecting and sub-pixel location of edges in a digital image
- 원문: 같은 폴더의 `US6408109B1_Cognex_subpixel_edge.pdf` (USPTO 공보 PDF, 21쪽, image-ppubs에서 받음. 표지 2쪽, 도면 7장, 명세서 12쪽, 청구항 34개)
- 번역: [번역.md](번역.md) (전문, 표 1~5와 청구항 1~34 포함, 인용 문헌은 원문 그대로)
- 출원인: Cognex Corporation (Natick, MA). 발명자: William Silver, Arman Garakani, Aaron Wallack
- 서지: US 6,408,109 B1. 출원 번호 08/727,721, 출원 1996-10-07, 등록 2002-06-18. 계속 심사 출원(CPA). IPC G06K 9/82, 미국 분류 382/300, 190, 199, 266
- 근거 상태: 원문 확인 (공보 전문). 공보는 OCR 문서이고 식 3~5와 표는 쪽 이미지로 다시 읽었다. 아래 "우리와의 관계", "리뷰 카드", "후보 방법" 절의 우리 장비 관련 내용은 우리 추론이며 실험으로 확인하지 않았다.
- 핵심 (원문 확인)
  - 처리 흐름(도 6): 기울기 성분 추정(Sobel 3x3) → 크기와 방향으로 변환(CORDIC, 7비트 가까운 정밀도) → 기울기 방향에 따라 이웃 2개 선택, 봉우리 판정 → 1차원 기울기 크기 프로파일에서 3점 보간 → 방향별 편향 보정 → 평면 위치(기울기 방향으로의 거리 r).
  - 봉우리 판정: $G_0 > G_+$이고 $G_0 \ge G_-$이면 에지. 비대칭 비교라서 같은 값이 이어져도 봉우리가 정확히 하나 나오고, 보간 결과가 항상 ±0.5 격자 단위 안에 들어온다.
  - 3점 보간 두 가지
    - 포물선: $s = \dfrac{G_+ - G_-}{4G_0 - 2(G_+ + G_-)}$ (식 3)
    - 선형(대칭 삼각형): $s = \dfrac{G_+ - G_-}{2[G_0 - \min(G_+, G_-)]}$ (식 4)
  - 주장 1: 보간 곡선이 맞는지는 밝기 프로파일보다 **커널과 이웃 배치(곧 기울기 방향)** 에 주로 달려 있다. 에지 날카로움이 넓게 바뀌어도 기울기 크기 프로파일 모양은 "놀랄 만큼 일정"하다(합성, 실측 영상 경험. 수치 없음).
  - 주장 2: 그래서 곡선 하나로 보간한 뒤 **방향별 지수 b 하나**로 S자 보정을 한다. $s' = s|2s|^{b}$, $b > -1$ (식 5). s = 0, ±0.5에서는 b와 관계없이 고정이다. b > 0이면 $G_0$ 쪽으로 당기고, b < 0이면 밀어낸다.
  - 기울기 방향 수직 방향으로는 위치 정보가 없다. 프로파일선이 기울기 방향과 어긋나면(대각 이웃) 보간 값에 √2와 각도 코사인을 곱해 기울기 방향 거리로 바꾼다(도 4c).
  - 최선의 형태: Sobel, CORDIC, 3x3 이웃 선택, 포물선 보간, 평면 위치, 거듭제곱 편향 보정.
- 정량 수치 (원문 확인)
  - 편향 지수 b (표 5, 3x3 이웃 선택): Sobel+포물선은 N-S, E-W 이웃 0.0, 대각 이웃 -0.5. Sobel+선형은 +0.5, -0.2. Roberts+포물선은 -0.7, -0.7. Roberts+선형은 -0.6, -0.6.
  - 그러므로 Sobel을 쓸 때 축 방향 에지는 포물선이 보정 없이(b = 0) 맞고, 대각 에지는 선형 보간이 낫다고 본다(본문의 방향별 곡선 선택 실시예와 같은 결론).
  - 정밀도: 8비트 밝기, 기울기 성분 11비트, 크기와 방향 각 8비트 조회표(65,536 x 16비트), 방향 최소 단위 약 1.4°. CORDIC 4단, 크기 배율 약 1.16, 단마다 방향 정밀도 약 1비트.
  - 메모리: 래스터 순서로 계산하면 기울기 크기 3행만 있으면 된다.
  - 위치 정확도(px), 잡음 표준편차, 처리 시간 수치는 **공보에 없다**. b 값을 어떤 자료로 정했는지도 적혀 있지 않다.
- 우리와의 관계: ○ 질문 **3, 5, 8**
  - 질문 3 (1차원 프로파일 부화소 방법): "기울기 봉우리 보간"의 대표 산업 구현이다. 포물선과 선형 두 곡선, 그리고 곡선이 틀린 만큼을 S자 보정으로 메우는 방법을 준다. 다만 편향과 잡음을 수치로 비교하지 않았으므로 "어느 것이 가장 작은가"에는 답하지 않는다. 다른 계열(erf 적합, 면적 효과, 상관)과의 비교도 없다.
  - 질문 5 (방향 의존 편향): 바로 이 문제를 다룬다. 편향의 원인을 이웃 배치(축 방향, 대각)로 보고, 방향 구간별 b로 보정한다. 우리 가로선은 기울기 방향이 거의 수직(90°)이다. T 명령 범위 ±1.00단위는 d=0 가정 아래 약 ±1.02°이고, 선 기울기도 이 정도라고 보면(우리 추론, 영상에서 재지 않음) 3x3 구간 67.5°~112.5° 안에 늘 들어간다. 그러면 이웃은 항상 N-S이고 표 5의 b = 0 조건이다. 곧 이 특허가 다루는 이웃 배치 전환 편향은 우리 가로선에서는 생기지 않는다. 남는 것은 축 방향 포물선 보간 자체의 부화소 위상 편향인데, 공보는 이것을 b = 0으로 두어 "보정 불필요"로 볼 뿐 크기를 재지 않았다.
  - 질문 8 (처리 시간): 조회표, CORDIC, 3행 버퍼 같은 속도 설계를 주지만 1996년 하드웨어 기준이고 시간 수치가 없다. 우리에게 쓸 만한 것은 "3점 닫힌 식이라 반복 적합이 없다"는 계산량 성질뿐이다.

## 상세 요약 (번역본 기반)

### 1. 문제
- 기울기 기반 에지는 싸고 빠르지만 부화소 정확도가 낮고, 계단 모형 국소 적합은 정확하지만 비싸고 느리다(배경 절). 싼 기울기 추정은 방향을 3비트(8방향)로만 주고, 격자 축과 기운 에지에서 크기 정확도가 떨어진다.

### 2. 방법
- 기울기 크기와 방향을 7비트 정도로 싸게 계산(도 2c CORDIC, 표 1, 2).
- 방향으로 이웃 2개를 골라(도 3a, 22.5° 경계의 8구간) 봉우리 판정, 3점 보간(식 3, 4), 방향별 거듭제곱 편향 보정(식 5, 표 3~5), 평면 위치(도 4c).
- 이웃이 한 직선 위에 있지 않으면(5x5 이웃, 도 3c) 보간 전에 표본을 기울기 방향선 위로 옮긴다. 간격이 다르면 적합식에 반영한다. 이웃이 많으면 최소제곱 적합을 쓴다.

### 3. 근거
- 실험 표나 정확도 수치는 없다. "경험상" 커널과 이웃 배치가 주된 효과이고, 화소 격자에 대한 기울기 방향 정렬은 이웃 배치 선택을 빼면 효과가 작다는 진술과 표 5의 b 값만 있다.

### 4. 청구 범위 요지
- 독립항 1, 11, 21, 28, 33. 핵심은 "기울기 방향으로 이웃 선택 + 봉우리 판정 + 1차원 기울기 크기 프로파일 보간"(1, 11, 21)과, 평면 위치선 교점(2, 3, 22, 23, 28), 방향별 보간 함수 선택(5, 15, 25, 29, 30), 거듭제곱 편향 보정(26, 31), Sobel+CORDIC+포물선+편향+평면 위치 조합(33).
- 등록 2002년, 출원 1996년이므로 존속기간은 이미 끝났을 것으로 보인다(확인 필요, 법적 상태는 조회하지 않았다).

## 리뷰 카드

- **어떻게 해결했나**: 에지 위치를 밝기 모형 적합이 아니라 기울기 크기 봉우리의 3점 닫힌 식 보간으로 구한다. 보간 곡선과 실제 봉우리 모양의 차이로 생기는 계통 편향은 기울기 방향(곧 이웃 배치)에만 달려 있다고 보고, 방향 구간별 지수 b 하나로 S자 보정을 해서 없앤다. 반복 계산이 없어 빠르고 싸다.
- **같은 점**:
  - 우리 joint의 가로선 측정도 선에 수직인 1차원 프로파일(블록 64x49 화소, 64열 평균, 49표본)에서 부화소 위치를 구한다.
  - 이웃 비교로 정수 위치를 정한 뒤 부화소로 다듬는 2단계 구조가 같다(우리는 상관 최대 탐색 뒤 Brent 탐색).
  - 우리도 측정 전에 가우스 평활(9탭, 표준편차 1 px)을 한다. 특허의 "평활 후 기울기" 축척 조절과 같은 역할이다.
- **다른 점**:
  - 우리는 에지 절대 위치를 재지 않는다. 센터 사진 같은 블록의 프로파일과 정합해 이동량만 잰다(스플라인 보간, 밝기 이득과 오프셋 함께 적합). 특허는 영상 하나에서 에지 절대 위치를 낸다.
  - 특허 방법의 보간 값 s는 기울기 크기 비율이라 밝기 이득에 무관하고, 미분이라 밝기 오프셋에도 무관하다. 우리 정합은 이득과 오프셋을 자유 변수로 두어 같은 효과를 얻지만, A19에서 가로선 블록이 잡음, 조명 교란에 0.1~0.7 px 흔들렸다. 원인이 정합 방식에 있는지는 아직 모른다.
  - 특허는 3x3 국소 기울기로 화소마다 에지 점을 낸다. 우리는 64열을 먼저 평균하므로 열 방향 정보(선 기울기)를 블록 안에서 버린다. 기울기는 48블록 위치의 차이로만 얻는다.
  - 우리 선은 거의 수평이라 특허의 핵심인 방향별 편향 보정이 거의 쓰이지 않는다(위 질문 5).
  - 요구 정밀도가 다르다. 우리는 Y 허용 0.65 px(±0.045 단위), joint T 기준 0.01 단위(약 0.80 px)이고, 실제 문제는 블록 잡음보다 Y와 T의 혼동과 날짜 간 영점 이동(세로 +0.44 px)이다. 특허는 범용 에지 검출로 정밀도 목표 수치가 없다.
- **가져올 해결책**:
  1. **블록 기울기 봉우리 위치를 별도 측정으로 만든다.** 블록마다 열 평균 프로파일을 중심 차분해 기울기 크기 봉우리를 찾고, 식 3(포물선)으로 s를 구해 절대 에지 위치를 낸다. 센터 사진의 같은 값과 차이를 내어 지금 정합 이동량과 나란히 둔다. 선이 띠 모양이면 위, 아래 에지 두 봉우리를 따로 잰다. 계산은 블록당 표본 49개의 닫힌 식이라 48블록 전체가 정합보다 훨씬 가벼울 것으로 본다(추론, C++로 시간 측정).
  2. **조명 강건성을 A19 교란으로 비교한다.** s는 이득, 오프셋에 불변이므로 A19의 같은 교란(잡음, 조명)을 걸어 봉우리 보간과 지금 정합의 블록 흔들림(0.1~0.7 px)을 비교한다. 흔들림이 줄면 joint_v2의 선 측정 후보로 올린다.
  3. **부화소 위상 편향을 학습 분할 안에서만 확인하고 보정한다.** 축 방향 포물선 보간의 위상 편향 크기는 특허에 없다. 센터 대비 차이를 쓰면 위상이 같을 때만 편향이 상쇄되므로, 학습 분할 사진에서 s 분포와 이동량 잔차를 s에 대해 그려 S자 패턴이 있는지 본다. 있으면 식 5의 b를 학습 분할에서만 맞추고 시험 분할에는 고정해 쓴다. 시험 정답은 b 결정에 쓰지 않는다.
  4. **선 기울기는 열 단위 에지 점으로 직접 잰다(질문 6, 7 연결).** 열 평균을 하지 않고 열마다(또는 8열 묶음마다) 봉우리 보간으로 에지 점을 얻어 강건 직선 적합을 하면, 위, 아래 선 기울기를 블록 위치 차이보다 촘촘히 얻는다. A20에서 기울기 차 특징이 1014만 학습으로 233/234였으므로, 이 특징의 측정 잡음을 줄이는 쪽이 이득이 크다고 본다(검증 전 가설).
  5. **평가**: 같은 사진, 같은 분할(날짜를 나눈 평가, 1014만 학습 → 다른 날짜, 날짜별 80/20 5-fold)에서 joint |eT| ≤ 0.01 통과율과 최대오차, 블록 잡음(직선 잔차), 처리 시간(ms)을 지금 정합과 비교한다. 341/575장은 개발 노출 자료임을 결과에 적는다.

## 이 단계 후보 방법으로서

- **방법 이름**: 기울기 크기 봉우리 3점 보간(포물선 또는 선형) + 방향별 거듭제곱 편향 보정 (Cognex US6408109B1)
- **전제 조건**
  - 에지 하나가 기울기 크기의 뚜렷한 봉우리 하나를 만든다. 봉우리 근처 3표본 안에 다른 에지가 없다.
  - 기울기 크기 프로파일 모양이 커널과 이웃 배치로 정해지고, 에지 날카로움에 크게 달라지지 않는다(특허의 경험 진술, 수치 근거 없음).
  - 방향별 b는 미리 정해 둔다. 공보 값(Sobel+포물선, 축 방향 b = 0)은 그들의 커널과 영상에서 나온 값이다.
  - 잡음 문턱으로 약한 봉우리를 버릴 수 있을 만큼 대비가 있다.
- **장점**
  - 닫힌 식이라 반복이 없고 매우 빠르다. 결과가 항상 ±0.5 격자 안에 있어 발산이나 실패가 없다.
  - 기울기 크기 비율이라 밝기 이득과 오프셋 변화에 영향받지 않는다.
  - 방향별 편향 보정 틀(식 5)이 간단해서, 우리 자료로 b를 다시 맞추기 쉽다.
  - 화소마다 에지 점과 방향을 주므로 직선 적합으로 선 기울기를 바로 얻을 수 있다.
- **단점**
  - 정확도, 잡음, 시간 수치가 공보에 없다. 다른 방법보다 낫다는 근거가 주장뿐이다.
  - 3표본만 쓰므로 잡음 평균 효과가 적다. 미분이 잡음을 키운다. 열 평균이나 평활에 기대야 한다.
  - 3점 보간은 봉우리 모양이 곡선과 다르면 부화소 위상에 따른 S자 편향이 남는다. b 하나로 다 지우지 못할 수 있다.
  - 흐림이 사진마다 달라지면 봉우리 폭이 바뀌어 편향 모양도 바뀔 수 있다(1020 세트의 약한 흐림). 특허는 이 경우를 "모양이 일정하다"는 경험으로만 넘긴다.
- **우리 적용 조건**
  - 위, 아래 가로선 48블록 안에서만 쓴다. 나사, 볼트, 일반 배경에는 쓰지 않는다.
  - 가로선의 기울기 방향은 늘 거의 수직이므로 이웃은 N-S 고정, 보간은 포물선(공보 기준 b = 0)에서 시작한다. 방향별 구간 전환은 구현하지 않는다.
  - 프로파일은 64열 평균(지금과 같음)과 열별(또는 8열 묶음) 두 가지로 만들고, 평활 유무를 함께 비교한다.
  - 출력은 센터 사진 대비 차이로 써서 지금 204차원 GLS의 선 변위 48개 자리에 넣거나, 열별 에지 점의 강건 직선 적합으로 얻은 위, 아래 선 기울기와 위치를 특징으로 쓴다.
  - b 보정은 학습 분할에서만 정한다. 같은 사진, 같은 분할에서 |eT| ≤ 0.01 통과율, 최대오차, 처리 시간을 지금 정합과 비교하고, A19 교란 아래 블록 흔들림도 함께 보고한다.
