## 2. 오프라인 실험 (data/clean 정지 사진으로 가능)

### V2-2-2b-E1. joint ECC 자체의 측정 품질과 반복 수

| 항목 | 내용 |
|---|---|
| 질문 | 단계 질문 1, 4, 7. QR 전체 ECC 호모그래피(M2)의 합성 편향 곡선, 반복 잡음, 실제 반복 수는 얼마인가. 쌍선형 보간과 5x5 가우스 때문에 편향이 L7이 말한 0.1 px 수준까지 커지는가 |
| 왜 필요한가 | 10-29에서 잰 ECC는 점별 31x31 창이라 joint ECC와 다른 방법이다. joint의 54좌표 자체 품질은 한 번도 재지 않았다 |
| 후보 | M2(joint 현행 FA-ECC, 대조군), M1(control GN, 비교 기준선), M10(가우스 세기 0, 0.8, 5x5와 보간 쌍선형 대 3차 B-스플라인) |
| 고정 조건 | 센터 사진에 FFT 위상 이동으로 0~1 px를 0.05 px 간격 21단계 넣어 합성 정답을 만든다. QR 3개 각각, 여백 130, 260, 512 현행값. 반복 상한 200, eps 1e-8 현행값. 반복 잡음은 1020, 1029의 반복 3장 묶음에서 QR별 아핀을 뺀 잔차로 잰다 |
| 지표 | QR당 9점, 합계 54좌표의 부화소 위치별 평균 편향(px)과 표준편차, 최대 편향. 반복 잡음 SD(px). 실제 ECC 반복 수의 중앙값과 p95. 측정 ms 중앙값과 p95 |
| 판정 기준 (사전 고정) | (a) 54좌표 최대 편향 0.05 px 이하면 joint ECC 편향은 무시한다. 0.05~0.2 px이면 M10의 보간 차수 상향을 E2 후보에 넣는다. 0.2 px 초과면 편향 보정(M7)을 되살린다. (b) 반복 수 p95가 30 이하면 상한 200은 과하다고 보고 E2에서 상한과 eps를 줄인 조건을 포함한다. (c) 가우스, 보간을 바꿔 54좌표가 점 잡음 0.009 px보다 작게만 변하면 현행 유지 |
| 예상 소요 | 측정 구현 반나절, 실행 1~2시간(575장 곱하기 변형 조건 4종) |

### V2-2-2b-E2. ECC 가속 후보 비교 (역합성, ESM, 종료 조건)

| 항목 | 내용 |
|---|---|
| 질문 | 단계 질문 1, 7. joint 모듈 774.5 ms의 대부분인 ECC를, 54좌표를 점 잡음 이상으로 바꾸지 않으면서 얼마나 줄일 수 있는가 |
| 후보 | M2 FA-ECC(대조군, 현행), M3 IC-ECC와 IC-GN 호모그래피, M4 ESM 호모그래피, 그리고 M2에 종료 조건만 바꾼 변형(상한은 E1의 p95 값, 갱신량 0.001 px 멈춤) |
| 고정 조건 | 같은 NCC 초기값, 같은 여백, 같은 마스크, 같은 가우스. 54좌표 추출 방식(QR당 3x3 격자 9점 투영) 동일. 후단은 기존 joint 그대로(가로선 48블록, 204차원 GLS). 341장 외부 4-fold와 날짜 분할(1014 학습 → 1020, 1029) 둘 다 돌린다 |
| 지표 | 대조군 대비 54좌표 차이의 중앙값과 최대(px), T 축 평균오차와 최대오차, T 0.01 통과율, T 0.045 통과율, 측정 ms와 모듈 ms(중앙값, p95), 수렴 실패 수 |
| 판정 기준 (사전 고정) | 채택 조건은 셋을 모두 만족할 때만이다. (1) 54좌표 차이 최대가 0.009 px 이하(한 장 점 잡음), (2) 날짜 분할과 4-fold 양쪽에서 T 0.01 통과율이 대조군보다 낮아지지 않음, (3) 측정 ms 중앙값이 대조군의 0.7배 이하. 하나라도 어기면 현행 FA-ECC를 유지하고 그 사실을 적는다. 시간만 줄고 통과율이 떨어지면 채택하지 않는다 |
| 예상 소요 | IC-ECC와 ESM 구현 1~1.5일, 실행 2~3시간, 분석 반나절 |

### V2-2-2b-E3. 점별 창 대 영역 전체 대 혼합, 그리고 오정합 검출

| 항목 | 내용 |
|---|---|
| 질문 | 단계 질문 3, 2. 점별 작은 창(control M1)과 영역 전체 변환(joint M2)을 같은 측정 정밀도 지표로 직접 비교하면 어느 쪽이 나은가. 섞으면 나은가. FB에 이웃 중앙값과 P12 잔차 3시그마를 더하면 오정합을 얼마나 더 잡는가 |
| 왜 필요한가 | 지금 두 방식 비교는 최종 Y/T 성적 기준뿐이고, 편향과 반복 잡음 기준으로 맞댄 적이 없다. M12의 이웃 중앙값과 P12 3시그마는 실험이 없다 |
| 후보 | M1 점별 GN 536점(대조군, control 현행), M2 영역 호모그래피 54좌표, 혼합(호모그래피로 각 점 예측 위치를 주고 점별 GN을 1~2회만 돌리는 따뜻한 시작, M11 아이디어), 검출은 M12 세 가지(FB 단독, FB에 이웃 중앙값 추가, 거기에 P12 잔차 3시그마 추가) |
| 고정 조건 | 같은 합성 정답 자료(E1과 같은 생성 규칙)와 같은 반복 3장 묶음. control 비교는 `validation/splits.json` 고정 4-fold, 센터 차감과 P12, 6절편 후보 곡선 역산 후단은 현행 그대로. 검출 임계값은 A1의 점 잡음 0.0087 px를 기준으로 미리 정하고 실행 중에 바꾸지 않는다 |
| 지표 | 합성 편향 최대와 p95(px), 반복 잡음 SD(px), 1 px 초과 점 수, 검출 재현율과 오경보율(합성에서 정답을 아는 오정합에 대해), Y 축 평균오차와 최대오차, Y 0.045 통과율, ms |
| 판정 기준 (사전 고정) | (a) 혼합 방식은 Y 0.045 통과율이 대조군 이상이고 ms가 대조군 이하일 때만 채택한다. (b) 검출은 FB 단독 대비 재현율이 0.1 이상 오르고 오경보율이 1% 이하로 유지될 때만 추가한다. (c) 거른 점은 (0,0)으로 숨기지 않고 2-4 품질 판정으로 넘긴다 |
| 예상 소요 | 구현 1일, 실행 2시간, 분석 반나절 |

실행 순서는 E1, E2, E3이다. E1의 반복 수와 편향 결과가 E2의 조건을 정하기 때문이다.
