## 0. 이 단계가 실험으로 답할 수 있는 것과 없는 것

이 단계는 영상 처리 단계가 아니다. 문제와 평가 기준을 정하는 단계다.
그래서 "새 알고리즘을 비교하는 실험"은 없다. 대신 뒤 단계가 전부 올라설 **평가 틀과 대조군 성적표, 오차 예산**을 오프라인 자료로 고정한다.

| 질문 (00_단계.md) | 답하는 길 |
|---|---|
| 1 명령만으로 왜 못 가는가 | 기존 실험으로 답함 (20261014_1313, A1, A15). 새 실험 없음 |
| 2 왜 비전인가 | 기존 실험으로 답함 (A1, A2, A3, A15, A20). 새 실험 없음 |
| 3 어떤 환경인가 | 문헌으로 못 닫음. 기업 확인 체크리스트 (4절) |
| 4 목표, 허용, 시간, 턴 수 | **V2-P-E1** (대조군 성적표 + 시간), 일부는 기업 확인 |
| 5 정확히 무슨 문제인가 | **V2-P-E3** (자료 대장과 노출, 누수 점검) |
| 6 언제 다시 생기는가 | 오프라인 불가. 촬영 요청 B1, B2 |
| 7 무엇으로 평가하는가 | **V2-P-E1**, **V2-P-E2** (오차 예산) |
| 8 정지 사진이 대표하는가 | 오프라인 불가. 촬영 요청 B1, B2, B5 |

오프라인 실험 3개, 촬영 요청 4건이다.
모두 `data/clean` 정지 사진과 기존 캐시만 쓴다. 원본, 기존 결과, 기존 final 폴더는 고치지 않는다.

## 1. 모든 오프라인 실험의 고정 조건

실험 전에 정하고, 실험 중에 바꾸지 않는다.

| 항목 | 값 |
|---|---|
| 자료 | `data/clean` 정지 사진 575장. 개발에 노출된 341장을 성적표에 표시한다 |
| 점 측정 캐시 | [A0 캐시](../../../../../experiments/hye/20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache)를 먼저 재사용한다. 캐시에 없는 사진만 새로 측정한다 |

| joint 비교 분할 | 341장 밖 자료로 만든 외부 4-fold |
| 날짜 분할 (필수) | (a) 1014 학습 → 1020, 1029 시험, (b) 날짜별 80/20 5-fold, 10분할 반복 |
| 대조군 | `20261028_1327_final_Y_T control`, `20261028_1258_final_Y_T_joint` (기존 final, 코드 수정 금지) |

| 폴더 | `experiments/hye/YYYYMMDD_HHMMSS_V2_P_<주제>/` |

## 2. 오프라인 실험

### V2-P-E1. 대조군 성적표와 처리 시간 고정

- 묻는 것: 뒤 단계의 모든 비교가 기준으로 삼을 기존 final 두 모듈의 성적이 **세 가지 분할에서 각각 얼마인가**. 한 장 처리 시간은 얼마인가. (질문 4, 7)
- 후보 (00_단계.md 표): M5 정확도와 반복정밀도 분리, M1 요구사항 체크리스트의 처리 시간 항목, M12 노출 자료 표시.
- 고정 조건: 1절 전부. 모듈 코드와 학습 설정은 11-04 상태 그대로 둔다.
- 하는 일
  1. 네 모듈(final control, final joint, v2 control, v2 joint)을 같은 사진, 같은 분할 세 종류로 돌린다.
  2. 사진 단위 결과를 `per_shot.csv`로 남긴다. 사진 ID, 날짜, 명령 Y, 명령 T, 추정값, 오차, 통과 여부, ms.
  3. 반복 묶음(1020, 1029의 3장 묶음)마다 평균 편차, 전폭, 3SD를 따로 낸다 (ISO 9283 AP, RP 흉내, 정답은 명령값 기준).
- 지표: 축별 평균오차, 최대오차, 통과율, 반복 묶음 전폭과 3SD, ms 중앙값과 p95.
- 판정 기준 (실험 전 고정)
  - 성적표가 네 모듈 × 세 분할 전부 채워지고, 빈칸이 있으면 이유가 적혀 있으면 성공이다.
  - 기존 보고서와 겹치는 칸(A10 시간, A17 1020 통과율 91.7%, A20 1029 233/234)이 **같은 값으로 재현되면** 캐시와 분할이 맞다고 본다. 어긋나면 그 자리에서 멈추고 원인을 적는다.
  - 이 실험은 모듈을 고르는 실험이 아니다. 어느 쪽이 좋다는 결론을 내지 않는다.
- 재사용: A10(시간), A17(날짜 층화 5-fold), A20(1014 학습 → 1029), A22, A23의 숫자는 같은 조건이면 **다시 돌리지 않고 인용**한다. 비어 있는 칸만 새로 돌린다.
- 예상 소요: 측정 캐시 재사용 시 2시간 안. 캐시 없는 사진이 많으면 4시간.

### V2-P-E2. 오차 예산 합성과 관측 대조

- 묻는 것: 허용(Y 0.65 px, T 0.80 px)을 **무엇이 얼마나 먹고 있는가**. 항목을 더한 값이 실제 관측 오차를 설명하는가. (질문 7, 4)
- 후보: M7 오차 예산, M6 측정 시스템 오차 분리, M2 고정 오차와 변하는 오차 분해.
- 고정 조건: 1절. 항목은 실험 전에 다음 5개로 고정한다.
  1. 점 측정 잡음 (A1: 0.0087 px, 유효 독립 차원 18.86/536)
  2. 하루 안 영점 변화 (가로 ≤0.84 px, 백래시 β -0.34 px)
  3. 날짜 간 영점 변화 (세로 +0.44 px, QR과 선의 차 -0.044 px)
  4. Y와 T 누출 (오차 주축 ΔY = -5.617 ΔT, 상관 -0.914)
  5. 가로선 블록 측정 흔들림 (A19: 0.1~0.7 px)
- 하는 일
  1. 항목마다 px 크기를 기존 보고서에서 가져오고, 가져온 자리를 적는다. 없으면 A0 캐시로 다시 잰다.
  2. 항목을 Y(mm), T(단위)로 환산하고, 독립 가정으로 제곱합 합성한다. 독립 가정은 가정이라고 표시한다.
  3. 합성값을 V2-P-E1의 실제 오차 분포(SD, p95, 최대)와 같은 표에 놓는다.
  4. 항목을 하나씩 0으로 두고 합성값이 얼마나 줄어드는지 적는다 (개선 상한 추정).
- 지표: 항목별 px, Y mm, T 단위, 허용 대비 비율. 합성 SD 대 관측 SD의 비.
- 판정 기준 (실험 전 고정)
  - 합성 SD와 관측 SD의 비가 **0.5배에서 2배 사이**면 예산표를 뒤 단계 설계에 쓴다.
  - 범위 밖이면 빠진 항목이 있다고 보고, 예산표를 쓰지 않고 "설명 안 되는 성분"을 크기와 함께 남긴다.
  - 항목 하나를 0으로 해도 허용 안에 못 들어오면, 그 항목만 고치는 설계는 뒤 단계에서 채택하지 않는다.
- 재사용: A1, A15, A19, A2, A3, [결론 문서](../../../../../experiments/hye/20261102_142904_결론_센터복귀_반복정밀도.md)의 수치를 그대로 쓴다. 새 측정은 캐시에 없는 항목만 한다.
- 예상 소요: 1시간에서 2시간. 대부분 집계다.

### V2-P-E3. 자료 대장, 노출 표시, 분할 누수 점검

- 묻는 것: 우리가 가진 자료가 **정확히 무엇이고**, 분할에 정답 누수나 같은 자세 중복이 없는가. (질문 5, 7)
- 후보: M12 독립 일반화 시험의 전제, M9 문제 범위 정의.
- 고정 조건: 1절. 자료는 `data/clean` 전수.
- 하는 일
  1. 사진마다 날짜, 명령 Y, 명령 T, 반복 묶음 ID, 개발 노출 여부(341/575)를 표로 만든다.
  2. 날짜별 자세 지도를 그린다. 빈 사분면(Y<0 그리고 T<0)과 혼합 자세가 어느 날짜에만 있는지 적는다.
  3. 세 분할(control 4-fold, joint 외부 4-fold, 날짜 분할) 각각에서 **같은 명령 자세가 학습과 시험에 함께 들어가는 경우**를 센다.
  4. 반복 묶음이 분할로 쪼개지는 경우를 센다.
- 지표: 자세 겹침 건수, 묶음 쪼개짐 건수, 날짜별 자세 수, 노출 사진 수.
- 판정 기준 (실험 전 고정)
  - 겹침과 쪼개짐이 0이면 분할을 그대로 쓴다.
  - 0이 아니면 해당 분할의 성적은 "낙관적"이라고 표시하고, 묶음 단위로 묶은 분할을 추가로 만든다. 기존 분할 파일은 고치지 않고 새 파일로 둔다.
- 재사용: A0의 계층 분할 산출물과 자극 지도를 쓴다. A0이 이미 만든 표가 위 4항목을 다 담고 있으면 **다시 만들지 않고 점검 결과만 적는다**.
- 예상 소요: 1시간 안.

## 3. 오프라인으로 못 하는 것

아래는 정지 사진으로 답이 안 나온다. 오프라인 실험을 만들지 않는다.

- 질문 6 재정렬 주기와 열 드리프트: 촬영 시각, 온도, 가동 시간 기록이 자료에 없다.
- 질문 8 정착 시간과 접근 방향: 575장 모두 명령한 자리에 멈춰 찍은 사진이고, 접근 방향 기록이 없다.
- 실제 작업 후 도착 사진에서의 성적: 자료가 한 장도 없다.
- 명령값과 독립한 참 위치: 독립 기준기가 없다. 그래서 ISO 9283 AP의 참값을 낼 수 없다.

## 6. 보고 규칙

- 성적표마다 분할 이름, 날짜 구성, 노출 사진 수(341/575)를 같이 적는다.
- 실패를 (0,0)으로 숨기지 않는다. 실패는 실패로 세고, 판정(신뢰, 재촬영) 결과를 함께 적는다.
- 정확도와 처리 시간을 같은 표에 둔다.
- 기존 보고서에서 인용한 수치는 출처 링크를 붙인다. 확인 못 한 수치는 쓰지 않는다.
- 일부만 끝났으면 전체가 끝났다고 적지 않는다.
