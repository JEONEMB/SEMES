## 1. 모든 실험이 함께 지키는 고정 조건

자료
- 입력은 `data/clean/` 원본 사진이다. 원본과 기존 결과 폴더는 고치지 않는다.
- 점 측정은 [A0 캐시](../../../../../../experiments/hye/20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache)(`points.csv`, `disp.f32`, `lines.f32`, `lines_valid.u8`, `quality.f32`)를 먼저 쓴다. 캐시에 없는 사진이나 새 특징이 필요할 때만 같은 측정 설정으로 다시 측정하고, 다시 측정한 사진 수를 보고서에 적는다.
- 575장 가운데 center는 평가에서 뺀다. 341/575장은 개발에 노출된 자료라고 모든 표 아래에 적는다.

분할
- control 비교: `experiments/hye/20261028_1327_final_Y_T control/validation/splits.json`의 고정 4-fold를 그대로 쓴다.
- joint 비교: 341장 외부 4-fold를 쓴다.
- 날짜를 나눈 평가는 반드시 함께 돌린다.
  - D1: 1014만 학습, 1020과 1029 시험 (현장과 같은 "새 날 재학습 없음")
  - D2: 날짜별 80/20 5-fold를 10가지 분할로 반복. 통과율은 10분할의 중앙값과 최솟값, 최댓값을 함께 적는다.
- 조절값(람다, 성분 수, 축소 계수, 문턱, 트리 수)은 바깥 시험 자료를 보지 않고 안쪽 분할에서만 고른다. 중첩 CV로 돌린다.
- 시험 정답은 어떤 단계에서도 학습, 선택, 영점 보정에 쓰지 않는다.

지표 (모든 후보가 같은 표에 들어간다)
- 축별 평균 절대오차, 최대 절대오차
- 통과율: joint는 `|eT| <= 0.01`, control은 `|eY| <= 0.045`. 다른 축은 참고로만 적는다.
- 누출 기울기: 사진별 (eY, eT)의 기울기. 감도비 -5.617과 비교한다.
- 자유도: 후보마다 유효 자유도를 적는다(논02). 조절값 차이에서 오는 성적 차이를 걷어내기 위함이다.
- 처리 시간: 같은 기계에서 C++ 한 장 추론 ms의 중앙값과 p95. 학습 시간은 따로 적는다.
- 반복 묶음(1020, 1029의 3장 묶음): Y 전폭, 3시그마, 보조 기준 (b) 통과 여부

대조군
- joint 대조군: [v2 joint](../../../../../../experiments/hye/v2_Y_T_joint/README.md)의 `(y, t) = [1, s, d] W`와 v1 `20261028_1258_final_Y_T_joint`의 204d GLS
- control 대조군: v2 control과 v1 `20261028_1327_final_Y_T control`의 P12 6절편 후보 역산
- 대조군은 다시 학습하지 않는다. 같은 사진, 같은 분할에서 그대로 돌려 점수만 받는다.

산출
- `experiments/hye/YYYYMMDD_HHMMSS_V2_5a_<주제>/`에 C++17로 둔다. 구성은 `실험/`, `결과/`, `종합/`이며 `결과/`는 C++로 다시 만들 수 있어야 한다.
- 기존 final 폴더와 기존 결과는 고치지 않는다. 자료는 커밋하지 않는다.

## 3. 오프라인 실험

### V2-5a-E1 라벨 오차 분해: 남은 꼬리가 모델로 줄일 몫인가

- 질문: Q3. 덧붙여 Q7의 "지금 꼬리의 정체".
- 왜 먼저 하나: 남은 실패가 라벨(판이 실제로 선 자리) 쪽이면 추정기를 바꿔도 줄지 않는다. E2, E3의 목표 수준을 여기서 정한다.
- 후보(후보 표 K): 정방향 학습 유지, 반복 묶음 분산 분해, control 곡선 곡률 점검, 백래시 방향 보정.
- 고정 조건
  - 반복 묶음 93개(1020, 1029의 3장 묶음)로 묶음 안 분산을 구한다.
  - 측정 잡음 시그마_eps는 [A19](../../../../../../experiments/hye/20261104_093558_A19_QR선측정_안정성점검/결과/보고서.md)의 교란 실험 값을 밖에서 가져온다. 자료 안에서 다시 추정하지 않는다.
  - 라벨 흩어짐은 묶음 안 전체 분산에서 시그마_eps의 제곱을 빼서 얻는다. 음수가 나오면 0으로 자르고 그 사실을 적는다.
  - 백래시는 접근 방향을 아는 사진에서만 계통 성분으로 빼고, 뺀 전후를 둘 다 적는다(베타 -0.34 px).
  - control 곡선의 2계 도함수를 고정 536점에서 수치로 재고, 38 px/mm^2와 비교한다.
  - A18이 꼽은 0.01 초과 사진을 사진별로, 서로 다른 관측(QR 전용, 가로선 전용, 물리 전방)이 같은 방향을 가리키는지 표로 낸다.
- 지표: 라벨 흩어짐과 측정 잡음, 둘의 비. 곡률에서 온 Berkson 편향의 mm, T 단위 환산. 반복 묶음 Y 전폭과 3시그마, 보조 기준 (b) 통과율. 꼬리 사진의 관측 일치율.
- 판정 기준(실험 전 고정)
  - 라벨 흩어짐이 허용의 1/3(Y 0.015, T 0.0033)보다 크면 "꼬리의 주된 몫은 라벨"로 판정하고, E2, E3의 목표를 통과율 100%가 아니라 "대조군 대비 최대오차 감소"로 바꾼다.
  - 곡률 편향이 허용의 1/10(Y 0.0045) 미만이면 역방향, 곡선 역산의 편향 걱정은 닫는다.
  - 꼬리 사진에서 서로 다른 관측 3종이 모두 같은 부호를 가리키는 비율이 0.8 이상이면 라벨 쪽 설명을 채택한다.
- 예상 소요: 구현 반나절, 실행 10분 안쪽(캐시 사용).

### V2-5a-E2 같은 특징, 같은 분할에서 추정기 대조

- 질문: Q1, Q2, Q4 일부, Q7.
- 후보(후보 표)
  - A OLS 66d (대조군, 재채점)
  - B GLS + 고정 축소 0.01, 204d (v1, 재채점)
  - C GLS + 데이터로 정한 축소: Ledoit-Wolf, RBLW, OAS (신규)
  - D Ridge 0.01, 66d (재채점)
  - E PLS1을 T와 Y 따로, 성분 1~19, 자유도 BIC로 선택 (신규)
  - F 학습형 방해 부분공간 차단 사선 투영, 차단 수 1~3 (신규)
  - G 카메라 이동 불변 저차원 특징 [1, s, d] (v2, 대조군, 재채점)
  - H 날짜, 세션 무작위 절편 혼합 모형. 축소 가중을 준 센터 재영점 변형 포함 (신규)
- 고정 조건
  - 특징 집합을 두 줄로 고정한다. 줄1은 66d(QR 아핀 18 + 가로선 48), 줄2는 저차원 불변 특징(s, d). 같은 줄 안에서만 추정기를 바꾼다. 204d는 B 전용으로 둔다.
  - 학습 전 처리는 모든 후보에 똑같이 건다. 특징 표준화, 날짜 평균 제거, 접근 방향 제거를 학습 자료 안에서만 계산한다.
  - 분할은 1절 그대로. joint 341장 외부 4-fold, control `splits.json` 4-fold, 거기에 D1과 D2를 반드시 더한다.
  - H의 센터 재영점은 묶음마다 센터 사진 1장만 쓰고, 축소 가중 0.55~0.68 조건을 함께 돌린다. 시험 사진의 정답은 쓰지 않는다.
  - 모든 후보의 추론을 C++17로 같은 기계에서 재고, 초기화 비용과 한 장 비용을 나눠 적는다.
- 지표: 1절 지표 전부. 후보와 분할(4-fold, D1, D2)을 축으로 하는 표 하나로 낸다.
- 판정 기준(실험 전 고정)
  - 채택 조건: D1에서 통과율이 해당 축 대조군(joint는 G, control은 v2 control)보다 낮지 않고, 최대 절대오차가 줄며, 한 장 추론이 대조군의 1.5배 ms를 넘지 않을 것. 셋을 다 만족해야 채택 후보로 올린다.
  - D2에서 10분할 통과율의 최솟값이 대조군 최솟값보다 2.1%p(한 장) 넘게 낮으면 그 후보는 떨어뜨린다.
  - 누출 기울기가 -5.617에서 멀어질수록 좋다고 보되, 단독 채택 근거로 쓰지 않는다.
  - 자유도가 대조군의 3배를 넘는 후보는 같은 성적이면 떨어뜨린다.
  - 동점이면 자유도가 작은 쪽, 그다음 추론이 빠른 쪽을 고른다.
- 예상 소요: 구현 1~2일, 실행 1~2시간(10분할 반복 포함).

### V2-5a-E3 저차원 불변 특징 위 비선형 짧은 확인

- 질문: Q5.
- 왜 짧게 하나: 문헌(논05, 논07)의 전제가 우리 자료 수, 차원, 비 I.I.D. 조건과 맞지 않고 기존 실험도 선형보다 나빴다. 그래도 "저차원 불변 특징 위에서는 다른가"는 아직 안 해 봤다.
- 후보: L 트리 앙상블(ExtraTrees, 그래디언트 부스팅), M 작은 MLP. 둘 다 (1) 단독, (2) 선형 잔차 보조 두 가지로 돌린다.
- 고정 조건
  - 입력은 E2 줄2(s, d)와 거기에 품질 지표를 더한 소수 특징만. 66d, 204d에는 걸지 않는다.
  - MLP 매개변수 수는 학습 장수의 1/10 이하로 묶는다. 트리 수, 깊이, 학습률은 안쪽 분할에서만 고른다.
  - 탐색 예산을 선형 후보와 같게 맞추고, 쓴 탐색 횟수를 적는다.
  - 분할은 1절 그대로. D1을 주 판정으로 쓴다.
  - 범위 밖 거동을 함께 본다. 학습 범위를 벗어난 T 자극 사진에서 예측이 어디로 수렴하는지 기록한다.
- 지표: 1절 지표. 더해서 학습 시간, C++ 한 장 추론 ms, 범위 밖 예측의 포화 여부.
- 판정 기준(실험 전 고정)
  - D1 통과율이 G 대조군보다 높고 최대오차가 줄며 추론이 2 ms 이하일 때만 후보로 남긴다.
  - 하나라도 못 미치면 "우리 조건에서 비선형은 쓰지 않는다"로 닫고, 그 근거 수치를 02에 적는다.
  - 선형 잔차 보조가 단독보다 나아도, 보조만으로 통과율이 1.0%p 미만 오르면 복잡도를 추가하지 않는다.
