## 핵심 (원문 확인)

- 팬아웃 웨이퍼 레벨 패키징에서 층 사이 정렬 오차(오버레이)를 신경망 회귀로 예측한다.
- 입력(원인 인자)은 세 묶음이다.
  - 장비 정렬: 이전 장비 정렬, 웨이퍼 스테이지 위치, 스텝 위치, 레티클 키 위치, 노광 위치
  - 웨이퍼, 다이 정렬: 웨이퍼 오프셋, 웨이퍼 회전, 다이 오프셋, 다이 회전
  - 상황: 초점 심도, 노광 시간, 스텝 속도, 조명, EGA 측정점, 필드, 계측 위치
- 출력(오버레이 범주)은 계측 위치, x 오차, y 오차, 회전 오차다. 출력 범주마다 회귀 함수를 하나씩 만든다.
- 위치 값마다 세 종류를 구분해 넣을 수 있다.
  - 측정 위치 (레이저 등으로 잰 값)
  - 정렬 전 위치 (EGA 보정 전 명령)
  - 정렬 후 위치 (EGA 보정 후 명령)
  - 세 값 모두 실제 위치와 어긋날 수 있고, 그 어긋남이 오차 원인이라고 본다.
- 학습은 역전파 신경망이다. 구조, 층 수, 하이퍼파라미터는 적혀 있지 않다. "지도는 느슨하게, 엔진은 눈을 가린 채" 학습시킨다고만 한다.
- 계통 인자(같은 상황에서 같은 값, 예: 특정 갠트리의 다이 오프셋)와 무작위 인자(다이 두께 변동 등)를 구별할 수 있다고 한다. 구별 방법은 적혀 있지 않다.
- 검증은 두 가지다.
  - 예측 검증: 학습에 쓰지 않은 기준 웨이퍼(둘째 웨이퍼)의 원인 데이터를 넣어 예측하고, 실제 계측과 비교한다. 허용치에서 정한 임계값(팬아웃 WLP는 약 0.1 um)으로 통과를 판단한다.
  - 보정 검증: 모형이 낸 보정값으로 새 기준 웨이퍼를 처리하고, 실제로 오차가 줄었는지 다시 잰다. 보정값은 "이렇게 하면 오차가 0이 된다"는 예측으로 본다.
- 학습 자료는 고정 개수를 유지하는 이동 창이다. 새 측정이 들어오면 가장 오래된 항목을 뺀다. 웨이퍼 종류나 공정 조건(상황)마다 학습 자료와 모형을 따로 둔다.
- 필드끼리 따로 보정할 수 없으면, 전체 보정값을 정해 필드 사이 균형을 맞추는 결정 단계를 둔다.
- 청구항 1의 골격: 첫째 웨이퍼 자료로 함수 학습, 둘째 웨이퍼의 장비 위치와 대상 위치로 오버레이 추정, 그 추정으로 장비 위치나 대상 위치를 조정. 청구항 10이 신경망, 청구항 11이 둘째 웨이퍼 실측 비교 평가다.

## 정량 수치 (원문 확인, 출원인 주장)

- 계측 처리량: 하루 292 WLP에서 하루 약 11400 WLP. 출원인은 "약 40배"라고 쓴다(계산하면 약 39배).
- 오버레이 추정 정확도: 0.1 um보다 작은 수준
- 오버레이 품질 관리 주기: 약 4시간에서 거의 실시간
- 공정 주기 시간: 0.1일 단축
- 검증 임계값 예: 0.1 um
- 자료 수, 학습과 검증 분할 방법, 오차 분포, 선형 회귀 등 다른 모형과의 비교는 없다. "교차 검증으로 과적합을 피한다"는 주장도 절차나 수치 없이 한 줄로만 있다.

## 우리와의 관계

- 관련도: 질문 5 △, 질문 7 ○
- 질문 5 (트리, 부스팅, 신경망이 수백 장 규모에서 선형보다 나은가)
  - 산업에서 위치 오차를 신경망 회귀로 푸는 사례이긴 하다.
  - 하지만 하루 수천 장 규모의 실측 라벨이 계속 쌓이는 환경이다. 우리는 341/575장, 정지 사진, 명령값 라벨이다.
  - 신경망이 선형보다 낫다는 비교 근거는 이 공보에 없다. 그래서 질문 5에 대한 직접 답은 아니다. "자료가 아주 많고 계속 갱신될 때 쓰는 방법"이라는 전제 조건만 확인해 준다.
- 질문 7 (선택 편향 없이 성능을 보고하는 분할)
  - 학습에 쓰지 않은 "둘째 웨이퍼"로 예측을 검증하고, 허용치에서 나온 임계값으로 통과를 판단한다. 우리의 "다른 날짜로 검증, |eY|,|eT| ≤ 0.045 통과율"과 같은 구조다.
  - 예측 검증과 보정 검증(보정 후 다시 재기)을 나눈다. 우리에게는 오프라인 정지 사진 평가와 실기 반복 정지 평가의 구분에 해당한다.
  - 상황별로 모형을 따로 둔다. 우리에게는 날짜, 세션, 접근 방향이 상황이다. 평가도 상황 단위(날짜 통째)로 나눠야 한다는 근거로 쓸 수 있다.
- 질문 3, 4에 대한 곁가지 시사점 (우리 추론)
  - 측정 위치, 정렬 전 명령, 정렬 후 명령을 다른 값으로 본다. 명령값이 실제 위치와 다르다는 우리 라벨 오차(백래시 β −0.34 px, 하루 안 가로 영점 ≤ 0.84 px)와 같은 인식이다.
  - "이전 장비 위치"를 입력에 넣는다. 우리에게는 직전 턴 위치나 접근 방향이 백래시를 설명하는 입력이 될 수 있다.

## 리뷰 카드

- **어떻게 해결했나:** 장비 위치, 웨이퍼와 다이 위치(오프셋, 회전), 공정 상황을 입력으로, x, y, 회전 오버레이를 출력으로 하는 역전파 신경망 회귀를 출력 범주별, 상황별로 학습한다. 학습에 쓰지 않은 기준 웨이퍼의 실측과 0.1 um 임계값으로 비교해 검증하고, 고정 크기 이동 창으로 계속 재학습한다.
- **같은 점:** 위치 오프셋과 회전을 회귀로 추정한다. 명령 위치와 실제 위치가 다를 수 있다고 본다. 허용치에서 정한 임계값으로 통과를 판단한다. 학습에 쓰지 않은 대상으로 검증한다. 상황(날짜, 세션)마다 영점이 다른 문제를 상황별 모형으로 다룬다.
- **다른 점:** 이 공보는 실측 라벨이 매일 수천 건 쌓이지만, 우리는 명령값 라벨의 정지 사진 341/575장이고 운전 중에 실제 위치를 잴 수 없어 온라인 재학습이 불가능하다. 입력이 공정 로그 수치이고 영상 특징이 아니다. Y, T 반응이 거의 평행한(cos 0.99999) 공선성 문제가 없다. 신경망 구조, 자료 수, 선형 모형과의 비교가 없다. 우리 허용치는 Y 0.65 px, T 1단위 80.3 px 기준 ±0.045(joint_v2는 |eT| ≤ 0.01)로 측정 잡음(0.009~0.015 px) 대비 훨씬 빠듯하다.
- **가져올 해결책:**
  1. 검증 분할을 "둘째 웨이퍼" 방식으로 둔다. 학습에 쓰지 않은 날짜 통째(1014만 학습, 1020, 1029 평가)를 주 평가로 하고, 통과 기준은 |eY| ≤ 0.045(Y 0.65 px), |eT| ≤ 0.01(joint_v2)로 허용치에서 바로 정한다.
  2. 예측 검증과 보정 검증을 나눠 보고한다. 오프라인 정지 사진 성적은 예측 검증이고, 실기에서 명령 후 재촬영해 잔차가 0.045 안에 드는지는 보정 검증이다. 후자는 아직 자료가 없다고 명시한다.
  3. 상황 변수를 명시한다. 날짜(세로 영점 +0.44 px), 접근 방향(백래시 β −0.34 px)을 상황으로 두고, 상황별 모형 대신 상황 불변 특징(QR−가로선 차, A15, A20의 2특징)과 비교한다.
  4. 신경망 회귀는 비교 후보로만 넣는다. 같은 특징, 같은 날짜 분할에서 GLS, Ridge와 정확도, ms를 비교하고, 기존 트리, 신경망 188/341 결과를 기준선으로 둔다.

## 이 단계 후보 방법으로서

- **방법 이름:** 신경망(역전파 MLP) 회귀 + 상황별 분리 모형 + 미사용 시료 임계값 검증 (TSMC US 11,626,304 B2)
- **전제 조건:**
  - 입력과 출력 사이 관계가 비선형이고 복잡하다.
  - 실측 라벨(계측기로 잰 실제 오차)이 많고, 운전 중에도 계속 들어온다.
  - 상황 변수(웨이퍼 종류, 공정 조건)를 기록할 수 있고, 상황마다 자료가 충분하다.
- **장점:**
  - 입력 종류를 많이 넣어도 사람이 모형식을 정하지 않아도 된다.
  - 이동 창 재학습으로 드리프트를 따라간다.
  - 검증 기준이 허용치와 바로 이어져 이해하기 쉽다.
- **단점:**
  - 구조, 자료 수, 선형 대비 이득이 공개되지 않아 재현 근거가 약하다.
  - 자료가 적으면 과적합이 쉽다. 우리 536점의 유효 독립 정보는 약 19개뿐이다.
  - 학습 범위 밖(다른 사분면, 혼합 자세)으로 외삽하면 무너지기 쉽다(Xu 2021, 질문 6).
  - Y, T가 거의 평행한 반응을 두 축으로 나누는 구조적 장치가 없다. 혼합 자세에서 Y 오차 ≈ −5~−6 × T 오차인 누출을 오히려 학습할 수 있다.
  - 온라인 재학습은 실제 위치 라벨이 필요한데 우리 장비는 운전 중에 이를 얻지 못한다.
- **우리 적용 조건:**
  - 입력은 저차원 불변 특징으로 제한한다(예: A20의 QR 평균 가로 이동 + 위아래 선 기울기 차 2특징, 또는 GLS 투영 후 소수 성분). 204차원이나 536점을 그대로 넣지 않는다.
  - 은닉층 작은 MLP(매개변수 수가 학습 장수의 1/10 이하)로 두고, 같은 특징의 GLS, Ridge와 같은 분할에서 비교한다.
  - 주 평가는 날짜 통째 분할(1014 학습, 다른 날짜 평가)과 날짜별 80/20 5-fold(10분할 반복)다. 하이퍼파라미터는 안쪽 분할에서만 고른다(중첩 CV).
  - 채택 조건: 날짜 분할에서 |eY| ≤ 0.045, |eT| ≤ 0.01 통과율과 최대오차가 선형 후보보다 낫고, 한 장 처리 시간이 늘어도 수 ms 이내일 것. 아니면 근거 없음으로 표시하고 선형 모형을 유지한다.
  - 341/575장은 개발에 노출된 자료이며, 이동 창 재학습과 보정 검증은 실기 자료가 생긴 뒤에만 평가할 수 있다고 적는다.
