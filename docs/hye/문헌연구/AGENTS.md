# 문헌연구 작업 지침

이 폴더에서 논문·특허를 조사하거나, 조사 결과를 문서·캔버스·실험 계획에 쓸 때 따른다. 알고리즘 목표·평가 규칙은 [ALGORITHM_RULES.md](../../../ALGORITHM_RULES.md)를 따른다.

## 1. 후보 방법은 문헌에서 나온다

- 파이프라인 단계별 "후보 방법" 목록(예: [00005_파이프라인](00005_파이프라인/00_파이프라인_검증현황.canvas))은 **잠정 목록**이다. 기억이나 일반 지식으로 적은 목록을 그대로 실험 대상으로 확정하지 않는다.
- 단계마다 다음 순서를 거친다.
  1. 그 단계의 **해결할 질문**을 정한다.
  2. 질문에 답하는 논문·특허를 조사한다 (아래 2절).
  3. 문헌에서 나온 방법으로 후보 목록을 **다시 작성**한다. 방법마다 출처, 전제 조건, 장단점, 우리 장비에 적용할 조건을 적는다. 잠정 목록에 없던 방법은 추가하고, 근거가 없는 방법은 근거 없음으로 표시한다.
  4. 다시 작성한 후보를 **같은 자료·같은 분할**에서 정확도와 처리 시간으로 비교 실험한다. 실험은 `experiments/hye/YYYYMMDD_HHMMSS_주제/`에 C++로 둔다.
  5. 결과로 캔버스의 후보 방법·현재 상태를 갱신한다.
- 이미 해 본 실험이 있으면 결과를 재사용하되, 문헌 조사로 새로 나온 후보와 같은 조건인지 확인한다. 조건이 다르면 다시 돌린다.

## 2. 수집 방식

- 수집 범위를 줄이지 않는다. 논문과 특허를 모두 찾는다.
- 주제 폴더마다 `조사방법론.md`를 먼저 쓴다: 목적, 문제 정의(P#와 근거 수치), 조사 질문, 검색어(블록 안 OR, 블록 사이 AND).
- 검색 기록(날짜, 경로, 검색어, 걸린 건수, 후보, 선정)을 `00000_..._조사_방법론_및_결과_.md`에 남긴다.
- 선정한 문헌마다 폴더 `NN_저자연도_출처_핵심어/`를 만들고 다음을 둔다.
  - 원문 PDF (특허는 등록·공개 공보)
  - `번역.md`: 전문 번역. 그림·표 캡션 포함, 그림은 처음 언급되는 곳 근처에 삽입
  - `요약.md`: 서지, 핵심, 정량 수치, 우리와의 관계(관련도, 해결하는 P#), 상세 요약
  - `그림/` 또는 `도면/`
- 원문을 받지 못하면 `00000_논문_원문_받을_목록.md`에 링크와 이유를 적는다. 봇 차단을 우회하지 않는다.
- 주제 폴더의 `00001_심층비교분석_vN.md`와 [문헌대장](00002_문헌대장_v2.md)을 갱신한다.

## 3. 근거 표기

- 원문 확인 / 초록만 확인 / 2차 자료만 확인 / 미확보를 구분한다. 초록·2차 자료만 본 내용은 `*`로 표시한다.
- 기억에서 나온 서지는 확보 전까지 "확인 필요"로 적는다.
- 문헌의 실험 결과, 저자 해석, 우리 과제로의 추론, 검증 전 가설을 구분한다.

## 4. 폴더 구조 변경

- 폴더 이름을 바꾸거나 옮기면 이 폴더의 md, 캔버스, 문헌대장, 종합 보고서에 있는 링크를 전부 같이 고친다.
