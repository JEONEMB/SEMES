# Xu et al. 2021 — 신경망은 어떻게 외삽하는가 (ICLR 2021)

- 원제: How Neural Networks Extrapolate: From Feedforward to Graph Neural Networks
- 원문: `Xu2021_ICLR_how_neural_networks_extrapolate.pdf` (arXiv 2009.11848 공개본)
- 저자: Keyulu Xu, Mozhi Zhang, Jingling Li, Simon S. Du, Ken-ichi Kawarabayashi, Stefanie Jegelka
- 서지: International Conference on Learning Representations (ICLR) 2021 / arXiv:2009.11848
- 핵심 (초록 기준*)
  - 경사 하강으로 학습한 ReLU 다층 퍼셉트론(MLP)은 원점에서 어느 방향으로든 **학습 분포 밖에서 빠르게 선형 함수로 수렴**한다. 따라서 대부분의 비선형 함수는 외삽하지 못한다.
  - 목표 함수가 선형이고 학습 분포가 **충분히 다양하면(모든 방향을 덮으면)** 선형 목표는 외삽할 수 있다.
  - 외삽에 성공하는 구조는 과제 고유의 비선형성을 **구조나 특징에 미리 넣은 경우**다.
- 정량 수치: 초록에 없음.
- 우리와의 관계: △ **P4**. 실측 혼합 자세가 Y>0, T>0 한 사분면뿐이어서 (−2, −1) 모서리에서 29~42 %로 떨어진 현상(팀 보고서 그림 6)의 이론 배경. 해결 방향은 (1) 기하 구조를 모델에 넣거나(P3), (2) 학습 자료가 모든 사분면 방향을 덮도록 촬영을 설계하는 것(P4)이다.

## 상세 요약 (번역본 기반)

### 1. 배경 및 문제 정의
- 심층 신경망(MLP, GNN 등)이 학습 데이터 분포(In-Distribution) 밖의 영역(Out-of-Distribution, OOD)으로 외삽(Extrapolation)할 때 비선형 함수를 제대로 일반화하지 못하는 근본적 수학적 한계 규명 (ICLR 2021 최우수 논문).

### 2. 핵심 이론 및 수식
- **신경망 외삽의 선형성 수렴 정리**:
  - ReLU 활성화 함수를 사용하는 다층 퍼셉트론(MLP)은 학습 데이터가 존재하는 볼록 껍질(Convex Hull)을 벗어나면 방향성으로 1차 선형 함수(Linear Function)로 점근적으로 수렴함.
  $$f(\alpha \mathbf{x}) \to \alpha \mathbf{c}^T \mathbf{x} + d \quad (\alpha \to \infty)$$
  - 따라서 학습 데이터에 포함되지 않은 비선형 기하학적 왜곡(예: 틸트-변위 간의 고차 결합 곡면)을 순수 데이터 기반 딥러닝 모델이 자율적으로 외삽하여 예측하는 것은 불가능함을 증명.

### 3. 실험 및 주요 결과
- 대수적 비선형 연산(곱셈, 거듭제곱, 삼각함수)에 대한 외삽 시험에서 MLP의 예측 오차는 OOD 영역 진입 즉시 1000% 이상 폭증.
- 반면 비선형 기하학적 구조(Nonlinear Inductive Bias)를 아키텍처에 명시적으로 내장한 모델만이 유효한 외삽 달성.

### 4. SEMES 과제 시사점
- $Y-T$ 오차 보정을 위해 기하학적 물리 모델 없이 단순 딥러닝/MLP 회귀기를 블랙박스로 적용할 경우, 작업자가 티칭한 특정 궤적 밖의 영역에서 보정 성능이 파국적으로 붕괴될 위험이 큼.
- 반드시 투영 기하학 공식(Homography, IPPE)과 기구학 기하 모델을 먼저 결합한 하이브리드 보정 구조를 채택해야 함.
