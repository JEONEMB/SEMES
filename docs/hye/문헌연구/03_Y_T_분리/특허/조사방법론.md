# Y·Θ 분리 특허 조사 — 조사 방법론 (계획서)

- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 상위 문서: `../논문/00000_YT분리_조사_방법론_및_결과_.md` (문제 정의 P1~P5), `../논문/조사방법론.md`
- 결과서: `00000_YT분리_특허_조사_방법론_및_결과_.md`

## 1. 목적

| 목적 | 활용처 |
|---|---|
| 논문 결과서의 P1~P5 각각에 대해, 산업 장비 특허가 쓰는 해결 구성(장치·절차·계산식)을 찾는다 | 4장 "본 과제에서 할 일"의 실무 근거, 알고리즘 설명 자료 |
| XYθ 비전 얼라인먼트의 표준 절차(회전 중심 산출, 좌표 변환 보정, 시험 이동)를 원문으로 확인한다 | 1014 자료 자기 보정(P3-2), 시험 이동 루틴(P5-2) 설계 |
| 유사연구 특허 01~09와 겹치지 않는 Y·Θ 분리 관련 특허를 확보한다 | 과제 차별점 정리 |

## 2. 대상 문제 (논문 결과서 1장 P#를 그대로 사용)

| P# | 문제 | 특허에서 찾을 근거 |
|:---:|---|---|
| P1 | Y와 T의 영상 반응 방향이 거의 같아 동시 추정이 불안정(공선성) | 마크 2개 이상을 멀리 떨어뜨려 θ와 X·Y 오프셋을 분리하는 구성, 회전·평행이동 결합을 피하는 계산 순서 |
| P2 | 단일 평면(QR 판)만으로는 분리 정보 부족 | 두 번째 마크·두 번째 카메라·다른 위치 관측을 추가해 회전을 분리하는 구성 |
| P3 | 카메라 내부·외부 파라미터 미보정 | 스테이지를 알려진 양만큼 움직여 영상-스테이지 좌표 변환(스케일·기울기)과 회전 중심을 자동으로 구하는 보정 절차 |
| P4 | 학습 회귀의 외삽(미관측 사분면·범위) | 스테이지 전 영역·여러 위치에서 보정점을 잡거나 기하 모델로 전 범위에 적용하는 구성 |
| P5 | 1장씩 수동 추정, 알려진 이동의 정보를 쓰지 않음 | 시험 이동(알려진 회전·이동) 전후 영상으로 보정량을 산출하는 절차, 반복 보정 |

| 블록 | 영문 | 국문 |

| B. 얼라인먼트 | XY theta stage, alignment mark, two marks, fiducial, positioning, aligner | XYθ 스테이지, 얼라인 마크, 기준 마크, 2점 정렬, 얼라이너 |
| C. 좌표 보정 | calibration, camera coordinate system, stage coordinate system, coordinate transformation, hand-eye calibration, move known amount | 캘리브레이션, 좌표 변환, 카메라 좌표계, 스테이지 좌표계 |
| D. 이송 로봇 | substrate transfer robot, end effector, position deviation, angle deviation, camera image correction | 이송 로봇, 핸드, 위치 편차, 각도 편차 |

## 5. 선정 기준과 관련도

- 포함: P1~P5 중 하나 이상에 해결 구성(장치·절차·계산식)을 주는 특허. 카메라(비전)로 마크·기판을 보고 회전과 평행이동을 구분하거나 보정하는 것.
- 제외: 유사연구 특허 01~09(US12566413, US12472621, US12224191, US12283510, US9966290, US12074051, US6973370, US12536776, US20240312821)와 그 패밀리. 비전과 무관한 순수 기구 특허. 원문을 열지 못한 특허.
- 관련도: ◎ 문제를 직접 해결하는 구성 / ○ 부분적으로 해결 / △ 참고.
- 선정 수: ◎·○ 4~6건(번역까지), △ 0~3건(요약.md만). 번호는 관련도 순.
- 우선: 반도체 장비사·디스플레이·PCB 얼라이너(XYθ 비전 정렬) 특허. 단 주제 적합성이 우선.
