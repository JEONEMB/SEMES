# QR 분석 · 특허 8건 — 심층 비교 분석 v2

작성: 2026-10-30 · 범위: 8개 등록 항목

질문: **산업 계측은 식별·정밀 측정·품질 판정을 어떻게 나누는가?**

이 보고서는 폴더의 기존 요약·조사 결과를 재구성한 비교 분석이다. 이번 작업에서 모든 PDF의 식·수치를 새로 대조한 것은 아니다. 각 카드의 결과는 기존 기록의 확인 수준을 승계하며, SEMES 적용 문장은 검증할 설계 제안이다. 문헌 파일 존재와 내용 검증을 구분한다.

## 문헌군 비교와 해석

### 코드와 좌표 측정의 분업

Cognex는 코드로 절대 ID를 정하고 주변 코너로 위치를 잰다. Honda는 QR의 소수 기준 패턴으로 자세를 구하며, PI는 시야·마커 크기·가시 개수를 설계한다. Hexagon은 절대 위치 코드 트랙이다. 모두 코드 사용이라는 공통점이 있지만 다수 내부점·소수 외곽점·라인 센서는 정보량과 오차 구조가 다르다.

### Canon 세 특허의 차이

US7352891은 요소 간격 잔차로 잘못 측정된 요소를 고르는 **품질 판정**, US7019836은 미세 이동·조명·초점별 간격 변동으로 측정계를 평가하는 **조건 선택**, US7265841은 파형 지표와 위치 오차의 관계를 학습하는 **편향 보정**이다. 세 방법을 동일한 ‘서브픽셀 알고리즘’으로 합치지 않는다.

### 그대로 옮기기 어려운 전제

물리 점 간격이 일정해도 영상 점 간격은 원근·깊이·왜곡에 따라 달라진다. 따라서 설계 간격과의 차를 바로 불량으로 버리면 T의 실제 신호를 제거할 수 있다. 합법적인 warp로 예측되는 간격을 기준으로 잔차를 만들고, 격자 잔차를 지우면서 축 분리 정보도 지우는지 검사한다. Sys-Tech의 인쇄 편차는 고정 패턴의 식별 지문이지 실제 위치 정답이 아니다.

청구한 구성·실시예·정량 시험을 구분하고, 이번 비교로 특허 권리 범위나 실시 가능성을 법률적으로 판단하지 않는다.
