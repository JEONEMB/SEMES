# QR 분석 특허 조사 방법론 (계획)

- 작성일: 2026-10-30
- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 결과 문서: `00000_QR분석_특허_조사_방법론_및_결과_.md` (이 계획대로 조사를 마친 뒤 작성)
- 짝 문서: `../논문/00000_QR분석_조사_방법론_및_결과_.md` (문제 정의 P1~P6과 4장 "본 과제에서 할 일")
- 제외: 유사연구 특허 01~09번(US12566413, US12472621, US12224191, US12283510, US9966290, US12074051, US6973370, US12536776, US20240312821)은 다시 고르지 않고 번호로만 참조한다.

## 1. 목적

1. 논문 결과서가 정의한 QR 분석 문제(P1~P6)에 대해, **장비 회사가 실제 제품에 넣으려고 권리화한 해결 구성**을 찾는다.
2. 논문이 주지 못한 부분, 즉 장비 안에서의 구현 방식(마크 선택·기각 규칙, 조명·초점 조건 선택, 재측정 흐름, 코드로 위치를 부호화한 판 설계)을 확인한다.
3. 각 특허 구성을 논문 결과서 4장의 할 일(P1-1 ~ P6-4)에 연결해 구현 근거로 쓴다.

## 2. 대상 문제 (논문 결과서 1.1절 그대로)

| P# | 문제 | 특허에서 찾을 것 |
|:---:|---|---|
| P1 | 반복 무늬로 인한 대응 오류 | 2D 코드를 격자 안에 넣어 각 점에 절대 ID를 주는 판·스케일, 반복 마크의 오검출 방지 |
| P2 | 부화소 위치 편향과 잡음 하한 | 얼라인 마크 중심의 부화소 검출, 신호 파형(비대칭)으로 중심 오차를 보정하는 방법 |
| P3 | 점 종류·측정 모델 선택 | 2D 코드의 어떤 점(파인더 중심, 셀 격자, 코너)으로 위치·자세를 계산하는가, 마커 여러 개로 자세를 구하는 구성 |
| P4 | 블러·조명·렌즈 왜곡 강건성 | 초점·조명 조건을 바꾸어도 위치가 변하지 않게 하는 조건 선택·보정 |
| P5 | 실시간성과 정밀도의 맞교환 | 고속 패턴 탐색 + 정밀화 2단계, 계산 절감 구성 |
| P6 | 검출 실패와 신뢰도 판단 | 마크 요소별 정밀도 판정·기각, 측정 재현성 자체 평가, 실패 시 재측정 |

## 5. 선정 기준·관련도

- 포함: P1~P6 중 하나 이상에 **구체적인 해결 구성**(단계·판정 규칙·수식)이 청구항이나 실시예에 있음.
- 관련도
  - ◎ 문제를 직접 해결하는 구성 (2D 코드·마크 위치 측정에서 같은 문제를 같은 수단으로 다룸)
  - ○ 부분 해결 (분야는 다르나 구성을 옮겨 쓸 수 있음)
  - △ 참고 (배경, 대체 방식)
- 우선: 반도체·디스플레이·로봇·정밀 스테이지 장비사. 주제 적합성이 우선.
- 제외: 판독 성공률만 다룬 바코드 판독기 특허, 위치 정밀도 없는 물류·AR 응용, 유사연구 특허 01~09번.
- 선정 수: ◎·○ 4~6건(번역까지), △ 0~3건(요약.md만).
