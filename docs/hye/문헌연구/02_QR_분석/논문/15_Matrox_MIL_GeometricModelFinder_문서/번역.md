## 1. 개요 및 기본 개념 (Basic Concepts)

### 1.1 기하학적 모델 파인더(GMF)란 무엇인가?
기하학적 모델 파인더(Geometric Model Finder, GMF)는 영상 내에서 사전에 정의된 기하학적 형상(모델)을 빠르고 신뢰성 있게 검출하고, 그 2차원 위치(X, Y), 회전 각도(Angle), 및 스케일(Scale)을 정밀하게 측정하는 고급 패턴 매칭 툴이다.

종래의 정규화 상호 상관(Normalized Cross-Correlation, NCC)이나 밝기 기반 패턴 매칭(Gray-level Pattern Matching)은 템플릿과 대상 영역 간의 화소 밝기값(intensity)을 직접 비교한다. 반면 GMF는 대상의 형상을 규정하는 **기하학적 에지(edge) 특징과 윤곽선(contour)**을 추출하여 매칭을 수행한다.

### 1.2 밝기 기반 매칭 대비 GMF의 장점
- **조명 변화 및 불균일 조명에 대한 불변성**: 에지의 방향성과 구배(gradient)를 기반으로 하므로 전체 밝기 변화, 비균일 조명, 국부적 그림자 및 금속면 정반사(specular reflection) 환경에서도 안정적으로 동작한다.
- **가림(Occlusion) 및 결함에 대한 강건성**: 모델의 일부가 가려지거나 결함이 발생하더라도 잔여 에지 정보만으로 대상체를 식별할 수 있다.
- **다양한 자유도 지원**: 2차원 평행이동(X, Y)뿐만 아니라 360도 전방위 회전(Rotation), 균일/비균일 크기 변화(Scale), 종횡비(Aspect Ratio) 변화를 동시에 탐색할 수 있다.
- **초고정밀 부화소(Sub-pixel) 정확도**: 에지 서브픽셀 보간 알고리즘을 통해 최대 1/20 ~ 1/40 픽셀에 달하는 높은 위치 결정 정확도를 제공한다.

## 2. 모델 정의 및 학습 (Model Definition & Training)

### 2.1 모델 유형 (Model Types)
GMF에서는 크게 두 가지 방식으로 모델을 생성할 수 있다:
1. **영상 기반 모델 (Raster Image-based Model)**: 실제 촬상된 기준 화상에서 관심 영역(ROI)을 지정하고 에지 검출기를 적용하여 기하학적 특징을 자동으로 추출한다.
2. **합성 기하 모델 (Synthetic/CAD-based Model)**: CAD 도면 데이터(DXF) 또는 원, 사각형, 선분, 호(arc) 등의 수학적 기하 기본 도형(geometric primitives)을 파라미터로 결합하여 이상적인 노이즈 프리(noise-free) 모델을 정의한다.

### 2.2 특징 추출 및 전처리 (Preprocessing)
- **에지 검출**: 소벨(Sobel) 또는 미분 연산자를 적용하여 밝기 변화 구배 벡터의 크기와 방향을 산출한다.
- **필터링 및 세선화**: 임계값 이하의 미약한 잡음 에지를 제거하고, 서브픽셀 정밀도로 에지 중심선을 세선화한다.
- **전처리(Preprocess)**: 설정된 탐색 각도 범위, 스케일 범위에 맞춰 다해상도 피라미드(Multi-resolution Image Pyramid) 구조를 사전 생성하여 실시간 탐색 속도를 극대화한다.

## 3. 탐색 및 점수화 메커니즘 (Search & Scoring Mechanism)

### 3.1 탐색 프로세스 (Search Process)
1. **대략적 탐색 (Coarse Search)**: 축소된 저해상도 피라미드 레벨에서 후보 위치를 고속으로 스크리닝한다.
2. **정밀 정렬 및 서브픽셀 최적화 (Fine Tuning & Sub-pixel Optimization)**: 후보 위치를 원본 해상도로 전파한 후 에지 거리 필드(Distance Field) 상에서 비선형 최적화를 수행하여 최적의 $(X, Y, \theta, S)$를 결정한다.

### 3.2 평가 점수 체계 (Scoring System)
GMF는 탐색된 각 매칭 결과에 대하여 다각적인 신뢰도 점수를 제공한다:

- **모델 점수 (Score / Fit Score)**:
  - 모델의 에지 중 대상 영상의 실제 에지와 일치하는 비율을 나타낸다.
  - 모델의 필수 형상이 대상체에 얼마나 온전히 존재하는지를 평가한다.
  - 거리 편차에 따라 가중 감점이 적용된다:
    $$\text{Score} = \frac{1}{L_{\text{model}}} \sum_{i} w(d_i)$$
    여기서 $d_i$는 모델 에지 포인트 $i$에서 가장 가까운 대상 에지까지의 거리, $w(d)$는 가중 감소 함수이다.

- **대상 점수 (Target Score)**:
  - 대상 영역에 존재하는 에지 중 모델에 부합하지 않는 불필요한 에지(잡음, 오염, 배경 간섭)가 얼마나 적은지를 나타낸다.
  - Target Score가 높을수록 군더더기 에지 없이 깨끗하게 모델 형상만 존재함을 의미한다.

- **신뢰도 및 수락 임계값 (Certainty & Acceptance)**:
  - `M_ACCEPTANCE`: 매칭 후보로 인정받기 위한 최소 점수 임계값 (기본값 통상 60~70%).
  - `M_CERTAINTY`: 추가 탐색이나 모호성 검토 없이 즉시 유효한 일치로 확정하는 높은 신뢰도 임계값 (기본값 통상 80~90%). Score와 Target Score가 모두 Certainty를 초과하면 해당 결과는 즉각 확정된다.

## 4. 정밀도, 속도 및 파라미터 트레이드오프

### 4.1 부화소 정밀도 (Sub-pixel Accuracy)
- GMF는 이산 픽셀 그리드에 의존하지 않고 연속 좌표 공간에서 에지의 제로 크로싱(zero-crossing) 및 거리 최소화를 수행한다.
- 대비(contrast)가 양호하고 기하 형상이 뚜렷한 경우 위치 정확도는 1/20 ~ 1/40 픽셀, 각도 정확도는 0.01° ~ 0.05°에 도달한다.

### 4.2 속도-정밀도 제어 모드
- `M_SPEED`: 탐색 속도 우선 모드. 피라미드 스킵 단계를 늘리고 후보군 검토를 축소하여 속도를 대폭 높이나, 미세한 형상 왜곡에 대한 수렴성 및 서브픽셀 정밀도가 소폭 저하될 수 있다.
- `M_ACCURACY`: 정밀도 우선 모드. 모든 피라미드 단계에서 정밀 반복 수렴을 거치므로 연산 시간은 증가하지만 최고 수준의 반복능(repeatability)을 보장한다.

## 5. 핵심 MIL GMF 함수 참조 (C/C++ API Reference)

```cpp
// 1. GMF 컨텍스트 및 결과 버퍼 할당
MIL_ID MilSearchContext, MilSearchResult;
MmodAlloc(MilSystem, M_GEOMETRIC, M_DEFAULT, &MilSearchContext);
MmodAllocResult(MilSystem, M_DEFAULT, &MilSearchResult);

// 2. 모델 정의 (기준 화상 버퍼로부터 사각형 영역 지정)
MmodDefine(MilSearchContext, M_IMAGE, MilSrcImage, 
           OffsetX, OffsetY, SizeX, SizeY);

// 3. 탐색 제어 파라미터 설정 (탐색 각도, 스케일 범위, 수락 점수)
MmodControl(MilSearchContext, M_CONTEXT, M_SEARCH_ANGLE_RANGE, 10.0); // ±10도 탐색
MmodControl(MilSearchContext, M_CONTEXT, M_ACCEPTANCE, 70.0);        // 최소 수락 점수 70%
MmodControl(MilSearchContext, M_CONTEXT, M_CERTAINTY, 85.0);         // 확정 신뢰도 85%
MmodControl(MilSearchContext, M_CONTEXT, M_ACCURACY, M_HIGH);        // 고정밀 모드

// 4. 모델 전처리
MmodPreprocess(MilSearchContext, M_DEFAULT);

// 5. 대상 화상에서 모델 탐색 실행
MmodFind(MilSearchContext, MilTargetImage, MilSearchResult);

// 6. 탐색 결과 판독 (검출 수, 위치 X, Y, 각도, 매칭 점수)
MIL_INT NumMatches = 0;
MmodGetResult(MilSearchResult, M_DEFAULT, M_NUMBER + M_TYPE_MIL_INT, &NumMatches);

if (NumMatches > 0) {
    double PosX, PosY, Angle, Score;
    MmodGetResult(MilSearchResult, 0, M_POSITION_X, &PosX);
    MmodGetResult(MilSearchResult, 0, M_POSITION_Y, &PosY);
    MmodGetResult(MilSearchResult, 0, M_ANGLE, &Angle);
    MmodGetResult(MilSearchResult, 0, M_SCORE, &Score);
    // 검출된 (PosX, PosY, Angle)을 정밀 얼라인먼트 좌표로 활용
}

// 7. 자원 해제
MmodFree(MilSearchResult);
MmodFree(MilSearchContext);
```

## 6. 반도체 얼라인먼트 및 QR 마커 검출 응용 고찰

반도체 웨이퍼 이송 로봇 및 정밀 얼라인먼트 시스템에서 MIL GMF는 다음과 같은 용도로 강력하게 기능한다:
1. **웨이퍼 노치 및 에지 고속 검출**: 웨이퍼 원호 및 노치 형상을 기하학적 기본 모델로 등록하여 0.02 픽셀급 중심 및 회전각 추출.
2. **QR 코드 / 피듀셜 마크 기준점 탐색**: QR 코드의 'ㅁ'자 파인더 패턴(Finder Pattern)을 기하학적 모델로 등록하면, 조명 반사나 배경 노이즈가 심한 환경에서도 회전 각도와 3개 모서리 파인더의 절대 좌표를 서브픽셀 정밀도로 안정적으로 획득할 수 있다.
3. **신뢰도 지표(Certainty) 기반 품질 관리**: 검출 점수가 `M_CERTAINTY` 미만으로 떨어질 경우 비전 이상, 렌즈 오염, 또는 마커 손상 경보를 즉각 발행하여 설비 충돌 사고를 사전에 차단할 수 있다.
