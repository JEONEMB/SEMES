# 원인분석 조사 방법론 (계획)

- 작성일: 2026-10-30
- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 결과 문서: `00000_원인분석_조사_방법론_및_결과_.md` (이 계획대로 조사를 마친 뒤 작성)
- 근거 문서: 명세서 2차 본문, 팀 3차 멘토링 보고서 v8(이하 "팀 보고서"), `../../유사연구/00000_유사연구_종합요약.md`

## 1. 목적

1. **왜 Y 이동과 Θ(이하 T, PAN) 회전이 2D 영상에서 구분되지 않는가**를 기하·통계·장비 관점에서 문헌으로 설명한다.
2. 원인마다 "어떤 조건에서 구분 단서가 커지는가(시야각, 작업 거리, 회전축 위치, 깊이 차)"를 수식과 정량 근거로 정리한다.
3. 원인별 해결 과제를 다음 조사 폴더(02 QR 분석 / 03 Y·T 분리 / 04 오차 보정)로 넘긴다.

팀 보고서가 이미 쓴 방법(특징점 이동장, P12, GLS, 가로선 추가)은 반복하지 않는다. 그 방법들이 **왜 그 성적에서 멈췄는지**를 설명할 근거를 찾는다.

## 2. 이 주제에서 발생하는 문제 정의

| P# | 문제 | 근거 (명세서·팀 보고서 수치) |
|:---:|---|---|
| P1 | **기하학적 동치**: 평면 판을 좁은 시야로 볼 때 작은 Y 이동과 작은 T 회전이 1차 근사로 같은 영상 이동을 만든다. 차이는 2차(원근) 항뿐이다. | Y 1 mm ↔ T 0.178이 판 이동이 거의 같음. 점별 반응 방향 코사인 유사도 0.9999997. 판 이동 제거 후 점별 차이 표준편차 0.029 px (팀 보고서 3.4절) |
| P2 | **관측 가능성·조건수**: QR 판 관측만으로 Y·T를 동시에 풀면 두 열이 거의 평행한 선형계가 되어 해가 불안정하다. 평면 자세의 두 해 모호성, 약원근 근사도 같은 방향으로 작용한다. | QR만으로 동시 추정 134/280(47.9 %), 반응 유사도 0.994. 여러 방법으로도 188/341을 넘지 못함. 가로선을 더하자 337/341 (팀 보고서 4.2.2절) |
| P3 | **신호 대 잡음**: 구분 단서(2차 항)가 점 위치 잡음과 같은 크기다. | 구분 단서 0.029 px, 점 잡음 0.0124~0.033 px, 템플릿 잡음 0.0124 px가 CRLB에 근접 (팀 보고서 4.1절) |
| P4 | **장비 기하 미보정**: 회전축의 위치(카메라·판과의 거리)와 기울기, 카메라 내부 매개변수를 모른다. 이 때문에 T 1 단위가 판을 얼마나 옮기는지, 가로선이 왜 T에만 반응하는지 물리적으로 설명되지 않는다. | 감도 Y 14.25 px/mm, T 80.04 px/T (비율 5.62 mm/T). 가로선은 T에만 반응. 명세서에 카메라·스테이지 기하 정보 없음 |
| P5 | **백래시·영점 변동**: 같은 명령값에서도 접근 방향에 따라 판 위치가 달라진다. | 촬영 묶음마다 영점 −0.85~0 px, 같은 날 센터·혼합 세션 차 약 0.6 px(Y 약 0.04 mm) = Y 허용오차(1.28 px)의 절반 수준. 1020 세트 초점 7 % 흐림 (팀 보고서 3.2·3.6절) |

## 3. 조사 질문

| P# | 무엇을 알아야 해결되는가 |
|:---:|---|
| P1 | 핀홀 모델에서 병진과 회전의 영상 운동식은 어떻게 다르며, 차이 항의 크기는 시야각·거리·회전축 오프셋에 어떻게 의존하는가? 평면 대상일 때 운동 매개변수는 몇 개로 줄어드는가? |
| P2 | 회전–병진 혼동(rotation–translation confusion)이 시야각·평면 기울기·병진 방향에 따라 얼마나 커지는가? 평면 자세의 두 해 모호성과 약원근 근사가 언제 문제가 되는가? 영상만 맞추는 되먹임 제어에서 같은 영상을 만드는 (Y, T) 조합이 남는가? |
| P3 | 운동 매개변수 추정의 크라메르-라오 하한(CRLB)은 시야각·점 밀도·잡음에 어떻게 의존하는가? 우리 점 수(536)·잡음으로 구분 단서의 SNR은 얼마인가? |
| P4 | 회전 중심이 카메라 광학 중심에서 떨어져 있을 때(오프셋) 영상 모델은 어떻게 바뀌고, 그 오프셋을 영상으로 보정하는 방법은 무엇인가? 깊이가 다른 점(가로선)이 회전과 병진을 어떻게 가르는가? |
| P5 | 백래시가 위치 결정에 주는 영향과 표준적 대응(단방향 접근, 모델 보상)은 무엇인가? |

## 4. 검색어

세 블록을 조합한다(블록 안 OR, 블록 사이 AND).

| 블록 | 검색어 |
|---|---|
| A. 현상 | rotation translation ambiguity / confusion / coupling, inherent ambiguity, observability, bas-relief ambiguity, pose ambiguity, two-solution |
| B. 대상 | 3-D motion, egomotion, optical flow field, planar surface, planar target, coplanar points, structure from motion |
| C. 조건·수단 | small/narrow field of view, weak perspective, Cramér-Rao bound, planar parallax, region alignment, visual servoing, rotation axis / rotation center offset calibration, turntable, pan-tilt, backlash |

- 핵심: A∧B (+ C의 field of view, Cramér-Rao)
- 해결 원리: planar parallax, region alignment, 2.5D visual servoing, homography decomposition
- 장비: rotation axis calibration, rotation center offset, backlash
