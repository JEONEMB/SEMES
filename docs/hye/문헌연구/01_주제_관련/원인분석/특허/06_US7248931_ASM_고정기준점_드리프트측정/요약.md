## 상세 요약 (USPTO 등록본 PDF 판독 기준)

### 1. 해결하려는 문제
- 웨이퍼를 서셉터 포켓(200 mm 웨이퍼에 201 mm 포켓, 틈 0.5 mm)에 중심을 맞춰 놓아야 함. 벽에 닿으면 국부 온도 변화 → 공정 불균일, 손상.
- 웨이퍼는 이송 중엔 엔드 이펙터 위에서 움직이지 않지만, 집을 때마다 붙는 자리가 조금씩 달라 "드리프트"가 생김.
- 종래 광학 투과 빔 센서 방식은 센서 위치를 얼마나 정확히 아느냐에 정확도가 좌우되고, 기계적 설치가 복잡·고가. 별도 센터링 스테이션은 내려놓고 다시 집는 시간이 듦.
- → 이송 도중 "인라인"으로 간단·신뢰성 있게 측정·보정하는 방법이 필요.

### 3. 동작 순서
1. 엔드 이펙터가 웨이퍼를 집고 후퇴(또는 전진)하는 동안, 첫 기준 마크(302)와 웨이퍼 에지 1이 시야에 들어오면 촬영(트리거: 로봇 위치 센서, 또는 카메라 자체 광량 변화·임계 이하 화소 수).
2. 계속 이동해 둘째 기준 마크(304)와 에지 2가 들어오면 다시 촬영. (카메라 2대로 동시 촬영도 가능, 도 4C)
3. 각 영상에서 기준 마크와 웨이퍼 에지 사이 거리를 화소 수로 셈(카메라 화소 축을 이동 방향 X / 수직 Y에 맞춤).
4. 방법 A — 중심 계산(도 6A·6B): 에지 점 (0, y1), (d, y2)와 웨이퍼 반경 Rw로 두 원의 교점을 풀어 중심을 구함.
   - Rw² = x² + (y−y1)², Rw² = (x−d)² + (y−y2)²
   - 수직이등분선 y = a·x + b, a = d/(y1−y2), b = (d² + y2² − y1²)/(2·(y1−y2))
   - 0 = (1+a²)·x² + (2·a·b − 2·a·y1)·x + (b² − 2·b·y1 + y1² − Rw²) → 근의 공식, y1 > y2 / y1 < y2 / y1 = y2 로 해 선택.
5. 방법 B — 중심 없이 드리프트(도 7): 미리 이상 위치 웨이퍼로 기준 거리를 저장해 두고,
   - ΔY1 = (Y_R1 − Y1) − (Y_R1 − Y1′), ΔY2 = (Y_R2 − Y2) − (Y_R2 − Y2′)  (8a, 8b)
   - Y 방향 중심 이동 ΔYc = [ΔY1 + ΔY2]/2  (5)
   - 현의 기울기 tan(α) = [ΔY1 − ΔY2]/2b  (6)
   - X 방향 이동 ΔXc = tan(α)·s = [ΔY1 − ΔY2]·[s/2b], s = √(r² − b²)  (7, 8)
   - 반경 방향 측정(도 8)일 때 ΔY1 = Δr1·cos(β) = Δr1·√(r² − b²)/r  (9)
6. 계산한 드리프트를 로봇 위치 매개변수 R·θ 조정으로 보상하거나, 스테이징·쿨다운 스테이션에 내려놓았다가 보정된 위치로 다시 집음.
7. 노치·플랫이 기준 마크와 겹치면 에지 점들을 원에 맞춰 보고, 원이 아니면 원 부분을 외삽한 가상 에지(908)와 홀더의 교점(910)을 써서 계산(도 9).

- 장점으로 명시: 마크가 엔드 이펙터에 고정된 실시예에서는 **촬영 시점의 로봇 절대 위치를 알 필요가 없어 복잡한 캘리브레이션·검증 절차가 불필요**. 로봇과 장비 고정물의 공간 관계에 의존하는 절대 측정 대신 이상 중심점 대비 비교로 드리프트를 검출.

### 4. 청구항 요지 (24항)
- 청구항 1(방법): 기판을 엔드 이펙터에 싣고 경로를 따라 이동 → 기판 에지 1과 근처 기준점 1을 함께 담은 영상 1, 에지 2와 기준점 2를 담은 영상 2 촬영 → 이상 위치 대비 위치 차를 영상으로 결정 → 이후 로봇 이동에서 보상.
- 청구항 23(방법): 각 영상에서 기준 마크–기판 에지 거리를 측정하고 그 거리들로 이상 위치 대비 드리프트를 계산.
- 청구항 24(시스템): 로봇(제1·제2 위치를 포함하는 병진 경로), 기준 마크, **기준 마크에 대해 고정된 카메라**(두 위치에서 각각 기준 마크 + 에지의 다른 부분 촬영), 카메라와 로봇의 입력을 받아 기준 마크 대비 기판 위치를 계산하는 처리기.
- 주요 종속항
  - 2~4: 기준점이 엔드 이펙터에 고정(엔드 이펙터 위 / 홀더 위).
  - 5·6: 두 기준점이 경로에 대략 평행 / 대략 수직한 선 위에 배치.
  - 7~9: 촬상 시야 50×50 / 20×20 / 10×10 mm 이하.
  - 10·11: 중심점 계산 후 이상 중심점과 비교.
  - 16·17: 촬상 장치 2대가 거의 동시에 촬영.
  - 19: 플랫·노치 식별.
  - 20~22: 기준점이 카메라에 고정, 카메라 1대가 두 시점에 촬영, 두 기준점이 같은 점일 수 있음.

### 6. 본 과제(Y·Θ 얼라인먼트)와 비교
- 같은 점:
  - 카메라 한 대 영상에서 기준 표식과 대상의 상대 위치를 화소로 재서 위치 보정값을 만든다.
  - 두 측정점의 **공통 이동 → 평행이동(ΔYc = 평균)**, **차동 이동 / 간격 → 회전(tan α = 차/2b)** 으로 나누는 구조가 본 과제의 Y·T 분리와 같은 꼴이다.
- 다른 점:
  - 대상은 엔드 이펙터 위 웨이퍼의 놓임 오차(드리프트)이고, 로봇 축의 영점·백래시나 회전축 위치 추정은 다루지 않는다.
  - 기준 마크가 대상(웨이퍼) 바로 옆, 같은 평면·같은 거리에 있어 회전 중심이 시야 밖 멀리 있는 문제(P1)가 없다. 반경 r이 기지값이라 X 이동도 바로 풀린다.
  - 오차 수치·반복 정밀도는 기재 없음(카메라 화소 수·시야 크기만 제시).
- 참고할 점 / 해결하는 P#:
  - **P5(영점·드리프트)**: 측정값을 "같은 영상 속 고정 기준 대비 상대 거리"로 정의하면 측정 기준 자체(카메라 장착·로봇 절대 위치)의 변동이 빠진다. 특허도 이 때문에 "절대 위치·복잡한 캘리브레이션 불필요"를 장점으로 든다.
  - **P2(보조)**: 회전 분해능 = 점 측정 잡음 / 기준점 간격(2b). 간격이 넓을수록 각도가 안정.
  - 본 과제에서 할 일:
    1. 장비 프레임(움직이지 않는 쪽)에 고정 기준 표식을 QR과 같은 영상에 넣을 수 있는지 확인하고, 접근 방향(+/−)별 반복 촬영에서 "QR − 고정 기준" 차분값의 영점 흔들림이 원시 QR 좌표보다 줄어드는지 측정한다(−0.85~0 px 영점 변동이 줄면 카메라 쪽 변동, 그대로면 실제 스테이지 백래시로 구분).
    2. QR 3개 중 가로로 가장 먼 두 점의 간격을 기준선으로, 평균은 Y 후보·차분/간격은 T 후보로 두는 식을 C++에 그대로 넣고, 간격 대비 점 잡음(0.012~0.033 px)으로 각도 분해능을 계산해 둔다.
