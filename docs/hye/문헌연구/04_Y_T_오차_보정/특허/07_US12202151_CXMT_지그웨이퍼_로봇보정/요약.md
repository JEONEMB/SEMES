## 상세 요약 (등록본 표지 기준, 번역본 없음)

### 1. 해결하려는 문제
- 웨이퍼 이송 로봇의 위치 보정을 사람이 외부 핸들로 하던 것을 자동화하고, 보정이 필요한지부터 데이터로 판정하고 싶다.

### 2. 핵심 구성 (표지 도면)
| 구성 | 부호 | 역할 |
|---|---|---|
| 로봇 | 11 | 웨이퍼 이송 로봇 |
| 보정 장치 | 12 (121 지그 웨이퍼, 122 센서 측) | 지그 웨이퍼 위에 센서·통신 모듈(13~16) |

### 3. 동작 순서 (초록 기준)
1. 지그 웨이퍼를 포함하는 보정 장치 준비.
2. 로봇으로 지그 웨이퍼를 잡거나 옮겨 데이터 수집.
3. 데이터로 보정 필요 여부 판정.
4. 필요하면 보상값을 구해 로봇 보정.

### 4. 본 과제와 비교
- "보정 필요 여부 판정 → 필요할 때만 보정"이라는 2단 구조는 본 과제의 운용 시나리오(주기 점검)에 참고할 만하다. 판정 기준·수치는 원문 확인이 필요하다(번역하지 않음).
