# Y·Θ 오차 보정 특허 조사 방법론 (계획)

- 작성일: 2026-10-30
- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 결과 문서: `00000_YT오차보정_특허_조사_방법론_및_결과_.md`
- 근거 문서: 명세서 2차 본문, 3차 멘토링 보고서 v8(이하 "팀 보고서"), 같은 주제의 논문 결과서 `../논문/00000_YT오차보정_조사_방법론_및_결과_.md`(문제 정의 P1~P6)
- 표기: Θ축은 팀 보고서와 같이 T로 쓴다.

## 1. 목적

1. 논문 조사에서 방법(GUM, 시각 서보 안정 조건, ISO 9283, nested CV)은 찾았으나, **장비 회사가 실제 장비에서 남는 오차를 어떻게 관리하는지**(백래시·로스트 모션 측정, 열변위 보정, 반복 보정 종료 조건, 검증용 지그)는 특허에 더 구체적으로 적혀 있다. 이를 P#별로 확보한다.
2. 특허의 청구항·실시예에서 본 과제가 바로 가져다 쓸 수 있는 절차(측정 순서, 판정 기준, 보정식)를 뽑는다.
3. 같은 구성이 이미 특허로 있는지 확인해, 본 과제가 새로 하는 부분과 선행 기술을 따른 부분을 나눈다.

## 2. 대상 문제 (논문 결과서 P# 그대로)

| P# | 문제 | 특허에서 찾을 근거 |
|:---:|---|---|
| P1 | 오차 예산이 없다 | 이송·정렬 장비가 위치 오차를 성분(기구 오차, 열변위, 로스트 모션, 측정 오차)으로 나눠 따로 보정하는 구성 |
| P2 | 평가 정답이 명령값이다 | 명령 위치와 실제 위치의 차를 외부 기준(센서, 지그, 기준 마크)으로 재는 구성 |
| P3 | 영점 변동(백래시·히스테리시스) | 백래시·로스트 모션을 측정하는 절차, 보정 테이블, 접근 방향 고정 |
| P4 | 반복 보정 수렴이 보장되지 않는다 | 촬영→이동→재촬영 반복의 종료 조건(허용치, 횟수 상한), 보정 이득·단계 전환 |
| P5 | 검증 설계가 낙관적이다 | 보정 결과를 독립 측정으로 확인하는 검증 단계, 검증 지그 |
| P6 | 허용오차 근거·단위 | 특허에 적힌 허용치·정확도 수치와 단위 |

## 3. 검색어

블록 안은 OR, 블록 사이는 AND.

| 블록 | 영문 | 국문 |
|---|---|---|
| A. 대상 | substrate/wafer transfer robot, aligner, alignment stage, XYθ stage, display panel alignment | 이송 로봇, 얼라이너, 정렬 스테이지 |
| B. 오차원 | backlash, lost motion, hysteresis, thermal expansion/displacement, drift, positional deviation, repeatability | 백래시, 로스트 모션, 열변위, 드리프트, 위치 편차 |
| C. 보정·검증 | camera/image, alignment mark, repeat until within tolerance, correction amount, coefficient/gain, approach direction, correction table, jig, verification | 카메라, 얼라인 마크, 허용 범위, 보정량, 접근 방향, 보정 테이블, 지그, 검증 |

- 핵심 조합: A∧B∧C, A∧C(반복 보정 종료 조건)
- CPC 후보: H01L21/681(위치 맞춤), H01L21/677(이송), B25J9/1692(로봇 보정), G05B19/401·G05B2219/41032(백래시 보상), G06T7/73, G01B11
