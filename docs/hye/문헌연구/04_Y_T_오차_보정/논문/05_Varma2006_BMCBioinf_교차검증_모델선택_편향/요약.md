# Varma & Simon 2006 — 모델 선택에 교차검증을 쓸 때 오차 추정의 편향 (BMC Bioinformatics)

- 원제: Bias in error estimation when using cross-validation for model selection
- 원문: `Varma2006_BiasInErrorEstimation_CV.pdf` (BMC 오픈 액세스)
- 저자: Sudhir Varma, Richard M. Simon (NCI)
- 핵심 (원문 확인)
  - 교차검증(CV) 오차를 최소화하도록 파라미터를 고른 뒤, **그 CV 오차를 성능으로 보고하면 크게 낙관적으로 편향**된다.
  - 두 클래스에 차이가 전혀 없는 "null" 자료로 실험: Shrunken Centroids(10-fold)는 모의 자료의 **18.5 %**에서, SVM(LOOCV)은 **38 %**에서 CV 오차가 30 % 미만으로 나왔다. 독립 시험 자료에서는 우연 수준이었다.
  - **중첩 CV(nested CV)**: 안쪽 CV로 파라미터를 고르고 바깥 CV로 오차를 잰다. 편향을 크게 줄여 독립 시험 자료와 거의 같은 추정을 준다.
  - 결론: 파라미터 조정을 포함한 **알고리즘의 모든 단계를 각 CV 루프 안에서 반복**해야 한다.
- 정량 수치: null 자료에서 낙관 편향 발생률 18.5 %, 38 %
- 우리와의 관계: ◎ **P5** 팀 보고서는 실험 223건 중 26건을 같은 고정 4-fold 성적으로 골랐다(280/280 등). 이 숫자는 "선택에 쓴 CV 성적"이라 낙관 편향이 있다. 고른 절차 전체(영점 후보 수, 점 집합, 축소 계수 등)를 안쪽 루프에 넣은 nested CV 또는 새 촬영 홀드아웃이 필요하다.
- DOI: https://doi.org/10.1186/1471-2105-7-91

## 상세 요약 (번역본 기반)

### 1. 배경 및 문제 정의
- 통계적 기계학습 및 파라미터 튜닝 시, 단일 교차 검증(Cross-Validation, CV)으로 하이퍼파라미터 선택과 모델 일반화 성능 평가를 동시에 수행할 경우 발생하는 극심한 낙관적 편향(Optimistic Selection Bias) 규명.

### 2. 핵심 이론 및 수식
- **중첩 교차 검증 (Nested Cross-Validation)**:
  - 외부 루프(Outer Loop): 편향 없는 실제 일반화 오차 평가.
  - 내부 루프(Inner Loop): 훈련 데이터 내부에서 최적 하이퍼파라미터 탐색.
  $$\text{Bias} = E[\text{Err}_{CV}] - \text{Err}_{true} < 0$$

### 3. 실험 및 주요 결과
- 표준 CV를 이용해 모델 선택 후 보고된 오차율은 실제 참 오차율보다 최대 40~50% 낙관적으로 과소평가됨을 다양한 벤치마크에서 입증. 중첩 CV만이 실제 미관측 테스트 환경에서의 정확한 오차를 예측.

### 4. SEMES 과제 시사점
- 비전 티칭 오차 보정 회귀 모델(Ridge, Polynomial, MLP 등)의 파라미터 선정 시 중첩 교차 검증을 적용하여 모델의 과적합을 방지하고 실제 팹 라인 배치 시의 오차 성능을 엄밀하게 보증해야 함.
