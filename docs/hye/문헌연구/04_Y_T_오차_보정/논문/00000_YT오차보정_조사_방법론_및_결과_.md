## 1. 목적

1. 추정한 Y·T에 남는 오차를 항목별로 나누고 합성하는 방법(오차 예산)의 근거를 찾는다.
2. 보정·재촬영 반복(최대 20턴)이 허용오차 0.09로 수렴하도록 하는 설계 근거(이득, 양자화, 백래시)를 찾는다.
3. 성능 숫자를 실제 정확도로 주장할 수 있게 하는 검증 설계(외부 기준, 반복성·재현성, 낙관 편향 제거)의 근거를 찾는다.

### 우리 과제와의 관계

- **오차 예산의 방법은 표준(GUM)과 비전 정렬 사례(02)로 확보했다.** 감도계수는 팀 보고서의 14.25 px/mm·80.04 px/T를 그대로 쓰면 된다(GUM 5.1.4절: 실험으로 구한 감도계수 허용).
- **현재 알려진 두 항(영점 변동, 제어 단위)만으로도 Y 허용오차의 절반을 쓴다**(4.1절 표). 스테이지 반복정밀도·열·진동은 아직 모른다 → 외부 기준 측정이 가장 먼저다.
- **백래시는 "불확도"가 아니라 "보정할 계통 오차"로 다뤄야 한다**(GUM F.2.2.2, 03·09번). 접근 방향을 고정하거나 방향별 보상값을 주면 영점 후보 6개가 필요 없어질 수 있다.
- **우리 루프는 정적 look-and-move이고, 학습한 GLS 투영 W는 문헌의 "상호작용 행렬 의사역의 수치 추정"이다**(07, 14번). 이 경우 이론적 안정성 보장이 없다고 문헌이 명시하므로, W·J의 고유값을 실측해 이득을 정해야 한다.
- **개발 성적 280/280·337/341은 선택 편향이 있는 숫자다**(05, 08번). 모델을 고정한 뒤 새로 찍은 자료로만 최종 성능을 보고해야 한다.

## 4. 문제별 해결 방안

### 4.1 P1 — 오차 예산 부재

- **원인**: 각 오차원이 서로 다른 단위(px, mm, 통과 장수)와 서로 다른 자료로 보고되어 합성되지 않았다. 추정기 오차(Y 최대 0.0366 등)는 명령값 기준이라 스테이지 오차가 이미 섞여 있다(P2).
- **문헌 근거**: GUM(01) — A형/B형 분리, 감도계수, 직사각형 분포 u = a/√3, 분해능·히스테리시스 u = 0.29δx, k = 2. Wang 2023(02) — 오차원 나열 → 시험으로 크기 추정 → 사슬 전파 → 몬테카를로 → 주요 오차원 결정. Kyrki(13) — 영상 오차의 제어 출력까지 해석적 전파. 조성만 2009(11) — 열변형을 레이저 간섭계로 재서 예산 항목화.

**Y축 오차 예산 (초안)** — 크기는 팀 보고서 수치와 문헌 공식으로만 채웠다. 환산은 Y 14.25 px/mm.

### 4.4 P4 — 반복 보정의 수렴성

- **원인**: 보정값을 그대로(이득 1) 내보내는 구조로, 감도 오차·양자화·백래시·단계 전환(joint ↔ control) 오판이 있을 때의 수렴 조건이 분석되지 않았다. 시나리오 재생은 가장 가까운 영상을 재사용하므로 실행 오차(양자화·백래시·반복정밀도)가 빠져 있다.
- **문헌 근거**: Hutchinson 1996(14) — 우리 구조는 (정적) look-and-move로, 스테이지 내부 제어가 안정을 맡고 비전 루프는 설정값만 준다. Chaumette 2006(04) — v = −λL̂⁺e, 안정 조건 L̂⁺L > 0. Chaumette 2007(07) — L⁺를 자료로 수치 추정하면 **안정성 이론 보장이 없다**, Broyden 갱신으로 온라인 보정 가능. 조성만 2009(11) — 패널 정렬에서 "오차가 기준 이하가 될 때까지" look-and-move 반복으로 3 µm 달성. van Hulst 2026(10) — 반복되는 오차는 ILC로 앞먹임 학습.

**본 조사 유도 — 축별 이산 루프 (검증 필요)**

e_{k+1} = e_k − round_q( g · ê_k ) + b_k, ê_k = a·e_k + n_k

(g: 이득, a: 실제 감도/모델 감도 비, q: 제어 단위 0.05 mm, b: 방향 반전 시 백래시, n: 측정 잡음)

| 조건 | 식 | 우리 값 적용 |
|---|---|---|
| 수렴(선형부) | 0 < g·a < 2, 턴당 축소율 ρ = \|1 − g·a\| (04번 조건의 이산·스칼라판) | 2 mm에서 0.09 mm까지 20턴 안: ρ ≤ 0.045^(1/20) = 0.856 → **0.14 ≤ g·a ≤ 1.86** |
| 도달 턴 수 | n = ⌈ln(τ/\|e₀\|) / ln ρ⌉ | g·a = 0.8(감도 20 % 과대) → ρ = 0.2 → 2 mm에서 **2턴**. g·a = 0.5 → 5턴 |
| 양자화 데드밴드 | 반올림 명령이 0이 되는 \|g·ê\| < q/2에서 멈춤 → 허용오차 밖에서 멈추지 않으려면 g·τ ≥ q/2 | g ≥ 0.025/0.09 = **0.28** |
| 정상 상태 산포 | a = 1일 때 Var = (g²σ_n² + σ_x²) / (g(2 − g)) | g = 1: σ_n² + σ_x². g = 0.5: σ_n²/3 + 1.33σ_x² — 측정 잡음이 크면 이득을 낮추고, 실행 잡음이 크면 높인다 |
| 백래시와 과보정 | g·a > 1이면 매 턴 부호가 바뀌어 반전마다 b(≈ 0.04 mm)를 잃음. **g·a < 1이면 한쪽에서 단조 접근 = 자연스러운 단방향 접근**(06번 원리) | 권장 출발점 g = 0.8~0.9 (단, g ≥ 0.28) |

- 2축(Y, T)은 e_{k+1} = (I − G·W·J) e_k 꼴이며, G·W·J의 고유값이 모두 (0, 2) 안이어야 한다. W(학습 투영)와 J(실제 반응)의 불일치가 클수록 축 사이 누설이 생긴다.
- **단계 전환 순환 위험**: joint가 \|T\| ≤ 0.09로 판단해 control로 넘겼는데 control이 "T가 움직였다"고 고르면 1차로 되돌아가고(팀 보고서 그림 7), 같은 판단이 반복되면 20턴을 다 쓸 수 있다.

**본 과제에서 할 일**

| 할 일 | 방법 | 성공 기준 |
|---|---|---|
| 감도 비 a·W·J 실측 | 실기에서 알려진 소이동(Y ±0.2 mm, T ±0.05) 각 5회 → 추정 변화/명령 변화 = a. 2×2 행렬 W·J의 고유값 산출(07번 L⁺ 직접 추정과 같은 절차) | 고유값이 [0.8, 1.2] 안이면 g = 1 유지, 밖이면 g = 1/고유값으로 보정 |
| 이득별 수렴 시뮬레이션 | 위 식에 실측 σ_n, σ_x, b, q = 0.05 mm를 넣고 g = 0.3~1.2(0.1 간격) × 시작 자세 격자(Y ±2 mm, T ±1, 혼합 포함) × 1,000회 몬테카를로 | 모든 시작 자세에서 20턴 내 도달률 ≥ 99 %, 중앙값 ≤ 3턴인 g 범위 확정 |
| 실기 폐루프 시험 | 시작 자세 최소 12개(사분면 4 × 크기 3, Y<0·T<0 포함) × 각 5회, 실제 이동·재촬영 | 60회 전부 20턴 이내, 최종 자세를 외부 기준기로 확인해 \|Y\| ≤ 0.09 mm |
| 전환 순환 방지 | 같은 단계 전환이 2회 반복되면 joint의 Y·T를 채택하는 규칙, 턴별 판단 기록 | 실기 시험에서 joint ↔ control 왕복 0회 또는 2회 이하 |
| (선택) Broyden·ILC | 턴마다 (명령, 관측 변화)로 W 갱신(07번), 같은 시작 자세 반복 시 잔차를 앞먹임(10번) | 평균 도달 턴 감소 확인 |

### 4.5 P5 — 검증 설계의 낙관 편향

- **원인**: 같은 1014 280장의 고정 4-fold로 223건 중 26건을 골랐다. 선택에 쓴 성적(280/280, 337/341)을 그대로 보고하면 낙관 편향이 있다. 279/280과 280/280의 1장 차이는 선택 기준의 분산 안일 수 있다. 같은 자세 반복 촬영이 없어 반복성·재현성을 분리할 수 없다.
- **문헌 근거**: Varma & Simon 2006(05) — 튜닝에 쓴 CV 오차는 크게 편향, 모든 선택 단계를 안쪽 루프에 넣는 nested CV로 해소. Cawley & Talbot 2010(08) — 선택 편향이 알고리즘 간 차이와 같은 크기. NIST e-Handbook(15) — 반복성·일간 재현성·런간 안정성의 3단계 중첩 설계. Kuric 2018(06)·ISO 9283 — 30사이클, 단방향.

**본 과제에서 할 일**

| 할 일 | 방법 | 성공 기준 |
|---|---|---|
| 모델 동결 + 새 홀드아웃 | control·joint의 모든 선택(점 집합, 영점 후보, 축소 계수 0.01 등)을 고정해 해시 기록. 이후 **새 촬영** 자료로만 최종 성적 보고: Y<0·T<0 포함 4사분면 혼합 자세 + T = ±2 | 새 자료에서 joint ≥ 95 %, control(단일축) ≥ 98 % 통과, 각 95 % 신뢰구간 함께 보고 |
| nested CV (기존 자료 내부 평가) | 바깥 4-fold × 안쪽 4-fold. 안쪽에서 선택 절차 전체 재실행 | 기존 고정 4-fold 성적과의 차이(낙관 편향 크기)를 수치로 보고 |
| 같은 자세 반복 촬영 (Gage R&R식) | 자세 5개(center, Y ±1 mm, T ±0.5) × 이동 없이 J = 10회 촬영 × K = 3세션(이동 후 복귀 포함) × L = 2일 | s₁(반복성)·s₂(세션 재현성)·s₃(일간) 분리. Y 추정의 총 σ ≤ 0.003 mm(아래 P6의 P/T 10 %) |
| 방법 비교 시 분산 보고 | 반복 CV(시드 10회)의 통과 수 평균 ± 표준편차 | 채택 판정에 "1장 차이"를 쓰지 않음 |

- 화소 기준으로 보면 우리 Y 허용오차 1.28 px는 11번(약 3.2 px)보다 엄격하고 12번(약 0.27 px)보다 느슨하다.
- **측정 능력 기준**(15번, AIAG*): P/T = 6σ_GRR / (USL − LSL) ≤ 10 %. 허용 구간 ±0.09(폭 0.18)이면 **σ_GRR ≤ 0.003 mm(Y 0.043 px)**, T는 σ ≤ 0.003 T(0.24 px). 점 잡음은 이를 만족하지만 세션 간 영점 0.6 px는 크게 넘는다 → P3 해결이 측정 능력의 전제.
