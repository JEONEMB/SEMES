# Y·Θ 오차 보정 문헌 조사 방법론 (계획)

- 작성일: 2026-10-30
- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 결과 문서: `00000_YT오차보정_조사_방법론_및_결과_.md` (이 계획대로 조사를 마친 뒤 작성)
- 근거 문서: 명세서 2차 본문, 3차 멘토링 보고서 v8(이하 "팀 보고서"), `../../01_주제_관련/유사연구/00000_유사연구_종합요약.md`

## 1. 목적

1. 추정한 Y·Θ(이하 T)에 남는 오차가 어디서 오는지 항목별로 나누고 크기를 합성하는 방법(오차 예산)의 근거를 찾는다.
2. 보정·재촬영을 반복하는 폐루프가 20턴 안에 허용오차로 수렴함을 보장하는 설계 근거(이득, 양자화, 백래시)를 찾는다.
3. 성능 숫자를 실제 정확도로 주장할 수 있도록 검증 실험의 설계 근거(외부 기준, 반복성·재현성, 낙관 편향 제거)를 찾는다.

QR 측정 정밀도(02 폴더)와 Y·T 분리 모델(03 폴더)은 다루지 않는다. 여기서는 "추정 이후" 남는 오차와 그 오차를 반복 보정으로 없애는 과정만 본다.

## 2. 이 주제에서 발생하는(할) 문제 정의

| P# | 문제 | 근거 (명세서·팀 보고서 수치) |
|:---:|---|---|
| P1 | **오차 예산이 없다.** 측정 잡음, 모델 오차, 영점 변동, 스테이지 분해능·반복정밀도, 열·진동 등 각 항의 크기를 합성한 표가 없어, 무엇을 줄여야 허용오차 안에 들어오는지 판단 근거가 없다. | 허용오차 0.09는 화면에서 Y 1.28 px, T 7.2 px(Y가 5.6배 엄격). 점 잡음 0.0124~0.0286 px, 영점 변동 −0.85~0 px가 따로따로만 보고됨 |
| P2 | **평가 정답이 명령값이다.** 파일명의 명령값을 정답으로 쓰므로 스테이지가 실제로 간 위치와의 차이(스테이지 자체 오차)가 알고리즘 오차에 섞인다. 외부 기준 측정이 없다. | 팀 보고서 3.1절 "평가 정답은 파일명의 명령값". 스테이지 제어 단위 0.05~2 mm(명세서), 반복정밀도는 미제공 |
| P3 | **영점 변동(백래시·히스테리시스)이 허용오차의 절반에 가깝다.** 같은 명령값이라도 촬영 묶음·접근 방향에 따라 판 위치가 다르다. 현재는 학습 절편으로 영점 후보 6개를 두어 맞췄을 뿐 원인 제어가 없다. | 영점이 묶음마다 −0.85~0 px, 같은 날 세션 간 약 0.6 px(Y 약 0.04 mm) — 허용오차 1.28 px의 약 47 % (팀 보고서 3.6절) |
| P4 | **반복 보정의 수렴이 보장되지 않는다.** 이득(보정값을 그대로 낼지 줄여 낼지), 과보정·진동, 제어 단위 0.05 mm의 양자화와 데드밴드, 단계 전환(joint→control) 중 오판 시 순환이 20턴 안 수렴에 미치는 영향이 분석되지 않았다. | 최대 20턴(팀 보고서 1장). 시나리오 6개 2턴 도달은 가장 가까운 영상 재사용 시뮬레이션(실제 로봇 아님). Y 0.05 mm = 0.71 px로 허용오차 1.28 px의 56 % |
| P5 | **검증 설계가 낙관적이다.** 같은 자료로 방법을 반복 선택한 개발 성적이고, 동일 자세 반복 촬영이 없어 반복성·재현성을 모른다. 위치 정확도 표준 절차(양방향·반복 측정)를 따르지 않았다. | 실험 223건 중 26건 채택, "같은 자료로 방법을 반복해 고른 개발 성적"(4장 서두). 혼합 자세는 한 사분면 57장뿐 |
| P6 | **허용오차의 근거와 단위가 문헌과 맞춰지지 않았다.** 0.09가 Y(mm)·T(단위값) 공통으로 쓰이며, 유사연구 정확도(Y ≤0.2 mm, 회전 ≤0.5°, 0.1~0.5 mm, 50 µm)와 비교할 단위 환산이 없다. | 허용오차 0.09(팀 보고서), T 감도 80.04 px/T(단위 미상). 유사연구 01·09·10·11번 및 TEL 특허 수치 |

## 3. 조사 질문

| P# | 무엇을 알아야 해결되는가 |
|:---:|---|
| P1 | 불확도 성분을 A형(반복 측정)·B형(사양·문헌)으로 나누고 감도계수로 합성하는 표준 절차(GUM)는 무엇인가? 비전 측정·정렬 시스템에서 오차 예산을 세운 사례는? |
| P2 | 명령 위치와 실제 위치의 차이를 어떤 외부 기준(레이저 간섭계, 다이얼 게이지, 기준 영상)으로 재는가? 위치 정확도 시험 표준(ISO 230-2, ISO 9283)은 무엇을 요구하는가? |
| P3 | 백래시·히스테리시스는 어떻게 측정하고(양방향 접근 차이), 어떻게 없애는가(단방향 접근, 보상 테이블, 모델 기반 보상)? |
| P4 | look-and-move 반복 보정의 수렴 조건(이득·자코비안 추정 오차 허용 범위)은? 양자화된 구동기로 반복 보정할 때 한계 주기·데드밴드는 어떻게 생기는가? ILC 관점의 수렴 조건은? |
| P5 | 같은 자료로 모델을 고르고 평가하면 성능이 얼마나 낙관적으로 나오는가(nested CV)? 측정 시스템의 반복성·재현성(Gage R&R)은 어떻게 설계·판정하는가? |
| P6 | 유사 분야(웨이퍼·패널 정렬, 정렬 스테이지)의 정렬 정확도 수치와 그 단위는? 측정 시스템이 허용오차 대비 얼마나 작아야 하는가(측정 능력 비율)? |
