# Chaumette & Hutchinson 2007 — 시각 서보 제어 Part II: 고급 방법 (IEEE RAM)

- 원제: Visual servo control, Part II: Advanced approaches
- 원문: `Chaumette2007_VisualServoControl_PartII.pdf` (INRIA Lagadic 저자 공개본)
- 저자: François Chaumette, Seth Hutchinson
- 핵심 (원문 확인)
  - **상호작용 행렬의 수치 직접 추정**: 알려진 카메라(로봇) 이동 Δv와 특징 변화 Δs의 쌍 N개를 모아 최소제곱으로 L̂_s = B A⁺ 를 구한다. 의사역행렬을 직접 추정(L̂_s⁺ = A B⁺)하는 편이 **실제로 더 잘 동작**한다고 보고.
  - 온라인 반복 추정: **Broyden 갱신** L̂(t+1) = L̂(t) + α (Δx − L̂Δv)Δvᵀ / (ΔvᵀΔv). α는 갱신 속도.
  - 장점은 모델링·보정 단계를 모두 피하는 것, **단점은 이론적 안정성·강건성 분석을 할 수 없다는 것**.
  - 이 밖에 하이브리드·분할 제어, 목표 궤적 계획 등.
- 정량 수치: 없음(튜토리얼)
- 우리와의 관계: ○ **P4** 팀의 GLS 투영 W(관측 → Y·T)는 "L⁺를 오프라인 학습으로 직접 추정"한 것에 해당한다. 문헌은 이 경우 안정성 보장이 없다고 하므로, 우리가 **실측으로 수렴을 확인**해야 하는 근거다. 실제 로봇에서 매 턴의 (보정 명령, 관측 변화) 쌍으로 Broyden 갱신을 하면 감도 오차를 턴마다 줄일 수 있다(선택 과제).

## 상세 요약 (번역본 기반)

### 1. 배경 및 문제 정의
- 시각 서보 Part II로, 고전적 IBVS/PBVS의 한계를 극복하는 고급 시각 서보 기법(하이브리드 2.5D 비주얼 서보, 특이점 회피, 관절 한계 극복, 가시성 제약 조건 최적화)을 체계화.

### 2. 핵심 이론 및 수식
- **2차 작업 제약 프로젝션 (Redundancy Formalism)**:
  $$\mathbf{v} = -\lambda \mathbf{J}_1^+ \mathbf{e}_1 + (\mathbf{I} - \mathbf{J}_1^+ \mathbf{J}_1) \mathbf{e}_2$$
  - $\mathbf{e}_1$: 메인 비전 티칭 오차 벡터.
  - $(\mathbf{I} - \mathbf{J}_1^+ \mathbf{J}_1)$: 자코비안의 영공간(Null Space) 투영기.
  - $\mathbf{e}_2$: 마커 가시성(Field-of-View) 유지 또는 관절 백래시 회피 2차 목적함수의 구배.

### 3. 실험 및 주요 결과
- 큰 회전 오차($180^\circ$) 조건에서도 로봇 카메라가 마커를 시야 중심에 안정적으로 유지하면서 최단 시간 내에 수렴하는 하이브리드 제어 성능 입증.

### 4. SEMES 과제 시사점
- 웨이퍼 이송 로봇의 잉여 자유도를 활용하여, 비전 티칭 메인 작업을 수행하는 동시에 영공간(Null Space) 제어를 통해 엔드이펙터가 장애물이나 카메라 시야 한계(FOV limit)를 벗어나지 않도록 보조 제어 가능.
