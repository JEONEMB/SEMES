## 1. 무엇을 보정하고 무엇으로 증명하는가

분리 후 잔여오차는 **영상 측정 오차**, **추정/교정 오차**, **실제 구동 오차**, **판정·평가 오차**로 나눈다. 낮은 추정 오차만으로 실제 티칭 정밀도를 주장할 수 없다. 실제 이동 뒤 재촬영·독립 위치 측정이 필요하며 반복성·재현성·정확도도 별도로 보고한다.

문헌은 백래시·온도·학습 편향 등 가능한 오차와 검증 틀을 제시한다. 이번 분석이 우리 장비의 백래시량, 확장불확도, 폐루프 성공률을 새로 측정한 것은 아니다.

## 3. 오차 예산 작성 방법

열벡터 관측 오차의 공분산을 Σs, 관측→축 선형 변환을 W로 정의하면 1차 근사에서 Σq=WΣsWᵀ다. 실제 특징에 비선형 항이나 선택 분기가 있으면 해당 국소 야코비안·분기 불확실성 또는 검증된 시뮬레이션을 사용한다.

| 성분 | 구할 자료 | 구분할 것 | 현재 처리 |
|---|---|---|---|
| 정지 반복 잡음 | 같은 자세·같은 세션의 반복 영상 | 점 간 상관·공통 영상 흔들림 | 미실측 성분은 기호/범위로 남김 |
| 광학·보간 편향 | 위상·노출·초점 시험 | 무작위 산포와 계통 편향 | 편향 보정 전후를 별도 기록 |
| 교정 파라미터 | 교정 반복·신규 자세 | K·축·척도·인쇄 오프셋 | 훈련 잔차와 일반화 잔차 분리 |
| 기구 양자화 | 실제 명령/실행 변위 | 명령 간격·위치 분해능·오차 분포 | 명령 단위를 곧바로 균등 오차로 확정 금지 |
| 접근 이력 | 정·역·다방향 재접근 | 백래시·비틀림·정지 시간 | 방향 효과 확인 후 상태 보상 검토 |
| 온도·시간·재설치 | 날짜·온도·세션 교차 | 드리프트·영점 변화·측정 기준 변동 | 재현성·안정성으로 분리 |
| 외부 기준 | 기준기 교정·분해능·설치 | 기준기 자체 불확도·기준 좌표 | 비교 측정 예산에 포함 |

GUM의 합성은 알려진 감도와 공분산·분포 가정 아래 수행한다. 기존 U=0.045 mm는 일부 입력 가정의 예시 계산으로 남기며 현 장비 검증값으로 쓰지 않는다. 분포가 정규에 가깝고 자유도가 충분한 등의 조건 없이 k=2를 정확한 95%로 표현하지 않는다.

## 4. 폐루프 수렴 조건의 올바른 범위

q를 실제 목표 대비 축 오차, J를 국소 영상 감도, W를 특징→축 추정, G를 보정 이득으로 두고 지연·포화·이력을 무시하면 다음 국소 근사를 얻는다.

\[
q_{k+1}\approx (I-GWJ)q_k + \eta_k
\]

이 선형 이산계의 안정 조건은 **ρ(I−GWJ)<1**이다. GWJ의 고유값이 모두 실수일 때에만 각 고유값이 (0,2)에 있다는 표현으로 단순화할 수 있다. 잡음·백래시·양자화·단계 전환을 추가하면 별도 분석과 실측이 필요하다.

작은 이득이 단일 축 이상계에서 오버슈트를 줄일 수는 있지만, g=0.8~0.9라고 항상 단방향 접근하거나 20턴 도달이 보장되지는 않는다. 이전 이득 범위는 고정 운영값으로 전용하지 않는다. 감도 오차·부호·최대 이동·실행 지연을 확인한 대조 실험으로 판단한다.

## 5. 검증을 네 층으로 분리한다

| 층 | 질문 | 필요한 자료 | 보고할 결과 |
|---|---|---|---|
| A 정지 사진 | 현재 영상에서 Y/T를 얼마나 잘 추정하는가 | 모델 고정 후 신규 혼합·단일축 촬영 | 축별 평균/최대오차·동시 통과·실패 |
| B 측정계 | 같은 물리 자세에서 얼마나 흔들리는가 | 정지 반복·세션·날짜·재설치 | 반복성·재현성·안정성·편향 |
| C 실기 복귀 | 이동·재촬영으로 실제 목표에 도달하는가 | 시작 자세·명령·전후 영상·실행 시간 | 실제 최종 잔여오차·턴·총시간·복구 |
| D 기준 정확도 | 최종 위치가 독립 물리 기준과 맞는가 | 외부 기준기·좌표 정합·기준기 예산 | 절대 위치/각도 오차와 불확도 |

정지 사진 조합·가정 시뮬레이션은 C층 실기 성적을 대신하지 않는다. 같은 영상의 알고리즘 출력끼리 비교한 일치는 D층 검증이 아니다.

## 6. 표준·통계 판정 사용의 주의점

Kuric은 ISO 9283을 적용한 연구다. 30회만 수행했다고 표준 전체 적합으로 선언하지 않는다. 실제 2축 장비에 적용할 항목·방향·하중·속도·측정계를 확인한다.

NIST의 Gauge R&R 자료는 반복성·재현성·안정성·히스테리시스·드리프트를 나누는 근거다. 자동 측정에는 작업자 대신 날짜·재설치·촬영 세션 등 의미 있는 요인을 설계한다. %GRR와 P/T의 분모를 구분하고, %GRR<10%·ndc≥5는 해당 원전·합의 조건 확인 없이 NIST 의무 기준으로 쓰지 않는다.

모델 선택은 특징·영점 후보·전처리·정규화·임계값을 포함한다. 이를 고른 CV 점수를 최종 독립 성능으로 쓰지 않는다. 같은 자세의 반복 사진은 같은 분할에 묶고, 최종 시험은 모델을 고정한 후 확보한다.

## 7. 적용 순서와 판정

1. H12/H13/H14를 구분할 반복 설계로 영점 원인을 먼저 확인한다.
2. 실제 구동과 독립 기준의 차이를 측정해 명령 오차를 예산에 넣는다.
3. H17의 진동·불신 관측·단계 전환을 포함한 실제 복귀 시험을 한다.
4. H18의 독립 촬영에서 선택 편향을 분리한다.
5. 반복 원인이 확인된 경우에 방향 보상·ILC·온라인 갱신을 비교한다.

현재 실행·반환·오류 처리 계약은 [공통 규칙](../../../../ALGORITHM_RULES.md)과 실제 API를 따른다. 보고서 작성으로 새 이득·오차 한계·알고리즘을 채택하지 않는다.
