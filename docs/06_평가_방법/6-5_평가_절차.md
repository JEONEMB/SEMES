# 6-5. 평가 절차

처음 실행하는 담당자는 [02 사용법](../02_사용법.md)을 순서대로 따른다.

## 1. 사진 준비

같은 날, 같은 촬영 조건의 사진을 center와 photos로 나눈다. center는 평가 좌표의 Y 0, T 0에서 촬영한 사진이다. 이름만 center인 사진이 실제 원점임을 프로그램이 확인해 주지는 않는다. 여러 장이면 동일한 정지 자세를 사용한다.

사진은 3840x2160이며 BMP, PNG를 지원한다. API에 직접 넘기는 영상은 8비트 회색, BGR, BGRA다. PNG 예시는 원본 픽셀을 보존해 변환했다.

정답은 파일명 또는 정답표에서 읽는다. Y-0.05.png는 Y -0.05, T 0이고 Y+0.05 T+0.01 (1).png는 Y 0.05, T 0.01이다. 정답을 읽지 못한 파일과 center로 사용하는 사진은 채점에서 제외될 수 있으므로 시작 전 사진 수를 확인한다.

## 2. 예시로 실행

패키지 루트에서 입력한다.

```powershell
.\build\Release\score_photos.exe
```

1. 기준 사진 선택에서 폴더 선택을 고르고 data/examples/20261014/center를 선택한다.
2. 평가 사진 선택에서 같은 날짜의 photos를 선택한다. center를 골랐다면 다음 창은 같은 날짜의 photos에서 열린다.
3. 정답 출처는 파일명을 선택한다.
4. center 1장, 평가 6장인지 확인하고 콘솔 안내에 따라 시작한다.
5. 결과 경로를 확인한다. 다른 날짜는 다시 실행해 해당 날짜의 center와 photos를 선택한다.

여러 파일이나 폴더를 선택할 수 있지만 촬영 날짜와 조건은 같아야 한다. 경로에서 날짜를 알아내지 못하는 경우도 있으므로 담당자가 확인한다. 취소하면 평가를 시작하지 않는다.

결과는 data/results/eval/<날짜_시각>/에 저장된다. 대화식 실행은 입력을 inputs/center와 inputs/photos에 복사하고 inputs.txt에 원래 위치를 남긴다. 원본은 이동하지 않는다.

## 3. 경로를 직접 입력

```powershell
.\build\Release\score_photos.exe data/examples/20261014/photos auto --zero data/examples/20261014/center
```

폴더 이름은 center지만 기존 옵션은 --zero다. auto는 새 결과 폴더를 만든다. 명령행 방식은 원본을 직접 읽으며 대화식 입력 복사와 날짜 선택 검사까지 수행하지는 않는다.

| 옵션 | 의미 |
|---|---|
| --zero | center 파일 또는 폴더. 생략하면 평가 폴더의 명령 (0, 0) 사진을 찾고, 없으면 영점 없는 진단 평가 |
| --data | 모델 폴더. 기본 data/model |
| --answers | 파일명 대신 사용할 정답표 |
| --tolerance-y, --tolerance-t | 설정 기준 허용오차. 고정 두 기준 비교도 함께 출력 |

지정한 center를 읽지 못하거나 영점 설정이 실패하면 평가를 중단한다. 정답표의 열 사이는 탭이다.

```text
file	y_mm	t_deg
IMG_0001.bmp	0.05	0.01
IMG_0002.bmp	-1.00	0
```

## 4. 결과 확인

| 파일 | 내용 |
|---|---|
| summary.txt | 두 기준 통과율, 설정 기준 결과, 상태별 개수, 시간 |
| results.csv | 사진별 정답, 측정, 오차, 판정, 여유, 경고와 실제 오차, 로그 경로 |
| logs/ | 단계별 수치, 경고, 실패, 후속 단계 미실행 기록 |

두 기준은 Y +/-0.045 mm와 +/-0.09 mm이며 T는 모두 +/-0.01도다. 실패는 평가 불가이며 전체 통과율 분모에는 포함한다. 여유는 허용오차에서 오차 절댓값을 뺀 값이다. 음수면 그만큼 초과다.

CSV의 경고와 실제 오차에서 '경고 없음 / OUT (미검출)'을 먼저 확인한다. 경고는 실제 오차의 예측값이 아니다. IN이어도 자동 이동 여부는 correction_allowed와 장비 조건을 별도로 확인한다.

측정 시간은 측정 함수와 메모리 내 상세 로그 작성 시간이다. 사진 읽기와 로그 파일 저장 시간은 제외되므로 전체 경과 시간과 다르다. 읽기 시간은 상세 로그에 있다.

CSV의 영점 없는 값은 측정값에 영점을 다시 더한 비교값이다. 영점을 초기화해서 검출과 경고를 따로 실행한 결과가 아니다. 오차가 치우쳤으면 center 실제 자세, 정답 좌표, 모델과 촬영 조건을 함께 확인한다. 평균만으로 영점 문제라고 확정하지 않는다.
