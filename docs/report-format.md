## 디자인

- 흰색과 연회색 바탕, 진한 회색 본문, 파랑 `#0071e3` 한 가지 강조색. 신호등 색·그라데이션을 쓰지 않는다.
- 최대 본문 폭1080px. 첫 제목은24~32px의 담백한 보고서명으로 왼쪽 정렬하고 상단 여백은28~40px로 제한한다. 모바일에서는 크기와 간격을 줄인다.
- 상단 고정 목차와 짧은 보고서명 뒤에 핵심 지표·본문을 바로 둔다. 중앙 정렬의 대형 질문형 제목, 영문 장식 문구, 소개 문단, 기술 스택 메타 나열은 첫 화면에서 생략한다. 표만 길게 나열하지 않는다.
- 설명과 근거 그래프를 나란히 배치하고, 작은 화면에서는 위아래로 읽힌다. 세부 수치 표는 가로 스크롤을 허용한다.
- 비교 그래프는0부터 시작하고 각 지표의 분모·단위·좋은 방향을 명시한다. 축/색 변경으로 개선을 과장하지 않는다.
- 모션은 짧고 기능적으로 사용하며 `prefers-reduced-motion`을 지원한다. 키보드 포커스·버튼 상태·인쇄용 스타일을 제공한다.

## 내용 순서

1. 짧은 보고서명과 핵심 지표: 왼쪽 정렬로 시작하고 결과가 바로 보이게 한다.
2. 조건별 비교: 동일 분할·데이터에서의 평균/최대·통과 수를 함께 보여준다.
3. 오차 분포: 중앙값/p95·대표 실패·개선/악화 수로 평균의 맹점을 설명한다.
4. 처리 시간: 초기화/사진별 계산/디코딩 포함을 구분하고 환경·반복 수를 표시한다.
5. 판단: 무엇을 유지하고 무엇을 후속 후보로 볼지, 근거와 함께 쓴다.
6. 평가 근거: 데이터·학습/시험 분리·보존·검증 범위와 원자료 링크를 둔다.

모든 제목은 수치가 뒷받침하는 주장으로 쓴다. 개발용 교차검증·재대입·독립 시험·실제 로봇 제어를 구분한다. 자료가 없는 부분은 빈 성과로 채우지 않는다. 평가와 모델의 변경 여부는 보고서 디자인 변경과 구분한다.

## 재사용 파일

기준 보고서 폴더의 `report_assets/style.css`는 디자인 토큰과 반응형 배치, `data.js`는 표시용 데이터, `report.js`는 지표 선택 그래프를 담당한다. 새 보고서에서는 이 세 파일과 HTML의 섹션 구조를 새 실험 폴더에 복사하고 내용·데이터를 바꾼다. 저장소 밖 참고 경로를 실행 의존성으로 연결하지 않는다. CSS는 카드·표의 순번 대신 의미에 맞는 클래스로 확장한다.

HTML과 표시 데이터에 실제 평가 결과를 대조한다. 모바일·데스크톱 배치, 지표 전환, 원자료 링크를 확인한다. 원본 결과 파일은 유지하고 디자인 수정 전 HTML도 보관한다. 그래프를 못 쓰는 환경에서도 표로 내용을 읽을 수 있게 한다.
