# 나사 위치 품질 경고 처리 (2026-11-17)

위치 탐색, 밝기 맞춤, 테두리 맞춤 계산이 완료된 나사는 모양 또는 맞춤 차이 기준을 넘어도 계산된 위치를 유지한다. W_SCREW_UNSTABLE과 "나사 위치 추정이 불안정합니다"를 반환하고 Y/T 계산을 계속한다. 이 경고만으로 Failed가 되거나 측정값이 NaN으로 바뀌지 않는다.

모양 유사도와 맞춤 차이는 정확도 확률이 아니다. 기존 기준값 0.93과 0.5px는 경고 기준으로 유지한다. SEMES의 둘레 영역 계산도 유지하며, 테두리와의 차이 초과는 경고로 처리한다.

위치 탐색, 밝기 맞춤 또는 테두리 맞춤이 완료되지 않은 나사는 제외한다. 테두리 맞춤까지 성공하고 둘레 영역 맞춤만 실패한 경우는 아래 대체 규칙을 적용한다. QR 미검출, 계산식 누락, 수치 오류와 명시적인 불일치 실패 설정은 이번 변경 대상이 아니다. 모델과 계수는 변경하지 않는다.

## 영역 맞춤 실패 시 대체

1. 4단계 영역 맞춤에 성공하면 기존 area_dx를 그대로 사용한다.
2. 영역 맞춤만 실패하면 area_dx = dx로 대체한다. 나사를 제외하지 않고 기존 9개 입력 계산식으로 Y, T를 계속 계산한다.
3. W_SCREW_UNSTABLE로 "나사 위치 추정이 불안정합니다 (영역 맞춤 미완료, 3단계 값으로 대체)"를 표시한다. 이 경고만으로 측정이나 보정을 차단하지 않는다.
4. 영점에서도 동일한 대체 규칙을 사용한다. 별도 계산식이나 별도 영점을 추가하지 않는다.

tools/tests/area_fallback.cpp는 나사 중심 93x93을 남기고 주변 고리를 검게 만든다. 수정 전 코드에서 실제 OpenCV 영역 정합이 실패하는 조건이며, 수정 후에는 대체 여부, area_dx와 dx의 일치, 정상 나사의 영역 값 유지, 최종 Y/T와 보정 허용, 영점 설정, 완전 가림 검출 실패를 검사한다. 물리 장비에서 촬영한 고장 사진이 아니라 실제 사진에 손상을 합성한 재현 시험이다.

## 검증 결과

영역 실패 회귀 검사 29개가 통과했고 safety_contract, runtime_contract, screw_quality, area_fallback 전체가 통과했다. 합성 실패 입력은 Y -0.000064126 mm, T 0.00000967509도를 반환했으며 나사 1234와 보정 허용을 유지했다. 제출용 이전 API 패키지도 별도로 빌드하고 3개 테스트 전체를 통과했다.

기존 장비 사진 719장을 수정 후 재실행하여 측정 실패 0건, 수정 전 정상 측정 Y/T와 사용 나사 조합의 변경 0건을 확인했다. 정상 영역 값은 그대로 사용한다. 학습 사진을 포함한 앞선 비교에서 기존 4단계와 3단계 값 대체는 각각 650/652장이 허용 오차를 만족했다. 이 점수는 회차별 5장 출력 영점 보정 조건의 재평가이며 실제 실패 영상에서의 정확도 보장은 아니다.
