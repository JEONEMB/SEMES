# 02. 사용법

빌드해서 확인하고, 장비 쪽 프로그램에서 호출하는 방법이다. 이 문서만 따라 하면 쓸 수 있다.

## 1. 빌드와 확인

```
cmake -S . -B build -DOpenCV_DIR=<OpenCV 폴더>
cmake --build build --config Release
```

예제 사진 5장으로 값이 맞는지 본다 (패키지 맨 위 폴더에서 실행).

```
build/Release/check_photos data/model data/sample/list.tsv out.tsv data/sample/expected.tsv
```

아래처럼 나오면 맞다.

```
기대값과 비교 5장: Y 차이 최대 0.00000000 mm, T 차이 최대 0.00000000 도
```

사진 한 장의 단계별 값을 보려면:

```
build/Release/measure_one data/model data/sample/sample_1.png
```

환경은 C++17, OpenCV 3.4.15 다. 다른 환경으로 옮길 때는 [08 포팅 안내서](08_포팅_안내서.md)를 본다.

## 2. 호출 순서

```cpp
#include "alignment.hpp"

alignment::initialize("data/model");                           // 1. 프로그램을 시작할 때 한 번
alignment::set_zero_from_photos(zero_photos);                  // 2. 매일, 장비를 조정한 뒤 (3절)
alignment::Result r = alignment::measure_alignment(photo);     // 3. 사진마다
// r.y_mm, r.t_deg   → 보정 이동은 (−r.y_mm, −r.t_deg)
// r.status, r.code, r.message → 4절
```

| 함수 | 하는 일 | 호출 시점 |
|---|---|---|
| `initialize(data_folder, settings_file)` | 기준 사진, 위치, 계수, 점검식을 읽는다 | 시작할 때 한 번 |
| `set_zero_from_photos(명령 0 사진들)` | 그날의 0 을 맞춘다 | 매일 (3절) |
| `measure_alignment(photo)` | 사진 한 장의 Y, T 를 잰다 | 사진마다 |
| `read_photo(path)` | 사진 파일을 회색으로 읽는다 (한글이 든 경로도 읽힌다) | 파일에서 사진을 읽을 때 |

- 입력 사진은 3840×2160, 8비트다. 회색 또는 컬러(BGR, BGRA)를 받는다. 컬러 순서를 주의해야 하는 이유는 [08 포팅 안내서](08_포팅_안내서.md) 2-1 에 있다.
- 어떤 함수도 예외를 던지지 않는다. 결과의 `status` 로 판단한다.
- 함수와 구조체 전체는 `include/alignment.hpp` 에 있다.

## 3. 영점 설정

**필수 조건: 매일 로봇을 명령 0 (Y 0, T 0) 으로 보내 찍은 사진 5 ~ 10장으로 영점을 잡는다.**

```cpp
std::vector<cv::Mat> zero_photos = { 사진1, 사진2, 사진3, 사진4, 사진5 };   // 명령 0 에서 찍은 사진
alignment::Result zero = alignment::set_zero_from_photos(zero_photos);
if (zero.status == alignment::Status::Failed) { /* 멈추고 사진을 확인한다 */ }
```

### 3-1. 영점을 매일 잡는 이유

| 이유 | 내용 |
|---|---|
| 로봇의 "명령 0" 자리가 날마다 다르다 | 받은 사진에서 Y 로 0.04 ~ 0.13 mm 차이가 났다. 허용오차(0.045 mm)보다 크다. 영점을 잡지 않으면 이 차이가 그대로 오차가 된다 |
| 카메라가 조금만 움직여도 값이 치우친다 | 카메라가 0.05도만 돌아도 Y 가 0.27 mm 틀어진다. 영점을 다시 잡으면 없어진다 |

| 처음 보는 날의 통과율 | |
|---|---|
| 영점을 잡지 않으면 | 31.6% |
| 그날 사진 5장으로 영점을 잡으면 | 95.5% |

### 3-2. 관련 함수

| 함수 | 하는 일 | 호출 시점 |
|---|---|---|
| `set_zero_from_photos(명령 0 사진들)` | 그 사진의 자세를 (0, 0) 으로 삼는다. 여러 장이면 평균을 쓴다 | 매일. 카메라, 조명, 판을 조정한 뒤에는 반드시 |
| `set_zero_value(y, t)` | 적어 둔 영점을 다시 넣는다 | 프로그램을 다시 켰을 때 (영점은 메모리에만 있다) |
| `clear_zero()` | 처음 영점으로 되돌린다 | 필요할 때 |
| `set_reference_from_photos(센터 사진들)` | QR 과 나사 위치를 다시 찾는다 | 화면이 많이 밀려 QR, 나사를 못 찾을 때만 |

### 3-3. 주의 사항

- 명령값을 모르는 "센터 사진"으로 영점을 잡으면 안 된다. 그 사진이 그날 명령 0 과 다른 만큼 값이 치우친다.
- 영점이 무엇인지, 사진 수에 따른 차이, 명령 0 이 아닌 자세로 잡는 방법은 [5-0 준비와 영점](05_구현_방법/5-0_준비와_영점.md)에 있다.

## 4. 측정 결과 처리

| 상태 | 뜻 | 측정값 | 로봇 |
|---|---|---|---|
| 정상 (`Ok`) | 그대로 믿어도 된다 | 나옴 | (−`y_mm`, −`t_deg`) 만큼 보정한다 |
| 경고 (`Warning`) | 값은 나오지만 정확도가 떨어질 수 있다 | 나옴 | `message` 의 안내대로 옮기고 다시 잰다 |
| 실패 (`Failed`) | 잴 수 없거나 쓰면 안 된다 | 쓰지 않는다 | 멈춘다 |

경고와 실패의 코드마다 조건, 위험, 조치는 [03 상태와 알림](03_상태와_알림.md)에 모두 있다.

## 5. 설정과 기본값

설정 파일 없이 `initialize("data/model")` 만 불러도 기본값으로 동작한다. 바꾸려면 `initialize("data/model", "config/settings.json")` 으로 설정 파일을 지정한다.

| 항목 | 기본값 | 바꾸는 곳 |
|---|---|---|
| 쓸 나사 | 4개 모두 | `config/settings.json` 의 `screws` |
| 값이 서로 안 맞을 때 | 경고만 | `fail_on_disagreement` |
| 알림 출력 | 콘솔(stderr) | `log_file` |
| QR 탐색 범위 | 사진 전체 폭의 QR 띠 (QR 상자 세로 범위 ±40 px). QR 3개가 아니면 실패 | (자동) |
| 영점 | 학습한 모든 촬영의 공통 0 | `set_zero_from_photos` (3절) |

장비에는 `data/model/` 폴더만 같이 보내면 된다. 경로에 한글이 있으면 Windows 에서 설정, 위치 파일을 읽지 못할 수 있으니 영문 경로에 둔다.
