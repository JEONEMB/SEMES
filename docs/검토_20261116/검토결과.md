# 알고리즘 설명 대조 검토 (2026-11-16)

## 확인 범위

include, src, tools의 현재 구현과 README, 사용법, 구현 설명, 평가 설명, 포팅 안내를 대조했다. docs2는 요청에 따라 커밋 대상에서 제외한다. 과거 실험의 모든 원본 사진과 외부 장비 동작까지 재현한 검토는 아니다.

## 수정한 주요 설명

| 항목 | 확인한 현재 동작 |
|---|---|
| 초기화 실패 | 기존 준비 상태와 영점을 무효화한다. 이전 모델로 운영 측정을 이어가지 않는다 |
| 영점 실패와 기준 재등록 | 운영용 영점 무효화. 기준 좌표를 carry_over로 연결해도 영점 재설정 필요 |
| 영점 없는 측정 | measure_alignment는 E_ZERO_REQUIRED. measure_diagnostic은 진단만 허용 |
| 숫자 영점과 초기화 | set_zero_value와 clear_zero는 값 일치 점검의 기준 어긋남도 삭제 |
| 실패 값 | Y, T는 NaN. status, action, correction_allowed와 전체 notices 확인 |
| 정상 상태 | 구현된 점검을 통과했다는 뜻이며 실제 오차의 보장은 아님 |
| 대표 알림 | Stop, Recapture, Review, Correct 순의 우선순위. 같은 순위는 먼저 추가된 코드 |
| QR | 후보 3개, 간격, 정밀 맞춤 검사. 모든 오검출을 배제한다는 증명은 아님 |
| 나사 | 위치 탐색, 밝기 맞춤, 테두리 맞춤, 모양 점검. 부분 가림 의심 시 전체 실패 |
| 범위 검사 | raw + carry_over로 검사하며 zero를 빼기 전이다 |
| 시간 | 측정 함수와 메모리 내 로그 작성. 사진 읽기와 파일 저장은 제외 |
| 내부 정확도 | 섞음과 마지막 확인 등은 전처리 학습 라벨로 채점. 원래 명령값 평가와 구분 |
| 영점 성능 | 근처 자세의 (예측 - 명령) 평균 실험은 center 화소 평균 API와 다름 |
| 독립 평가 | 회차별 전처리를 각 학습 묶음 안에서 다시 하지 않으므로 전체 과정의 독립 검증이라고 주장할 수 없음 |

5-0의 영점 삭제 후 운영 측정을 호출하던 예제를 진단 측정으로 수정하고 실패 시 중단하도록 바꿨다. 값 일치 기대식의 잘못된 쉼표를 곱셈으로 복구했다. 오래된 평가 절차를 center 선택, photos 선택, 정답 출처, 결과 파일 순서로 수정했다.

## 정확도 재실행

현재 저장된 표와 evaluate_accuracy를 사용했다. [accuracy_report.txt](accuracy_report.txt)와 [입력 SHA-256](inputs_sha256.txt)을 보관한다. 마지막 확인 결과는 129/130, 99.2%다. 기존 131/131, 100% 설명을 현재 결과에서 제외했다. 상세 조건은 [6-1 정확도](../06_평가_방법/6-1_정확도.md)를 따른다.

이 검토에서 Y/T 학습 계수나 허용오차를 결과에 맞춰 조정하지 않았다. 예시의 성적은 선택된 성공 사례의 실행 확인이며 전체 성능으로 제시하지 않는다.

## 과거 시각 자료 처리

부록 B PDF 2개와 HTML, canvas에는 현재 코드와 다른 영점, 실패 처리 설명이 남아 있었다. 기존 그림을 보존하되 과거 자료임을 명시하고 현재 규칙을 앞에 추가했다. PDF는 정정 안내 페이지와 모든 페이지의 안내 띠를 추가했으며 새 페이지와 대표 기존 페이지를 렌더링해 확인했다. 전체 그림을 최신 구현으로 재작성한 것은 아니다.

부록 A의 합성 시험 이미지와 09 추가 논의의 표는 과거 시험 기록이다. 현장 전체 오차 검출 보장이나 현재 모델의 실행 정확도로 인용하면 안 된다. docs2의 PPT는 이전 설명을 포함한 초안이며 이번 커밋에 포함하지 않는다. 모든 이미지의 내부 글자와 모든 PPT 슬라이드의 배치를 육안으로 검수했다고 주장하지 않는다.

## 남은 검증 한계

파일 선택 창의 클릭 흐름은 이번 자동 검증에서 직접 재현하지 못했다. 명령행 입력으로 같은 예시의 측정과 저장을 검증한다. 실제 장비 보정 동작, 로봇 명령 단위, 센터의 물리적 원점 여부, 외부 계측기 기준 정확도는 현장 확인이 필요하다. 정상 결과만으로 실제 오차가 작다고 결론내리지 않는다.
