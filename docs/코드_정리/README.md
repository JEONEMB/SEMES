# 코드 정리 (흐름 그림)

사진 한 장이 들어와서 Y, T 와 상태가 나올 때까지를 한 장의 그림으로 그렸다. 카드마다 그 일을 하는 파일, 함수, 조정 상수를 적었다.

| 파일 | 여는 법 |
|---|---|
| [코드_정리.pdf](코드_정리.pdf) | 한 쪽짜리 큰 그림이다. PDF 보기 프로그램에서 확대해서 본다. 글자를 검색할 수 있다 (함수 이름, 코드 이름) |
| [코드_정리.canvas](코드_정리.canvas) | Obsidian 에서 이 폴더(`docs/코드_정리`)를 보관소로 열면 카드를 옮기고 고칠 수 있다. 사진은 `images/` 에 있다 |

## 그림의 구성

| 묶음 | 내용 |
|---|---|
| 입력과 미리 준비 | 사진 한 장, 모델 파일 읽기(`initialize`), 그날 영점(`set_zero_from_photos`), 영점을 직접 다루기, 기준 다시 잡기 |
| 처리 | `measure_alignment`: 사진 검사 → 1단계 QR → 2단계 나사 → 3단계 Y, T 계산 → 4단계 결과 점검 → 알림 붙이기 |
| 출력 | `Result`, 상태마다 할 일, 경고와 실패 사례 사진 |
| 도구 | `tools/` 의 학습, 평가, 써 보기와 확인, 합성 화면 시험, 같이 쓰는 코드 |

## 색과 화살표

| 색 | 뜻 |
|---|---|
| 초록 | 하는 일 (계산, 실행 단계) |
| 노랑 | 갈림길 (예 / 아니오) |
| 파랑 | 자료 (넣는 것, 그 단계에서 나온 결과) |
| 주황 | 경고 (값은 나오고 계속 진행) |
| 빨강 | 실패 (값 없음, 멈춤) |
| 보라 | 측정 함수와 출력 |
| 회색 | 참고 |

- 처리 묶음에서 **초록 화살표만 따라가면** 정상(Ok)으로 끝나는 길이다.
- 카드의 **파일**, **함수** 줄에서 화살표(→)는 "앞 함수가 뒤 함수를 부른다"는 뜻이다.
- 카드의 **조정 상수** 줄은 그 단계에서 바꿀 수 있는 값의 이름과 지금 값이다.
