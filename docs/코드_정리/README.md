# 코드 정리 (흐름 그림)

사진 한 장이 들어와서 Y, T 와 상태가 나올 때까지를 그림으로 그렸다. 카드마다 그 일을 하는 파일, 함수, 조정 상수를 적었다.

## 두 가지 그림

| 그림 | 담은 것 | 누가 보나 |
|---|---|---|
| **model** | 측정 코드(`include/`, `src/`)만. 입력과 미리 준비 → 처리(1 ~ 4단계) → 출력 | 알고리즘을 읽거나 다른 곳으로 옮길 때 |
| **tool포함** | 위 그림에 `tools/` 를 더한 것. 학습, 평가, 써 보기와 확인, 합성 화면 시험, 같이 쓰는 코드 | 계수를 다시 만들거나 성능을 잴 때 |

## 쪽 구성 (PDF)

| 쪽 | 내용 |
|---|---|
| 1 | 전체 그림 (줄여서) |
| 2 ~ 4 | 입력: 사진 한 장과 모델 파일 읽기, 그날 영점, 기준 다시 잡기 |
| 5 ~ 10 | 처리: 사진 검사, 1단계 QR, 2단계 나사, 3단계 Y, T 계산, 4단계 결과 점검, 알림 붙이기 |
| 11 ~ 13 | 출력: Result, 경고 사례, 실패 사례 |
| 14 ~ 19 | 도구 (tool포함 에만): 전체 관계, 학습, 평가, 써 보기와 확인, 합성 화면 시험, 같이 쓰는 코드 |

## 색과 화살표

| 색 | 뜻 |
|---|---|
| 초록 | 하는 일 (계산, 실행 단계) |
| 노랑 | 갈림길 (예 / 아니오) |
| 파랑 | 자료 (넣는 것, 그 단계에서 나온 결과) |
| 주황 | 경고 (값은 나오고 계속 진행) |
| 빨강 | 실패 (값 없음, 멈춤) |
| 보라 | 측정 함수와 출력 |
| 회색 | 참고 |

- 처리 묶음에서 **초록 화살표만 따라가면** 정상(Ok)으로 끝나는 길이다.
- 카드의 **파일**, **함수** 줄에서 화살표(→)는 "앞 함수가 뒤 함수를 부른다"는 뜻이다.
- 카드의 **조정 상수** 줄은 그 단계에서 바꿀 수 있는 값의 이름과 지금 값이다.
