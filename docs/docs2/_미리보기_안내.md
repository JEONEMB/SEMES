# docs2 미리보기 안내 (확정되면 지우는 파일)

`docs2` 는 문서를 새 번호 구조로 다시 정리한 **미리보기**다. 지금의 `docs/` 와 `README.md` 는 그대로다.

## 보는 순서

1. `README_새버전.md` (확정되면 맨 위 `README.md` 를 이것으로 바꾼다)
2. `01_개요.md` → `02_사용법.md` → `03_상태와_알림.md` …

## 확정할 때 할 일

- 그림 경로를 `../images/` 에서 `images/` 로 되돌린다 (지금은 미리보기라 한 칸 위를 가리킨다).
- `README_새버전.md` 를 맨 위 `README.md` 로 옮기고 링크 앞에 `docs/` 를 붙인다.
- 옛 문서를 지우고, 그림 폴더(`시각화/`, `코드_정리/`)를 부록 폴더로 옮긴다.
- 코드 주석과 알림 문구에 "README 5절" 처럼 옛 위치를 적은 곳을 새 위치로 고친다.
