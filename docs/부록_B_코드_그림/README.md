## 3. 데이터 전처리는 어디에 있나

[tool포함 캔버스](코드_정리_tool포함.canvas) 맨 아래의 **데이터 준비와 전처리** 묶음에 있다. 위쪽 학습 카드에서도 같은 흐름을 요약했다. 측정 시점만 다루는 `model` 캔버스에는 학습 데이터 처리를 넣지 않았다.

1. **원본 715장과 원본 명령을 보존한다.** 사진 파일·파일명을 고치거나 삭제하지 않는다.
2. **확인된 정정과 제외 규칙을 적용한다.** 이번 자료의 420번은 학습용 T 명령을 `+0.33 → +0.32°`로 정정한다. 702번은 명령과 영상의 불일치가 의심되어 학습·영점 추정에서 제외한다. 실제 규칙은 숫자 ID가 아니라 회차·상대 경로·예상 원본값으로 확인한다.
3. **원본·확인값·학습 정답을 분리한다.** `photos.tsv`의 원본 명령은 이번 독립 평가의 정답으로 남는다. 확인값은 영점 추정과 같은 자세의 반복 사진 묶기에 사용한다. `labels.tsv`의 학습 정답은 **확인값 − 학습 회차 영점**이다.
4. **제외 사유를 기록한다.** 범위 밖 T=+2° 12장과 의심 사례 1장을 학습에서 제외해 최종 702장을 사용한다. 영점 추정에서만 제외한 사진은 명령 불일치가 아니면 최종 학습에 포함한다. 제외된 사진도 원본과 평가 결과에는 남긴다.
5. **검증과 최종 학습을 구분한다.** 독립 검증에서는 학습·영점용·평가 사진을 먼저 나누고, 학습 사진만으로 회차 영점과 계수를 다시 추정한다. 최종 모델은 사용할 702장 전량으로 학습한다. 최종 학습 사진에 다시 대입한 성적은 일반화 검증이 아니다.

| 확인할 것 | 위치 |
|---|---|
| 적용할 정정·제외 규칙, 사유와 출처 | [config/data_preprocessing.tsv](../../config/data_preprocessing.tsv) |
| 규칙 읽기·대상 확인·적용 | [data_preprocessing.hpp](../../tools/common/data_preprocessing.hpp), [data_preprocessing.cpp](../../tools/common/data_preprocessing.cpp) |
| 전처리와 학습 표 생성 | [prepare_dataset.cpp](../../tools/train/prepare_dataset.cpp) |
| 사진별 적용 내역 | 생성한 표 폴더의 `preprocessing.tsv`: 원본값, 확인값, 학습 사용 여부, 제외 사유, 규칙·출처, 영점 추정 제외 여부 |
| 적용 규칙과 캐시 버전 | 같은 표 폴더의 `preprocessing_rules.tsv`, `preprocessing_version.txt` |
| 이번 정정 반영 학습·원본 명령 평가 | 작업공간의 [run_experiment.py](../../../experiments/20261115_corrected_training_raw_eval/run_experiment.py), [results/metrics.tsv](../../../experiments/20261115_corrected_training_raw_eval/results/metrics.tsv) |

새 표는 `prepare_dataset <사진 폴더> --output <새 표 폴더> --rules <규칙.tsv>`로 별도 저장할 수 있다. 새 모델도 별도 폴더에 생성하며, 배포 `data/model`은 자동 교체하지 않는다.

`validate_preprocessing_cache`는 전처리 적용 내역·버전·현재 규칙과 저장된 규칙 사본의 일치를 검사한다. `train`은 오래된 캐시를 재사용하지 않고 새 결과 폴더의 `tables/`에 다시 만든다. `fit_coefficients`도 규칙과 다른 캐시를 오류로 차단한다. 기존 표를 삭제하지 않는다.

기존 `tools/evaluate/evaluate_accuracy.cpp`의 섞음·마지막 확인·범위 밖 시험은 **보정 학습 라벨 기준의 내부 진단**이다. 처음 보는 날 시험에는 원본 명령 기준 점수도 함께 있다. 모든 시험을 원본 명령 채점으로 해석하지 않는다. 위 `run_experiment.py`가 이번 **학습 정답 보정·원본 명령 평가**를 담당한다.

데이터 준비와 전처리 묶음은 tool포함 의 캔버스, HTML, PDF(20쪽)에 모두 들어 있다.

## 4. 쪽 구성 (PDF)

| 쪽 | 내용 |
|---|---|
| 1 | 전체 그림 (줄여서) |
| 2 ~ 4 | 입력: 사진 한 장과 모델 파일 읽기, 그날 영점, 기준 다시 잡기 |
| 5 ~ 10 | 처리: 사진 검사, 1단계 QR, 2단계 나사, 3단계 Y, T 계산, 4단계 결과 점검, 알림 붙이기 |
| 11 ~ 13 | 출력: Result, 경고 사례, 실패 사례 |
| 14 ~ 20 | 도구 (tool포함 에만): 전체 관계, 학습, 평가, 써 보기와 확인, 합성 화면 시험, 같이 쓰는 코드, 데이터 준비와 전처리 |

## 5. 색과 화살표

| 색 | 뜻 |
|---|---|
| 초록 | 하는 일 (계산, 실행 단계) |
| 노랑 | 갈림길 (예 / 아니오) |
| 파랑 | 자료 (넣는 것, 그 단계에서 나온 결과) |
| 주황 | 경고 (값은 나오고 계속 진행) |
| 빨강 | 실패 (값 사용 금지, 멈춤) |
| 보라 | 측정 함수와 출력 |
| 회색 | 참고 |

- 처리 묶음에서 **초록 화살표만 따라가면** 정상(Ok)으로 끝나는 길이다.
- 카드의 **파일**, **함수** 줄에서 화살표(→)는 "앞 함수가 뒤 함수를 부른다"는 뜻이다.
- 카드의 **조정 상수** 줄은 그 단계에서 바꿀 수 있는 값의 이름과 지금 값이다.
