데이터 준비와 전처리

원본 715장을 보존하고, 확인된 명령 정정 → 학습 대상 선택 → 학습 회차 영점 보정 → 최종 702장 학습으로 이어진다.

이번 독립 평가의 정답은 파일에서 읽은 원본 명령이다. 기존 도구의 보정 라벨 진단 점수와 구분한다. 아래의 숫자 ID는 이번 자료의 행 번호이며, 실제 정정 규칙은 회차·파일 경로·예상 원본값으로 찾는다.

1. 원본 715장과 원본 명령 보존

사진 파일과 파일명을 바꾸거나 삭제하지 않는다.

photos.tsv: command_y_mm, command_t_deg

파일명에서 읽은 값 그대로이며 이번 독립 평가의 정답이다.

features.tsv: QR 1개 요약값 + 나사 4개 이동량

명령값 정정이나 영점 보정으로 영상 특징을 바꾸지 않는다.

2. 근거 있는 규칙만 적용

420번: 학습에 쓸 T 명령 +0.33 → +0.32°

동봉 장비 기록으로 확인. 같은 자세 반복 사진의 그룹도 +0.32로 묶는다.

702번: 명령과 영상 자세 불일치 의심 → training_allowed = 0

확정 오탈자로 간주해 임의로 정답을 고치지 않는다.

config/data_preprocessing.tsv
load_preprocessing_rules → apply_preprocessing_rule
회차 + 상대 경로 + 예상 원본값 확인; 근거는 provenance에 기록

값의 역할 세 가지

원본 명령(raw) → 이번 독립 평가의 정답으로 유지

확인된 명령(verified) → 학습 범위·영점 추정·동일 자세 그룹

학습 정답(label) → verified − 학습 회차 영점

420번의 예:

원본 T=+0.33 / 확인값 T=+0.32 / 학습 정답 T=+0.32−회차 영점

원본: photos.tsv
확인값·적용 근거: preprocessing.tsv
학습 정답: labels.tsv

3. 학습에 쓸 행을 정한다

usable = 측정 성공 ∧ 나사 4개 ∧ 범위 안 ∧ 규칙 허용 ∧ 명령 불일치 아님

현재 자료의 학습 대상:

715 − 범위 밖 12 − 명령 불일치 의심 1 = 702장

  • T=+2° 12장: 명목 범위 Y±2 mm, T±1° 밖이므로 학습 제외
  • 702번: 규칙으로 학습·영점 추정 제외
  • 제외는 행과 파일의 삭제가 아니다. 원본과 평가 결과는 남는다.
PreparedPhoto::usable, training_allowed, in_range
실제 사용 여부는 preprocessing.tsv의 training_used

4. 학습 회차의 영점 어긋남 추정

확인된 명령(verified)과 영상 특징으로 회차별 영점을 구한다.

특징 = Y·T의 1차/2차 항 + 회차별 상수

회차 상수를 영상의 Y·T 변화율로 역산해 영점으로 바꾼다.

큰 잔차는 영점 추정에서만 제외하고 다시 맞춘다. 명령 불일치 기준까지 넘은 경우에만 최종 학습 제외로 표시한다.

영점 추정에서 빠졌어도 명령이 맞는 사진은 학습에 다시 포함한다.

estimate_session_zeros → fit_session_zeros
mark_command_mismatch
교차검증 때는 현재 학습 묶음만으로 다시 추정한다.

5. 학습 정답을 만든다

label_y = verified_y − session_zero_y

label_t = verified_t − session_zero_t

그날의 명령 0 어긋남이 계수에 섞이지 않도록 학습 정답을 보정한다.

영상 특징·사진·원본 평가 명령은 그대로 둔다.

학습 입력: features.tsv + labels.tsv
collect_training_photos가 label_y_mm, label_t_deg를 사용
photos.tsv의 원본 명령은 이 단계에서 덮어쓰지 않는다.

학습 정답 보정과 실제 사용 시 그날의 출력 영점 설정은 서로 다른 단계다.

6. 최종 모델은 702장 전량 학습

확인된 정정과 제외 규칙을 적용한 usable 전체를 사용한다.

final_check 표시는 검증용 구분이며 최종 모델 생성에서는 제외하지 않는다.

  • Y·T 계수: 나사 조합별 16개
  • 일치 점검식: 11개
  • 학습 범위와 기준 사진
fit_coefficients → collect_training_photos → fit_all_sets
새 모델은 별도 폴더에 저장; 배포 data/model은 자동 교체하지 않는다.
이 702장에 재대입한 정확도는 학습 결과 점검이다.
