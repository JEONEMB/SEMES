사진 검사 → 1단계 QR 이동 → 2단계 나사 이동 → 3단계 Y, T 계산 → 영점 빼기 → 4단계 결과 점검 → 알림 붙이기

1단계: QR 이동

QrFinder::find_qr_shift (src/steps/01_find_qr)

QR 3개가 기준에서 가로로 몇 px 움직였는지 잰다

QR 하나 (find_one): 창을 흐리게 → 가장 닮은 자리 (NCC) → 포물선으로 소수 px. 닮은 정도 0.8 미만이면 못 찾은 것이다

파일 src/steps/01_find_qr.cpp
함수 measure_values → QrFinder::find_qr_shift
안에서 부르는 함수 find_one → blurred_area (창을 흐리게) → cv::matchTemplate (가장 닮은 자리) → parabola_offset (소수 px)
조정 상수 kBlurSigma 2.0 px (흐리는 정도), kBlurMargin 8 px, kMinSimilarity 0.8 (이보다 덜 닮으면 못 찾은 것)

자리를 잡았는가?

한 번에 3 px 넘게 가지 않고, 처음 자리에서 8 px 넘게 벗어나지 않아야 한다

E_INTERNAL

측정, 영점 설정 또는 기준 갱신 중 예외가 발생함.

E_NOT_INITIALIZED

초기화 성공 전에 측정, 영점 설정 또는 기준 갱신을 호출함.

E_ZERO

실패 (값이 없다, 멈춘다)

  • E_SETTINGS, E_DATA 설정이나 모델 파일을 못 읽음
  • E_NOT_INITIALIZED 준비를 안 함
  • E_PHOTO 사진 크기나 형식이 다름
  • E_QR_NOT_FOUND QR 을 하나도 못 찾음
  • E_ZERO 영점을 잡지 못함
  • E_REFERENCE 기준을 다시 잡지 못함
  • E_INTERNAL 예상 못 한 오류

Y (mm), T (도)

상태: 정상 / 경고 / 실패
