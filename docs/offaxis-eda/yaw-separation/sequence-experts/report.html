시퀀스 모델로 정확도가 좋아지는가?

시퀀스를 알고 있을 때의 조건부 정확도는 좋았습니다. 이미지만으로 모델을 선택할 때는 일부 큰 오차가 남았습니다. 모델을 나누는 아이디어는 유효하지만, 임의의 혼합 자세까지 해결된 결과는 아닙니다.

확인한 시간 구간과 직선 관계

사용자가 파일 수정 시각을 촬영 시퀀스 기준으로 확인했습니다. 60/120/300초 간격을 시험 규칙으로 미리 정했고, 오류가 작아지는 경계를 골라 결과로 제시하지 않았습니다. 대표 설명은 120초입니다. 이 경계가 실제 기구 재설정과 항상 일치한다는 뜻은 아닙니다.

같은 사진에서 공정하게 비교

같은 좌표의 반복 3장은 함께 보류했습니다. 대표 보류 110장 중 학습 자료가 충분한 시퀀스 모델이 있는 98장만 공통 비교했고, 자료가 부족한 혼합 12장은 제외했습니다. 아래 표는 같은 QR별 평균 dx/dy 6채널을 쓰므로 특징 종류가 달라 생기는 차이를 줄였습니다.

모델 분리 효과와 조건 정보의 효과

통합 계수를 그대로 두고 시퀀스의 고정축 조건만 알려준 대조도 두 축 ±1틱 100%였습니다. 구간별 보정은 추가로 오차를 줄였지만, 큰 개선을 전부 세션별 기울기의 효과로 해석할 수는 없습니다. 공통 기울기+시퀀스별 중심도 좋은 결과를 보였습니다.

이미지 선택이 남은 병목

이미지 gate는 정답·파일명·수정 시각 없이 각 모델의 영상 재구성 잔차만 비교했습니다. 대부분을 잘 고르는 경우에도 일부 오선택이 큰 좌표 오차를 만들었습니다. 단순 soft blend는 서로 다른 모델의 좌표를 평균하면서 더 나빠졌습니다.

시퀀스별 좋은 모델을 보관하고, 현재 run 정보·선택의 불확실성·새 기준 영상으로의 세션 보정을 다루는 방향은 검토할 가치가 있습니다. 새 세션 일반화나 장비 동작은 이번에 시험하지 않았습니다.

놓치면 안 되는 제한

  • 120초 분할의 활성 시퀀스에는 독립 2축을 함께 변화시킨 구간이 없습니다.
  • 300초로 크게 묶은 혼합 2축 구간에서는 알려진 시퀀스 모델도 큰 오차가 남았습니다.
  • 수정 시각으로 구분된 기존 run 안에서의 검증입니다. 미래 시각만으로 예전 모델 ID를 알 수는 없습니다.
  • 이전 실험도 일부 그룹별 절편을 사용했습니다. 이번에는 시퀀스의 1차원 조건까지 추론에 사용했습니다.
