# SSAFY 측정 모듈 문서

이 문서는 현재 chore/hye/merge-ssafy 브랜치의 운영 모듈을 설명한다. 과거 실험 구현은 legacy에 있으며 현재 사용법과 혼동하지 않는다.

| 목적 | 문서 |
|---|---|
| 빌드하고 사진 한 장 실행 | [빠른 시작](01_quickstart.md) |
| QR와 나사에서 Y, T를 구하는 과정 | [알고리즘](02_algorithm.md) |
| 카메라 연동, 영점, 경고와 보정 허용 | [API와 상태](03_api_and_status.md) |
| 장비 설정, 모델 파일, 재학습 | [모델과 데이터](04_model_and_data.md) |
| 정확도, 속도, 실패 사례와 재현 범위 | [검증 결과](05_validation.md) |
| 장치 통합과 라즈베리파이 확인 사항 | [통합 안내](06_integration.md) |
| 이전 joint API에서의 전환 | [변경 내역](runtime_migration.md) |

학습 범위 밖이라는 이유만으로 측정이나 보정을 막지 않는다. 정상 검출과 유효한 영점 조건이면 3.00 mm를 포함한 범위 밖 결과도 반환한다. 정확도가 떨어질 수 있다는 경고를 남기며 다른 실패 조건은 유지한다.
