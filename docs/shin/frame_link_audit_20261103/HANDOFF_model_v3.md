## v3를 만든 근거

- 생성시각은 복사 시각이며 수정시각도 촬영 시각의 대리값이다. 시간 구간을 확정된 물리 세션이라고 부르지 않는다.
- center.bmp와 center3를 인접 움직임 스캔에서 분리했다. 전체 원점 기준 노출 분리 규칙이다. center3는 직전 반복 후 46초라 120초 공백 규칙으로 분리되지 않았었다. 실제 재원점 장비 이벤트를 입증한 것은 아니다.
- .32 폴더/.33 파일명 한 건의 파생 T만 .32로 정정. 원본 이름 유지.
- .57 세 장은 영상 궤적이 .57을 지지해 복원. Actual .56과의 충돌은 기록하고 참값으로 단정하지 않음.
- 반복 공통 변위 네 장만 학습에서 낮은 가중치. 시험 자료에서는 삭제하지 않음. 모든 575장 유지.
- QR 630개의 실제 코너 수는 212/210/208. 직선의 임의 지점을 2차원 정확한 점으로 취급하지 않는다. 기존 exact Lanczos-3 sinc 계측 재사용. 자연 특징은 방향성/공분산 검사를 거침. A 원점용 22개, B 보류용 17개는 패치가 겹치지 않는다. 아래 선은 품질 기준 미달이라 제외했다.
- 전체 Y4/Y5 항 보완을 선택. T는 기존 3차. 평균 원점 기준 네 장의 잠재 Y/T=0을 좌표 규약으로 사용. Oct15→Oct4 영상 등록을 기계/카메라 원인으로 분리 해석하지 않는다.

## 후속 작업 요청

1. 기존 T 단독 추정 모델(method7 등) 코드와 평가 상태를 읽고 중단됐던 빌드/평가부터 복구한다. v3 가정 기준으로 모델을 수정하고 학습·평가까지 이 대화에서 수행한다. 사진만으로 추론하는 조건을 유지하고 세션 ID/시각을 시험 정답 보정에 몰래 사용하지 않는다.
2. 좌표는 CSV의 T_standard/Y_standard를 사용하되 물리 참값으로 선언하지 않는다. 기존 원래 명령 라벨, 정정 명목 라벨, 가정 v3 좌표에 대한 성능을 각각 명확히 구분한다. v2보다 나쁜 결과도 공개한다. T 1tick=.01°; Y는 방해변수.
3. 전체 데이터로 생성한 v3 좌표를 목표로 사용한 CV는 조건부 모델 적합 평가다. 독립 원점 정확도나 누수 없는 전체 시스템 평가라고 주장하지 않는다. 가능한 경우 fold 내부에서 원점/보정/모델을 재적합하는 평가를 추가하고 식별이 안 되는 보류 구간을 억지로 정답화하지 않는다. 어려우면 구체적 한계와 가능한 공정한 평가를 제시한다.
4. 경계 12개와 사전척도의 민감도를 확인하고, 큰 영상 오차 개선이 실제 T 추정 개선으로 이어지는지 확인한다. 보류 예측, RMSE/MAE/최대오차, 1tick 통과 비율, 세션/자세별 잔차, 실패 사진을 제공한다. 원본 575장/기준4장과 추정 평가571장의 분모 차이를 설명한다. 성능 때문에 시험 아웃라이어를 삭제하지 않는다.
5. 결과는 반드시 PDF로 작성하고 실제 사용 특징을 사진 위에 표시한다. 왜 검증이 타당한지와 무엇을 증명하지 못하는지 설명한다. PDF 렌더 점검을 마친다. 웹페이지는 원격 사용자가 볼 수 없다.
