# camera_calib

Raspberry Pi HQ 카메라(IMX477) + 6mm 렌즈의 **내부 파라미터(fx, fy, cx, cy)와 렌즈 왜곡 계수**를 구하는 도구.
결과로 왜곡을 편 사진과, SEMES 카메라와 같은 화각의 3840x2160 사진을 만들 수 있다.

| 파일 | 하는 일 |
|---|---|
| `checkerboard_A4_12x9_15mm.pdf` | 인쇄용 체커보드 (A4 가로, 12x9 칸, 한 칸 15mm, 내부 코너 11x8) |
| `make_checkerboard.py` | 위 PDF 생성기 (칸 수·크기 변경 가능) |
| `capture_calib.py` | Pi 에서 브라우저 미리보기를 보며 4056x3040 흑백 PNG 촬영 |
| `calibrate.cpp` | 촬영한 사진으로 캘리브레이션 (C++ / OpenCV 3.4) |

**처음이라면 [GUIDE.md](GUIDE.md)부터 읽는다.** 왜 하는지, 언제 다시 하는지, 초점을 먼저 맞추고 잠그는 이유, 기구 장착 후 할 일이 정리되어 있다.

## 1. 체커보드 준비

1. `checkerboard_A4_12x9_15mm.pdf` 를 **"실제 크기(100%)"** 로 인쇄한다. "페이지에 맞춤"은 끈다.
2. 아래 100mm 눈금자를 자로 재서 100mm 가 맞는지, 한 칸이 15.0mm 인지 확인한다.
   다르면 실제로 잰 값을 아래 `--square` 에 넣는다.
3. 종이를 **평평한 판**(우드락, 아크릴, 두꺼운 골판지)에 붙인다. 울거나 휘면 결과가 틀어진다.

## 2. 촬영 (Pi)

```bash
cd hardware/camera_calib
python3 capture_calib.py                # 저장 폴더: captures/
```

- 브라우저에서 `http://<Pi IP>:8000` 을 열고 **[촬영]** 버튼, 또는 터미널에서 **Enter** 로 찍는다. 종료는 Ctrl+C.
- **멈춤 확인**: 버튼을 누르면 연속 프레임 이동이 0.3px 미만으로 2번 연속일 때(보드가 멈췄을 때) 3장을 평균해 저장한다.
  4초 안에 안 멈추면 저장하지 않는다. 손에 든 보드가 움직이면 롤링 셔터 때문에 사진이 휘어 오차가 커지기 때문이다.
- 카메라는 한 프로그램만 쓸 수 있다. 다른 카메라 프로그램(`rpicam-*`, 스트리밍 서버)은 먼저 끈다.
- 실내 조명 깜빡임(60Hz) 줄무늬를 막기 위해 노출을 8333us 배수로 맞춘다 (`--flicker 8333`, 기본값).
  노출을 직접 고정할 때는 `--exposure 8333` 또는 `16666` 처럼 배수로 준다.

**좋은 사진 찍는 법 (15~25장)**

- 카메라는 **실제로 쓸 거리(약 30cm)** 에 두고, 초점과 조리개를 먼저 고정한다. 캘리브레이션 후 링을 돌리면 다시 해야 한다.
- 보드 **전체**가 화면 안에 들어와야 한다. 잘리면 그 사진은 쓰이지 않는다.
- 보드를 화면 **가운데, 네 구석, 위·아래·좌·우 가장자리**에 골고루 둔다. 가장자리 사진이 있어야 왜곡을 정확히 구한다.
- 보드 **면을 앞뒤·좌우로 20~40° 젖힌** 사진을 1/3 이상 섞는다 (위·아래·왼쪽·오른쪽이 카메라 쪽으로 오게).
  화면 안에서 빙글 돌린 것은 젖힌 것이 아니다. 정면 사진만 있으면 fx 가 정해지지 않는다
  (2026-11-12: 정면만 29장 → fx 2833~3336 으로 흔들림, 젖힌 14장 추가 → 3979~3986).
- 보드를 손에 들지 말고 어딘가에 기대 세운 채 찍는 것이 가장 확실하다.
- 종이는 단단한 판에 **전면** 접착한다 (가장자리 테이프만으로는 휘어서 오차가 수 px 이 된다).

## 3. 캘리브레이션

**권장: `calibrate_ro.py`** (Python, OpenCV 4: `findChessboardCornersSB` + `calibrateCameraRO`)

```bash
python3 calibrate_ro.py captures_YYYYMMDD --square 15 --out camera_calib.yml   # 젖힌 각도·fx 안정성도 출력
```

종이 보드가 1 mm 만 휘어도 아래 `calibrate.cpp`(일반 calibrateCamera)는 오차가 수 px 이 된다.
`calibrateCameraRO` 는 보드의 실제 코너 위치(휨·인쇄 오차)를 같이 추정해서 렌즈 값을 정확히 구한다.
2026-11-12 같은 사진 43장: `calibrate.cpp` 방식 RMS 1.94 px → RO 0.69 px, 보드 휨 ±0.9 mm 를 흡수함.

아래 C++ 도구도 그대로 쓸 수 있다 (보드가 정말 평평할 때).

빌드 (Pi, OpenCV 3.4.15 가 `/usr/local` 에 설치된 상태)

```bash
cmake -S . -B build
cmake --build build -j4
```

실행

```bash
./build/camera_calib captures --square 15 --out camera_calib.yml --undistort captures/calib_001.png
```

출력 예 (fx=3871 로 합성한 시험 사진의 결과)

```
RMS 재투영 오차 : 0.243 px  (0.5 px 이하면 좋음)
fx, fy         : 3871.3, 3871.3 px  (초점거리 6.00 mm)
cx, cy         : 2028.4, 1520.1 px
화각           : 가로 55.3° 세로 42.9°
SEMES 같은 화각 : 왜곡 편 사진에서 3700x1951 를 잘라 3840x2160 으로
크롭 후 SEMES 감도 14.25 px/mm 가 되는 거리 : 282.0 mm (광학 중심 ~ 벽)
```

- 12MP 사진이라 Pi 5 에서 사진 12장에 약 3분 걸린다. 보드를 못 찾은 사진이 특히 오래 걸린다.
- **RMS 가 0.5px 를 넘거나** 특정 사진의 오차가 1px 이상이면, 그 사진을 지우고 다시 실행한다.
- `camera_calib.yml` 에 카메라 행렬, 왜곡 계수, 화각, SEMES 크롭 크기가 저장된다. 팀 공유 시 이 파일을 전달한다.
- `--undistort` 로 준 사진에서 `*_undistort.png` (왜곡 보정)와 `*_semes3840.png` (SEMES 와 같은 화각·크기)가 만들어진다.

## 참고: SEMES 카메라와 맞추는 원리

- SEMES: 12mm / 2.8um, 4096x2160 을 가로만 3840 으로 축소 → fx 4018, fy 4286 (px)
- 우리: 6mm / 1.55um → fx·fy 약 3871 (px), 화각이 SEMES 보다 넓다
- 왜곡을 편 뒤 가운데를 `3840 x fx/4018` × `2160 x fy/4286` 크기로 잘라 3840x2160 으로 늘리면
  SEMES 와 같은 화각·픽셀 비율이 된다. 같은 거리에서 찍으면 같은 기하의 사진이 된다.
- 운용 시에는 4056x2160 센서 모드(19.6fps)를 쓸 수 있다. 이 모드는 전체 센서에서 위아래 440줄씩 잘린 것이라
  `cy` 에서 440 을 빼서 쓴다.

## 기울기 보정 (`roll_deg`)

`camera_calib.yml` 의 `roll_deg` 는 왜곡을 편 뒤 광축 기준으로 사진을 돌리는 값이다 (+ = 시계 방향, 없으면 0).
카메라가 롤 방향으로 조금 돌아가 있을 때 `Rectifier`(C++)와 `verify_web`(Python)이 같은 변환표에서 함께 보정한다 (두 결과는 픽셀 단위로 같음).

- 재는 법: SEMES 형식으로 찍은 사진에서 **배경 가로선**(판 전체 길이라 가장 정확)의 기울기를 SEMES `center.bmp` 의 벽 가로선과 비교한다.
  화면 각도 차이 ÷ 1.067(SEMES 픽셀 가로세로 비) = `roll_deg`.
- QR 플레이트 자체가 배경판보다 돌아가 붙은 것은 roll 로 고치지 않는다 (Θ 축/센터 기준으로 맞춘다).
- 2026-11-12: 배경선 3개 평균 SEMES +0.21°, 우리 −0.04° → `roll_deg: 0.23` (적용 후 +0.21°). QR 줄은 SEMES 보다 약 0.57° 돌아가 있음(판 부착 각도).

- 54장 (정면 29 + 젖힌 14 + 좌우 끝 보충 11), RO RMS 0.780 px, fx 3988.5 / fy 3987.7, 무작위 70% fx 3986~3994.
- 처음 43장은 SEMES 화면 좌우 끝 약 10% 에 보드가 한 번도 없었다 → 보드를 화면 좌우 테두리에 붙여 11장 보충.
- 배경판 띠로 직선 확인: 위 띠 1~2 px, 아래 띠 약 6.7 px 휨. 아래 띠 휨은 예전·43장·54장 캘리브레이션 모두 비슷해서
  렌즈가 아니라 띠 자체의 휨(약 0.5 mm)으로 본다 (아래 띠만 위 띠와 0.3° 평행하지 않음).
