# data/new_photos: 설비에서 받은 사진

계수를 다시 만들거나 성능을 잴 때 쓰는 사진을 넣는 곳입니다. 사진은 장당 24 MB 라 Git 에 올리지 않습니다 (이 파일만 올라갑니다).

## 넣는 법

촬영한 날(회차)마다 폴더를 하나 만들고, 받은 사진을 **이름 그대로** 넣습니다. 폴더 이름이 회차 이름이 됩니다.

```
data/new_photos/
├── 20261014/                      촬영 날짜
│   ├── Y+0.00 T+0.00 (1).bmp      명령 0 에서 찍은 사진 5~10장 (영점용)
│   ├── Y+0.05.bmp                 Y 만 움직인 사진 (T 는 0)
│   ├── T-0.30.bmp                 T 만 움직인 사진 (Y 는 0)
│   └── Y+0.05 T+0.01 (2).bmp      둘 다 움직인 사진, (2) 는 같은 자세의 두 번째 사진
├── 20261020/
└── tables/                        prepare_dataset 이 만드는 표 (자동 생성, 직접 고치지 않음)
```

- 파일 이름의 `Y`, `T` 뒤 숫자가 로봇 명령값입니다 (Y 는 mm, T 는 도). 이 값을 정답으로 씁니다.
- 이름에 명령값이 없는 사진(예: `center.bmp`)은 건너뛰고 `tables/prepare_report.txt` 에 적습니다.
- 회차 폴더 안에 하위 폴더가 있어도 됩니다.

## 표 만들기

```
build\Release\prepare_dataset.exe data/new_photos
```

`tables/` 가 이미 있으면 덮어쓰지 않고 멈춥니다. 다시 만들려면 `tables/` 를 지우고 실행합니다.

| 파일 | 내용 |
|---|---|
| `photos.tsv` | 사진 번호, 회차, 경로, 받은 명령값 |
| `features.tsv` | 사진마다 잰 QR, 나사 1~4 의 가로 이동 |
| `labels.tsv` | 학습용 정답 (명령 − 그 회차의 영점 어긋남) |
| `splits.tsv` | 학습, 평가에 쓰는지, 시험 나누기 |
| `sessions.tsv` | 회차별 영점 어긋남 |
| `prepare_report.txt` | 사진 수, 뺀 사진과 이유 |
