## 2026-11-12 추가: 날 차이 증강 (현재 가장 잘 된 증강)

위의 "증강은 무효" 결론은 **Y, T 위치를 넓히는 증강**(A9)에 대한 것이다. 아래는 종류가 다르다. 촬영한 날마다 QR, 바, 나사가 서로 조금씩 다르게 놓이는 **날 차이**를 흉내 낸다. C11 문서는 고치지 않았다.

| 경로 | 크기 | 내용 |
|---|---:|---|
| `20261112_1806_처음보는날오차_날차이증강/결과/증강자료/augmented_training_features.tsv` | 8.5 MB | 학습용 증강 자료. 6318행 = 원본 702장 + 복사본 8 × 702. 열: row, id(원본 사진 ID), copy(0 = 원본), source, Y_abs, T_abs(절대 영점 라벨), Y_cmd, T_cmd(그날 명령), z_1차~z_4차(더한 배율), features66 |
| `.../증강자료/augmented.npz` | 3.3 MB | 같은 내용의 배열(features, labels_abs, id, copy, source, z, day_vectors, sessions, slope) |
| `.../증강자료/day_vectors.tsv` | 6 KB | 세션 4개의 날 차이 벡터(값 66개)와 절대 영점 위치 |
| `.../증강자료/확인.txt` | 1 KB | 생성 직후 확인 출력 |
| `.../결과/결과.md`, `출력.txt` | | 증강 방식 비교 결과와 스크립트 출력 |

- 생성식: 복사본 = 원본 특징 + Σ z × (세션별 날 차이 벡터), z 는 표준편차 2 의 정규분포 난수, seed 20261112. 정답은 그대로 둔다.
- 고른 근거: 세션 하나를 통째로 뺀 시험에서 증강 없음 66.1%, 배율 0.5 는 79.6%, 배율 1 은 80.9%, **배율 2 는 82.9%**. 같은 날 섞은 평가의 탈락은 1.0장으로 같다. 방향을 모르고 흔드는 증강은 39% 로 나빠져 쓰지 않는다.
- 확인: 이 자료로 학습한 모델은 날 차이 벡터를 더해도 예측이 거의 변하지 않는다(Y 0.0085 에서 0.0001, T 0.0009 에서 0.00001). 원본 702장을 다시 넣으면 701장이 통과한다(원본만 학습하면 702장).
- 조건: 범위 안 702장(ID 702 제외, T=+2.00 12장 제외, ID 420 라벨 T 0.32), 절대 영점 라벨, 지금 나사 측정(00004 의 66개 특징).
- 한계: 4차는 오르지 않는다(7.7% 에서 21.7%). 본 적 있는 종류의 날 차이만 막는다. 세션이 4개뿐이다. 세션을 통째로 뺀 시험은 날 효과와 안 배운 위치 효과가 섞여 있다. 특징 수준 증강이며 BMP 는 만들지 않았다. Python 분석이고 C++ 학습 도구로 검증하지 않았다.
- 다시 만들기: 저장소 루트에서 `python "experiments/hye/20261112_1806_처음보는날오차_날차이증강/실험/make_augmented.py"` (이미 있으면 덮어쓰지 않는다).

## 2026-11-12 추가: 방법론별 날 차이 증강 (48 폴더)

위 `20261112_1806_...` 자료는 예전 구성(00004 의 66개 값, 지금 나사 측정) 하나에만 만든 것이다. 방법론이 바뀌면 값의 개수와 날 차이 벡터가 달라지므로, 방법론마다 따로 만들어 두었다.

- 위치: `20261112_1835_조합마다검증방식다름_방법론별증강과고정검증/결과/증강자료/<방법론>/` (48 폴더, 74 MB)
- 폴더 이름: `QR-<표현>_나사-<측정>_바-<구성>`
  - QR: `ECC54`(9곳), `ECC24`(모서리 4곳), `ECC6`(QR별 평균), `P536_2`(536점 평균), `P536_12`(P12), `P536_20`(3차식)
  - 나사(4개): `old`(밝기 조각 맞춤), `grad`(기울기 영상 맞춤)
  - 바: `both`, `up`(위만), `lo`(아래만), `none`
- 폴더마다: `augmented.npz`(features, labels_abs, id, copy, source, z, day_vectors, sessions. 6318행 = 원본 702 + 복사본 8 × 702), `day_vectors.tsv`(그 방법론의 세션별 날 차이 벡터)
- 생성과 시험: `experiments/hye/20261112_1835_조합마다검증방식다름_방법론별증강과고정검증/실험/combo.py`. 시험 결과는 그 폴더의 `결과/결과.md`, `결과/결과.tsv`(96행).
- 이 자료는 702장 전체로 만든 학습용이다. 시험할 때는 학습 조각만으로 증강을 다시 만들었다(이 파일을 그대로 쓰지 않았다).
- 시험 결과 요약: 날 차이 증강은 처음 보는 날 성적을 평균 59.8% 에서 89.0% 로 올리고 같은 날 탈락을 평균 0.9장 늘린다. `QR-P536_2_나사-grad_바-none` 에서 처음 보는 날 99%(4차 94%).
