## 먼저 알아야 할 것

**증강은 무효로 결론 났다.** [C11_증강은무효.md](../../docs/hye/지식베이스/사실/C11_증강은무효.md) 를 먼저 읽는다.

A9 실험에서 통과율이 0.0 에서 0.0 %, 81.3 에서 79.2 %, 96.2 에서 97.0 % 로 사실상 변하지 않았다. 증강은 이미 아는 물리를 다른 (Y, T) 로 옮겨 놓을 뿐이고, 1014 를 빼면 감도 자체가 나쁘기 때문이다.

양은 합성으로 늘릴 수 있지만 자극은 로봇을 실제로 움직여야 생긴다.

**합성 사진(BMP)은 만들지 않았다.** 증강은 전부 점 변위 수준에서 했고 `.npz` 배열로만 남아 있다.
