# M2 — IC-GN 아핀 정합 + 서브픽셀 치우침 감소

> 코드 : `code/yt/m2_icgn.hpp/.cpp` · 결과 : `results/verify/M2_icgn/` · 이전 버전 : `backup/m2_icgn.v1*`, `v2_bspline*`, `v3_adopted*` · σ 탐색 기록 : `backup/explore_sigma.txt`
> 논문 : Pan 2013 (IC-GN, ZNSSD, 가우시안 사전 필터), Unser 1999 (B-스플라인 보간), Liu 2021 (DPG)

## 1. 목적
트랙 A 의 Θ 신호는 좌·우 QR 의 가로 늘어남 차이 ε_R − ε_L 입니다. Θ 0.01° 에서 이 값은 3.6 × 10⁻⁵ 정도로 매우 작습니다. 이동(u, v)뿐 아니라 늘어남(∂u/∂x 등)까지 10⁻⁶ 급으로 재야 합니다.

## 2. 수행 방법
1. QR 마다 1차 형상 함수 6개 (u, uₓ, u_y, v, vₓ, v_y) 를 IC-GN 으로 풉니다. M1 이동값을 초기값으로 씁니다.
   - 비용 함수는 ZNSSD (밝기·대비 변화에 둔감)입니다.
   - 역합성 갱신 `W ← W ∘ W(Δp)⁻¹` 을 쓰므로 기준 영상의 기울기·헤시안은 한 번만 계산합니다.
2. **보간은 직접 구현했습니다.** OpenCV `remap` 은 1/32 px 고정 소수점이라 10⁻⁶ 급 늘어남을 읽을 수 없습니다.
   - 선형, Keys 3차 (a = −0.5), 3차 B-스플라인 (Unser 사전 필터 계수)
   - 기준 기울기는 스플라인 계수에서 직접 계산합니다.
3. **채택 설정** : B-스플라인 + 두 영상 모두 가우시안 σ = 1.0 사전 필터 (Pan 2013). 비교를 위해 선형(`_ux_lin`)과 필터 없는 B-스플라인(`_ux_bs0`)도 함께 저장합니다.
4. 결과 `m2_affine.csv` : QR 별 6 변수, ZNCC, `dEx = ε_R − ε_L`, `dEy` 등.

## 5. 시행착오 (기준은 낮추지 않음)
1. **v1 DUAL (선형 + Keys 평균)** : Python 시험판에서는 두 보간의 치우침 부호가 반대여서 서로 지워졌습니다. 하지만 이는 OpenCV 의 Keys 계수 a = −0.75 때문이었습니다. a = −0.5 에서는 부호가 같아 상쇄되지 않았습니다 (0.0177 px). → 채택하지 않음.
2. **v2 B-스플라인** : 0.0059 px 로, 기준 0.005 px 에 미달했습니다.
3. **v3 B-스플라인 + 가우시안 사전 필터** : σ 를 {0, 0.5, 0.7, 1.0, 1.4} 로 탐색해 σ 1.0 에서 0.0006 px 를 얻었습니다. 탐색 기록은 `explore_sigma.txt` 입니다.
4. 실제 사진 잔차 σ (9.98e-5) 는 합성 정확도보다 훨씬 큽니다. 원인은 트랙 A 문서 4절을 보십시오.
