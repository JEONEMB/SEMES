5각자의 장점

ksh 김성현

  • 깊이 시차 특징 s, d — 한 장으로 Y·Θ 를 가르는 핵심
  • 물리 보정식 6계수 : 단독축 학습 → 섞인 움직임·다른 날 일반화
  • IC-GN · O-MOMS 부화소 정합, 실패 0, 35 ms
  • 실험계획 근거 : ROI 크기·영역·블록 수·Center 정의·반복 정밀도를 수치로 결정
  • 학습/평가 분리, 1차 → 3rd 독립 시험, 시뮬레이터 폐루프

shin 신윤석

  • 판 검출 · QR 해독 · 모듈 재생성 : 판과 주소(payload)를 확인
  • Fourier · 영상 형성 코너 : 해석 미분 검사·단위 시험을 갖춘 부화소 코너
  • 식별성 분석 : 판 특징만으로는 한 틱 구별이 안 됨을 정량화 (SNR 0.4)
  • 검증 규율 : 원본 SHA256, 소스 해시 manifest, 좌표 단위 보류로 누출 방지
  • 팀 공통 인터페이스 include/alignment.hpp, CMake·clang-format·Windows 설정 문서

7한계

  • 통합 프로젝트는 Linux(GCC 13, OpenCV 4.6)에서 빌드·평가했다. Windows(MSVC v141, OpenCV 3.4.15) 빌드는 확인하지 못했다.
  • 검증 장치가 실제 오정합을 잡는 비율은 시험하지 못했다 (실제 사진에서 모순이 한 번도 없었음). 오탐(정상인데 거부)은 0건.
  • shin 의 L630 코너·가장자리 계측(파이썬)은 다시 돌리지 않고 저장된 예측값을 채점했다. shin 모델은 2차 세트 안에서 학습한 것이라 P1(다른 날)로는 평가하지 못했다.
  • 2차·3rd 는 같은 날 같은 장비다. 다른 날짜 일반화는 다음 촬영으로 확인해야 한다.
