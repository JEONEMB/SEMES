# QR_OpenCV_Check — QR Y-Θ Viewer (MFC)

이미지를 등록하면 위상(Gabor) 기반 측정 엔진으로 **Y 이동(mm)과 Θ 회전(°)**을 계산하고, QR 3개의 기준 위치와 측정 위치를 겹쳐 보여 주는 MFC 대화 상자 앱입니다.

## 빌드

- Visual Studio 2026, 플랫폼 도구 집합 **v145**, **x64** (Win32 구성은 OpenCV 가 없어 사용하지 않음)
- OpenCV 3.4.15 (`C:\opencv\build`, vc15). 경로가 다르면 `QR_OpenCV_Check.vcxproj` 의 `<OpenCVDir>` 한 곳만 고치면 됩니다.
- 빌드 후 `opencv_world3415(d).dll` 이 실행 파일 폴더로 자동 복사됩니다.
- 측정은 Debug 에서 5 ~ 10배 느립니다. 폴더 일괄 처리는 **Release** 권장.

## 사용 순서

1. **[기준 이미지]** — Y = 0, Θ = 0 인 `center.bmp`. QR 3개를 자동으로 찾습니다.
   **[기준 이미지 보기]** — 다른 사진을 보다가 언제든 기준 영상으로 돌아갑니다 (측정 결과·목록은 유지).
2. **[보정 모델]** — `phase_calib.yml` (특징 → Y·Θ 모델). 없으면 QR 이동(t, s)만 표시합니다.
3. **[이미지 열기]** — 한 장 또는 여러 장(Ctrl/Shift) 선택. 결과는 아래 목록에 **추가**되고, 한 장이면 바로 오버레이 + 오른쪽 수치 패널에 표시
4. **[폴더 일괄]** — 폴더(하위 폴더 포함) 전체를 작업 스레드에서 측정 → 아래 목록. 진행 중에는 버튼이 **[중지]** 로 바뀝니다. 목록에서 행을 고르면 그 사진을 다시 보여 줍니다.
5. **[CSV 저장]** — 일괄 결과 저장 (UTF-8 BOM, 엑셀에서 바로 열림)
6. **[전체 분석]** — `image` 폴더 전체(center + Y + Θ + 2변수 사진)를 한 번에 측정 → 끝나면 `results\qr_yt_날짜_시각.csv` 와 같은 이름의 `.png` 를 자동 저장하고 **결과 그래프 창**을 띄움. 진행 중에는 [폴더 일괄] 버튼이 [중지] 로 바뀜
7. **[결과 그래프]** — 저장된 CSV(이 앱의 CSV 또는 QR_Image 의 phase_results.csv)를 골라 그래프 창 + PNG 저장
8. **QR 영역 확대** — QR 띠 주변만 크게 보기

시작할 때 작업 디렉터리(VS 디버깅 기본값 = 이 폴더)에서 `model\phase_calib.yml`, `image\center.bmp` 가 있으면 자동으로 불러옵니다.
파일·폴더 선택 창은 `image` 폴더에서 시작합니다. **[폴더 일괄] 에서 `image` 폴더를 고르면 Y 80장 + Θ 200장 전체를 검증**합니다.

### 오버레이

| 표시 | 의미 |
|---|---|
| 빨간 점선 | 기준 위치 (QR 별 측정 영역) |
| 초록 실선 | 측정 위치 (주황 = 품질 기준 미달) |
| 노란 화살표 | 이동 방향·크기 |
| 글자 | QR 별 가로 이동 t (px) |

### 정답 비교

파일 이름에서 정답을 정규식으로 읽어 오차와 판정을 표시합니다.

| 파일 이름 | 정답 |
|---|---|
| `Y + 1.00 T + 1.00 (3).bmp` (2변수, 공백·`(n)` 허용) | Y +1.00 mm, Θ +1.00° |
| `Y+1.05.bmp` | Y +1.05 mm, Θ 0 |
| `T-0.35.bmp` | Y 0, Θ −0.35° |
| `center.bmp` | 0, 0 |

목록 열 : 파일 | 정답 Y | 추정 Y | Y 오차 | 정답 Θ | 추정 Θ | Θ 오차 | 판정(OK / Y NG / Θ NG / Y·Θ NG) | 유효 QR | 시간
허용 오차는 `QR_OpenCV_CheckDlg.cpp` 맨 위 `TOL_Y_MM = 0.09`, `TOL_T_DEG = 0.01`.

## 결과 그래프 (모델 적합도)

| 위치 | 내용 | 보는 법 |
|---|---|---|
| 맨 위 표 | 전체 / center / Y only / Θ only / Y+Θ 별 Θ·Y 오차 RMS, 최대, 통과율 | 그룹별로 어디가 약한지 |
| ① | 추정 Θ vs 정답 Θ | 회색 대각선 위 = 정확 |
| ② | Θ 오차 vs 정답 Θ | 초록 띠(±0.01°) 안 = 통과, 기울어짐 = 배율(기울기) 오차 |
| ③ | Θ 오차 분포 | 중심이 0 에서 벗어남 = 편향 |
| ④ | 추정 Y vs 정답 Y | |
| ⑤ | Y 오차 vs 정답 Y | 초록 띠(±90 µm) |
| ⑥ | Y 오차 vs Θ 오차 | 강한 상관(약 −5.6 mm/°) = Y 오차가 Θ 오차에서 옴 |

점 색 : 회색 center, 파랑 Y only, 주황 Θ only, 초록 Y+Θ (2변수 파일)

## 파일

| 파일 | 내용 |
|---|---|
| `QR_OpenCV_CheckDlg.h/.cpp` | 화면·버튼·일괄 처리 스레드·목록·CSV |
| `ResultPlot.h` | 결과 그래프 그리기 (헤더만, OpenCV) |
| `MatView.h/.cpp` | `cv::Mat` 을 비율 유지로 그리는 Static 컨트롤 (더블 버퍼, StretchDIBits) |
| `cv_inc.h` | OpenCV 헤더 포함 시 Windows `min`/`max` 매크로 충돌 방지 |
| `core/phase_align.hpp/.cpp` | 측정 엔진 (QR_Image 프로젝트와 같은 코드, 미리 컴파일된 헤더 사용 안 함) |
| `image/` | 교보재 사진 (center.bmp, Y/, Theta/) |
| `results/` | [전체 분석] 결과 CSV·PNG (자동 생성) |
| `model/phase_calib.yml` | 2변수 [Y, Θ] 보정 모델 (교보재 281장으로 학습) |
| `_backup_wizard/` | 마법사가 만든 원본 파일 보관 |

## 주의

- `cv::imread` 는 한글 경로를 못 읽어서 파일을 바이트로 읽은 뒤 `cv::imdecode` 로 엽니다.
- 보정 모델 경로는 시스템 코드 페이지(CP949)로 변환해 읽습니다. 한글 외 특수 문자가 든 경로는 피하세요.
- 기준 이미지와 크기가 다른 사진은 측정하지 않습니다.
