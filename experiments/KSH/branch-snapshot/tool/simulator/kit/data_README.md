# data\img — 팀 공통 사진 데이터를 여기에 그대로 복사

팀원 모두 같은 데이터를 받았으므로 받은 폴더 구조 그대로 넣는다. 시뮬레이터가 하위 폴더까지 찾는다.

```
data\img\
├─ 1st\                 1차 (10/04) — 가상 장면을 만드는 사진
│  ├─ center.bmp
│  ├─ Y\     Y+0.05.bmp …
│  └─ Theta\ T+0.01.bmp …
├─ 2nd\                 2차 (10/15)
│  ├─ 기준 위치\  center1.bmp …
│  └─ Y+0.05 T+0.01\ …
└─ 3rd\                 3차 (선택, 합성 검증에서 validation.include_set3: 1)
```

- 세트는 폴더 이름(`1st`, `2nd`, `3rd`)으로 구분한다. 폴더 이름의 라벨이 파일 이름보다 우선한다
- **필요한 때** : [합성 검증], [파노라마 생성](가상 장면 다시 만들기)
- **필요 없는 때** : [1 단계], [자동 실행], [다회 시험] — 키트에 든 `world\` 를 씀
- 다른 위치의 데이터를 쓰려면 `config\simulator.yml` 의 `paths.data_dirs` 맨 앞에 경로를 넣는다
