# Retrain — 1~4차 전체 데이터 재학습 · 4차 데이터 진단 (2026-11-10)

보정식(s·d 다항식)을 1~4차 사진 719장으로 다시 학습하고, 차수·기준 센터·사분면 균형·반복 학습 횟수를 비교한 기록이다.
4차 세트(4개 사분면 등비 격자)의 데이터 문제와, 그 오차가 실제 폐루프 정렬 판정에 주는 영향도 함께 정리했다.

**배포 수식(`config/model_s1d1.yml`)은 바꾸지 않았다.** 새 수식은 `models/`에 후보로만 둔다.

## 결과 요약

| 실험 | 결과 |
|---|---|
| E0 재현 확인 | 기존 학습 240장으로 다시 맞추면 기존 계수가 그대로 나옴 (차이 ≤ 10⁻⁷). 3차 234/234·228/234, 4차 109/143 재현 |
| E1 전체 재학습 (s·d Θ 차수 1~3, 9개 조합) | 셀프 테스트 명세 통과 : 기존 s1d1 665 → 새 s1d1 692 → 새 s3d2 700 / 714장. 세트 단위 제외 검증(LOSO)은 9개 조합 모두 668~675장. 고차식은 Θ 2°처럼 범위 밖에서 크게 틀림. 지표를 고르게 만족하는 조합은 **s1d2** |
| E2 기존 수식 대비 | 기울기 계수 0.1~3.4% 변화, 상수항 s −0.070 px · d −0.028 px. 목표 근처(\|Y\| ≤ 0.5 mm, \|Θ\| ≤ 0.2°) 183장은 LOSO 167~168장으로 기존(169장)과 차이 없음 |
| E3 상수항 기준 (센터 1장 vs 4장 평균) | 상수항을 센터 특징으로 고정하면 크게 나빠짐 (1차식 347~564장). 고정한다면 4장 평균이 단일보다 나음. 상수항을 자유롭게 맞추면 센터 선택 무관. 최선은 세트마다 같은 날 센터 (692장). 날짜가 다른 센터끼리 Y 약 90~105 µm 차이 |
| E4 사분면 균일 vs 전체(Q1 편향) | 2~4사분면 데이터 유무의 차이는 큼 (Q2~Q4 명세 83% → 95%). 이미 사분면마다 35장 이상인 지금은 균일하게 맞춰도 ±1%p 이내 |
| E5 반복 학습 횟수 | 최소제곱이라 1·3·10회 학습한 계수는 완전히 같음. 부트스트랩 200회(Efron & Tibshirani)는 계수 흔들림을 1회의 약 1/15로 줄이나 같은 값으로 수렴. 10겹×10 교차검증(Bouckaert & Frank 2004)은 정확도 추정 편차를 1/3로 줄임 |
| E6 기존 보고 수치 대조 | 모두 일치. 데이터 문제 3건 (아래) |
| 4차 데이터 진단 | 측정은 정상 (144/144, 묶음 안 잡음 Y 3.4 µm · Θ 0.0022°). 문제는 같은 날 기준 사진 없음 + 장비 배치 변화, 로봇 Y·Θ 이력(백래시) 의존 위치 오차 (묶음 간 Y σ 19 µm, Θ 0.004~0.006°), 이상 사진 1장, 1장씩 촬영·모터 값 없음 |
| E7 폐루프 영향 (몬테카를로, `loopsim.py`) | 측정 잡음·수식 배율 오차·로봇 백래시는 이동 횟수만 늘림 (1.23 → 1.5~1.9회), 명세 통과 100% 유지. **기준 사진이 측정 시점과 맞지 않으면** 판정 자체가 틀림 (다른 날 기준 : 명세 95% → 0%) |

## 데이터 문제 (원본은 수정하지 않음)

1. `QR_Image\QR_Image\img`(1·2·4차를 한 폴더로 합침)에 3차 234장이 없음 → `data/img/3rd` 사용. 3차를 같은 폴더에 합치면 2차와 이름이 겹침 (예 `Y+0.05 T+0.10 (1).bmp`)
2. `3rd/Y+0.05 T+0.32/` 안의 세 번째 사진 이름이 `Y+0.05 T+0.33 (3).bmp` → 폴더 라벨(모터 값 T −1.350 = +0.32°)로 처리
3. `4th/Y-0.8 T-0.96.bmp` : 추정 Θ +0.72°, +0.96° 줄 촬영 도중(101분)에 저장됨 → 학습·평가 제외, 재촬영 필요
