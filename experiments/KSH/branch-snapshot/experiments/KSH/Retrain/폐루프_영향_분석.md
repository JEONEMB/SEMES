# E7 : 4차에서 잰 오차가 실제 폐루프 정렬 판정에 주는 영향

`code/loopsim.py`, 결과 `data/E7_loop.json` (조건마다 20,000회, 2026-11-10)

## 가정

- 루프 : 사진 → 추정 → (−Y, −Θ) 이동 → 다시 사진. 추정이 Y ±45 µm · Θ ±0.005° 안이면 멈춤 (`config/alignment.yml` `tolerance`), 최대 20회
- 출발 : Y ±1 mm · Θ ±0.5° 무작위, 직전 이동 방향 무작위 (백래시 이력 모름)
- 로봇 반복 정밀도 σ Y 7.5 µm · Θ 0.002° (기존 시뮬레이터 실측값), 백래시 = 방향을 바꿀 때 처음 b만큼 움직이지 않음
- Python 단순 모델 (MFC 시뮬레이터 결과 아님)

## 결론

- 측정 잡음 · 수식 배율 오차 · 로봇 백래시 : 이동 횟수만 늘고 판정은 그대로 (판정은 마지막 사진의 추정값으로 하므로)
- **기준 사진과 측정 시점의 불일치** : 알고리즘이 볼 수 없는 치우침이라 "정렬 완료"로 잘못 판정 → 티칭 직전에 기준 사진을 찍고(`alignment_set_reference`), 카메라를 건드리면 다시 찍는다
- 별도 확인 : 기준 사진 자체는 Y +36 µm로 읽힘 (보정식 상수항) → 목표가 "기준 사진 화면"인지 "지령 0"인지 SEMES와 결정 필요
