## 1. 요약

| 항목 | 내용 |
|---|---|
| 가설 (H2) | QR 3개를 포함한 띠 전체를 ECC 정합 한 번으로 맞추면, 원근 성분을 약 700 px의 긴 기준선에서 추정해 Θ 측정 잡음이 위상 방식(QR별 약 200 px)보다 작아진다 |
| 판정 | **기각** — 1차 세트 검증 Θ RMS가 위상 방식과 같거나 나쁨 (Θ 스윕 0.0184° → 0.0271°), ±0.01° 통과율도 늘지 않음 |
| 얻은 것 | 다른 날·Y·Θ 동시 이동 데이터(2차 세트)에서는 ECC 계열이 위상 방식보다 일반화가 좋음 (Θ RMS 0.052° → OpenCV 호모그래피 0.023°) |
| 핵심 발견 | 같은 자세 연속 촬영의 Θ 반복성은 σ ≈ 0.003°로 **측정 자체는 0.01°를 낼 수 있음**. 0.01°를 막는 것은 이동마다 생기는 자세 차와 모델 계통 오차 |

Θ 허용 오차는 사진마다 **±0.01°** 기준입니다.

## 3. 실험 진행 방법

### 3.1 데이터

| 세트 | 구성 | 용도 |
|---|---|---|
| 1차 세트 | `img/center.bmp` 기준, Y ±2 mm(0.05 mm 간격) 80장 + Θ ±1°(0.01° 간격) 200장. 한 축씩만 이동, 반복 촬영 없음 | 학습(값 순서로 짝수 번째 140장)과 검증(홀수 번째 140장) |
| 2차 세트 | `img/일부 데이터 추출/` — 기준 `center1~3.bmp` + Y·Θ 동시 이동 19개 조합 × 3장. 다른 날 촬영, Θ 최대 2°(1차 학습 범위 밖) | 1차 세트 모델을 **그대로** 적용해 일반화 검증, 같은 자세 3장 반복성 |

- 사진은 저장소에 올리지 않습니다 (`img/`는 gitignore 대상). 위치는 `img/DATA.md` 기준입니다.
- 2차 세트의 txt(모터 값)는 촬영마다 기록된 값이 아니라 같은 값을 복사한 것으로 보여, **연속 촬영인지 다시 이동해 찍었는지를 영상 내용으로 판정**했습니다 (`H2_결과.md` 3절).

### 3.2 측정 절차 (영상 한 장)

1. **거친 단계** — 기준 띠와 현재 띠를 `phaseCorrelate`로 맞춰 정수 수준 이동을 구합니다 (Θ 2° ≈ 160 px 이동도 처리).
2. **정밀 단계** — QR 3개를 포함한 띠에서 QR 영역 마스크만 사용해 정합합니다. 방법은 두 가지를 비교했습니다.

   | method | 이름 | 워프 | 특징 |
   |---|---|---|---|
   | 1 (기본) | 심화 ECC | 원근 다항 워프 9개 매개변수 `u = p0 + p1·x̂ + p2·x̂² + p3·ŷ + p4·x̂ŷ`, `v = p5 + p6·ŷ + p7·x̂ + p8·x̂ŷ` | ECC와 같은 ZNCC 기준을 double 정밀도 쌍삼차 보간 + 해석적 미분 Gauss-Newton으로 최적화 |
   | 0 (비교) | OpenCV ECC | 호모그래피 (`findTransformECC`) | 내부 보간 양자화로 작은 이동에서 배율 값이 0.005~0.01 흔들림 |

3. **특징** — 워프에서 QR 3개 중심의 가로 이동 t(px)와 가로 배율 s(px/100px)를 계산합니다: `f = [tL, sL, tC, sC, tR, sR]`. 위상 방식과 같은 특징이라 결과를 바로 비교할 수 있습니다.
4. **추정** — `f = a·Y + b·Θ + q·Θ² + c`와 잡음 공분산 Σ로 일반화 최소제곱(Gauss-Newton). 비교를 위해 Θ² 항이 없는 **선형 모델**도 함께 학습했습니다.

### 3.3 평가 절차

1. 1차 세트 280장을 측정하고 짝수 번째 140장으로 모델(Θ², 선형)을 학습합니다.
2. 학습에 쓰지 않은 홀수 번째 140장으로 Y 스윕·Θ 스윕별 Θ·Y 오차(RMS, 최대, 평균, ±0.01° 통과 수)를 구합니다.
3. 2차 세트는 기준 영상을 `center1.bmp`로 바꾸고, 1차 세트 모델을 다시 학습하지 않고 그대로 적용합니다. Θ 구간(≤0.2°, 1°, 2°)별로 나눠 봅니다.
4. 2차 세트의 같은 자세 3장 묶음(19개 자세)으로 반복성(σ)을 구합니다.
5. 같은 절차를 method 0(OpenCV 호모그래피)으로 한 번 더 실행해 `results/h2_ecc_opencv/`에 저장합니다.

### 3.4 판정 기준 (실험 전에 정함)

1. 1차 세트 검증 Θ RMS가 위상 방식(0.018~0.020°)보다 작을 것
2. 사진마다 |Θ 오차| ≤ 0.01° 통과율이 위상 방식보다 높을 것
3. 2차 세트(다른 날, Y·Θ 동시 이동)에서도 성능 유지
4. 같은 자세 반복성 확인, 처리 시간이 MFC에서 쓸 수 있는 수준

## 4. 결과 요약

ECC 수치는 커밋된 결과 CSV로 다시 계산해 `H2_결과.md`·`h2_summary.txt`와 일치함을 확인했습니다. 위상(Gabor) 1차 세트 수치는 `Hypothesis_1` 결과 CSV로 확인한 값이고, 위상 방식의 2차 세트 수치(0.0516°)는 `H2_결과.md` 기재값입니다 (위상 방식의 2차 세트 결과 파일은 이 폴더에 없음).

### 4.1 1차 세트 검증 (홀수 번째 140장, Θ² 모델)

| 방법 | Y 스윕 (40장) Θ RMS / ±0.01° 통과 | Θ 스윕 (100장) Θ RMS / ±0.01° 통과 | Y RMS (Y / Θ 스윕) |
|---|---|---|---|
| 위상(Gabor) 기준선 | 0.0202° / 13 | **0.0184° / 42** | 111.7 / 102.1 µm |
| 심화 ECC (method 1) | 0.0200° / 12 | 0.0271° / 27 | 112.0 / 152.2 µm |
| OpenCV ECC (method 0) | 0.0195° / 15 | 0.0273° / 28 | 114.4 / 152.5 µm |

→ 판정 기준 1·2 불만족. Θ 스윕에서는 위상 방식보다 나쁩니다.

### 4.2 2차 세트 (center 제외 57장, 1차 세트 모델 그대로)

| 방법 | Θ RMS (평균 편향) | ±0.01° 통과 |
|---|---|---|
| 위상(Gabor) | 0.0516° (+0.042) | — |
| 심화 ECC, Θ² 모델 | 0.0601° (+0.038) | 12/57 |
| 심화 ECC, 선형 모델 | 0.0346° (+0.023) | 8/57 |
| OpenCV ECC, Θ² 모델 | **0.0227° (+0.009)** | 17/57 |

→ 다른 날·동시 이동 데이터에서는 OpenCV 호모그래피가 가장 좋고, 특히 Θ 1~2°에서 치우침이 작습니다. 심화 ECC의 큰 Θ 오차는 다항 워프(원근 근사)의 한계로 해석됩니다 (`H2_결과.md` 4-2).

### 4.3 반복성과 특징 잡음

- 같은 자세 **연속 촬영**(이동 없음) 구간: Θ σ 0.003° — 측정 자체는 0.01° 기준을 만족
- 같은 자세 3장 묶음 전체(대부분 **매번 다시 이동**해 촬영): Θ σ 0.016°(심화 ECC) / 0.018°(OpenCV) — 접근 방향에 따른 실제 자세 차가 섞임
- QR별 배율 잡음은 위상 방식 0.012 → 심화 ECC 0.003~0.006으로 줄었지만, Θ 단서(곡률·배율 차)가 같은 워프 항에서 나와 Θ 잡음은 줄지 않음

## 5. 확인 범위와 주의 사항

- **처리 시간 표기가 서로 다릅니다.** `H2_결과.md`는 심화 ECC를 "약 80 ms/장 (측정만, -O2)"로 적었지만, 결과 CSV의 `ms` 열 평균은 약 270~320 ms(OpenCV 방법은 약 1.2~1.5 s)이고 `main.cpp` 주석도 "장당 수백 ms"입니다. 빌드 구성(Debug/Release)이나 측정 범위가 달랐을 가능성이 있으며 확인하지 않았습니다.
- **`results/h2_ecc/h2_summary.txt`는 글자가 깨져 있습니다.** UTF-8로도 CP949로도 읽히지 않습니다. 같은 수치는 `H2_결과.md`에 있고, `h2_ecc_opencv/h2_summary.txt`는 정상(UTF-8)입니다. 다시 실행해 만들면 바로잡을 수 있습니다.
- 2차 세트는 57장(자세 19개)으로 작고, Θ 1°·2° 구간은 각 12장입니다. center2·3 비교는 2장뿐입니다.
- 1차 세트 학습·검증은 이웃한 값을 짝수/홀수로 나눈 분할이라 보간 성능에 가깝습니다. 2차 세트가 실제 일반화 성능에 더 가깝습니다.
- 실행 환경(OS, 컴파일러, 빌드 구성)은 결과 파일에 기록되어 있지 않습니다. 코드는 OpenCV 3.4.15 함수만 사용하고, 한글 경로를 위해 C++17 `std::filesystem`을 씁니다.

1. 심화 ECC의 Gauss-Newton에 **완전 호모그래피(8 매개변수) 워프** 적용 — OpenCV의 큰 Θ 정확도와 심화 ECC의 낮은 잡음·속도를 함께 얻는지 시험 (새 데이터 없이 가능)

4. SEMES 확인: 촬영 시 접근 방향, 백래시 보정 여부, txt 값이 지령값인지 엔코더 값인지
5. MFC 앱에 `ecc_align` 엔진과 `ecc_model.yml` 적용
