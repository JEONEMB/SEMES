# M3 — 샘플링 모아레 / 격자법 (적용 가능성 판정)

> 코드 : `code/yt/m3_grid.hpp/.cpp` · 결과 : `results/verify/M3_grid/` · 논문 : Ri 2010 (샘플링 모아레), Grédiac 2016 (격자법)

## 1. 목적
격자법은 간격이 일정한 무늬에서 10⁻⁴ px 급 변위와 10⁻⁶ 급 변형률을 잽니다. 두 가지를 확인합니다.
1. 구현이 제대로 동작하는가.
2. 이 QR 또는 배경에 쓸 수 있는가.

## 2. 수행 방법
1. **샘플링 모아레** : 각 행을 피치 p 간격으로 솎아(시작점 k = 0..p−1) 선형 보간해 모아레 p 장을 만듭니다.
   - 위상 이동법으로 위상 φ 를 구합니다.
   - 변위는 u = −p·Δφ/2π, 변형률은 위상 차의 x 기울기로 구합니다.
2. **주기성 점수** : 행마다 Hann 창 FFT 파워를 평균한 뒤 (최대 봉우리 / 중앙값) 을 냅니다. 합성 격자 점수의 10 % 이상이면 격자로 봅니다.
3. 화면 전체를 128 px 타일로 훑어 격자처럼 쓸 수 있는 배경이 있는지 찾습니다 (`m3_tile_periodicity.png`).
4. QR 에 억지로 적용(피치 18)해 M1 과 비교합니다.

## 3. 검증 절차와 기준
| 단계 | 내용 | 통과 기준 |
|---|---|---|
| V3-1 | 합성 격자 (피치 10 px, 잡음 σ 0.7) | 변위 RMS ≤ 0.01 px, 변형률 오차 ≤ 2e-5 |
| V3-2 | QR·배경의 주기성 | 판정만 함 (구현 통과 여부와 무관) |
| V3-3 | QR 에 억지 적용 vs M1 | 기록만 함 |

## 4. 결과
| 항목 | 값 |
|---|---|
| 격자 변위 오차 | RMS 0.0001 px ✅ |
| 격자 변형률 오차 | 최대 3.1e-6 ✅ |
| 주기성 : 합성 격자 / QR_L·C·R | 496416 / 19.7 · 21.5 · 18.8 |
| 배경 최고 타일 | (2048, 1728) 점수 1055 — 아래쪽 브래킷 모서리, 격자 아님 |
| QR 억지 적용 vs M1 | 차이 RMS 0.021 px (이동은 읽히지만 이점 없음) |

**종합 : 구현 통과 / 이 데이터에는 적용 불가.** QR 모듈 배치는 무작위라 단일 주기 봉우리가 없습니다. 격자 점수의 0.004 % 수준입니다. 위상으로 읽는 원리는 M4 Gabor 가 대신합니다. M3 는 트랙 A·B 에 쓰지 않습니다.
