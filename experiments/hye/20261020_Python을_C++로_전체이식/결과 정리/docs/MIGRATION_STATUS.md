## 수치 차이와 비교의 한계

- 초기84점 C++ 추적은 저장 관측과 dx최대0.0038682px/dy0.0064014px 차이가 남는다. detector와 snapshot 모드를 구분하며 완료 체크를 보류한다.
- affine은 OpenCV3와4를 분리 실행해도 기존 CSV와 최대0.036315918px 차이가 남았다. 라이브러리 버전 원인으로 단정하지 않는다. 생성 중 CSV를 조기 대조했던 실패 실행도 무효 사유를 붙여 보존했다.
- OpenCV4.11 소스 빌드로 ArUco 의존성을 해결했다. QR 측정은 대조 통과했지만 ECC 튜닝은7설정×68행 실패0.10월12일 Claude 로그에서 코드 내용이 일치하는4자리 출력을 복구했으나 잡음 최대차0.00712078이 남는다. 당시NPZ·런타임은 별도 미동결이므로 동등성 완료를 표시하지 않는다.
- native G1은 원본과 T최대2.56e-5/Y1.45e-4 차이다. 이식 허용차와 사후 선택 시점을 별도 기록했다. 원본 홀짝 분할·학습 평균 템플릿을 유지한 개발자료 재현이며 독립 성능 검증이 아니다.
- 그림 입력에서 사라진 임시 pickle은 기존 Excel 판정280개와 C++ 판정의 일치를 확인해 대체했다. 원점 부근2행의 center 포함/제외 보간 차이는 숨기지 않고 그림의 기존 center 제외 방식을 유지했다.
