최초 동결 목록은 `inventory_20261022_01`의359개 소스다. `inventory_20261022_02`에서 확인한 추가25개와 변경 중이던 기존 소스1개는 `concurrent_changes_001`에 분리했다. 첫 목록 자체를 나중 자료로 덮어쓰지 않는다.

최신 파일별 체크는 [전체 파일 목록](../../실험%20방법/전체_파일_목록.md)에 있다. `catalogue_004/migration_ledger.json` 등 앞선 원장은 당시 기록으로 보존한다. `inventory_20261023_01`은21,614파일·소스444개를 추가 기록했다. 상태 근거는 `../config/port_progress.json`에, 전체 범위와 남은 작업은 [진행 상태](../docs/MIGRATION_STATUS.md)에 기록한다.

## 실행 기록 읽는 방법

각 결과의 `created_kst`는 이번 C++ 실행·비교 시각이다. `checks.json`과 `audit.json`은 숫자 대조·입력 해시·도구 버전·실패를 담는다. `_001`에서 실패하거나 경로를 잘못 짝지은 결과도 삭제하지 않으며 수정 실행은 `_002`처럼 새 폴더를 쓴다.

원본 저장 관측에서 계산을 재현한 결과와 실제 사진을 C++로 다시 측정한 결과는 다른 폴더에 둔다. 과거의 홀짝 분할·전체 자료 보정은 현재 고정4fold 평가로 바꾸어 표시하지 않는다. 알고리즘 규칙은 루트 `ALGORITHM_RULES.md`를 따른다.
