## 해석

- 통과율은 바를 빼도 같거나 낫다. A 는 처음 보는 날 99.70% 로 같고 폴드 탈락이 7.7 → 6.1 장으로 준다. B 는 폴드 탈락 16.9 → 9.0 장, 공통 시험 99.04 → 99.73% 로 좋아진다.
- 바가 주는 것은 T 정보 조금이다. 바를 빼면 σT 가 0.1~0.4 mdeg 커지고 σY 는 줄어든다. 정답 잡음(σT 약 4.2 mdeg)에 견주면 작다.
- B 에서 바가 오히려 해가 되는 것은, 두 날 사이에 바 기울기가 날마다 달라지는 몫(카메라 처짐 등)이 있고 모델이 그것을 Y·T 로 읽기 때문으로 보인다(측정 기준을 옮길 때 바 기울기 차이 위 −0.10, 아래 +0.07). 바를 쓰는 B 의 출력은 바를 뺀 것과 일부 사진에서 T 14 mdeg 까지 다르다.
- SEMES 보고서에서도 바 기울기를 빼도 성적이 같았다(탈락 0.0 대 0.1 장).
- 바를 빼면 덤으로: 바 측정 실패(11-13 아침 1698장 모두 거부된 원인)가 없어지고, 기준 다시 잡기에서 바 칸 찾기가 필요 없어지며, 1.5 ms 빨라진다.

## 한계

- 정답이 영상 값과 명령에서 만든 라벨이라 σT 0.1~0.4 mdeg 차이가 실제로 의미 있는지는 이 자료로 가를 수 없다.
- 바가 T 를 돕는다면 나사가 가려지거나 흐릴 때일 수 있으나 그런 사진은 없다.
- Python 분석이다. 학습식은 C++ 과 같은 값을 내는 것을 앞 실험에서 확인했다.
