# 평가 계획 — 실행 전 고정

- 목적: 기존 QR536 control에 허용된 가로선 관측을 더했을 때 오차와 처리 시간의 변화 확인. 기존 최종 control/joint 파일은 수정하지 않는다.
- 네 조건: QR12 / QR12+위24 / QR12+아래24 / QR12+위24+아래24.
- 측정: 최종 control의 Tracker를 재사용. 선은 기존 joint의 좁은64×49px 마스크48개와 profile matcher만 재사용한다. QR ECC나 전체 joint 측정을 추가하지 않는다. 각 관측은 동일 고정센터 측정값을 차감한다.
- 학습: 기존 control과 같은 축별 공유2차식+학습세션별6절편, 공분산 축소0.05. 모든 조건에 같은 값을 사용하며 결과를 보고 튜닝하지 않는다. whitening은 고유값분해로 동일 Mahalanobis 비용을 구현한다.
- 주 평가: 기존 고정4-fold(학습210/시험70), 합계280장. 모델의 절편·응답·곡률·공분산은 학습 사진에서만 계산한다. 시험 사진의 세션/축/정답은 후보 선택에 전달하지 않는다.
- 별도 지표: T=0인 Y80장, Y=0인 T200장, 전체280장. Y/T 평균·최대오차, 두 축 모두0.09 통과 수/율, 축·부호 구분 수, 측정 실패 수.
- 재대입은 별도 표기한다. QR만 재학습한 모델이 기존 최종 QR 모델과 추정량차1e-6 이하/축 일치인지 대조해 학습식 구현을 검증한다.
- 20261020의60장(센터3+혼합57)은280장 전수 모델을 적용한 날짜 간 참고 평가다. 이미 개발에 노출됐으며 혼합 자세는 Y-or-T 전제 밖이다. 2차 T정렬 후 실측을 대신하지 않는다.
- 실패는 분모에 포함한다. 학습 관측 실패가 있으면 사진을 몰래 빼지 않고 실행 실패로 공개한다.
- 속도: Release, MSVCv141/OpenCV3.4.15, CPU1스레드. 초기화 시간을 분리한다. 기존 Y/T에서각16장+20261020의16장, 결정적 균등 간격으로48장을 선정, 예열 후3회 반복한다. 위/아래와 후보 모델 호출 순서를 번갈아 실행한다.
- 공통 QR 측정을 한 번씩 실행하고 조건별 선 측정과 예측 비용을 더한 paired component timing이다. 조건당144개 표본의 중앙값/p95를 보고한다. 디코딩 포함/제외를 나누고 로봇 이동·카메라 촬영·네트워크 시간은 포함하지 않는다.
- 전제: 기존 자료는 개발 자료다. 선 추가 실험 성적을 독립 신규 사진 성능이나 실제 순차 제어 성적으로 표현하지 않는다. 네 조건 결과와 실패를 모두 보존하며 최종 모듈 자동 교체는 하지 않는다.
