# 결과: 전체 630점 직접 1260차원 SVD 축소 4-fold

입력: `data/clean/clean_20261014` 281장 (center 1, T 200, Y 80). center.bmp 의 630 구조점에서 QR마다 패치를 잘라 LK15로 시작하고 GN으로 정밀화한 이동을 다시 측정했다 (옛 측정 파일을 읽지 않는다).

측정 3종: gn17 = GN(창 17, 흐림 0.8), gn31 = GN(창 31), huber6 = GN17에 화소 Huber(delta 6) IRLS 2회. 630점 dx, dy를 그대로 1260차원 특징으로 쓴다.
축마다 [v] 또는 [v, v^2]와 시행 절편을 최소제곱으로 맞추고, 잔차를 열마다 RMS로 나눈 R/sqrt(n)의 SVD로 공분산 alpha I + (1-alpha) R^T R 의 역제곱근을 만들어 백색화한다. SVD는 R R^T(학습 장수 크기)의 고유분해로 같은 특이값·벡터를 얻었다.

분할: 바깥 4-fold (StratifiedKFold 4, 시행 6개로 층화, seed 20261021, 학습 210 / 시험 70), 안쪽 3-fold (seed 100+fold). 안쪽 성적(실패 수, Y·T 최대 오차, 설정 번호 순)이 가장 좋은 설정을 바깥 시험에 쓴 것이 내부 선택 OOF다.
