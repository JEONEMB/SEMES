# 격자 증강으로만 학습, 실측은 평가만

- 상태: **실험 (미채택)**. 채택 모듈과 `selected_modules.cmake`는 바꾸지 않았다.
- 계획: [PROTOCOL.md](../실험%20방법/PROTOCOL.md) (실행 전 고정)
- 코드: [run.py](../실험%20방법/run.py) (빠른 검증용 Python, 팀 전달 코드 아님). 실행 `python -I run.py` → `results/`
- 입력: [20261028_211553 증강 실험](../../20261028_211553_YT증강_점별변위_결합항/결과%20정리/README.md)의 `inputs/module_features` (채택 C++ 모듈이 실측 341장에서 뽑은 특징)
- 앞선 시도 [20261029_095521](../../20261029_095521_증강학습_실측평가/결과%20정리/README.md)은 샘플 간격을 임의로 바꿔(joint 연속 균등, control 0.002) 만들었다. 이번은 어제 정한 명령 격자(Y 0.05, T 0.01) 그대로다.

**결론: 격자대로 다시 해도 결과는 앞선 시도와 거의 같다. 1014 안에서는 증강 학습이 실측 학습과 같은 성적(joint, control 모두 280/280)을 낸다. 1014만으로 만든 증강은 새 날짜(1020)의 영점 이동을 담지 못해 joint가 1020 센터를 Y +0.15로 읽는다(0/3). 증강 학습 joint는 1020 혼합에서 흩어짐이 절반이지만 치우침이 두 배라 통과는 더 적다.**

## 무엇을 했나

- 증강: 영점 11개(1014 센터, trial S1~S6, 주성분 ±2σ 4개) x 명령 격자 16,281점 x 잡음 3 = joint 537,273개. control은 단일축 모델이라 같은 격자의 축 위 점만, 세션 규칙대로 840개. 명령값 사이는 따로 만들지 않고 잡음(1014 반응식 잔차)으로만 흔들린다.
- \|T\| > 1은 쓰지 않았다. 1020 T = 2 혼합 12장은 평가에서 뺐다 (`summary.json`의 `excluded_abs_T_gt_1`).
- A. 1014 겹 바깥: 시험 겹을 뺀 1014 사진으로 생성기와 실측 모델을 만들고, 1014 단일축 280장을 4겹으로 평가.
- B. 1020 새 날짜: 1014 281장만으로 만들고 1020 48장(센터 3, 혼합 T ≤ 1 45)에 적용. 1020은 생성기, 잡음, 영점, 학습 어디에도 쓰지 않았다.

- control 1020 혼합은 Y 또는 T 하나만 내는 모델의 전제 밖이다. 숫자로는 실측, 증강 모두 18/45인데, 남은 축이 0.09보다 작은 자세(T 0.01~0.02, 또는 Y 0.05)에서만 통과한 것이다.
- control 실측 학습(B)은 학습 사진이 동결 모델과 같아(1014 280장) 결과가 같다.
- control 증강 학습은 1014 안에서 실측 학습과 거의 같다(Y 최대 0.0368 → 0.0359). 증강이 실측 반응식 위 같은 점을 다시 뽑기 때문이다. 1020 센터 Y 오차는 더 작았지만(0.0062 → 0.0019) 3장뿐이라 근거로 쓰지 않는다.

| 모델 | 1020 센터 Y 치우침 | 1020 혼합 Y 치우침 (표준편차) | 1020 혼합 T 치우침 |

- 1014만 본 두 모델 모두 1020 센터를 Y +0.15로 읽는다. 날짜 영점 이동이고, 1014 영점 11개로는 덮지 못했다.
- 증강 학습은 Y x T 조합에서의 흩어짐을 절반으로 줄였지만(0.107 → 0.058) 치우침은 그대로 남거나 더 커졌다.

## 학습기 확인

앞선 시도와 같다. control 재학습은 채택 `model.json`과 세션 계수 최대 차 2.4e-8, 341장 축 일치 341/341. joint 학습기는 원래 코드가 없어 다시 만든 것이라 동결 모델과 같지 않다(341장 전수 학습 재대입 338/341, 동결 341/341). 그래서 같은 학습기의 실측 모델과 증강 모델을 비교한다.
