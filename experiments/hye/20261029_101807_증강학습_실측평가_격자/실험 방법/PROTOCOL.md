# 실행 전 고정한 계획: 격자 증강으로만 학습, 실측은 평가만

- 상태: 실험 (채택 모듈은 바꾸지 않는다)
- 앞선 시도 [20261029_095521](../../20261029_095521_증강학습_실측평가/결과%20정리/README.md)와 같은 질문이다. 그 실험은 샘플을 연속 균등(joint)과 0.002 간격(control)으로 임의로 바꿔 만들어서, 이번에는 어제 정한 격자 방식 그대로 다시 한다.
- 질문: joint와 control을 **증강 자료로만** 학습하면, 실측 사진으로 학습한 같은 모델보다 실측 사진에서 나은가?

## 평가

| 평가 | 평가 사진 | 생성기와 실측 학습에 쓴 사진 |

| B. 1020 새 날짜 | 1020 센터 3장, 혼합 T ≤ 1 45장 | 1014 281장 전체 |

## 모델 (모듈마다)

- 실측: 위 표의 실측 사진으로 학습
- 증강: 같은 사진으로 맞춘 생성기의 격자 샘플만으로 학습
  - joint: 영점 11 x 16,281점 x 3 = 537,273개
  - control: Y-or-T 단일축 모델이라 같은 격자의 축 위 점(T = 0 줄, Y = 0 줄)만 쓴다. 세션은 실측 규칙대로 Y 0.1 배수 ±는 Y1± (영점 S1, S2), Y 0.05 홀수 배 ±는 Y2± (S5, S6), T ±는 T± (S3, S4). 점마다 잡음 표본 3개.
- 참고: 채택 동결 모델 (평가 사진을 학습에 썼으므로 재대입)

학습기는 앞선 시도와 같다 (joint: 선형 전방식 + 0.01 축소 GLS, 원래 학습 코드가 없어 다시 만든 것. control: `train_yort` 이식, 채택 모델 재현 확인). joint 증강은 행이 많아 정규방정식을 나눠 쌓는다 (수식은 같다).

## 채점

- 두 축 동시 통과: |Y 오차| ≤ 0.09 이고 |T 오차| ≤ 0.09. Y, T 평균, 최대 절대오차. joint는 1020에서 치우침(평균 오차)과 흩어짐도 본다.
- control은 Y 또는 T 하나만 내므로 1020 혼합 통과는 전제 밖이다. 숫자 대신 "전제 밖"으로 적고, 남은 축이 0.09 이내인 사진에서만 통과한 것임을 함께 쓴다.
- 결과를 본 뒤 격자, 샘플 수, 영점, 잡음, 축소값, 분할을 바꾸지 않는다. 시드 20261029.
