# B1 실험 계획서 — 정지 대기 시간과 날짜 영점

가설: **H12**(세션 영점), **H14**(시간·온도 드리프트) · 상태: **촬영 대기**
작성: 2026-11-02 · 선행: [A1](../20261102_125341_A1_반복잡음과세션영점_공분산과유효점수/결과/보고서.md)

## 1. 묻는 것

이동이 끝난 뒤 **얼마나 기다렸다 찍어야** 판이 멈춘 상태인가? 그리고 **날짜가 바뀌면 영점이 움직이는가?**

## 2. 왜 기존 자료로 안 되는가

A1이 밝힌 것.

| 사실 | 값 | 뜻 |
|---|---|---|
| 점 측정 잡음 | 0.0087 px | 측정은 충분히 좋다 |
| 반복 3장 사이 판 이동 SD (dx) | **0.0852 px** | 측정의 10배. 반복 사이에 판이 실제로 움직였다 |
| 1014 → 1020 세로 영점 차 | **0.4423 px** (세션 내 변동의 81배) | 날짜 사이에 무언가 바뀌었다 |

**그런데 기존 자료에는 촬영 시각도, 정지 후 대기 시간도, 온도도 기록이 없다.** 반복 3장 사이에 로봇을 다시 움직였는지조차 모른다. 그래서 위 0.0852 px가 재현 오차인지 드리프트인지 가를 수 없다.

또 **같은 명령을 두 날짜에 찍은 자료가 사실상 없다.** 1014 center와 1020 기준 위치만 둘 다 (0,0)이고, 1020과 1029 사이에는 겹치는 명령이 하나도 없다(1029는 1020의 T+0.10을 건너뛰었다).

## 3. 촬영 요청

### 3.1 대기 시간 스윕

| 항목 | 값 |
|---|---|
| 시작 자세 | center (Y=0, T=0) |
| 이동 | center에서 Y+0.50으로 이동한 뒤 center로 복귀 |
| 복귀 후 대기 | **0, 0.5, 1, 2, 5 초** 5수준 |
| 수준마다 | 10장 연속 촬영 |
| 같은 날 반복 | 3회 (오전, 오후, 저녁 권장) |
| 다른 날 | 1회 더 (같은 절차) |
| **합계** | 5 × 10 × (3 + 1) = **200장** |

### 3.2 함께 기록해 주실 것 (사진마다)

| 항목 | 형식 | 왜 |
|---|---|---|
| 촬영 시각 | YYYY-MM-DD HH:MM:SS | 드리프트 분리 |
| 정지 후 경과 시간 | 초 | 대기 시간 효과 |
| 직전 이동의 방향과 크기 | 예: Y −0.50 | 접근 이력 (B2와 연결) |
| 장비 온도 | 가능하면 | H14 |
| 전원 켜고 경과한 시간 | 가능하면 | 예열 효과 |

기록은 사진 옆 TXT나 CSV 한 장이면 된다. **파일명에 명령값을 넣는 기존 방식은 그대로 유지**해 주시면 기존 도구를 그대로 쓸 수 있다.

## 4. 판정 기준 (촬영 전 고정)

| 조건 | 판정 |
|---|---|
| 대기 0초와 5초의 판 위치 차가 세션 내 SD의 3배 초과 | 대기 시간이 필요하다. 최소 대기를 그 곡선에서 정한다 |
| 날짜 간 center 차이가 세션 내 SD의 3배 초과 그리고 Y 환산 또는 T 환산 > 0.015 | **H12 성립.** 매 티칭 시 center 재촬영을 설계 1순위로 |
| 같은 날 3회 사이의 차이가 날짜 간 차이와 비슷 | 날짜가 아니라 **세션**이 변수다 |
| 시각에 따라 단조 변화 | **H14 성립.** 온도·예열 보정 검토 |

## 5. 분석 방법 (코드 준비 완료)

A1의 코드를 그대로 쓴다. `measure_noise`와 판 평행이동 계산이 이미 있다. 새 자료를 `data/clean/clean_<날짜>/`에 같은 형식으로 넣으면 A0 캐시 생성부터 동일하게 돈다.

## 6. 우선순위

**B1을 가장 먼저 요청한다.** 이유는 세 가지다.

1. A1이 "반복 사이 판 이동이 측정 잡음의 10배"를 이미 쟀고, 그것이 현재 오차 예산에서 가장 큰 미지수다.
2. 촬영이 단순하다(한 자세, 대기 시간만 바꿈). 장비 점유가 짧다.
3. 결과가 나오면 **대기 시간 규칙**이라는 바로 쓸 수 있는 운용 규칙이 나온다.

## 7. 한계

- 외부 기준기가 없으면 "판이 멈췄다"는 것을 영상으로만 판단한다. 영상이 못 보는 방향의 움직임은 안 보인다.
- 온도 기록이 없으면 H14를 시간으로만 보게 된다.
