# 실행 전 고정한 비교 계획

- 목적: 2차에서12차원 대신 joint의102관측→204차원 표현을 사용하면 Y 추정이 나아지는지 확인한다. 기존 final 코드·모델을 자동 교체하지 않는다.
- 특징: P12=QR536점의 위치 다항식 변위12계수. J204=기존 joint Observer의 QR54+선48관측과 상호작용102항. J204는 기존 feature_map()을 그대로 호출한다. 고정센터에서 얻은 각 특징을 차감하며 점·선 마스크는 기존값 그대로다.
- 주 비교: T=0인 Y80장, 기존 고정4-fold의 Y사진20장씩을 시험으로 사용한다. 두 특징을 같은 Y전용 GLS로 학습한다. fold마다 나머지Y60장+고정센터1장만으로 절편·응답·공분산을 계산한다. 센터는 최초부터 고정된 보정 영상이며 시험 사진을 기준으로 바꾸지 않는다.
- Y전용 GLS: 특징=절편+Y×응답의 전방 최소제곱, 잔차 공분산의 상관행렬을0.01 축소한 GLS 역산. 두 특징에 같은 식·같은 축소값을 사용한다. 출력T=0은 적용 전제이며 실제T를 측정해0이라고 확인한 값이 아니다.
- 추가 비교: 원래 control의6절편·축별 공유2차식·부호게이트 방식을 P12와J204에 각각 학습한다. 고정4-fold210/70,280장 전체 OOF를 비교하고 Y80장 부분집합을 별도로 표시한다. 공분산 축소0.05 고정. P12 재학습 결과와 원본 최종/fold 모델의 차이1e-6 이하·축 일치로 학습 구현을 확인한다.
- 재대입은 별도로 보고하고 OOF와 합치지 않는다. 원본Y-or-T의280/280과 Y전용의80/80은 분모와 전제가 다름을 명시한다.
- 잔여T 민감도: 20261020의혼합57장과센터3장에14일전수학습 모델을 적용한다. abs(T)<=0.09와나머지를 나누고 Y오차·Y통과와두축동시통과를 별도 집계한다. 사진을 로봇이T보정후재촬영한 것으로 취급하지 않는다.
- 모든 학습 항목은 해당fold의학습사진에서만 결정한다. 시험정답은 최종 채점과 부분집합 표시용이며 예측함수 인자로 넘기지 않는다. 실패는 분모에 포함한다. 학습측정 실패 시 임의제외하지 않고 실행을 중단한다.
- 속도: CPU1스레드,Release/OpenCV3.4.15. 고정센터로 예열한 뒤 같은사진별P12/J204 측정순서를 번갈아1회씩 실행한다. 디코딩·초기화는 별도 측정, 영상측정의중앙값/p95를 보고한다. 모델예측 시간은 캐시특징의시간으로 별도 기록한다.
- 결과를 보고 모델구조·축소계수·분할·허용오차를 바꾸지 않는다. 이미개발에노출된사진이므로 독립시험·실제제어성공률을 주장하지 않는다.
