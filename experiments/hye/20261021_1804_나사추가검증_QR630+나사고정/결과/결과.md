## 옮기지 않은 부분

- center 630점 위치(QR 디코딩 격자 + erf 경계 모델 맞춤)는 옮기지 않고 #56 실험의 `points630.hpp` 고정 ID 목록을 쓴다. 나사 39점은 C++에서 다시 골랐다.
- 원본 verify_raw.py 는 바깥 fold 모델을 옛 캐시 특징(gn17_screws_mean_features.npy)으로 맞추고 새로 잰 특징으로 시험했다. C++ 는 캐시를 쓰지 않으므로 새로 잰 특징으로 맞추고 시험한다(원본 기록상 두 특징 차 최대 1.2e-6).
- 재대입 모델도 옛 c12_model.json 대신 새로 잰 280장으로 다시 맞췄다. 기준 사진 SHA-256 확인, 모델 json 저장, HTML 보고서는 옮기지 않았다.
