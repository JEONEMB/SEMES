현재 상태: 새 실제 촬영에 대한 독립 평가는 수행하지 않았습니다.
341장은 이미 반복적인 성적·오답 관찰과 모델 개발에 사용한 개발 자료입니다.
재분할한 CV도 독립 시험이 아니며, 60/60 재대입은 학습사진 재예측입니다.

감사 결과
- evaluation_audit.json: 이전/현재 저장 모델의 분할, 학습 인덱스, 예측 재현,
  지표 재계산 및 과거 모델 보존 확인. 직접 fold 누출과 adaptive 오염을 구분.
- source_inventory.json: 프로젝트 내 711개 원시/변환 이미지를 SHA로 비교.
  기존 341개 + 복사/형식변환 368개 + 합성 검정 테스트 2개. 새 촬영 없음.
- exposed_images.csv: 개발 노출된 341개 원본 및 회색조 픽셀 SHA.
- dependency_snapshot.json: 최종 개발 후보와 630 측정의 의존 파일 SHA 목록.
  모델 스냅샷일 뿐, 촬영 수/계획까지 고정한 독립 시험은 아직 아닙니다.

future_validator.py 사용 절차
아래 경로는 프로젝트 루트에서 실행할 때의 상대 경로 예시입니다.
MODEL은 joint_yt_erroraudit_20261022/robust/exploratory_nested_model.joblib,
INFERENCE는 joint_yt_erroraudit_20261022/predict.py,
REFERENCE는 hw-analysis/data/hw/bmp/20261014/center.bmp입니다.
실제 명령에는 생략한 상위 codex_experiments_20261014 경로를 포함합니다.

1) 실제 안전한 촬영 범위와 수를 먼저 고정합니다. future_protocol.json의
   156장/2세션은 제안이며 실제 촬영 또는 로봇 명령을 실행하지 않습니다.
   코드/모델 변경 시 snapshot_dependencies.py를 다시 실행하고 검토합니다.

2) python future_validator.py freeze --model MODEL --inference INFERENCE
   --reference REFERENCE --dependency-manifest dependency_snapshot.json
   --planned-count N --sampling-plan "사전에 정한 촬영 범위/조건/세션/반복수"
   --output future_frozen_protocol.json
   명령은 한 줄로 입력합니다. 출력 파일이 이미 있으면 덮어쓰지 않습니다.
   이 단계 후 실제 새 촬영을 시작합니다.

3) 정답 관리자는 truth.csv를 별도로 보관합니다. 추론 담당자는 정답 없는
   manifest.csv와 acquisition attestation만 받습니다. manifest schema와
   attestation 항목은 future_protocol.json에 정의되어 있습니다.

4) python future_validator.py infer --protocol future_frozen_protocol.json
   --manifest manifest.csv --attestation attestation.json --output sealed_batch
   모든 예측/실패와 파일 SHA가 저장되어 receipt.json이 생성됩니다.
   추론 함수에는 이미지 bytes와 모델 경로만 전달됩니다.

5) 예측이 봉인된 다음에만 정답을 열고 한 번 평가합니다.
   python future_validator.py score --batch sealed_batch --truth truth.csv
   score.json에서 Y/T 평균·최대오차와 실패 포함 동시 통과 수/전체 수를 봅니다.
   모든 사진이 양축 0.09 이내이고 실패가 0개여야 배치 전체 목표를 통과합니다.
   한 배치의 두 번째 채점은 거부합니다. 잘못된 정답파일로 시작한 시도도
   scoring_started.json에 기록되어 조용히 다시 채점할 수 없습니다.

6) 평가된 배치는 더 이상 독립 시험으로 재사용하지 않습니다.
   now_exposed_images.csv를 누적 노출 registry에 반영한 뒤 다음 개발을 합니다.
   현재 프로그램은 악의적인 운영자의 조작까지 막는 보안 장치가 아닙니다.
   촬영 이력, 정답 은닉, near-duplicate 여부는 별도 운영 기록도 필요합니다.

validator_selftest.json의 검사는 작은 합성 이미지로 수행한 소프트웨어 검사이며
로봇이나 실제 사진의 추정 성적이 아닙니다.
