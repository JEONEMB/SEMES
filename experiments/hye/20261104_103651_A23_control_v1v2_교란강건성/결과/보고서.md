# A23 보고서: control v1, v2 교란 강건성

실행 2026-11-04 · 대상: 운용 영역 사진 39장(1014 Y 단독 중 매 4번째와 center, 1020 남은 \|T\| ≤ 0.03) · v1은 `00000_final_Y_T control` 복사본(macOS용 sha256만 바꿈), v2는 `20261104_1435_v2_control_강등`

- **문제:** control_v2가 v1보다 강건한가?
- **해결:** 같은 사진에 교란 11종을 넣고 두 모듈의 Y 출력 변화(같은 사진의 교란 전후 \|ΔY\|)를 비교했다. v2는 문턱 θ = 0.0075와 0.01 두 가지로 돌렸다.
- **결과:** v2는 밝기, 흐림, 카메라 세로 이동에 훨씬 강하다(v1은 밝기 ×0.8에서 축 판정이 뒤집혀 최대 1.85). 대신 영상 잡음과 조명 기울기에는 v1보다 약하다. θ = 0.01이 조명 기울기 영향을 0.023 → 0.011로 줄여 모듈에 채택했다.

| 교란 | v1 \|ΔY\| 평균 / 최대 | v2 θ=0.01 \|ΔY\| 평균 / 최대 |
|---|---|---|
| 이동 x +0.25 px | 0.0174 / 0.0175 | 정상 반응 (판 이동과 같음) |
| 이동 y +0.25 px | 0.0058 / 0.0123 | 0.0008 / 0.0046 |
| 이동 y +0.50 px | 0.0114 / 0.0179 | 0.0007 / 0.0065 |
| 밝기 ×0.8 | 0.268 / 1.850 | 0.0008 / 0.0057 |
| 밝기 ×1.2 −20 | 0.0000 / 0.0000 | 0.0005 / 0.0035 |
| 흐림 σ0.7 | 0.0004 / 0.0005 | 0.0007 / 0.0061 |
| 흐림 σ1.2 | 0.0076 / 0.249 | 0.0010 / 0.0066 |
| 잡음 σ2 | 0.0001 / 0.0003 | 0.0048 / 0.044 |
| 잡음 σ4 | 0.0002 / 0.0006 | 0.0132 / 0.063 |
| 조명 기울기 ±10% | 0.0000 / 0.0001 | 0.0022 / 0.011 |

측정 실패는 두 버전 모두 0. θ = 0.0075 결과는 [perturb_v2_theta0075.csv](results/perturb_v2_theta0075.csv), θ = 0.01은 [perturb_v2_theta010.csv](results/perturb_v2_theta010.csv)와 [summary.csv](results/summary.csv).
