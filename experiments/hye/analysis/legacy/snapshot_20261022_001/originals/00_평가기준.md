# 평가 기준 (2026-10-14 확정, 모든 방법에 공통 적용)

## 무엇을 내는가 (방법의 출력)
임의의 사진 1장마다 아래를 기록한다.
- 판정 축: Y인지 Θ인지
- 값: 얼마나 이동했는지 (Y mm) 또는 얼마나 돌아갔는지 (Θ)

## 무엇으로 채점하는가
사진마다 정답과 비교해서 아래를 구하고, 평균을 낸다.
1. **축 정확도**: 판정 축이 정답 축과 같은가 (맞음 / 틀림). 전체, Y 사진, Θ 사진별 비율.
2. **오차**: 예측 값과 정답 값의 차이.
   - 축 맞은 사진만: 평균 절대 오차, RMS, 최대 (Y는 µm, Θ는 mΘ = 0.001)
   - 전체 사진: 축을 틀리면 "정답 축의 예측값 = 0"으로 보고 오차 = |정답 값| (참고용)

## 정답 기준 2개 (둘 다 항상 보고)
- **보정 안 함 (명령값)**: 파일 이름의 값 그대로.
- **보정함 (실제 위치)**: 명령값 + 백래시, 드리프트 0점 보정 (v4의 ①). 시험 사진이 보정 모델 학습에 들어가지 않도록 교차검증 폴드마다 학습 사진으로만 맞춘다.
  - 주의: 보정값 자체를 영상(QR 평균 이동)으로 추정했기 때문에 영상 기반 방법에 유리한 순환이 있다.

## 합격선 (2026-10-14 사용자 목표)
- Y/Θ 판정 정확도: Y 사진, Θ 사진 모두 100%.
- 값 오차: Y, Θ 모두 0.09 안. 근거는 "한 스텝 정도 허용" (Y 1스텝 0.05mm, Θ 1스텝 0.01)이라 아래 두 해석을 모두 보고한다.
  - (가) |오차| ≤ 0.09 (Y mm, Θ 단위 그대로)
  - (나) 한 스텝: Y ≤ 0.05mm, Θ ≤ 0.01
- 축을 틀린 사진은 "보정 후 남는 오차"로도 본다: 정답 축은 0만큼 보정됨 (= |정답|), 틀린 축은 |예측|만큼 잘못 보정됨. 둘 다 합격선 안이면 실제 피해 없음 (참고 지표).

## 공통 조건
- 사진 280장 (center 제외), 교차검증은 촬영 순서 짝/홀 2겹 (모든 사진이 정확히 한 번 시험). 구간 빼기 검증은 보조.
- center 사진은 시험에 쓰지 않는다.
- 결과 표에는 학습에 쓴 라벨(raw / 보정본)과 정답 기준(명령값 / 실제 위치)을 따로 적는다.
- 허용 오차 0.09 통과율은 보조 지표로 함께 적는다 (Y mm로 가정, Θ 허용치는 미확인).
