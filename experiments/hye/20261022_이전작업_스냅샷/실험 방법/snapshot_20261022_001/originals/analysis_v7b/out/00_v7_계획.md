# v7 계획: center 사진 + 현재 사진 2장으로 Y/Θ 판정과 값 (QR 판만)

## 목표
- 입력: center 사진, 현재 사진 (2장). 판밖 점은 쓰지 않는다 (QR 3개만, 판 나사 2개는 최후의 보루로 따로 검증).
- 출력: Y인지 Θ인지 + 값.
- 합격선: Y/Θ 판정 정확도 100% (Y 사진, Θ 사진 모두), 값 오차 0.09 안 (Y mm, Θ 둘 다).
  - 해석 2가지를 모두 보고: (가) |오차| ≤ 0.09, (나) 한 스텝 허용 = Y ≤ 0.05mm, Θ ≤ 0.01.
- 평가 기준: `00_평가기준.md` (정답 2개: 명령값 / 0점 보정한 실제 위치).

## 실험 단계
| 단계 | 질문 | 비교할 것 |
|---|---|---|
| S1 특징점 | 점을 몇 개, 어떤 크기로 뽑나 | 템플릿 9 / 13 / 17 / 25px (간격 = 템플릿 크기), QR만 vs QR+나사 |
| S2 위치 재기 | center 점 ↔ 현재 점 짝짓기 | 템플릿 + 가우스-뉴턴 (A) vs 모서리 각각 검출 (B). v6 t14에서 A 승 → A 사용 |
| S3 0점 문제 | 7개 0점(구간 6 + center)을 보정해야 하나 | 학습 라벨 명령값 / 보정본 x 절편 자유 / center 고정(절편 0) |
| S4 계산 방법 | 점 위치 → (축, 값) | M1 점별 모델 + 가설 비교 (1차/2차), M2 Y, Θ 동시 추정, M3 판 원근 변환(8개 값) + 전체 공분산 가설 비교, M4 분류기 (판별 분석) + 회귀 |
| S4b 점 넣는 법 | 전부 넣으면 상쇄되나 | 같은 가중 / 잡음 가중 / Huber / 상위 k개 |
| S5 판정 문턱 | 가설 비용 비 문턱 1이 맞나 | 학습 폴드에서 문턱 보정 |
| S6 평가 | 합격선 도달? | 짝/홀 + 구간 빼기 교차검증, 정답 2개, 합격선 2가지 |
| S7 한계 | 100%가 불가능하면 어디서 왜 | 틀리는 크기 구간, 이론 한계와 비교 |

## 원칙
- 런타임에 쓸 수 있는 것만: center 사진 + 현재 사진 + 미리 학습한 모델 (이 데이터로 보정 학습).
- 시험 사진은 학습(모델, 점 고르기, 문턱, 0점 보정)에 쓰지 않는다.
