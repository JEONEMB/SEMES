# 계획: 영상 교란 시험 (11-13, 결과를 보기 전에 적음)

## 목적

학습하지 않은 촬영 조건(흐림, 밝기, 노이즈, 가림, 반사, 화면 밀림, 배율·회전, QR 판–나사 상대 밀림)에서 지금 모듈이

- 그대로 맞는지(안전),
- 오류로 멈추는지(안전하게 실패),
- 오류 없이 틀린 값을 내는지(조용히 틀림, 위험)

를 재고, 어디부터 깨지는지 한계를 찾는다.

## 과적합 방지

- 교란 종류와 세기를 아래에 미리 정하고, 결과를 본 뒤 바꾸지 않는다.
- 모델·계수·코드는 바꾸지 않는다. 학습에 쓰지 않는다. 지금 assets 그대로 공개 경로(Estimator::predict, 절대 영점)로 잰다.
- 교란 노이즈는 고정 시드다.

## 자료와 모델

| 이름 | 사진 | 모델 |
|---|---|---|
| semes_536 | SEMES 702장 | semes 기본(track536, 값 7개) |
| semes_ncc | SEMES 702장 | semes alt ncc(흐림 NCC, 값 7개) |
| ssafy_ncc | 장비 11-12 1959장 | ssafy 기본(흐림 NCC, 값 5개) |

## 지표 (교란마다)

- 멈춤: 예외로 값을 내지 않은 사진 수
- ΔY, ΔT: 같은 사진의 교란 없는 출력과의 차이 (중앙값, 95%, 최대)
- 조용히 틀림: 교란 없을 때는 통과했는데 교란 뒤 값은 냈고 허용오차(|eY| ≤ 0.045 mm, |eT| ≤ 0.01)를 넘은 사진 수
- 판정 기준(미리 정함): ΔY 95% ≤ 0.010 mm 그리고 ΔT 95% ≤ 0.002 이면 "영향 작음"

## 교란 목록

모두 사진 전체(화면 고정)에 적용한다. 측정 기준(center.bmp)은 바꾸지 않는다.

| 묶음 | 교란 | 세기 |
|---|---|---|
| 흐림 | 가우시안 흐림 σ | 0.5, 1, 2, 3, 5 px |
| 흐림 | 가로 흔들림 흐림(길이) | 5, 9 px |
| 밝기 | 곱하기(포화 허용) | ×0.6, ×1.4 |
| 밝기 | 더하기 | −40, +40 |
| 밝기 | 감마 | 0.7, 1.4 |
| 노이즈 | 가우시안 노이즈 σ (고정 시드) | 3, 8 회색값 |
| 화면 밀림 | 가로 이동 | 0.5, 2 px |
| 화면 밀림 | 세로 이동 | 10, 25 px |
| 배율 | 화면 중심 기준 확대·축소 | ×0.998, ×1.002, ×1.005 |
| 회전 | 화면 중심 기준 회전 | 0.05°, 0.2° |
| 가림 | QR1 상자 왼쪽 위 1/4 을 회색(128)으로 덮음 | 1/4 |
| 가림 | QR1 상자 왼쪽 절반을 회색으로 덮음 | 1/2 |
| 반사 | QR1 중심에 반지름 30 px 하얀(255) 원 | 1 |
| 가림 | 나사1 중심 기준 왼쪽 절반(가로 60 × 세로 120 px)을 회색으로 덮음 | 1/2 |
| 반사 | 나사1 중심에 반지름 20 px 하얀 원 | 1 |
| 판–나사 밀림 | QR 영역만 원래대로 두고 나머지 화면을 가로로 이동 | 0.1, 0.3 px |

가림·반사 위치는 센터 사진 기준 화면 고정 위치다(렌즈 먼지, 고정 조명 반사를 흉내). 자세가 큰 사진에서는 물체가 그 자리를 벗어나 영향이 없을 수 있어, 센터 근처(|Y_abs| ≤ 0.1 mm, |T_abs| ≤ 0.1) 사진만 따로도 센다.

판–나사 밀림의 QR 영역 = QR 상자 3개를 (search_x + 8, search_y + 8) 만큼 넓힌 합 상자와 536점 추적 영역(full_crop)의 합.
