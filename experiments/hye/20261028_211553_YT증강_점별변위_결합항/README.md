## 생성식

샘플 = 영점 필드 + 단일축 반응 `Y, Y², T+, T+², T−, T−²` (점마다) + [YT 결합항, 기본 끔] + 반복 촬영 잡음

- 센터 사진 영점에는 접근 방향 백래시를 더한다. T가 있으면 T 부호, 없으면 Y 부호를 쓴다.
  - +접근: S1·S3·S5 영점과 (1020 혼합 세션 − 1020 센터)의 평균. 판 평균 dx는 −0.61px다.
  - −접근: S2·S4·S6 영점의 평균. 판 평균 dx는 −0.17px다.
- 반복 잡음은 1020 같은 자세 3장의 점별 편차 60개에서, 같은 촬영 순번의 편차를 하나 뽑는다.

## 결과 (모두 개발 자료, 선택 536점 RMS px)

반복 촬영 잡음 바닥: **0.120** (x 0.167, y 0.029). 촬영 순번별 판 dx 평균은 1번째 −0.12, 2번째 +0.16, 3번째 −0.04다.

| 반응식 | RMS | Y trial | T trial |

T의 +/− 기울기를 나누면 T 잔차가 0.072에서 0.049로 줄어든다.

### 2. 1020 혼합 57장 (자세 하나 빼기, 학습 T ≤ 1)

| 영점 | 결합항 | 평가 T ≤ 1 (45장) | 평가 T = 2 (12장, 외삽) |
|---|---|---|---|
| 1020 센터 3장 평균 | 없음 | 0.486 (판 dx −0.66) | 0.721 |
| 1020 센터 3장 평균 | YT | 0.499 | 0.515 |
| **세션 영점 1개** | **없음** | **0.135** | 0.305 |
| 세션 영점 1개 | YT | 0.150 | 0.453 |
| 세션 영점 1개 | YT+YT²+Y²T | 0.201 | 1.114 |

- 혼합 자세 잔차의 대부분은 결합항이 아니라 판 전체가 x로 −0.66px 밀린 세션 영점 차이였다. 크기가 1014의 +/− 접근 차이(약 −0.6px)와 같아서 백래시로 본다.
- 세션 영점을 두면 0.135로 잡음 바닥(0.120)에 가깝다. 결합항을 더하면 자세 하나 빼기에서 오히려 나빠진다. **지금 자료(Y > 0, T > 0, |Y| ≤ 1)에서는 결합항이 잡음과 구분되지 않는다.** 전체 학습한 YT 계수는 (Y=1, T=1)에서 판 dx +0.29px다.
- T = 2는 1014 범위(±1) 밖이라 외삽이 맞지 않는다. 생성 격자는 |T| ≤ 1이다.

### 5-1. 증강 자체 평가: 실측 사진 vs 증강 쌍둥이

사진마다 그 사진을 빼고 맞춘 생성기로 같은 자세·영점의 쌍둥이를 만들어 두 모듈에 넣었다 (1014는 trial 안 4겹, 1020 혼합은 자세 하나 빼기 + 그 자세의 잡음 표본 제외).

| | 1014 단일축 280장 | 1020 혼합 T ≤ 1 45장 | 1020 T = 2 12장 (외삽) |
|---|---|---|---|
| joint Y 차이 (실측 − 쌍둥이) RMS / 최대 | 0.020 / 0.084 | 0.030 / 0.079 | 0.804 / 0.851 |
| joint T 차이 RMS / 최대 | 0.0036 / 0.016 | 0.0066 / 0.018 | 0.143 / 0.153 |
| joint 통과 판정 일치 | 280 / 280 | 45 / 45 | 0 / 12 |
| 실측 추정이 잡음 쌍둥이 95% 구간 안 (Y / T) | 100% / 100% | 89% / 87% | 0% |
| control 고른 축 일치 | 280 / 280 | 45 / 45 | 0 / 12 |
| control 값 차이 RMS / 최대 | 0.0024 / 0.036 | 0.0097 / 0.023 | - |
| control 통과 판정 일치 | 280 / 280 | 45 / 45 | 9 / 12 |

- |T| ≤ 1 범위에서는 증강 쌍둥이가 두 모듈의 추정값과 통과 판정을 모두 재현한다.
- 1020 혼합에서 실측이 쌍둥이 95% 구간 밖에 나오는 경우가 11~13%다. 증강의 퍼짐이 실제보다 조금 좁거나 치우쳐 있다.
- 잡음을 넣은 쌍둥이의 통과율은 1014에서 joint 98%, control 91%로 실측 100%보다 낮다. 잡음 표본을 1020 반복 촬영(2번째 장 +0.3px 포함)에서 가져와서, 1014 연속 촬영보다 잡음을 크게 넣은 것으로 보인다.
- T = 2는 생성기 범위 밖이라 재현하지 못한다.
- joint와 control 모두 이 사진들로 학습·선택한 모델이라, 실측 통과는 재대입 성적이다.

### 5-2. Y-T 평면 오차 지도 (격자 16,281 × 영점 15 × n = 3)

| | joint | control |
|---|---|---|
| 두 축 0.09 통과율 (전체) | 93.6% | 4.4% (Y 또는 T 하나만 출력) |
| \|Y\| ≤ 1 | 96.1% | 7.3% |
| Y·T 축 위 (단일축 자세) | 96.9% | 83.7% (T=0 줄 90.8%, Y=0 줄 81.0%) |
| 센터 허용 박스 안 | 97.2% | - |
| 평균 \|Y 오차\| / \|T 오차\| | 0.037 / 0.0070 | - |

- joint는 |Y|, |T|가 클수록 떨어진다 (|Y| 1.5~2: 89%, |T| 0.75~1: 89%). 사분면별로는 Y > 0·T > 0이 97%로 가장 좋고, Y < 0·T < 0이 88%로 가장 나쁘다. 모서리 (−2, −1)은 29%다.
- 실측 혼합 자세가 없는 사분면은 "Y·T 효과가 더해진다"는 가정 위의 결과다.
- control은 1020 센터·세션 영점과 추가 후보 PC2(날짜 방향)에서 T축 통과율이 70% 정도로 떨어진다.

### 5-3. 반복 잡음 두 가지 (2026-10-29, `results/module_eval_2noise/`)

`module_eval.py`가 이제 두 잡음으로 쌍둥이와 지도를 따로 채점한다. 5-1·5-2의 잡음 1종 결과(`results/module_eval/`)는 그대로 둔다.

- **1020 반복:** 1020 같은 자세 3장의 편차. 촬영 순번을 유지하고, **T = 2 자세는 뺐다** (T ≤ 1 자세 15개 + 센터 = 48개). 5-1·5-2는 T = 2 자세 12개를 넣었는데, 그 사진들에서 control LK 추적이 자세마다 37~76점씩 1px 넘게 튄다 (최대 21px). 이는 반복 잡음이 아니라 범위 밖 자세의 추적 실패다.
- **1014 연속:** 1014는 같은 자세 반복이 없어서, 1014 281장의 점별 반응식 잔차를 자유도 보정(√(n/(n−p)))해서 쓴다. 1014 사진의 쌍둥이에는 그 겹을 뺀 맞춤의 잔차만 쓴다.

control 선택 536점 RMS (px):

| 잡음 | RMS | x | y | 판 dx 표준편차 |
|---|---|---|---|---|
| 1020 반복 (T = 2 포함, 5-1·5-2) | 0.513 | 0.563 | 0.458 | 0.174 |
| 1020 반복 (T ≤ 1) | 0.108 | 0.152 | 0.017 | 0.152 |
| 1014 연속 | 0.029 | 0.035 | 0.021 | 0.028 |

1020 반복 잡음은 거의 판 전체 x 이동이다. 촬영 순번마다 판이 ±0.15px 밀린다. 1014 연속 촬영에는 이 흔들림이 없다.

증강 자체 평가 (잡음 쌍둥이):

| | 1014 단일축 280장 | 1020 혼합 T ≤ 1 45장 |
|---|---|---|
| joint 실측이 쌍둥이 95% 안 (Y / T): 1020 반복 | 99% / 99% | 84% / 87% |
| joint 실측이 쌍둥이 95% 안 (Y / T): 1014 연속 | **95% / 95%** | 82% / 76% |
| joint 잡음 쌍둥이 통과율 (실측 100%): 1020 / 1014 | 100% / 100% | 100% / 100% |
| control 실측이 쌍둥이 95% 안: 1020 / 1014 | 100% / 93% | **82% / 18%** |
| control 잡음 쌍둥이 통과율 (실측 100% / 40%): 1020 / 1014 | 100% / 100% | 39% / 40% |

- 5-1에서 잡음 쌍둥이 통과율이 실측보다 낮았던 원인(joint 98%, control 91%)은 T = 2 추적 실패가 잡음 표본에 섞인 탓이었다. 그것을 빼면 두 잡음 모두 1014에서 100%다.
- 1014 사진에는 1014 연속 잡음이 맞는다. 실측이 95% 구간 안에 정확히 95% 들어온다. 1020 반복 잡음은 1014에 조금 넓다 (99%).
- 1020 혼합 사진에는 1014 연속 잡음이 너무 좁다 (control 18%). 반복 잡음은 날짜·세션에 따라 다르다. 1020 반복 잡음으로도 82~87%라서, 1020 세션의 퍼짐을 다 설명하지는 못한다.

Y-T 평면 오차 지도 (joint, 두 축 0.09 통과율):

| | 1020 반복 (T ≤ 1) | 1014 연속 | 참고: 5-2 (T = 2 포함) |
|---|---|---|---|
| 전체 | 95.4% | 96.8% | 93.6% |
| \|Y\| ≤ 1 | 98.1% | 99.0% | 96.1% |
| Y·T 축 위 | 99.0% | 99.7% | 96.9% |
| 센터 허용 박스 안 | 99.2% | 99.8% | 97.2% |
| 사분면 ++ / −− / +− / −+ | 98.6 / 90.1 / 96.2 / 96.5% | 99.3 / 92.2 / 97.7 / 97.7% | 97 / 88 / - / -% |

control 축 위 통과율: T = 0 줄은 98.2% (1020) / 97.8% (1014), Y = 0 줄은 두 잡음 모두 87.0%다. Y = 0 줄의 실패는 잡음이 아니라 영점 때문이다. C14·S1~S6 영점은 91~99%지만, 1020 센터·세션 영점과 PC2(날짜 방향) 영점에서는 72~79%다.

- 잡음을 줄여도 Y < 0·T < 0 사분면과 |Y|가 큰 곳은 거의 그대로다. 이 지역의 실패는 잡음이 아니라 joint 모델의 계통 오차다 (가정 시뮬레이션).

## 한계와 다음 일

- 1~4절은 흐린 경계 직접 맞춤 측정, 5절은 각 모듈의 실제 측정(joint 102관측, control LK/GN)이다.
- 1~4절과 대시보드 샘플 패널(흐린 경계 공간)의 반복 잡음 표본에는 아직 T = 2 자세가 들어 있다. 이 공간에서는 영향이 작다 (잡음 바닥 0.120 → T ≤ 1만 쓰면 0.111).
- 1014 연속 잡음은 반응식 잔차라서, 반응식이 못 맞춘 부분이 있으면 그만큼 크게 잡힌다. 같은 자세 연속 반복 촬영이 있으면 직접 잴 수 있다.
- 혼합 자세가 한 사분면뿐이다. 다른 사분면의 결합항과 백래시 부호는 내일 자료로 확인해야 한다 (Y < 0 또는 T < 0 혼합 자세, |Y| > 1, 촬영 순서 기록 요청).
- 접근 방향은 자세 부호로 가정했다. 실제 촬영 순서가 있으면 그것을 쓴다.
