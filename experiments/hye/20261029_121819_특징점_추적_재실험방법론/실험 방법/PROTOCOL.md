# 특징점 선택·추적·정밀 보정 재실험 방법론

작성: 2026-10-29. 상태: 실행 전 제안, 신규 측정·학습 결과 없음.
공통 알고리즘 규칙은 [단일 원본](../../../../ALGORITHM_RULES.md)을 따른다. 아래는 이번 비교의 실험 설계이며 공통 규칙의 별도 사본이 아니다.

## 1. 무엇을 결정할 것인가

질문은 ‘유명한 검출기 중 무엇이 최고인가’가 아니라 ‘현재 정렬 목적에서 어떤 점 선택·대응·정밀 보정 구성이 오차와 실패를 억제하면서 시간을 줄이는가’다.

우선순위는 QR 고정 구조점 + LK의 재검증이다. 최종 control과 joint 교체 여부는 단계별로 판단한다. 신규 실행 도구·학습기는 C++17/MSVC v141/OpenCV 3.4.15로 구현한다. 이 문서는 방법론 산출물이며 구현 완료를 의미하지 않는다.

## 2. 기존 결과에서 출발하는 시사점

출처: [기존 C++ 비교](../../20261029_112722_QR특징점검출기_비교/결과%20정리/README.md), [원시 요약](../../20261029_112722_QR특징점검출기_비교/결과%20정리/results/summary.csv).

- 고정 QR 구조점+LK는 단순 판정기에서 276/280, 측정 중앙값 8.6ms였다. 기존 구조점+LK/GN은 273/280, 59.4ms였다. 우선 재검증할 후보지만 3장 차이로 정확도 우위를 확정하지 않는다.
- 반복 무늬에서 기술자를 다시 짝짓는 구성보다 기준점의 대응을 유지한 추적 구성이 유리했다. 이는 해당 데이터·설정의 파이프라인 결과이며 모든 기술자에 대한 일반 명제가 아니다.
- 점 선택, 점 수, 공간 배치, 전처리, 추적 창, 대응 검사와 점 제거가 동시에 달랐다. 검출기나 GN 한 요소의 효과로 해석할 수 없다.
- 기존 비교의 ‘오매칭률’은 변위 중앙값에서 2px 이상 벗어난 비율이다. 물리적 대응 정답으로 확인한 오매칭률이 아니므로 새 보고서에서는 ‘변위 이상치율’로 명명한다. 작게 잘못 이동한 대응은 놓칠 수 있다.
- P12 잔차는 이동장 적합 잔차다. 실제 점 위치의 정답 오차가 아니며, 공간적 변형 자체를 이상치 제거로 없애지 않았는지도 확인한다.
- 기존 273/280은 단순 판정기 성적이다. 채택 전체 control의 고정 4-fold 280/280과 직접 비교하지 않는다.
- SIFT·SURF·Förstner는 미평가다. 미실행을 열세로 표기하지 않는다.

## 3. 데이터와 분할을 먼저 동결

입력은 저장소 `data/clean/`의 원본 바이트를 사용한다. C++ 도구로 파일 목록·해시·조건·그룹·fold를 manifest로 저장한다. 공통 기준 영상과 원점 처리 방식은 기준 규칙을 따른다.

| 평가 묶음 | 용도 | 보고 방식 |
|---|---|---|
| 1014 단일축 280장 | control 재현·추적 비교 | 고정 4-fold OOF, Y80/T200/전체 별도 |
| 1020 센터 3장 | 날짜 영점 이동 진단 | 학습 사용 여부를 명시, 3장으로 일반화 주장 금지 |
| 1020 혼합 57장 | joint 혼합 자세 평가, control 전제 밖 진단 | 혼합 결과를 단일축 성적과 분리 |
| 기준 center 1장 | 기준 영상·자기 정합 | 정지 정확도 평가 표본과 중복 계산하지 않음 |

기존 280장 fold는 원본 검증 자료에서 가져오고 기존 비교의 순번%4 분할과 일치 여부를 검사한다. 불일치하면 원본 fold를 공통 비교에 사용하고 이전 표는 역사적 결과로 남긴다. 반복 혼합 조건은 같은 그룹으로 묶는다. joint에는 그룹 단위의 공통 4-fold를 먼저 저장하며 모든 후보에 동일하게 적용한다. 기존 joint OOF의 원본 분할을 복구하지 못하면 새 분할임을 표시한다.

두 평가 트랙을 분리한다: (a) 같은 날짜·혼합 자료의 개발 OOF, (b) 1014만 학습→1020 적용의 날짜 간 전이. 단일축만 학습한 joint의 혼합 예측에는 학습 범위 한계를 표시한다. 현재 자료 전체는 이미 개발에 노출되어 있으므로 전이를 독립 신규 시험이라 부르지 않는다.

## 4. 실험 A: 채택본 재현과 학습기 검증

1. 채택 control과 joint의 코드·assets·컴파일 설정을 해시로 고정한다.
2. BMP에서 다시 측정하여 특징·예측·실패·시간을 저장한다. 기존 캐시 재생은 별도 표시한다.
3. control은 원본 동결 fold 모델 평가와 최종 전수 모델 재대입을 각각 재현한다. joint 전수 모델의 재실행을 기존 OOF 재현으로 표시하지 않는다.
4. 후보 비교용 C++ 학습기가 채택본 측정에서 원본 학습 절차를 재현하는지 확인한다. 원점 후보 생성, whitening, 부호 게이트까지 검사한다. joint도 원본 학습기와 차이를 확인한다.
5. 재현이 안 되면 ‘공통 재구현 학습기’로 이름을 붙인다. 채택본 고정 모델 성적, 공통 학습기의 기준 측정 성적, 후보 측정 성적을 세 줄로 분리한다. 측정 개선과 학습기 변경을 혼동하지 않는다.

## 5. 실험 B: 같은 점에서 LK와 GN 효과 분리

우선 기존 630점 추적→고정 536점 선택 경로를 유지한다. 모든 군에 같은 center 측정 차감을 적용한다.

| 군 | 변경 | 답할 질문 |
|---|---|---|
| B0 | 기존 측정 전체 그대로 | 채택 대조군 |
| B1 | B0에서 추가 GN만 생략 | 추가 GN의 순효과 |
| B2 | B1에서 LK 창만 15→21 | 창 크기 영향 |
| B3 | B2에서 피라미드·종료 조건을 비교용 설정으로 변경 | LK 설정 영향 |
| B4 | 전처리·crop·자료형 차이를 한 항목씩 변경 | 전처리와 구현 경로 영향 |
| B5 | 과거 비교의 OpenCV LK 구성을 그대로 재현 | 과거 빠른 후보 연결 |

먼저 기존 소스의 실제 LK API·피라미드·보간·반복 조건을 기록한다. ‘기존 LK’와 ‘OpenCV LK’를 다른 수학 알고리즘으로 가정하지 않는다. B2~B4에서 이미 동일한 설정은 중복 실행하지 않는다. 독립 효과를 한 번에 하나씩 바꾸고, 상호작용은 최종 유망 설정에서 GN 유/무로 추가 확인한다.

점 제외로 성능이 좋아진 효과를 분리한다. 주 비교에서는 고정 점·마스크를 유지하고 실패를 진단한다. 필수 점의 수치 결과가 없으면 해당 영상 실패로 기록한다. 유효 점만 사용한 P12는 별도 보조군으로 두고 사용점 수·공간 분포·행렬 rank/조건수를 함께 보고한다. 정상값처럼 누락을 감추지 않는다.

## 6. 실험 C: 검출기·점 수·배치 분리

QR 구조점, Shi–Tomasi, Harris, FAST를 공통 NCC 초기화·전처리·LK·품질 검사·P12·학습기에 연결한다. center에서 한 번 선택한 점 ID를 모든 현재 영상에서 유지한다.

두 표를 만든다: (1) 각 방법의 자연스러운 전체 점 집합, (2) 같은 점 수와 유사한 공간 배치를 맞춘 집합. 배치는 QR별 고정 4×4 셀로 나누어 center만으로 quota를 정한다. 최소 간격·동점 순서·점 수 후보(예: 128/256/536)는 실행 전에 고정한다. 특정 셀이 부족하면 임의 재검출·복제로 채우지 않고 부족을 표시하고 가능한 공통 quota로 별도 비교한다. 점 수가 줄어든 결과를 536점 결과로 부르지 않는다.

이 실험의 결론은 ‘같은 추적 조건에서 어떤 초기점 집합이 유리한가’다. 공통 위치의 직접 정답이 없으면 검출기 자체의 절대 위치 정확도 순위를 주장하지 않는다.

## 7. 실험 D: 기술자 대응과 누락 방법

ORB·BRISK·AKAZE·KAZE의 기존 구성부터 재현한다. 각 방법에서 가능하면 동일한 center 키포인트 집합을 (a) LK 추적, (b) 현재 영상 재검출+기술자 매칭으로 비교한다. 서로 다른 추적 가능성·재검출 생존율을 공개한다. 같은 키포인트를 강제로 제공할 수 없는 API는 순수 대응 비교에서 제외하고 전체 구성 비교에 남긴다.

매칭 검사는 원시 매칭, 비율 검사, 상호 최근접 검사, NCC로 얻은 QR별 이동 제한을 단계별로 기록한다. 매칭 허용 범위·후처리를 적용한 계산 시간도 포함한다. 동일점 유지가 어려운 군은 재검출 기반 대안으로 구분한다.

SIFT·SURF·Förstner는 C++/현 팀 환경에서 구현·의존성·라이선스 조건을 먼저 확인한다. 기존 OpenCV를 임의 교체하지 않는다. 별도 실험 빌드가 가능하면 출처와 수치 검증을 남긴 뒤 추가한다. 불가능하면 구체적 사유와 함께 미평가로 남긴다. Förstner는 기본적으로 점 선택/위치 정밀화 후보이므로 기술자 매칭 군에 억지로 넣지 않는다.

## 8. 실험 E: 측정 후보별 재학습과 단계별 평가

고정 기존 GN 모델에 새 측정을 넣는 결과는 ‘모델 호환성’ 표에만 둔다. 최종 상대 비교는 후보마다 동일 분할·동일 모델 계열·동일 튜닝 예산으로 재학습한다. 학습되는 모든 항목은 학습 fold 안에서 추정한다. 튜닝이 필요하면 학습 fold 내부의 그룹 교차검증으로 고르고 외부 시험 fold에는 한 번 적용한다. 이미 본 결과를 근거로 후보를 추가하면 프로토콜 버전을 올린다.

control은 P12와 6원점 후보·부호 게이트를 포함하는 공통 학습 절차로 비교한다. Y80의 Y 정밀도를 주목하되 Y-or-T 계약에 맞게 T200도 포함한 전체 회귀·축·부호 성적을 함께 유지한다. 현재 사진의 실제 T=0을 추론 입력으로 주거나 출력 한 축을 사후 강제하지 않는다.

joint 확장은 별도 단계다. ECC QR 관측을 점 추적 기반 관측으로 바꾸되 위·아래 선 관측·마스크는 고정하여 QR 측정 교체 효과를 비교한다. 서로 다른 차원의 QR 관측은 공통 전방 GLS 계열과 같은 내부 선택 절차로 재학습하고, 특징 표현 차이까지 포함한 비교임을 명시한다. 기존 ECC의 가상 27점과 실제 구조점은 동일 측정이라고 부르지 않는다. 혼합57장의 T 오차를 중점 보고하되 Y 오차와 동시 통과율도 함께 보고한다.

## 9. 지표·시간 측정·판정

주 표에는 Y/T 각각 평균·최대 절대오차, 두 축 동시 통과 수/전체 수, 영상 실패·보류 수를 둔다. 실패도 전체 통과율 분모에 남긴다. 오차 통계는 계산 가능한 표본 수와 함께 표시한다. 보조 표에는 축·부호, 점 유효율, 정역방향 오차, P12 적합 잔차, 변위 이상치율, 사용점 분포를 둔다.

실제 대응 정답 없는 영상의 ‘오매칭 0%’를 보증으로 사용하지 않는다. 알려진 이동·변형을 준 합성 영상은 대응 실패 검증의 보조 자료로만 사용하고, 보간된 영상의 성적을 실측 정밀도로 대체하지 않는다.

동일 CPU·Release·스레드 수에서 계측한다. 공통 하니스는 기본 OpenCV 1스레드로 고정하고 실제 운용 스레드 설정은 별도 측정한다. 채택 소스의 수식·상수는 바꾸지 않는다. 초기화 5회, warm-up 10회 후 전체 목록 5회 반복을 기본으로 한다. 후보 실행 순서는 고정 seed로 바꾸며 원시 시간을 저장한다. 영상별 반복 중앙값에서 전체 중앙값/p95를 계산한다. 파일 읽기, 전처리/NCC, 추적, GN, 특징, 추론, 전체 추론을 구분하며 center 사전 계산 비용은 초기화에 포함한다. cold 시작과 warm 처리 시간을 섞지 않는다.

선정은 다음 순서다: (1) 전체 실패·동시 통과와 단계별 오차 악화 여부, (2) 최악 오차, (3) 장당 전체 시간 p95/중앙값. 평균오차와 fold별 결과도 함께 제시한다. 유일한 종합 점수로 상쇄하지 않는다. 한 후보가 정확도와 속도 모두 우세하지 않으면 Pareto 후보로 남긴다. 허용할 정확도 저하 폭은 결과를 본 뒤 만들지 않으며 이번 기본 비교에서는 채택본 대비 저하를 허용하는 교체 결론을 내리지 않는다.

같은 사진에서 후보 간 오차 차이·통과가 바뀐 사진 목록을 저장한다. 반복 조건이 있으면 그룹 단위 재표본화로 차이의 구간을 보조 제시하되, 이 구간이 반복 개발에 따른 평가 오염을 해소한다고 주장하지 않는다. fold별 순위와 실패 집중 조건이 불안정하면 우열 미확정으로 남긴다.

## 10. 산출물과 실행 순서

실행 순서: manifest/fold 동결 → A 재현·학습기 검증 → B 추적/GN 분리 → C 초기점 비교 → D 기술자·미평가 방법 → E 후보 재학습·joint 확장 → 새 촬영/실제 순차 제어 검증.

각 실행은 새 `runs/<실행시각>/`에 저장한다: 설정·코드/assets 해시·환경, 파일/fold manifest, 점별 좌표·진단, 영상별 특징·예측·실패, 단계별 원시 시간, OOF/재대입/날짜 전이별 요약, 전체점 시각화와 배율 명시 확대도. 이전 결과가 있으면 덮어쓰지 않는다. C++ 학습기 재현 검증이 끝나기 전에는 ‘채택 전체 알고리즘보다 우수’ 결론을 보류한다.

최종 보고 문구는 ‘개발 자료에서 선정한 후보’로 한정한다. 새 날짜·설치·QR 내용의 미사용 촬영과 실제 T정렬→이동·재촬영→Y정렬 검증 전에는 생산 환경의 최종 승자로 확정하지 않는다.
