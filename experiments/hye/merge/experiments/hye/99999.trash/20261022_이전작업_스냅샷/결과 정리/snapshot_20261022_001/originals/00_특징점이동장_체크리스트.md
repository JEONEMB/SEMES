# 특징점 이동장으로 Y, Θ 구분: 고려 요소 체크리스트

질문: v5 패치 이동장(픽셀 단위)을 특징점 단위로 바꾸면 Y와 Θ를 구분할 수 있나?
코드는 `analysis_v6/`, 결과 파일은 42번부터. 원본(사진, 14번, 15번 CSV)은 읽기만 한다.
각 항목은 [ ] 미확인, [x] 확인 완료, [!] 확인했더니 문제 있음. 확인 결과는 항목 아래 "→"로 적는다.

---

## A. 먼저 알고 들어갈 것 (기존 분석에서 이미 나온 사실)

- [ ] A1. 구분 단서는 "평균 이동"이 아니라 "이동 무늬의 차이"뿐이다.
  Y 1mm ≈ 14.39px, Θ 1 ≈ 80.66px라서 Θ 0.178이 Y 1mm와 평균 이동이 같다. 남는 건 위치마다 다른 이동량(원근, 시차).
- [ ] A2. QR 판은 평평하다. 평평한 판에서는 Y와 Θ의 차이가 원근 변환(키스톤) 성분뿐이다.
  특징점이든 패치든 같은 판 위의 점이면 같은 정보를 본다. 그래서 QR만 쓰면 큰 개선은 기대하기 어렵다 (이걸 숫자로 확인하는 게 목적 중 하나).
- [x] A3. 깊이가 다른 점(뒤쪽 벽 볼트, 레일, 브래킷)은 시차가 생겨 구분 단서가 크다 (v1, v3: Y 12~19µm).
  v5의 "나사"는 판 위에 있어서 깊이가 같다. 그래서 QR+나사가 QR만과 거의 같았다 (19.5 → 21.8).
  → 확인 (v1 특징점 51개). 점마다 Y기울기/Θ기울기 비: 판 위 0.177~0.178, 위쪽 브래킷 0.16~0.17, 아래 벽 0.143, 먼 벽 볼트 0.137.
     비가 23% 차이 = Y와 Θ를 가르는 직접 단서. 판 위 점끼리는 차이가 0.001 수준.
- [ ] A4. v5 결과 기준선: QR만 구분 단서 19.5σ (Y 1mm당), 3σ 구분 최소 |Y| ≈ 0.15mm. 판정 오류 3~23장.
- [ ] A5. G1(픽셀 직접) Y RMS 91µm, 구분 불가 Y 12/80, Θ 8/71. v1 QR 내부 특징점 263개(Q7) 137µm.

## B. 정답값(라벨)과 평가

- [ ] B1. 명령값에 백래시, 드리프트 오차가 있다 (구간마다 0점이 최대 0.6px ≈ Y 0.04mm). raw와 보정본 두 기준으로 채점.
- [ ] B2. 보정본은 영상(QR 평균 이동)으로 만든 라벨이다. "실제 위치 기준" 점수가 좋게 나오는 건 일부 순환일 수 있음을 표시.
- [ ] B3. center 사진은 밝기 +1.2%, 0점이 Y 30~50µm 어긋나 있다. 기준 영상으로 그대로 쓰지 않는다 (학습 사진 평균 템플릿, 폴드마다 따로).
- [x] B4. 교차검증: 촬영 순서 짝/홀 (v5와 동일) + 촬영 구간 하나 빼기 (드리프트, 15분 공백에 약한지).
  → 구간 빼기도 짝/홀과 비슷하거나 더 좋음 (판밖 포함 판정 오류 0~1장). 드리프트에 약하지 않음.
- [ ] B5. 구분 판정 규칙을 v3, v5와 같게 맞춘다: (a) 가설 비용 비교(v5), (b) 규칙3 (짝의 Θ에서 3σ). 구분 불가 Y n/80, Θ n/71, 전부 불가 범위, 전부 구분 시작점.
- [ ] B6. 허용 오차 0.09 (Y mm로 가정, Θ 허용치 미확인). 축을 틀리면 실패 (둘 다 0.09 안이면 통과).
- [ ] B7. 반복 촬영이 없어서 순수 영상 잡음과 스테이지 오차를 나눌 수 없다. 잡음은 학습 잔차로 추정 (보수적).

## C. 특징점 고르기

- [ ] C1. 후보: QR 모듈 모서리(판 위), 판 밖 구조물(벽 볼트, 레일, 브래킷 모서리). 영역별로 따로 집계.
- [ ] C2. 2차원 무늬가 있는 점만 (구조 텐서 작은 고유값 기준). 한 방향 줄무늬(모서리 아닌 경계)는 한 방향만 잴 수 있다.
- [ ] C3. 포화(255) 영역 제외: 나사 와셔, 볼트 반사광. 포화 픽셀은 이동해도 밝기가 안 변한다.
- [ ] C4. 위치마다 바뀌는 것 제외: "ADDRESS 240" 라벨, 케이블(늘어지며 흔들릴 수 있음).
- [ ] C5. Θ ±1에서 ±81px 움직여도 사진 밖으로 나가지 않는 점만.
- [x] C6. (확인: 템플릿 안 겹침, 이웃 잡음 상관 0~0.05. 겹친 v5 패치는 0.65 → F3) 점 사이 간격: 템플릿이 겹치면 잡음이 서로 얽혀서 "점이 많다 = 정보가 많다"가 아니다. 겹침 없이 고르거나, 겹침을 계산에 반영.
- [x] C7. 깊이(거리) 다양성: 각 점의 Y 기울기 / Θ 기울기 비 (= 1/거리에 비례) 분포를 그려서 실제로 깊이가 다른 점이 몇 개인지 확인.
  → 판 위 점 비 0.1776~0.1788 (거의 한 값), 판밖 0.142~0.178. 판 위와 0.01 넘게 다른 판밖 점: 17px 50개, 25px 27개.

## D. 특징점 위치 재기 (서브픽셀)

- [x] D1. 신호 크기: 구분 단서는 점마다 0.02~0.06px. 측정 편향이 이보다 작아야 한다.
- [x] D2. 템플릿 매칭 + 포물선 보간(v1 방식)은 정수 쪽으로 끌리는 편향(픽셀 고착)이 있다. 합성 이동 시험으로 크기를 잰다.
  → 확인. v1 방식 편향 -0.03~-0.05px, 점마다 흩어짐 0.02~0.04px (합성, 0.25px 이동). 구분 단서와 같은 크기라 v1 특징점 결과(Q7 137µm)가 나빴던 이유 중 하나.
- [x] D3. 기본 방법: 정수 위치 찾기(정규화 상관) → 가우스-뉴턴 정밀화 (이동 2 + 밝기 a, b), 3차 스플라인 보간. OpenCV remap 쓰지 않음 (1/32px 잘림).
  [!] 새로 찾은 문제: QR 무늬가 반복돼서 ±110px 넓게 찾으면 다른 모듈에 잘못 붙음 (0.5px 이동에서 최대 108px 오류). → 큰 템플릿(81x81)으로 대략 위치, 작은 템플릿으로 ±4px 정밀 탐색하는 2단계로 해결.
- [x] D4. 큰 이동에서 모양 변화 → 무시 가능. 실제 사진에서 |Θ|<0.3과 |Θ|>0.7의 점마다 흔들림이 0.0148 vs 0.0166px (hp12)로 거의 같음.
- [x] D5. 기준 템플릿 하나를 모든 사진에서 추적 (재검출 안 함).
- [x] D6. 밝기 a, b를 같이 푼다.
- [x] D7. 합성 검증 통과. GN 편향 ≤ 0.001px (0~0.5px, 40px, -80px 모두), 흩어짐 QR 0.002~0.003px, 판밖 0.005~0.007px (이론 한계의 1.2~1.5배).
- [!] D8. 실제 데이터: QR 평균 vs 14번 CSV 차이 표준편차 0.0145px (기준 0.02 통과, 최대 0.095px).
  하지만 실제 사진의 점마다 흔들림은 합성보다 6~8배 큼: 가로 0.015px (17x17 템플릿이면 0.021px), 세로 0.010px.
  → 원인 진단: 센서 잡음 아님 (실제 σ 0.62), 자세 흔들림 아님 (원근 무늬로 안 줄어듦), 픽셀 위상 편향 아님 (설명 8%), 점끼리 독립 (상관 0~0.1), 사진끼리 독립.
     사진마다 흔들림 크기가 3배까지 다르고 (0.011~0.034px) 덜 선명한 사진일수록 큼 (상관 -0.34). 사진마다 미세한 흐림(진동, 초점)이 모서리 모양을 바꾸는 것으로 추정.
  → 결론: 점마다 서로 독립인 잡음 0.015px로 취급 가능. 점 N개 평균이면 √N배 줄어든다.

## E. 모델 (이동 무늬 → Y, Θ)

- [ ] E1. 점마다 1차 (d = s·v + b), 2차 (+ c·v²). 2차는 회전 중심이 떨어져 있을 때의 휨.
- [x] E2. 방해 무늬(세로 평행 이동, 화면 내 회전)를 넣을지: Θ에는 세로 이동 0.43px가 따라온다 (회전축 기울어짐). 이걸 방해 무늬로 지우면 구분 단서 하나를 버리는 것. 넣은 경우 / 뺀 경우 둘 다 계산.
  → 영향 작음. QR만 최소 |Y| 0.224 (없음) / 0.242 (v5) / 0.248 (+크기). 세로 이동 단서는 거의 도움 안 됨. 판밖은 차이 없음.
- [ ] E3. 잡음 가중: 점마다 잡음 분산 (학습 잔차). 점마다 x, y 따로.
- [ ] E4. 튀는 점 방어 (Huber).
- [ ] E5. 십자 데이터: Y와 Θ가 동시에 움직인 사진이 없다. "Y만 / Θ만" 가설 비교가 주 방법, 동시 추정은 참고.

## F. 구분 가능성 계산 (이게 핵심 답)

- [x] F1. 이론 한계 (3σ로 구분되는 최소 |Y|, v5 방해 무늬). `analysis_v6/t6_F1.csv`
  | 대상 | 점 | 잡음=맞추기 잔차(v5식) | 잡음=점마다 독립 |
  |---|---|---|---|
  | 특징점 17px, QR만 | 177 | 0.24mm | 0.14mm |
  | 특징점 25px, QR만 | 98 | 0.30mm | 0.14mm |
  | 특징점 17px, 판밖만 | 130 | 0.015mm | 0.009mm |
  | 특징점 17px, QR + 판밖 | 309 | 0.011mm | 0.007mm |
  | v5 패치, QR만, 겹침 (v5 보고값 재현) | 397 | 0.146mm | 0.060mm |
  | v5 패치, QR만, 안 겹침 | 104 | 0.29mm | 0.12mm |
- [x] F2. 영역 조합별 → 판밖 점이 들어가면 20배 좋아짐. QR을 더해도 판밖만과 거의 같음 (판밖이 정보 대부분).
- [!] F3. 같은 영역에서 v5 패치와 비교 → QR만이면 특징점 ≈ 패치 (0.24 vs 0.29, 0.14 vs 0.12). A2 확인.
  v5의 "0.15mm"는 16px 겹친 패치 잡음을 독립으로 센 값이라 낙관적 (이웃 패치 잡음 상관 0.65, 32px 떨어져도 0.35). 정직한 값 약 0.25~0.3mm.
- [x] F4. 실제 판정 (교차검증, `t7_F4.csv`)
  - QR만: 판정 오류 3~22장, 틀린 사진은 |Y| ≤ 0.25mm, |Θ| ≤ 0.15 (일부 0.24)에 몰림. 매핑(1차/2차)과 라벨에 따라 Y쪽 / Θ쪽으로 오류가 쏠림 = 경계에서 두 가설 비용이 거의 같다는 뜻. v5 패치(6/0 등)와 같은 수준.
  - 판밖 포함: 판정 오류 0~4장, 틀린 사진은 Y 0.05, Θ ±0.01~0.02뿐. 보정본 + 2차, 구간 빼기 검증에서 0장. 0.09 통과 99.6~100%.
  - 이론(3σ 최소 |Y|)과 실제 구분 시작점: QR만 0.14~0.3 vs 0.25~1.3 (실제가 더 나쁨: 모델 불일치), 판밖 0.01 vs 0.05~0.11 (가장 작은 값에서만 틀림).
