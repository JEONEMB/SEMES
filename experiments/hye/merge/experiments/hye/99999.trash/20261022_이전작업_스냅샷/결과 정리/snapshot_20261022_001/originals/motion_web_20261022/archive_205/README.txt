Motion Studio

실행: 이 폴더에서 python server.py
접속: http://127.0.0.1:8765
필요 패키지: numpy, opencv-python, scipy

실제 고정 center와 기존 six_origin_205_restored 실험 모델을 읽기 전용으로 사용합니다.
파일명은 브라우저에서 형식 확인 및 추론 후 정답 평가에만 쓰이며 서버로 전송하지 않습니다.
서버 입력은 이미지 바이트뿐입니다. 예측 완료 후 브라우저에서 파일명 정답과 비교합니다. 축/부호, Y/T 벡터 절대오차, 0.09 기준 통과 여부를 표시하고 결과 JSON에 포함합니다.
좌측: 고정/현재 205점, 변위 화살표(길이 20배), 절대 차이 영상.
우측: Y(mm), T(물리 단위 미확정), 추적 진단.
기준 데이터 경로는 기존 measurement/measure.py의 ROOT를 따릅니다.
기존 설치의 3840x2160 원본용입니다. 새로운 환경은 별도 보정이 필요합니다.
모델은 전체 학습된 실험 모델이므로 기존 사진은 재대입 추론입니다.
규칙 단일 원본: ../ALGORITHM_RULES.md

Python/OpenCV 서버가 필요하여 로컬 실행용으로 제공됩니다.
외부 배포에는 Python 추론 서버와 비공개 데이터 배포 설정이 추가로 필요합니다.
