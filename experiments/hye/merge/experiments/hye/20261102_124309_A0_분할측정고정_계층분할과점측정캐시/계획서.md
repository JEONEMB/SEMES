# A0 실험 계획서 — 분할 고정과 점 측정 캐시

작성: 2026-11-02 · 근거: [문헌 종합 v3](../../../docs/hye/문헌연구/00000_문헌연구_종합_결과보고_v3.md) · [실험 계획](../../../docs/hye/문헌연구/00003_실험계획.md) · 규칙: [ALGORITHM_RULES](../../../ALGORITHM_RULES.md)

## 0. 이 실험이 왜 먼저인가

실험 계획 1절은 "분할 파일은 A1 시작 전에 한 번 만들어 고정하고 모든 실험이 같은 파일을 쓴다"고 정했다. A1~A9는 모두 같은 575장의 같은 점 측정과 같은 fold를 써야 서로 비교된다. 그래서 A0에서 **분할과 측정을 한 번 확정해 파일로 굳히고**, 이후 실험은 사진을 다시 측정하지 않고 이 캐시만 읽는다.

A0은 가설을 검증하지 않는다. 뒤의 9개 실험이 공유할 입력을 만든다.

## 1. 허용오차 기준 (2026-11-02 변경)

| 항목 | 값 | 비고 |
|---|---|---|
| 5회 반복 정밀도 (전폭) | 0.09 | 사용자 확인 2026-11-02 |
| **한 장의 허용 절대오차** | **±0.045** | 이 값으로 통과를 판정한다 |
| 독립 기준기 요구 정밀도 | 0.015 이하 | 허용오차의 1/3 (Cheng 2013 비율) |
| 판정용 "작다" 경계 | 0.015 | 이전 계획의 0.03을 절반으로 내린 값 |

이전 실험의 0.09 기준 성적(337/341, 280/280)은 당시 기준 그대로 두고 환산하지 않는다.

## 2. 입력 자료

| 세트 | 장수 | 구성 | 조건 묶음 수 |
|---|---|---|---|
| clean_20261014 | 281 | center 1, Y 단독 80(0.05 mm 간격), T 단독 200 | 281 (반복 없음) |
| clean_20261020 | 60 | 기준 위치 3장, 혼합 19조건 × 3장 | 20 |
| clean_20261029 | 234 | Y+0.05 고정, T 0.04~0.82 78조건 × 3장 | 78 |
| **합계** | **575** | | **379** |

정답은 파일명 명령값(Y mm, T deg)이다. 동봉 TXT 원시값은 정답으로 쓰지 않는다(규칙).

## 3. 단계별 방법

### 3.1 조건 묶음 (group)

같은 `(세트, Y 명령, T 명령)`을 한 묶음으로 만든다. 반복 3장은 반드시 같은 묶음, 따라서 같은 fold에 들어간다. 379개 묶음이 나온다.

### 3.2 혼합 분할 (주 평가, 4-fold)

1. **1014의 280장은 기존 고정 4-fold 배정을 그대로 쓴다.** 출처는 [`20261028_1327_final_Y_T control/validation/splits.json`](../../20261028_1327_final_Y_T%20control/validation/splits.json)이며 파일명으로 대조한다. 기존 결과와 비교 가능성을 지키기 위해서다.
2. `center.bmp`는 측정 기준 영상이라 어느 fold의 시험에도 넣지 않는다 (`fold = -1`).
3. 1020, 1029의 묶음은 **계층 배정**한다. 세트별로 `(Y 명령, T 명령)` 오름차순으로 정렬한 뒤 fold 0,1,2,3을 돌려 가며 준다. 정렬 순서가 곧 크기 계층이므로, 각 fold에 작은 T부터 큰 T까지 고르게 들어간다.
4. 난수를 쓰지 않는다. 같은 코드를 다시 돌리면 같은 배정이 나온다.

### 3.3 날짜 분할 (일반화 평가, 3-fold)

`fold_date` = 1014 → 0, 1020 → 1, 2029 → 2. 날짜 하나를 통째로 빼고 나머지 둘로 학습한다.

### 3.4 점 측정

채택 측정기를 그대로 쓴다. 새 측정기를 만들지 않는다.

| 항목 | 내용 | 출처 |
|---|---|---|
| 기준 영상 | `clean_20261014/center.bmp` (sha256 고정 확인) | control assets |
| 점 집합 | 고정 630점 (그중 536점이 `selected`) | `control/assets/points.json` |
| 측정 | QR별 NCC 정수 이동 → 피라미드 LK(15×15) → 스플라인 GN 12회 | `control/src/tracker.cpp` |
| 유효 판정 | 정역 일치 < 0.5 px, 초기값 대비 < 1.5 px, 마지막 보폭 < 0.02 | 같은 파일 |
| 선 측정 | 허용된 위·아래 가로선 48블록의 법선 프로파일 이동량 | `joint/src/line_profile.cpp`, `joint/assets/line_protocol.json` |

선 48블록은 2026-10-23 사용자가 허용한 위·아래 가로 구조물 선만 쓴다. 볼트·브래킷·배경 텍스처는 쓰지 않는다(규칙 77행).

### 3.5 캐시 파일

| 파일 | 형식 | 크기 | 쓰는 실험 |

## 4. 판정 기준

A0은 가설 판정이 아니라 **점검**이다. 아래를 모두 만족해야 A1 이후로 넘어간다.

| 점검 | 통과 조건 |
|---|---|
| 자료 무결성 | center.bmp sha256 일치, 575장 전부 3840×2160 |
| 측정 성공 | 측정 예외 0장. 예외가 나면 해당 장을 목록에 남기고 제외 표시 |
| 유효점 | 536 선택점의 유효 비율 중앙값이 0.95 이상 |
| 분할 | 묶음이 fold를 가로지르지 않음, fold별 장수 편차 10% 이내, 1014 배정이 기존 splits.json과 100% 일치 |
| 재현성 | 두 번 돌려 캐시 바이트가 동일 |

## 6. 한계

- 이 측정은 **채택 측정기 1종**이다. 측정기 비교는 2026-10-29 실험들이 이미 했고 여기서 다시 하지 않는다.
