# A17 결과 - control 범위 밖 정수 이동 실패

`실험/src/main.cpp` 가 다시 쓴다. 해석은 [보고서](보고서.md). 계획은 [계획서](../계획서.md).

세 전략은 정수 이동 단계만 다르고 정밀화와 유효 판정은 같은 코드다. 참 정수 이동의 대리값은 `dx = 14.2491*Y + 80.0650*T` 다(A16).
