# A3 실험 계획서 — 실제 오차의 방향과 날짜 일반화

가설: **H01**(Y/T 감도 공선, 실측 확인), **H18**(선택 편향) · 우선순위: 둘 다 최상
작성: 2026-11-02 · 입력: [A0 캐시](../20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache) · 선행: [A2](../20261102_130257_A2_YT식별성_정보행렬약한방향/결과/보고서.md)

## 1. 묻는 것

1. A2가 이론으로 계산한 **약한 방향에 실제 오차가 몰리는가?**
2. 학습에 쓰지 않은 **날짜**에서 성적이 떨어지는가?

A2는 정보 행렬에서 약한 방향 각도가 0.00°(ΔY = −5.617ΔT와 일치)임을 냈다. 그것은 선형·가우스 가정 아래의 **하한**이다. 실제 추정기가 정말 그 방향으로 틀리는지는 돌려 봐야 안다.

## 2. 기준 모델

**전달한 joint/control 모델이 아니다.** fold마다 다시 학습할 수 있어야 해서 만든 진단용 대리 모델이다. 여기 성적을 전달 모델의 성적으로 쓰지 않는다.

| 항목 | 내용 |
|---|---|
| 특징 | QR별 아핀 6 × 3 = 18, 선 48블록 이동량 = 48. 합 **66차원** |
| 아핀 정의 | QR마다 `d = B·[1, (x−cx)/100, (y−cy)/100]`를 선택 536점에 맞춘 계수 |
| 추정 | `(Y, T) = W·f + c`, 최소제곱 |
| 학습 | **fold 안의 학습 사진에서만** W, c를 정한다 |

이 요약을 고른 이유는 물리에 맞기 때문이다. A2가 보였듯 Y는 거의 순수 평행이동(아핀의 상수항), T는 평행이동 + 배율 기울기(아핀의 1차항)이고, 선은 회전 투영을 크게 본다.

## 3. 쓸 수 있는 자극

A0의 자극 지도 그대로다. 두 분할을 **둘 다** 돌린다.

| 분할 | 구성 | 무엇을 재나 |
|---|---|---|
| 혼합 4-fold (주) | 575장을 묶음 단위로 4등분. 1014는 기존 `splits.json` 배정 유지 | 같은 날짜의 이웃 조건이 학습에 있을 때의 성적 |
| 날짜 3-fold | 날짜 하나를 통째로 뺀다 | 날짜가 바뀔 때의 성적 |

관측 조건도 두 가지로 본다. **QR + 양쪽 선**(66차원)과 **QR만**(18차원). 규칙 77행의 4조건 중 선이 있는 쪽과 없는 쪽을 가른다.

T+2.00 12장은 1014 학습 범위 ±1.00 밖이므로 **범위 밖으로 따로 센다**(A0에서 측정도 깨졌다).

## 4. 단계별 방법

1. 네 조합(2 관측 × 2 분할)의 OOF 예측을 낸다.
2. 오차 (eY, eT)의 **상관계수 r**과 **주축 각도**를 낸다. 주축은 오차 공분산의 큰 고유벡터이고, 각도는 ΔY = −5.617ΔT 방향과의 사이각이다.
3. 날짜 3-fold에서 **어느 날짜를 뺐느냐별로** 성적을 나눈다.
4. 1029에서 T 크기(0.04~0.82)에 따른 오차 곡선을 그린다.
5. 지표: Y·T 평균/최대 절대오차, 동시 통과 ±0.045, 참고로 ±0.09.

## 5. 판정 기준 (실험 전 고정)

| 가설 | 조건 | 성립하면 |
|---|---|---|
| **H01 실측** | \|r\| > 0.8 **그리고** 주축이 약한 방향과 10° 이내 | 보정을 2축 문제가 아니라 약한 방향 1축 문제로 다룬다 |
| **H18** | 날짜 fold 통과율이 혼합 fold보다 **10%p 이상** 낮음 | 이후 모든 성능 비교를 날짜 단위 fold로 바꾼다 |
| (부가) | T가 학습 범위 밖으로 갈수록 오차가 커짐 | 외삽 한계로 기록하고 운용 범위를 정한다 |
