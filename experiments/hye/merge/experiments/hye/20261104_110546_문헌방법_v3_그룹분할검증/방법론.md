# 문헌 방법 비교와 v3 승격 실험 방법론

작성일: 2026-11-04. 상태: **다른 컴퓨터에서 실행할 계획 문서**. 이 문서는 실험 완료·성능 개선·v3 채택을 주장하지 않는다.

적용 규칙: [ALGORITHM_RULES.md](../../../ALGORITHM_RULES.md), [AGENTS.md](../../../AGENTS.md). 목표·관측 제한·공식 허용오차의 단일 원본은 공통 규칙이다. 구현은 C++17, 팀 실행 환경은 Windows x64 / MSVC v141 / OpenCV 3.4.15이다.

사용자 최종 요청에 따라 **폴더 구조와 방법론만 남긴다.** 앞서 착수했던 무작위 80/20 반복 실행은 아래의 5-fold 프로토콜과 다르므로 본 실험 결과나 승격 근거로 사용하지 않는다. 현재 폴더에는 실행 코드·모델·평가 결과를 포함하지 않는다. 기존 v1/v2와 활성 모듈 선택은 변경하지 않는다.

## 1. 목적과 용어

문헌 기반 측정·추정 방법을 기존 v2와 동일한 사진·동일한 fold에서 비교한다. 개선이 재현된 모듈에 한해서 `_v3`를 별도 생성한다.

| 용어 | 의미 |
|---|---|
| 1차 촬영 | 20261014 자료 |
| 2차 촬영 | 20261020 자료 |
| 3차 촬영 | 20261029 자료 |
| joint | T 정렬을 위한 추정 모듈 |
| control | T가 0에 가까운 상태에서 Y를 정렬하기 위한 추정 모듈 |
| fold 1~5 | 각 사진이 정확히 한 번 시험되는 외부 5-fold 분할 |

‘1차 촬영 평가’와 ‘joint 평가’를 혼용하지 않는다. 매 fold에서 joint와 control을 각각 학습하고, 각 모델의 결과를 1·2·3차 촬영별로 따로 집계한다. 정지 사진으로 실제 순차 이동·복귀 성공을 입증하지 않는다.

## 3. 자료 구성과 제외 규칙

| 촬영 | 전체 | 제외 center | 사용 사진 | 그룹 단위 |
|---|---:|---:|---:|---|

센터는 회귀 학습과 평가에서 모두 제외한다. 고정 `assets/center.bmp`를 영상 정합의 기준 영상으로 사용하는 것은 유지한다. 이는 center를 정답이 있는 회귀 학습 행에 넣는 것과 다르다. 시험 날짜의 center로 재영점하지 않는다.

파일명 명령 Y/T는 평가 정답이며 실제 자세 계측값이 아니다. 추론 함수에는 파일명·명령값·반복 번호·fold 번호를 제공하지 않는다. 정확한 중복 이미지와 경로 중복을 해시로 검사한다. 중복이 발견되면 서로 다른 fold에 두지 않고 기록한다.

## 4. 반복 3장과 5-fold 분할

### 4.1 그룹을 먼저 만든다

**같은 날짜·같은 자세의 반복 3장은 전부 같은 fold에 넣는다.** 2장은 학습, 1장은 시험으로 나누지 않는다. 인접 반복 사진의 유사성으로 점수가 낙관적으로 나오는 것을 방지한다.

그룹 키는 `(촬영 날짜, 자세 ID)`다. 기존 group ID를 쓸 경우 실제 `(Y,T)`·파일 목록과 대조한다. 센터 제외 후에는 다음 4개 층을 만든다.

1. 1014 Y 단독
2. 1014 T 단독
3. 1020 혼합 자세
4. 1029 자세

각 층의 **그룹 목록**을 고정 seed `20261104`로 독립적으로 섞은 뒤 5개 fold에 균등 배정한다. 그룹 수가 5로 나누어떨어지지 않으면 앞 fold부터 하나씩 더 배정한다. 각 층에는 seed와 층 ID로 구분한 난수 흐름을 사용한다. 생성된 CSV를 정본으로 공유한다. C++ 표준 라이브러리 간 shuffle 구현 차이가 있을 수 있으므로 seed만으로 동일 분할을 보장한다고 쓰지 않는다.

### 4.2 fold별 사용법

| 실행 | 학습 | 평가 |
|---|---|---|
| fold 1 | fold 2·3·4·5의 세 날짜 자료 합집합 | fold 1의 1014·1020·1029, 날짜별 별도 보고 |
| fold 2 | fold 1·3·4·5 | fold 2, 날짜별 별도 보고 |
| fold 3 | fold 1·2·4·5 | fold 3, 날짜별 별도 보고 |
| fold 4 | fold 1·2·3·5 | fold 4, 날짜별 별도 보고 |
| fold 5 | fold 1·2·3·4 | fold 5, 날짜별 별도 보고 |

**기본 실험은 날짜별 모델 3개를 따로 학습하는 방식이 아니다.** 각 fold에서 세 날짜의 학습 부분을 합쳐 joint 모델 1개·control 모델 1개씩 적합하고, 평가를 날짜별로 나눈다. 후보별로 이 과정을 동일하게 수행한다.

그룹 수 기준의 80/20이므로 19개·78개 자세는 정확히 20%로 나눌 수 없다.

| 시험 fold | 1014 Y | 1014 T | 1020 | 1029 | 총 시험 | 총 학습 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 16 | 40 | 12(4자세) | 48(16자세) | 116 | 455 |
| 2 | 16 | 40 | 12(4자세) | 48(16자세) | 116 | 455 |
| 3 | 16 | 40 | 12(4자세) | 48(16자세) | 116 | 455 |
| 4 | 16 | 40 | 12(4자세) | 45(15자세) | 113 | 458 |
| 5 | 16 | 40 | 9(3자세) | 45(15자세) | 110 | 461 |
| OOF 합계 | 80 | 200 | 57 | 234 | **571** | — |

이 표는 중복이나 비정상 그룹이 없다는 사전 검사가 통과했을 때의 예상이다. 실제 분할 목록과 행 수를 반드시 검증한다.

단순히 80/20 무작위 분할을 다섯 번 새로 뽑는 것과 다르다. 위 방식은 시험 집합 5개가 서로 겹치지 않고, 모든 571장이 정확히 한 번 외부 평가에 등장한다. 최종 통과율은 fold 비율의 단순 평균이 아니라 **OOF 전체 통과 수 / 전체 사진 수**로 구한다.

## 5. 유지할 측정과 비교 후보

### 5.1 공통 측정

- control: **630점 LK 정방향·역방향 추적** → 기존 스플라인 GN 정밀화 → 기존 고정 536점 마스크와 center 자기 측정 차감 유지. v2는 536점 중 유효점의 가로 이동 평균을 사용한다. 630점 전부를 회귀에 쓰는 변경과 혼동하지 않는다.
- joint: 기존 QR 3개 NCC/ECC → 가상점 27개 관측을 기준으로 유지한다. 기존 joint는 LK 630점 방식이 아니다. joint까지 LK로 바꾸는 후보는 별도 ablation으로 구분해야 한다.
- 위·아래 바의 허용 ROI, center, 사진 디코딩 방식은 후보 간 동일하게 유지한다.
- 이번 주 비교는 바 측정·기울기 추정의 변경 효과다. QR 추적기와 최종 회귀식을 동시에 바꿔 개선 원인을 섞지 않는다.

### 5.2 후보 목록

|---|---|---|---|
| B0 | 기존 v2 블록 정합 + 비가중 직선 | 기준선 | v2 회귀 계수만 fold별 재학습 |
| B1 | 블록 불확도 기반 WLS 기울기 | 바 24블록 → 기울기 | 불확도 계산식·가중치 하한을 사전 고정하거나 내부 CV |

- B1/B2: `단계/4_특징만들기/논문/04_Zhang2020_ExpFluids_상관오차_GLS가중/`, 공분산 축소 문헌. 상관을 무시한 단순 점 수 증가와 구분한다.
- B3/B4: `단계/4_특징만들기/논문/02_Roux2006_IJF_변위장모드투영_통합DIC/`. 논문의 모드를 그대로 복사하는 것이 아니라 바 이동·기울기 모드로 응용하는 실험이다.
- 불확도 전파: `단계/3_기준과비교/논문/04_JCGM2011_GUM보충2_다출력_공분산전파/`. 선택한 측정기의 s,d 오차를 Y/T로 전달하는 후속 검증이다. 불확도 출력만 추가한 것을 정확도 개선이라고 부르지 않는다.
- 기존 Huber·열 에지·구간 ECC·좁은 블록 비교는 A21 결과를 참고한다. 같은 후보를 새 방법처럼 중복 주장하지 않는다.

기준 B0도 전달 모델을 그대로 재생하지 않고 **동일한 학습 fold로 다시 적합**한다. 모델 JSON은 평가 fold별로 구분한다. 기존 전달 모델 재생은 보조 점검으로만 별도 기록한다.

## 6. fold 안에서 학습하는 순서

1. 전체 목록에서 학습/시험 파일을 분리하고 그룹 교집합이 0인지 검사한다.
2. 이미지에서 정답과 무관한 측정값을 계산한다. 결정론적 고정 측정값은 캐시 재사용 가능하나 이미지·center·측정 코드·파라미터 해시가 같아야 한다.
3. 공분산·가중치·정규화·절편·회귀·문턱 등 **자료에서 배우는 값은 학습 부분에서만** 계산한다. 시험 반복 3장으로 공분산을 구해 학습 기울기에 쓰지 않는다.
4. 학습 데이터에서 같은 자세 반복 평균을 빼 공분산을 추정할 때는 실제 구동계 반복 차이도 섞일 수 있음을 기록한다. 이를 순수 센서 잡음으로 단정하지 않는다.
5. joint는 `[1,s,d] → (Y,T)` 회귀 계수를 학습한다.
6. control은 학습 부분의 T=0 사진으로 `s → Y` 기본 직선을 적합하고, 학습 부분에서 잔여 T 회귀와 T→Y 보정 계수를 적합한다. center는 사용하지 않는다. 매 fold의 1014 T=0 Y 사진은 기본 64장이다.
7. 기본 비교에서는 v2의 soft 문턱을 동일하게 고정한다. 문턱·공분산 축소량을 탐색한다면 **외부 학습 80% 안의 그룹 보존 내부 CV**로만 고르고, 외부 시험 20%는 선택에 사용하지 않는다.
8. 외부 시험 사진의 추정값을 저장한 다음에만 정답과 비교한다. 시험 결과를 보고 fold 모델을 수정하지 않는다.

### 범위 정책

사용자가 지정한 **센터 제외 전체 571장**을 외부 평가에 포함한다. 기존 코드에 있던 `|T|≤1` 필터로 T=2 사진을 평가 분모에서 제거하지 않는다.

기본 비교는 할당된 모든 학습 자세를 사용해 B0~B4를 동일하게 재학습한다. 기존 v2의 학습 범위 `|T|≤1`을 그대로 유지하는 비교가 필요하면 **별도 조건**으로 추가하되, 모든 후보에 같은 조건을 적용하고 범위 밖 시험 사진도 실패·외삽 포함 전수 보고한다. 두 조건을 한 성적으로 섞지 않는다.

## 7. 평가와 보고

### 7.1 기본 결과표

joint와 control 각각에 대해 아래 표를 후보별로 작성한다. 통과 판정은 공통 규칙의 최신 단계별 기준을 사용한다.

| 모델 | fold | 평가 촬영 | 전체 수 | 성공 측정 수 | 허용오차 통과 수/전체 수 | 평균 절대오차 | p95 | 최대오차 | 시간 중앙/p95 |
|---|---|---|---:|---:|---|---:|---:|---:|---|
| B0~B4 | 1~5 | 1014 / 1020 / 1029 | | | | | | | |
| B0~B4 | OOF | 1014 / 1020 / 1029 / 전체 | | | | | | | |

- joint는 T 오차를 주 평가하고 Y는 참고로 보고한다.
- control은 Y 오차를 주 평가한다. T가 큰 사진은 2차 운용 전제를 벗어날 수 있으므로 **전체 결과와 운용 범위 결과를 함께** 보고한다.
- control 보조 표: 정답 `|T|≤0.01`, `≤0.03`, `≤0.1`, `T=0`별 오차. 이는 정답으로 나눈 사후 분석이며 운용에서 알고리즘이 성공적으로 선별한 성적이 아니다.
- 운용 선별 표: 추정 T로 전제 충족을 판정했을 때의 승인율, 승인 사진 Y 통과율, 잘못 승인한 사진 수, 재촬영/복귀 요구 비율. 모든 승인·거부 사진의 분모를 남긴다.
- 반복 표: 1020·1029의 같은 자세 3장에 대한 예측 전폭과 오차 흩어짐. 동일 자세 3장은 같은 외부 모델로 예측돼야 한다. 서로 다른 fold 모델의 예측으로 반복 정밀도를 계산하지 않는다.
- 시간은 동일 기기·스레드 수·Release 환경에서 디코딩/초기화/추론을 구분한다. 캐시 회귀 시간만 전체 추론 시간으로 쓰지 않는다.

### 7.2 실패 포함 규칙

측정 실패·수치 실패·보류를 행 삭제로 숨기지 않는다. 통과율 분모는 원래 배정된 시험 사진 전체다. MAE/p95/최대오차는 수치 출력이 있는 사진에서 계산하고 유효 사진 수를 함께 쓴다. 실패가 있으면 최대오차가 전체 위험을 대표한다고 표현하지 않는다. 실패 사진을 `(0,0)` 정상 예측으로 채우지 않는다.

### 7.3 교란과 불확도

같은 외부 시험 사진의 밝기·흐림·잡음·카메라 세로 이동에 대한 원본 대비 변화량을 같은 조건에서 비교한다. 교란 원본과 변형본은 같은 fold에 속한다. 교란 결과로 하이퍼파라미터를 선택하려면 내부 학습 자료의 교란만 사용한다.

불확도는 단순 정합 잔차를 오차 확률로 부르지 않는다. 예측 구간의 실제 포함률, 구간 폭, 잘못 승인한 비율을 확인한다. 반복 3장 평균은 별도 운용 후보로 평가하며, 독립 잡음 가정 없이 개선량을 무조건 1/√3으로 보장하지 않는다.

## 8. v3 승격 판단

외부 결과를 보기 전에 `config/experiment.json`과 `decision.md`의 판단 규칙을 고정한다.

1. 모든 후보가 동일 분할·동일 학습 정책·동일 평가 분모를 사용했는지 확인한다.
2. 모듈별로 B0 대비 OOF 통과율, 평균·최대오차, 날짜별 실패와 교란 민감도·처리 시간을 비교한다. control은 운용 범위와 전수 외삽 결과를 분리한다.
3. 한 날짜의 큰 악화나 실패 증가를 전체 평균으로 가리지 않는다. 통과 수만 늘고 최대오차·반복 전폭이 악화되면 자동 승격하지 않고 보류 사유를 적는다.
4. 통과율 차이는 동일 사진의 짝 비교로 계산하고, 반복 사진은 자세 그룹 단위 bootstrap 등으로 불확실성을 보고한다. fold 5개는 학습 집합이 겹치므로 독립 표본 5개처럼 유의성 검정하지 않는다.
5. 여러 후보 중 최선의 외부 OOF 성적으로 고른 모델의 점수에는 선택 편향이 있음을 명시한다. 최종 독립 성능 확인은 새 촬영에서 고정 모델로 한 번 수행한다.
6. 개선이 확인된 **모듈만** v3 폴더를 만든다. control만 좋아지면 joint v3를 억지로 만들지 않는다. 개선이 불명확하면 기존 v2를 유지한다.
7. 승격용 배포 모델은 비교를 마친 뒤 center를 제외한 사용 가능 전체 자료로 최종 적합한다. 이 모델의 재대입 점수를 OOF 점수로 표기하지 않는다.
8. v3는 소스·assets·학습 설정·출처·빌드·공개 API 점검을 포함한다. control의 LK 정방향·역방향 630점 측정과 출력 계약을 보존한다. 선택 설정을 v3로 바꿀 때는 채택 결정을 문서에 남긴다.

5-fold 날짜 층화 평가는 **학습에 포함된 날짜의 미학습 자세**에 대한 개발 평가다. 새로운 날짜 일반화 검증과 구분한다. 날짜 일반화가 필요하면 `1014+1020→1029` 등의 날짜 통째 제외 평가를 보조로 추가한다. 이미 모든 날짜가 개발에 노출됐으므로 이를 신규 독립 시험이라고 부르지 않는다.

## 9. 실행 순서와 완료 조건

```text
환경/코드/데이터 해시 기록
 → images·groups 생성(center 제외)
 → 5-fold manifest 생성·고정·검사
 → 정답과 분리한 영상 측정 캐시 생성
 → fold 1: 세 날짜 80% 합쳐 후보별 학습 → 세 날짜 20% 각각 평가
 → fold 2~5 동일 수행
 → OOF 571장 합치기
 → 날짜별·운용범위별·반복·교란·시간 비교
 → 승격 또는 보류 결정
 → 승격 시 전체 자료 최종 학습 및 v3 API 확인
```

도구를 구현할 때의 명령 인터페이스 예시(아직 실행 가능한 도구가 아님):

```text
experiment manifest --config config/experiment.json
experiment split --seed 20261104 --folds 5 --group-by date,pose
experiment measure --config config/experiment.json
experiment run --fold 1
experiment run --fold 2
experiment run --fold 3
experiment run --fold 4
experiment run --fold 5
experiment summarize
experiment package --stage <승격된 모듈>
```

완료 조건:

- center 4장이 학습·평가 행에 없음.
- 같은 날짜·자세의 반복 3장이 모두 같은 fold이며 학습/시험 그룹 교집합 0.
- 각 후보의 OOF 시험 행은 정확히 571개, 사진별 시험 횟수 1.
- B0와 후보의 시험 파일 집합·분모 일치, 측정 실패 행 보존.
- 학습된 모든 파라미터가 fold 학습 자료만 사용함.
- joint/control 각각 1·2·3차 촬영별 표와 전체 OOF 표가 있음.
- 개선 여부와 한계, v3 생성 여부를 decision.md에 기록함.
