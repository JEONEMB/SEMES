# 결과: trial 원점 - 절편 외삽 역산

입력: `data/clean/clean_20261014`의 단일축 280장(center 제외). 변위는 center.bmp 기준 630점 경계 맞춤(현재 - 기준, px)의 1260성분이다.
trial: 파일명 그룹(Y 0.1 간격, Y 0.05 홀수, T 부호)을 원본 zip의 파일 시각 순으로 S1~S6으로 번호 붙였다(#79와 같은 시각 출처, clean 메타데이터에는 시각이 없다).

방법: trial마다 성분별 직선 D = b + a x 명령을 맞춘다. 사진별로 D - a x 명령을 계산해 명령 0으로 외삽하고 trial 안에서 평균한 것이 trial 원점 변위다. J = [Y trial 4개 기울기 평균, T trial 2개 기울기 평균] (1260 x 2)에 최소제곱으로 맞춰 Y0, T0를 얻는다. '공통 기울기'는 a 대신 J의 해당 열을 쓴 경우다.
