# SEMES 다음 촬영과 장비

우선 새 장비 한 대에서 **교정용 사진과 합격 판단용 사진을 처음부터 분리**한다. 교정 과정에서 확인한 사진은 이후 독립 시험에 포함하지 않는다. Y/T 값은 명령, 실제 장비 로그, 독립 계측을 구분해 남긴다.

| 필요한 것 | 촬영·측정 방법 | 답할 질문 |
|---|---|---|
| 장비별 소량 교정 | 센터 1장, Y± 2장, T± 2장으로 시작한다. 양 축이 움직이는 방향·단위를 안전한 범위에서 확인한다. 필요시 더 넓은 양·음 축 자세 4장과 혼합 자세를 추가한다. 각 증분은 장비 허용 범위에서 사전에 정한다. | 5장 또는 9장 교정과 QR 9점+바 48블록이 다른 장비에서도 유효한가 |
| 교정과 분리한 검증 | 위 5/9장에는 손대지 않고 새 날짜의 네 사분면 혼합 자세와 센터 근처를 촬영한다. B6은 **100장 이상**이다. 같은 모델 장비라도 2대 이상에서 각각 교정과 봉인 평가를 시행한다. | 날짜·장비 일반화, 음수 혼합 자세, 소량 교정 실패율 |
| B1 정착·예열 | 기존 계획은 대기 0/0.5/1/2/5초의 **200장**이다. 여기에 이동 종료 신호 전후의 짧은 연속 영상과 실제 프레임 타임스탬프를 붙인다. 예열용 센터 고정 시계열, 전원 켠 시각, 온도, 노출, 속도와 직전 명령을 기록한다. 2.8 Hz 같은 진동을 볼 때 0.5/1초 간격은 느리므로 짧은 연속 구간은 0.1초 이하부터 확인한다. | 진동, 드리프트, 대기, 카메라 예열, 정지 임계 |
| B2 방향·백래시 | Y와 T 각각 같은 목표를 정·역방향에서 30회씩 접근해 총 **120회**. 동일 대기 시간, 시작 자세, 속도, 방향과 독립 위치를 남긴다. 작은 명령 간격도 따로 스윕한다. | 데드존, 방향별 백래시, 한 방향 접근, 실제 부호와 이득 |
| B3 광학 조건 | 기존 노출·초점 스윕 **81장**. 조명 각도·반사·부분 가림과 작업 중 도착 직후 사진을 별도 조건으로 붙이고 자동 노출/초점 설정을 남긴다. | 합성에서 본 밝기·흐림 약점의 실물 재현, 품질 판정 |
| B4 기하와 기준 | 카메라 보정판, QR 피치와 설치 도면, 작업 거리, 회전축 치수와 실제 각도 기록. 장비가 허용하는 T 스윕 **60~90장**. | 물리식 Y/T 분리, 왜곡과 축 위치, 센터 좌표 기준 |
| B5 실제 폐루프 | 독립 시작 자세 **30개**, 각 최대 20턴. 매 턴 원본 영상, 예측, 보낸 명령, 실행값, 이동·정지·촬영 시각, 최종 독립 Y/T를 기록한다. Y만 이동한 뒤 T를 보는 짧은 시퀀스도 포함한다. | T→Y와 동시 이동 비교, 전환·되돌림 문턱, 실제 20턴 성공률 |
| 독립 기준기 및 설비 명세 | 변위·각도 추적이 가능한 독립 기준기, 교정 기록, 반복성·불확도 예산. 사이클 한도, 축 이동 범위, 단위·부호, 최대 속도, 인포지션 신호 의미, 장비 ID와 재장착 기록. | 명령 라벨 편향, 최종 실제 위치와 장비마다의 보정 한도 |

파일마다 `장비 ID / 설치 ID / 세션 ID / 자세 ID / 역할(교정·검증) / 프레임 시각 / 실제 이동 시각 / Y,T 명령 / 계측값 / 접근 방향 / 노출·초점 / 온도`를 남긴다. 한 자세의 반복은 한쪽에만 둔다. 바나 QR의 배치가 달라진 장비에서는 기존 관측 위치의 대응부터 확인한다.

사진을 적게 찍을 수 있는 현장이라면, **한 축을 물리적으로 고정할 수 있는지** 먼저 확인한다. 가능하면 그 축을 고정하고 반대 축의 음·양 교정 사진과 별도의 시험 사진으로 시작한다. 두 축이 독립적으로 바뀌는 장비에서 한 축의 교정 사진만 받으면 그 자료로 두 축의 감도를 새로 구할 수 없다. [현 데이터의 조건별 성적](보고서.md)
