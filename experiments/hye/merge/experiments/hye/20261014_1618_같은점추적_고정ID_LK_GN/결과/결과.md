# 결과: 같은 점 추적 (고정 ID, LK -> GN)

입력: `data/clean/clean_20261014` 281장의 판 영역(x 1340~2470, y 800~1330). center에서 고른 점을 모든 사진에서 같은 ID로 추적했다.

- 점: 흐림 0.65 center에서 QR 상자(경계 28px 침식)마다 Shi-Tomasi(품질 .005, 간격 4) + cornerSubPix, QR 경계 27px 안쪽만. QR 928개(316/302/310), 나사 39개.
- 추적: QR 전체 NCC(±110 x ±22)로 정수 이동 -> 단일 단계 LK(창 15/31/51, 흐림 0.8 선택) 왕복 -> GN17(흐림 0.8, 3차 B-spline, gain/offset, 12회).
- 재검출: 현재 사진에서 같은 규칙으로 점을 다시 뽑아 GN17 추적 위치에서 가장 가까운 점까지 거리.
- 합성: center를 scipy 3차 보간(reflect)으로 알려진 만큼 옮긴 사진 7장, affine 6장.

## 옮기지 않은 부분

- measure.py의 OpenCV warpAffine 합성(synthetic_validation.csv): OpenCV 3.4 warpAffine은 좌표를 1/32 px로 양자화해 Python cv2와 다르다. 원래 노트도 이 값을 scipy 합성과 섞지 않는다.
- refine.py GN31의 실사진 281장 측정(gn31.npz), extract_pair.py(PairExtractor API), spread.py(QR205 측정, 6후보 실험 폴더에서 옮김).
