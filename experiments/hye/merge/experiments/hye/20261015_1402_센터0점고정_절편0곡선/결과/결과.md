# 결과: center 0점 고정 + 절편 0 곡선

입력: `data/clean/clean_20261014` 281장. center 에서 QR 세 상자마다 Shi-Tomasi(간격 14)로 205점을 한 번 고르고, 280장을 center 와 직접 비교해 추적했다(상자 NCC → LK 15px → GN17). center 의 이동은 0 이다. 사진마다 점 이동을 판 좌표 2차식 12값으로 요약했다.

모델: center_quadratic = 축마다 12값 ~ v·s + v²·c (절편 0, 후보 2개 Y/T), center_linear = v·s, legacy_six_origins = 원래 6후보 0점 + 2차. 잔차 상관 백색화 후 비용 최소 축을 고른다.

분할: 재대입 1개 + 원래 `splits.json` 과 같은 규칙으로 다시 만든 118개(교차·층화·덩어리·반복 20회·구간 빼기). sklearn StratifiedKFold 의 섞기는 MT19937 로 그대로 재현해 서명이 모두 같다.
