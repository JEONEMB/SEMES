## 1부. 보상 이동으로 가상 회전 중심 (PT-01 Cognex US9247684)

### 특허가 말하는 것

> 회전 중심이 촬상 범위 **밖**이면 마크 궤적이 짧은 원호라 **등변이 길고 꼭지각이 작아 중심 오차가 크다**(도 9A).
> 범위 **안**에 "설정 회전 중심"을 두고 다시 회전시켜 얻은 중심과의 차로 바깥 중심을 보정한다.

### 우리 2축에 옮기면

특허는 X·Y·θ 3축이라 평행이동으로 가상 중심을 만든다. 우리는 Y·T 2축뿐이지만 **"T 회전 + 보상 Y 이동"**을 함께 주면 판이 제자리에 머문다. 그 보상비가 곧 **지렛대(등가 회전 반경)**다.

```
14.25·ΔY + 80.06·ΔT = 0   →   ΔY = −5.617·ΔT
```

### 방법

**세션 안의 조건 쌍**만 쓴다. 쌍의 차를 보면 세션 영점 드리프트가 빠진다(A15 가 그 드리프트를 확인했다).

1. 같은 세트의 두 조건 (i, j) 마다 명령 차 (ΔY, ΔT) 와 실측 판 이동 차를 모은다.
2. `Δ(판 dx) = a·ΔY + b·ΔT` 를 맞춘다. 지렛대는 b/a.
3. ΔY ≈ −5.617·ΔT 인 쌍(보상에 가까운 쌍)에서 판이 실제로 안 움직이는지 본다.
4. Cognex 의 1/tan(각/2) 로 T 범위를 넓혔을 때의 이득을 계산한다.

## 2부. 대칭·극값으로 축 찾기 (PT-04 Kawasaki US11749547)

### 특허가 말하는 것

> 회전 위치를 여러 값으로 바꿔 잰 1차원 신호에서 **"같은 값이 나오는 두 위치의 가운데"**와 **"최댓값"**만으로 회전 중심을 찾는다. 원 맞춤 같은 **매개변수 추정이 없다.**

### 우리에 옮기면

선 블록의 세로 응답은 `v = C(x − x0)(y − y0)` 이므로 **x = x0 에서 부호가 바뀐다.**

- 줄마다 x 에 대한 직선을 맞춰 **영교차점**을 찾으면 x0
- 두 줄의 기울기 비로 y0: `slope ∝ (y − y0)` 이므로 `slope_up/slope_lo = (y_up − y0)/(y_lo − y0)`

**모형 전체를 적합하지 않는다.** A13 의 최소제곱(1919.0, 1097.0)과 비교해 **서로 검증**한다.

## 판정 기준 (실험 전 고정)

| 조건 | 판정 |
|---|---|
| 쌍에서 구한 지렛대가 A13 의 등가 반경(315.9 mm)과 2% 이내 | 서로 확인됨 |
| 보상 쌍에서 판 이동이 잡음 수준(0.01 px) | 보상 관계가 정확하다 |
| 대칭법 x0·y0 가 A13 과 10 px 이내 | 두 방법이 일치. 보정값을 믿을 수 있다 |
| 두 줄의 영교차점이 서로 다르다 | **모형이 불완전하다.** A13 의 값을 다시 봐야 한다 |

## 한계

- **진짜 보상 자세를 찍은 자료가 없다.** Y<0 이면서 T>0 인 혼합 자세가 하나도 없어서(A0 자극 지도), 쌍의 차로 대신한다. 쌍의 차는 "두 자세를 따로 찍은 것"이지 "보상 자세 한 장"이 아니다.
