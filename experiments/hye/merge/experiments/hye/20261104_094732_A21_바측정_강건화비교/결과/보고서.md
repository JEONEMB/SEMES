# A21 보고서: 위·아래 바 측정 강건화 비교

실행 2026-11-04 · 요청: 사용자 ("바 측정 강건하게 만드는 것을 반드시 실시하고, 각각 실험해서 검증 결과를 보고") · 앞 실험: [A19](../../20261104_093558_A19_QR선측정_안정성점검/결과/보고서.md)(바 블록이 잡음·조명에 흔들림, 카메라 세로 이동에 joint T 민감), [A20](../../20261104_093913_A20_실제joint측정_세션재영점/결과/보고서.md)(QR 평균 가로 이동 + 바 기울기 차 2특징이 다른 날짜로 잘 넘어감)

- **문제:** joint T를 카메라 이동, 밝기, 흐림, 잡음, 조명에 강건하게 하려면 바를 어떻게 재야 하는가?
- **해결:** 바 기울기 측정 5가지를 같은 575장, 같은 교란 11종 × 31장, 같은 2특징 모델 `(Y, T) = W · [1, s, d]`로 비교했다. s = QR 27점 가로 이동 평균(ECC, A19 캐시), d = 위 바 기울기 − 아래 바 기울기.
- **결과:** **측정 방법은 지금 블록 정합(S0)이 가장 좋다.** 강건성은 블록 값을 그대로 쓰지 않고 **기울기 차**로 바꾼 데서 나온다. 카메라 세로 0.5 px 이동에 T 변화가 지금 joint의 최대 0.033에서 **최대 0.0015**로 줄었다. 남은 약점은 영상 잡음이다.

## 4. 해석

- **카메라 세로 이동:** 기울기 차는 바 전체가 같이 오르내리는 성분을 지운다. 그래서 날짜 사이 카메라 이동(0.44 px)이 T로 새지 않는다. 이것이 A20에서 다른 날짜 1029가 0% → 99.6%로 바뀐 이유다.
- **측정 방법:** S0의 블록 정합은 블록마다 밝기 아핀을 맞추고 64 px를 평균해 이미 강건하다. 표본을 늘린 S4, 에지만 보는 S2, 구간을 통째로 맞춘 S3는 어느 것도 S0을 넘지 못했다. S2는 극값 3점 포물선의 부화소 편향이 커서 쓸 수 없다. S3는 바 구간 안의 질감이 적어 ECC가 불안정하다.
- **Huber(S1):** 실제 사진에서 이상 블록이 없어 이득이 없고, 잡음에서는 조금 더 흔들린다.
- **남은 약점은 영상 잡음이다.** 실제 잡음(σ ≈ 1.05)에서 1장 T 흔들림은 최대 약 0.003~0.004, σ2에서 0.007이다. 한 자리 3장 평균이면 √3배 줄어든다.

## 5. 결정

- joint_v2의 바 측정은 **S0(지금 블록 정합)을 유지**하고, 특징을 **바 기울기 차 d**로 바꾼다. 블록 48값을 회귀에 직접 넣지 않는다.
- 1장 T 흔들림을 더 줄여야 하면 운용에서 같은 자리 N장 평균을 쓴다(측정 방법 변경보다 효과가 확실하다).
- 실험한 4개 대안(S1~S4)은 채택하지 않는다. 결과는 근거로 남긴다.

## 한계

- 교란은 합성이다(FFT 정확 이동, 전역 밝기, 가우스 흐림·잡음, 가로 조명 기울기). 실제 반사·그림자·부분 가림은 시험하지 않았다.
- 575장 모두 개발에 노출된 자료다.
- S3는 OpenCV 5.0의 기본 `findTransformECC`가 마스크 없이 호출하면 내부 예외를 내서, joint와 같은 호환 ECC(`ecc_compat`, 마스크 지정)로 실행했다.
