# A6 실험 계획서 — 추정 모델 대조

가설: **H02**(평면 자세 이중해), **H06**(축 교정), **H07**(왜곡), **H15**(정규화 부족) · 우선순위: 중
작성: 2026-11-02 · 입력: [A0 캐시](../20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache)

## 1. 묻는 것

**같은 측정에서, 어떤 추정 모델이 가장 나은가?** A3이 기준 모델(66차원 선형, 혼합 4-fold 95.7%)을 세웠다. 그보다 나은 것이 있는지 같은 분할에서 비교한다.

## 2. 쓸 수 있는 자극

A3과 같다. 혼합 4-fold(주 평가)와 날짜 3-fold(일반화)를 **둘 다** 보고한다. A3에서 날짜 fold가 모델 성능이 아니라 자극 결손을 잰다는 것이 드러났으므로, 날짜 fold 성적을 단독으로 모델 우열의 근거로 쓰지 않는다.

## 3. 비교군

| ID | 모델 | 무엇이 다른가 | 대응 가설 |
|---|---|---|---|
| M0 | OLS 66차원 (대조) | A3의 기준 모델 | — |
| M1 | Ridge 66차원 | λ를 **fold 안의 내부 CV**로 고른다 | H15 |
| M2 | 백색화 + Ridge | 반복에서 잰 특징 잡음 공분산으로 특징을 백색화한 뒤 Ridge | H11 |
| M3 | 물리 전방 역해 | 학습된 회귀 대신 감도 J의 가중 최소제곱 역해. (Y,T) 라벨로 회귀를 맞추지 않는다 | H06 기반 |
| M4 | OLS + 2차항 | 66차원에 주요 항의 제곱·교차를 더한다 | 비선형, H07 |
| M5 | QR만 18차원 | 선을 뺀다 | 관측 비교 |
| M6 | 선만 48차원 | QR을 뺀다 | 관측 비교 |
| M7 | 전체 점 1260차원 → PCA | 요약(아핀) 대신 점 전부 | 요약 손실 확인 |

### 하지 않는 것과 이유

계획서 원안의 **호모그래피/IPPE 물리 모델(H02)**은 카메라 내부 파라미터 K가 없어 제대로 세울 수 없다. K를 추정하려면 알려진 3차원 좌표나 넓은 자세 변화가 필요한데 우리 자극은 (Y,T) 평면의 십자와 선분뿐이다(A0). **대신 M3(물리 전방 역해)로 대체**하고, H02(이중해)는 A2의 점 수 근거(536점, Oberkampf의 4점 대비)로 우선순위 하로 유지한다.

**왜곡 항(H07)**도 K 없이는 제대로 못 넣는다. M4의 2차항이 그 효과를 일부 흡수하는지만 본다.

## 4. 평가

- 지표: Y·T 평균/최대 절대오차, **동시 통과 ±0.045**, 참고로 ±0.09
- 분할: 혼합 4-fold(주), 날짜 3-fold(병기)
- T+2.00 12장은 범위 밖으로 따로 센다
- λ는 **각 외부 fold의 학습 사진만**으로 3-fold 내부 CV에서 고른다. 시험 사진을 보지 않는다
- 처리 시간: 캐시에서 특징 추출 + 예측까지의 시간. **점 측정 자체의 비용은 A0에서 쟀고(575장 15초, OpenMP) 모델 간에 같다**
