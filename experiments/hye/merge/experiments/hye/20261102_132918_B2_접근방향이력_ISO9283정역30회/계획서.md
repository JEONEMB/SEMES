# B2 실험 계획서 — 접근 방향 이력 (ISO 9283식)

가설: **H13**(접근 방향 이력, 백래시) · 상태: **촬영 대기**
작성: 2026-11-02 · 선행: [A1](../20261102_125341_A1_반복잡음과세션영점_공분산과유효점수/결과/보고서.md), [A3](../20261102_130739_A3_오차방향과날짜일반화_날짜fold대조/결과/보고서.md)

## 1. 묻는 것

**같은 목표에 +방향으로 가는 것과 −방향으로 가는 것이 다른가?** 다르다면 얼마나 다르고, 단방향 접근 정책으로 없앨 수 있는가?

## 2. 왜 기존 자료로 안 되는가

기존 575장에는 **접근 방향 기록이 없다.** 파일명은 목표 명령만 담는다. 1014의 Y 80장이 −2.00에서 +2.00까지 순서대로 찍혔다면 전부 같은 방향 접근이고, 그렇다면 백래시는 자료 전체에 **공통 편향**으로 숨어 있어 보이지 않는다.

A1은 반복 3장 사이 판 이동 SD가 0.0852 px(≈0.006 mm)임을 쟀다. 이것이 같은 방향 접근의 재현 오차다. 방향을 바꿨을 때 얼마나 더 벌어지는지는 모른다.

문헌 기대값:
- Liang 2012: 한 방향 입력으로 최대 위치 오차 86.9 → 64.7 µm. **방향 오차는 개선 없음**
- 보정 PA-10: 양방향 스테핑에서 7배, 음방향 12배
- Kuric 2018 (ISO 9283): 방향별 30회, RP = ±3S

## 3. 촬영 요청

### 3.1 ISO 9283식 정·역 접근

| 항목 | 값 |
|---|---|
| 목표 자세 | Y 축: Y=+0.50 (T=0) / T 축: T=+0.50 (Y=0) |
| 접근 방향 | 각 목표에 **+방향 접근**과 **−방향 접근** |
| 접근 거리 | 목표에서 ±1.00 떨어진 곳에서 출발 |
| 반복 | 방향마다 **30회** |
| 합계 | 2축 × 2방향 × 30회 = **120회**, 회당 1장 |

### 3.2 가능하면 함께

| 항목 | 왜 |
|---|---|
| 다이얼 게이지 또는 레이저 변위계 동시 측정 | **독립 기준**. 영상 밖에서 실제 위치를 확인한다 |
| 기준기 분해능과 교정 상태 | 기준기 자체의 불확도를 예산에 넣어야 한다 |

독립 기준기의 정밀도는 **0.015 이하**여야 한다(허용오차 ±0.045의 1/3, Cheng 2013의 ±50/±15 µm 비율). 이것이 안 되면 B2는 영상 자기 일관성 시험에 그친다.

### 3.3 기록할 것

사진마다: 접근 방향, 출발 자세, 촬영 시각, 정지 후 대기 시간(B1에서 정한 값으로 고정), 온도.

## 4. 판정 기준 (촬영 전 고정)

| 조건 | 판정 |
|---|---|
| 두 방향 평균의 차 > 3S (S는 방향 내 표준편차) | **H13 성립.** 방향 의존이 있다 |
| 같은 조건에서 RP = ±3S ≤ 0.045 | 단방향 접근만으로 허용오차를 만족한다 |
| Y에서는 차이가 크고 T에서는 작다 | Liang 2012의 예측과 일치. 단방향 정책을 **Y에만** 적용 |
| 방향 차가 3S 이하 | H13 기각. 백래시 보상은 우선순위에서 뺀다 |

## 5. 분석 방법

1. 방향별 평균과 S를 낸다(ISO 9283의 RP = ±3S).
2. 두 방향 평균 차를 허용오차 단위로 보고한다.
3. 영상 추정값과 독립 기준값을 나란히 둔다. **둘의 차이가 영상 추정의 절대 정확도**다.
4. A8의 지표가 방향을 구별하는지 본다(구별하면 측정만으로 이력을 알 수 있다).

## 6. 한계

- 30회는 ISO 9283의 한 항목일 뿐이다. 30회를 했다고 표준 전체 적합으로 선언하지 않는다(보정 폴더 v2 6절).
- 독립 기준기가 없으면 절대 정확도는 못 낸다.
- 2축 장비에 ISO 9283을 그대로 적용하는 것이 타당한지는 SEMES 확인이 필요하다.
