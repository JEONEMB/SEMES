# 결과: 정답값 신뢰도, 구간별 0점 분석

입력: `data/clean/clean_20261014` 281장. 측정량은 파인더 패턴 한 점(1846.7, 1010.3)의 48x48 템플릿 매칭 가로·세로 이동(NCC + 포물선 보간)에서 center 자신의 값(템플릿 정수 위치 때문에 생기는 +0.3 px)을 뺀 center 대비 이동이다.

촬영 순서는 원래 zip 파일 수정 시각에서 구했다. `data/clean`에는 시각이 없어 `00_데이터분석.md` 5절의 순서(center → Y 1차 + → Y 1차 − → T + → T − → Y 2차 + → Y 2차 − 반대 방향)를 규칙으로 썼다.
