새 날짜, 혼합 자세 100장 이상.

**자극을 절반씩 나눈다.**
- 기존과 같은 (Y,T) 를 다시 찍는 절반 -> 날짜 효과만 깨끗이 분리
- Y<0, T<0 를 포함한 새 영역 절반 -> 현재 혼합 자세가 1사분면에만 있다
- 게이트 근처(|T| 0.005~0.015)를 Y 여러 값에서 -> C08 의 임계 검증

**모델·임계값을 고정하고 해시를 기록한 뒤 한 번만 평가한다.** 성적을 보고 고치면 독립성이 사라진다.
