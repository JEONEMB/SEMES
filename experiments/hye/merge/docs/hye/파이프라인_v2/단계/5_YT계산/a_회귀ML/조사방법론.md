# [5a] Y/T 계산: 회귀, ML 조사방법론

작성 2026-11-04. 지침은 [문헌연구/AGENTS.md](../../../../문헌연구/AGENTS.md), [ALGORITHM_RULES.md](../../../../../../ALGORITHM_RULES.md)를 따른다.
캔버스 노드 `s5`([5] Y/T 계산)는 5a(회귀, ML)와 5b(물리식)가 함께 쓴다. 이 문서는 5a에 해당하는 부분만 다룬다.

## 1. 목적

특징(QR 점 이동, 가로선 프로파일)에서 센터 대비 Y(mm), T(명령 단위)를 계산하는 통계 모형을 고른다.
고르는 기준은 다음과 같다.

- 정확도: 축별 평균, 최대 오차, |eY|,|eT| ≤ 0.045 통과율
- 시간: 한 장 처리 ms
- 강건성: 학습하지 않은 자리, 다른 날짜에서도 맞는지

## 2. 문제 상황과 근거 수치

- Y와 T의 영상 반응이 거의 평행하다. 두 반응의 cos는 0.99999다. 회귀 관점에서는 심한 공선성이다.
- Y 1mm는 약 14.36px, T 1단위는 약 80.3px다. 허용 ±0.045는 Y로 0.65px다.
- 점 측정 잡음은 0.009~0.015px다. 536점의 유효 독립 정보는 약 19개다. 특징 차원(joint 204차원, control 536점)에 비해 독립 정보가 적다.
- 정답 라벨은 명령값이다. 실제 위치는 명령값과 다를 수 있다. 하루 안에서 가로 영점이 0.84px까지 움직이고, 백래시 β는 −0.34px다. 날짜가 바뀌면 세로 영점이 +0.44px 움직인다(카메라 이동).
- 현재 control은 6절편 후보 곡선을 역산한다. 즉 절편(영점)이 상황마다 다르다는 가정이 이미 들어 있다.
- 기존 트리, 신경망 시도는 QR만으로 188/341에 그쳤다.
- 341/575장은 개발에 이미 노출된 자료다. 모든 자료는 명령한 자리에 멈춰 찍은 정지 사진이다.

## 3. 해결할 질문

캔버스 `s5` 질문 1, 2, 4를 5a 범위로 나누고 보강했다. (질문 3 "학습 없이 수식만으로"는 5b가 맡는다.)

1. (s5-1 보강) Y, T 반응이 거의 평행할 때 OLS, GLS, Ridge, PLS 중 무엇이 두 축을 가장 덜 섞고 정확한가? 정규화 세기나 성분 수는 어떻게 정하나?
2. (신규) 204차원 GLS의 잡음 공분산을 적은 사진 수로 어떻게 안정되게 추정하나? 지금 쓰는 Ledoit-Wolf보다 나은 축소 방법이 있나?
3. (s5-4 보강) 명령값을 정답으로 쓰면 어떤 종류의 라벨 오차가 생기나? 고전형 오차인가, Berkson형 오차인가? 회귀 계수에 편향이 생기나, 분산만 늘어나나?
4. (신규) 날짜, 세션, 접근 방향마다 다른 영점(절편)을 혼합 효과(무작위 절편)나 잠재 절편 모형으로 다룰 수 있나? 지금의 6절편 후보 역산과 무엇이 다른가?
5. (s5-1 보강) 트리, 부스팅, 신경망은 수백 장 규모 자료에서 선형 회귀보다 정확한가? 학습과 추론 시간은 얼마인가?
6. (s5-2 보강) 학습 범위 밖 자리(다른 사분면, 큰 편차)와 다른 날짜로 외삽할 때 어떤 모형이 덜 무너지나? 범위 밖 입력을 어떻게 감지하나?
7. (s5-1 보강) 여러 후보를 같은 자료로 비교할 때 선택 편향 없이 성능을 보고하려면 어떻게 나눠야 하나?
