## 2. 오프라인 실험 (data/clean 정지 사진으로 가능)

### V2-11-E1 반복성과 재현성 분해, 공차 기준 판정 지표

- **질문:** 2번(같은 결과가 반복되는가, 반복과 재현을 나눌 수 있는가), 3번의 일부(날짜 성분의 크기), 5번의 입력(σ_GRR).
- **후보 (00_단계.md 표에서 고른다):**
  - V3a 범위법 3단계 중첩(반복 J, 세션 K)
  - V3b ANOVA R&R. Y와 T의 상호작용 항을 넣는다. 오차 주축이 ΔY = −5.617ΔT라 범위법으로는 안 보인다
  - V4 공차 기준 판정 지표. P/T = 6σ_GRR/0.09, % Tol = 100 × MU/0.09, C_m = 0.09/(4u_m). T축은 분모를 0.02로 한다
  - 참고로 PV 기준 지표(% GRR, ndc)도 같이 내되, 자세 범위가 넓어 저절로 좋아진다는 단서를 붙인다
- **고정 조건:** 0절 전부. 묶음은 1020과 1029의 반복 3장 묶음 93개. 세션은 2개까지만 계산되고 세 번째 세션은 없다고 명시한다. 추정기는 final joint와 final control 두 대조군을 그대로 쓴다. 새 모델을 만들지 않는다.
- **지표:**
  1. s₁(반복, 같은 세션 연속 촬영)과 s₂(세션, 날짜) SD를 축별로 분리
  2. σ_GRR, P/T, % Tol, C_m, ndc
  3. 날짜별 분해값(1014, 1020, 1029 각각)
  4. 턴당 평균 장수 N = 1, 3, 5에서 3SD와 남는 예산
  5. 모든 값에 부트스트랩 95% 구간(묶음 단위 재표집)
  6. 처리 시간 ms 중앙값과 p95
- **판정 기준 (실험 전에 고정):**
  - P/T ≤ 10%면 "판정 능력 있음", 10 ~ 30%면 "간신히 있음", 30% 초과면 "능력 없음"으로 적는다
  - s₂ / s₁ > 1이면 다음 작업은 날짜 영점 보정이다. s₂ / s₁ ≤ 1이면 턴당 평균 장수를 늘리는 쪽이다. 둘 중 하나를 문서에 단정해 적는다
  - 어떤 분해값이든 부트스트랩 구간 폭이 0.015를 넘으면 "추정 불안정"으로 적고 숫자를 결론에 쓰지 않는다. 그 칸은 촬영 요청 R2로 넘긴다
  - 상호작용 항이 σ_GRR을 10% 이상 바꾸면 범위법 결과는 보고에서 빼고 ANOVA 값만 쓴다
- **예상 소요:** 캐시 재사용이라 측정이 없다. 구현과 실행 반나절.

### V2-11-E2 사진별 불확도 보정과 보호대 정지 규칙

- **질문:** 5번(한 번의 측정으로 0.045 안이라고 판정하려면), 1번의 숫자 요구(U ≤ 0.015, 표준불확도 0.0075 = 0.108px).
- **후보:**
  - V6a GLS와 가우스뉴턴 공분산에서 바로 꺼낸 u_m
  - V6b 반복 묶음 잔차로 교정한 u_m. 축별 스케일 c 하나를 학습 분할에서만 추정한다
  - V5 보호대 규칙. 정지 기준을 `|추정값| ≤ 0.045 − r × 2u_m`으로 바꾸고 r = 0, 0.25, 0.5, 0.65, 1.0을 같은 분할에서 비교한다
  - 대조군은 지금 쓰는 보호대 없는 단순 수용(r = 0)이다
- **고정 조건:** 0절 전부. 영점 보정을 먼저 하고 잔차를 B형으로 더한다(한계만 아는 성분 0.58, 되먹임 성분 0.71, 양자화 0.29). 20턴 평가는 A1의 실측 잡음과 E1의 s₁, s₂를 입력으로 받는 궤적 모의로 한다. 실기 자료가 아니라 모의라는 것을 결과 제목에 적는다. 사전 분포 g₀가 없으므로 전체 위험 R_C, R_P는 내지 않고 개별 위험 R_C* = 1 − p_c만 낸다.
- **지표:**
  1. z = e / u_m 의 SD. 보정 전과 보정 후, 축별, 날짜별
  2. 교정 계수 c와 p_c 보정 곡선
  3. r별 거짓 수용률(추정은 통과인데 실제가 0.045 밖), 거짓 거절률
  4. r별 20턴 수렴율과 평균 턴 수
  5. % Tol = 100 × MU/0.09, C_m, u_m의 p50과 p95
  6. 처리 시간 ms
- **판정 기준 (실험 전에 고정):**
  - 보정 후 z의 SD가 0.7 ~ 1.4에 들어오면 u_m을 쓸 수 있다고 적는다. 못 들어오면 보호대는 채택하지 않고 "사진별 불확도 사용 불가"로 적는다. A8에서 z SD가 6.395였으므로 실패 가능성이 크다
  - r 선택은 거짓 수용률 1% 이하를 만족하는 r 가운데 평균 턴 수가 가장 작은 값으로 한다
  - 어떤 r도 20턴 수렴율 99% 이상을 못 지키면 "보호대 미채택"으로 적고 대신 턴당 평균 장수를 늘리는 쪽(E1의 N)을 권고한다
  - u_m의 p95가 0.0225를 넘으면 기본 보호대 규칙으로는 통과 선언 자체가 불가능하다고 적는다
  - Y와 T를 동시에 판정하는 규칙은 이 실험에서 정하지 않는다. 축별로 따로 내고, 두 축 cos가 0.99999라 독립 가정이 틀린다는 한계를 적는다
- **예상 소요:** 모의 엔진을 새로 짜야 한다. 하루 반.

### V2-11-E3 중첩 검증과 누출 점검표

- **질문:** 6번(선택 편향과 자료 누출), 3번의 나머지(날짜 간 평가가 재현성인가 전이인가).
- **후보:**
  - V8 선택 단계를 폴드 안에 넣은 중첩 검증. 6절편, P12, 11후보, 정합 설정값 선택 규칙을 코드로 적는다
  - V7 날짜 하나 빼기 교차검증(내부-외부 검증)
  - V9 누출 점검표와 블록 분할. 575장을 개발 집합(노출 341장), 블록 검증 집합, 봉인 시험 집합으로 나누고 목록과 날짜를 문서로 남긴다
- **고정 조건:** 0절 전부. 특징은 A0 캐시에서 한 번만 뽑고 묶음 단위로 뒤쪽(GLS, P12, 절편 선택)만 다시 돌린다. 고정 상수는 명시한다(0.045, 14.36px/mm, 80.3px/단위). 사람이 눈으로 고른 설정은 이 절차에 넣을 수 없으므로 목록으로 따로 적는다. 봉인 집합은 열지 않는다. 지금까지 234장을 몇 번 들여다봤는지 기록부터 만든다.
- **지표:**
  1. 겉보기 성적, 중첩 성적, 그 차이(낙관 편향의 크기)를 축별 통과율과 최대오차로
  2. 무작위 분할 성적과 블록 분할(날짜, 자리) 성적의 차이
  3. 날짜 하나 빼기 3폴드의 폴드별 성적과 최악 날짜
  4. 날짜를 맞히는 분류기 AUC(특징만으로). 날짜 사이 거리의 대리 지표다
  5. 누출 점검표 통과 여부를 L1.2, L1.3, L2, L3.1, L3.2 항목별로
  6. 폴드당 처리 시간 ms와 전체 실행 시간
- **판정 기준 (실험 전에 고정):**
  - 중첩과 겉보기의 통과율 차이가 2%p를 넘으면 기존 보고 숫자에 "선택 편향 있음"을 붙이고 앞으로 모든 성적을 중첩 값으로 바꾼다
  - 무작위와 블록 분할 차이가 5%p를 넘으면 무작위 분할 성적을 보고에서 뺀다. A3에서 이미 48.8%p가 나왔으므로 거의 확실하다
  - 날짜 분류기 AUC ≥ 0.9이면 날짜 간 평가를 "전이"로 적고 "재현성"이라 부르지 않는다
  - 1장 차이 비교는 근거로 쓰지 않는다. 통과율 차이가 부트스트랩 구간 안이면 "차이 없음"으로 적는다
  - 다른 로봇 자료가 없으므로 결론 문장은 "재현성 확인, 전이 미확인"으로 고정한다
- **예상 소요:** 중첩이라 비용이 크다. 2 ~ 3일.

## 3. 실기 촬영이 필요한 실험 (촬영 요청서)

아래는 정지 사진으로 답할 수 없다. 실제 작업 후 도착 사진이 없고, 독립 기준기가 없고, 날짜가 셋뿐이다.
요청을 넣기 전에 V10(시험 전 모의 설계 진단)을 먼저 돌린다. A1의 실측 잡음과 E1의 s₁, s₂를 넣어 각 설계의 분산 추정 95% 구간 폭을 내고, 0.015보다 넓으면 반복 수나 날짜 수를 늘린 뒤 요청한다. 촬영 순서는 날짜를 묶고 그 안에서 자세와 접근 방향을 무작위로 돌린다.
