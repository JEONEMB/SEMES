## 1. 목적

현재 측정값에서 센터 측정값을 빼서, 센터에서 얼마나 벗어났는지만 남긴다.
이때 다음 세 가지를 문헌으로 정한다.

- 무엇을 기준으로 뺄지 (센터 한 장, 여러 센터의 평균, 같은 사진 안의 고정 구조)
- 카메라나 장비가 움직인 몫을 어떻게 지울지
- 기준이 가진 오차를 결과에 어떻게 함께 넘길지

## 2. 문제 정의 (근거 수치)

- 허용오차는 |eY|, |eT| ≤ 0.045다. Y로는 0.65px이다.
- Y 1mm는 약 14.36px, T 1단위는 약 80.3px이다.
- 점 측정 잡음은 0.009~0.015px이다. 536점의 유효 독립 정보는 약 19다.
- 영점이 흔들린다.
  - 하루 안에서 가로 방향으로 최대 0.84px 움직인다. 백래시 β는 -0.34px이고, 나머지는 드리프트다.
  - 날짜가 바뀌면 세로 방향으로 +0.44px 움직인다. 카메라가 움직인 것으로 본다. QR에서 가로선을 빼면 상쇄된다(A15).
- 하루 안 영점 변화 0.84px는 허용오차 0.65px보다 크다. 그래서 기준을 잘못 고르면 그것만으로 허용오차를 넘는다.
- 원래 고정 기준은 `data/clean/clean_20261014/center.bmp` 한 장이다. 다른 날짜의 센터 사진으로 자동 교체하지 않는다(ALGORITHM_RULES).
- 자료는 모두 명령한 자리에 멈춰 찍은 정지 사진이다. 341/575장은 개발에 노출됐다.

## 3. 해결할 질문

캔버스 s3의 1~3번을 그대로 두고 4~7번을 보강했다.

1. 기준(센터)이 흔들리면 결과가 얼마나 틀리는가?
2. 카메라가 움직인 몫을 사진 안에서 빼낼 수 있는가?
3. 기준의 불확실성을 결과에 어떻게 반영하는가?
4. (보강) 기준을 센터 한 장으로 둘지, 여러 장의 평균으로 둘지, 여러 기준을 서로 맞춰 쓸지? 몇 장이면 기준 잡음이 현재 사진 잡음보다 충분히 작아지는가?
5. (보강) 기준은 언제 다시 잡아야 하는가? 느린 드리프트와 빠른 흔들림을 어떻게 나누고, 기준 갱신 조건을 무엇으로 정하는가?
6. (보강) 고정 기준점(가로선)도 로봇 이동에 조금 반응하면, 빼기가 신호까지 지우지 않는가? 기준점이 신호에 얼마나 반응하는지 어떻게 확인하는가?
7. (보강) 기준과 현재 측정의 오차가 서로 상관되어 있을 때(같은 카메라, 같은 점), 빼기 후 공분산을 어떻게 계산하는가?

## 4. 검색어

블록 안은 OR, 블록 사이는 AND.

| 블록 | 검색어 |

| A 기준 | reference image, reference frame, reference mark, fiducial, fixed reference point, stationary reference, baseline, base frame, master image |
| B 문제 | drift, camera motion, camera relocation, ego-motion, self-heating, temperature variation, thermal drift, offset change, pole drift |
| C 처리 | compensation, correction, subtraction, differential, relative measurement, averaging, redundant referencing |
| D 불확도 | uncertainty, covariance propagation, error propagation, Cramer-Rao bound, precision, noise in both images |
| E 분야 | digital image correlation, vision-based displacement, image registration, localization microscopy, wire bonding, lithography alignment, video stabilization |

조합 예: (A) AND (B) AND (C), (A) AND (D), (B) AND (C) AND (E).
