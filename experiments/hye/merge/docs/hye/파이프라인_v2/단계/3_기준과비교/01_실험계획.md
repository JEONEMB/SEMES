## 0. 이 계획이 지키는 것

- 후보는 [00_단계.md](00_단계.md)의 문헌 기반 표 C1~C10에서만 고른다. 표에 없는 방법을 새로 만들지 않는다.
- 같은 자료, 같은 분할을 쓴다. 측정은 A0 캐시를 먼저 재사용하고, 사진을 다시 측정하지 않는다.
- 정확도와 처리 시간을 함께 보고한다. 날짜를 나눈 평가를 반드시 넣는다.
- 기존 final 두 모듈을 대조군(C1)으로 둔다.
- 시험 정답으로 학습하거나 후보를 고르지 않는다. 모든 계수, 표준화, 공분산은 학습 분할 안에서만 추정한다.
- 원본, 기존 결과, 기존 final 폴더를 고치지 않는다. 새 실험 폴더에만 쓴다.

### V2-3-E1. 기준 차감 방식 네 가지 비교

| 항목 | 내용 |
|---|---|
| 질문 | 질문 1, 2, 4. 어떤 차감 방식이 날짜가 바뀌어도 가장 덜 틀리는가 |
| 후보 | C1 그냥 빼기(대조군), C2 같은 측정기로 잰 센터 빼기(자기 정합 D0 차감), C3 QR에서 가로선 빼기, C4 같은 날 센터 K장 평균 빼기 |
| 고정 조건 | 1절 공통. 네 후보 모두 같은 A0 캐시, 같은 fold, 같은 뒤단 추정기를 쓴다. 바뀌는 것은 차감 식 하나뿐이다. control 뒤단은 P12 고정 536점, joint 뒤단은 204차원 GLS로 고정한다. C3의 선 요약은 블록 위치 대신 강건 직선 적합의 평균 세로 이동과 위아래 기울기 차를 쓴다(A21). C4의 K는 1, 3으로만 본다(같은 날 반복이 1020 3장, 1029 3장뿐이다) |
| 지표 | Y, T 축별 평균 절대오차와 최대 절대오차, `|e| ≤ 0.045` 통과율, joint는 `|eT| ≤ 0.01` 통과율도. 날짜 3-fold 표와 "1014만 학습 → 1029" 표. 한 장 처리 시간 중앙값과 p95 |
| 판정 기준 (실험 전 고정) | 채택 조건은 둘 다 만족이다. (1) 날짜 3-fold 전체에서 대조군 C1보다 최대 절대오차가 작거나 같고 통과율이 낮지 않다. (2) "1014만 학습 → 1029"에서 통과율이 C1보다 3 %p 이상 높다. 시간은 한 장 처리가 C1의 1.3배를 넘으면 채택하지 않는다. 같은 조건에서 두 후보가 동률이면 더 단순한 쪽(C1 → C2 → C3 → C4 순)을 고른다 |
| 예상 소요 | 캐시 재사용 기준 구현 반나절, 실행 20분 안쪽 (측정 없이 차감과 회귀만) |
| 재사용 | C3의 joint 쪽 날짜 일반화는 A15가 이미 같은 조건으로 끝냈다(QR 세로 +0.4423 px, 선 평균 +0.4863 px, 차 −0.044 px, 선을 안 쓰는 모델에서 날짜 일반화 3.3배 개선). 그 숫자는 다시 돌리지 않고 인용한다. C4의 joint 세션 3장 평균도 A20이 끝냈다(1029에서 81.2% → 89.7%). 새로 돌릴 것은 **control 쪽 C2, C3, C4뿐**이다. control에 선 빼기를 넣은 결과가 지금 없기 때문이다(00_단계 질문 2의 "아직 모르는 것") |

### V2-3-E2. 가로선 빼기가 신호를 얼마나 깎는가

| 항목 | 내용 |
|---|---|
| 질문 | 질문 6, 2. 가로선은 고정 기준이 아니다. 빼면 카메라 이동과 함께 Y, T 신호도 깎인다. 얼마나 깎이고, 깎인 뒤 다시 학습하면 회복되는가 |
| 후보 | C10 가로선 반응 계수를 재고 보정 계수 재학습, C5 방해 모델 사영 제거 후 사영 계수 재학습 |
| 고정 조건 | 1절 공통. 학습 분할에서만 선 반응 계수와 사영 행렬을 만든다. 방해 공간 N은 (a) 전역 평행 이동 2축, (b) 평행 이동 2축에 주점 중심 확대 1을 더한 C6형 3축, 두 가지만 본다. 비교는 같은 특징, 같은 추정기에서 사영 전후만 바꾼다 |
| 지표 | (1) 겹침 비율 `‖P_N J‖ / ‖J‖`를 Y, T 각각. J는 536점 변위의 명령 미분이다. (2) 사영 뒤 남은 감도를 14.36 px/mm, 80.3 px/단위와 비교한 비율. (3) 재학습 뒤의 축별 평균, 최대 절대오차와 통과율, 날짜 3-fold. (4) 사영 연산이 더한 시간 ms |
| 판정 기준 (실험 전 고정) | 겹침 비율이 Y나 T에서 0.30을 넘으면 그 방해 공간은 쓰지 않는다(신호를 너무 많이 먹는다). 0.30 이하이면서 재학습 뒤 날짜 3-fold 최대 절대오차가 C1보다 작아야 채택이다. 감도가 절반 아래로 떨어지면 통과율이 올라도 채택하지 않고 "원인 불명 개선"으로 기록한다 |
| 예상 소요 | 구현 반나절, 실행 10분 안쪽 |
| 재사용 | 선 반응 계수 자체는 A4가 끝냈다(T 2.5275 px/deg, ΔAIC 251.1, Y 0.0600 px/mm는 선 잡음의 2.3배로 미지지). 다시 재지 않고 입력으로 쓴다. A3의 "선을 빼니 통과율 95.7% → 24.6%"도 깎임의 증거로 인용한다. 새로 할 것은 겹침 비율 측정과 사영 뒤 재학습이다. 둘 다 지금 없다 |

### V2-3-E3. 빼기 뒤 불확실성 전파가 실제 오차와 맞는가

| 항목 | 내용 |
|---|---|
| 질문 | 질문 3, 7. `U_e = U_cur + U_ref − U_cr − U_crᵀ`로 낸 불확실성이 실제 오차 분포와 맞는가. 기준과 현재의 교차 공분산 `U_cr`을 무시하면 얼마나 과대평가하는가 |
| 후보 | C9 빼기 후 공분산 전파, C8 점별 편차를 GLS 가중으로 |
| 고정 조건 | 1절 공통. `U_cur`, `U_ref`, `U_cr`을 학습 분할의 반복 묶음에서만 추정한다. 반복은 1020 20묶음, 1029 78묶음의 3장씩이다. 3장이라 2차원 공분산이 정의되지 않으므로(L4 5.3.2) 이 실험은 축별 분산과 교차 공분산의 대각 성분까지만 낸다. 2축 동시 판정(k_q = 2.24)은 4절 촬영 요청 뒤로 미룬다. 수치 계산은 역행렬 대신 숄레스키와 QR로 한다. 공분산 축소 계수는 학습 분할 안에서 고른다 |
| 지표 | (1) 교정 곡선. 예측 표준편차로 정규화한 잔차 `e / u(e)`의 분포와, 68 %, 95 % 구간의 실제 포함 비율. (2) `U_cr`을 넣었을 때와 0으로 뒀을 때의 `u(e)` 비율. (3) C8 가중을 넣고 뺀 축별 평균, 최대 절대오차와 통과율, 날짜 3-fold. (4) 공분산 분해와 풀이에 드는 시간 ms |
| 판정 기준 (실험 전 고정) | 교정 채택 조건은 95 % 구간의 실제 포함 비율이 0.90 이상 0.99 이하다. 그 밖이면 전파식이 맞지 않는다고 적고 판정 단계로 넘긴다. C8 가중은 날짜 3-fold 최대 절대오차가 비가중보다 작아야 채택이다. 출력 공분산 조건수가 1e6을 넘으면 수치적으로 못 푼다고 적고 조건수가 작은 좌표로 바꿔 다시 푼다 |
| 예상 소요 | 구현 하루, 실행 20분 안쪽 |
| 재사용 | 점 측정 잡음 0.0087 px(p95 0.0147)과 유효 독립 차원 18.86은 A1 값을 그대로 쓴다. GLS, WLS 가중 비교는 [공분산 가중 효과](../../../../../experiments/hye/20261021_1621_공분산가중효과_GLS_WLS_비교)와 [픽셀 잡음 가중](../../../../../experiments/hye/20261021_1621_픽셀잡음가중_역분산가중GN)이 있으나 분할이 다르다. 그 결과는 참고로만 인용하고, 비교는 A0 분할에서 다시 돌린다 |

## 3. 실행 순서

1. V2-3-E1을 먼저 돌린다. 차감 방식이 정해져야 E2, E3의 입력이 고정된다.
2. V2-3-E2. E1에서 C3를 채택했든 아니든 겹침 비율은 설계 근거로 남긴다.
3. V2-3-E3. E1, E2에서 고른 차감과 특징 위에서 불확실성을 전파한다.
4. 결과는 `02_실험결과.md`에 같은 ID로 적는다. 판정 기준은 실험 뒤에 바꾸지 않는다. 바꿔야 하면 바꾼 이유와 원래 기준을 함께 남긴다.

## 4. 실기 촬영 요청서

오프라인으로 답할 수 없는 것만 적는다. 기존 B 계획서와 겹치면 새로 쓰지 않고 그 문서를 가리킨다.

### R1. 센터 반복과 세션 영점 (질문 3, 4, 5, 7)

| 항목 | 값 |
|---|---|
| 자세 | center (Y=0, T=0) 1자세 |
| 한 묶음 | 연속 10장 |
| 하루 안 반복 | 4회 (출근 직후, 예열 2시간 뒤, 오후, 퇴근 전) |
| 날짜 | 서로 다른 3일 |
| 합계 | 10 × 4 × 3 = 120장 |
| 조건 | 묶음 안에서는 로봇을 움직이지 않는다. 묶음 사이에는 center를 떠났다가 같은 접근 방향으로 돌아온다 |
| 함께 기록 | 촬영 시각(초 단위), 장비를 켠 시각, 직전 이동의 방향과 크기, 가능하면 온도 |
| 왜 필요한가 | 묶음당 10장이면 2차원 공분산과 `U_cr`을 추정할 수 있다(L4 5.3.2는 5장 이상을 요구한다). K ≥ 5 평균의 실익도 이 자료로만 본다. 하루 안 4회로 느린 드리프트와 빠른 흔들림을 나눠 C7 갱신 임계값을 정한다 |

### R2. 날짜 간 영점의 모양 (질문 1, C6)

| 항목 | 값 |
|---|---|
| 자세 | center 1자세, 그리고 화면 네 모서리 쪽으로 치우친 자세 4개 (Y ±0.5, T ±0.5 조합) |
| 자세마다 | 5장 |
| 날짜 | 서로 다른 3일, 각 날 같은 시각대 |
| 합계 | 5 × 5 × 3 = 75장 |
| 함께 기록 | 촬영 시각, 카메라와 치구를 만졌는지 여부 |
| 왜 필요한가 | 날짜 간 이동이 평행 이동인지, 확대나 틸트가 섞였는지 가른다. A15에서 위 선 +0.225 px, 아래 선 +0.748 px로 달라 순수 평행 이동이 아니었다. 화면 여러 위치의 자세가 있어야 C6의 확대 항을 식별할 수 있다 |

### R3. 가로선의 명령 반응 재확인 (질문 6)

| 항목 | 값 |
|---|---|
| 자세 | T 단독 스윕 9수준 (−0.8 ~ +0.8), Y 단독 스윕 9수준 (−0.6 ~ +0.6) |
| 자세마다 | 5장 |
| 날짜 | 1일 (같은 세션 안에서 끝낸다) |
| 합계 | 18 × 5 = 90장 |
| 함께 기록 | 촬영 시각, 조명 설정 |
| 왜 필요한가 | A4가 T 반응 2.5275 px/deg를 찾았지만 Y 반응 0.0600 px/mm는 선 잡음에 묻혔다. 자세마다 5장이면 Y 반응도 가를 수 있다. 이 계수가 E2의 입력이라 정밀도가 결과를 좌우한다 |
