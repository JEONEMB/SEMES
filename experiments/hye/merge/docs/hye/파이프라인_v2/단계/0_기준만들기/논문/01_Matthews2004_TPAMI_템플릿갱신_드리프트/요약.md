# Matthews, Ishikawa, Baker 2004, 템플릿 갱신 문제와 드리프트 보정 (IEEE TPAMI)

- 원제: The Template Update Problem
- 원문 파일: 같은 폴더의 `Matthews2004_TPAMI_template_update.pdf` (CMU RI 저자 공개본, 원고 15쪽. 학술지 인쇄본 6쪽과 배치가 다르다)
- 번역: [번역.md](번역.md) (전문)
- 저자: Iain Matthews, Takahiro Ishikawa, Simon Baker (Carnegie Mellon University, Robotics Institute)
- 서지: IEEE Transactions on Pattern Analysis and Machine Intelligence, 26(6), pp. 810-815, 2004. doi:10.1109/TPAMI.2004.16
- 근거 상태: 원문 확인 (저자 공개본 전문). 인쇄본과 문구가 같은지는 확인하지 않았다.
- 핵심 (원문 확인)
  - 기준(템플릿)을 매 프레임 새 영상으로 바꾸면(전략 2), 정렬 오차가 매번 기준에 들어가 쌓인다. 기준이 물체에서 떠나간다(드리프트).
  - 기준을 전혀 바꾸지 않으면(전략 1), 드리프트는 없다. 그러나 겉모습이 바뀌면 국소 최소에 빠져 결국 실패한다.
  - 제안(전략 3): 새 템플릿으로 먼저 맞춘 결과 $\mathbf{p}_n$에서 시작해, **첫 템플릿 $T_1$에 다시 맞춘다**($\mathbf{p}^*_n$). 두 결과 차이가 $\epsilon$ 이하일 때만 템플릿을 바꾸고, 넘으면 갱신하지 않는다.
  - 저자 해석: 전략 3은 "첫 템플릿을 고정 기준으로 쓰고, 최근 영상은 시작점만 잡아 주는 것"과 같다. 최종 위치는 늘 첫 템플릿 기준이다.
  - 외형 변화가 있으면(전략 4), 첫 템플릿에 다시 맞춘 영상들을 PCA(에너지 95%)로 묶어 평균 템플릿과 외형 기저를 만든다. 최종 맞춤은 다시 처음 모델로 한다.
  - 한계(저자): 갱신하면 계산 비용이 크게 는다. 매 프레임이 아니라 "크게 바뀌었다고 판단될 때만" 갱신하라고 권한다. 보이는 부분이 바뀌는 경우는 다루지 않는다.
- 정량 수치 (원문 확인)
  - 자동차 972프레임, 2차원 닮음 변환(4매개변수). 전략 1은 312번째 프레임 뒤 실패, 전략 2는 약 200번째 프레임에서 드리프트, 전략 3은 끝까지 추적.
  - 수렴 판정: 템플릿 네 모서리가 정답에서 모두 1.0화소 안. 프레임당 50회 흔듦 시행.
  - 그림 3 (그래프 판독, 대략값): 흔듦 시그마 10화소에서 전략 1 약 41%, 전략 3 약 75% 수렴. 시그마 3 이하는 둘 다 거의 100%.
  - 얼굴 600프레임, 손 표시 80프레임으로 첫 AAM, 시험 50 x 600. 갱신하는 알고리즘 2, 3, 4가 갱신 없는 1, 5보다 전 구간에서 높다. 수렴률 차이는 그래프로만 제시.
  - 영점 이동 크기(화소 단위의 드리프트 양)는 수치로 주지 않는다.
- 우리와의 관계: ○ 질문 **1, 2, 7**
  - 질문 1 (사진 1장 센터): 지금 방식(`center.bmp` 1장 고정, 매 사진을 직접 센터와 비교)은 이 논문의 **전략 1**이다. 우리는 이동 사이에 기준을 사슬처럼 이어 붙이지 않으므로 전략 2형 드리프트는 생기지 않는다. 대신 전략 1의 약점, 곧 "기준과 현재 사진의 겉모습 차이"가 문제다. 우리에게 그것은 조명, 날짜 간 카메라 이동(세로 +0.44px), 하루 안 영점 이동(가로 ≤0.84px)이다.
  - 질문 2 (여러 장): 전략 4는 여러 장을 **첫 기준에 다시 정렬한 뒤** 평균(PCA 평균)한다. 여러 센터 사진을 평균할 때 각 장을 먼저 기준 1장에 정렬하지 않으면, 정렬 오차가 평균 기준에 섞인다는 근거다.
  - 질문 7 (언제 다시 만드나): 전략 3의 $\lVert \mathbf{p}^*_n - \mathbf{p}_n \rVert \le \epsilon$ 조건과 "크게 바뀌었을 때만 갱신"이 갱신 조건의 형태를 준다. 다만 $\epsilon$의 값과 정하는 법은 주지 않는다.
  - 문헌 결과와 우리 추론의 구분: 위 대응은 우리 추론이다. 논문은 동영상 추적이며 정지 사진, 서브화소(0.65px 허용) 정확도, 기계 영점 이동을 다루지 않는다.

## 리뷰 카드

- **어떻게 해결했나**: 첫 템플릿 $T_1$을 버리지 않고 늘 보관한다. 새 템플릿으로 맞춘 결과를 시작점으로 $T_1$에 다시 맞추고, 두 결과가 $\epsilon$ 안에서 일치할 때만 템플릿을 바꾼다. 그래서 갱신 오차가 쌓이지 않는다.
- **같은 점**: 기준 영상 하나와 현재 영상을 경사 하강(Gauss-Newton류)으로 정합해 위치 매개변수를 얻는다. 우리 joint(NCC 다음 ECC 호모그래피)와 control(NCC 다음 LK15, 17x17 스플라인 GN)도 "거친 시작점 다음 기준 정합" 구조다. 기준을 바꾸면 오차가 기준에 들어간다는 문제 구조도 같다.
- **다른 점**:
  - 논문은 연속 동영상이고 프레임 사이 움직임이 작다. 우리는 명령한 자리에 멈춰 찍은 정지 사진이고, 매 턴 사진을 센터와 직접 비교한다.
  - 논문의 성공 기준은 1.0화소 안 수렴이다. 우리 허용은 Y 0.65px, 점 잡음은 0.009~0.015px로 두 자릿수 이상 정밀하다.
  - 논문의 드리프트는 갱신 알고리즘이 만든다. 우리 영점 이동은 기계(백래시 β −0.34px, 하루 안 드리프트)와 카메라(날짜 간 +0.44px)에서 온다. 기준을 고정해도 생긴다.
  - 논문은 겉모습 변화(조명, 자세)를 국소 최소 문제로 본다. 우리 QR과 가로선은 겉모습이 거의 그대로이고, 국소 최소보다 미세 편향이 문제다.
- **가져올 해결책**:
  1. 센터 기준은 `clean_20261014/center.bmp` 1장을 **최종 정합 기준($T_1$)으로 고정**한다. 턴마다 직전 사진을 기준으로 바꾸는 사슬 방식은 쓰지 않는다. 20턴 사슬이면 각 턴 정합 오차가 기준에 쌓인다(추론).
  2. 여러 센터 사진(1020의 3장 등)으로 기준을 만들 때는 각 장을 먼저 $T_1$에 정렬하고, 정렬 잔차를 기록한 뒤 평균한다. 정렬 잔차(QR54 좌표, 가로선 48블록)가 점 잡음 수준(0.015px)을 넘는 장은 평균에서 뺀다.
  3. 기준 점검은 전략 3의 일치 조건으로 한다. 새 센터 사진을 현재 기준과 $T_1$ 양쪽에 맞추고 Y, T 차이를 본다. 차이가 허용의 1/3(Y 0.015 단위, 약 0.22px) 이하이면 기준 유지, 넘으면 기준을 바꾸지 말고 원인(카메라 이동 A15, 백래시)을 먼저 확인한다. 이 임계값은 우리 제안이며 검증 전이다.
  4. 갱신은 매번 하지 않는다. 날짜가 바뀔 때, 카메라 재설치 뒤처럼 "크게 바뀌었다고 판단될 때"만 점검 절차를 돈다.

## 이 단계 후보 방법으로서

- **방법 이름**: 첫 기준 고정과 드리프트 보정 갱신 (Matthews 2004 전략 3, 4)
- **전제 조건**
  - 첫 기준 사진 $T_1$이 믿을 만하다 (센터 자세, 잡음, 초점이 정상).
  - 새 사진을 $T_1$에 다시 정합할 수 있을 만큼 겉모습이 비슷하다.
  - 일치 임계값 $\epsilon$을 정할 근거(반복 측정 분산)가 있다.
- **장점**
  - 기준을 바꿔도 오차가 쌓이지 않는다. 기준이 원래 센터에 묶여 있다.
  - 구조가 단순하다. 정합을 한 번 더 하는 것뿐이다.
  - 갱신 거부 조건이 있어 이상한 사진이 기준을 망치지 않는다.
  - 여러 장 평균(전략 4)으로 확장할 수 있다.
- **단점**
  - $T_1$ 자체의 잡음과 편향은 그대로 남는다. 모든 측정에 같은 방향으로 들어간다 (질문 6은 이 논문으로 답할 수 없다. 논문 02 Su 2016 참조).
  - $\epsilon$의 값을 주지 않는다. 우리 자료로 정해야 한다.
  - 기계, 카메라의 실제 영점 이동은 겉모습 문제가 아니라서 이 방법으로 없어지지 않는다. QR 빼기 가로선(A15) 같은 영상 안 고정 기준이 따로 필요하다.
  - 계산이 늘어난다 (정합 2회). 우리는 기준 점검 때만 쓰므로 운용 시간에는 영향이 작다(추론).
- **우리 적용 조건**
  - 운용 루프(최대 20턴)에서는 기준을 바꾸지 않는다. 매 턴 사진은 고정 센터와만 비교한다.
  - 기준 점검과 재작성은 운용 밖에서 한다. 새 센터 사진을 기존 기준과 $T_1$에 모두 정합해 Y, T 차이가 Y 0.015 단위(약 0.22px), T 0.015 단위(약 1.2px) 안이면 유지한다. 임계값은 우리 제안이며, 같은 날 센터 반복 사진(1020의 3장)의 분산으로 먼저 확인한다.
  - 여러 장 평균 기준을 시험할 때는 개발 노출 자료(341/575)와 분리된 센터 반복 사진으로 평가하고, 같은 사진, 같은 분할에서 1장 기준과 비교한다.
