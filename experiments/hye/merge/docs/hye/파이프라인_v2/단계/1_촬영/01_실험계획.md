## 2. 오프라인 실험 (지금 자료로 가능)

### V2-1-E1 블러 내성과 노출 상한

| 항목 | 내용 |
|---|---|
| 묻는 것 | 노출 중 번짐이 Y, T 추정을 얼마나 흔들고 얼마나 치우치게 하는가? 허용 안에 들려면 번짐 길이가 몇 px 아래여야 하는가? (질문 3, 7) |
| 후보 | C4 노출 상한 역산. 비교 대상은 C3 고정 노출 상태(번짐 0) |
| 자료 | A0 분할의 전체 사진. 화소를 바꾸므로 점 측정 캐시는 쓰지 않고 다시 측정한다 |
| 고정 조건 | 번짐 길이 0, 0.1, 0.3, 0.65, 1.0, 2.0 px 6수준. 방향은 Y 방향(세로)과 T 방향(가로) 2가지. 커널은 대칭 상자형과 감쇠 진동꼴 비대칭 2가지. 모델은 기존 final 두 모듈을 그대로 쓰고 다시 학습하지 않는다 |
| 지표 | 수준마다 축별 평균오차, 최대오차, 통과율. 번짐 0 대비 평균 이동량(치우침)과 SD 증가량. 1장당 ms |
| 판정 기준 (실험 전 고정) | 번짐 길이 L을 올릴 때 (a) 평균 이동량 ≤ 0.011(Y 허용의 1/4), (b) 통과율이 번짐 0 대비 2%p 넘게 떨어지지 않음, 두 조건을 함께 만족하는 가장 큰 L을 허용 번짐으로 정한다. 그 L과 실기에서 잴 영상 속도로 노출 상한을 계산해 적는다. 비대칭 커널에서 치우침이 대칭보다 2배 넘게 크면 "정착 대기가 노출보다 중요"로 적고 C5, C6로 넘긴다 |
| 예상 소요 | 구현 반나절, 실행 2~3시간 (6수준 x 2방향 x 2커널 = 24조건, 조건마다 전수 재측정) |

### V2-1-E2 N장 평균의 이득 곡선

| 항목 | 내용 |
|---|---|
| 묻는 것 | 같은 자세 반복 사진을 평균하면 오차가 1/√N 으로 줄어드는가? 몇 장부터 이득이 멈추는가? (질문 8) |
| 후보 | C2 N장 평균. 비교 대상은 C1 1장 |
| 자료 | 1020과 1029의 같은 명령 반복 묶음(묶음당 3장). A0 캐시 재사용 |
| 고정 조건 | N = 1, 2, 3. 평균은 (a) 사진별 추정값 평균, (b) 측정 특징 평균 뒤 1회 추정, 두 방식을 모두 본다. 모델은 기존 final 두 모듈 고정. 묶음 안 조합은 전수로 쓴다 |
| 지표 | N별 축별 SD, 최대오차, 통과율. 사진 간 상관계수. 측정된 SD와 1/√N 예측선의 차이. 1장당 ms x N |
| 판정 기준 (실험 전 고정) | N=3에서 측정 SD가 1/√3 예측의 1.2배 안이면 "평균이 듣는다"로 보고 턴당 장수를 N=3으로 제안한다. 1.2배를 넘으면 사진 간 상관이 남은 것으로 보고 상관계수를 함께 적고, 평균 대신 C5 정착 대기와 C6 안정 판정을 우선 후보로 올린다. 어느 경우든 "이 반복 3장이 같은 정지인지 다시 도착인지 기록이 없다"는 한계를 결과에 적는다. 이 한계 때문에 이 실험은 이득 곡선의 상한만 준다 |
| 예상 소요 | 구현 2시간, 실행 30분 |

## 3. 오프라인으로 답할 수 없는 것

질문 1(도착 방향과 속도), 2(예열과 가동 열), 3의 실제 값(정착 시간), 4(사이클 시간 예산), 5의 원인 분리, 7의 실제 광학 변화와 깜빡임은 지금 자료로 값을 낼 수 없다.
정지 사진에는 도착 방향, 촬영 시각, 카메라 켠 시각, 온도, 대기 시간 기록이 없기 때문이다.
아래 촬영 요청과 기업 확인 체크리스트로 넘긴다.

## 5. 기업 확인 체크리스트

문헌으로 답이 안 나오고 촬영으로도 알 수 없는 항목이다. 값이 오기 전에는 가정으로 적고 가정임을 표시한다.

- [ ] 웨이퍼 투입 사이클 안에서 쓸 수 있는 턴당 시간 한도(ms)
- [ ] 턴당 쓸 수 있는 촬영 장수
- [ ] 카메라 렌즈 장착 방식(투영 중심 고정형인가)
- [ ] 카메라에서 뒷벽까지 거리와 QR 판까지 거리
- [ ] 조명 구동 방식(전원 주파수, LED PWM 주파수)
- [ ] 자동 노출, 자동 초점을 끌 수 있는가. 지금 노출 시간은 몇 ms인가
- [ ] 보드 온도나 주변 온도를 기록할 수 있는가
- [ ] 이동 끝 시각을 제어기에서 받을 수 있는가
