# QR 분석 문헌 조사 방법론 (계획)

- 작성일: 2026-10-30
- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 결과 문서: `00000_QR분석_조사_방법론_및_결과_.md` (이 계획대로 조사를 마친 뒤 작성)
- 상위 문서: `../../01_주제_관련/유사연구/00000_유사연구_종합요약.md` (3장 "QR을 측정 도구로 쓸 때의 정밀도" 빈칸)

## 1. 목적

1. 영상에서 QR 판(QR 3개)의 움직임을 **정밀하고 안정적으로** 재는 단계(QR 분석)에서 생기는 문제를 정의한다.
2. 각 문제의 원인과 해결 방법을 문헌으로 확인하고, 본 과제에서 할 실험·구현 항목과 성공 기준을 정한다.
3. 팀 보고서(3차 멘토링 v8, 이하 m3)에서 이미 시도한 방법은 반복하지 않고, 그 결과에서 드러난 문제의 근거를 찾는다.

## 2. 이 주제에서 발생하는(할) 문제 정의

신호 크기의 기준: Y 허용오차 0.09는 화면에서 1.28 px, Y와 T를 가르는 점별 차이 성분의 표준편차는 0.029 px이다(m3 3.3·3.4절). 즉 QR 분석은 **0.03 px보다 충분히 작은 점 잡음·편향**을 내야 한다.

| P# | 문제 | 근거 (명세서·m3) |
|:---:|---|---|
| P1 | **반복 무늬로 인한 대응 오류.** QR 모듈은 같은 크기의 흑백 정사각이 반복되어, 기술자 짝짓기나 넓은 탐색이 이웃 모듈로 짝을 짓는다. | ORB·BRISK·AKAZE·KAZE 짝의 8.8~16.4 %가 이웃 모듈로 오매칭, 일반 특징점 309개에서 최대 108 px 오매칭(m3 표 10·12) |
| P2 | **부화소 위치 편향(pixel/peak locking)과 잡음 하한.** 보간 방식에 따라 위치가 정수 화소 쪽으로 끌리는 계통 편향이 생기고, 신호(0.029 px)와 같은 크기이다. | 포물선 피크 보간 −0.03~−0.05 px, 위상상관 −0.022 px, 템플릿 GN ≤ 0.001 px, 17 px 템플릿 잡음 0.0124 px(CRLB 근접), 536점 LK+스플라인 GN 0.0286 px(m3 표 11·12) |
| P3 | **점 집합·측정 모델의 선택.** 어떤 점(파인더, 격자 모서리, 모듈 중심)을 어떤 모델(점별 추적, 아핀·호모그래피 직접 정합)로 재야 Y·T 단서(미세 2차 변형)가 보존되는가. | 파인더 66점 Y 65/80, 내부 536점 최선. ECC 아핀 Y 0.128 mm·부호 오류, 직접 GN 69 %(m3 4.1절) |
| P4 | **영상 품질 변화에 대한 강건성.** 초점(블러)·조명·노출 변화와 렌즈 왜곡이 코너·모서리 위치를 계통적으로 옮긴다. | 1020 세트 초점 약 7 % 흐림(m3 3.2절), cornerSubPix 87.5~93.9 %(블러에 민감한 코너 방식), 렌즈 보정 정보 없음(m3 표 4) |
| P5 | **실시간성과 정밀도의 맞교환.** | 명세서 "실시간 처리". LK+스플라인 GN 59 ms vs OpenCV LK 8.6 ms(같은 판정 성적), joint 824~1067 ms, J204는 측정 18배(m3 4.1·4.2절) |
| P6 | **실제 장비에서의 QR 검출 실패와 신뢰도 판단.** 오염·가림·반사·디코딩 실패 시 잘못된 측정을 내보내지 않아야 한다. | 현재 데이터는 정제된 실험 영상(`data/clean`)뿐이며 검출 실패 사례를 다루지 않음. 명세서 사용 대상에 사외 고객·설비 유지보수 담당자 포함 → 현장 조건 대비 필요(예상 문제) |

참고 제약: QR 판 밖 구조물은 과제 조건상 사용 불가(위·아래 가로선은 허용). 판은 QR 3개 고정이므로 다른 마커는 **측정 방법의 참고**로만 본다. OpenCV 3.4.15 빌드에 SIFT/SURF 없음.

## 3. 조사 질문

| P# | 무엇을 알아야 해결되는가 |
|:---:|---|
| P1 | 반복 무늬에서 대응 오류를 막는 구조적 방법(코드 디코딩 기반 격자 대응, 격자 모델 맞춤, 바둑판·ChArUco 코너 대응)과 그 정확도 |
| P2 | peak-locking의 원인과 크기(PIV·영상 정합), 편향 상쇄 방법(대칭 보간, 역방향 보간, 반복 변형), 위치 측정의 이론 하한(CRLB) |
| P3 | 코너 vs 원·모듈 중심 등 점 종류별 위치 정확도와 편향, 특징점 이동장 vs 직접 정합의 차이 |
| P4 | 디포커스·블러에서 코너 위치 편향, 조명 변화 불변 정합, 렌즈 왜곡이 상대 측정에 주는 영향 |
| P5 | 정밀도를 유지하며 계산을 줄이는 방법(역합성 정합, 점 수 감축, 상용 라이브러리 성능) |
| P6 | QR 검출 실패 원인과 신뢰도 지표(추적 오차, 디코딩 품질 등급, 잔차 검정) |

## 4. 검색어

블록 안은 OR, 블록 사이는 AND.

| 블록 | 영문 |
|---|---|
| A. 대상 | QR code, 2D barcode, data matrix, fiducial marker, checkerboard, ChArUco, circular target, concentric circle |
| B. 문제 | sub-pixel, localization accuracy, peak locking, pixel locking, bias, repetitive pattern, mismatch, defocus, blur, lens distortion, detection failure, robustness |
| C. 수단 | corner detection, template matching, image registration, phase correlation, cross-correlation, Lucas-Kanade, centroid, ellipse fitting |

- 조합 예: A∧B (QR code localization accuracy), B∧C (peak locking cross-correlation, sub-pixel estimation error), A∧B∧C (checkerboard corner sub-pixel defocus)
- 저자 지정: Shimizu·Okutomi(부화소 편향 상쇄), Mallon·Whelan, Heikkilä(원형 표적 편향), Westerweel(PIV peak-locking)
