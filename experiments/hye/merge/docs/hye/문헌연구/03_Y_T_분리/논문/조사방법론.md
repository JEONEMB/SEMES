# Y·Θ 분리 문헌 조사 방법론 (계획)

- 작성일: 2026-10-30
- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 결과 문서: `00000_YT분리_조사_방법론_및_결과_.md` (이 계획대로 조사를 마친 뒤 작성)
- 근거 문서: 명세서 2차, 3차 멘토링 보고서 v8(이하 "팀 보고서"), `../../01_주제_관련/유사연구/00000_유사연구_종합요약.md`

## 1. 목적

1. 측정한 판 움직임에서 **Y 이동과 Θ(PAN) 회전을 분리해 각각의 값을 추정할 때** 생기는 문제를 근거 수치와 함께 정의한다.
2. 팀이 이미 시도한 방법(단일축 모델, QR 동시 추정, 학습·증강, 위·아래 가로선 joint 모델)을 반복하지 않고, **드러난 문제를 해결할 문헌 근거**를 찾는다.
3. 문제마다 본 과제에서 할 실험·구현 항목과 성공 기준(허용오차 0.09, 혼합 자세 통과율, 처리 시간 ms)을 정한다.

## 2. 이 주제에서 발생하는(할) 문제 정의

| P# | 문제 | 근거 (명세서·팀 보고서) |
|:---:|---|---|
| P1 | **관측 행렬의 공선성(ill-conditioning)**: Y와 Θ의 영상 반응 방향이 거의 같아 동시 추정이 불안정하다. | 명세서 배경("같은 x축으로 투영"). QR 536점 반응 코사인 유사도 0.9999997, Y +1.00 mm와 T +0.18의 점별 차이 표준편차 0.029 px(팀 보고서 3.4절). QR만으로 동시 추정 134/280(47.9 %), 특징 공간 유사도 0.994(표 16). 허용오차 0.09는 Y 1.28 px, T 7.2 px로 Y가 5.6배 엄격(3.3절). |
| P2 | **단일 평면(QR 판)만으로는 분리 정보가 부족**하다. 깊이가 다른 관측(평면 시차)이 필요하나, 과제가 허용한 관측만 써야 하고 그 관측은 Y 정밀도·속도를 떨어뜨린다. | QR만의 비선형·증강·신경망·공유 표면 모델 188/341 한계. QR 밖 볼트 341/341이나 과제 범위 밖이라 철회. 위·아래 가로선 joint 외부 4-fold 337/341이나 Y 평균 오차 0.0175로 단일축 모델(0.0016)의 약 11배, 측정 824~1067 ms(표 16·17, 5.2절). |
| P3 | **카메라 내부·외부 파라미터 미보정**: 기하 모델(PnP, 호모그래피 분해)을 쓰지 못하고 학습 회귀에 의존한다. | 팀 보고서 표 4 "보정 정보 없음, 미사용". 명세서 제공 자료는 영상 세트뿐(소스·교보재 N). |
| P4 | **학습 기반 회귀의 일반화(외삽)**: 학습 자료에 없는 사분면·범위에서 성능이 떨어진다. | 혼합 자세 실측이 Y>0, T>0 한 사분면뿐, T=2 12장은 1014 범위(T ±1) 밖. 증강 평가에서 (−2, −1) 모서리 통과율 29~42 %. 단일축 모델 혼합 자세 18/57, T=0으로 학습한 조건부 Y 모델 12~15/18(3.1절, 표 15·18, 그림 6). 영점이 촬영 묶음마다 −0.85~0 px 변동(3.6절). |
| P5 | **수동적(1장) 추정의 한계 → 능동적 분리 필요**: 로봇을 알려진 양만큼 움직여 얻는 정보(시험 이동, 자코비안 갱신)를 아직 쓰지 않는다. | 과제는 보정·재촬영을 최대 20턴 반복할 수 있다(1장). 현재 2단계 흐름은 매 턴 1장 추정만 쓰고, 시나리오 재생은 영상 재사용 시뮬레이션이라 실제 로봇 이동 정보가 없다(5.1절, 표 20). 제어 단위 0.05~2 mm(명세서). |

## 3. 조사 질문

| P# | 무엇을 알아야 해결되는가 |
|:---:|---|
| P1 | 평행이동·회전 혼동이 언제 생기며(시야각, 깊이 변화) 얼마나 큰가? 조건수·관측성 지표로 어떻게 진단하고, 정칙화(ridge)·자세(실험) 설계로 어떻게 줄이는가? |
| P2 | 평면 + 시차(plane+parallax)에서 평면 호모그래피를 지운 뒤 남는 시차가 회전과 무관하다는 근거와 사용 조건은? 깊이가 다른 관측을 최소 비용으로 쓰는 방법은? |
| P3 | 보정 없이(또는 거친 보정으로) 회전과 평행이동을 나누는 방법(2.5D 시각 서보, 호모그래피 분해, IPPE)은? 순수 회전·알려진 이동으로 카메라·스테이지 축을 자기 보정할 수 있는가? |
| P4 | 회귀 모델의 외삽 한계에 대한 근거와, 물리(기하) 구조를 넣어 외삽을 줄이는 방법은? |
| P5 | 로봇을 알려진 양만큼 움직여 자코비안을 추정·갱신하는 방법(Broyden 등)과 수렴 조건, 시험 이동 크기 선택 기준은? |
