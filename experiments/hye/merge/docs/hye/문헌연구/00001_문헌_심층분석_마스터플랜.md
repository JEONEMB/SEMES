# SEMES Y–T 분리·자동 티칭 문헌 심층분석 마스터플랜

작성: 2026-10-30. 상태: 분석 설계안. 개별 원문 재검증 및 실험은 아직 수행하지 않았다.

## 1. 분석 목적과 기준

각 문헌에서 **어떤 상황에서 → 어떤 문제가 생겼고 → 무엇을 바꾸어 해결했으며 → 우리 장비에 어떤 조건으로 적용 가능한지**를 추적한다. 최종 산출물은 방법 추천 목록이 아니라, 경쟁 가설을 판별하고 다음 실험·설계를 선택할 수 있는 근거 지도다.

현재 알고리즘 목표·입력 제한·평가 기준의 단일 원본은 [ALGORITHM_RULES.md](../../../ALGORITHM_RULES.md)다. 이 계획은 운영 기준을 변경하지 않는다. 기존 모델을 교체하거나 장비를 이동시키는 작업도 포함하지 않는다.

### 분석 시작 전에 바로잡을 사항

- **문헌 수:** 제안된 75편+39건=114개는 주제별 등록 건수로 관리한다. [기존 종합 결과보고 v2](00000_문헌연구_종합_결과보고_v2.md)는 중복 제외 논문 72편·특허 34건으로 집계한다. 실제 목록을 재대조하기 전에는 114개를 독립 근거 114개로 계산하지 않는다. 특허는 공개·등록 공보 및 같은 패밀리의 중복도 따로 점검한다.
- **축 정의:** 요청문의 틸트와 기존 보고서의 PAN 설명이 다르다. 로봇·카메라·마커 좌표계, T의 회전축, 단위·부호를 먼저 대조한다. 미확정 상태에서 특정 회전 운동식을 장비에 대입하지 않는다.
- **정밀도 표현:** 50 μm는 0.05 mm다. 이를 서브미크론이라고 쓰지 않는다. 영상 오차(px), 위치 오차(mm), 각도 오차, 반복정밀도, 절대정확도를 분리한다. 제안문의 50 μm와 기존 운영 기준의 관계도 요구사항 원문으로 확인한다.
- **목표 수치:** 0.01 px, 50 μm, 처리시간, 반복 횟수는 문헌 실적·실험 목표·장비 요구사항을 구분해 기록한다. 특정 조건에서의 결과를 보편적 성능으로 옮겨 적지 않는다.
- **특허 해석:** 청구한 구성, 실시예 설명, 실제 측정 결과를 구분한다. 미발견은 부존재·신규성의 증거로 취급하지 않는다.

## 2. 다섯 분석 축과 공통 데이터셋

| 축 | 반드시 추출할 내용 | 비교 시 확인할 조건 |
|---|---|---|
| 상황 | 카메라 설치, 투영·렌즈, 거리, 마커 크기·배치·깊이, 로봇 구조, 환경 | SEMES와 같은 요소와 미확인 요소 |
| 문제 | 관측 증상, 원인 후보, 수식의 가정, 실패 조건 | 식별 불가능·수치 불안정·편향·기구 오차 구분 |
| 해결 | 입력 정보, 추정 대상, 알고리즘, 보정·제어 절차 | 추가 센서·이동·사전 교정 필요 여부 |
| 비교 | 기준 방법, 절제 실험, 데이터 수, 계산량, 실패율 | 같은 데이터·단위·오차 정의에서 비교 가능한가 |
| SEMES 연계 | 동일점, 차이점, 수정 설계, 검증 실험, 채택 조건 | 현재 구성에서 가능 / 교정 필요 / 장비 변경 필요 |

문헌대장은 `문헌 ID, 주제별 별칭, DOI/공보번호, 특허 패밀리, 원문 경로, 확보 상태, 근거 위치, 연결 가설, 근거 등급`을 가진다. 한 문헌은 여러 주제·가설에 연결할 수 있지만 독립 문헌 수는 한 번만 센다.

근거 상태는 원문 확인 / 초록만 확인 / 기존 요약만 확인 / 미확보로 표시한다. 주장별로 **직접 결과 / 저자의 해석 / 우리 과제로의 추론 / 검증 전 가설**을 붙인다. 페이지·식·그림·표 또는 청구항 번호가 없는 수치와 인용은 확정 근거로 승격하지 않는다.

## 3. 경쟁 가설 18개와 판별 실험

아래는 검증할 후보이며, SEMES에서 확인된 원인 목록이 아니다. 여러 가설이 동시에 성립할 수 있다. 각 실험의 반복 수·이동 범위·판정 임계값은 예비 측정과 허용 범위를 확인한 뒤 본평가 전에 고정한다.

| ID | 경쟁 가설 | 구별되는 예측 | 판별 실험·분석 | 성립 시 검토할 접근 |
|---|---|---|---|---|
| H01 | 현재 관측에서 Y·T 영상 감도가 거의 같은 방향이다 | 서로 다른 Y·T 조합이 잡음 범위 안에서 비슷한 영상을 만든다 | 독립 축 이동의 특징 변화로 감도행렬을 만들고, 단위를 정규화한 특이값·잡음 대비 축 분리량 평가 | 관측 배치 변경, 추가 정보 |
| H02 | 평면 자세의 복수 후보가 추정 불안정을 만든다 | 비슷한 재투영 오차의 서로 다른 자세 후보가 남는다 | 후보별 재투영·시간 일관성 및 독립 기준 자세 비교 | 다중 후보 유지·능동 판별 |
| H03 | 관측 범위가 좁아 회전을 구분하는 공간 변화가 약하다 | 넓게 분포한 점이 중앙 밀집점보다 축 분리에 유리하다 | 같은 점 수·검출 품질로 중앙/외곽/분산 배치 비교 | 넓은 기준선·분산 마커 |
| H04 | 보조 선의 반응은 깊이 차에 의한 시차다 | 마커와 선의 상대 깊이를 바꾸면 축별 잔차가 체계적으로 달라진다 | 깊이 측정·평면 정합 후 Y/T별 선 잔차 비교 | 깊이 차를 이용한 관측 설계 |
| H05 | 보조 선의 반응은 회전 투영 성분이다 | 선의 위치에 따라 예측 가능한 공간 패턴이 나타난다 | 축 정의 후 투영 모델을 만들고 위·아래·좌·우 선의 변위장 대조 | 물리 모델 기반 선 특징 |
| H06 | 실제 회전축 기울기·편심이 미모델링 상태다 | 명목 회전 모델의 구조적 잔차가 남는다 | 여러 자세의 궤적으로 축·중심을 추정하고 별도 자세에서 검증 | 축 교정·강체 기구 모델 |
| H07 | 렌즈 왜곡 잔차를 Y/T 신호로 학습했다 | 영상 위치가 달라지면 같은 운동의 추정 편향이 바뀐다 | 교정 전후·영상 영역별 잔차 비교 | 왜곡 교정·유효 영역 제한 |
| H08 | 부화소 위상 편향이 작은 운동을 왜곡한다 | 잔차가 화소 내 위상에 따라 반복된다 | 미세 이동의 독립 기준값과 잔차를 위상별 비교; 합성 이동은 보조 검증 | 에지·직접 정합·편향 보정 |
| H09 | 포화·반사·블러가 구조적인 좌표 편향을 만든다 | 같은 자세에서도 촬영 조건에 따라 추정값이 이동한다 | 자세 고정 후 노출·조명·초점 변화의 반복 측정 | 광학 개선·강건 추정·품질 판정 |
| H10 | QR 반복 무늬의 대응 오류가 큰 실패를 만든다 | 특정 셀 간격의 점프나 구조 ID 불일치가 발생한다 | 실패 프레임의 대응 ID·정합 잔차를 검사 | 디코딩 기반 대응·다중 초기화 |
| H11 | 점별 잡음이 상관되어 점 수 증가 효과가 제한된다 | 점을 늘려도 반복 변동이 기대만큼 줄지 않는다 | 정지 반복 영상의 블록 공분산과 점 수별 성능 비교 | 공분산 가중·특징 선택 |
| H12 | 세션별 영점 이동을 Y/T로 오인한다 | 세션 내 성능보다 세션 간 성능이 나쁘다 | 날짜·재설치·촬영 묶음을 통째로 분리하고 센터 반복 비교 | 영점 상태 추정·기준 재관측 |
| H13 | 접근 방향·이력이 백래시 잔차를 만든다 | 같은 목표라도 도달 방향에 따라 위치가 달라진다 | 양방향·단방향 접근을 독립 계측으로 비교 | 접근 경로 관리·이력 보상 |

| H15 | 정규화가 부족한 회귀 문제다 | 규제·특징 변경으로 새 세션 오차가 개선된다 | 같은 분할에서 최소제곱·Ridge·공분산 가중 비교 | 정규화·물리 제약 회귀 |
| H16 | 알려진 소규모 이동이 단일 영상의 모호성을 줄인다 | 이동 전후 관측을 쓰면 모호한 후보가 구별된다 | 정지 사진 비교와 실제 이동·재촬영을 별도 평가 | 능동 관측·온라인 감도 추정 |
| H17 | 추정기는 충분하지만 제어 이득·양자화·지연이 복귀를 제한한다 | 오프라인 추정이 좋아도 반복 제어는 진동·정체한다 | 실행 명령·재촬영·독립 잔여오차를 시간순으로 기록 | 이득·정지 조건·실행량 모델 개선 |
| H18 | 평가 누수와 개발 데이터 재사용이 성적을 높였다 | 미사용 날짜·장비·QR 조건에서 성능이 낮아진다 | 모델 고정 후 신규 촬영 평가, 반복 사진은 같은 분할에 배치 | 일반화 검증·모델 복잡도 조절 |

H01과 H15는 별도로 판단한다. 정규화로 추정 분산이 줄어도 관측에 없는 정보가 생겼다고 해석하지 않는다. H04·H05·H06 역시 하나의 선 반응만으로 확정하지 않고 깊이·축·영상 위치를 바꾸어 경쟁 설명을 비교한다.

## 4. 다양한 해결 접근의 비교군

| 접근 | 비교할 설계 | 핵심 확인점 |
|---|---|---|
| 영상 계측 | 코너·안장점·에지·직접 정합·ICGN 계열 | 반복 변동과 편향을 각각 측정 |
| 투영 기하 | 호모그래피·평면 자세 후보·물리 투영 모델 | 가정과 실제 축·카메라 배치의 일치 |
| 기구 교정 | 회전축·중심·핸드아이·카메라 공동 보정 | 파라미터 식별성과 신규 자세 잔차 |
| 마커 설계 | 분산 배치·넓은 기준선·非공면 기준점 | 같은 광학 조건에서 정보 증가량 |
| 센서 보완 | 거리계·엔코더·추가 카메라 | 추가 센서의 정확도·설치·동기화 비용 |
| 통계 추정 | 최소제곱·Ridge·GLS·강건 추정 | 분할 내부 학습과 외부 검증 |
| 능동 관측 | 알려진 탐색 이동·재관측·국소 감도 추정 | 추가 이동의 정보 이득과 시간 비용 |
| 피드백 제어 | 순차 정렬·공동 정렬·반복 보정 | 실제 잔여오차·턴 수·실패 복구 |
| 기계 이력 보상 | 단방향 접근·백래시·열 드리프트 보상 | 명령값과 실제 변위를 구분한 효과 |
| 신뢰도 관리 | 품질 판정·추정 보류·재촬영 요청 | 오차가 큰 프레임을 실제로 식별하는가 |

현재 하드웨어 유지, 교정 추가, 하드웨어 변경의 세 시나리오로 비교한다. 변경 비용이 큰 접근도 참고군에 남겨 현재 구성의 한계를 판단한다.

## 5. 개별 문헌 표준 카드

```markdown
### [고유 ID] 저자/출원인 · 연도 · 제목
- 서지: DOI/공보번호, 패밀리, 주제별 별칭
- 확보·검증: 원문/초록/요약/미확보, 확인 날짜
- Context: 카메라, 거리, 마커·깊이, 축·기구, 작업 환경
- Problem: 증상, 원인, 수식과 성립 가정
- Solution: 입력, 추정 대상, 알고리즘·교정·제어 절차
- Results: 지표 정의, 단위, 표본 수, 기준 방법, 실패 포함 여부
- 근거 위치: 페이지·식·그림·표・청구항; 직접 결과/해석 구분
- Comparison: 공통점, 차이점, 계산·설치·교정 비용
- SEMES Same: 실제로 같은 조건
- SEMES Diff: 다른 조건과 미확인 조건
- SEMES Action: 이식할 구성과 필요한 수정
- 연결 가설: Hxx, 지지/반증/조건부/미판정
- 판별 실험: 예측, 대조군, 관측량, 사전 판정 기준
- 한계: 원문 미확보, 비교 불가능 지표, 우리 과제로의 추론 범위
```

성능 수치가 없으면 미보고로 기록한다. 특허의 구성 설명을 정밀도 향상의 실험 증거로 바꾸지 않는다. 관련도와 증거 강도는 별도 열로 둔다.

단계 1에서 18개 가설 모두를 확정하려 하지 않는다. 원인 문헌은 원인 구조를 만들고, 이후 챕터에서 증거를 보강한다. 앞 단계의 결론은 뒤 단계의 반증에 따라 갱신한다.

### Step 1의 구체적 구성

1. 15편 논문·8건 특허를 등록 목록과 대조한다.
2. 기존 요약·번역으로 카드 초안을 만들되, 확인 수준을 표시한다.
3. 핵심 주장에 해당하는 원문 식·그림·청구항을 대조한다.
4. 기하·광학/통계·기구/교정·제어/평가의 원인 트리를 만든다.
5. 행=문헌, 열=H01~H18인 매트릭스에 지지·반증·조건부·미판정을 기록한다.
6. 근거가 충돌하면 촬영 조건·좌표계·추정 대상·노이즈 가정의 차이를 먼저 분석한다.
7. 가장 적은 추가 비용으로 경쟁 가설을 구별할 실험 3개를 선정한다.

## 7. 실험 우선순위와 평가 설계

첫 후보는 ① 정지 반복 및 세션별 영점 측정(H08~H12), ② 독립 축 이동의 감도·공간 잔차 분석(H01·H03~H07), ③ 양방향 접근 및 실제 이동 전후 관측(H13·H16·H17)이다. 이는 장비 범위와 자료 가용성을 확인하기 전의 우선순위 초안이다.

각 후보는 정보 이득, 예상 잔여오차 개선, 실험 비용, 설치 변경, 사이클 시간으로 비교한다. 가중치와 점수를 임의로 확정하지 않고 근거를 기록한다.

평가표에는 Y/T 각 축의 평균·최대 절대오차, 동시 허용오차 통과율, 측정 실패율, 처리시간 중앙값·p95를 둔다. 실제 제어에서는 잔여오차·이동 및 재촬영 횟수·총시간·복구 실패를 추가한다. 정답 메타데이터는 추론 입력에서 분리하며 학습·교정·임계값 선택은 평가 분할 밖에서 수행한다.

GUM, ISO 9283, Gauge R&R은 적용할 평가 설계와 해당 원문 조항을 확인한 뒤 사용한다. 제안문에 적힌 반복 수·%GRR·ndc만으로 양산 적합을 판정하지 않는다. 추정값끼리의 일치는 외부 기준에 대한 정확도 검증과 구별한다.

## 8. 최종 의사결정 산출물

- **근거 지도:** 상황→원인→해결→가설→SEMES 실험을 문헌 ID로 연결한다.
- **가설 판단표:** 지지됨/반증됨/조건부/미판정과 근거 수준을 기록한다.
- **설계 대안 비교:** 현 구성 개선, 능동 관측, 교정 추가, 센서·마커 변경을 비교한다.
- **검증 계획:** 개발 자료, 신규 정지 촬영, 실제 이동·재촬영, 외부 계측의 역할을 나눈다.
- **남은 불확실성:** 미확보 원문, 축·단위, 설치 조건, 장비 데이터 부족을 표시한다.

완료는 114개 요약 작성 여부만으로 판단하지 않는다. 추천한 설계가 어떤 근거에서 나왔고, 어떤 실험 결과가 나오면 채택하거나 폐기할지 설명할 수 있어야 한다.
