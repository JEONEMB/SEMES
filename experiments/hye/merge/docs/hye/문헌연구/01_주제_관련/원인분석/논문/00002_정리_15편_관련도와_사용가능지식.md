## 0. 먼저 — 문제 정의 P1~P5

관련도 평가의 기준이다. 출처는 [조사방법론.md](조사방법론.md) 2절.

| | 문제 | 팀 실측 근거 |
|---|---|---|
| **P1** | **기하학적 동치.** 평면 판을 좁은 시야로 보면 작은 Y 이동과 작은 T 회전이 1차로 같은 영상 이동을 만든다. 차이는 2차(원근) 항뿐이다 | Y 1 mm ↔ T 0.178 이 판 이동이 거의 같음. 반응 방향 코사인 유사도 0.9999997 |
| **P2** | **관측 가능성·조건수.** QR 판만 보면 두 열이 거의 평행한 선형계가 되어 해가 불안정하다 | QR만 134/280 (47.9%). 가로선을 더하자 337/341 |
| **P3** | **신호 대 잡음.** 구분 단서(2차 항)가 점 위치 잡음과 같은 크기다 | 구분 단서 0.029 px, 점 잡음 0.0124~0.033 px |
| **P4** | **장비 기하 미보정.** 회전축 위치·기울기, 카메라 내부 매개변수를 모른다 | 감도 Y 14.25 px/mm, T 80.04 px/T. 명세서에 기하 정보 없음 |
| **P5** | **백래시·영점 변동.** 같은 명령값에서도 접근 방향에 따라 판 위치가 달라진다 | 묶음마다 영점 −0.85~0 px |

## 2. 논문별 사용 가능한 지식

"쓸 수 있는 것"과 "쓸 수 없는 것"을 나눠 적는다. 실험으로 확인된 것은 실험 ID를 붙였다.

### 01. Daniilidis & Nagel 1993 — 회전·병진 결합 ◎

| | |
|---|---|
| **쓸 수 있는 것** | 좁은 시야(A=0.1)에서 **합 `v_x + ω_y` 만 강건하고 개별 분산은 크게 는다**. 결합이 가장 큰 세 조건은 ① 정면 평면(기울기 ≈ 0) ② 좁은 시야 ③ 광축에 수직인 병진이다 |
| **우리에게 적용** | 세 조건을 **전부** 갖췄다. "합"은 판 전체 가로 이동이다 |
| **실험으로 확인** | **A2:** 정보행렬의 약한 방향 각도 **0.00도**. **A3:** 실측 오차 주축 **0.18도**, 상관 −0.914. 예측과 일치 |
| **쓸 수 없는 것** | 초록·번역에 **수치 예가 없다.** "얼마나 나빠지는지"는 우리가 직접 재야 했다 |
| **결론에 쓰임** | 오차를 2축이 아니라 **약한 방향 1축 문제**로 다룬다 |

### 02. Young & Chellappa 1992 — CRLB ◎

| | |
|---|---|
| **쓸 수 있는 것** | CRLB 식 (44). 하한이 **시야각과 점 밀도**에 의존한다 |
| **우리에게 적용** | 점을 판 가장자리까지 넓게 쓰는 것과 점 수를 늘리는 것의 효과를 **미리 계산**할 수 있다 |
| **실험으로 확인** | **A2:** F = JᵀΣ⁻¹J 를 만들어 조건별 σ를 냈다. **바깥 점이 안쪽보다 20% 낫다**(0.0211 → 0.0168) |
| **쓸 수 없는 것 (중요)** | **이 논문은 잡음이 IID 가우스라고 가정한다.** 우리는 그 가정이 깨졌다. **A1:** 유효 독립 차원 **18.9 / 536 (3.5%)**. 그래서 "점을 늘리면 좋아진다"는 계산은 우리에게 **성립하지 않는다** |
| **결론에 쓰임** | 점 증설은 무효. 대신 **관측 영역을 넓히는 쪽**(선)으로 간다 |

### 03. Irani, Rousso & Peleg 1994 — 평면 운동식 ◎

| | |
|---|---|
| **쓸 수 있는 것** | 평면 운동의 영상 변위식. **`u = −(f/Z)Tx − fΩ − (x²/f)Ω`, `v = −(xy/f)Ω`**. u의 x² 계수와 v의 xy 계수가 **같다** (둘 다 −Ω/f) |
| **우리에게 적용** | 팀 문서 `2.1.1_원인의_수식_정리.docx` 가 이 식을 우리 장비에 맞춰 정리했다 |
| **실험으로 확인** | **A4:** 선의 T 반응에서 위·아래 기울기 부호가 반대 (xy 항). 단순 모델보다 AIC **251** 낮음. **A13:** 같은 제약으로 **f = 4492 px, 주점 (1919, 1097)** 을 자료에서 뽑았다. 주점이 영상 중심(1920, 1080)에서 **가로 1 px** |
| **쓸 수 없는 것** | 정성 결과 위주라 **비교할 수치가 없다**. 그리고 식이 설명 못 하는 항이 남는다(**A13:** u의 y² 항이 x²의 14%) |
| **결론에 쓰임** | 이 폴더에서 **가장 많이 쓴 논문**이다. 선의 기전 규명(A4)과 카메라 자기 보정(A13) 둘 다 이 식에서 나왔다 |

### 04. Adiv 1989 — 모호성 조건 9개 ○

| | |
|---|---|
| **쓸 수 있는 것** | 모호성에 기여하는 조건 **9개**: FOV 작음 / **국소성 인자 γ 작음** / 평면 기울기 작음 / 물체 멂 / 병진 작음 / 해상도 낮음 / 잡음 높음 / 흐름장 성김 / **인접 흐름 벡터의 잡음 상관** |
| **우리에게 적용** | 우리 값을 넣어 **몇 개에 해당하는지** 셀 수 있다 |
| **실험으로 확인** | **A2:** **9개 중 7개 해당.** 해상도와 잡음만 유리하다. 특히 **γ 는 QR만 쓰면 0.09~0.18 로 Adiv 가 시험한 최악(1/4)보다 나쁘다.** 선을 더하면 0.53~0.77 |
| **쓸 수 없는 것** | 조건을 나열할 뿐 **"그래서 얼마나 나쁜가"의 식은 없다.** 그 몫은 02(CRLB)와 06(최소 고유값)이 한다 |
| **결론에 쓰임** | **선이 왜 결정적인지를 설명하는 가장 좋은 틀.** 선은 정보를 더하는 게 아니라 **조건 2번에서 빠져나오게** 한다 |

### 05. Fermüller & Aloimonos 2000 — 관측 가능성 ○

| | |
|---|---|
| **쓸 수 있는 것** | 좁은 시야에서 "병진 오차를 회전 오차로 갚는" 해가 **오차 함수의 최소점 근처에 남는다** |
| **우리에게 적용** | Y 오차와 T 오차가 `ΔY ≈ −5.62 × ΔT` 방향으로 **함께** 나타나는지 확인하면 이 현상인지 판단된다 |
| **실험으로 확인** | **A3:** 상관 **−0.914**, 주축이 그 방향과 **0.18도**. **A10:** 전달 모듈 `joint()` 의 최대오차 상위 10장도 eY/eT 비가 전부 −3.8 ~ −5.9 |
| **쓸 수 없는 것** | 초록에 수치 없음 |
| **결론에 쓰임** | 01 과 같은 결론의 독립적 보강 |

### 06. Szeliski & Kang 1997 — 최소 고유값 진단 ○

| | |
|---|---|
| **쓸 수 있는 것** | 정보 행렬(헤세 행렬)의 **가장 작은 고유값과 그 고유벡터**를 보면 ① 어떤 조합이 안 보이는지 ② 어떤 관측을 더하면 그 고유값이 커지는지를 **정량으로** 보일 수 있다 |
| **우리에게 적용** | **A2 의 방법론이 곧 이것이다** |
| **실험으로 확인** | **A2:** 조건수 측정 잡음만 **5.6×10⁶**, 반복 자세 차이 포함 **419**. 선을 넣으면 8,981 → 419 로 **21배** 좋아진다 |
| **쓸 수 없는 것** | 200 화소 폭 영상의 수치 실험이라 값을 직접 비교할 수 없다 |
| **용어** | "옆방향 병진–회전 혼동"을 **우리 문제의 문헌상 명칭**으로 쓸 수 있다 |

### 07. Chaumette 1998 — 시각 서보 안정성 ○

| | |
|---|---|
| **쓸 수 있는 것** | 되먹임에서 자코비안 두 열이 거의 평행하면 ① 역행렬이 잡음을 키우고 ② **영상은 목표와 같아 보이는데 Y·T 가 서로 상쇄되어 틀어진 자세**에 머물 수 있다 |
| **우리에게 적용** | **영상 일치만으로 "정렬 완료"를 판정하면 안 된다.** 종료 판정 설계에 직결 |
| **실험으로 확인** | **못 했다.** 실기 폐루프 자료가 없다 → **B5** |
| **쓸 수 없는 것** | 안정 조건 `L·L̂⁺ > 0` 은 연속시간이다. 이산 지연·양자화·단계 전환은 별도 분석이 필요하다 |
| **결론에 쓰임** | 종료 판정에 **독립 검증**이 필요하다는 근거 |

### 08. Malis, Chaumette & Boudet 1999 — 2½D 시각 서보 ○

| | |
|---|---|
| **쓸 수 있는 것** | 정면 평면에서 호모그래피 `H = R + t·nᵀ/d` 의 **3행 1열 원소는 Y축 회전에서 생기고 X 병진에서는 안 생긴다.** 회전과 병진을 "같은 영상 이동"이 아니라 **호모그래피의 다른 원소**로 분리한다 |
| **우리에게 적용** | 팀 P12 의 2차 항과 같은 정보를 **물리 매개변수로 묶어 준다** |
| **실험으로 확인** | **A14 에서 실제로 세워 돌렸다.** A13 의 K 를 써서. 결과는 **반반이다** |
| | **T 는 된다.** 학습 없이 기울기 **0.9008**, 잔차 0.024도 |
| | **Y 는 안 된다.** 기울기 **−0.1586**, 잔차 1.19 mm. 통과율 2.5% |
| **쓸 수 없는 것** | 요약이 이미 경고했다. **"그 원소의 크기는 시야가 좁으면 작아서 P3 의 잡음 문제는 그대로 남는다."** 실측이 그대로 확인했다 |
| **결론에 쓰임** | **T 축 검산용**으로 쓸 수 있다. Y 추정에는 못 쓴다 |

### 09. Schweighofer & Pinz 2006 — 평면 두 해 모호성 ○

| | |
|---|---|
| **쓸 수 있는 것** | 정면에 가까운 평면을 PnP·호모그래피 분해로 풀면 **기울기 부호가 반대인 두 해**가 비슷한 재투영 오차를 낸다 |
| **우리에게 적용** | 팀이 기하 모델을 쓰지 않은 판단의 **문헌 근거**. 기하 모델을 쓴다면 두 해를 모두 구해 **T 부호를 가로선으로 고르는** 구조가 필요하다 |
| **실험으로 확인** | **A14: 519장 전부에서 후보가 2개 이상.** 두 후보의 Y 차이 중앙값 **0.87 mm** (허용오차의 19배) |
| **쓸 수 없는 것** | — |

### 10. Oberkampf 외 1996 — 약원근 자세 추정 ○

| | |
|---|---|
| **쓸 수 있는 것** | 약원근에서는 기울기 변화가 1차로 안 나타나(`cos θ ≈ 1 − θ²/2`) 부호가 정해지지 않는다. **거리가 멀수록, 점 정확도가 낮을수록 두 해가 구분 안 된다** |
| **우리에게 적용** | P1·P3 과 같은 조건 |
| **실험으로 확인** | **A13:** 거리 Z = **315 mm**, 판 폭 49 mm → 거리/크기 비 6.4. 약원근 영역에 가깝다 |
| **쓸 수 없는 것 (중요)** | 이 논문의 "4점은 10점보다 이중해 확률이 극적으로 높다"를 근거로 **A2 에서 "536점이면 안전하다"고 판단했는데, A14 가 반증했다.** 점 수는 잡음을 줄일 뿐 **기하적 모호성은 없애지 못한다** |
| **결론에 쓰임** | 판단 정정의 근거. 점 수 논리를 이중해에 적용하면 안 된다 |

### 12. Chai, Wei & Gao 2023 — 회전축 보정 △

| | |
|---|---|
| **쓸 수 있는 것** | 축이 떨어져 있으면 T 회전 = **순수 회전 + (축 거리 × 각도) 병진**. 축이 기울면 T 가 **영상 세로 이동(롤)** 도 만든다. 절차: 여러 각도에서 기준판 촬영 → 축 방향·위치 추정 |
| **우리에게 적용** | 감도비 5.62 mm/T 가 이 **등가 회전 반경**을 반영한다 |
| **실험으로 확인** | **A13:** 등가 반경 **315.9 mm**, T 1단위 = **1.0187도**. 단 **축이 광학 중심을 지난다(d=0)고 가정**해야 나온 값이다 |
| **쓸 수 없는 것 (중요)** | **축 오프셋 d 를 식별하지 못했다.** T 범위가 ±1.02도뿐이라 Hou 2020 이 쓴 22.5도의 **1/22** 이다. → **B4** |
| **결론에 쓰임** | 이 논문이 제안한 절차(여러 각도 촬영)가 **곧 B4 요청서의 내용**이다 |

### 13. Baker 외 2001 — 넓은 시야로 모호성 해소 △
