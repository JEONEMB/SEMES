## 상세 요약 (USPTO 등록본 PDF 판독 기준)

### 1. 해결하려는 문제
- 광학 계측기는 설치 면적을 줄이려 X-Y 스테이지 대신 R-θ(극좌표) 스테이지를 씀: 직선축 R로 이동 + 회전 중심 둘레 회전.
- 회전하면 시야도 함께 돌아감. X-Y-θ 스테이지는 3자유도로 임의 θ 뒤에도 어느 점이든 시야 중심에 가져올 수 있어 종래 알고리즘이 이를 이용했지만, R-θ는 2자유도라 그 방법을 못 씀.
- 종래('609 특허, US 6,320,609)는 회전 중심을 시야 중심과 거의 일치시킬 수 있다고 가정 — 실제로는 기계적 정렬이 어렵거나 불가능. 오프셋을 보정하지 않으면 원하는 웨이퍼 지점을 시야 중심에 정확히 놓지 못함.

### 2. 핵심 구성
| 구성 | 부호 | 위치·역할 |
|---|---|---|
| R-θ 스테이지 | 101 | 2자유도: 트랙(104)을 따라 R축(106) 이동, 회전자(108)로 척 회전 |
| 척 | 102 | 웨이퍼(122) 고정. 300 mm 웨이퍼에 트랙 길이 약 160 mm 예시 |
| 대물 렌즈 / 시야 중심 | 120 / 206, 시야 300 | 광학 촬상계(118 검출기, 116 영상 처리기, 114 모니터) |
| 회전 중심 | 202 | 척의 기계적 회전 중심 |
| 홈 위치 원점 | 208 | 홈 위치의 회전 중심 = home 좌표계 원점 (0,0), Y+ = R+ 방향 |
| 오프셋 | 204 | 시야 중심(렌즈)과 홈 위치 회전 중심 사이 거리 — 구하려는 값 |
| 특징 지점 | 210 | 웨이퍼 위의 식별 가능한 점(회전 중심에 가까울수록 오프셋 작음) |
| 처리기 / 조작부 | 112 / 110, 제어기 111 | 이동량 저장·오프셋 계산, 사용자 조작 입력 |

- 좌표계 3개: home(고정, 원점 208), lens(렌즈 중심, Y축은 home과 같음), stage(척과 함께 돌고 이동 — 웨이퍼 점의 stage 좌표는 불변).

### 3. 동작 순서
1. 사전 조정: 트랙에 수직한 가로 방향으로 스테이지 위치를 기계 나사로 조정해 회전 중심과 렌즈를 약 10~20 µm 이내로 맞춤.
2. 특징 지점(210)을 골라 조작부로 척을 움직여 시야 중심에 둠(도 3, 예: 시계 방향 약 130° 회전 + 거리 R 이동). 정확히 중심일 필요는 없고 시야 안이면 됨.
3. 스테이지를 180° 회전 + −2R 이동(조작자 또는 처리기가 자동으로). 오프셋이 0이면 지점이 다시 렌즈 정중앙에 와야 함.
4. 오프셋(204)이 있으므로 지점이 렌즈 아래에서 벗어나 있음(도 4) → 조작부로 ΔΘ 회전 + ΔR 이동해 다시 시야 중심에 맞춤(도 5). 처리기가 ΔΘ, ΔR 저장.
5. 계산(도 6·7): 회전 중심이 둘째 자세에서 가 있는 위치를 (x(site), y(site))라 할 때
   - 렌즈의 home 좌표: y(lens) = ΔR/2,  x(lens) = tan(ΔΘ/2)·[(x(site)² + y(site)²)^(1/2) − ΔR/2]
   - 회전 중심의 lens 좌표: y(CR) = −ΔR/2 = −y(lens),  x(CR) = −tan(ΔΘ/2)·[(x(site)² + y(site)²)^(1/2) − ΔR/2] = −x(lens)
   - 근거: 502–504를 잇는 선에서 208까지 거리가 ΔR/2, 선 702를 포함한 삼각형의 각이 ΔΘ/2.
6. 여러 지점(가능하면 서로 다른 사분면, 점점 중심에서 먼 지점)으로 반복. 180° + −2R 뒤 사용자 조정이 더는 필요 없으면 종료 — 실제로는 1회로 충분할 수 있다고 기재.
7. 구한 회전 중심 좌표를 소프트웨어 내부 매개변수로 갱신해 이후 모든 지점 위치 지정에 보상.
- 180° + −2R 대신 조작자가 둘째 자세로 직접 몰아가서, 실제 스테이지 좌표와 "정렬됐다면 기대되는 좌표"의 차이로 오프셋을 구해도 된다고 기재.
- 이 정렬은 스테이지나 광학 요소를 바꾸거나 옮길 때만 하면 됨. ½X·½Y 스테이지 등 다른 회전형 스테이지에도 적용 가능.

### 4. 청구항 요지 (21항)
- 청구항 1(시스템): 척·트랙을 가진 극좌표 스테이지, 시야를 가진 광학 촬상계, 시료 지점을 시야에 놓아 얻은 정보로 시야 중심–회전 중심 오프셋을 구해 검사 지점 위치 결정에 쓰는 처리기.
- 청구항 7(방법): 홈에서 제1 거리 떨어진 제1 위치(지점이 시야 안) → 180° 회전 + 제1 거리의 두 배 이동(제2 위치) → 지점이 다시 시야에 오도록 조정(제3 위치) → 제2→제3 조정의 ΔΘ, ΔR로 오프셋 결정 → 오프셋으로 척 이동 제어.
- 청구항 12(방법): 같은 지점이 시야에 오는 제1·제2 위치의 차이로 오프셋 계산(180°에 한정하지 않음).
- 청구항 19·20: 시야 중심–회전 중심 오프셋을 써서 검사 지점 위치를 결정하는 시스템·방법.
- 청구항 21: 제2 위치와 "제1 위치에서 180° 회전 + 두 배 이동한 제3 위치"의 차이로 오프셋 결정.
- 종속항 6·11·16~18: 위 y(lens) = ΔR/2, x(lens) = tan(ΔΘ/2)·[…] 식을 청구항에 그대로 기재.

### 6. 본 과제(Y·Θ 얼라인먼트)와 비교
- 같은 점:
  - 직선 1축 + 회전 1축(본 과제 Y·T, 특허 R·θ)뿐인 2자유도 장비에서, 회전 중심과 카메라 시야의 관계를 모르는 상태로 출발한다.
  - 카메라 시야 안 한 지점을 기준으로, 축 이동량만 써서 회전 중심 위치를 거꾸로 구한다(별도 지그·외부 측정기 없음).
- 다른 점:
  - 특허는 카메라 고정·웨이퍼가 움직이고, 본 과제는 카메라가 스테이지에 달려 고정된 QR 판을 본다(운동학적으로는 역할만 뒤바뀜).
  - 특허는 180° 회전과 트랙 왕복(−2R)을 전제로 한다. 본 과제 T(PAN)는 회전 범위가 작아 180° 대칭 자세를 만들 수 없으므로, 청구항 12·본문의 "임의의 두 자세" 일반형을 써야 한다.
  - 지점을 시야 중심에 맞추는 일을 조작자(또는 반복)가 하며, 화소 단위 정밀도·백래시·잡음은 다루지 않는다.
- 참고할 점 / 해결하는 P#:
  - **P4(회전 중심–카메라 시야 오프셋)**: "같은 점을 시야 같은 자리에 다시 놓는 두 자세"의 축 이동량(ΔR, ΔΘ)만으로 회전 중심 위치가 닫힌 식으로 나온다. 한 번 구해 소프트웨어 매개변수로 저장하고, 장비를 바꿀 때만 다시 한다.
  - **P1(보조)**: 회전 중심까지의 거리(지렛대 길이)를 알면 T 회전이 만드는 영상 이동 = 거리 × 각도로 예측할 수 있어, 같은 가로 이동으로 합쳐진 Y·T를 나눌 근거가 된다.
  - 본 과제에서 할 일:
    1. 캘리브레이션 절차로 "T를 +Δθ 돌림 → QR 중심이 원래 화소로 돌아올 때까지 Y로 되돌림 → 필요한 ΔY 기록"을 여러 Δθ에 대해 반복해, ΔY/Δθ 기울기로 회전축–QR 판 거리(지렛대)를 추정한다. 백래시 영향을 줄이려 매번 같은 방향으로 접근한다.
    2. 구한 회전 중심 매개변수를 설정 파일에 저장해 실시간 C++ 계산(Y·T 감도 행렬)에 넣고, 장비 교체·카메라 재장착 때만 다시 측정하는 운용 규칙을 정한다.
