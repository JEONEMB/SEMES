## 상세 요약 (USPTO 등록본 PDF 판독 기준)

### 1. 해결하려는 문제
- 레일 주행 대차는 정확하지만 전용 설비가 필요하고 설치 후 바꾸기 어려움. 아무 방향으로 움직이는 대차는 로봇 위치 정확도가 보장되지 않음.
- 종래 방식처럼 대차 어긋남을 재서 티칭 위치를 계산으로 오프셋해도, 공작기계 도어의 좁은 개구부로 팔을 넣는 작업에서는 대차가 잘못 놓이면 로봇이 기계와 간섭할 수 있음.
- 바닥 마크·맞닿음 지그로 대차를 맞추는 방법은 로봇 팔 길이·작업물마다 적정 위치가 달라 마크·지그가 여러 개 필요하고 작업자 숙련이 필요.
- → 위치 결정 기구 없는 대차라도 어느 정도 정확하게, 쉽게 놓을 수 있게 하자.

### 3. 동작 순서
1. 작업자 절차(도 4): 대차를 작업 공간 목표 근처로 이동(101) → 시작 버튼(102) → 로봇 위치 판정(103) → 범위 밖이면 화면 지시대로 대차 이동(105) 후 102로 → 범위 안이면 스토퍼로 잠금(106) → 작업 시작(107).
2. 판정 제어(도 7):
   - 121~124: 로봇이 카메라를 제1 마크 촬영 위치로 이동 → 촬영 → 영상 처리로 마크 위치(직선 교점) 검출. 템플릿 매칭(정규화 상관) 등 사용. 마크가 시야(71) 밖이면 경고 표시.
   - 125~128: 제2 마크도 같은 방식. 제1 마크 검출 결과로 제2 마크 촬영 자세를 미리 오프셋하면 더 확실히 찍힘.
   - 129: 두 마크 위치를 합침 — 예: 두 마크를 잇는 선분의 **중점** 위치 계산.
   - 130: 중점을 로봇 좌표계(원점 예: J1·J2 축 교점, 또는 상판과 J1 축 교점)로 변환.
   - 131: 목표 중점과 현재 중점의 거리가 임계값 이내면 범위 안(132, COMPLETE 표시), 아니면 133에서 대차 이동 방향·이동량 계산·표시.
3. 거리 판정 방식: 직선 거리, 또는 평면 x·y 성분과 z축 둘레 r축(회전각) 성분으로 나눠 **방향별 임계값** 판정. 3차원이면 x, y, z, w, p, r 성분별 판정.
4. 마크 수와 정확도(본문 취지): 화살표 같은 기호를 마크로 쓰면 마크 1개로도 위치 편차와 각도 편차를 검출할 수 있다. 그러나 **마크 2개로 판정하면 회전 방향 편차를 마크 1개보다 더 정확히 계산**할 수 있고, 여러 마크의 측정 결과를 합치면 비전 센서 식별 정확도가 높아질 수 있다.
5. 대차 고정 후에는 마크 영상으로 공작기계에 대한 로봇의 위치·회전 편차를 계산해 로봇 동작(위치·자세)을 오프셋하는 것이 바람직하다고 기재.
6. 변형예: (1) 손목 2D 카메라로 같은 마크를 두 시점에서 찍는 스테레오로 마크 3개의 3D 위치 → 평면·대차 기울기, (2) 3D 카메라(교차 레이저 2줄)로 마크 평면 기울기 + 2D 위치 → (x, y, z, w, p, r), (3) 대차 위 2D 카메라 3대의 시선을 기지 삼각형에 맞춤.
- 마크는 식별만 되면 됨 — **QR 코드(등록상표)·매트릭스 코드 같은 바코드** 사용 가능. 공작기계와 로봇의 대응(번호)을 바코드로 표시해 오선택을 막을 수 있음.

### 4. 청구항 요지 (5항)
- 청구항 1(시스템): 작업 로봇, 작업자가 미는 대차, **로봇 손목에 고정한 비전 센서**, 작업 공간의 제1·제2 마크, 제어 장치, 표시 장치. 제어 장치는 제1 마크 촬영 뒤 로봇 자세를 바꿔 제2 마크를 촬영하고, 위치 취득부가 두 마크 위치를 구하고, 판정부가 판정 범위 밖이면 대차 이동 방향·이동량을 계산해 표시.
- 청구항 2: 로봇 위치와 두 마크 영상의 관계를 비전 센서에서 미리 캘리브레이션하고, 작업 공간에 대한 위치 관계가 정해진 마크 영상을 처리해 위치 계산. (정정증명서: 16단 청구항 2 둘째 줄 "which" 뒤 "a" 삭제)
- 청구항 3: 실제 마크 위치와 목표 마크 위치의 거리를 **여러 정해진 방향별로** 계산하고 방향마다 판정 범위 이내인지 판정.
- 청구항 4: 판정 결과로 표시를 갱신해 작업자가 화면을 보며 대차를 맞춤.
- 청구항 5(시스템): 반대 배치 — 작업 공간에 제1·제2 비전 센서, 로봇 손목에 마크 1개. 로봇이 마크를 옮겨 두 센서가 차례로 촬영.

### 6. 본 과제(Y·Θ 얼라인먼트)와 비교
- 같은 점:
  - 로봇에 단 카메라 한 대로 작업 공간에 고정된 마크(QR 코드도 가능)를 찍어, 미리 캘리브레이션한 카메라–로봇 관계로 위치·회전 편차를 구한다.
  - 평면 위치(x, y)와 수직축 둘레 회전(r)을 성분별로 나누고 성분마다 임계값을 둔다 — 본 과제 Y·T 허용치 판정과 같은 구조.
- 다른 점:
  - 두 마크를 **로봇을 움직여 따로따로** 찍는다(한 영상에 담지 않음). 본 과제는 QR 3개를 한 장에 찍는다.
  - 마크 간격이 기둥 두 개 사이(작업 공간 크기)라 기준선이 길다. 본 과제는 좁은 시야 안 QR 간격이라 기준선이 짧다.
  - 두 마크로 회전 편차를 계산하는 식은 없고(중점 계산만 명시), 정확도 수치도 없다. 목적은 대차를 임계값 이내로 놓게 돕는 것이며 실시간 보정이 아니다.
  - 카메라–로봇 캘리브레이션은 "이미 되어 있다"고 전제 — 본 과제의 P4(축·카메라 관계 미상)는 다루지 않는다.
- 참고할 점 / 해결하는 P#:
  - **P2(마크 간격과 회전 분해능)**: 마크 1개(방향성 기호)로도 각도는 나오지만, 떨어진 마크 2개를 쓰면 회전 편차가 더 정확하다고 명시 — 회전 정확도가 마크 간 기준선 길이에 달려 있다는 근거로 인용할 수 있다. 시야가 좁으면 "로봇을 움직여 먼 마크를 차례로 찍는" 방식으로 기준선을 시야 밖까지 늘릴 수 있다는 예이기도 하다.
  - **P1(보조)**: 위치 = 두 마크 중점, 회전 = 두 마크의 상대 배치로 나눠 평행이동과 회전을 분리한다.
  - 본 과제에서 할 일:
    1. QR 판에서 가로로 가장 멀리 떨어진 마크 쌍으로 T를, 중점으로 Y를 계산하는 경로를 만들고, 간격을 바꿔(가까운 쌍 / 먼 쌍 / 뒷벽 가로선 포함) T 추정 표준편차가 간격에 반비례하는지 측정한다.
    2. 한 장 안 기준선이 부족하면, 스테이지를 Y로 옮겨 시야 밖의 둘째 마크(또는 뒷벽 특징)를 차례로 찍고 엔코더 이동량을 더해 기준선을 늘리는 2회 촬영 방식을 후보로 검토한다(이때 접근 방향을 한쪽으로 고정해 백래시를 피함).
