## 0. 논문과 특허는 성격이 다르다

## 2. 질문별로 묶으면

### Q. 왜 Y / T 가 영상에서 같아 보이는가 — 특허도 같은 말을 한다

**[PT-01] Cognex US9247684 ◎**

이 특허가 **우리 문제를 그림으로 그려 놓았다.**

> 도 9A — 촬상 범위 **밖** 회전 중심: 마크 궤적이 원호의 일부뿐이고, **등변이 길고 꼭지각이 작아 중심 오차가 크다**
> 도 9B — 촬상 범위 **안** 회전 중심: 반지름이 작고 꼭지각이 커서 중심 오차가 작다

**"회전 중심이 멀면 회전이 짧은 원호 = 거의 평행이동으로 보인다."** 논문 쪽 P1을 특허가 장치 문제로 인정하고 그린 것이다.

| | |
|---|---|
| **우리 실측** | **A13: 등가 회전 반경 = 315 mm.** 판 폭이 49 mm이므로 회전 중심이 판 크기의 **6.4배** 떨어져 있다. 도 9A 상황 그대로다 |
| **수치 근거** | 중심 오차가 대략 **1/tan(Δθ/2)** 배로 커진다. 우리 T 범위 ±1.02도면 tan(0.51°) = 0.0089 → **112배** |
| **쓸 수 있는 절차** | ① T를 Δθ씩 여러 번 돌려 QR 코너 화소 좌표를 모아 **최소제곱 원호**로 중심을 구한다 ② 또는 이등변 삼각형 `h = (L/2)/tan(Δθ/2)` |
| **핵심 해법** | 시야 **안**에 "설정 회전 중심"을 만들어 재측정하고 그 차로 바깥 중심을 보정 (`c1' = c1 + (c2 − cs)`) |

**이 해법을 우리 장비에 옮기면 이렇게 된다.** 특허는 X·Y·θ 3축이라 평행이동으로 가상 중심을 만들 수 있다. 우리는 Y·T 2축뿐이지만 **"T 회전 + 그만큼 보상하는 Y 이동"을 함께 명령하면 가상 회전 중심을 Y 방향으로 옮길 수 있다.** 추정한 축 위치로 보상 Y를 계산해 넣고, QR 한 점이 화상에서 제자리에 머물도록 회전시킨 뒤 남은 이동을 보정량으로 쓴다.

**→ 이것은 B4(넓은 T 스윕)에 더해 바로 설계할 수 있는 실험이다.** 지금 B4 요청서에 없다.

**[PT-07] Therma-Wave US6747746 △** — 축 구성이 우리와 가장 비슷하다

직선 1축(R) + 회전 1축(θ)뿐인 장비다. **우리 Y·T와 같은 2자유도**다.

> 같은 지점을 시야 중심에 놓는 자세가 **최대 두 개**뿐이다. 180° 회전 + −2R 이동으로 둘째 자세로 보내고, 남은 어긋남을 다시 맞추는 데 든 ΔΘ·ΔR로 **중심 오프셋을 닫힌 식으로** 구한다.

| | |
|---|---|
| **쓸 수 있는 것** | 2축만으로 회전 중심을 구하는 **닫힌 식**이 있다. 원 맞춤이 필요 없다 |
| **못 쓰는 것** | **180° 회전을 전제한다.** 우리 T 범위는 ±1.02도다. 1/176 |
| **그래도 쓸 것** | "회전 중심 위치를 알면 Y·T가 같아 보이는 문제를 푸는 **지렛대 길이**가 정해진다"는 관점. **A10이 `σ_Y = Z × σ_T` 로 이 지렛대를 수로 확인했다** |

### Q. 회전축과 좌표계를 어떻게 보정하는가 — 특허의 주종목

**[PT-02] OMRON US10334239 ◎**

> X축만 실제로 움직이고 Y축 이동은 상대 각도 α·상대 배율 β로 계산한 "가상 위치"로 대신해 **3점 대응**으로 카메라→스테이지 아핀 변환을 구한다. θ 스테이지는 소정 각도만 돌려 **회전 전후 두 점**으로 회전 중심을 구한다.

| | |
|---|---|
| **핵심 발상** | **한 축씩만 움직여 따로따로 보정한다.** 동시에 움직이지 않는다 |
| **우리에게** | **1014 자료가 정확히 이 구조다.** Y 단독 80장(T=0) + T 단독 200장(Y=0) |
| **실험으로 확인** | **A2에서 이 자료로 감도 J의 두 열을 따로 뽑았다.** 혼합 자료로는 불가능하다. **A3에서 1014를 빼면 통과율 0%** 가 된 이유 |
| **못 쓰는 것** | Y·T를 **한 장의 영상에서 동시에 구분하는 문제(P2)는 다루지 않는다.** 우리의 핵심 문제는 그대로 남는다 |

**[PT-04] Kawasaki US11749547 ○**

카메라가 아니라 1차원 광 센서지만 **절차의 구조가 같다.**

> 회전 위치 θ를 여러 값으로 바꿔 1차원 신호를 재고, **"같은 값이 나오는 두 위치의 가운데 = 대칭축"**과 **"최댓값 위치"**만으로 회전 중심 방향과 거리를 구한다.

| | |
|---|---|
| **쓸 수 있는 것** | **원 맞춤 같은 매개변수 추정 없이** 대칭과 극값만 쓴다. 모델이 틀려도 덜 흔들린다 |
| **우리에게** | T를 여러 값으로 돌려 재는 신호에서 **대칭점을 찾는 방식**을 A13의 최소제곱 적합과 **나란히 돌려 비교**할 수 있다 |
| **아직 안 함** | A13은 최소제곱만 썼다. 대칭법은 시도하지 않았다 |

### Q. 회전과 평행이동을 어떻게 가르는가 — "두 점" 계열

세 건이 **같은 말**을 한다. 그리고 그중 하나가 **SEMES 자체 특허**다.

**[PT-03] SEMES US12387316 ○** · **[PT-08] FANUC US10500731 △** · **[PT-06] ASM US7248931 △**

| 특허 | 분리 방식 |
|---|---|
| SEMES | 떨어진 **두 기준점**의 중심 좌표 → 이동값 (Δx, Δy), **두 중심을 잇는 선의 각도** → 회전 |
| FANUC | 두 마크의 **중점** → 위치, 두 마크의 **상대 배치** → 회전. "마크 2개면 1개보다 회전 방향 편차를 더 정확히 계산할 수 있다"고 명시 |
| ASM | 두 기준 마크에서 잰 거리 변화 ΔY1, ΔY2 → **평균 = 평행이동**, **차이/간격 = 회전** |

**공통 원리:** 떨어진 두 점의 **공통 이동 = 평행이동**, **차동 이동 ÷ 간격 = 회전**.

| | |
|---|---|
| **우리 구조와 같은가** | **그렇다.** QR 3개가 "떨어진 기준점"이고, 그 상대 이동이 회전 단서다 |
| **실측** | **A2: T 구조 성분 0.291 px/deg (잡음의 33배), Y 구조 성분 0.027 px/mm (잡음의 3배)** |
| **그런데** | 세 특허 모두 **간격이 충분히 클 때**를 전제한다. 우리 QR 3개의 간격은 700 px이고, 이는 영상 가로의 **18%**뿐이다 |
| **그래서** | **A2의 국소성 인자 γ = 0.18.** Adiv가 시험한 최악(1/4)보다 나쁘다. **뒷벽 가로선을 넣으면 0.77**로 올라간다 |

**→ "두 점 분리"라는 특허들의 원리는 맞다. 다만 우리는 그 두 점의 간격이 모자란다. 그래서 선이 필요하다.**

ASM 특허에는 **추가 지식**이 하나 더 있다.

> 측정을 로봇 절대 위치가 아니라 **같은 영상 속 고정 기준 대비 상대 거리**로 하므로, 측정 기준 자체의 흔들림이 상쇄된다.

**A1이 잰 세션 영점 변동(1014→1020 dy 0.44 px, 세션 내 변동의 81배)이 정확히 이 문제다.** 뒷벽 가로선이 우리의 "고정 기준"에 해당하지만, 우리는 그것을 영점 상쇄에 쓰고 있지 않다. **검토할 가치가 있다.**

### Q. 백래시·영점 변동은 어떻게 다루는가

**[PT-05] Tokyo Electron US12198955 ○**

| | |
|---|---|
| **핵심** | 열팽창(링크 길이)과 기어 백래시로 위치가 변한다. **가속/감속에 따라 백래시 오차 방향이 바뀐다** |
| **해법** | 같은 기판을 두 지점에서 실측해, 이상적으로 같아야 할 두 값의 차이로 **모델 오차를 걸러낸다** |
| **우리 실측** | **A1: 반복 3장 사이 판 이동 0.085 px (측정 잡음의 10배). A10: 1020의 네 묶음 모두 반복 2번에서 +0.33 px** |
| **못 하는 것** | **접근 방향 기록이 없어 확인 불가.** 백래시인지 드리프트인지 못 가린다 → **B1·B2** |
| **한계** | 특허도 백래시 방향 추정이 **정성적**이다(가속/감속 상태로 판정). 수식은 없다 |

논문 쪽 [PA-14] Nordin & Gutman 2002 와 짝이다. 논문은 **단방향 접근**을 권하고, 이 특허는 **두 번 재서 모델을 보정**한다. 둘 다 B2에서 시험할 수 있다.

## 4. 이 폴더에서 바로 할 수 있는 것 두 가지

### (1) PT-01의 "가상 회전 중심" 시험 — 자료가 이미 있을 수 있다

Cognex가 제시한 절차를 우리 2축에 옮기면

```
1. A13이 추정한 축 위치 c1 (등가 반경 315 mm)로
   "T를 Δ만큼 돌릴 때 QR 한 점이 제자리에 머물게 하는 Y 보상량"을 계산한다
2. 그 조합 (ΔT, 보상 ΔY)을 실제로 명령해 찍는다
3. 점이 정말 제자리에 머물면 c1이 맞다. 남은 이동이 c1의 오차다
```

**1020 자료에 Y와 T를 함께 준 19조건이 있다.** 그중 보상 관계에 가까운 조합이 있는지 먼저 찾아보면, 새 촬영 없이 축 위치 검증을 한 번 해볼 수 있다.

### (2) PT-06의 "고정 기준 대비 상대 측정"

지금 우리는 QR 변위를 **center.bmp 기준**으로 잰다. 그 기준 자체가 날짜마다 흔들린다(A1: dy 0.44 px).

ASM 방식은 **같은 영상 안의 고정 구조물**을 기준으로 삼는다. 우리에겐 **뒷벽 가로선**이 있다. 선은 판과 함께 움직이지 않으므로(A4: Y 감도 0.060 px/mm = 잡음의 2.3배) **영점 기준으로 쓸 수 있다.**

**A1의 캐시로 바로 확인할 수 있다.** 선을 기준으로 QR 변위를 다시 계산했을 때 날짜 간 영점 차이가 줄어드는지 보면 된다.

## 5. 이 폴더의 한계

| 한계 | 내용 |
|---|---|
| **수치가 거의 없다** | 8건 모두 구성과 순서만 있고 **정밀도·오차 수치가 없다.** 판정 기준으로 쓸 수 없다 |
| **회전축이 광축과 평행한 경우가 대부분** | PT-01·02·03·08은 카메라가 위에서 내려다보고 θ가 광축과 평행하다. 영상 안에서 **각도 자체가 회전량을 준다.** 우리는 카메라가 PAN 회전이라 정면 판의 화상 내 각도가 거의 안 변한다. **"각도로 회전 보정"을 그대로 못 쓴다** |
| **3축 이상 전제** | PT-01·02는 X·Y·θ 3축으로 가상 중심을 만든다. 우리는 2축이다 |
| **큰 회전 전제** | PT-07은 180°. 우리는 ±1.02° |
| **P2를 다루지 않는다** | 8건 중 어느 것도 "한 장의 영상에서 Y·T를 동시에 구분하는" 문제를 풀지 않는다. **그 몫은 전부 논문 쪽이다** |
