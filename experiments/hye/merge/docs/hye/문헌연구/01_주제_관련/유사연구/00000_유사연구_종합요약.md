## 1. 명세서가 정의한 문제

| 구분 | 명세서 내용 |
|---|---|
| 배경 | 로봇 스테이지의 **Y축 이동과 Θ축(PAN) 회전이 2D 비전 영상에서 같은 x축 방향으로 투영**되어 구분하기 어렵다. 그래서 현재는 **반자동**(사람이 Y를 수동 보정한 뒤 Θ만 자동 보정)으로 운영한다. |
| 목표 | QR 마커 3개(좌·중·우)가 붙은 판을 Y 위치·회전 각도별로 찍은 영상에서 **Y 이동과 회전을 구분**하고, 목표 센터링 영상에 도달하기 위한 **Y·Θ 보정값**을 계산한다. |
| 입력 / 출력 | 다양한 Y 위치·Θ 각도의 영상 / Y축·Θ축 보정값 |
| 조건 | 실시간 처리, C++ · OpenCV 3.4.15(변경 가능) · MIL10, Windows, 스테이지 제어 단위 0.05~2 mm |
| 산출물 | 평가 영상 세트, C++ 소스, 알고리즘 설명 자료, 중간·완료 보고서 |

이 요구는 다음 네 질문으로 나뉜다. 이후 조사 폴더가 이 순서를 따른다.

1. **원인**: 왜 Y와 Θ가 영상에서 구분되지 않는가 → `01_주제_관련/원인분석/`
2. **QR 분석**: 영상에서 QR 판의 움직임을 얼마나 정밀하고 안정적으로 잴 수 있는가 → `02_QR_분석/`
3. **Y·Θ 분리**: 잰 움직임에서 두 축을 어떻게 나누는가 → `03_Y_T_분리/`
4. **오차 보정**: 분리한 값에 남는 오차를 어떻게 줄이고 목표에 수렴시키는가 → `04_Y_T_오차_보정/`

## 3. 유사연구로 채워지지 않는 빈칸

| 빈칸 | 설명 | 다음 조사 |
|---|---|---|
| **Y와 Θ가 섞이는 이유의 정량 설명** | 특허는 "2축은 되고 깊이는 어렵다"까지만 말한다. 같은 가로 방향으로 움직이는 평행이동과 회전이 왜, 얼마나 구별되지 않는지는 다루지 않는다. | 원인분석 |
| **QR을 측정 도구로 쓸 때의 정밀도** | 마커 연구(13~15)는 자세 추정·코너 정확도를 다루지만, 3개 QR로 판 전체의 미세 변형을 재는 경우는 없다. QR 반복 무늬, 조명·초점 변화 문제도 별도로 봐야 한다. | QR 분석 |
| **로봇 장착 카메라 + 마커로 Θ를 분리하는 방법** | 회전 보정 특허는 모두 고정 카메라이고, 계산식은 비공개다. 01번은 마커 없이 형상으로 푼다. | Y·Θ 분리 |
| **반복 보정의 수렴과 오차 예산** | 특허·논문 모두 최종 정확도만 제시하고, 영점 변동·백래시·제어 단위(0.05 mm)를 포함한 오차 예산과 반복 보정 수렴은 다루지 않는다. | 오차 보정 |

## 4. 본 과제에 주는 시사점

1. **과제의 필요성은 근거가 충분하다.** SEMES 자체 특허가 QR 마커 방식의 한계를 종래기술로 적고 있고, 명세서가 말하는 반자동 운영과 같은 문제를 가리킨다.
2. **목표 정확도는 Y 0.1~0.2 mm, Θ 0.2~0.5° 수준이 문헌 기준이다.** 팀 허용오차(0.09)가 이보다 엄격한지 단위를 맞춰 비교해야 한다(오차 보정 조사에서 다룸).
3. **차별점은 "로봇 장착 카메라 + QR 3개 + Θ 분리"이다.** 이 조합을 직접 다룬 특허·논문은 확인되지 않았다. 다만 특허 DB 전수 검색 전이므로 단정하지 않는다.
4. **방법의 실마리는 이미 문헌에 흩어져 있다.** 깊이가 다른 특징(01번의 챔버 입구, 특허의 거리 센서)이 회전과 평행이동을 가르는 열쇠이고, 반복 촬영·보정 구조(특허 2단계 측정)가 단일 추정의 한계를 보완한다.
