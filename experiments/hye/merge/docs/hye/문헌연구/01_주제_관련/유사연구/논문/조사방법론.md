# 관련 논문 조사 방법론 (계획)

- 작성일: 2026-10-30
- 대상 과제: 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
- 결과 문서: `00000_주제_논문_조사_방법론_및_결과_.md` (이 계획대로 조사를 마친 뒤 작성)
- 짝 문서: `../특허/00000_주제_특허_조사_방법론_및_결과_.md`

## 1. 목적

1. 우리 과제(로봇에 단 카메라로 마커를 찍어 Y·Θ 보정값을 구함)와 같은 방식을 다룬 학술 연구를 찾는다.
2. 특허에는 없는 **정량 근거**를 모은다: 달성 정확도(mm, °), 카메라·마커 조건, 실험 방법.
3. 우리 알고리즘의 각 단계(마커 검출, 자세 추정, 부화소 정합, 카메라-로봇 보정)의 이론적 근거를 확보한다.

특허 조사는 웹 검색에 걸린 후보만 봤다(특허 문서 "한계" 참고). 논문 조사는 **학술 DB를 정해진 검색어로 검색하고 건수를 기록**해서 재현할 수 있게 한다.

## 2. 검색어

세 블록을 조합한다. 블록 안은 OR, 블록 사이는 AND.

| 블록 | 영문 | 국문 |
|---|---|---|
| A. 대상 | wafer transfer robot, wafer handling robot, substrate transfer robot, semiconductor transfer robot, EFEM, vacuum robot | 웨이퍼 이송 로봇, 반송 로봇, 기판 이송 |
| B. 문제 | auto-teaching, automatic teaching, teaching position, calibration, alignment, position correction, offset | 자동 티칭, 티칭, 위치 보정, 정렬, 캘리브레이션 |
| C. 수단 | vision, camera, image, eye-in-hand, fiducial, marker, ArUco, AprilTag, QR code | 비전, 카메라, 영상, 마커 |

- **핵심 검색 (A∧B∧C, A∧B):** 우리 과제와 직접 겹치는 논문.
- **인접 검색 (B∧C, A 제외):** 반도체 분야 논문이 적을 것이므로 방법 근거는 여기서 찾는다.
  - fiducial marker pose estimation accuracy (ArUco, AprilTag 비교)
  - hand-eye calibration (eye-in-hand)
  - image-based visual servoing for alignment / positioning
  - sub-pixel template matching, planar marker in-plane rotation estimation

## 4. 선정 기준

1차(제목·초록)로 거르고 2차(본문)로 관련도를 정한다.

- 포함: ① 카메라·비전 사용 ② 로봇의 위치·자세 보정 또는 티칭 ③ 마커나 기준 표식 인식 ④ 정확도 수치나 실험 조건이 있음
- 관련도
  - ◎ 반도체 이송 로봇 + 비전 티칭/보정 (①②, 가능하면 ③)
  - ○ 다른 분야지만 같은 방식 (로봇 장착 카메라 + 마커로 위치·회전 보정), 또는 반도체 이송 로봇 + 비전 아닌 센서
  - △ 방법 근거용 (마커 정확도, hand-eye 보정, 부화소 정합 등)
- 제외: 웨이퍼 결함 검사, 로봇 경로 계획·스케줄링만 다룬 것, 학습 기반 파지(grasping) 등 위치 보정이 아닌 것
- 목표 분량: ◎·○ 5~10편, △ 3~5편. 너무 많으면 인용 수와 최신성으로 줄인다.

## 5. 확인 항목

제목, 저자, 연도, 게재처(저널·학회), DOI, 공개 여부(OA), 카메라 위치, 인식 대상(마커), 보정 축, **정확도 수치**, 실험 환경(실제 장비/테스트베드/시뮬레이션), 종래 방식의 문제점.

```
   ├─ 요약.md
   ├─ 번역.md             (◎만, 원문 PDF가 있을 때)
   └─ 그림/               (번역.md에 넣는 그림)
```

- 번호는 관련도 순(◎ → ○ → △).
- 원문 PDF는 무료 공개(OA)본만 Claude가 받는다. 유료 논문은 결과 문서의 "원문 받을 목록"에 DOI를 적고 사용자가 학교·SSAFY 계정으로 받는다.
- 번역 범위: ◎ 논문은 본문 전체, ○·△는 요약.md만.
- 원문을 직접 읽지 못하고 초록만 본 내용은 `*`로 표시한다.
