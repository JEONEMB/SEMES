## 문헌군 비교와 해석

### 추정 성적·실제 위치·반복 제어 성적을 분리한다

GUM·Wang·Kyrki는 오차원을 전파·합성하는 틀이고, Le Reun·Yao·van Hulst는 열·기계 이력을 보정하는 계열이다. Chaumette·Hutchinson·Cho는 피드백 구조, Varma·Cawley는 선택 편향, Kuric·NIST는 측정 반복과 변동 성분을 다룬다. 제어가 수렴했다는 사실만으로 외부 기준 정확도나 세션 간 안정성이 증명되지는 않는다.

### v2에서 수식 해석을 바로잡는다

국소 상태 오차를 q, 영상 감도를 J, 특징→축 추정기를 W, 이득을 G라고 두면 단순 이산 근사에서 q 다음값은 (I−GWJ)q다. 안정 조건은 스펙트럴 반경 ρ(I−GWJ)<1이다. ‘GWJ 고유값이 0~2’는 고유값이 실수인 추가 조건에서만 같은 설명이 된다. 지연·백래시·포화·상태 전환까지 이 식으로 보장할 수 없고, 이득 0.8~0.9가 항상 단방향 접근을 만든다는 주장도 철회한다.

### 불확도와 양산 기준의 범위

GUM 합성에는 감도와 상관을 포함한다. k=2를 언제나 정확한 95% 확률로 쓰지 않는다. 제어 명령 단위가 0.05라는 사실만으로 실제 위치 오차가 균등분포라고 확정하지 않는다. NIST는 반복성·재현성·안정성의 분해 근거이고, %GRR·ndc의 수용 기준을 이 웹 페이지의 규정으로 적지 않는다. ISO 9283 적용 사례와 표준 자체의 적합성 선언도 구분한다.

### 검증 순서

고정 자세 반복→방향/날짜 교차 반복→독립 기준 비교→실제 복귀 반복 순서로 오차원을 식별한다. 모델·점 집합·임계값을 고른 자료는 개발 성적으로 남기고 새 세션에서 최종 평가한다. 히스테리시스·ILC는 반복되는 원인이 확인될 때 검토하며 무작위 오차의 만능 보정으로 사용하지 않는다.
