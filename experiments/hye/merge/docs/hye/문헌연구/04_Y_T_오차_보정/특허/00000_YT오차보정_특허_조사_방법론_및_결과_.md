# Y·Θ 오차 보정 특허 조사 결과 — 남는 오차의 원인 관리와 반복 보정 수렴·검증

**과제:** 비전 기반 2축(Y·Θ) 로봇 얼라인먼트 자동 보정 (SEMES 기업연계)
**조사일:** 2026-10-30 · **계획 문서:** `조사방법론.md` · **대상 문제:** 논문 결과서 `../논문/00000_YT오차보정_조사_방법론_및_결과_.md`의 P1~P6
**조사 대상:** 미국 등록 특허 7건 (◎ 3건, ○ 1건은 원문·국문 전문 번역·도면 확보, △ 3건은 원문·요약)
**표기:** Θ축은 팀 보고서와 같이 T로 쓴다.

## 핵심 요약

1. **반복 보정 루프의 종료 조건과 "수렴 뒤 검증"을 장비 특허가 구체적으로 적고 있다.** TEL US11984340은 "놓기 → 독립 센서로 재기 → 허용 범위 밖이면 다음 동작 보정"을 허용 범위 안이 될 때까지 반복하고, 확정 뒤 같은 측정을 10~100회 더 해 **편차 분산으로 확정값을 허용 범위 중심에 다시 맞춘다**(P4·P5). Omron US9424646은 비전 XYθ 정렬에서 오차 허용값 판정, 측정 실패 시 보정 생략 규칙을 둔다(P4).
2. **백래시(로스트 모션)는 "방향을 일부러 뒤집어" 재고, "지나치지 않게" 접근해 피한다.** Kawasaki US10403539는 관절을 직전과 반대 방향으로 지령값만큼 돌린 뒤 외부 측정(프리얼라이너)과 지령값의 차이로 로스트 모션을 구한다(청구항 5: 반대 방향이 최대 편차를 준다). Omron은 목표 앞 마진 거리에서 감속해 **목표를 지나쳐 반전하는 일(백래시 유발)을 막는다**(P3).
3. **오차는 성분별로 나눠 따로 추정하고, 측정값에 섞인 장치 변위를 빼야 한다.** TEL US12211719는 열변위를 링크 열팽창 + 백래시 크기 + **가감속 상태로 정해지는 백래시 방향**으로 나누고, 측정 순간의 변위와 목표 위치의 변위를 따로 계산한다(P1·P3). 같은 계열 US12198955는 두 번 잰 값의 차이로 모델 오차를 온라인으로 고친다.
4. **"마진 = 시스템 오차의 최댓값"을 실험으로 정하는 절차가 본 과제 검증 실험 설계로 바로 쓰인다.** Omron은 무작위 또는 X·Y·θ 격자 위치에서 목표로 명령 복귀 → 영상으로 측정 → 목표와의 거리 최댓값을 마진으로 정한다(청구항 3·11). 명령값이 아닌 측정 결과로 성능을 보고하는 방법이다(P2·P5).
5. **허용오차의 근거·단위(P6)를 직접 다루는 특허는 없었다.** 요구 정확도 R에서 동작 조건(Vns_max ≤ 2R/3f)을 역산하는 Omron의 방식, TEL US11984340의 "수십 µm 편차도 무시할 수 없다"는 서술 정도가 근거다.

### 2.3 한계

- **Google Patents 접근 차단**: 첫 xhr 질의 몇 건 뒤부터 Google Patents 전체(특허 페이지·xhr)가 HTTP 503을 냈고, 30분 동안 1분 간격으로 확인해도 풀리지 않았다(같은 시간 다른 주제 조사가 동시에 접근한 영향으로 추정). 그래서 ① 검색 기록 후반은 웹 검색으로만 했고 ② 번역 원본 텍스트는 Google Patents HTML이 아니라 **USPTO 등록본 PDF를 Windows 내장 문자 인식(OCR)으로 읽은 뒤 쪽 이미지와 대조**해 만들었다. 수식·기호는 쪽 이미지를 직접 보고 옮겼다. 문자 인식이 줄머리 단어를 빠뜨린 곳은 쪽 이미지로 확인했지만, 전 문장을 이미지와 한 줄씩 대조하지는 않았다.
- Justia·FreePatentsOnline은 자동 접근이 막혀(403) 쓰지 못했다. KIPRIS는 시도하지 않았다. 일본·한국 대응 특허 원문은 받지 않았다.
- 표에 적은 Google Patents 링크는 번호 형식으로 만든 것이며, 이번 조사 중에는 열어 보지 못했다(서지는 USPTO PDF 표지에서 확인).
- xhr 전문 검색은 잡음이 커서(수술 로봇, 레이저 가공 등) 상위 20~25건만 봤다. 걸린 건수는 그 질의의 총 결과 수이다.
- △ 3건(05~07)은 표지·도면·초록만 보고 요약했다. 05번은 문자 인식 본문을 읽었으나 번역하지 않았다.

### 시사점

- **카메라로 마크를 찍어 반복 정렬하는 특허(03)와, 결과를 독립 센서로 재는 이송 로봇 특허(01·02·04)가 같은 원리를 쓴다**: 명령값을 정답으로 쓰지 않고, 실제로 간 위치를 따로 재서 차이를 오차로 본다. 본 과제의 P2(정답이 명령값)를 해결하는 공통 패턴이다.
- **백래시 대응은 두 갈래다**: 재서 보정(02·04: 방향별 크기 측정·모델) 또는 피해서 접근(03: 지나치지 않는 마진). 논문 결과서 4.3절의 "방향별 보상"과 "단방향 접근" 두 대안에 각각 특허 근거가 생겼다.
- **반복 루프의 "종료 판정"은 모든 특허가 허용값 비교 하나로 한다**. 이득·수렴 속도를 청구한 특허는 없었다 → 본 과제의 이득 설계(논문 결과서 4.4절 본 조사 유도)는 특허로 막혀 있지 않고, 근거도 특허가 아닌 논문·시뮬레이션에서 와야 한다.

## 4. 문제(P#)별 특허 근거와 본 과제에서 할 일

논문 결과서 4장(4.1~4.6)의 "본 과제에서 할 일"과 짝을 맞췄다. 특허가 더해 주는 것만 적는다.

### 4.1 P1 — 오차 예산 부재 (논문 결과서 4.1절)

- **특허가 주는 해결 구성**
  - 04번: 위치 오차 = 링크 열팽창(온도 × 계수 × 길이) + 기어 백래시 증가분(온도, 재질 차, 축간 거리) × **방향(가속/감속 상태)** + 자세. 측정 순간과 목표 순간을 따로 계산.
  - 03번: 오차 원인을 (a) 측정마다 바뀌는 카메라 노이즈와 (b) 위치에 따라 정해지고 측정마다 안 바뀌는 스테이지·광학계 특성으로 나누고, (a)는 센서 통계로, (b)는 실험으로 잰다.
  - 05번: 같은 양을 두 경로로 재서 차이를 모델 오차 크기로 쓴다.
- **본 과제에서 할 일**

| 할 일 | 방법 | 성공 기준 |
|---|---|---|
| 예산 항목을 "측정마다 변함 / 위치마다 고정 / 방향에 따라 변함"으로 재분류 | 논문 결과서 4.1 표의 각 항에 03번 (a)/(b) 구분과 04번 방향 성분 열을 추가 | 영점 변동이 "방향 성분"으로, 점 잡음이 "측정마다 변함"으로, 판 이동 직선성이 "위치마다 고정"으로 분리 기재 |
| 위치별 계통 오차 지도 | 03번 결정 방법 그 2: Y 격자(예: 0.25 mm 간격) × T 격자 각 점에서 목표(0, 0)로 명령 복귀 → 촬영 → 남은 Y·T | 위치별 평균(계통)과 산포(측정마다)를 따로 표로 보고 |

### 4.2 P2 — 정답이 명령값 (논문 결과서 4.2절)

- **특허가 주는 해결 구성**
  - 02번: 지령값으로 계산한 이상 위치 (P1)과 외부 측정 위치 P1의 차가 곧 기구 오차. 외부 측정기는 이미 장비에 있는 프리얼라이너.
  - 01번: 동작 결과(놓인 웨이퍼)를 별도 센서(검사 웨이퍼 카메라)로 다시 재서 정답으로 쓴다. 시야에 눈금을 두면 높이도 보정.
  - 03번: 캘리브레이션·목표 위치를 **전용 지그와 치수가 정확한 마스터 워크**로 잡는다.
- **본 과제에서 할 일**

| 할 일 | 방법 | 성공 기준 |
|---|---|---|
| 외부 기준 확보 시 02번 방식 적용 | 다이얼 게이지 등 외부 기준 + 영상을 동시에 기록하고 "명령 이동량 vs 외부 측정 이동량"으로 스테이지 오차 분리 | 논문 결과서 4.2절 명령값-실위치 지도 완성 |
| 외부 기준이 없을 때의 대안 | 판에 눈금(등간격 점)을 함께 두고 영상 안에서 mm 기준을 직접 재는 01번 방식, 또는 SEMES에 지그·마스터 판 요청(03번) | 감도계수 14.25 px/mm를 판 위 눈금으로 독립 확인(차이 < 2 %) |

### 4.3 P3 — 영점 변동(백래시·히스테리시스) (논문 결과서 4.3절)

- **특허가 주는 해결 구성**
  - 02번 청구항 1·5: **직전과 반대 방향으로 돌린 뒤** 지령 이동 → 재측정. 반대 방향이 백래시 최대 편차를 준다.
  - 04번: 백래시 오차 방향은 마지막에 기어가 밀던 쪽(가속/감속)으로 정해진다 → 상태로 추정 가능.
  - 03번: 목표를 지나치면 반전이 필요하고 반전 때 백래시가 생긴다 → **마진을 두고 한쪽에서만 접근**.
  - 01번: 측정 도구를 실어 나를 때와 제품을 실어 나를 때 백래시·히스테리시스 때문에 정지 위치가 다르다 → 제품과 같은 조건으로 측정.
  - 02번 실시예 3: 위치(수용부)마다 로스트 모션이 다르다.
- **본 과제에서 할 일**

| 할 일 | 방법 | 성공 기준 |
|---|---|---|
| 축별 역전값 측정 (02번 절차) | Y·T 각각: 반대 방향으로 움직여 놓고 촬영 → 지령 방향으로 Δ 이동 → 촬영. (지령 Δ × 감도) − (영상 이동량) = 로스트 모션. 여러 위치에서 반복 | 역전값 B(px)가 세션 간 영점 차 약 0.6 px와 맞는지, 위치마다 다른지 확인 |
| 마지막 이동 방향을 상태로 기록 (04번) | 로그에 축별 마지막 이동 부호를 남기고 영점을 방향별로 둠 | 영점 후보 6개 → 방향별 2개로 줄여도 1014 통과 수 유지(논문 결과서 4.3절 기준과 같음) |
| 단방향 접근 (03번) | 보정 명령이 직전과 반대면 마진만큼 더 가서 되돌아오거나, 이득 < 1로 한쪽에서 접근 | 단방향 반복성이 양방향보다 작아지는지 확인 |

### 4.4 P4 — 반복 보정의 수렴성 (논문 결과서 4.4절)

- **특허가 주는 해결 구성**
  - 01번 청구항 2: 편차가 허용 범위 안이 될 때까지 (놓기 → 재기 → 다음 보정) 반복. 확정 뒤 갱신 단계(청구항 3·4)를 따로 둔다.
  - 03번 도 10: 오차 ≤ 허용값이면 종료(S26), **측정 결과를 쓸 수 없으면 보정을 건너뛰고 기존 명령 유지**(S28). 불가 판정 기준 = 미검출, 직전 대비 비정상 점프·인코더 추정과의 차이 임계값 초과, 처리 시간 초과.
  - 03번: 요구 정확도 R과 제어 주기에서 속도 상한을 역산(Vns_max ≤ 2R/3f), 마진은 "오차 최댓값 + 지연·감속 이동량".
  - 05번: 매 이송의 중복 측정으로 보정 모델을 온라인 갱신.
- **본 과제에서 할 일**

| 할 일 | 방법 | 성공 기준 |
|---|---|---|
| 턴별 "측정 사용 가능" 판정 추가 (03번 S28) | ① 마커 검출 실패 ② 직전 턴 대비 추정 변화가 (명령 이동 + 3σ)를 넘음 ③ 처리 시간 초과 → 그 턴은 보정 명령 0, 재촬영 | 실기 폐루프 시험에서 이상 추정으로 인한 큰 역보정 0회 |
| 전환 순환 방지 | joint ↔ control 판단이 2회 이상 왕복하면 직전 확정값 유지(03번 "기존 모션 유지"와 같은 원리) | 논문 결과서 4.4절 기준(왕복 2회 이하) |
| 마진·이득 설계 | 03번처럼 "격자 복귀 실험의 오차 최댓값"을 마진으로 두고, 그 안에서만 이득 1, 밖에서는 이득 < 1(지나치지 않게) | 몬테카를로·실기에서 20턴 내 도달률 ≥ 99 %, 반전 횟수 최소 |
| 매 턴 감도 갱신(선택) | 05번처럼 "명령 이동 vs 추정 이동" 차이를 누적해 W 감도 보정(Broyden과 같은 방향) | 평균 도달 턴 감소 |

### 4.5 P5 — 검증 설계의 낙관 편향 (논문 결과서 4.5절)

- **특허가 주는 해결 구성**
  - 01번 청구항 3·4: 확정 뒤 **같은 조건 측정을 10~100회 반복해 분산을 구하고 확정값을 갱신** — 동일 자세 반복 측정이 장비 절차로 들어가 있다.
  - 03번 결정 방법 그 1·2: 무작위 또는 격자 출발점에서 목표로 명령 → 측정 오차의 **최댓값**이 더 이상 갱신되지 않을 때까지 반복(그 1)하거나 전 격자 최댓값(그 2) — 평균이 아닌 최악값으로 성능을 정한다.
  - 07번: 지그로 모은 데이터로 "보정 필요 여부"를 판정하는 주기 점검.
- **본 과제에서 할 일**

| 할 일 | 방법 | 성공 기준 |
|---|---|---|
| 최종 성능을 "새 촬영 + 실제 이동"으로만 보고 | 03번 그 2를 Y·T 격자에 적용: 격자 각 점에서 시작해 루프를 끝까지 돌리고, 최종 자세를 외부 기준(또는 별도 재촬영)으로 측정 | 평균과 함께 최댓값·95 % 값 보고, 개발 성적(280/280)과 분리 |
| 수렴 후 반복 측정 (01번) | 최종 자세에서 이동 없이 10회 이상 재촬영 → 산포 | 논문 결과서 4.5절 Gage R&R 설계의 반복성 s₁ 산출 |

### 4.6 P6 — 허용오차 근거·단위 (논문 결과서 4.6절)

- 2.3절과 같다. 특히 번역 원본이 Google Patents 텍스트가 아니라 USPTO PDF 문자 인식이므로, 단어 단위 누락이 남아 있을 수 있다. 청구항 수는 4건 모두 등록본 표지와 일치한다(12, 8, 13, 4).

- SEMES 특허 중 이 주제(백래시·반복 보정 수렴·검증)에 해당하는 것은 이번 검색에서 나오지 않았다. KIPRIS 출원인 검색을 하지 않아 없다고 단정할 수 없다.

## 7. 추가로 할 일

- Google Patents가 풀리면 ① 01~04번의 원문 텍스트로 번역을 한 번 대조하고 ② 2.2절에서 표지만 본 후보(US11413767, US9330951, US11759954, US20250232997)를 열어 관련도를 다시 판정한다.
- KIPRIS: 출원인 "세메스" × (백래시 ∨ 반복 정렬 ∨ 티칭 보정 ∨ 열변형) 검색.
- Omron 03번의 일본 원출원(JP 2013-080774 기반 공개본)과 후속 Omron 정렬 특허(US11999068B2 Control device and alignment device, US11922616B2 Alignment device)를 확인해 "마진 접근" 계열의 후속 개량을 본다.
- 4.3절 "축별 역전값 측정"과 4.5절 "격자 복귀 실험"을 실기 실험 계획서(논문 결과서 4장 할 일과 합쳐)로 묶는다.
