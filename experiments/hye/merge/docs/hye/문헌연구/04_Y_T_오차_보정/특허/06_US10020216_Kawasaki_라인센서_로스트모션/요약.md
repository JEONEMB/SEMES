## 상세 요약 (등록본 표지·도면 기준, 번역본 없음)

### 1. 해결하려는 문제
- 02번과 같다: 오프셋 위치를 여러 번 오가며 보정 테이블을 만드는 종래 절차는 번거롭다.

### 2. 핵심 구성
| 구성 | 부호 | 역할 |
|---|---|---|
| 로봇 | 10 | 3관절 수평 다관절, 엔드 이펙터 30(피검출부 80) |
| 라인 센서 | 60 (투광부·수광부 62·64) | 수광 상태로 피검출부 위치 검출 |

### 3. 동작 순서 (초록 기준)
1. 로봇과 라인 센서 준비 → 2~3. 피검출부를 센서에 넣어 위치 검출 → 4. 지령값으로 제1 관절 회전 → 5. 다시 검출 → 6. 처음 위치 + 지령값과 재검출 위치의 차로 로스트 모션 편차량.

### 4. 본 과제와 비교
- 02번과 원리가 같고, 웨이퍼 없이 엔드 이펙터 자체를 재는 점만 다르다. 본 과제에 적용하면 "판의 특정 마커 한 점의 영상 위치"를 피검출부로 쓰는 것과 같다. 02번을 우선 참조한다.
