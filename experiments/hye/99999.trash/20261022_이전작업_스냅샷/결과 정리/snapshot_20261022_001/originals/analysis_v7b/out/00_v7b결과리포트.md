# v7b 결과 리포트: center + 현재 사진 2장으로 Y/Θ 판정과 값 (QR 3개만)

이 폴더(`analysis_v7b/`)는 다른 세션의 `analysis_v7/`과 별개로 진행한 작업이에요. 계획: [00_v7_계획.md](../../../../../../20261014_v7b_센터와현재2장_YΘ판정/실험%20방법/out/00_v7_계획.md). 평가 기준: [../../00_평가기준.md](../../../../../실험%20방법/snapshot_20261022_001/originals/00_평가기준.md).

## 한 줄 결론
**축 판정과 값 계산을 나눈 2단계 방법으로 280장 중 2장만 틀려요 (Y+0.05, Θ+0.01, 둘 다 가장 작은 한 스텝). 값은 축을 맞힌 사진 전부 한 스텝 안. 틀린 2장도 "보정 후 남는 오차"로 보면 합격선 안이라 피해 없음 100%.**

## 최종 방법 (2단계)
1. 특징점: center 사진의 QR 3개 위 모서리 232개 (17x17 템플릿).
2. 점 위치: 큰 템플릿(81x81)으로 대략 → 17x17 + 가우스-뉴턴으로 소수점 (center ↔ 현재 점-점 짝).
3. 판 변형 요약: 점 232개 이동을 판 전체 2차 다항 변형 12개 값으로 (점 전부, 같은 가중).
4. **축 판정**: 0 근처 사진(Y ≤ 0.6mm, Θ ≤ 0.12)만으로 학습한 직선 모델, 0점 = center. "Y만" / "Θ만" 가설을 전체 공분산 거리로 비교.
5. **값 계산**: 전체 사진으로 학습한 2차 모델로, 판정된 축의 값을 풂.

- "실제 위치" 정답은 영상(QR 평균 이동)으로 만든 0점 보정값이라 일부 순환이 있어요.
- 2단계 설정은 9가지 설정 중 같은 데이터로 골랐어요 (`62_v7_0근처편향.csv`). 약간 낙관적일 수 있어요.

## 왜 예전엔 Y가, 그다음엔 Θ가 틀렸나 (`59_v7_틀리는방향.png`, `62_v7_0근처편향.csv`)
- Θ 이동은 휘어 있어요: 2차 항이 Θ=1에서 잡음의 13.2배 (Y는 0.6배로 거의 직선).
- **직선 모델**로 맞추면 휨이 절편에 섞여 Θ 모델의 0점이 잡음의 4.4배 어긋나요 → 0 근처에서 Y 가설이 이김 → **Θ 사진이 틀림** (v7 첫 결과 0 / 3).
- **2차 모델**(v5, v6 표)은 Θ의 휨을 잡아서 0 근처에서 Θ 가설이 이김 → **Y 사진이 틀림** (v6 QR만 8~12 / 3~5).
- 0 근처에서는 Y 사진과 Θ 사진의 비용 비가 한 덩어리라, 덩어리가 문턱 어느 쪽에 걸치느냐로 한쪽 축이 몽땅 틀려요. 덩어리 위치를 정하는 게 모델의 0점 편향이에요.
- 해결: 축 판정 모델은 0 근처 사진만으로, 0점 = center로 학습 → 덩어리가 Y 사진은 Y 쪽(-0.14), Θ 사진은 Θ 쪽(+0.20)으로 갈라짐.

## 0점 맞추기 (`65_v7_0점맞추기.csv`, `zero_cal.py`)

구간(접근 방향, 시간)마다 "0에 있을 때의 판 모양"이 center와 달라요 (잡음 대비 4.5~34σ, Θ+ 구간이 가장 큼).

| 방법 | 런타임에 하는 일 | 틀림 Y / Θ | Y 값 오차 평균 / 최대 (명령값 기준) | Θ 값 오차 평균 / 최대 | 한 스텝 합격 |
|---|---|---|---|---|---|
| Z0 지금 | center 1장 = 0점 | 2 / 1 | 13.3 / 32µm | 0.0024 / 0.0074 | 98.9% |
| Z1 상한 | 같은 조건(접근 방향, 시각) 0점을 정확히 앎 | 4 / 1 | **1.5 / 8.9µm** | **0.0004 / 0.0022** | 98.2% |
| Z2 | 같은 조건 0점 사진 1장 | 3.1 / 1.4 | 1.8 / 8.5µm | 0.0004 / 0.0027 | 98.4% |
| Z2 | 같은 조건 0점 사진 4장 | 3.1 / 1.3 | 1.6 / 8.8µm | 0.0004 / 0.0026 | 98.4% |
| Z2 | 같은 조건 0점 사진 16장 | 3.4 / 1.2 | 1.5 / 8.8µm | 0.0004 / 0.0025 | 98.4% |

- **값에는 효과가 커요**: 명령값 기준 Y 오차 13µm → 1.5µm, Θ 0.0024 → 0.0004 (백래시, 드리프트가 빠짐). 0점 사진 1장이면 충분.
- **축 판정에는 효과가 없어요**: 2~5장 사이에서 오르내림 (평가의 흔들림 범위). 구간 0점 모양을 Y/Θ 구분 방향으로 재면 모두 1σ 미만 (-0.95 ~ +0.34)이라, 0점 차이가 축 판정을 좌우하지 않아요.
- Z1, Z2는 구간마다 0점을 알아야 해서 짝/홀 검증만 했어요.

### 0점 맞추기 + 여러 장 (`66_v7_0점맞추기_여러장.csv/png`, `zero_ms.py`)
280장 기준 기대 틀림 수 (전체 / 한 스텝 사진 제외). 시뮬레이션은 1장일 때 실측(2~5장)보다 약간 비관적이에요.

| 0점 사진 | 측정 N장 | A 낙관 | B 현실 |
|---|---|---|---|
| 1장 | 64 | 4.3 / 2.8 | 5.5 / 3.9 |
| 4장 | 16 | 2.0 / 0.9 | 4.1 / 2.6 |
| 16장 | 16 | 0.9 / 0.16 | 3.1 / 1.7 |
| 16장 | 64 | 0.6 / 0.08 | 2.7 / 1.3 |
| 정확히 앎 | 16 | 0.7 / 0.09 | 2.2 / 1.0 |
| 정확히 앎 | 64 | **0.06 / 0.00** | 1.7 / 0.6 |

- 0점 사진의 잡음도 판정에 그대로 들어가요 (center와 현재의 차이를 보니까). **0점 사진을 측정 사진만큼 찍어야** 여러 장 효과가 남아요. 0점 1장이면 측정을 64장 찍어도 4장 넘게 틀려요.
- 0점을 맞추면 여러 장 평균에서 한 스텝 사진(Y 0.05, Θ 0.01)의 치우침도 사라져요 (0점 안 맞춘 시뮬레이션은 64장에서도 10% 넘게 틀림 → 정확한 0점이면 3%).
- 가정 A면 "0점 16장 이상 + 측정 16~64장"에서 100%에 가까워요. 가정 B면 64장에서도 0.6~1.7장 틀려서 100%는 안 돼요. 어느 쪽인지는 같은 자세 반복 촬영으로만 확인돼요.

## 여러 장 촬영 시뮬레이션 (`64_v7_여러장_시뮬레이션.csv/png`, `multishot.py`)

같은 자세 반복 촬영 데이터가 없어서 "증강"은 잡음 구조를 재서 가짜 판 변형 값을 만드는 방식으로 했어요 (실측 아님).
- 잡음 나누기: 구분 방향 잡음 중 81%가 점마다 독립 흔들림 (찍을 때마다 바뀜), 19%는 그대로인 부분 (스테이지 실제 위치, 구간마다 다른 0점 모양, 모델 오차).
- 가정 A (낙관): 잡음 전부가 N장 평균으로 줄어듦. 가정 B (현실): 81%만 줄어듦.
- 판정기는 2단계 방법, 정답 생성기는 전체 사진 2차 모델. 1장일 때 기대 틀림 5.3장 (실측 2장) → 시뮬레이션이 실제보다 비관적.

| N장 | A: 기대 틀림 (한 스텝 제외) | A: 최악 | B: 기대 틀림 (한 스텝 제외) | B: 최악 |
|---|---|---|---|---|
| 1 | 3.8장 | 42% (Y 0.10) | 3.7장 | 40% |
| 4 | 1.1 | 34% | 2.3 | 45% |
| 16 | 0.19 | 13% | 1.6 | 52% |
| 32 | 0.05 | 5% | 1.4 | 53% |
| 64 | 0.02 | 2% | 1.2 | 46% |

- 한 스텝(Y 0.05, Θ 0.01) 사진은 A에서도 64장까지 10~37% 틀림.
- **B에서는 장 수를 늘려도 0이 되지 않고, Y 0.05, 0.10은 오히려 더 틀려요.** 잡음이 줄면 안 줄어드는 치우침(구간마다 다른 0점 모양)이 판정을 더 확실하게 한쪽으로 밀기 때문이에요.
- 결론: 여러 장 평균은 잡음 부분만 줄여요. 100%를 막는 남은 원인은 0점 모양의 치우침이라, 여러 장보다 **0점을 현장에서 맞추는 것** (예: center를 같은 접근 방향으로 찍기, 보정 사진)이 먼저예요. 가정 A가 맞다면 한 스텝 제외 기준 약 32장이면 기대 틀림 0.05장.
- 이 결론은 반복 촬영 실측으로 확인해야 해요 (SEMES에 같은 자세 반복 촬영 요청).
