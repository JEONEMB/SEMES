# v8 결과 리포트: 특징점 잡음의 원인 (정답 라벨 + 강체 검사)

## 한 줄 결론

**특징점 위치 잡음(0.015~0.022px)의 주원인은 "판의 무늬 있는 곳이 찍을 때마다 픽셀 단위로 미세하게 바뀌는 것"이에요 (한 장 기준 밝기 4~12, 매끈한 벽은 0.66).** 이걸 합성 사진(정답을 정확히 앎)에 넣으면 실제 잡음의 세로 100%, 가로 약 2/3가 재현돼요. 흐림 차이, 조명, 픽셀 위상(앨리어싱), 롤링 셔터, 압축, 색 보간은 원인이 아니에요.

## 1. 강체 검사 (라벨 없이 실제 사진의 점 잡음 재기)

판은 휘지 않으니 판 위 점은 사진마다 하나의 원근 변환을 따라야 해요. 맞추고 남은 양이 점 오차예요.

| 측정 | 강체 검사 (x / y) | 이전 방법: 구간 안 흔들림 (x / y) |
|---|---|---|
| 17px σ1 | 0.022 / 0.014px | 0.022 / 0.014px |
| 33px σ2 | 0.015 / 0.009px | 0.016 / 0.010px |

독립된 두 방법이 같은 값이라 이 잡음 크기는 믿을 수 있어요. 코드: `analysis_v8/r1_rigid.py`

## 2. 합성 사다리 (정답 라벨이 있는 시험)

center 사진을 푸리에로 정확히 옮긴 합성 사진 40장에 원인을 하나씩 넣었어요. 정답 이동을 정확히 알아서 점 오차를 바로 계산해요.

| 넣은 원인 | 17px σ1 (x / y) | 33px σ2 (x / y) |
|---|---|---|
| 센서 잡음만 (벽에서 잰 0.66) | 0.002 / 0.002 | 0.0015 / 0.0015 |
| + 실측 흐림 차이 분포 | 0.002 / 0.002 | 0.0016 / 0.0015 |
| + 조명 기울기 1% | 0.002 / 0.002 | 0.0015 / 0.0016 |
| **실측 판 잡음 (밝기별, 픽셀 독립)** | **0.014 / 0.014** | **0.010 / 0.010** |
| 실제 사진 (강체 검사) | 0.022 / 0.014 | 0.015 / 0.009 |

- 편향(평균 오차)은 모든 조건에서 0.0006px 이하예요. 추적 알고리즘 자체의 치우침은 없어요.
- 실측 흐림 차이는 스펙트럼으로 쟀어요 (사진마다 Δσ² 표준편차 가로 0.017, 세로 0.012px²). 추정기는 정확한 흐림으로 검증했어요 (오차 ±0.005).

## 3. 아니라고 확인된 원인

| 후보 | 확인 방법 | 결과 |
|---|---|---|
| 흐림 차이 (초점, 진동) | 실측 분포로 합성 | 잡음 거의 안 늘어남 |
| 조명 변화 | 합성 | 거의 안 늘어남 |
| 픽셀 위상 (앨리어싱) | 실제 잔차를 이동 소수부의 주기 함수로 회귀 | 설명 0~9% (교차검증) |
| 롤링 셔터 + 진동 | 같은 줄의 다른 QR 점끼리 상관 | 0.00 |
| 넓은 장면 일렁임 | 60px 넘게 떨어진 점끼리 상관 | 0.00 (가까운 점은 0.14~0.17, 템플릿 겹침 수준) |
| 영상 압축 (JPEG, H.264) | 8, 16 블록 경계 흔적, DCT 양자화 | 없음 |
| 색 보간 (베이어) | 2x2 위치별 잡음 크기 | 없음 (0.93으로 같음) |

## 4. 진짜 원인: 판의 무늬가 찍을 때마다 바뀜

이동이 거의 정확히 정수 픽셀인 사진 쌍을 보간 없이 뺐어요 (`66`, `67` 그림).

| 영역 | 한 장 기준 변화 크기 |
|---|---|
| 매끈한 벽 (밝기 약 188) | 0.66 |
| 판 어두운 곳 (밝기 32~96) | 1.4~2.7 |
| 판 중간 밝기 (112~192) | 4.7~6.3 |
| QR 흰 곳 (208~240) | 8~12 |
| QR 경계 | 6.2 |

- 같은 밝기인데 벽은 0.66, 판은 4.9예요. 센서 잡음이라면 밝기에만 따라야 하니 순수 센서 잡음이 아니에요.
- 차이 영상은 픽셀마다 제각각인 점무늬이고, 무늬가 있는 곳(QR 흰 종이 결)에서 커요.
- 두 사진의 위치 차이(0.1~2mm)가 커져도 변화량이 늘지 않아요 (시점 의존성 없음, 0.1mm부터 이미 최대).

**아직 못 가른 것**: 이게 (A) 카메라 잡음인데 매끈한 곳만 카메라 내부 잡음 제거가 지워 준 것인지, (B) 광택 있는 라벨/금속 표면의 미세 반사가 0.1mm 시점 차이에서도 바뀌는 것인지 가를 수 없어요. 같은 자세에서 반복으로 찍은 사진이 없기 때문이에요.
- (A)라면 같은 자세 여러 장 평균으로 줄어요.
- (B)라면 평균해도 안 줄고, 무광 라벨 같은 대상 쪽 변경이 필요해요.
- → **SEMES에 같은 자세 반복 촬영(예: 10장)을 요청하면 바로 갈려요.**

## 5. 남은 부분: 가로 전용 잡음

가로(x)만 실제가 합성보다 1.5배 커요. 가로 전용 성분이 따로 약 0.011px (33px) 있어요. 가로는 스테이지가 움직이는 방향이에요. 흐림 차이도 가로가 세로보다 커요 (0.017 vs 0.012). 원인은 아직 미확인이에요.

## 6. 알고리즘 개선 여지 (이론 하한 계산)

| 점 창 크기 | 같은 무게 (지금 방식) | 잡음 가중 (최적) |
|---|---|---|
| 17px | 0.0124px | 0.0101px |
| 33px | 0.0066px | 0.0054px |
| 49px | 0.0045px | 0.0036px |

- 17px: 지금 합성 결과(0.0138)가 같은 무게 하한(0.0124)에 가까워요. 지금 매칭은 이미 거의 최적이에요.
- 33px σ2: 하한 0.0066인데 실제 0.010이에요. 미리 흐리는 것(σ2) 때문에 정보를 1.5배 잃고 있어요.
- 잡음 가중(어두운 픽셀을 더 믿기)은 1.2배 개선이에요.
- 창이 클수록 점 하나는 좋아지지만, 이웃 창이 겹치면 판 전체 정보는 그만큼 늘지 않아요. 판 전체로 본 비교가 다음 단계예요.

## 다음 단계: 특징점을 가장 정확하게 잡는 방법 찾기

이제 실제 잡음 모델을 알아서 **정답 라벨이 있는 현실적인 합성 시험장**을 만들 수 있어요. 평가는 세 겹으로 해요.
1. 합성 (정답 있음): 점 오차, 편향, 판 전체 원근 단서 정밀도
2. 실제 사진 강체 검사 (정답 없음): 점 잡음
3. 최종: v7 판정기로 Y/Θ 축 정확도

후보: 잡음 가중 매칭, 흐림 없이 또는 약하게, 창 크기 17~65px, 판 전체를 모든 픽셀로 한 번에 맞추기(강체 원근 변환 직접 추정), 양방향 매칭, OpenCV ECC / LK 광류 / 위상 상관 / cornerSubPix, 가로 전용 잡음 원인 조사.
