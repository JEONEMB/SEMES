# 결과: 630점 경계 모델 추론 (해석미분 감쇠 LM)

입력: `data/clean/clean_20261014` 281장. center.bmp에서 QR 해독 격자로 구조 모서리 630점(대각 접촉 제외)을 만들고, 같은 경계 맞춤으로 center 기준 좌표를 정했다.
측정: QR 상자 NCC(±130) → 점마다 9x9 erf 경계 soft_l1 맞춤(창 다시 맞추기 최대 3번) → 11x11 진단. 계산기는 compiled.py의 해석미분·경계 제한 감쇠 LM을 그대로 옮겼다.
모델: 630점 이동(현재 - center 기준)을 이차식 6항으로 회귀한 P12 → 280장 전체로 학습한 Y/T 이차곡선(center 1원점) GLS → 두 가지 비용 비교. 같은 280장을 추론한 재대입 성적이다.

## 옮기지 않은 부분

- 원래 비교 대상인 SciPy least_squares TRF(수치미분) 계산기 `baseline.py`, 중간 단계 `optimized.py`·`fast_fit.py`는 옮기지 않았다. 원래 시간은 상수로만 인용한다.
- 상주 HTTP API(`serve.py`, `client_example.py`)와 API 왕복 시간 검사는 옮기지 않았다.
- 원래 모델은 SciPy TRF로 잰 280장 좌표로 학습했고, C++은 같은 LM으로 잰 좌표로 학습한다. center 기준 좌표도 LM으로 맞췄다.
