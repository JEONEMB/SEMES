# 계획: QR 탐색 창 — 좁게 / 넓게 / 좁게 하다가 필요하면 넓히기 (11-14, 결과를 보기 전에 적음)

## 비교할 방식

| 방식 | 하는 일 |
|---|---|
| A 늘 좁게 | 탐색 창 ±110 px (원래 SEMES) |
| B 늘 넓게 | 탐색 창 ±250 px |
| C 자동 넓히기 | ±110 으로 먼저 잰다. QR 을 못 찾으면(탐색 창 끝, NCC 낮음) ±250 으로 다시 잰다 |

## 자료

- 실험 20261114_0230 의 사진별 결과를 쓴다(`shift_rows.tsv`).
  - SEMES 702장 × 가로 이동 11가지(0 ~ ±250 px) × 창 2가지
  - 구성: 흐림 NCC + 값 5개
- 시간은 새로 잰다.
  - 사진 100장(702장에서 7장마다 1장) × 이동 {0, +150} × 창 2가지
  - 성공할 때와 실패할 때 시간을 따로 잰다
  - OpenCV 4스레드, 사진 읽기 제외
- 계산은 C++ 로 한다.

## 지표

| 지표 | 계산 |
|---|---|
| 정확도 | 같은 사진·같은 이동에서 두 창의 Y·T 가 같은지(차이 최대값). 같으면 정확도는 방식과 무관하다 |
| 측정률(안정성) | 이동량마다 값을 낸 비율. C 는 A 가 실패하면 B 결과를 쓴다 |
| 평균 시간 | 아래 두 분포에서 계산 |
| | A, B: 성공·실패 시간 중앙값 |
| | C: A 성공이면 A 시간, A 실패면 A 실패 시간 + B 시간 |

평균 시간을 낼 이동 분포:

1. SEMES 학습 자료(702장, 이동 0)
2. 성현 님 평가표 35 자세(QR 이동 ≈ 14·Y + 80·T px 로 환산, 110 px 넘는 자세 10개)
