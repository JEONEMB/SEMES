# Y, Θ 자동 보정: 오차 분석 실험 계획표

## 0. 공통 규칙

- **데이터 나누기**: 계수를 학습할 사진과 채점할 사진을 반드시 나눠요. 기본은 짝수번째 사진으로 학습하고 홀수번째 사진으로 채점해요. 조합을 고를 때는 4등분해서 써요.
  - 1/4 + 2/4: 학습
  - 3/4: 조합 선택
  - 4/4: 최종 채점
- **결과 기록**: 실험 하나당 아래 표의 한 행으로 기록하고, 원본 수치는 CSV로 남겨요.
- **목표치 (임시)**: Y ±0.05mm (명세서의 제어 단위), Θ는 멘토 답변을 받으면 확정해요.

### 공통 지표

| 지표 | 정의 |
|---|---|
| RMS 오차 (Θ, Y) | 평균적인 오차 크기 |
| 최대 오차 | 가장 나쁜 사진 한 장의 오차 |
| 허용 안 비율 | 오차가 목표치 안에 든 사진의 비율 (%) |
| 혼선 | Y만 틀어진 사진에서 Θ로 잘못 읽는 양, Θ만 틀어진 사진에서 Y로 잘못 읽는 양 |
| 치우침 | 오차 평균 (한쪽으로 쏠려 있는지) |
| 처리 시간 | 사진 1장당 ms (C++ 기준) |

## 1. 실험 축

| 축 | 바꿔볼 값 |
|---|---|
| **A. 특징점 영역, 조합** | A1 QR 파인더 1개 / A2 QR 꼭짓점 12개 / A3 QR 3개 전체 픽셀 / A4 QR + 브래킷 / A5 QR + 브래킷 + 배경 / A6 자동 선택 최적 2점 / A7 자동 선택 N점 |
| **B. 측정 방법** | B1 QR 검출 박스 중심 / B2 꼭짓점 서브픽셀 / B3 템플릿 매칭 + 포물선 보간 / B4 ECC (affine, homography) / B5 위상상관 / B6 직선 맞춤 (모서리 각도) |
| **C. 추정 알고리즘** | C1 이동량 ÷ 계수 (Y=0 가정) / C2 2×2 야코비안 / C3 N×2 최소제곱 / C4 가중 최소제곱 / C5 원근 왜곡 회귀 / C6 호모그래피 분해 (캘리브레이션 필요) |
| **D. 다른 방법 (베이스라인)** | D1 solvePnP (카메라 캘리브레이션 + QR 실제 크기) / D2 Fourier-Mellin (위상상관 기반 회전, 크기 분석) / D3 CNN 회귀 (참고용) / D4 반복 보정 (비주얼 서보잉) |
| **E. 촬영 전략** | E1 사진 1장 / E2 같은 자세 N장 평균 / E3 로봇을 Θ로 조금씩 돌려가며 N장 (직각 찾기) / E4 보정 → 다시 촬영 반복 |
| **F. 테스트 조건** | F1 Θ만 / F2 Y만 / F3 Θ, Y 섞임 (데이터 요청 필요) / F4 작은 값 (±0.1) vs 큰 값 / F5 범위 끝부분 |
| **G. 강인성** | G1 가우시안 노이즈 / G2 밝기, 대비 변화 / G3 흐림 (초점) / G4 다른 주소의 QR / G5 일부 가려짐 / G6 세로 미세 어긋남 |
| **H. 보정 데이터 양** | 계수를 구하는 데 쓰는 사진 수: 5 / 10 / 20 / 50 / 전체 |
| **I. 속도, 구현** | 해상도 1 / 0.5 / 0.25배, ROI 크기, 파이썬 vs C++ 결과 일치 확인 |
