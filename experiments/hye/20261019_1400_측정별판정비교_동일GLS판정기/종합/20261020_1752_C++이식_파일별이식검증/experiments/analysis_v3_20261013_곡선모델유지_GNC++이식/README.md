# 20261013 특징 곡선 Gauss–Newton 비교

이 폴더는 초기 `v1_data` 보관본과 구별한 `analysis_v3/gn_features.py`, `run_v3.py`의 C++ 이식이다. 생성 관측 시각은 각각2026-10-13 13:05:59.108 KST와13:09:23.896 KST다. 원본의 실제 수정 시각·해시·도구 호출 흔적은 파일별 원장에 따로 보존한다. C++ 이식 작업자는 현재 채팅의 Codex다.

## 문제·조사·해결

초기 선형 특징 모델에 이차 곡선을 추가하면 Y/T 구분과 추정이 개선되는지 비교했다. C6는 학습 사진에서 `[T,Y,T²,TY,Y²,1]`에 대한 특징 모델을 맞추고 잔차 공분산으로 가중한 Gauss–Newton 반복으로 T/Y를 푼다. 초기값은 C5 GLS이며 비용이 줄어드는 경우에만 이동한다.

단일축 명령으로만 학습했으므로 T×Y 상호작용은 식별되지 않는다. 원본의 해당 열을 유지하며, 이 계산을 실제 혼합 자세 일반화의 증거로 사용하지 않는다.

## 유지한 부분

기존13개 특징 조합과 판 전체14변위 Q5b를 같은 순서로 비교한다. C1~C5는 `../analysis_v1_20261013_고정점분할유지_선형계산C++이식/src/common.hpp`를 공유한다. C6의 이차 기저·Jacobian·1% 공분산 보정·100회 한도·감쇠값·중단값을 유지했다.

판정 규칙3은 원본과 같이 전체 OOF 잔차의 T 표준편차3배로 상대 축 가설과의 차이를 판단한다. 이 전체 자료 기반 임계값 보정은 과거 분석 조건이며 현재 독립 시험 성적과 구분한다. 명령값 순 보간으로 만든 짝을 실제 촬영 궤적으로 표시하지 않는다.

## 바꾼 부분

실행형 Python import·NumPy/SciPy 연산을 C++ 자료 구조와 OpenCV 선형대수로 바꾸었다. Python pickle 대신 사진별 예측·판정·집계 CSV와 감사 JSON을 기록한다. 원본 파일·모델·관측은 그대로 둔다.

원본 `run_v3.py` 자체도 마지막 G1 행은 `g1_est.npy`를 읽는다. C++도 이 행을 같은 저장 예측으로 재생하되 `kind=saved_G1_prediction_replay`로 명시했다. 나머지65개 행은 C++에서 특징 모델을 새로 학습·추론한다. G1 픽셀 직접 추론은 이후 별도 [C++ 실험](../analysis_v3_20261013_정합모델유지_픽셀GNC++이식/README.md)에서 구현·281장 대조했다. 이 폴더의 앞선 저장 예측 재생은 당시 기록으로 보존한다. 저장 예측 재생을 픽셀 추론 이식으로 세지 않는다.
