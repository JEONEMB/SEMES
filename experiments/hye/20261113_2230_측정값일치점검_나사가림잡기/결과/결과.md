# 결과: 측정값 일치 점검 (11-13 ~ 11-14)

방법은 [계획.md](../계획.md)에 결과를 보기 전에 정했고 바꾸지 않았다. 한 가지만 덧붙였다(아래 "덧붙인 것").

계산은 모두 C++ 로 했다.

- 점검식 만들기·확인: `final00_tool health`, `final00_tool health-check`
- 교란 요약: 실험 20261113_2130 의 `perturb_summary`
- 공개 API 확인: `final00_tool predict`

처음에 Python 으로 만든 점검식과 C++ 로 만든 점검식은 계수·기준값이 소수 11자리까지 같았고, assets 에는 C++ 로 만든 파일을 넣었다.

## 무엇을 하나

자세는 Y·T 두 개인데 재는 값은 장비 5개(QR 1 + 나사 4), SEMES 7개(+ 바 2)다. 정상이면 값들이 한 자세로 함께 설명된다.

| 단계 | 내용 |
|---|---|
| 점검식 | 값마다 "모델 출력 (Y, T) → 값" 2차식(1, Y, T, Y², YT, T²) |
| 정상 흔들림 | 학습 사진 잔차의 1.4826 × MAD |
| 점검값 | max \|잔차 − 기준 잔차\| / 정상 흔들림 |
| 기준값 | 학습 사진 점검값 99.9% 분위 × 1.5 |

점검값이 기준값을 넘으면 값 하나가 다른 값들과 맞지 않는다는 뜻이다.

## 덧붙인 것: 그날 기준 잔차

계획에는 측정 기준을 다시 잡을 때만 기준 잔차를 다시 맞추게 했다. 학습하지 않은 날(11-13 역순)에 확인해 보니 이것만으로는 부족했다.

- 카메라 처짐으로 왼쪽 나사는 −0.18 px, 오른쪽 나사는 +0.2 px 일정하게 달라져 있었다.
- 그래서 정상 사진의 15% 가 기준을 넘었다.

그래서 영점 업데이트(`set_zero`) 때도 그 센터 사진의 잔차를 기준 잔차로 삼게 했다. 기준값·점검식은 바꾸지 않았다.

## 결과 2. 교란 사진에서 잡아낸 것 (교란 시험 다시 돌림, `교란_점검효과.tsv`)

"조용히 틀림" = 교란 전에는 통과, 교란 뒤 값은 냈는데 허용오차 밖.

| 교란 (장비 사진, ssafy) | 조용히 틀림 | 점검 경고 | 경고 없이 남음 |
|---|---:|---:|---:|
| 나사1 절반 가림 | 641 (Y 최대 3 mm) | 500 | 141 |
| 나사1 반사 | 383 | 321 | 62 |
| 흐림 σ5 | 81 | 67 | 14 |
| 배율 ×1.005 | 1183 | 1183 | 0 |
| 회전 0.2° | 1950 | 1950 | 0 |
| 회전 0.05° | 1949 | 65 | 1884 |
| 가로 밀림 2 px, 판–나사 밀림 0.3 px | 1950 | 0 | 1950 |

- 나사 가림·반사에서 Y 가 0.1 mm 넘게 틀린 사진은 모두 경고했다.
  - 남은 것은 Y 0.05~0.095 mm, 평균 0.053 mm 로 허용오차(0.045)를 조금 넘는다.
- 화면 전체가 같이 바뀌는 변화(가로 밀림, 판–나사 밀림)는 값들이 서로 맞아 경고하지 않는다. 영점 업데이트로 없앤다(실험 20261113_2130 결과 1).
- 배율·회전은 경고한다. 영점을 다시 잡으라는 신호로 쓴다. 배율 ±0.2% 에서는 맞는 값에도 경고가 많이 난다(장비 1916/1959).
- SEMES 사진의 나사 가림·반사는 원래 나사 NCC 0.6 검사에서 멈추므로 이 점검과 상관없다.

## 적용

| 모듈 | 점검식 | 기준값 |
|---|---|---:|
| ssafy | `assets/health.tsv`(ncc), `health_track536.tsv` | 7.44 / 7.43 |

기준을 넘었을 때의 동작:

- **기본은 값을 그대로 내고 경고만 남긴다**(2026-11-14 사용자 지시).
  - `alignment_diagnostics().normalized_cost_margin > 1`
  - `message` 가 `WARNING 측정값이 서로 맞지 않는다(…)` 로 시작한다.
- `set_joint_health_check(true)` 면 예외를 던진다.

## 한계

- 점검식과 기준값은 모델과 같은 사진으로 만들었다. 학습하지 않은 날 확인은 장비 1일(11-13), SEMES 회차 빼기 4번뿐이다.
- 나사 가림·반사 중 Y 0.05~0.1 mm 정도로 조금 틀린 것은 경고하지 못한다.
- 교란은 인위로 넣은 것이다.
