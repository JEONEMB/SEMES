# 계획: 측정값 일치 점검 (11-13, 결과를 보기 전에 적음)

## 문제

영상 교란 시험(실험 20261113_2130)에서 장비 사진의 나사 하나가 가려지거나 반사되면 오류 없이 크게 틀렸다.

- 나사 절반 가림: 641장이 조용히 틀림, Y 최대 3 mm
- 나사 반사: 383장이 조용히 틀림

## 생각

자세는 Y, T 두 개뿐인데 재는 값은 여러 개다(장비 5개, SEMES 7개). 정상이면 값들이 한 자세로 함께 설명된다. 나사 하나만 틀리면 그 값만 다른 값들과 맞지 않는다.

## 방법 (미리 정함, 결과를 보고 바꾸지 않음)

1. 모델이 쓰는 값만 쓴다(가중치가 0 이 아닌 값: 장비 5개, SEMES 7개).
2. 학습 사진마다 모델 출력 자세 (Y, T) 를 구한다(측정 기준을 바꾸기 전 원래 출력, 영점 빼기 전).
3. 값마다 "자세 → 값" 2차식을 최소제곱으로 맞춘다. 항은 1, Y, T, Y², YT, T² 이다(T ±1° 에서 회전이 곡선이라 2차까지).
4. 잔차 = 측정값 − 2차식(모델 출력 자세). 값마다 정상 흔들림 s_j = 1.4826 × 학습 사진 잔차의 MAD.
5. 점검값 H = max_j |잔차_j| / s_j
6. 기준값 = 1.5 × (학습 사진 H 의 99.9% 분위). 이 값을 넘으면 joint() 가 예외를 던진다(멈춤).
7. 측정 기준을 다시 잡으면(set_reference), 그 센터 사진의 잔차를 새 기준에서의 0 으로 다시 맞춘다. 새 기준으로 잰 값이 이전 기준 값과 상수만큼 달라져 생기는 잔차를 빼기 위해서다.

## 확인 (기준값을 정한 뒤 한 번)

- 거짓 경보: 학습에 쓰지 않은 사진에서 정상인데 멈추는 비율
  - 장비: 11-13 역순 1679장. 측정 기준을 다시 잡지 않고 잰 값
  - SEMES: 회차 하나를 빼고 점검식을 만든 뒤 그 회차를 잼(4회)
- 잡아내기: 교란 시험을 다시 돌려, 조용히 틀린 사진 중 몇 장이 멈춤으로 바뀌는지, 정상이던 사진 중 몇 장이 새로 멈추는지
- 화면 전체 변화(회전, 가로 밀림, 판–나사 밀림)는 값들이 서로 맞으므로 이 점검으로 잡히지 않는 것이 정상이다. 그건 영점 업데이트의 몫이다.
