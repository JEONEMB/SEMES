# A17 보고서: 날짜 층화 5-fold로 joint 대리 모델 재평가

실행 2026-11-04 · 요청: 사용자 ("날짜별로 80/20으로 나눠 20을 5-fold") · 기준: [ALGORITHM_RULES 2026-11-04](../../../../ALGORITHM_RULES.md) joint `|eT| ≤ 0.01`

- **문제:** joint T가 0.01 기준으로 1020 날짜에서 85.4%였다. 날짜마다 80%를 학습에 넣으면 나아지는가?
- **해결:** A0 캐시의 QR 아핀 18 + 가로선 48 = 66차원 선형 대리 모델(A3와 같음)로, 세트마다 같은 자세 묶음을 (Y, T) 순으로 정렬해 5개 fold에 돌려 배정했다. 반복 3장은 같은 fold에 묶었다. 각 fold에서 모든 날짜의 80%로 학습하고 20%로 시험했다.
- **결과:** 1020의 T 통과율이 85.4% → **91.7%** (44/48), 최대 오차 0.043 → **0.028**. 전체는 97.5% → **98.0%**. 그래도 0.01을 넘는 사진이 562장 중 11장 남는다.

## 1. 결과 (T+2.00 범위 밖 12장 제외, 562장)

| 평가 | 날짜 | T 평균 | T 최대 | \|eT\|≤0.01 | Y 최대 | \|eY\|≤0.045 (참고) |
|---|---|---|---|---|---|---|
| 기존 4-fold (A3 재현) | 전체 | 0.0033 | 0.0427 | 548/562 (97.5%) | 0.193 | 95.7% |
| | 1020 | 0.0065 | 0.0427 | 41/48 (85.4%) | 0.193 | 75.0% |
| **날짜 층화 5-fold** | 전체 | 0.0031 | 0.0278 | **551/562 (98.0%)** | 0.133 | 95.6% |
| | 1014 | 0.0030 | 0.0123 | 276/280 (98.6%) | 0.075 | 96.4% |
| | **1020** | 0.0055 | **0.0278** | **44/48 (91.7%)** | 0.133 | 79.2% |
| | 1029 | 0.0029 | 0.0121 | 231/234 (98.7%) | 0.061 | 97.9% |
| 5-fold + 상호작용 132d, ridge 0.01 | 전체 | 0.0030 | 0.0228 | 550/562 (97.9%) | 0.123 | 92.9% |

- 기존 4-fold는 A3 수치와 소수점 4자리까지 같게 재현됐다(이 맥, Homebrew OpenCV 5.0 빌드).
- 기존 4-fold도 이미 날짜마다 75%를 학습에 넣는 층화 분할이었다. 5-fold는 학습 비율이 80%로 늘고 fold 경계가 바뀐 효과다.
- 상호작용 항(joint의 204차원 구조를 흉내 낸 것)은 T를 거의 바꾸지 않고 Y를 나쁘게 한다.

### 나누는 방식에 따른 흔들림

5-fold는 모든 사진을 정확히 한 번씩 시험한다. 조합을 전부 돌릴 필요는 없다. 다만 어떻게 5조각으로 나누느냐에 따라 숫자가 흔들리므로, 크기 층화는 유지하고 조각 배정만 바꾼 10가지 분할(seed 0~9)로 다시 돌렸다([repeat_seeds.csv](results/repeat_seeds.csv)).

| | 범위 (10회) |
|---|---|
| 전체 \|eT\|≤0.01 | 97.5% ~ 98.6% (548~554/562) |
| 1020 \|eT\|≤0.01 | **87.5% ~ 93.8%** (42~45/48) |
| T 최대 오차 | 0.027 ~ 0.034 |

1020은 48장뿐이라 한 장이 2.1%p다. 분할에 따라 ±3장 정도 흔들린다. 어떤 분할에서도 0.01을 넘는 사진이 남고 최대 오차는 0.027 이상이다.

- **11장 중 10장이 eY/eT ≈ −4 ~ −6.5**다. T 1단위가 Y 5.6 mm와 같은 화면 이동을 만든다는 감도비와 맞는다. 실제 Y 이동의 일부를 T로 읽는 **Y↔T 누출**이 남은 오차의 주된 정체다.
- 같은 자세 반복인 1020 Y+0.10 T+0.20 (2)와 (3)은 eT가 +0.022와 −0.010으로 **부호가 반대**다. 같은 명령이라도 사진마다 판이 실제로 조금씩 다른 자리에 섰을 가능성(A1: 반복 사이 판 이동 SD 0.085 px)이 있다. 이 경우 정답 라벨(명령값) 자체가 틀린 것이므로 모델 개선으로 없앨 수 없는 부분이다.

## 3. 한계

- 66차원 선형 **대리 모델**이다. 전달 중인 joint(ECC 54 + 선 48 → 204차원 GLS)와 관측·학습식이 다르다. 대리 모델의 날짜 OOF 85.4%가 보고된 85%와 맞아 같은 현상을 보고 있다고 판단했다.
- 575장 모두 개발에 노출된 자료다. 독립 성능이 아니다.
- 혼합 자세(Y·T 동시)는 1020의 Y>0, T>0 한 사분면 19조건뿐이다.
