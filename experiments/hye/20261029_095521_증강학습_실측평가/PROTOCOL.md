# 실행 전 고정한 계획: 증강으로만 학습, 실측은 평가만

- 상태: 실험 (채택 모듈은 바꾸지 않는다)
- 질문: joint와 control을 **증강 자료로만** 학습하면, 실측 사진으로 학습한 같은 모델보다 실측 사진에서 나은가?
- 입력: 앞선 증강 실험 [20261028_211553](../20261028_211553_YT증강_점별변위_결합항/README.md)의 `inputs/module_features` (채택 C++ 모듈이 실측 341장에서 뽑은 joint 102관측, control 630점 변위). 이번에 다시 측정하지 않는다.

## 누출 막기

생성기도 실측 사진으로 맞추므로, "평가 사진이 생성기에 들어갔는가"를 기준으로 평가를 둘로 나눈다.

| 평가 | 평가 사진 | 생성기와 실측 학습에 쓴 사진 |
|---|---|---|
| A. 1014 겹 바깥 | 1014 단일축 280장, 4겹 (앞선 실험의 trial 안 순위 겹) | 같은 겹을 뺀 1014 210장 + 1014 센터 |
| B. 1020 새 날짜 | 1020 60장 (센터 3, 혼합 T≤1 45, T=2 12) | 1014 281장 전체 |

- 1020 사진은 B에서 생성기, 잡음, 영점, 학습 어디에도 쓰지 않는다. 그래서 1020 세션 영점, 1020 반복 잡음, 1020 센터 영점은 이번 생성기에서 뺀다.
- 결합항은 끈다 (앞선 실험에서 잡음과 구분되지 않음).

## 비교하는 모델 (모듈마다)

| 이름 | 학습 자료 | 학습기 |
|---|---|---|
| 실측 | 위 표의 실측 사진 | 같은 학습기 |
| 증강 | 같은 실측 사진으로 맞춘 생성기의 샘플만 | 같은 학습기 |
| 참고: 채택 동결 모델 | 원래 학습 (joint 341장, control 280장) | 원래 학습기 |

참고 모델은 평가 사진을 학습에 썼으므로 재대입 성적이며 공정한 비교 대상이 아니다.

## 학습기

- joint: 102관측 → 204차원(관측 + 관측 × 평균 QR 가로 이동/100, 채택 모듈과 같은 식). 전방 선형식 `z = 원점 + 계수 × [Y/2, T/2]` 최소제곱, 잔차 공분산을 상관행렬에서 0.01 축소한 GLS로 역산. 원래 학습 코드는 저장소에 없어 이 학습기는 저장된 모델 구조(degree 1, shrink 0.01, origin, projector, gram, initial, scale 2)로부터 다시 만든 것이다. 원래 계수와 같지 않다.
- control: P12 특징, 세션 6개(Y1±, Y2±, T±)의 절편 + 축별 공유 2차식, 잔차 상관 0.05 축소 백색화, 6후보 곡선 역산과 부호 게이트. [P12_vs_J204](../20261028_141257_control_P12_vs_J204/src/models.cpp)의 C++ `train_yort`를 옮겼다. 실측 280장으로 다시 학습해 채택 `model.json`과 같은지 먼저 확인한다.

## 증강 샘플 (고정)

- 생성식: 영점 + 단일축 반응(4겹 교차검증으로 반응식 고르기, 후보 6개) + 반복 잡음. 잡음은 학습 사진의 반응식 잔차(자유도 보정, 1014 연속)에서 사진 단위로 뽑는다.
- 영점: 학습 사진에서 맞춘 1014 센터(0)와 trial S1~S6, 그리고 이 7개의 주성분 2개 ±2σ 후보 4개, 모두 11개. 센터 영점에는 접근 방향 백래시(+: S1, S3, S5 평균, -: S2, S4, S6 평균)를 더한다.
- joint 증강: Y [-2, 2], T [-1, 1]에서 연속 균등으로 20,000개, 영점 11개 중 균등, 잡음 1개씩. 난수 시드 20261029.
- control 증강: control은 단일축 Y-or-T 모델이라 세션별 단일축 샘플만 만든다. 세션의 축과 부호 범위에서 Y는 0.01 간격, T는 0.002 간격, 값마다 잡음 5개, 영점은 그 세션의 trial 영점. 분모는 실측과 같은 방식으로 세션 절편을 맞춘다.

## 채점 (바꾸지 않는다)

- 두 축 동시 통과: |Y 오차| ≤ 0.09 이고 |T 오차| ≤ 0.09. Y, T 평균, 최대 절대오차.
- 묶음: A 280장 (Y 80, T 200), B 센터 3, 혼합 T≤1 45, 혼합 T=2 12 (범위 밖).
- control은 Y 또는 T 하나만 내므로 혼합 자세 통과는 전제 밖이다. 따로 표시한다.
- 결과를 본 뒤 생성식, 샘플 수, 축소값, 분할을 바꾸지 않는다. 바꾸면 새 실험 폴더로 한다.
