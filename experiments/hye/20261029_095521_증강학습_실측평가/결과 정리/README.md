# 증강으로만 학습, 실측은 평가만

- 상태: **실험 (미채택)**. 채택 모듈(`00000_final_*`)과 `selected_modules.cmake`는 바꾸지 않았다.
- 주의: 이 실험의 증강 샘플 간격(joint 연속 균등, control Y 0.01, T 0.002)은 근거 없이 임의로 정한 것이다. 계획(PLAN.md)의 명령 격자 Y 0.05, T 0.01대로 다시 한 결과는 [20261029_101807](../../20261029_101807_증강학습_실측평가_격자/결과%20정리/README.md)에 있다.
- 계획: [PROTOCOL.md](../실험%20방법/PROTOCOL.md) (실행 전 고정, 결과를 보고 바꾸지 않음)
- 코드: [run.py](../실험%20방법/run.py) (빠른 검증용 Python. 팀 전달 코드 아님)
- 입력: [20261028_211553 증강 실험](../../20261028_211553_YT증강_점별변위_결합항/결과%20정리/README.md)의 `inputs/module_features` (채택 C++ 모듈이 실측 341장에서 뽑은 특징). 해시는 `results/summary.json`의 `inputs_sha256`.
- 실행: `python -I run.py` → `results/` (같은 시드로 다시 돌리면 같은 결과)

**결론: 같은 날짜(1014) 안에서는 증강으로만 학습해도 실측으로 학습한 것과 성적이 같다(joint, control 모두 280/280). 하지만 1014만으로 만든 생성기로는 새 날짜(1020)의 영점 이동을 담지 못해서, joint는 증강 학습이든 실측 학습이든 1020에서 크게 틀렸다(센터 0/3). 증강이 "새 날짜"를 대신하지는 못했다.**

## 무엇을 비교했나

| 모델 | 학습 자료 |
|---|---|
| 실측 | 1014 실측 사진 (평가 사진 제외) |
| 증강 | 같은 실측 사진으로 맞춘 생성기의 샘플만 (joint 20,000개, control 8,530~8,780개) |
| 동결 (참고) | 채택 모델. 평가 사진을 학습에 써서 재대입 성적 |

- **A. 1014 겹 바깥**: 1014 단일축 280장을 4겹으로 나눠, 시험 겹을 뺀 사진으로 생성기와 실측 모델을 만들었다.
- **B. 1020 새 날짜**: 1014 281장만으로 생성기와 실측 모델을 만들고 1020 60장에 적용했다. 1020 사진은 생성기, 잡음, 영점, 학습 어디에도 쓰지 않았다.

## 결과

두 축 동시 통과 (|Y 오차|, |T 오차| 모두 0.09 이하) / Y 평균, 최대 절대오차

| 모델 | A 1014 단일축 280 | B 1020 센터 3 | B 1020 혼합 T≤1 45 | B 1020 T=2 12 (범위 밖) |
|---|---|---|---|---|
| joint 실측 | 280/280, Y 0.0144 / 0.046 | 0/3, Y 0.151 / 0.163 | 13/45, Y 0.107 / 0.288 | 0/12 |
| **joint 증강** | **280/280, Y 0.0153 / 0.050** | **0/3, Y 0.150 / 0.162** | **6/45, Y 0.124 / 0.229** | **7/12** |
| joint 동결 (참고, 재대입) | 280/280, Y 0.0162 / 0.051 | 3/3 | 45/45 | 12/12 |
| control 실측 | 280/280, 축 280/280 | 3/3 | 18/45 | 0/12 |
| **control 증강** | **280/280, 축 280/280** | **3/3** | **18/45** | **0/12** |
| control 동결 (참고) | 280/280 | 3/3 | 18/45 | 0/12 |

control은 Y 또는 T 하나만 내므로 혼합 자세 통과는 전제 밖이다. control의 B 실측 모델은 학습 사진이 동결 모델과 같아(1014 280장) 결과도 같다.

### joint가 1020에서 틀린 방향

| 모델 | 1020 센터 Y 치우침 | 1020 혼합 T≤1 Y 치우침 (표준편차) | T 치우침 |
|---|---|---|---|
| joint 실측 | +0.151 | +0.055 (0.107) | -0.018 |
| joint 증강 | +0.150 | +0.118 (0.057) | -0.018 |
| joint 동결 (1020 포함 학습) | +0.021 | -0.000 (0.025) | -0.000 |

- 1014만으로 학습한 두 모델 모두 1020 센터를 **Y +0.15**로 읽는다. 날짜가 바뀌며 생긴 영점 이동이고, 1014 영점 11개(실측 7 + 주성분 ±2σ 4)로는 이 크기와 방향을 덮지 못했다.
- 증강 모델은 혼합 자세에서 **흩어짐이 절반**(0.107 → 0.057)이지만 치우침이 더 크다(+0.055 → +0.118). 증강이 Y×T 조합에는 강해졌지만, 날짜 영점은 전혀 배우지 못했다는 뜻이다.
- 1020 사진을 학습에 넣은 동결 모델은 치우침이 거의 0이다(재대입이라 성적 자체는 비교 대상이 아니다).
- T=2(범위 밖)에서 증강 모델이 7/12로 나아진 것은 3차 반응식의 외삽 덕일 수 있으나, 범위 밖이라 근거로 쓰지 않는다.

## 학습기 확인 (`results/summary.json`의 `check`)

- control: 실측 280장으로 다시 학습한 모델이 채택 `model.json`과 세션 절편, 기울기, 곡률 최대 차 2.4e-8, 341장 축 일치 341/341, 추정값 최대 차 1.1e-5. 백색화 행렬 W는 고유벡터 부호와 순서만 달라 값이 다르지만 추정에는 영향이 없다.
- joint: 원래 학습 코드가 저장소에 없다. 저장된 모델 구조(선형, 축소 0.01)로 다시 만든 학습기로 341장 전수 학습하면 동결 모델과 Y 최대 0.037, T 최대 0.0066 차이가 나고 재대입 통과는 338/341(동결 341/341)이다. 그래서 동결 모델과 직접 비교하지 않고, **같은 학습기로 만든 실측 모델과 증강 모델을 비교**했다.

## 한계

- 1014 안의 비교(A)는 증강이 실측을 대신할 수 있는지만 보여 준다. 생성기가 1014 단일축에서 나왔으므로 1014 단일축에서 비슷한 성적은 예상된 결과다.
- 1014에는 혼합 자세가 없어 B의 증강 생성기는 결합항 없이 "Y와 T 효과가 더해진다"는 가정만 쓴다.
