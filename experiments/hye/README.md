# 실험 안내

실험 이름 규칙과 평가 기준은 [ALGORITHM_RULES.md](../../ALGORITHM_RULES.md)를 따른다. 기존01/02/03 이름은 파일시스템의 생성 시각을 사용해 시분초로 변경했다. [이름 대응표](directory_rename_20261028.json)에 이전·현재 이름을 보존했다. 스냅샷 안의 당시 경로와 해시는 과거 기록이므로 변경하지 않았다.

## 폴더 구조

10-06 ~ 10-29 작업을 시각 순서로 다시 나눴다. 이름은 `<YYYYMMDD>_<HHMM>_<어떤 문제>_<어떤 해결>/`이고, 시각은 그 실험 코드 파일의 가장 이른 생성·수정 시각이다.

- `실험/`: 코드, CMake, 계획(PROTOCOL), 실행 자산. 빌드할 때 CMake 소스 폴더로 쓴다.
- `결과/`: 실행 결과(`EXPERIMENT_DIR`), README, 보고서, 로그. C++로 다시 돌리면 `결과/이미지/`, `결과/결과.md`, `결과/보고서.md`를 같은 내용으로 다시 쓴다.
- `결과/원본자료/`: 당시 ppt·그림·영상·표 사본. 용량 때문에 git에서 제외했고 원본은 저장소 밖 `00000.legacies/`에 있다.
- `종합/<시각_문제_해결>/`: 이 실험과 다음 실험 사이에 한 문서·발표·도구 작업.

`00000_final_*` 두 폴더는 전달 경로라 이 구조를 따르지 않는다. 10-22 백업 스냅샷은 다른 폴더의 사본이라 `99999.trash/`로 옮겼다.
