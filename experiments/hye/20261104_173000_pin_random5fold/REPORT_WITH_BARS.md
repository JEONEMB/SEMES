# QR+나사+위·아래 바 추가 비교

2026-11-04 사용자 요청에 따라 빠졌던 전체 결합 조건을 평가했다. **선형은 569/571장, 99.65%로 기존 QR+나사와 같았고, 2차식은 562/571장으로 낮아졌다.** 이 자료에서는 바를 추가하면 더 좋아진다고 결론 낼 수 없다. 기존 운영 모듈과 최초 `results/`는 유지했다.

## 같은 조건에서 추가한 것

기존 원본 571장의 저장 관측, SHA-256, seed 20261104와 fold를 그대로 사용했다. center 제외, 이미지 단위 무작위 80/20 5-fold, Y/T 동시 추정이다. 학습 fold에서만 표준화하고 ridge 1e-4를 유지했다. 바는 영상 관측 값이며 정답이나 파일명에서 만드는 특징이 아니다.

QR+나사의 14특징에 다음 4개를 붙였다.

1. 위 바 24블록 세로 변위 평균 - 나사 4개의 평균 세로 변위.
2. 위 바 24블록의 세로 변위 기울기, px/1000px.
3. 아래 바 24블록 세로 변위 평균 - 나사 4개의 평균 세로 변위.
4. 아래 바 24블록의 세로 변위 기울기, px/1000px.

기울기는 저장소 line_protocol.json의 실제 블록 중심으로 최소제곱 적합한다. 모든 48블록을 사용하되 회귀 열은 평균과 기울기 4개로 요약한다. 각각을 독립 48특징으로 넣은 실험은 아니다. 선형과 전체 2차식을 평가했고, 결과를 보고 ridge나 특징을 다시 조정하지 않았다.

## 한 장 정확도

Y ±0.045 mm, T ±0.01 명령 단위. 각 방법의 유효 예측은 571/571이며 실패를 분모에서 제외하지 않았다.

| 방법 | Y 통과 | T 통과 | 동시 통과 | Y MAE | T MAE | Y 최대오차 | T 최대오차 |
|---|---:|---:|---:|---:|---:|---:|---:|
| QR+나사 선형, 기존 | 571 | 569 | 569 | 0.008318 | 0.002103 | 0.041284 | 0.010689 |
| **QR+나사+위·아래 바 선형** | **571** | **569** | **569** | **0.008211** | **0.002054** | **0.043159** | **0.011314** |
| QR+나사 2차식, 기존 | 570 | 570 | 569 | 0.008017 | 0.001679 | 0.059720 | 0.011441 |
| QR+나사+위·아래 바 2차식 | 568 | 565 | 562 | 0.008066 | 0.001749 | 0.061750 | 0.021629 |

바를 더한 선형은 평균오차가 조금 작지만 최대오차는 더 컸다. 두 선형 모두 index 420과 308의 T가 기준 밖이었다. index 420의 폴더 T+0.32 / 파일명 T+0.33 불일치는 그대로 기록하고 파일명 라벨을 유지했다. 이 사진을 빼거나 정답을 바꾸지 않았다.

선형의 fold 동시 통과 수는 115/115, 114/114, 113/114, 114/114, 113/114다. 통과율 범위 99.12~100%, 표준편차 0.43%p다. 바 결합 2차식은 범위 96.49~100%, 표준편차 1.40%p였다. 전체 8개 방법의 fold별 결과와 같은 자세 반복의 전폭은 `results_with_bars/summary.tsv`, `aggregate.tsv`, `repeat_spread.tsv`에 있다.

## 재현성과 인계

- 팀 기준 OpenCV 3.4.15, MSVC 19.16 v141, C++17 Release 빌드 통과.
- 8방법×571장 = **4,568행 OOF 예측**, 40개 fold 모델, 전체 학습 개발용 QR+나사 계열 모델 4개 저장.
- 별도 결과 폴더에서 재평가한 predictions.tsv, summary.tsv, simulation.tsv, integrity.txt의 SHA-256이 일치했다.
- 기존 6개 방법의 OOF 예측은 최초 결과와 모두 동일했다. 바 결합 비교 때문에 대조군이 달라지지 않았다.
- 14특징과 18특징의 선형/2차 모델 모두 실제 이미지 입력 API와 저장 특징 예측 차이가 0이었다. 입력 영상 변경도 0이다.
- 기존 원본 측정과 분할을 재사용했다. 특징으로 평가를 재현하는 데 BMP는 필요 없고, 측정과 이미지 API 검증에는 원본 BMP가 필요하다.
- 모델 차원으로 14/18특징을 구분하는 `final_pin::Estimator`와 실행 명령은 [모듈 README](../20261104_1750_나사관측_YT동시추정후보/README.md), [실험 README](README.md)에 있다.

같은 반복 자세가 학습과 시험에 나뉠 수 있고 이미 개발에 노출된 자료를 추가 비교한 결과다. 이번 결과로 새 날짜 성능, 바가 항상 불필요하다는 결론, 실제 복귀 성능을 주장하지 않는다. 현재 자료의 우선 후보는 기존 QR+나사 선형으로 유지하고, 바 결합 모델은 별도 비교 후보로 보존한다.
