# 나사 실험 재개 결과, 2026-11-04

이 문서는 최초 6방법 비교 기록이다. 이후 요청한 **QR+나사+위·아래 바** 추가 비교는 [후속 결과 보고](REPORT_WITH_BARS.md)를 본다. 최초 결과 파일은 보존했다.

QR와 나사를 함께 쓰는 선형 후보는 무작위 이미지 5-fold 개발 평가에서 **569/571장, 99.65%**가 Y/T 기준을 동시에 통과했다. Y는 571장 모두 ±0.045 안이었다. T는 2장이 ±0.01을 조금 넘었다. 같은 분할의 v1 joint 재학습 대조군은 548장, v2 joint 재학습 대조군은 515장이 동시 통과했다.

**100% 달성이나 운영 모델 채택을 뜻하지 않는다.** 같은 자세의 반복 사진이 학습과 시험에 나뉘는 사용자 지정 분할이며, 이미 개발에 노출된 사진이다. 실제 로봇 복귀와 새 날짜 검증은 하지 않았다. 기존 운영 모듈은 보존했다.

## 실제 수행한 것

- OpenCV 3.4.15 vc15, MSVC 19.16, v141, C++17, Windows x64 Release 빌드.
- 원본 571장 각각의 실제 SHA-256과 기존 메타데이터 대조. center 4장은 평가 대상에서 제외하고 고정 center 1장을 관측 기준으로 사용.
- seed 20261104 무작위 이미지 분할. test는 fold 1에 115장, 나머지에 114장씩. train은 456/457장. 사진은 test에 정확히 한 번 배정.
- 네 나사와 QR 측정 모두 **571/571장 유효**, 측정 실패 0장.
- 후보 4개, 재학습 대조군 2개, 총 30개 fold 모델과 **3,426행 OOF 예측** 저장.
- 학습 전용 평균/척도와 모델 저장·재읽기, 실제 이미지 API와 저장 특징 예측의 일치 확인.
- 선형/2차 전방 세계 모델에 대해 각각 최대 20턴 시뮬레이션. 실제 재촬영 0회.
- 저장 특징만 복사한 별도 출력 폴더에서 재평가. 예측, fold 요약, 시뮬레이션, 무결성 기록의 SHA-256이 첫 실행과 동일함을 확인.

## 한 장 정확도

Y 허용오차 ±0.045 mm, T 허용오차 ±0.01 명령 단위. 모든 분모는 571장이다. 유효 예측만의 MAE와 전체 통과 수를 구분했다. 이번에는 측정 실패가 없어 유효 예측도 모두 571장이다.

| 방법 | Y 통과 | T 통과 | 동시 통과 | Y MAE | T MAE | Y 최대오차 | T 최대오차 |
|---|---:|---:|---:|---:|---:|---:|---:|
| v1 joint, forward GLS 재학습 | 549 | 556 | 548 | 0.01630 | 0.00305 | 0.20570 | 0.03868 |
| v2 joint, 2특징 선형 재학습 | 523 | 547 | 515 | 0.02112 | 0.00397 | 0.19637 | 0.04234 |
| 나사만, 선형 | 284 | 397 | 281 | 0.05258 | 0.00797 | 0.22219 | 0.03351 |
| 나사만, 2차식 | 326 | 436 | 323 | 0.04666 | 0.00687 | 0.21018 | 0.03103 |
| QR+나사, 선형 | **571** | **569** | **569** | **0.00832** | 0.00210 | **0.04128** | **0.01069** |
| QR+나사, 2차식 | 570 | 570 | 569 | 0.00802 | 0.00168 | 0.05972 | 0.01144 |

2차식은 평균오차가 더 작지만 큰 Y 오차가 남았다. 선형과 동시 통과 수가 같고 시뮬레이션 민감도도 더 컸다. 현재 자료로는 단순한 QR+나사 선형 후보를 다음 검증의 우선 대상으로 둔다. 이 우선순위 선택도 개발 자료를 본 결과이므로 새 성능 증거와 구분한다. 실패 2장을 맞추기 위해 계수나 문턱을 사후 조정하지 않았다.

v1/v2 대조군은 동일 분할 재학습 joint이며 기존 고정 모델의 점수를 그대로 옮긴 것이 아니다. 한 축을 고르는 control을 동시 추정 모델처럼 표시하지 않았다.

## Fold 간 흩어짐과 같은 자세의 반복

QR+나사 선형 후보의 동시 통과 수는 fold 순서대로 **115/115, 114/114, 113/114, 114/114, 113/114**였다. 통과율 범위 99.12~100%, 5개 통과율의 모집단 표준편차는 **0.43%p**다. 표본이 공유되는 교차검증 fold이므로 이 표준편차를 독립 시험의 신뢰구간으로 해석하지 않는다.

같은 날짜·자세 반복 그룹은 97개이며 92개 그룹이 여러 fold에 걸친다. 의도한 이미지 단위 분할이지만, 반복 그룹 독립 성능을 측정한 것은 아니다.

선형 후보의 같은 자세 OOF 예측 전폭은 Y 최대 **0.05373**, T 최대 **0.01168**이었다. Y 전폭이 0.045보다 큰 그룹은 97개 중 1개다. 그 그룹은 20261029 Y+0.05 T+0.76이며 Y 평균 중심 최대편차는 0.02754다. 전폭과 ±편차는 다르다. 사진별 Y 정확도가 모두 통과해도 더 엄격한 반복 전폭 기준까지 모두 통과한 것은 아니다.

여기에는 서로 다른 fold의 학습 모델 차이도 들어 있다. 실제 같은 자세로 5번 복귀시킨 단일 고정 모델의 반복정밀도를 대신하지 않는다. 모든 그룹의 수량과 전폭은 `results/repeat_spread.tsv`에 남겼다.

## 선형 후보의 실패 2장

| index / fold | 원본 | 정답 Y,T | 예측 Y,T | T 절대오차 |
|---|---|---|---|---:|
| 420 / 3 | clean_20261029/Y+0.05 T+0.32/Y+0.05 T+0.33 (3).bmp | 0.05, 0.33 | 0.05290, 0.31931 | 0.01069 |
| 308 / 5 | clean_20261020/Y+0.10 T+1.00/Y+0.1 T+1.0 (2).bmp | 0.10, 1.00 | 0.07132, 1.01049 | 0.01049 |

index 420은 이미 데이터 README에 기록된 **부모 폴더 T+0.32 / 파일명 T+0.33 불일치** 사진이다. 기존 규칙대로 파일명 T=0.33을 정답으로 유지했다. 예측이 0.32에 가깝다는 이유로 라벨을 바꾸거나 분모에서 빼지 않았다. 실제 자세는 촬영자의 확인이 필요하다.

2차 후보는 index 420의 T 오차 0.01144와 index 296의 Y 오차 0.05972가 남았다. index 296은 20261020 Y+0.05 T+2.00 반복 2번이다. 차수를 올린 것이 모든 범위에서 안전한 개선은 아니었다.

## 20턴 대리 모델 시뮬레이션

QR+나사 선형 후보는 선형 세계와 2차 세계에서 각각 **568/571 시작점**이 실제 잔차 Y ±0.045, T ±0.01을 만족하며 멈췄다. 두 경우 모두 평균 2.44턴, 최대 8턴이었다. 571개 모두 추정상으로는 멈췄지만 **3개는 실제 잔차가 범위 밖인 오정지**였다.

| 방법 | 선형 세계 실제 통과 | 2차 세계 실제 통과 | 선형/2차 오정지 |
|---|---:|---:|---:|
| v1 joint 재학습 | 547/571 | 544/571 | 24 / 27 |
| v2 joint 재학습 | 511/571 | 525/571 | 60 / 46 |
| 나사만 선형 | 271/571 | 292/571 | 300 / 279 |
| 나사만 2차식 | 259/571 | 278/571 | 312 / 293 |
| QR+나사 선형 | **568/571** | **568/571** | **3 / 3** |
| QR+나사 2차식 | 552/571 | 566/571 | 19 / 5 |

이는 train-only 전방 특징 모델, 고정 test 잔차, 이상적 이동, 추가 관측잡음 없음이라는 조건이다. 실제 로봇의 백래시, 복귀마다 달라지는 자세, 이동 후 사진과 처리시간은 검증하지 않았다. 실제 20턴 복귀 성공률 99.47%라고 부르면 안 된다. 또한 이번에는 두 축 동시 보정이며 기존 joint T→control Y 순서를 실기로 시험한 결과도 아니다.

## 수치 검증과 속도

- 기준 영상을 다시 측정한 나사 변위 최대값: **0픽셀**.
- 합성 이동 (+3.25, -2.375)픽셀의 최대 나사 측정 오차: **0.001059픽셀**.
- 선형/2차 이미지 입력 API와 저장 특징 기반 예측 차이: 모두 **0**.
- 입력 이미지 변경량: 모두 **0**.
- 5개 fold 모델 모두 저장 후 재읽기 예측 차이가 1e-10 이하.
- 별도 결과 폴더 재평가의 주요 TSV 3개와 integrity.txt 해시 일치. `results/reproducibility.json` 참고.

4개 이미지 작업을 동시에 처리한 이번 측정에서 QR·가로선 관측의 장당 중앙값은 약 1065ms, p95는 1242ms였다. 나사 추가 측정은 중앙값 **47.8ms**, p95 **66.1ms**였다. 이것은 동시 실행 중 측정된 관측 계산시간이며 단일 실행 지연, 디코딩 포함 전체시간이나 실제 로봇 정렬시간이 아니다.

## 다른 컴퓨터에서 이어갈 일

코드, 분할과 해시를 포함한 측정 특징, fold별 모델, OOF 예측, 시뮬레이션을 커밋한다. 원본 BMP와 빌드 캐시는 커밋하지 않는다. 저장 특징으로 학습·평가를 다시 실행하는 데는 원본 BMP가 필요 없다. 측정 재실행이나 실제 이미지 API 검증에는 별도 복사한 `data/clean/`이 필요하다.

1. 모델과 문턱을 고정한 상태로 새 촬영에서 QR+나사 선형 후보를 검증한다.
2. index 420의 실제 촬영 자세를 확인하고 라벨 이슈를 별도 기록한다. 확인 전에는 현재 결과를 유지한다.
3. 실제 이동·재촬영 로그로 20턴과 오정지를 검증한다. 이때 카메라·나사·QR가 기구적으로 어디에 고정돼 있는지도 확인한다.
4. 기존 문헌 정리의 누락 26개 파일은 인계 문서에 별도로 남아 있다. 이번 실험이 문헌 작업의 완료를 뜻하지 않는다.
