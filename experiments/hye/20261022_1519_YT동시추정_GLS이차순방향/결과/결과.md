# 결과: Y·T 동시 추정, GLS 선형·가산 이차 순방향 모델

입력: `data/clean/clean_20261014` 281장. center.bmp 의 QR 3개를 디코딩해 구조 모서리 755점을 정하고, 대각선을 뺀 630점을 사진마다 흐린 경계 모델로 맞췄다(진단 실패 566 / 176400, 진단 실패 점도 그대로 쓴다). 변위(사진 - center)를 [1,u,v,u²,uv,v²]로 최소제곱해 P12 특징 12개를 만든다.

QR 디코딩: QR1 multi, QR2 multi, QR3 margin 15px, scale 1. QR3 사각형은 OpenCV 3.4 에서 원래(cv2 5.0) 사각형과 최대 1px 다르다(처음 위치·격자 방향만 영향).

분할: StratifiedKFold(4, shuffle, 20261021)을 세션(T±, Y1±, Y2±)으로 층화해 C++에서 다시 만들었다(numpy MT19937 셔플 재현). 원래 splits.json 과 4/4 fold 동일.
모델: X = sY·Y + sT·T (+ cY·Y² + cT·T²), 절편 없음. 잔차 상관을 (1-s)C + sI 로 줄이고 GLS 백색화 후 최소제곱으로 (Y,T)를 푼다. 이차는 시작점 4개 LM 중 비용 최소.
설정 8개(선형/이차 x 수축 0.001, 0.05, 0.2, 1.0)는 학습 210장 안 3-fold(StratifiedKFold(3, shuffle, 100+fold))에서 (실패 수, 최대 오차, 평균 오차) 순으로 골랐다.
