# 결과: 0 근처 축 오판 -> 2단계 판정 (v7b)

입력: `data/clean/clean_20261014` 281장. 기준은 center.bmp 한 장이다. 모든 값은 사진에서 다시 쟀다.

1. 점: 흐린 center(σ1)의 QR 판에서 goodFeaturesToTrack(품질 0.01, 간격 17, blockSize 7)으로 고르고 포화 점을 뺀 QR 점 232개(좌 81 / 중 73 / 우 78).
2. 추적: 81x81 NCC(가로 ±110, 세로 ±16) -> 17x17 NCC ±4 + 포물선 -> 흐린 사진에서 가우스-뉴턴(dx, dy, 밝기 a, b, 3차 B-spline 보간, 15회).
3. 특징: center 기준 점 이동을 판 2차 다항 변형 12값으로 요약.
4. 축 판정: |Y|<=0.6mm, |T|<=0.12 사진만으로 학습한 1차 모델(절편 0), 값: 전체 사진 2차 모델. 둘 다 12값 잔차의 전체 공분산으로 화이트닝하고, 세로 이동·화면 회전 방해 무늬를 함께 푼다. 비용비 log(Y/T) < 0 이면 Y.
5. 학습 라벨 = 파일명 명령값, 채점 = 명령값.
