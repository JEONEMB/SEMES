# QR536 C++ 이식 검증 (2026-10-28)

사용자가 선택한 Python QR-only 536점 최종 후보를 그대로 이식했다. 새 모델 학습과 실패 사진별 튜닝은 수행하지 않았다.

- 환경: Windows x64, C++17, MSVC 19.16/v141, OpenCV 3.4.15 vc15, Release.
- 자료: clean_20261014의 Y80장 + T200장, 총280장. 센터는 초기화 기준이며280장 성적에 넣지 않는다.
- 실행: 원본 사진 디코딩부터 NCC/LK/GN/P12를 C++로 재측정. 동일한 C++ 특징에 최종 모델과 당시 해당 fold 모델을 각각 적용.
- 기준 수치: 원본 raw_features.npz를 순서 보존 CSV로 변환한 validation/python_features.csv, 원본 raw_predictions.csv.
- 수치 검사 기준: 특징 최대차와 예측 최대차 각각1e-4 이하, 모델만의 계산 차1e-10 이하, 축 일치. 통과 오차 기준은 원래0.09 그대로.

| 방식 | 축 구분 | 두 축 0.09 동시 통과 | Y 최대오차 | T 최대오차 |
|---|---:|---:|---:|---:|
| 원본 고정4-fold 모델 | 280/280 | 280/280 | 0.036550228959 | 0.002993403091 |
| 원본 최종 전수 모델 재대입 | 280/280 | 280/280 | 0.036372778873 | 0.002898078184 |

- Python 대비 P12 특징 최대차: 1.4268894510394148e-8.
- Python 대비 추정량 최대차: 2.668689713658523e-10.
- 같은 Python 특징을 넣은 모델 계산 최대차: 8.881784197001252e-16.
- 모든280장에서 고정536점의 진단 valid 수: 536.
- CTest 2/2 통과: 독립 control 링크·잘못된 입력·원본 불변·BGR/BGRA·초기화 실패 후 기존 상태 유지·joint 호환 호출·기존 T 분기.

`summary.json`의 y_mae/t_mae는 비활성 축도 포함한 **전체280장** 평균이다. `predictions.csv`는280장×2방식=560행이다. 이식 확인은 독립 신규 촬영 또는 실제20턴 로봇 복귀 검증이 아니다. 개발 후 선택된 기존 후보와 당시 분할을 재현한 결과다.

실행 `control()`은 validation의 fold 번호와 정답 파일명을 사용하지 않고 assets/model.json만 사용한다. 모델·기준점 출처는 assets/provenance.json, 파일별 해시는 delivery_manifest.json에 기록한다.
