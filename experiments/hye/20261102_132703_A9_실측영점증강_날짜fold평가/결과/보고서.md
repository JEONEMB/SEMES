# A9 보고서 — 실측 영점 기반 데이터 증강

실행: 2026-11-02 · 수치: [결과.md](결과.md) · 계획: [계획서](../계획서.md) · 가설: H12, H18 · 규칙 64행

- **문제:** 자극이 없는 영역을 합성으로 메우면 날짜 일반화가 나아지는가?
- **해결:** 학습 날짜만으로 생성기(특징 감도 + Y×T 결합항 + 잔차 재표집)를 만들어 441개 합성 표본을 더하고, 빠진 날짜에서 실측만 학습과 비교했다.
- **결과:** **효과가 없다.** 세 날짜 모두 차이가 소수점 넷째 자리다. 통과율은 0.0% → 0.0%, 81.3% → 79.2%, 96.2% → 97.0%다. **채택하지 않는다.**

## 1. 판정

| 빠진 날짜 | Y 최대오차 | 통과율 | 판정 |
|---|---|---|---|
| 1014 | 0.4479 → 0.4447 | 0.0% → 0.0% | 변화 없음 (최대오차 0.7% 감소는 잡음) |
| 1020 | 0.1994 → 0.1984 | 81.3% → **79.2%** | 악화 |
| 1029 | 0.0703 → 0.0707 | 96.2% → 97.0% | 변화 없음 |

계획서의 채택 조건은 "최대오차가 줄고 통과율이 떨어지지 않음"이었다. 1014에서 형식상 만족하지만 **통과율이 양쪽 다 0%**라 의미가 없다. **기각한다.**

## 2. 왜 효과가 없는가

증강은 **자극을 새로 만들지 못한다.** 이미 아는 물리(특징 감도 B)를 다른 (Y,T)에 옮겨 놓을 뿐이다. 그래서 생성기의 품질은 B의 품질에 묶인다.

1014를 뺀 경우를 보자. B는 1020·1029에서만 나온다. 그런데
- 1029는 Y가 +0.05 하나로 고정이라 **∂f/∂Y 를 전혀 주지 못한다.**
- 1020은 Y가 5종(0, 0.05, 0.10, 0.50, 1.00)뿐이고 전부 0 이상이다.

그러니 B의 Y 열이 이미 나쁘다. 그 나쁜 B로 Y를 −2.00까지 합성해 봐야 **같은 오차를 441번 더 쓰는 것**이다. 학습 표본 수는 늘지만 정보는 늘지 않는다. 실제로 1014 성적이 그대로인 것이 그 증거다.

1029를 뺀 경우는 반대 이유로 효과가 없다. 남은 1014·1020이 이미 1029의 영역을 덮고 있어(A3: 96.2%) 메울 결손이 없다.

### 자극이 정해져 있다는 말의 가장 분명한 증거

A3은 "1014를 빼면 0%"를 보였고, A9는 "합성으로도 못 메운다"를 보였다. 둘을 합치면 결론은 하나다. **빠진 것은 데이터 양이 아니라 자극이다.** 양은 합성으로 늘릴 수 있지만 자극은 로봇을 실제로 움직여야 생긴다.

그러므로 **B 단계 촬영이 선택이 아니라 필수**다. 특히 B4(넓은 T 스윕), B5(폐루프, Y 방향 탐색 포함), B6(독립 날짜)이다.

## 3. 생성기가 규칙을 지킨 방식

규칙 64행이 요구한 것들을 지켰다.

| 요구 | 구현 |
|---|---|
| 균등 노이즈 대신 실측 영점 | 학습 사진의 모델 잔차를 **행 단위로 재표집**했다 |
| 판 전체 평행이동이 아니라 점별 변위 | 특징(QR별 아핀 18 + 선 48)을 통째로 합성했다 |
| 반복 잡음 공분산 반영 | 잔차 행을 그대로 가져와 A1이 잰 상관 구조(N_eff 19)가 유지된다 |
| Y×T 결합항을 0으로 두지 않음 | 생성 모델에 `C·Y·T` 항을 넣었다 |
| 합성과 실측 구분 표시 | 평가에서 합성은 **학습에만** 쓰고 시험에는 넣지 않았다 |
| 학습 날짜 자극 범위 밖으로 외삽 금지 | 격자를 학습 사진의 (Y,T) 최소·최대 안에서만 깔았다 |

## 4. 한계

- 합성은 **특징 수준**이다. 영상이 아니다. 측정 단계의 실패(점 깨짐, 반복 무늬 오대응, 조명 변화)는 재현되지 않는다. T+2.00에서 본 유효점 붕괴 같은 현상은 증강이 전혀 다루지 못한다.
- 생성기의 감도 B를 선형 + Y×T 하나로 두었다. A2가 찾은 Y의 2.7% 비선형은 반영하지 않았다.
- 잔차 재표집은 학습 날짜의 잔차 분포를 그대로 쓴다. 빠진 날짜의 영점이 학습 날짜와 다르면(A1: 1014→1020 dy 0.44 px) 그 차이는 합성에 들어가지 않는다.
- 증강으로 나온 어떤 수치도 실측 추정 성적이 아니다.
