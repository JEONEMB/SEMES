# 전달 패키지 작업 규칙

상위 AGENTS.md의 문자 규칙을 이 패키지 전체에 적용한다.

## 금지 문자

1. 이모지와 장식용 기호를 사용하지 않는다. 상태는 [완료], [주의], [실패]로 쓴다.
2. U+00B7, U+318D, U+2022, U+2013, U+2014를 사용하지 않는다.
3. 답변, 코드, 주석, README, 문서, 콘솔 출력, TXT 로그에 같은 규칙을 적용한다.
4. 함수 주석은 하는 일, 입력, 출력 순서로 작성한다.
5. 하위 단계 이름은 현재 구현과 맞춘다. 나사 검출 단계는 정확도와 속도 검토에 따라 바뀔 수 있으므로 이전 설명을 그대로 복사하지 않는다.

## 완료 전 검사

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/check_text_style.ps1
```

- 검사 실패를 무시하고 완료를 보고하지 않는다.
- 출력 문자열을 바꿨으면 해당 실행 파일을 빌드하고 실제 콘솔 출력과 새 로그도 검사한다.
- 검사 대상은 현재 체크아웃의 텍스트 파일 전체다. 숨김 문서와 미추적 문서도 포함한다.
- .git, 다른 작업자의 .claude 작업 트리, build, 과거 data/results는 현재 소스 검사에서 제외한다. 새 실행 결과는 -Path 인자로 따로 검사한다.
- PDF, Word, 이미지에 들어 있는 문자는 이 텍스트 검사로 검증되지 않는다. 그런 파일을 납품할 때에는 원본 수정 후 재생성하여 별도 검수한다.
- 알고리즘 변경 없이 문구만 바꾼 경우에도 수정 범위와 검사 결과를 명확히 보고한다.
