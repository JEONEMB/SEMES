# 학습 범위 초과는 경고만 반환

2026-11-16 사용자 요청으로 W_OUT_OF_RANGE를 Action::Correct로 변경했다. 학습 범위 초과만으로는 측정 또는 보정을 막지 않는다. 유효한 영점과 정상 검출 조건에서 3.00 mm를 포함한 범위 밖 결과도 반환하고 correction_allowed=true로 처리한다.

경고는 정확도가 떨어질 수 있음을 알린다. 모델 계수와 학습 범위를 바꾸거나 측정값을 잘라내지 않았다. 정확도 보장은 별도 검증 대상이다.

실제 검출 실패, 유효하지 않은 입력, 영점 미설정, 나사 정보 부족, 값 일치 점검 실패 등 다른 차단 조건은 그대로 유지한다. 여러 알림이 겹치면 범위 경고가 다른 차단을 해제하지 않는다. 진단 API는 계속 보정을 허용하지 않는다.

호출부는 status가 Ok인지 여부만으로 보정을 결정하지 않고 correction_allowed를 사용한다. Warning은 실패와 다르다. 이번 변경은 로컬 패키지에 적용했으며 라즈베리파이 배포는 별도다.
