# 결과: 0점 정렬 5방법 (Y, Θ 각각)

입력: `data/clean/clean_20261014` 281장 (center 1, Θ 200, Y 80). 촬영 시각은 `data/raw/zip_20261014.zip` 안 분할 zip의 NTFS 수정 시각(원래 스크립트의 파일 수정 시각과 같은 값)이고, 가장 이른 사진(center) = 0분이다.

측정: x = QR 세 개의 중심 가로 이동 평균(px, center = 0). 세 QR 영역(180x192 px)을 템플릿 매칭 후 ECC affine으로 정합했다(시범 실험과 같은 측정). 증인 방법(②)의 볼트 이동은 오른쪽 아래 볼트 64x64 px 영역을 ECC 평행 이동으로 쟀다. 원래 입력 `14_데이터_QR마커위치.csv`, `15_데이터_파인더_볼트이동량.csv`를 만든 코드는 남아 있지 않다.

모델: x_i = k v_i + o_i. 단위 환산 Y 1 µm = 0.01425 px (14.249 px/mm), Θ 0.001 = 0.08006 px (80.062 px/deg). 볼트/QR 비 rY = 0.759, rΘ = 1.122.
CV: 축마다 촬영 순서 짝수 번째로 맞추고 홀수 번째를 채점, 반대로도 해서 두 쪽 잔차를 합친 RMS.

## 옮기지 않은 부분

- 원래 그림(34·35번, matplotlib 3행 x 6열)은 OpenCV 차트 4장(01~04)으로 나눠 그렸다. 촬영 경로 화살표는 빼고 시간순 회색 선으로 이었다.
- 14·15번 CSV의 QR 박스 폭·높이, 파인더 위치는 이 실험에서 쓰지 않아 재지 않았다.
