# B5 실험 계획서 — 실기 폐루프 복귀

가설: **H16**(탐색 이동), **H17**(제어가 병목) · 상태: **촬영 대기 / 장비 점유 필요**
작성: 2026-11-02 · 선행: [A7](../20261102_132128_A7_탐색이동효과_조건쌍오프라인/결과/보고서.md), [A8](../20261102_132456_A8_사진별불안정판정_예측시그마교정/결과/보고서.md)

## 1. 묻는 것

**실제로 측정 → 이동 → 재촬영을 반복해 20턴 안에 센터에 도달하는가?** 도달했을 때 잔여 오차는 얼마인가?

## 2. 왜 기존 자료로 안 되는가

**정지 사진 성적은 복귀 성공률이 아니다.** 규칙 62행이 이것을 명시한다.

A7은 짝 추정이 최대오차를 55% 줄인다는 것을 보였지만, **서로 다른 시점의 정지 사진을 짝지은 오프라인 조합**이다. 실제 이동에 따르는 백래시·정지 오차·드리프트가 전부 빠져 있다. 그리고 A7에서 효과가 컸던 것은 **ΔY 짝(10개뿐)**인데, 1029는 Y 고정, 1020은 Y 5종이라 더 만들 수 없다.

A8은 "측정 품질로는 어느 사진이 틀릴지 알 수 없다"(순위 상관 0.08 이하)를 보였다. 그러니 **턴을 돌려 봐야** 안다.

## 3. 촬영 / 운전 요청

| 항목 | 값 |
|---|---|
| 시작 자세 | 무작위 **30개**. Y와 T를 모두 포함하고 **음수 방향도 넣는다** |
| 절차 | 촬영 → 추정 → 이동 → 재촬영을 반복 |
| 종료 | 두 축 추정이 모두 ±0.045 안이거나 **20턴** 도달 |
| 매 턴 기록 | 영상, 추정값, 보낸 명령, 실제 실행값(알 수 있으면), 시각 |
| 독립 기준 | 가능하면 정지 시 외부 기준기로 잔여 오차 측정 |
| 합계 | 30자세 × 평균 5턴 ≈ **150~600장** |

### 턴 세는 법 (규칙 43행)

첫 관측은 0턴. 이동과 그에 뒤따르는 관측 1회가 1턴. 정지 확인용 추가 촬영도 어떻게 세었는지 공개한다.

### 탐색 이동 분기

A7·A8을 합친 정책을 함께 시험한다.

| 정책 | 내용 |
|---|---|
| 기본 | 매 턴 단일 사진으로 추정하고 이동 |
| 조건부 탐색 | GN 잔차 p95가 상위 10%에 들면 **Y 방향으로 알려진 이동 1회**를 넣고 두 사진으로 추정 |

두 정책을 각각 15자세씩 돌리면 비교가 된다.

## 4. 판정 기준 (운전 전 고정)

| 조건 | 판정 |
|---|---|
| 턴 수 중앙값과 p95 | 운용 목표를 "20턴 이내"보다 구체적으로 다시 정한다 (Lee 2013: 보정 3회 이내, 1초 미만) |
| 정지 시 잔여 오차가 ±0.045 안 | 성공 |
| 진동(같은 자리를 왕복)이 보임 | **H17 성립.** 이득 g를 Chaumette 조건으로 다시 정한다 |
| 단일 사진 오차는 작은데 턴이 길다 | **H17 성립.** 병목이 추정이 아니라 제어다 |
| 조건부 탐색이 턴 수나 실패를 줄임 | **H16 성립.** 정책에 넣는다 |

## 5. 분석 방법

1. 턴별 오차 궤적을 그린다. 수렴·진동·정체를 분류한다.
2. 수렴 비율 ρ(I − GWJ)를 실측 궤적에서 추정하고 Chaumette의 안정 조건과 비교한다.
3. 독립 기준기가 있으면 영상 추정과 실제 위치의 차이(절대 정확도)를 낸다.
4. 두 정책의 턴 수 분포를 비교한다.

## 6. 안전과 범위

- A3이 보인 대로 **T+2.00에서는 측정이 깨지고 추정도 무너진다**(통과 0%, Y 최대 1.90). 시작 자세를 운용 범위(T ≤ 1.00) 안에서 고르거나, 범위 밖에서는 실패를 반환하도록 먼저 고쳐야 한다.
- 현재 코드는 범위 밖에서 **조용히 틀린 값**을 낸다. B5 전에 실패 반환 경로를 넣는 것을 권한다.

## 7. 한계

- 30자세는 통계적으로 넉넉하지 않다. 실패가 0이어도 95% 상한은 약 10%다.
- 독립 기준기가 없으면 "정지 시 잔여 오차"도 영상 자기 평가다.
- 이 시험의 성적은 **그 날의 장비 상태**에 묶인다. 날짜 일반화는 B6에서 본다.
