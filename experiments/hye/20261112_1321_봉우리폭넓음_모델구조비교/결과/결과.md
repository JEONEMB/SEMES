# 결과: 봉우리 폭 넓음, 모델 구조 비교 (11-12)

## 문제

Y-T 데이터 분포에서 라벨별 봉우리(OOF 오차 σ)가 넓어 이웃 라벨과 겹쳤다. 현재 Huber66은 σY 0.0139 mm, σT 0.0032로, 이웃과 헷갈리지 않으려면 대략 σY 0.0096, σT 0.0019가 필요했다.

## 방법

- 자료: 커밋 46152fd `experiments/hye/00004_final_Y_T/evidence/training_features.tsv`의 66개 특징. 영상에서 다시 재지 않았다.
- 정정: ID 420 라벨 T 0.33→0.32(원본 T+0.32 폴더, 동봉 TXT, 촬영 시각 근거), ID 702 학습·평가 제외(4차 아웃라이어). `apps/distribution/reoof.py`와 같은 조건이다.
- 평가: 같은 그룹 5-fold OOF, 00004 Huber 학습식(train 표준화, ridge 1e-7·n, 공유 Huber 가중 6회). 주성분·표준화·계수는 학습 fold에서만 구했다.
- 이웃 판정은 모든 후보를 현재 모델 Σ 하나로 센다(후보별 Σ를 쓰면 σ가 큰 모델이 유리해진다).
- 교란: 00004 README와 같은 숫자 교란(네 나사 x 에 모두 +0.5 px)을 시험 fold 특징에만 넣었다.
- 실행: 저장소 루트에서 `python "experiments/hye/20261112_1321_봉우리폭넓음_모델구조비교/실험/compare.py"` → `결과/결과.tsv`

물리 성분은 공통 이동(QR 평균 dx, dy), 시차(나사 평균 − QR 평균, x와 y), QR3 − QR1 가로 이동 차, 바 기울기 평균의 6개다.

## 해석

- 비선형항은 **T만** 줄였다(σT 약 −25%). T 오차에 라벨에 따른 S자 휨이 있던 것과 맞는다. Y는 줄지 않았다. Y의 자세별 고정 몫은 모델 모양보다 명령과 실제 자세의 차이(백래시, 드리프트) 쪽일 가능성이 크다(추정).
- 주성분 8개 2차항이 가장 좋았지만 8은 몇 개만 시험한 값이다. 3차항까지 넣으면 과적합으로 나빠진다.
- 나사 +0.5 px 교란에는 모든 후보가 무너졌다. 나사−QR 시차가 Y 한 칸(0.05)에 −0.155 px라, 나사 0.5 px 어긋남은 Y 약 3칸과 같은 모양이다. 모델 모양으로 피할 수 없고, 나사 위치를 기준 사진으로 다시 영점 잡는 쪽으로 다뤄야 한다.
- 같은 자세 반복 사이 흔들림은 QR과 나사가 거의 같이 움직인다(상관 0.97, 각 0.085, 0.093 px). 나사−QR 차이에서는 0.022 px로 줄어 Y 0.14칸에 해당한다.
