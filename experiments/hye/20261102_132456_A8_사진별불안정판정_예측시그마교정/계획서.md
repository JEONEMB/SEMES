# A8 실험 계획서 — 사진별 불안정 판정

규칙: ALGORITHM_RULES 39~45행 (불안정 판정 후 탐색 이동) · 우선순위: 중
작성: 2026-11-02 · 입력: [A0 캐시](../20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache)

## 1. 묻는 것

**이 사진의 추정을 믿을지 사진마다 미리 알 수 있는가?**

A7이 보였다. 탐색 이동은 평균에는 도움이 안 되고 최악의 경우에만 효과가 있다(최대오차 55% 감소, 통과율 변화 없음). 그러니 **항상 탐색하는 대신 불안정한 사진만 골라 탐색해야** 비용이 맞는다. 고르려면 사진마다 신뢰도를 매겨야 한다.

## 2. 후보 지표

측정에서 바로 나오는 양과 모델에서 나오는 양을 모두 본다. 정답을 쓰지 않는다.

| 지표 | 출처 | 왜 쓰나 |
|---|---|---|
| 유효 선택점 수 | A0 캐시 | 점이 깨지면 측정이 나쁘다 |
| 최소 NCC | A0 캐시 | 템플릿 정합 품질 |
| 유효 선 블록 수 | A0 캐시 | 선 관측 품질 |
| GN 잔차 중앙값·p95 | A0 캐시 quality 열 | 점별 정합 잔차 |
| **물리 모델 잔차** | 관측 d 와 J·q̂ 의 차를 Σ⁻¹ 가중한 값 | 2자유도 모델로 설명 안 되는 양. 자세가 모델 밖이면 커진다 |
| **예측 σ** | 그 사진의 유효 점으로 다시 계산한 F⁻¹ | 이론 하한 |

## 3. 단계별 방법

1. 사진마다 위 지표를 낸다. 정답은 쓰지 않는다.
2. A6의 기준 모델(M0) OOF 오차와 각 지표의 **순위 상관**을 낸다.
3. 물리 모델(M3)의 예측 σ로 z = e / σ 를 만들고 분포를 본다.
4. "상위 10%를 탐색 대상으로 고른다"고 했을 때, 그 10%가 실제 오차 상위에 얼마나 들어 있는지(적중률)를 낸다.

## 4. 판정 기준 (실험 전 고정)

| 조건 | 판정 |
|---|---|
| z의 표준편차가 0.7~1.4 | 예측 σ를 그대로 판정에 쓸 수 있다 |
| 그 밖 | 예측 σ를 판정 기준으로 쓰지 않고 이유를 기록한다 |
| 어떤 지표의 \|순위 상관\| > 0.5 | 그 지표를 불안정 판정에 쓴다 |
| 상위 10% 선별의 오차 상위 10% 적중률 > 0.3 | 조건부 탐색이 쓸모 있다 |
