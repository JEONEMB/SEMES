# 결과: 패치 이동장으로 Y/Θ 판정

입력: `data/clean/clean_20261014` 281장. 폴드는 축마다 촬영 순서(`data/raw` zip의 수정 시각)로 번갈아 나눴다. 시험 280장, center는 학습에만 쓴다.

1단계 기준 영상: 사진마다 판(1532..2269 x 947..1190) ECC 호모그래피로 구한 귀퉁이 이동을 판 영역(1420..2392 x 948..1192)에 적용해 center 좌표로 되돌리고(가우스 흐림 sigma 1, 3차 스플라인 보간), 학습 폴드 사진을 평균했다.

2단계 패치: 32x32 px, 16 px 간격. 구조 텐서 작은 고유값이 QR 패치 중앙값의 0.1배 이하면 뺐다. 나사 중심 (1491.9, 1066.6), (2317.4, 1071.9), 반지름 52 px.

3단계 측정: PC = 48 px Hann 창 위상 상관(1/100 px 업샘플, 정규화 없음), PC+GN = PC에서 출발한 가우스-뉴턴(3차 스플라인, 밝기 a, b, 최대 10회).

4~7단계: 패치 성분마다 d = s v (+ c v^2) + b 를 축별 학습 사진(center 포함)으로 맞추고, 가중 = 1/잔차 분산(하한 0.003 px). 새 사진은 Y 가설과 Θ 가설을 각각 Huber(3) 가우스-뉴턴으로 풀어(방해 무늬: 세로 평행 이동, 화면 회전) 비용이 작은 쪽을 고른다. 보정본 라벨 = 명령값 + o/k (#12의 ① 백래시+드리프트를 학습 폴드로만 맞춤). 0.09 통과: 축을 맞히고 |오차|<=0.09, 축을 틀리면 참값과 예측이 둘 다 0.09 안일 때만 통과.
