# 영점 방식 교차 실험 — 실행 전 고정 계획

사용자 요청: joint에 복수 영점, control에 단일 영점을 적용하고 같은 평가 루프로 비교한다. 기존 활성 모듈과 assets는 변경하지 않는다.

- 입력: 20261104_123000 실험의 571장 측정 캐시와 기존 그룹 5-fold. 같은 그룹의 반복 사진은 같은 fold다. 영상 측정은 동일하게 유지한다.
- joint: J204·전방 1차 GLS·공분산 축소 .01 유지. 단일 공통 절편 대 세션별 절편과 공통 Y/T 응답을 비교한다. 세션별 절편 후보는 1014 여섯 trial와 1020/1029 날짜별 절편이다. 시험 시 세션/정답을 주지 않고 GLS 잔차 최소 후보를 선택한다.
- joint 10후보 보조 실험: 1014 학습 trial 6절편 + 실제 center 사진 4개의 J204 관측을 후보로 사용한다. 이는 보정용 center를 추가 제공한 조건으로, 학습 데이터만 사용하는 8후보와 분리한다. center는 성능 평가 분모에 포함하지 않는다.
- control: 최신 규칙대로 T=0 80장만 학습·주 평가한다. 기존 T0 변형의 Y 4절편 대 학습된 공통 절편 1개 대 center 원점 0 고정 1개. 공유 이차 반응·공분산 축소 .05·곡선 역산을 유지한다. 단일 절편은 부호 게이트 없이 한 곡선을 역산한다. 기존 6후보 배포 모델 그대로의 OOF는 아니다.
- 주 지표: joint |eT|<=.01, control |eY|<=.045. 평균·최대오차, fold, 날짜, 잔여 T별 결과를 함께 저장한다. 정답은 파일명 명령값이다.
- 강건성: 1014 각 trial를 통째로 제외해 미관측 영점 구간 평가(LOSO). control은 T0 Y trial 4개에서만 평가 가능. joint 날짜 통째 제외 평가도 실행한다.
- 실제 center4장을 학습 사진에서 제외한 채 예측한다. 1014 center는 원래 영상 기준 자체이므로 독립 시험이 아니고, 1020 center3장은 동일 날짜 반복으로 독립 영점 3종이라고 볼 수 없다. 10후보 모델은 이 center들을 후보로 제공했으므로 center 적합도는 일반화 성적으로 주장하지 않는다.
- 영점10개는 실제 center4장과 외삽 영점6개다. 외삽값은 해당 fold의 학습 자료만으로 추정하며, 10개의 독립 새 촬영 세션으로 해석하지 않는다.
- 기존 평가 결과와 baseline 예측의 일치 여부를 자동 검사한다. 결과·모델·사진별 예측을 새 results에 저장한다. 실제 이동 루프는 실행하지 않는다.
