# 결과: ssafy 방식과 ssafy_2 방식의 강건성 비교 (11-13)

## 문제

우리 장비 모델 두 개(`00000_final_Y_T_ssafy`, `00000_final_Y_T_ssafy_2`)의 강건성을 같은 시험 사진, 같은 정답으로 비교했다. 데이터 줄이기, 폴드 검정, 범위 밖 예측, 다른 날, 값 교란, 계수 안정성.

## 방법

| 항목 | 내용 |
|---|---|
| A = ssafy 방식 | 11-12 사진(rig_1st, rig_grid)만, 라벨 L2 |
| B = ssafy_2 방식 | 11-12 + 11-13 역순, 라벨 = 격자는 정방향·역순 같은 자세 평균(avg), rig_1st 는 L2 |
| 학습식 | 값 7개, Huber 6회, ridge 1e-7·n (두 방식 같음) |
| 공통 시험 | ssafy_2 분할의 마지막 확인 728장(자세 묶음 20%, 세 세트). 어느 시험에서도 학습에 안 씀 |
| 공통 정답 | `data/labels/rig_20261113_avg/labels.tsv`. 정답 자체 잡음(라벨 − 영상 자세)이 σT 4.3 mdeg 라 상한이 100% 가 아니다 |
| 통과 | \|eY\| ≤ 0.045 mm 그리고 \|eT\| ≤ 0.01 도 |
| 코드 | `실험/robustness.py` (Python 분석. 학습식은 C++ 결과와 같은 값을 내는 것을 앞 실험에서 확인) |

## 결과

| 시험 | A ssafy | B ssafy_2 |
|---|---|---|
| 0 전체 학습 → 공통 시험 728장 | **99.6%** (탈락 3), σY 14.6 µm σT 4.2 mdeg | 99.0% (탈락 7), σY 11.1 σT 3.7 |
| 1 데이터 줄이기 15장 / 30장 / 60장 / 120장 (20회 평균) | 93.0 / 97.7 / 98.9 / 99.4% | 93.9 / 97.8 / 99.1 / 99.2% |
| 2 폴드 검정 5조각 × 10회 (2910장) | **탈락 7.2장** | 탈락 15.3장 |
| 3a 안쪽(\|Y\|≤1, \|T\|≤0.5)만 학습 → 바깥 537장 | 99.4% | 98.3% |
| 3b Y<0 만 학습 → Y>0 | 100.0% | 99.1% |
| 3c **T<0 만 학습 → T>0** | **84.8%** | **69.9%** |
| 4 다른 날 (11-12 학습 → 11-13 역순 1679장) | **99.8%** | 해당 없음 (두 날 모두 학습) |
| 5 값 교란 최소 | 82.9% (나사 하나 +0.3 px) | **90.5%** (QR 하나 +0.3 px) |
| 5 QR 하나 +0.3 / QR 잡음 0.1 | 86.7 / 95.6% | 90.5 / 97.5% |
| 5 나사 하나 +0.3 / 나사 잡음 0.1 | 82.9 / 94.1% | 92.1 / 96.7% |
| 5 바 기울기 하나 +10% 표준편차 | 99.2% | 98.6% |
| 6 계수 안정성 (복원 추출 30회, 예측 흔들림 중앙값) | Y 0.9 µm, T 0.15 mdeg | Y 0.6 µm, T 0.18 mdeg |

세트별(시험 0): A 는 rig_1st 98.2%, rig_grid 99.7%, rig_grid_rev 99.7%. B 는 94.6%, 99.1%, 99.7%. B 의 rig_1st 가 낮다(56장 중 3장).

## 해석

- 기본 정확도는 같은 수준이다(99.0~99.6%). 정답 잡음이 바닥을 정한다. 통과 수는 A 가, 흩어짐은 B 가 조금 낫다.
- 데이터가 적어도 버틴다. 두 방식 모두 60~120장이면 99% 에 닿고, 15장이면 93% 로 떨어진다.
- 계수는 안정하다. 학습 자료를 바꿔도 예측이 1 µm, 0.2 mdeg 안에서 흔들린다.
- **약점 1. T 범위 밖 예측.** T 한쪽(−)만 배우면 반대쪽(+)에서 A 85%, B 70% 다. Y 는 반쪽만 배워도 99~100% 다. T 와 값의 관계가 범위 전체에서 한 직선이 아니거나(스테이지 곡선, 원근), 정답의 T 곡선 몫이 있다. 학습 자료는 T 전 범위를 덮어야 한다.
- **약점 2. 값 하나가 0.3 px 틀어지면 떨어진다.** A 는 나사 하나 +0.3 px 에 83%, B 는 92% 다. 두 날 자료로 배운 B 가 값 하나에 덜 기댄다.
- A 는 처음 보는 날(11-13)에 99.8% 로 확인됐다. B 는 그런 시험이 아직 없다.

## 한계

- 정답은 영상 값에서 만든 라벨이다. 독립 정답이 아니다. A 는 학습 라벨(L2)과 시험 정답(avg)이 달라 불리할 수 있고, B 는 같은 종류라 유리할 수 있다.
- 값 교란은 측정값에 숫자를 더한 것이다. 사진을 바꿔 다시 잰 것이 아니다.
