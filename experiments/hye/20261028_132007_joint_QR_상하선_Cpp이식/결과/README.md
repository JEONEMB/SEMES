# 2026-10-28 / 01 / QR+위·아래 선 joint C++ 이식

## 기록 내용

아래 `snapshot/`과 `snapshot_manifest.json`은 [실험 방법](../실험) 폴더에 있다.

- `snapshot/module/`: 당시 joint C++ 구현, 측정 설정, 기준 영상, 동결 모델, 검증 결과와 설명.
- `snapshot/repository_context/`: 당시 공개 헤더, 호출부, 호환 함수, 루트 CMake, 검사·평가 도구.
- `snapshot_manifest.json`: 모든 보존 파일의 원래 위치와 SHA-256 대조 결과.

23개 파일을 바이트가 동일한 사본으로 보존했다. 원래 전달 폴더와 기존 결과는 지우거나 이동하지 않았다.
이 기록은 정리 시점의 스냅샷이며 이후 전달 폴더를 수정해도 덮어쓰지 않는다.

## 해석과 복원

기존337/341은 개발 교차검증이다. 여기에 기록된 C++341장 재생은 전수 학습 모델의 재대입 검사다.
두 수치를 같은 성적이나 실제 로봇 복귀 성능으로 해석하지 않는다.

스냅샷은 원문 바이트를 보존했으므로 내부 README·CMake의 상대 경로는 원래 저장소 배치를 기준으로 한다.
이 폴더 자체를 독립 빌드 프로젝트로 검증했다고 주장하지 않는다.
복원할 때는 `snapshot_manifest.json`의 `source_repository_relative`에 대응하는 배치를 사용한다.
2차 신규 모델의 당시 구현은 [같은 날짜의02 기록](../../20261028_132007_control_T0_조건부Y_신규모델_미채택/결과/README.md)에 있다.

현재 선택 기준은 [ALGORITHM_RULES.md](../../../../ALGORITHM_RULES.md)를 따른다.
