# A22 보고서: control_v2 후보 비교

실행 2026-11-04 · 입력: A0 캐시(control 측정기, 고정 536점), A21 바 기울기 차 d, A10 v1 control 출력 · 기준: 한 장 `|eY| ≤ 0.045`

- **문제:** v1 control은 남은 T에 약하다(T 1단위 ≈ Y 5.6 mm). 1차 후 남은 T가 0.01~0.03이어도 Y가 기준을 넘는다.
- **해결:** 특징 [s], [s, d], [P12, d], [s, d, s·d], [P12] × ridge 2종, 학습 범위 \|T\| ≤ τ 제한 5종, 문턱 보정 y = f0(s) − k·soft(t^, θ) 5종을 같은 분할로 비교했다.
- **결과:** **문턱 보정**이 가장 좋다. θ = 0.0075에서 1014 Y 단독 80/80(최대 0.029), 1014만 학습 → 다른 날 남은 \|T\| ≤ 0.03 18/18(v1 12/18), ≤ 0.1 46/48(v1 12/48). 모듈에는 잡음 강건성(A23)을 함께 보고 θ = 0.01을 썼다.

| 모델 | 1014 Y 단독 (4-fold) | 다른 날 \|T\|≤0.03 | \|T\|≤0.1 | 날짜 층화 \|T\|≤0.1 | dY/dT |
|---|---|---|---|---|---|
| v1 | 80/80, 0.037 | 12/18, 0.117 | 12/48 | 75.7% | −1.76 |
| [s, d] 전 범위 학습 | 75/80, 0.072 | 17/18 | 43/48 | 86~88% | −0.015 |
| [s, d] \|T\|≤0.03 학습 | 80/80, 0.045 | 18/18 | 20/48 | 67~70% | 1.92 |
| [P12, d] | 75/80 | 0/18 | 0/48 | 93~95% | −0.003 |
| **문턱 보정 θ=0.0075** | **80/80, 0.029** | **18/18, 0.033** | **46/48** | **91.2%** | −0.015 |
| 문턱 보정 θ=0.01 | 80/80, 0.029 | 18/18, 0.037 | 44/48 | 88.5~89.2% | −0.015 |

- P12에는 세로 성분(카메라 이동)이 섞여 다른 날짜로 넘어가지 못한다.
- 전 범위로 학습한 [s, d]는 T에 강하지만 바 기울기 잡음이 Y로 번져 T = 0 정밀도가 떨어진다. 문턱 보정은 남은 T가 잡음보다 클 때만 빼서 두 장점을 합친다.
