# A7 실험 계획서 — 알려진 탐색 이동의 효과 (오프라인)

가설: **H16**(탐색 이동이 모호성을 해소) · 우선순위: 상
작성: 2026-11-02 · 입력: [A0 캐시](../20261102_124309_A0_분할측정고정_계층분할과점측정캐시/결과/cache)

## 1. 묻는 것

A2·A3이 확인했다. 오차는 ΔY = −5.617ΔT 한 방향에 몰린다. **알려진 상대 이동을 한 번 주고 다시 찍으면 그 방향이 풀리는가?**

## 2. 쓸 수 있는 자극 — 이 실험의 가장 큰 제약

실제로 "이동 후 재촬영"한 자료는 **없다.** 서로 다른 시점에 따로 찍은 정지 사진을 짝지어 쓸 뿐이다.

| 짝 | 자료 | 명령 차 | 개수 |
|---|---|---|---|
| 1029 이웃 T | 같은 Y(+0.05), T가 0.01씩 다른 이웃 조건 | ΔT = 0.01, ΔY = 0 | 77쌍 × 반복 |
| 1029 건너뛴 T | ΔT = 0.05, 0.10 | ΔY = 0 | 다수 |
| 1020 같은 Y | 같은 Y, T가 다른 조건 | ΔT 여러 값, ΔY = 0 | 제한적 |
| 1020 같은 T | 같은 T, Y가 다른 조건 | ΔY 여러 값, ΔT = 0 | 제한적 |

**ΔY와 ΔT를 모두 주는 짝은 사실상 없다.** 1029는 Y가 고정이고, 1020은 격자가 성기다. 따라서 이 실험은 **"T 방향 탐색 이동"의 효과만** 잴 수 있다. Y 방향 탐색은 B5 촬영이 필요하다.

## 3. 단계별 방법

1. 짝 (i, j)를 만든다. 같은 세트, 알려진 명령 차 Δcmd = (ΔY, ΔT). 두 사진의 **반복 번호가 다른 조합**까지 쓰되, 같은 묶음끼리는 짝짓지 않는다(명령 차가 0이면 정보가 없다).
2. 두 추정기를 같은 시험 사진에 대해 비교한다.
   - **단일:** 특징 f(i) → (Y, T)
   - **짝:** 특징 [f(i), f(j) − f(i), Δcmd] → (Y, T)
3. 분할은 A3과 같다. 짝의 두 사진이 **모두 학습이거나 모두 시험**이 되도록 묶음 단위로 나눈다.
4. 약한 방향(ΔY = −5.617ΔT)으로 투영한 오차의 표준편차를 두 추정기에서 비교한다.

## 4. 판정 기준 (실험 전 고정)

| 조건 | 판정 |
|---|---|
| 짝 추정기의 약한 방향 오차 SD가 단일의 **절반 이하** | H16 성립. B5에서 조건부 탐색을 기본 후보로 넣는다 |
| 절반에서 1배 사이 | 부분 효과. 비용 대비 판단 보류 |
| 개선 없음 | H16 기각 |

## 6. 한계 (중요)

- **이것은 오프라인 조합이다.** 실제로 로봇을 움직이고 다시 찍은 것이 아니다. 두 사진 사이에 실제로 일어나는 백래시·정지 오차·드리프트가 빠져 있다. 규칙 62행이 금지하는 "실제 복귀 성능" 주장으로 쓰면 안 된다.
- ΔY 탐색은 자료가 없어 못 본다.
- 선형계에서는 알려진 이동 자체가 새 정보를 주지 않는다. 이득이 나온다면 **세션 영점 제거**나 **국소 감도 보정**에서 오는 것이며, 이 실험은 둘을 가르지 못한다.
