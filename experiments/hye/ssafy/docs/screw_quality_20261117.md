# 나사 위치 품질 경고 처리 (2026-11-17)

위치 탐색, 밝기 맞춤, 테두리 맞춤 계산이 완료된 나사는 모양 또는 맞춤 차이 기준을 넘어도 계산된 위치를 유지한다. W_SCREW_UNSTABLE과 "나사 위치 추정이 불안정합니다"를 반환하고 Y/T 계산을 계속한다. 이 경고만으로 Failed가 되거나 측정값이 NaN으로 바뀌지 않는다.

모양 유사도와 맞춤 차이는 정확도 확률이 아니다. 기존 기준값 0.93과 0.5px는 경고 기준으로 유지한다. SSAFY에는 SEMES의 둘레 영역 정합이나 area_dx가 없다. QR과 3단계 테두리 좌표 4개를 사용하는 5개 입력 계산식이다.

실제 위치 탐색이나 맞춤 계산이 완료되지 않은 나사는 유효한 측정값이 없으므로 제외한다. QR 미검출, 계산식 누락, 수치 오류와 명시적인 불일치 실패 설정은 이번 변경 대상이 아니다. 모델과 계수는 변경하지 않는다.

2026-11-17 추가한 edge_continuation 검사는 나사 중심을 남기고 주변 고리를 검게 바꾼 실제 영상 입력으로 3단계 좌표 유지, 최종 측정과 보정 허용, 영점, 완전 가림 검출 실패를 확인한다. SEMES 영역 맞춤을 SSAFY에 새로 넣거나 SEMES 계산식을 섞지 않는다. 두 패키지의 서로 다른 정답표와 평가 결과도 구분한다.
