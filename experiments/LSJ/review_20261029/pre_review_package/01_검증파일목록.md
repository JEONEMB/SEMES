## 패키지의 나머지 파일

- `baseline_dev/`: 로컬 `origin/dev`의 스켈레톤 4개 파일(`include/alignment.hpp`, `src/alignment.cpp`, `src/main.cpp`, `CMakeLists.txt`) 원본. commit은 메인 전달서에 명시.
- `evidence/`: 이전 CTest·통합 테스트 로그, CLI JSON, 당시 실행 명령. 이번 전달 작업에서 새로 실행한 결과가 아님.
- `context/calibration_excerpt.json`: 저장된 값의 발췌와 원본 해시. 새 분석/재적합 결과가 아님.
- `context/reference_path.txt`: 같은 PC에서 원본 center.bmp를 찾는 경로. BMP 자체는 포함하지 않음.
- `context/stage_helpers/`: 기존 설정 추출/검증 스크립트의 코드 열람용 복사본. 원래 폴더 구조와 절대 경로에 의존하며 검증 스크립트는 기존 결과를 덮어쓰므로, 복사본이나 원본을 그대로 실행하지 말고 `02_실행방법.md`를 따름.
- `manifest.json`: 패키지 파일 목록·SHA-256·원본 파일 대응·기존 테스트 해시 일치 여부. manifest 자신은 자기 해시 목록에서 제외.

원본 BMP/TXT 데이터, 영상 MP4, 기존 빌드 산출물(EXE/DLL/LIB), Git 저장소 전체, Jira 전달 YAML은 패키지에 포함하지 않았습니다. 코드 리뷰를 위해 소스·설정·테스트·관련 근거만 구성했습니다.
