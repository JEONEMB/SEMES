## 2. 프로젝트는 무엇을 하는가

반도체 세정 장비의 로봇·카메라 위치를 영상으로 정렬하는 프로젝트입니다. **QR Plate는 고정되어 있고, 카메라를 장착한 로봇이 Y 이동 및 θ 회전을 합니다.** 사진 속 QR 이동은 카메라 움직임에 따른 영상 변위입니다.

기존에는 사람이 영상을 보고 정렬했습니다. 목표는 새 이미지 한 장을 받아 정렬에 필요한 Y(mm), θ(°) 보정량을 반환하는 것입니다. 장비의 표시 위치와 실제 영상상의 정렬 상태가 어긋난 상황을 영상으로 보정합니다.

멘토는 한 번에 두 축을 추정하는 방식 외에 **θ 보정 → 이동·재촬영 → Y 보정 → 이동·재촬영** 방식도 허용했습니다. 전체 실제 이동 횟수는 20회 이하여야 합니다. 이동·촬영·장비 통신은 외부 제어기의 역할이고 현재 C++은 명령 계산을 담당합니다.

## 5. 현재 알고리즘과 검토할 구현 선택

실행 흐름은 `alignment()` → `SequentialAligner::estimate()` → θ 판단 → 필요할 때만 Y 판단 → `MoveBudget::issue()` → 한 축 명령 반환입니다.

### θ 처리

중앙 QR에 ZNCC(`TM_CCOEFF_NORMED`)와 ECC 아핀을 적용하여 이동한 구조물 측정 영역을 찾습니다. 원본 이미지의 구조물 경계에 서브픽셀 추정과 Huber 직선 맞춤을 적용합니다. 아핀 변환의 회전각을 그대로 로봇 θ로 쓰는 것이 아닙니다.

각 부호 후보의 변화율을 `a_i`, 선 각도 차이를 `d_i`라고 하면 `theta = sum(a_i*d_i)/sum(a_i*a_i)`를 구하고, 4번 후보는 양수·5번 후보는 음수 영역으로 제한합니다. 두 선의 잔차 제곱합이 작은 후보를 선택하고 보정 명령은 추정 θ의 반대 부호입니다. **현재 자세의 부호와 반환할 이동 명령의 부호를 혼동하지 않는지** 확인해 주세요.

두 선 각각의 θ 환산값이 모두 ±0.005° 안일 때만 θ 조건 충족입니다. 그 외에는 0.01° 단위 명령을 계산합니다. 두 선의 차이가 상쇄되어 명령이 0이 되는 경우는 별도 실패입니다.

좌·우 각도 잔차에 동일 가중치를 준 최소제곱 결합, 수렴 계산의 반복/epsilon, `max_step_deg=1.0`은 현 구현 선택입니다. 이 설정들이 학술적으로 최적이거나 실제 장비 성능으로 검증됐다고 가정하지 마세요. 기존 자료 범위 ±1° 밖 추정은 표시하지만 계산 자체를 일괄 거부하지 않습니다.

### Y 처리

좌·중·우 QR을 각자 ZNCC→ECC 아핀 정합하여 가로 좌표를 측정합니다. 중앙 QR 하나의 변위를 세 QR에 복제하지 않습니다.

각 QR의 현재 x, 목표 `[L,U]`, 각 촬영 구간의 양수 기울기 a에 대해 `L <= x+a*dY <= U`가 되려면 `dY`는 `[(L-x)/a, (U-x)/a]` 안에 있어야 합니다. 세 QR과 네 구간의 12개 구간을 교차하고, 교집합 안의 0.05mm 정수배 중 이동 절댓값이 가장 작은 명령을 고릅니다. 선택 후 12개 예상 좌표 조건을 다시 검사합니다.

네 촬영 구간의 기울기를 모두 가능한 경우로 다루는 것은 **제안하여 구현한 제어 규칙**입니다. 통계적 신뢰구간이나 새로운 확률 추정이 아닙니다. 작은 범위에 맞는 tick이 없을 때 더 가까운 명령으로 자동 대체하지 않습니다. 현재 좌표가 범위에 실제로 들어왔는지 새 이미지에서 확인해야 완료입니다.

### 세션 관리

명령 반환만으로 이동 횟수를 증가시키지 않습니다. 외부의 완료 통지를 받았을 때 Y/θ 합산 1회를 증가시킵니다. 완료 통지 전 중복 호출·중복 완료 통지를 거부하고, 20번째 이동 이후 최종 완료 판정은 허용하되 21번째 이동은 막습니다.

장비 통신, 이동 실패·부분 실행의 확인, 촬영 시점 검증은 외부 호출자의 책임입니다. 코드가 새 프레임임을 독립 검증하거나 실제 이동 성공을 센서로 확인하는 것은 아닙니다. 전역 스켈레톤 어댑터는 다중 장비/동시 호출을 지원하도록 설계하지 않았습니다.

`main.cpp`는 `SequentialAligner`를 직접 호출하는 독립 이미지 진단 CLI입니다. 여러 사진을 기계의 실제 연속 이동으로 세지 않으며 `MoveBudget`을 통해 장비를 구동하는 프로그램이 아닙니다. CLI 로그만으로 세션 횟수 제어가 입증되는지 혼동하지 마세요.

AlignmentDecision chooseAlignmentCorrection(const ThetaResult& theta, const YResult* y) {
    AlignmentDecision result; result.theta = theta;
    if (!theta.commandAvailable) { result.status = "theta_" + theta.status; return result; }
    if (!theta.thetaWithinTolerance) {
        result.thetaDeg = theta.commandDeg; result.commandAvailable = true;
        result.status = theta.outsideCalibration ? "move_theta_extrapolated" : "move_theta";
        return result;
    }
    if (!y) throw std::logic_error("Y measurement required after theta acceptance");
    result.yEvaluated = true; result.y = *y;
    result.commandAvailable = y->commandAvailable;
    if (!y->commandAvailable) { result.status = y->status; return result; }
    result.yMm = y->commandMm; result.aligned = y->withinTarget;
    result.status = result.aligned ? "aligned" : "move_y";
    return result;
}

SequentialAligner::SequentialAligner(const cv::Mat& reference, const ThetaConfig& theta, const YConfig& y)
    : theta_(reference, theta), y_(reference, y) {
    if (theta.width != y.width || theta.height != y.height) throw std::invalid_argument("Theta and Y image sizes differ");

AlignmentDecision SequentialAligner::estimate(const cv::Mat& image) const {
    const auto theta = theta_.estimate(image);
    if (!theta.commandAvailable || !theta.thetaWithinTolerance) return chooseAlignmentCorrection(theta);
    const auto y = y_.estimate(image);
    return chooseAlignmentCorrection(theta, &y);

AlignmentDecision MoveBudget::issue(const AlignmentDecision& decision) {
    if (pending_) throw std::logic_error("Acknowledge the previous executed move, then supply a newly captured image");
    auto result = decision;
    const bool moving = result.yMm != 0 || result.thetaDeg != 0;
    if (!std::isfinite(result.yMm) || !std::isfinite(result.thetaDeg) ||
        (result.yMm != 0 && result.thetaDeg != 0) || (moving && (!result.commandAvailable || result.aligned)))
        throw std::logic_error("Invalid sequential movement decision");
    if (moving && completed_ >= 20) {
        result.yMm = 0; result.thetaDeg = 0; result.commandAvailable = false;
        result.status = "move_limit_reached";
    } else if (moving) pending_ = true;
    return result;
}

void MoveBudget::acknowledgeExecuted() {
    if (!pending_) throw std::logic_error("No pending movement to acknowledge");
    ++completed_; pending_ = false;
}

// Continuous blurred-step fit, ported from the saved measurement implementation.
// The ridge/iteration/bounds below are numerical solver settings, not accuracy criteria.
double stepCenter(const cv::Mat& blurred, int x, int peak, double initial) {
    cv::Vec4d p(blurred.at<float>(peak - 5, x),
                blurred.at<float>(peak + 5, x) - blurred.at<float>(peak - 5, x), initial, 1.5);
    for (int iteration = 0; iteration < 30; ++iteration) {
        cv::Matx<double, 11, 4> jac;
        cv::Vec<double, 11> residual;
        for (int k = 0; k < 11; ++k) {
            const double t = (peak - 5 + k - p[2]) / p[3];
            const double cdf = 0.5 * (1.0 + std::erf(t / std::sqrt(2.0)));
            const double density = std::exp(-0.5 * t * t) / std::sqrt(2.0 * pi);
            residual[k] = p[0] + p[1] * cdf - blurred.at<float>(peak - 5 + k, x);
            jac(k, 0) = 1; jac(k, 1) = cdf;
            jac(k, 2) = -p[1] * density / p[3];
            jac(k, 3) = -p[1] * density * t / p[3];
        }
        auto solve = [&]() {
            cv::Matx44d normal = jac.t() * jac + cv::Matx44d::eye() * 1e-6;
            cv::Vec4d rhs = jac.t() * residual, delta;
            if (!cv::solve(normal, rhs, delta, cv::DECOMP_CHOLESKY))
                throw std::runtime_error("Edge fit linear solve failed");
            return delta;
        };
        cv::Vec4d delta = solve();
        const bool fixedCenter = (p[2] >= initial + 2 - 1e-8 && delta[2] < 0) ||
                                 (p[2] <= initial - 2 + 1e-8 && delta[2] > 0);
        const bool fixedWidth = (p[3] >= 4 - 1e-8 && delta[3] < 0) ||
                                (p[3] <= 0.6 + 1e-8 && delta[3] > 0);
        if (fixedCenter || fixedWidth) {
            for (int k = 0; k < 11; ++k) {
                if (fixedCenter) jac(k, 2) = 0;
                if (fixedWidth) jac(k, 3) = 0;
            }
            delta = solve();
        }
        delta[2] = clamp(delta[2], -0.5, 0.5);
        delta[3] = clamp(delta[3], -0.5, 0.5);
        p -= delta;
        p[2] = clamp(p[2], initial - 2, initial + 2);
        p[3] = clamp(p[3], 0.6, 4.0);
    }
    if (!std::isfinite(p[2])) throw std::runtime_error("Non-finite edge fit");
    return p[2];
}

ThetaConfig ThetaConfig::load(const std::string& path) {
    cv::FileStorage fs(readTextUtf8(path), cv::FileStorage::READ | cv::FileStorage::MEMORY | cv::FileStorage::FORMAT_JSON);
    if (!fs.isOpened()) throw std::runtime_error("Cannot parse theta config");
    if (static_cast<int>(fs["schema_version"]) != 1) throw std::runtime_error("Unsupported theta schema");
    ThetaConfig c;
    fs["width"] >> c.width; fs["height"] >> c.height;
    std::vector<int> roi; fs["locator_roi_xywh"] >> roi;
    if (roi.size() != 4) throw std::runtime_error("Locator requires four coordinates");
    c.locatorRoi = cv::Rect(roi[0], roi[1], roi[2], roi[3]);
    fs["search_margin_px"] >> c.searchMargin;
    fs["tick_deg"] >> c.tickDeg; fs["tolerance_deg"] >> c.toleranceDeg;
    fs["max_step_deg"] >> c.maxStepDeg;
    const auto entries = fs["lines"];
    if (entries.size() != 2) throw std::runtime_error("Exactly two upper structure lines are required");
    int i = 0;
    for (auto it = entries.begin(); it != entries.end(); ++it, ++i) {
        const auto node = *it; auto& line = c.lines[i];
        node["name"] >> line.name;
        node["x0"] >> line.x0; node["x1"] >> line.x1;
        node["expected_y"] >> line.expectedY; node["half_height"] >> line.halfHeight;
        node["polarity"] >> line.polarity;
        node["group4_slope"] >> line.positiveSlope; node["group5_slope"] >> line.negativeSlope;
    }
    c.validate();
    return c;
}

void ThetaConfig::validate() const {
    if (width <= 0 || height <= 0 || searchMargin < 1 ||
        !(tickDeg > 0 && std::isfinite(tickDeg)) ||
        !(toleranceDeg >= 0 && std::isfinite(toleranceDeg)) ||
        !(maxStepDeg >= tickDeg && std::isfinite(maxStepDeg)))
        throw std::invalid_argument("Invalid theta motion/image settings");
    const cv::Rect whole(0, 0, width, height);
    const cv::Rect search(locatorRoi.x - searchMargin, locatorRoi.y - searchMargin,
                          locatorRoi.width + 2 * searchMargin, locatorRoi.height + 2 * searchMargin);
    if (locatorRoi.width < 2 || locatorRoi.height < 2 || (search & whole) != search)
        throw std::invalid_argument("Locator search outside configured image");
    for (const auto& line : lines) {
        if (line.x0 < 0 || line.x1 <= line.x0 || line.x1 >= width || line.halfHeight < 2 ||
            line.expectedY - line.halfHeight - 8 < 0 || line.expectedY + line.halfHeight + 9 > height ||
            (line.polarity != 1 && line.polarity != -1) ||
            !std::isfinite(line.positiveSlope) || !std::isfinite(line.negativeSlope) ||
            line.positiveSlope >= 0 || line.negativeSlope >= 0)
            throw std::invalid_argument("Invalid upper-line ROI or nonnegative/nonfinite slope");
    }
}

LineMeasurement ThetaEstimator::measureLine(const cv::Mat& image, const LineConfig& line, cv::Point2d shift) {
    if (image.empty() || image.type() != CV_8UC1) throw std::invalid_argument("Line extraction requires gray8");
    const int x0 = static_cast<int>(std::nearbyint(line.x0 + shift.x));
    const int x1 = static_cast<int>(std::nearbyint(line.x1 + shift.x));
    const int yc = static_cast<int>(std::nearbyint(line.expectedY + shift.y));
    const int y0 = yc - line.halfHeight - 8, y1 = yc + line.halfHeight + 9;
    if (x0 < 0 || x1 >= image.cols || y0 < 0 || y1 > image.rows)
        throw std::runtime_error("Tracked edge ROI outside image");
    cv::Mat patch, blurred;
    image(cv::Rect(x0, y0, x1 - x0 + 1, y1 - y0)).convertTo(patch, CV_32F);
    cv::GaussianBlur(patch, blurred, cv::Size(), 1.0, 1.0, cv::BORDER_REFLECT_101);
    const auto gradient = [&](int y, int x) {
        return static_cast<float>(line.polarity) *
               ((blurred.at<float>(y + 1, x) - blurred.at<float>(y - 1, x)) * 0.5f);
    };
    std::vector<cv::Point2d> edges;
    const int stride = x1 - x0 < 300 ? 1 : 2;
    for (int x = 2; x < patch.cols - 2; x += stride) {
        int peak = 8; float gb = gradient(peak, x);
        for (int y = 9; y < patch.rows - 8; ++y) {
            const float v = gradient(y, x);
            if (v > gb) { peak = y; gb = v; }
        }
        if (peak <= 8 || peak >= patch.rows - 9 || gb <= 0) continue;
        const double ga = gradient(peak - 1, x), gc = gradient(peak + 1, x);
        const double denominator = ga - 2 * gb + gc;
        const double offset = denominator < -1e-8 ? clamp(0.5 * (ga - gc) / denominator, -0.5, 0.5) : 0;
        edges.emplace_back(x0 + x, y0 + stepCenter(blurred, x, peak, peak + offset));
    }
    if (edges.size() < 20) throw std::runtime_error("Insufficient valid edge columns");
    cv::Point2d mean;
    for (const auto& p : edges) mean += p;
    mean *= 1.0 / edges.size();
    std::vector<cv::Point2f> centered;
    for (const auto& p : edges) centered.emplace_back(static_cast<float>(p.x - mean.x), static_cast<float>(p.y - mean.y));
    cv::Vec4f fit;
    cv::fitLine(centered, fit, cv::DIST_HUBER, 0, 1e-6, 1e-8);
    const double slope = static_cast<double>(fit[1]) / fit[0];
    const double intercept = mean.y + fit[3] - slope * (mean.x + fit[2]);
    double sse = 0;
    for (const auto& p : edges) {
        const double error = (p.y - slope * p.x - intercept) / std::sqrt(1 + slope * slope);
        sse += error * error;
    }
    LineMeasurement out;
    out.angleDeg = std::atan(slope) * 180.0 / pi;
    out.edgeRmsPx = std::sqrt(sse / edges.size());
    out.points = static_cast<int>(edges.size());
    if (!std::isfinite(out.angleDeg)) throw std::runtime_error("Non-finite line angle");
    return out;
}

ThetaResult thetaFromAngles(const std::array<double, 2>& angles,
                           const std::array<double, 2>& targets, const ThetaConfig& config) {
    config.validate();
    struct Candidate { double theta, cost; int group; } candidates[2];
    for (int k = 0; k < 2; ++k) {
        double numerator = 0, denominator = 0;
        for (int i = 0; i < 2; ++i) {
            if (!std::isfinite(angles[i]) || !std::isfinite(targets[i]))
                throw std::invalid_argument("Non-finite angle or target");
            const double a = k == 0 ? config.lines[i].positiveSlope : config.lines[i].negativeSlope;
            numerator += a * (angles[i] - targets[i]); denominator += a * a;
        }
        double theta = numerator / denominator;
        theta = k == 0 ? std::max(0.0, theta) : std::min(0.0, theta);
        double cost = 0;
        for (int i = 0; i < 2; ++i) {
            const double a = k == 0 ? config.lines[i].positiveSlope : config.lines[i].negativeSlope;
            const double residual = angles[i] - targets[i] - a * theta;
            cost += residual * residual;
        }
        candidates[k] = {theta, cost, k == 0 ? 4 : 5};
    }
    const auto best = candidates[candidates[1].cost < candidates[0].cost ? 1 : 0];
    ThetaResult r;
    r.angles = angles; r.targets = targets; r.estimatedThetaDeg = best.theta;
    r.group = best.theta == 0 ? 0 : best.group;
    r.fitResidualImageDeg = std::sqrt(best.cost / 2);
    r.continuousCorrectionDeg = -best.theta;
    r.outsideCalibration = std::abs(best.theta) > 1.0; // saved groups cover [-1, +1]
    r.thetaWithinTolerance = true;
    for (int i = 0; i < 2; ++i) {
        const double a = best.group == 4 ? config.lines[i].positiveSlope : config.lines[i].negativeSlope;
        r.perLineTheta[i] = (angles[i] - targets[i]) / a;
        r.thetaWithinTolerance = r.thetaWithinTolerance && std::abs(r.perLineTheta[i]) <= config.toleranceDeg + 1e-12;
    }
    if (r.thetaWithinTolerance) {
        r.status = "theta_within_tolerance";
    } else {
        // Clamp in integer ticks so rounding cannot exceed the configured cap.
        const double maxTicks = std::floor(config.maxStepDeg / config.tickDeg + 1e-12);
        const double ticks = clamp(std::round(r.continuousCorrectionDeg / config.tickDeg), -maxTicks, maxTicks);
        r.commandDeg = ticks * config.tickDeg;
        r.commandAvailable = ticks != 0;
        r.status = ticks == 0 ? "unresolved_at_tick_resolution" :
                   r.outsideCalibration ? "move_extrapolated" : "move";
    }
    return r;
}

ThetaEstimator::ThetaEstimator(const cv::Mat& reference, const ThetaConfig& config) : config_(config) {
    config_.validate();
    const cv::Mat gray = grayscale(reference, config_);
    locatorTemplate_ = gray(config_.locatorRoi).clone();
    cv::Scalar mean, sd; cv::meanStdDev(locatorTemplate_, mean, sd);
    if (sd[0] <= std::numeric_limits<double>::epsilon()) throw std::invalid_argument("Flat reference QR patch");
    for (int i = 0; i < 2; ++i) targets_[i] = measureLine(gray, config_.lines[i]).angleDeg;
}

ThetaResult ThetaEstimator::estimate(const cv::Mat& image) const {
    const cv::Mat gray = grayscale(image, config_);
    const auto roi = config_.locatorRoi; const int margin = config_.searchMargin;
    const cv::Rect search(roi.x - margin, roi.y - margin, roi.width + 2 * margin, roi.height + 2 * margin);
    cv::Scalar mean, sd; cv::meanStdDev(gray(search), mean, sd);
    if (sd[0] <= std::numeric_limits<double>::epsilon()) throw std::runtime_error("Flat locator search");
    cv::Mat scores; cv::matchTemplate(gray(search), locatorTemplate_, scores, cv::TM_CCOEFF_NORMED);
    cv::Point peak; double zncc;
    cv::minMaxLoc(scores, nullptr, &zncc, nullptr, &peak);
    if (peak.x == 0 || peak.y == 0 || peak.x == scores.cols - 1 || peak.y == scores.rows - 1)
        throw std::runtime_error("QR locator reached search boundary");
    const cv::Point coarse(peak.x - margin, peak.y - margin);
    cv::Mat warp = cv::Mat::eye(2, 3, CV_32F);
    const double ecc = cv::findTransformECC(locatorTemplate_, gray(cv::Rect(roi.x + coarse.x, roi.y + coarse.y, roi.width, roi.height)),
        warp, cv::MOTION_AFFINE, cv::TermCriteria(cv::TermCriteria::COUNT | cv::TermCriteria::EPS, 60, 1e-6), cv::noArray(), 5);
    const double cx = (roi.width - 1) / 2.0, cy = (roi.height - 1) / 2.0;
    const cv::Point2d shift(coarse.x + warp.at<float>(0, 0) * cx + warp.at<float>(0, 1) * cy + warp.at<float>(0, 2) - cx,
                            coarse.y + warp.at<float>(1, 0) * cx + warp.at<float>(1, 1) * cy + warp.at<float>(1, 2) - cy);
    if (!std::isfinite(shift.x) || !std::isfinite(shift.y) || std::abs(shift.x) >= margin || std::abs(shift.y) >= margin)
        throw std::runtime_error("ECC locator left configured search");
    std::array<double, 2> angles;
    std::array<LineMeasurement, 2> lines;
    for (int i = 0; i < 2; ++i) { lines[i] = measureLine(gray, config_.lines[i], shift); angles[i] = lines[i].angleDeg; }
    ThetaResult r = thetaFromAngles(angles, targets_, config_);
    r.locatorShift = shift; r.zncc = zncc; r.ecc = ecc; r.measurements = lines;
    return r;
}

cv::Mat grayImage(const cv::Mat& image, const YConfig& config) {
    if (image.empty() || image.depth() != CV_8U || image.cols != config.width || image.rows != config.height)
        throw std::invalid_argument("Y requires a native-size 8-bit image");
    cv::Mat gray;
    if (image.channels() == 1) gray = image;
    else if (image.channels() == 3) cv::cvtColor(image, gray, cv::COLOR_BGR2GRAY);
    else if (image.channels() == 4) cv::cvtColor(image, gray, cv::COLOR_BGRA2GRAY);
    else throw std::invalid_argument("Y requires gray/BGR/BGRA image");
    return gray;
}

// Roundoff guard only (about 5.5e-11 px at width 3840), not a new target band.
double pixelEpsilon(const YConfig& c) { return 64 * std::numeric_limits<double>::epsilon() * c.width; }
bool inside(double value, const YMarkerConfig& marker, double epsilon) {
    return value >= marker.lowPx - epsilon && value <= marker.highPx + epsilon;
}

YConfig YConfig::load(const std::string& path) {
    cv::FileStorage fs(readTextUtf8(path), cv::FileStorage::READ | cv::FileStorage::MEMORY | cv::FileStorage::FORMAT_JSON);
    if (!fs.isOpened() || static_cast<int>(fs["schema_version"]) != 1)
        throw std::invalid_argument("Invalid Y config schema");
    YConfig c;
    fs["width"] >> c.width; fs["height"] >> c.height;
    fs["search_margin_px"] >> c.searchMargin; fs["tick_mm"] >> c.tickMm;
    fs["target_profile"] >> c.targetProfile;
    std::vector<int> groups; fs["slope_groups"] >> groups;
    if (groups != std::vector<int>{2, 3, 6, 7}) throw std::invalid_argument("Expected Y slope groups 2,3,6,7");
    const auto entries = fs["markers"];
    if (entries.size() != 3) throw std::invalid_argument("Expected L,C,R markers");
    int i = 0;
    for (auto it = entries.begin(); it != entries.end(); ++it, ++i) {
        const auto n = *it; auto& m = c.markers[i];
        std::vector<int> roi; std::vector<double> slopes;
        n["name"] >> m.name; n["roi_xywh"] >> roi;
        n["low_px"] >> m.lowPx; n["high_px"] >> m.highPx;
        n["slopes_px_per_mm"] >> slopes;
        if (roi.size() != 4 || slopes.size() != 4) throw std::invalid_argument("Invalid Y marker fields");
        m.roi = cv::Rect(roi[0], roi[1], roi[2], roi[3]);
        std::copy(slopes.begin(), slopes.end(), m.slopes.begin());
    }
    c.validate();
    return c;
}

void YConfig::validate() const {
    if (width <= 0 || height <= 0 || searchMargin < 1 || !(tickMm > 0 && std::isfinite(tickMm)) || targetProfile.empty())
        throw std::invalid_argument("Invalid Y settings");
    const cv::Rect whole(0, 0, width, height);
    const std::array<std::string, 3> names{{"L", "C", "R"}};
    for (int i = 0; i < 3; ++i) {
        const auto& m = markers[i];
        const cv::Rect search(m.roi.x - searchMargin, m.roi.y - searchMargin,
                              m.roi.width + 2 * searchMargin, m.roi.height + 2 * searchMargin);
        if (m.name != names[i] || m.roi.width < 2 || m.roi.height < 2 || (search & whole) != search ||
            !std::isfinite(m.lowPx) || !std::isfinite(m.highPx) || m.lowPx < 0 || m.highPx >= width || m.lowPx > m.highPx)
            throw std::invalid_argument("Invalid Y target range or ROI");
        for (double a : m.slopes) if (!(a > 0 && std::isfinite(a))) throw std::invalid_argument("Expected finite positive Y slope");
    }
}

YResult yFromPositions(const std::array<double, 3>& x, const YConfig& config) {
    config.validate();
    YResult r; r.x = x; r.withinTarget = true;
    const double eps = pixelEpsilon(config);
    r.commonLowMm = -std::numeric_limits<double>::infinity();
    r.commonHighMm = std::numeric_limits<double>::infinity();
    double minSlope = std::numeric_limits<double>::infinity();
    for (int i = 0; i < 3; ++i) {
        if (!std::isfinite(x[i]) || x[i] < 0 || x[i] >= config.width)
            throw std::invalid_argument("Invalid measured Y marker coordinate");
        const auto& m = config.markers[i];
        r.inside[i] = inside(x[i], m, eps);
        r.withinTarget = r.withinTarget && r.inside[i];
        double low = -std::numeric_limits<double>::infinity(), high = std::numeric_limits<double>::infinity();
        for (double a : m.slopes) {
            minSlope = std::min(minSlope, a);
            low = std::max(low, (m.lowPx - x[i]) / a);
            high = std::min(high, (m.highPx - x[i]) / a);
        }
        r.intervalLowMm[i] = low; r.intervalHighMm[i] = high;
        r.commonLowMm = std::max(r.commonLowMm, low);
        r.commonHighMm = std::min(r.commonHighMm, high);
    }
    if (!std::isfinite(r.commonLowMm) || !std::isfinite(r.commonHighMm))
        throw std::invalid_argument("Y movement interval overflow");
    if (r.withinTarget) {
        r.commandAvailable = true; r.status = "y_within_target";
        return r;
    }
    const double epsMm = eps / minSlope;
    if (r.commonLowMm > r.commonHighMm + epsMm) {
        r.status = "no_common_y_interval"; return r;
    }
    const double firstTick = std::ceil((r.commonLowMm - epsMm) / config.tickMm);
    const double lastTick = std::floor((r.commonHighMm + epsMm) / config.tickMm);
    if (!std::isfinite(firstTick) || !std::isfinite(lastTick) || std::abs(firstTick) >= 9007199254740992.0 || std::abs(lastTick) >= 9007199254740992.0)
        throw std::invalid_argument("Y tick interval overflow");
    if (firstTick > lastTick) { r.status = "no_reachable_y_tick"; return r; }
    const double ticks = std::max(firstTick, std::min(0.0, lastTick));
    const double command = ticks * config.tickMm;
    // Recheck all 12 model predictions after discretization; never clamp to an arbitrary endpoint.
    for (int i = 0; i < 3; ++i)
        for (double a : config.markers[i].slopes)
            if (!inside(x[i] + a * command, config.markers[i], eps)) {
                r.status = "no_reachable_y_tick"; return r;
            }
    if (ticks == 0) { r.status = "no_reachable_y_tick"; return r; }
    r.commandMm = command; r.commandAvailable = true; r.status = "move_y";
    return r;
}

int run(const std::vector<std::string>& args) {
    std::string referencePath, configPath, outputPath, listPath, yConfigPath;
    std::vector<std::string> images;
    for (size_t i = 1; i < args.size(); ++i) {
        const auto& flag = args[i];
        if (flag == "--reference" || flag == "--config" || flag == "--y-config" || flag == "--output" || flag == "--input-list") {
            if (++i == args.size()) throw std::invalid_argument("Missing value for " + flag);
            if (flag == "--reference") referencePath = args[i];
            else if (flag == "--config") configPath = args[i];
            else if (flag == "--y-config") yConfigPath = args[i];
            else if (flag == "--output") outputPath = args[i];
            else listPath = args[i];
        } else if (flag.rfind("--", 0) == 0) throw std::invalid_argument("Unknown option: " + flag);
        else images.push_back(flag);
    }
    if (referencePath.empty() || configPath.empty()) {
        std::cerr << "Usage: main --reference center.bmp --config configs/theta_alignment.json "
                  << "[--y-config configs/y_alignment.json] [--input-list paths.txt] [--output result.json] [image.bmp ...]\n";
        return 2;
    }
    if (!listPath.empty()) {
        std::string contents = semes::readTextUtf8(listPath);
        if (contents.compare(0, 3, "\xEF\xBB\xBF") == 0) contents.erase(0, 3);
        std::istringstream lines(contents); std::string path;
        while (std::getline(lines, path)) {
            if (!path.empty() && path.back() == '\r') path.pop_back();
            if (!path.empty()) images.push_back(path);
        }
    }
    if (images.empty()) throw std::invalid_argument("No input images");
    // Prevent accidentally replacing an input through an output argument.
    if (!outputPath.empty() && (outputPath == referencePath || outputPath == configPath || outputPath == listPath || outputPath == yConfigPath))
        throw std::invalid_argument("Output path must not equal an input path");
    for (const auto& path : images) if (outputPath == path) throw std::invalid_argument("Output equals image input");

    cv::setNumThreads(2);
    const auto config = semes::ThetaConfig::load(configPath);
    const cv::Mat reference = semes::readGrayUtf8(referencePath);
    std::unique_ptr<semes::ThetaEstimator> estimator;
    std::unique_ptr<semes::SequentialAligner> sequential;
    if (yConfigPath.empty()) estimator = std::make_unique<semes::ThetaEstimator>(reference, config);
    else sequential = std::make_unique<semes::SequentialAligner>(reference, config, semes::YConfig::load(yConfigPath));
    cv::FileStorage fs(".json", cv::FileStorage::WRITE | cv::FileStorage::MEMORY | cv::FileStorage::FORMAT_JSON);
    fs << "schema_version" << 1 << "opencv_version" << CV_VERSION << "stage" << (sequential ? "theta_then_y" : "theta_only")
       << "reference" << referencePath << "config" << configPath << "y_config" << yConfigPath
       << "mode" << "independent_offline_images_no_machine_moves" << "results" << "[";
    int failed = 0;
    for (const auto& path : images) {
        fs << "{" << "file" << path;
        try {
            const cv::Mat current = semes::readGrayUtf8(path);
            if (sequential) {
                const auto result = sequential->estimate(current);
                fs << "valid" << 1;
                semes::writeAlignmentDecision(fs, result);
                if (!result.commandAvailable) ++failed;
            } else {
                const auto result = estimator->estimate(current);
                fs << "valid" << 1;
                semes::writeThetaResult(fs, result);
                if (!result.commandAvailable) ++failed;
            }
        } catch (const std::exception& error) {
            ++failed;
            fs << "valid" << 0 << "status" << "measurement_failed" << "error" << error.what();
        }
        fs << "}";
    }
    fs << "]";
    const std::string json = fs.releaseAndGetString();
    if (outputPath.empty()) std::cout << json;
    else { semes::writeTextUtf8(outputPath, json); std::cout << "Processed " << images.size() << ", unresolved/failed " << failed << "\n"; }
    return failed ? 1 : 0;
}
