## 실행 및 검증 범위

이 이관에서는 원본 사본 SHA256, Python 문법, JSON/YAML 파싱, 포함 파일·이슈 대응을 확인한다.
이미지 재측정, 회귀 재실행, 최종 C++ 빌드·정렬 성능 시험은 실행하지 않는다.
저장 결과를 읽는 스크립트와 원본 이미지가 필요한 스크립트를 구분한다.

연구용 환경 버전은 `requirements-research.txt`에 기록했다. 실행 환경을 자동으로 변경하지 않는다.
일부 코드는 JSON에 기록된 작성 당시 원본 경로를 읽는다. 원자료는 별도 제공 자료를 사용하며,
다른 PC에서 재실행하려면 `Links.example.md`를 `Links.md`로 복사해 경로를 설정하고,
JSON 원본 경로와 데이터 추출 위치를 먼저 점검해야 한다.
JSON 경로를 임의 치환하면 저장된 입력 SHA256과 어긋날 수 있으므로 기존 측정 파일을 덮어쓰지 않는다.
원자료 검사·재측정은 별도로 요청받은 범위에서 진행한다.

최초 측정 코드의 인자 예시(이번 이관에서는 실행하지 않음):

```powershell
python analysis/initial_error/analyze_images.py --data-root "원본 데이터 경로" --output "새 결과 폴더"
```

이 명령의 작업 디렉터리는 `experiments/LSJ`다. 다른 스크립트의 출력 위치는 실행 전 코드에서 확인한다.
일부 역사적 문서의 절대 경로 링크는 당시 개인 작업 폴더를 가리킨다. 저장소 내 탐색은 위 작업별 링크를 사용한다.
