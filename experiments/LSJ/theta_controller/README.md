# θ 구현

기존 `dev` 스켈레톤의 입력/반환 구조를 유지한 C++ 구현입니다. 기준은 1차 `center.bmp`에서 직접 측정한 좌·우 상단 구조물의 선 각도입니다. 중앙 QR을 ZNCC→ECC 아핀으로 찾고, 그 이동량으로 원본 구조물 측정 영역을 옮깁니다. 구조물 경계의 서브픽셀 위치와 Huber 직선 맞춤으로 각도를 구합니다. 아핀 행렬의 회전각을 로봇 θ로 사용하지 않습니다.

목표 각도와 변화율은 다른 값입니다. 목표는 기준 이미지에서 측정하며, 변화율은 1차 4번/5번 촬영의 기존 회귀 기울기를 각 선별로 보존합니다. 양/음 현재 자세 후보를 각각 계산해 두 선의 각도 잔차 제곱합이 작은 후보를 선택합니다. 각 후보의 θ 추정식은 `sum(a_i*(phi_i-target_i))/sum(a_i*a_i)`이고 보정 명령은 그 반대 부호입니다. 동일 각도 잔차 가중치는 구현 선택이며 통계적으로 최적이라고 검증한 것은 아닙니다.

두 선의 개별 θ 환산값이 모두 ±0.005° 안이면 θ 보정은 0입니다. 이외에는 현재 모델에서 이동 후 두 조건을 함께 만족하는 0.01° 정수배 명령을 탐색합니다. 양·음 자세에 맞는 4·5번 변화율로 영점을 지나는 이동까지 예측하며, 후보마다 기존의 두 선 완료 조건을 다시 적용합니다. 후보가 없으면 `theta_target_conflict` 또는 `theta_no_reachable_tick`을 반환합니다. 허용오차를 넓히거나 결합 추정값만으로 완료 처리하지 않습니다.

`max_step_deg=1`은 초기 구현 설정입니다. 가능한 최종 이동량이 이 제한보다 크면 한 번의 명령만 제한하고, 새 이미지로 다시 판단합니다. 예상 도달은 `predicted_within_tolerance`, 실제 현재 영상의 판정은 `theta_within_tolerance`로 구분합니다. 기존 기울기 데이터의 ±1° 범위를 벗어난 추정에는 `outside_calibration` 표시가 붙습니다. 예측식과 한계는 [검증 피드백 반영 문서](../review_fixes/README.md)에 있습니다.

기준 이미지 자체와 합성 경계, 보정 계산 단위 테스트가 통과했습니다. 자료 출처는 [provenance.json](provenance.json)에 있습니다. 전체 장비 정확도 및 실제 20회 이내 수렴을 검증한 결과는 아닙니다.

Y 연결 및 실행 방법은 [순차 정렬 문서](../y_controller/README.md)를 따릅니다. Y 목표 범위에서 4번을 제외한 결정은 θ 변화율의 4번 사용을 변경하지 않습니다.
