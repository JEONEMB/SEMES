# S15P31A507-180 — 1차 이미지의 영상 변위 측정과 정합 모델 민감도 점검

Jira: https://ssafy.atlassian.net/browse/S15P31A507-180

상위 스토리: S15P31A507-176. 상태: 해당 분석·검토·기록 작성 완료.
기존 결과를 보관한 문서이며 GitLab 이관 과정에서 새 분석이나 장비 성능 검증을 수행하지 않았다.

## 수행 내용

작업일 10/19. 1차 기준 포함 281장의 QR 3개를 center.bmp 기준으로 추적했다.
ZNCC(TM_CCOEFF_NORMED)로 초기 위치를 찾고 ECC 아핀 정합으로 Δx·Δy를 계산했다.
Y·θ 단독 이동을 구분하여 촬영 묶음별 기준 위치 차이와 라벨–영상 변위 관계를 살폈다.
θ 대표 8장·QR 24개에서 아핀과 호모그래피 결과를 비교하고 카메라 사양 기반 배율도 검토했다.
ZNCC·아핀·호모그래피의 원리와 영상 변위/장비 이동량의 차이를 설명 문서로 정리했다.
분석과 결과 정리는 완료됐으며 팀 GitLab 반영·Claude 추가 코드 검토는 별도 후속 절차다.

## 확인한 결과와 해석 범위

대표 θ 샘플에서 아핀–호모그래피 Δx 차이는 RMS 약 0.0076px, 최대 약 0.0150px였다.
이는 두 계산법의 차이이며 실제 위치 정확도가 0.015px라는 뜻이 아니다.
산출물: analysis/initial_error/, 일지 1019.md,
정규화 상관 기반 템플릿 매칭(NCC).md, 아핀정합&호모그래피정합.md.

## 기존 근거 확인

perspective_sensitivity.json, geometry_scale_check.json 및 1019.md를 대조했다.
코드: analysis/initial_error/analyze_images.py, analyze_batches.py,
check_perspective_sensitivity.py, check_geometry_scale.py.
개인 저장소 10/19 커밋의 해당 파일 포함 여부를 확인했다. 이번 정리에서는 재실행하지 않았다.

위 원본 설명의 로컬 경로는 작성 당시 출처이며, 이 저장소에 포함된 파일은 아래 링크로 확인한다.
