# S15P31A507-190 — 4번 촬영 구간 제외 조건의 공통 영점 후보 검토

Jira: https://ssafy.atlassian.net/browse/S15P31A507-190

상위 스토리: S15P31A507-177. 상태: 해당 분석·검토·기록 작성 완료.
기존 결과를 보관한 문서이며 GitLab 이관 과정에서 새 분석이나 장비 성능 검증을 수행하지 않았다.

## 수행 내용

작업일 10/28. 사용자 지정에 따라 4번 θ 양수 구간을 제외하고 2·3·5·6·7번을 다시 비교했다.
이미지 180장·15개 회귀식을 사용하되 기존 18개 회귀식 기준의 동시 신뢰 배수와 허용오차를 유지했다.
기존 영상 측정값·회귀식을 재사용하고 OLS와 HAC 모두 허용하는 공통 구간을 산정했다.

## 확인한 결과와 해석 범위

OLS·HAC 모두를 만족하는 가로 좌표 후보는 좌 1641.5085~1642.0520px,
중 1899.5190~1900.0669px, 우 2158.5222~2159.0727px였다.
각각 폭은 약 0.5435, 0.5479, 0.5505px다. 허용오차와 회귀 불확실성이 이미 반영된 범위다.
이는 사후 선택한 5구간에 한정된 결과로 4번 자료의 오류나 전체 6구간 동등성을 증명하지 않는다.
4번 제외를 모든 후속 분석에 자동 적용하지 않았고 목표 설정 파일도 확정하지 않았다.
