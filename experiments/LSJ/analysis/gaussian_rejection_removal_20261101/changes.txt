2026-11-01 — Gaussian 피팅의 자체 제외 조건(5번) 제거

적용 대상
analysis/reference_line_methods_108_20261030의 Gaussian 공통 구현(E01/Q01).
원본 촬영 이미지나 이전 측정 결과를 다시 계산하지 않았다.

제거한 조건
1. 최소 Sobel 응답 미달: external 8 / qr 40.
2. 최초 경계가 탐색 띠 끝에 있다는 이유로 제외.
3. Nelder–Mead 미수렴이라는 이유로 제외.
4. 피팅 진폭 A가 0 이하라는 이유로 제외.
5. 최종 mu가 최초 경계에서 2px를 넘게 벗어났다는 이유로 제외.
min_peak, max_center_shift_px 설정 키도 제거했다. 대체 임계값은 넣지 않았다.

현재 동작
기존 가시 열마다 Gaussian 계산을 수행하고, 반환된 좌표를 모두 공통 직선 피팅 입력으로 전달한다.
각 열의 Sobel 응답, 계산 반복 수, 수렴 여부, 유한값 여부를 기록한다.
기존 표시용 state=selected는 직선 피팅에 전달했다는 뜻이며, 수렴·정확도 검증 통과를 의미하지 않는다.
NaN/무한대도 Gaussian 단계에서 조용히 삭제하지 않는다. 기존 공통 직선 피팅은 비유한 입력이 있으면 전체 피팅 실패를 기록하며, JSON에서는 비유한값이 null로 저장된다.

이번에 변경하지 않은 항목
표본 수, 초기값, 최대 반복 800회, 수렴 설정 1e-10, 기존 ROI·가림 구간·가로 간격.
후속 공통 Huber 피팅과 그 직선 거리 기반 trimming은 별도 처리이며 이번 수정 대상이 아니다.
다른 경계 추출 방법과 과거 실험·보고서·스냅샷도 변경하지 않았다.
