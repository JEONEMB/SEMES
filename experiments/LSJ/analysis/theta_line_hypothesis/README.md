먼저 [현재 적용 전제와 정정](../../CURRENT_CONTEXT.md#θ-선-기울기-보고서의-후속-정정)을 읽는다.

초기 이차 피크 보간판과 중복 QA 그림은 원본 작업 폴더에 보존하며 이 제출 묶음에서는 제외했다.
