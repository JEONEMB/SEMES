4. 유지할 수 있는 부분
==============
LSD와 Devernay의 실제 c/h는 보관된 공식 ZIP 원본과 같습니다. 모든 검출기 코어를 임의로 새로 만든 것은 아닙니다.
EDLines·ELSED·FLD는 보관 원본과의 실제 diff에서 접근자/지지점 출력·이식 변경을 구분했습니다. 주 검출 계산식을 바꾼 정황은 해당 diff에서 발견하지 못했습니다.
외부 구조물은 좌우 가시 영역의 점을 모아 상단 한 직선·하단 한 직선을 만듭니다. 좌우의 두 기울기를 평균하는 구현이 아닙니다.
QR은 세 영역 모두 처리합니다. Q01~Q11은 밝은 바깥 테두리 상단을 목표로 하고, Q12는 파인더 중심 연결선으로 별도 분류합니다.
Huber는 E01~E09 및 Q01~Q10에 적용됩니다. Q11·Q12는 두 점 연결이며 Huber를 적용하지 않습니다.
원본 픽셀 좌표 복원·법선각/기울기 변환의 검토 경로에서 명백한 대수 오류는 찾지 못했습니다. 이는 영상 각도 φ와 로봇 θ가 같다는 뜻이 아닙니다.
좌표는 x 오른쪽, y 아래, m=dy/dx, φ=atan2(dy,dx)입니다. 직선의 기울기 m은 px/px이며 φ는 영상의 각도입니다.

11. 근거 자료와 열람 범위
================

S01 Gaussian 원논문, III.A–C
https://annals-csis.org/proceedings/2014/pliks/136.pdf
이번 점검에서 원문 III.A–C 대조. Gaussian/Nelder–Mead/초기값은 근거 있음. 전체 처리의 동등성이나 우리 설정의 성능 근거는 아님.

S02 Canny–Devernay IPOL·저자 소스
https://www.ipol.im/pub/art/2017/216/
논문 소개와 저자 코드 1.0 대조. 전문 PDF는 도구 접근 시간 초과로 미열람. 로컬 공식 ZIP과 실제 c/h가 바이트 단위로 같음.

S03 OpenCV 특징 검출 공식 문서
https://docs.opencv.org/3.4/dd/d1a/group__imgproc__feature.html
Canny/Hough/cornerSubPix/goodFeaturesToTrack API의 정의 확인. 온라인 주소는 3.4.20으로 이동하므로 실행 버전 3.4.15의 수치적 동일성을 입증하는 자료로 쓰지 않음.

S04 LSD 1.6 원논문·저자 구현
https://www.ipol.im/pub/art/2012/gjmr-lsd/article.pdf
원문의 Gaussian subsampling, 선분과 지지 영역, 영상 크기 영향 및 로컬 소스 scale 분기 확인. 공식 ZIP과 실제 c/h 일치.

S05 Zernike ramp edge 원논문
https://pmc.ncbi.nlm.nih.gov/articles/PMC8321028/
식 1, 15, 18–25, 31, 33, 40–42와 구현 대조. 7×7 마스크 자체는 허용되는 형태. 흐림 폭 가정과 수치적분 정확성은 별도 문제.

S06 PAE 구현자 Method.md
https://github.com/juanse77/EdgeLocator/blob/master/Method.md
기본 3×5, 2차 열 합 공식, 모서리 A/B 추정 설명 대조. 2013 원논문 전문은 이번에도 직접 확인하지 못함. 원문 재현 인증을 하지 않음.

S07 EDLines 고정 버전 저자 코드
https://raw.githubusercontent.com/CihanTopal/ED_Lib/69b8d081bd6d28192d816ec0ed02aff9186d73c1/EDLines.cpp
EDLines 생성자 기본 ED 36/8, 분할·병합·검증 흐름, 병합 시 지지 구간 처리 대조. 논문 전문의 모든 절을 검토한 것은 아님.

S08 OpenCV contrib FLD 원본
https://raw.githubusercontent.com/opencv/opencv_contrib/3.4/modules/ximgproc/src/fast_line_detector.cpp
공식 소스와 보관 원본/이식본의 실제 diff 확인. 온라인 3.4는 이동 브랜치이므로 재현 기준은 보관 다운로드와 해시. 출력용 코드 추가와 계산 변경을 구분함.

S09 ELSED 고정 버전 파라미터
https://raw.githubusercontent.com/iago-suarez/ELSED/1878213b2f5f06a9261d8b1838f53d48e5fd128d/src/ELSED.h
저자 기본값과 실제 호출 값 대조. 원문 전체의 증명 재검토가 아니라 고정 소스와 추가 코드의 정적 대조.

S10 OpenCV 윤곽·직선 피팅 공식 문서
https://docs.opencv.org/3.4/d3/dc0/group__imgproc__shape.html
findContours/approxPolyDP/fitLine의 정의 확인. 3.4.20 문서로 이동. 각 API의 존재는 우리 조합 규칙이 검증됐다는 뜻이 아님.

S11 표준화된 Huber 가중의 공식 예
https://www.mathworks.com/help/stats/robustfit.html
1.345와 scale을 함께 쓰는 설명 확인. MATLAB 수직잔차 회귀를 우리 직교 피팅과 같은 알고리즘이라고 주장하지 않음. 95%는 정확도나 포함 확률이 아닌 특정 조건의 통계적 효율.
