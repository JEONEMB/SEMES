E06 · PAE로 경계점 찾기

경계가 한 픽셀을 가르면, 그 픽셀의 밝기에는 양쪽 면적의 비율이 섞인다는 생각으로 위치를 계산합니다.

예를 들어 어두운 쪽과 밝은 쪽이 한 픽셀을 절반씩 차지하면 중간 밝기가 관측된다는 모델입니다. 실제 구현은 경계 주변 세 열의 밝기 합으로, 픽셀 안에서 경계가 지나가는 위치를 계산합니다.

  1. 원본 밝기의 중앙차분으로 위아래·좌우 변화를 구합니다. 위→아래 밝아지고 세로 변화가 더 크며, 위아래 이웃보다 경사가 큰 후보를 찾습니다. 각 2px 간격 열에서 가장 강한 후보 하나를 고릅니다.
  2. 정수 후보를 중심으로 가로 3열, 세로 9행의 원본 밝기를 가져옵니다.
  3. 맨 윗행 세 픽셀의 평균을 어두운 쪽 밝기 A, 맨 아랫행 평균을 밝은 쪽 밝기 B로 둡니다. 세 열 각각의 밝기 합 S_L·S_M·S_R도 계산합니다.
  4. 이 작은 창 안 경계를 y_local=a+b_local·x_local+c·x_local²로 놓고 a·b_local·c를 계산합니다. 창 중앙 x_local=0에서 경계 위치가 a이므로, 점은 (원래 x, 최초 y+a)가 됩니다.
  5. B−A가 3보다 작거나 |a|가 1.5px보다 크면 제외합니다. 남은 점을 공통 Huber 피팅에 넣어 구조물별 직선 하나를 구합니다.

실제 점 하나: A=132, B=164, 세 열 합은 1329·1327·1323입니다. a=0.153646px이므로 (24, 707) → (24, 707.153646)px가 됩니다.

여기서 계산한 b_local은 3×9 창 안의 국소 곡선 계수입니다. 보고서의 최종 직선 기울기 m은 많은 경계점을 모아 별도로 계산합니다.

학술 근거를 따른 부분과 달라진 부분

구분실제 적용 내용
이론의 출처Trujillo-Pino 등 (2013), Accurate subpixel edge location based on partial area effect의 부분 면적 효과(PAE). 이번 코드 대조에서 직접 확인한 계산 설명은 EdgeLocator 저자 측 구현 설명, Method.md입니다.
실제로 참조한 부분Method.md의 기본 2차 경계 모델, 열별 밝기 합으로 a·b·c를 구하는 관계를 자체 C++로 작성했습니다. 저자 전체 구현을 그대로 가져온 방식은 아닙니다.
변경한 부분설명 예시의 3×5 창을 3×9로 확대했습니다. A/B도 설명의 모서리 쪽 픽셀 선택 대신 창의 맨 윗행·아랫행 세 픽셀 평균으로 정했습니다. 높이 변경은 식의 창 높이에 반영됐지만, 현재 영상에서 더 적절하다는 근거가 확보된 것은 아닙니다.
구현 범위·확인 한계평활된 영상용 보정식, floating window, 수직 경계 분기는 사용하지 않았습니다. 2013년 논문 전문을 직접 대조한 상태가 아니므로 논문 전체의 충실한 재현이라고 표현할 수 없습니다. 기본형의 부분 구현입니다.

계산식 자세히 보기
H = 9, D = 2(A−B)
c = (S_L+S_R−2S_M)/D
b_local = (S_R−S_L)/D
a = [2S_M−(A+B)H]/D − c/12
경계점 = (x₀, y₀+a)

이 계산은 작은 창 안에 어두운 쪽과 밝은 쪽의 대표 밝기를 둘 수 있고, 경계가 2차 곡선으로 근사된다는 모델을 전제로 합니다. A/B를 잘못 잡으면 이 식에 넣을 숫자부터 달라집니다.
