# 현재 적용 전제와 기존 보고서 해석 정정

기준: 2026-11-02. 날짜별 과거 기록과 아래 최신 상태를 구분한다. 이 문서는 새 데이터 분석 결과가 아니다.

## 정렬 개발 전제

- QR Plate 고정, 로봇·카메라 Y 이동 및 θ 회전. 영상 변위(px)와 로봇 변위(mm/°)를 구분한다.
- 카메라–QR 거리: 멘토 제공 공식값 385mm. 렌즈 WD 307.80으로 대체하지 않는다.
- 목표 허용오차: Y ±0.045mm, θ ±0.005°.
- 최소 이동 단위: Y 0.05mm, θ 0.01°. 최소 단위와 허용오차를 혼동하지 않는다.
- θ=0을 실제 정면 자세로 채택하고 Y를 가로 평행이동으로 모델링한다. 미세 기계 흔들림은 고려하지 않는다.
- 목표: 이미지 1장으로 Y·θ 보정량을 산출해 한 번의 보정으로 목표에 도달한다. 적용 순서는 θ 우선·Y 후행이다. 20회 제한은 코드 외부 문제로 설계·검증 범위에서 제외한다.
- 멘토가 표시한 외부 구조물 사용을 허용하며 목표 영상 좌표·각도는 설정값으로 관리한다.
- 향후 구현은 dev 스켈레톤 기반으로 한다. 기존 13개 작업의 완료가 제어 구현·실제 성능 검증 완료를 뜻하지 않는다.

## 결과별 해석 범위

1. 아핀–호모그래피 변위 차이는 두 측정법의 차이이며 실제 오차의 상한이 아니다.
2. 동일 라벨 반복 차이와 단독 이동 일관성은 점검 결과이며 모든 조건의 정렬 성능 보장이 아니다.
3. 1차 Y 구간의 인접 간격은 0.10mm다. 서로 다른 구간을 섞어 0.05mm 연속 촬영으로 취급하지 않는다.
4. 2차 순차 비교의 mm·° 값은 각각 한 축만 움직였다고 가정한 환산값이며 Y·θ 동시 추정이 아니다.
5. 점추정 후보들의 최대−최소 범위, 허용오차가 반영된 목표 좌표 범위, 통계적 불확실성 구간은 서로 다르다.
6. 영점 동등성 계산은 18개 회귀식 동시 신뢰영역을 이용한 조건부 검토다. 일반적인 고정 목표의 TOST를 그대로 수행한 것이 아니다.
7. HAC는 근사 민감도 계산이다. 4번 제외 결과는 2·3·5·6·7번에 한정하며 4번 오류나 전체 6구간 동등성의 증명이 아니다.
8. 4번 제외를 후속 분석 전체에 자동 적용하지 않았다. 선 기울기 분석에서는 4·5번을 각각 사용했다.
9. 영상 수평 0°가 라벨 θ=0을 뜻하지 않는다. 5번 구간에서 얻은 영상 각도 후보 약 0.2256°·0.3164°는 로봇 보정각이 아니다.

## θ 선 기울기 보고서의 후속 정정

`analysis/theta_line_hypothesis/report.txt`, `second_heldout_theta_errors.*`와 `notes/1028.md`는 작성 당시 기록을 보존한다.
그 안의 2차 조건 제외 교차검증은 **2차 데이터로 다시 회귀식을 적합한 탐색 실험**이다.
그 수치로 **1차 고정 모델 검증** 또는 **최종 알고리즘의 ±0.005° 달성 불가능**을 주장한 해석은 철회했다.
채택하는 결론은 일부 외부 구조물의 기울기가 θ에 반응하는 특징이라는 점까지다.
Y 관측 기울기 변화 전체를 기계적 노이즈로 확정하지 않는다. 후속 설계는 위의 사용자 채택 전제를 따른다.
위 초기 보고서와 별개로 11/1에는 새 θ 작성본의 촬영 라벨 대비 정확도를 평가했고 목표 미달이었다. 실장비에서 한 번의 보정으로 목표에 도달하는지는 아직 검증하지 않았다.
