# S15P31A507-191 — 멘토 요구사항과 θ 선행·Y 후행 정렬 설계 조건 정리

Jira: https://ssafy.atlassian.net/browse/S15P31A507-191

상위 스토리: S15P31A507-178. 상태: 해당 분석·검토·기록 작성 완료.
기존 결과를 보관한 문서이며 GitLab 이관 과정에서 새 분석이나 장비 성능 검증을 수행하지 않았다.

## 수행 내용

작업일 10/23 기업탐방·멘토 미팅, 10/27~28 후속 설계 논의.
미세 기계 흔들림 제외, 축별 보정과 재촬영 허용, 이동 20회 이하,
멘토 표시 외부 구조물 사용 가능 조건을 정리했다.
19일 개인 커밋에 포함된 매엽식 세정장비 3D 동작 모델.html을 전체 공정·FOUP 작업 이해 자료로 활용했다.
27일 허용오차를 Y ±0.045mm·θ ±0.005°로 정리했고, 28일 θ 먼저 맞춘 뒤 Y를 맞추는 순서를 논의했다.
최종 대화에서는 θ=0을 실제 정면 자세로 채택하고 Y는 가로 평행이동, 미세 기계 흔들림은 제외하기로 했다.

## 확인한 결과와 해석 범위

검토할 흐름은 이미지 입력 → θ 보정 → 재촬영 → Y 보정 → 재촬영·정렬 확인이다.
영상 수평 0°를 자동 목표로 삼지 않고 채택한 θ=0 자세의 특징값을 목표로 사용한다.
기준 좌표·각도는 설정값으로 관리하고 단일 이미지에서 두 축을 반드시 동시에 출력할 필요는 없다.
순차 제어 코드, 20회 이내 수렴 및 최종 허용오차 달성은 아직 구현·검증 완료로 등록하지 않는다.
