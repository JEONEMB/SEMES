기준 4장 직선 추출 결과: 후속 검증 후보 분리

열람: selection.html
선별: 외부 구조물 E01, E06, E02 / QR Q02, Q04
규칙: 4장 모든 대상 추출 성공, 대상별 영상 각도 최대-최소 범위 중 최댓값 순위. 외부 상위 3개 유지, QR은 사용자 지정 Q02·Q04만 사용.
3개는 작업량을 줄이기 위한 선별 개수이며 통계적 합격 기준이 아니다.
결과: 외부 24개, QR 24개, 전체 48개 직선. 방법 6조합 × 기준 4장 = 24개 조합 항목.
기존 측정 레코드·중간 산출물·그림은 수정 없이 복사. 원본 데이터 및 분석 코드 변경 없음.
새 영상 측정, 통계 검정, 각도-θ 환산, 정확도 검증은 수행하지 않음.
수치 선별 결과이며 모든 경계가 정확하다는 판정은 아님. 보류 방법도 사용 불가 판정 아님.
E06은 기존 PAE 변형 구현이다. 원 논문 재현 및 성능 보증과 구분할 것.
source_configs는 출처 재현을 위한 원본 전체 설정 복사본이며, 선별 대상은 selection_manifest에 지정.
원본 이미지 BMP는 복사하지 않았으며 각 records.input_path로 위치 확인 가능.
