작성 위치는 `.tmp/theta_implementation_20261029/payload`입니다. 기존 검증용 전달 패키지는 수정 전 스냅샷으로 보존했습니다. 이번 변경은 아래 소스와 테스트에 적용했으며 원본 촬영 데이터, 회귀 결과, 두 설정 JSON은 변경하지 않았습니다.

## θ 사전 검사의 의미

현재 추정 자세를 q, 측정한 선 각도를 φ_i, 기준 각도를 φ*_i라 합니다. 기존 4·5번 변화율로 `F_i(q)=a4_i*q (q>=0), a5_i*q (q<0)`를 정의하고, 현재의 잔차 `r_i=φ_i−φ*_i−F_i(q)`를 계산합니다. 이동 d 후의 후보 각도는 `φ'_i=φ*_i+r_i+F_i(q+d)`입니다.

현재 잔차가 한 번의 이동 동안 유지된다는 모델 가정입니다. 새 회귀를 수행하거나 잔차를 제거한 것이 아닙니다. 이 식에 0.01° 정수배 이동을 넣고 기존 분기 선택과 **두 선 모두 ±0.005°** 판정을 그대로 적용합니다. 가능한 후보 중 이동 절댓값이 가장 작은 것을 선택합니다. 전역 목표가 한 번의 최대 이동보다 멀면 명령을 `max_step_deg`로 제한하고 재촬영 후 다시 판단합니다.

`theta_target_conflict`는 두 선의 각도 허용 범위가 예측 모델에서 이미 분리된 경우입니다. `theta_no_reachable_tick`은 후보 검사에서 두 선 완료 조건을 만족하는 tick을 찾지 못한 경우입니다. 후자는 연속해가 반드시 존재한다는 뜻이 아닙니다. 모델이 예측한 도달 여부와 실제 영상의 완료 판정은 다른 필드이며, 예상 도달만으로 Y 단계나 완료로 넘어가지 않습니다.

왕복 검사는 실제 실행 완료 통지된 θ 명령 두 개와 다음 제안을 비교합니다. 기계적 원인을 진단하는 기능은 아닙니다. 차단 후 같은 작업에서 재설정만으로 이 상태를 지우지 않습니다. 원인 검토 없이 새 작업으로 초기화하여 제한을 우회하지 않아야 합니다.

## 호출자 계약

`Alignment_t`와 `alignment(cv::Mat&)`는 그대로입니다. 결합 모드에서 두 현재 영상 조건이 충족되어야 (0,0)을 반환합니다. 명령 불가나 측정 실패에는 예외를 던집니다.

- `acknowledgeAlignmentMoveExecuted()`: 실제 비영점 명령 실행 완료. 완료 횟수와 사용 횟수가 모두 증가합니다.
- `reportAlignmentMoveFailure(NoMotion)`: 이동하지 않았음을 외부 제어기가 확인한 경우. 대기를 해제하고 횟수는 유지합니다.
- `reportAlignmentMoveFailure(PartialOrUnknown)`: 부분 이동/실행 여부 불명. 사용 횟수를 하나 늘리고 다음 명령을 차단합니다.
- `resumeAlignmentAfterInspection()`: 외부 확인 후 재개. 횟수는 유지하고 새 이미지를 입력해야 합니다.
- `startNewAlignmentSession()`: 실제로 별개의 새 정렬 작업을 시작할 때만 사용합니다. 미확인 대기나 불명확 이동이 남아 있으면 거부합니다.
- `configureAlignment(...)`: 추정기 설정을 바꾸지만 위 상태와 횟수를 초기화하지 않습니다. 실패한 설정 로드는 이전 추정기를 보존합니다.
- `completedAlignmentMoves()` / `usedAlignmentMoves()`: 완료 확인 수 / 20회 제한에 사용한 수. 부분·불명확 이동이 있으면 후자가 큽니다.

θ 단독 전역 어댑터에도 같은 횟수·실행 통지가 적용됩니다. `SequentialAligner`와 CLI는 독립 영상 추정용이므로 그 자체로 기계 이동 횟수를 관리하지 않습니다. CLI는 `valid=1`이어도 `command_available=0`이면 실행 가능한 명령이 없습니다.

## 유지한 조건과 남은 한계

Y는 사용자가 선택한 4번 제외 OLS·HAC 공통 범위, 12개 개별 기울기, 0.05mm 이동 단위를 유지합니다. θ는 런타임 기준 이미지 선 각도, 4·5번 변화율, 0.01° 단위와 ±0.005° 기준을 유지합니다. Y 추가 허용대, 결합 θ만의 완료 판정, θ 잔여 편차의 Y 보상, 새 정합 점수 임계값은 도입하지 않았습니다.

따라서 도달 불가 상황 자체가 해결된 것은 아닙니다. 실패를 조기에 구분하고 불필요한 명령을 차단하는 변경입니다. 다른 기준 사진 사용을 해시로 강제 차단하는 기능, 가림·정합 신뢰도 임계값, 실장비 이동·재촬영 수렴 검증은 포함하지 않았습니다. 허용오차나 보정 모델을 새로 정하려면 별도 작업이 필요합니다.
