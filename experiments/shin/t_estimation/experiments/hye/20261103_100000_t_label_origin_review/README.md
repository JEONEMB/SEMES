# 라벨 감사 후 T 평가와 원점·구간 보정 비교

2026-11-03. 기존 method7(QR+외부 수평선, T만 출력)을 유지하고, 감사 대상 이미지를 학습과 평가에서 제외한 뒤 재학습한다. 1 tick=0.01°. 원본 파일·라벨·기존 모델은 변경하지 않는다. Git 규칙은 docs/gitConvention.md, 알고리즘 제약은 저장소 ALGORITHM_RULES.md를 따른다.

## 제외 정책

`exclusions.csv`는 참조 대화 「촬영 세션별 오차 EDA 시각화」와 그 자료 `label_anomalies.csv`, `outlier_actions.csv`를 합친 고정 목록이다. 예측 오차 순으로 추가 삭제하지 않는다.

- 주 평가: 파일명/폴더 충돌 1장, Actual 로그 충돌 3장, 반복 촬영 공통 변위 4장을 제외한다. 원본575장-제외8장-기준4장=563장.
- 민감도: 최신 영상 감사가 지지한 .57 사진3장을 복원한다. 566장. .57은 확인된 오촬영이라고 단정하지 않는다.
- 반복 위치 불일치 4장의 전체 경로를 보존한다. Y=.05/T=2, Y=.1/T=.1, Y=.1/T=2, Y=1/T=2의 각 두 번째 사진이다. 여러 관측 부위의 공통 변위가 근거이며, 물리적 참좌표의 확인은 아니다. 사용자 요청에 따라 제외한 개발 평가라는 조건을 표시한다.

## 비교 조건

- 기존 저장 OOF 예측의 단순 필터링: 과거 학습에 제외 이미지가 들어갔으므로 진단 대조군이다.
- 원래 명목 라벨로 재학습: 5개 구성원 후보와 결합 비중을 외부 fold의 학습 자료 내부에서 다시 선택한다. 같은 명목 Y/T의 반복 사진은 같은 fold다. 입력 특징은 기존104개이며 사진만으로 T를 예측한다. Y=0 가정은 없다.
- global_oof: 학습 내부 OOF의 평균 잔차를 공통 절편으로 더한다. 시험 라벨로 절편을 추정하지 않는다.
- session_oof: 같은 방식의 학습 내부 OOF 잔차를 알려진 촬영 구간별로 평균한다. session_shrink30은 구간 잔차합에 공통 절편30개분을 더해 축소한다. 30은 이번 비교 전에 고정했다. 구간별 보정에는 메타데이터 구간 ID가 필요하다. 알 수 없는 구간은 공통 절편으로 돌아간다. 순수 사진 모델과 운영 조건이 다르다.
- reference_zero: 별도의 기준 사진4장에 대한 예측 평균을 빼는 공통 원점 규약이다. 평가 대상 비원점 사진의 라벨을 사용하지 않는다. 이 규약이 서로 다른 촬영 구간을 실제로 연결한다고 가정하지 않는다.
- standard_crossfit: 기존 v3 원점 반응식을 재사용하되 제외8장을 원점 적합에서도 제거한다. 전체1회+외부5회+내부20회 원점/공분산/특징 선택을 재적합한다. 네 기준 사진은 보정 앵커이며 일반 평가에서 제외한다. 원점 정의는 기준4장의 잠재 좌표 평균0, Y prior .05mm/T prior .01°, 원시 보정범위±3이다. Y4/Y5 포함. 참조 관측에는 자연 특징 A도 포함하지만 최종 T 추정기의 입력은 QR+수평선104개다.

원점에 학습 자료가 없는 시험 구간은 `available=0`이며 해당 표준 좌표를 참값처럼 점수화하지 않는다. 명목 라벨 기준 점수는 이 사진들도 포함한다. 표준 좌표 점수는 통계 모델의 좌표 규약에 대한 일치도이며 물리적인 T 정확도가 아니다. 명목 모델과 표준 모델은 반드시 **같은 목표 좌표**에서도 비교한다.

## 누수와 한계

시험 정답으로 바이어스를 맞추는 사후 세션 중심화는 예측 성능으로 사용하지 않는다. 보고서에 포함하면 oracle 진단으로 명시한다. 내부 검증으로 구성원과 결합을 선택한 뒤, 동일 내부 OOF에서 보정량도 추정하므로 학습 내부에서는 선택 적응이 있다. 최종 외부 fold는 직접 사용하지 않는다.

라벨 감사·원점 가족·후보 모델은 이미 이 개발 자료를 보며 선택했다. fold 격리는 새로운 독립 시험을 뜻하지 않는다. 수정시각 구간은 확정된 실제 촬영 세션이 아니다. 참조 대화 최신 판정과 이번 보수적 제외 정책의 차이를 숨기지 않는다. 다른 대화의 파일은 읽기 전용 참조로 사용한다.

## 재현

저장소 루트에서 CMake Release 대상 `t_label_review`를 빌드한다(MSVC v141/OpenCV3.4.15). `t_label_review OLD_EXPERIMENT THIS_EXPERIMENT original_audit_coordinates.csv raw`로 명목 평가를 수행한다. `standard` 모드는 `origins/outer*.csv`를 사용한다. 모델 저장/재로딩을 모든 시험 예측에서 확인한다.

`prepare_origin_reference.py`는 기존 연구용 원점 구현을 그대로 불러와 보정 CSV를 만드는 재현 기록이며 최종 사진 추론 도구가 아니다. 기존 프로젝트 분석 캐시와 Python 패키지가 필요하다. 본 실험의 모델 적합·구성원 선택·결합·T 추론·보정 비교는 C++17 도구에서 수행한다. 기존 입력과 원본 영상은 덮어쓰지 않는다. `results/frozen_parameters`는 재탐색 전 고정 배포 파라미터를 사용한 별도 대조군이며 주 결과와 섞지 않는다.

`group` 모드는 수정시각/스캔 구간 전체를 차례로 보류한다. 이 구간을 학습/calibration에 사용하지 않았으므로 구간별 보정은 unknown fallback만 실행한다. 알려진 구간의 새로운 자세 평가와 구분한다. `all` 모드는 제외 없이571장을 같은 도구로 재실행하는 재현 대조군이다. 과거 저장 예측과 최대차이0을 확인했다.

`inner_predictions.csv`는 구성원/비중 선택 후 학습 내부 OOF와 보정 사용 여부를 보존한다. `report.py`는 네이티브 예측으로 지표·그림을 만들고, 보정량을 이 CSV에서 독립 재계산한다. 제외 목록·모든 시험/학습 경로·26개 원점 학습 경로를 검사한다. 표준 좌표가 식별되지 않은3장은 원점 학습에 해당 구간이 통째로 없는 경우다. 학습내 OOF에서도 그런 좌표는 비중 선택과 절편 보정에서 제외했다.

최종 결과는 [RESULTS.md](RESULTS.md), 수치 검사는 [verification.json](verification.json)에 있다. 전체 Release 빌드, 기존 CTest3개, 571장 예측의 과거 결과 재현, 제외 후5개 평가 구성의 수치·분할·보정 검사까지 수행했다. 테스트 통과가 독립 정확도 인증을 뜻하지 않는다.
