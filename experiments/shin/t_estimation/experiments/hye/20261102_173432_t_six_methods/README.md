# T 단독 추정: 여섯 방법 비교

**Y가 미지로 변하는 조건에서 여섯 방법과 두 결합식을 실행했다. 영상 전용 결합식이 최대오차를 3.849→2.640 tick으로 줄였지만, 최대 1 tick 목표는 미달이다.** 수치 전체는 [RESULTS.md](RESULTS.md)에 있다.

## 단위와 카메라 정보

사용자가 T는 degree이며 **1 tick=0.01°=1 centidegree**라고 확인했다. Y는 mm다. sin/cos 계산에서만 radian으로 변환하고 출력은 degree·tick으로 표시한다. 명목 명령 라벨과 동봉 TXT Actual을 섞지 않는다.

제공 제원은 QR판79×15mm, QR13×13mm, working distance385mm, 렌즈12mm, 센서4096×2160, 저장영상3840×2160, gain1, exposure10000이다. 원문 정보는 `specifications.json`에 기록했다. **카메라 내부 파라미터나 왜곡계수는 추정하지도, 가정해서 사용하지도 않았다.** 영상 중심과100/1000px 정규화는 수치좌표계의 원점·척도이며 광학 주점·초점거리 추정값이 아니다. 기하 후보는 영상에서 보정한 국소 투영 모델이다.

81920pulse 및 pulse×360/81920 환산식은 정보만 기록했다. 실제 pulse 로그가 없어 명령 라벨을 재보정하거나 모터 단위로 반올림하지 않았으며, 프로그램은 모터 명령을 전송하지 않는다.

## 데이터와 관측

사용자가 지정한 `data/SSAFY Test Image Set`의 원본575장을 재계측했다. 현재 checkout에 clean 원본이 없어 명시적으로 전달된 경로를 사용했다. 원본·기존 clean은 수정하지 않았다.

- 평가: T단독200 + Y단독80 + 기존혼합57 + 추가혼합234 =571장.
- 기준4장은 점수에서 제외했다. 모든 측정은 기존 고정 center1 PNG를 같은 기준으로 사용한다.
- 계측 실패0/575, 기존10특징과 최대차이0. 원본 해시 변화0, 과거341장과 불일치0, 동일 파일 중복0.
- QR630점을 고정3×3 공간셀로 나눠 dx/dy54개를 얻는다. 점은 삭제하지 않는다.
- 상·하 선을 좌우로 나눠 위치·기울기8개를 얻는다. 해당 분할 적합과 직접 정합은 저품질 표본도 .02의 양의 가중치로 포함한다. 기존10특징의 유효성 처리는 원래대로 보존한다.
- QR별 호모그래피24개와 QR판 전체의 공통 호모그래피8개를 추가한다. QR판과 외부 선을 하나의 평면으로 묶지 않는다.

총104특징은 기존10 + QR셀54 + 분할선8 + QR별기하24 + 공통기하8이다. 공통기하 추가 전후 앞96개 특징의 차이도0이었다. 나사·너트·일반 배경 텍스처는 추가하지 않았다.

`observations.csv`는 측정과 평가 메타데이터다. `cache/`는 재생성 가능한 점·선·초기변형 캐시이며 추적하지 않는다. 실행 모델은 이 캐시와 정답 CSV에 의존하지 않는다.

## 실제 구현한 방법

| 번호 | 방법 | 구현 |
| --- | --- | --- |
|0|대조군|기존10특징의6개 표현과 ridge로 T만 회귀한다. 이전571장 기준 결과를 재현한다.|
|1|관측·불확실성 결합|QR셀·분할선을 보존한다. 학습 내 동일 좌표 반복으로 공분산을 추정하고 대각축소·고유값 하한으로 백색화한다. 전방GLS와 백색화 T직접회귀를 비교한다.|
|2|yaw 투영 기하|QR별/공통 호모그래피와 선을 이용한다. sinθ,1−cosθ,Y 및 교차항으로 전방 관측 모델을 보정하고 T를 추론한다. K가 없는 실측 국소 모델이며 완전한 물리 카메라 복원은 아니다.|
|3|국소 비선형|학습 특징공간에서 거리가 먼32개 중심을 선택한다. 선형항+RBF를 T에 적합하고 폭·정규화를 학습 내에서 선택한다. GP 전체 대신 RBF ridge를 구현했다.|
|4|공동 밝기 정합|QR·선 패치를 공통 T와 방해변수 Y로 설명한다. 패치별 gain/offset을 제거하고 Lanczos 미분·soft-L1·감쇠Gauss–Newton으로 직접 최적화한다. 미채택이다.|
|5|촬영 구간 절편 보정|학습 사진의 수정 시각에서120초 이상 간격을 분리한다. 전역 T회귀의 구간별 잔차 절편을 축소 추정한다. 미등록/미제공 시각은 전역 모델로 복귀한다.|
|6|최악 그룹 학습|학습 Y의.5mm·T의.25° 구간별 손실로 그룹 가중치를 갱신한다. 15회 적합, 양의 기본 가중치와 ridge를 사용한다. 추론에는 그룹 정답을 주지 않는다.|

방법1·2·4의 일부 후보는 Y를 내부 방해변수로 계산하지만 CLI는 T만 출력한다. Y 정확도는 모델 선택 목표가 아니다. Y=0 가정은 없다.

방법4는 QR9×9 영역의5×5 정수 표본과 선7×5 영역의3×7 표본을 쓴다. 전체750패치의 gain/offset을 조건부 최소제곱으로 제거한다. gain범위.2~5, 강건척도3, 최대15회, 한 단계 한도Y.4mm/T.2°다. 단계 한도는 최적화 안정화이며 출력 clipping이 아니다. 초기 affine은 영상에서 측정한 값을 고정하고 셀·선 이동을 T/Y로 공유하는 근사 구조다. 완전한 시점별 투영 변형을 동시에 복원하는 모델과 구분한다.

## 공통 평가 절차

571장은 모두 개발에 노출된 자료다. 같은 (Y,T) 명령 좌표의 반복을 함께 보류하는 기존 FNV-1a5-fold를 사용했다. 각 외부 학습 집합에서 내부4-fold로 후보를 선택했다. 점수는 최대 절대오차(tick)+.1×RMSE(tick)이다. 평균·표준편차·공분산·RBF중심·전방계수·그룹가중치·세션절편은 각 학습 집합에서만 계산한다.

방법4의 초기화 후보는 내부 좌표 예측 검증으로 선택한다. 직접 밝기 오차까지 내부에서 반복 검증한 것과 다르다. 모든 외부 시험 사진에서는 실제 픽셀 정합을 실행했다.

`six_report`가9개 방법×571개 경로의 누락·중복, fold·정답 불일치, 저장오차와 예측−정답 불일치를 검사한다. 실패는 전체 시도의 분모에 포함하며 유효한 추론의 연속오차와 구분한다. 모델 전수 학습의 재대입을 OOF 성적으로 쓰지 않는다.

초기 성적을 보고 후보를 추가했으므로 적응적 평가 오염이 남는다. 직접적인 시험 정답 적합을 막았다는 것과 독립 시험이라는 주장은 다르다. 추가234장도 독립 시험으로 다시 부르지 않는다. 새 세션·장비·QR내용 및 음의Y에서 T가 함께 변하는 범위, 실제 제어 성능은 미검증이다.

## 결합식과 선택

method7은0·1·2·3·6을 결합한다. method8은 여기에5를 추가한다. 외부 학습 사진 안에서 교차예측을 다시 만들고 .25단위 비음수 가중치(합1)를 선택한다. 외부 시험 정답으로 결합 비율을 고르지 않는다.

배포 모델은 전체571장 보정 구성원을 사용하며 결합 비율은 외부 학습fold별 비율의 평균이다. method7의 비율은 기준회귀.05, 잡음결합.15, 기하.25, RBF.35, 최악그룹.20이다. **촬영 시각이나 Y값을 받지 않는다.** method8은 최대오차가 더 커 선택하지 않았다.

## 실패와 추가 개선 기록

초기 결과는 `results/initial/`에 보존했다. 전방 공분산/개별QR 기하가 좋지 않아 백색화 T직접회귀와 넓은 QR판 공통기하를 추가했다. 방법1의 MAE는1.458→.589tick으로 줄었지만 최대4.530tick은 남았다. 기하 단독은 나빴으나 다른 모델의 오차를 상쇄하는 결합 구성원으로 선택됐다.

방법4는 처음에 기준선의 완전 유효성을 요구해552/571장을 실패 처리했다. 실패 결과를 보존하고, 저품질 기준선은 기준 직선으로 보완해 .02가중치로 포함했다. 패치별 조명 보정과 초기화 선택·넓은 표본도 추가 검증했다. 중간 결과는 `results/direct_revision1/`에 있다. 최종 방법4는571장 모두 계산됐지만 최대62.041tick으로 악화돼 미채택했다. 초기 좌표 추정은 MAE1.458tick/최대4.936tick이었고 직접 최적화 후에는 MAE19.128tick으로 커졌다. 초기 좌표 예측보다 직접 정합 후 T오차가 커져, 이 근사 구조에서 밝기 오차 감소를 T정확도 개선으로 해석할 수 없었다. 전체 물리 원인을 한 가지로 확정하지 않는다.

method7의 최악 표본은 Y=1/T=.1의(2) +2.640013tick, Y=1/T=1의(2) +2.638247tick, Y=1/T=2의(3) −2.547567tick이다. T단독에서도 T=.15가−2.459569tick으로 남았다. 전수 실패는 `results/failures_method7.csv`에 있다. 실패 사진만 제외해 통과율을 올리지 않았다.

## 수정 시각과 세션

수정 시각의120초 간격으로14개 구간 후보가 나왔고, 기준 사진만 있는 구간을 제외하면12개다. 수정 시각은 촬영 로그가 아니며 복사·수정으로 바뀔 수 있다. 방법5는 각 학습 집합의 시각으로 구간을 다시 나눈다. 시험 시각까지 보고 학습 구간을 합쳐 절편을 맞추지 않는다.

한 구간 전체를 보류한 보조 평가에서 방법0과5는 같았다: MAE1.199275tick, RMSE1.416229tick, 최대3.877353tick,253/571통과, 등록 구간 판정0/571. 처음 보는 구간에는 쓸 절편이 없어 기본 모델로 복귀했다. 이 평가는 고정alpha.1/shrink30의 별도 진단이며 주 평가와 직접 성능 차이를 비교하지 않는다. 보류 구간에 따라 보정 범위와 촬영 조건도 달라진다.

## 실행과 검증

선택 모델은 `assets/best_image_ensemble.json`과 같은 폴더의 `deployment_method7_members/`다. QR기준 자산은 기존 reference.png/template3장을 사용한다. 개발 캐시·CSV정답·Python·외부 개인 실험 경로는 추론에 필요하지 않다.

```powershell
.\build-t-only\experiments\hye\20261102_173432_t_six_methods\Release\six_estimate.exe "IMAGE.bmp" modules/qrwithbar_lanczos/assets experiments/hye/20261102_173432_t_six_methods/assets/best_image_ensemble.json
```

출력은T의degree/tick, 등록 구간 여부, 학습T범위 밖 진단이다. 계산하지 않은 적합비용은 `cost:null`로 표시한다. 범위 안이라는 진단은 정확도 보증이 아니다. 입력은3840×2160uint8이며 원본 픽셀 불변을 검사한다. 측정·모델 실패를 정상T=0으로 숨기지 않는다.

선택 모델로 T=.5 원본에서 .49740510977483221°, Y=1/T=.1의(2)에서 .11880355684898616°를 계산했다. 캐시 기반 전수 모델 추론과 정확히 일치했다. 이는 학습 사진의 실행 검사이며 OOF 성적과 별개다. 저장·재로딩 예측차0, 시험 라벨 변경에 대한 학습 격리, 미등록 시각 복귀, 합성 투영·공간셀 복원 검사를 통과했다.
