전수 학습 모델과 모든 이미지의 교차검증 결과를 함께 제공한다. 정답은 명령값에 EDA v3에서 확정한 파일명 오기 1건(.33→.32)만 정정한 값이다. 표준 원점의 추정 좌표를 새 정답으로 사용하지 않았다. 실제 자세를 별도 계측한 값은 아니다.

측정 기준: feature/shin/QRwithBar · 55c5ebed · 10특징 Lanczos-3. 동일한 영상 특징으로 기존57장 모델·575장 학습 모델·전체 교차검증을 비교한다. 원본 이미지 입력만으로 추론하며, 기존 학습 사진은 SHA-256으로 식별했다.

EDA 감사 반영과 재현 근거

최신 EDA v3의 사진 삭제 확정은 0장이다. .32 폴더/.33 파일명 1건은 .32로 정정했고, Actual 로그가 충돌한 .57 사진 3장은 유지했다. 반복 편차 4장은 삭제하지 않고 학습에서만 강건 가중치를 적용했다. 영상 감사에서 측정한 동일 자세의 공통 반복 변위로 학습 자료 안의 중앙값+4×max(1.4826×MAD,0.02px) 기준을 다시 계산한다. 기준을 넘으면 가중치=max(0.2,(기준/편차)²). 평가 사진의 오차에는 이 가중치를 적용하지 않는다.

575장 전수 학습 모델은 기존 10특징 선형 구조, SVD와 사전에 고정한 α=0을 유지한다. 표준화·절편·계수를 전수 학습했다. 교차검증에서는 동일 좌표의 반복 사진을 모두 함께 제외하고, 각 학습 자료에서 가중치 기준·표준화·절편·계수를 다시 계산한다. 기준 사진 4장도 하나의 원점 좌표 그룹으로 함께 제외한다. 단, 영상 측정용 기준 사진 center1은 고정 보정 자산으로 계속 사용한다. 따라서 원점 그룹 결과도 기준 영상 자체를 새 촬영으로 보류한 검증은 아니다.

앞선 57장 평가는 Actual 상대값에 대한 19개 모델의 보류 예측이었다. 이번에는 감사 후 명령 라벨을 사용하므로 앞선 숫자와 직접 개선율을 계산하지 않는다. 전수 학습 자산은 full_assets에 별도 저장했고 기존 배포 모델은 교체하지 않았다. 세 방식 모두 이미 노출된 개발 자료의 평가이며 신규 독립 촬영·실제 반복 제어 검증이 아니다.

현재 원본 폴더의 BMP/PNG를 전수 열거했다. data/clean은 존재하지 않아 보존된 data/SSAFY Test Image Set을 읽었다. 파생 증강 이미지와 모듈 보정용 복사본은 중복 포함하지 않는다. 기준 이미지도 제외하지 않는다. 실패는 0,0으로 대체하지 않는다.
