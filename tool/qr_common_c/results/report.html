QR + 공통 경계 4개 특징의 C 구현

파란 원은 입력 이미지의 정답 좌표, 주황 ×는 C 실행 파일이 그 이미지에서 추출·예측한 좌표다. 선이 두 점을 연결한다. 같은 좌표의 반복 3장을 함께 보류한 19개 평가 모델을 사용했다. 학습 이미지 자체를 예측한 성능과 구분한다.

C 원본 이미지 경로: Y RMSE 0.074458 mm, yaw RMSE 0.013847°, 동시 ±1틱 52.6%.

저장된 동일 10개 특징을 C 회귀에 넣으면 기존 Python 0.075169mm / 0.014019° / 52.6%를 재현한다. 아래 검증 기록은 이 회귀 일치 검사와, 원본 BMP부터 다시 계산한 C 경로를 구분한다. 수치 최적화기·OpenCV 버전 차이로 이미지 경로는 완전한 비트 일치를 목표로 하지 않는다.

수치 계산은 C17이다. OpenCV가 제공하는 이미지 디코딩·템플릿 정합·초기 affine ECC만 C++17 어댑터를 사용한다. 실행 시 Python이나 이미지별 정답·특징점 캐시를 읽지 않는다. 캘리브레이션에는 기준 이미지의 QR 패턴/점·템플릿과 원점 경계, 학습 계수가 들어 있다. 경계는 원본 밝기 함수의 수치 적합이며 Canny를 사용하지 않는다.

원점까지의 반복 제어와 장비 간 일반화는 검증하지 않았다. 평가 fold는 정답 좌표를 알고 있는 평가기만 선택한다. 새 이미지의 일반 추론은 fold=-1의 전체 학습 모델을 사용한다.
