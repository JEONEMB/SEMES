# 트랙 B — QR + 배경 시차로 (Y, Θ) 분리

> 코드 : `code/yt/track_b.cpp`, `code/yt/yt_model.hpp/.cpp` · 결과 : `results/verify/TrackB_parallax/` · 이전 버전 : `backup/track_b.v1.cpp.bak` · 근거 : Sutton 2008 (한 평면만으로는 면외 운동 분리 불가 → 깊이가 다른 대상 필요)

## 1. 아이디어
- 카메라가 Y 로 1 mm 옮겨 가면 가까운 플레이트는 많이, 먼 벽은 적게 움직입니다 (시차).
- Θ 로 돌면 거리와 상관없이 거의 같은 각도만큼 움직입니다.
- 따라서 "플레이트 이동"과 "플레이트 − 벽 이동"을 함께 쓰면 두 미지수를 풀 수 있습니다.

| 특징 (M1 측정) | 정의 | Y 감도 | Θ 감도 |
|---|---|---|---|
| s | QR 3개 평균 가로 이동 | 14.249 px/mm | 80.061 px/° |
| d | s − 아래쪽 벽 W1~W4 평균 이동 | 3.097 px/mm | −1.210 px/° |

s 를 고정한 채 Θ 만 0.01° 바꾸면 d 는 0.186 px 변합니다. 이 값은 d 의 잔차 σ (0.041 px) 의 4.6 배입니다.

## 2. 수행 방법 (`yt_model`)
1. 특징 k 마다 `f_k = c + a·Y + b·Θ + q·Θ²` 를 **1차 세트**에서 최소제곱으로 학습합니다. 잔차 σ_k 도 함께 구합니다.
2. 새 사진은 측정 f 에서 (Y, Θ) 를 가중 Gauss–Newton 으로 풉니다 (가중 = 1/σ_k²).
3. 다른 날 보정(teaching) : 라벨을 아는 보정 이동 3장으로 특징별 `f' = g·f + h` 를 맞춥니다.
4. 학습과 평가의 분리 규칙 :
   - 1차는 한 장 빼고 학습(LOO)합니다.
   - 2차는 1차 모델을 그대로 씁니다.
   - teaching 에 쓴 3장은 평가에서 뺍니다.

## 3. 검증 절차와 기준
| 시험 | 내용 | 통과 기준 |
|---|---|---|
| 0.01° 계단 | 1차 Θ 스윕에서 라벨이 정확히 0.01° 차이 나는 이웃 쌍 198개의 추정 차 | 평균 0.0100 ± 0.0010°, σ ≤ 0.003° |
| 1차 LOO | 280장 | Y ±90 µm 95 % 이상, Θ 절댓값 ≤ 0.5° 에서 ±0.01° 95 % 이상 |
| 다른 날 | 2차 Y·Θ 동시 이동, Θ ≤ 0.2° (반복 보정의 마지막 단계에 해당) | ±0.01° 95 % 이상 |

- 비교 : 위쪽 벽까지 넣은 3 특징은 1차 LOO Θ RMS 0.0027° 로, 이득이 없었습니다.
- 대조군 : s 하나만 쓰면 감도 행렬의 계수(rank)가 1 이라 분리가 불가능합니다.
- 처리 시간 : 모델 부분은 무시할 수준입니다. 한 장 처리 시간은 M1 과 같아 약 151 ms 입니다.

**종합 : 통과 (구현 + 사양).**
- Θ 1~2° 에서는 오차가 0.01~0.03° 입니다. 이는 반복 보정의 첫 이동에 해당하므로 판정 대상이 아닙니다.
- 반복 수렴 여부는 시뮬레이터에서 확인할 예정입니다.
- 2차 Θ = 2° 의 평균 오차가 +0.029° 로 한쪽으로 치우칩니다. 1차 학습 범위(±1°) 밖이라 Θ² 외삽 오차로 보입니다.

## 5. 시행착오
- Python 시험판(일부 데이터)에서는 1차 LOO 가 34/36 이었습니다. 전체 데이터로 학습한 C++ 판에서는 280/280 입니다.
- 첫 C++ 판(`track_b.v1.cpp.bak`)과 현재 판의 차이는 보고서 문구 두 줄뿐입니다. 표 깨짐을 고쳤고, 확인하지 않은 "회마다 줄어듦" 주장을 뺐습니다. 계산은 같습니다.
