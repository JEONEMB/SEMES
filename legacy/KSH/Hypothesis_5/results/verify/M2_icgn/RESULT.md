# M2 IC-GN 아핀 정합 + 서브픽셀 치우침 감소 — 검증 결과


## V2-1 합성 부분 화소 이동 — 보간 방식별 치우침

QR_L 영역을 푸리에 위상 회전으로 정확히 (dx, 0.25) px 이동. 늘어남은 0 이 정답.

| 보간 | 이동 치우침 RMS (px) | 최대 (px) | 늘어남 ux 최대 (정답 0) |
|---|---|---|---|
| 선형 | 0.0170 | 0.0245 | 2.15e-05 |
| Keys 3차 (a = −0.5) | 0.0184 | 0.0264 | 1.11e-05 |
| DUAL (선형·Keys 평균) | 0.0177 | 0.0254 | 1.40e-05 |
| B-스플라인 3차 | 0.0059 | 0.0086 | 7.86e-06 |
| **채택 : B-스플라인 + 가우시안 σ 1.0** | 0.0006 | 0.0009 | 1.05e-06 |

DUAL 은 선형·Keys 치우침 부호가 같아(평균 -0.0001 / +0.0001 px) 상쇄되지 않음 → 채택하지 않음.

B-스플라인만으로는 0.0059 px (기준 0.005 px 미달) → 가우시안 사전 필터(Pan 2013)를 더해 채택. σ 선택 과정은 build/explore_sigma.txt.

- ✅ 통과 — **채택 설정의 치우침** : 0.0006 px (선형 0.0170 의 절반 이하, 0.005 이하)
- ✅ 통과 — **이동만 있을 때 늘어남 0 유지** : 채택 설정 ux 최대 1.05e-06 (≤ 1e-5 : Θ 0.01° 의 QR 1개 신호 1.7e-5 보다 작게)
