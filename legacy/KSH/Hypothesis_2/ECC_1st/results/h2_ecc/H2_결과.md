# 가설 H2 — ECC 전역 원근 정합 (심화 ECC)

## 1. 가설 정의

> **H2 : QR 3개를 모두 포함하는 띠 전체를 ECC(정규화 상관) 정합 한 번으로 맞추면, 원근(키스톤) 성분을 약 700 px 의 긴 기준선 위에서 직접 추정할 수 있어 Θ 측정 잡음이 위상(Gabor) 방식(QR 별 약 200 px 기준선)보다 작아지고 Y·Θ 를 더 정확히 구분한다.**

- 근거 : Evangelidis & Psarakis (2008) ECC, Pan et al. (2013) IC-GN/ZNSSD, Sutton et al. (2008) 팬 회전 = 이동 + 원근, Grédiac et al. (2016) 배율 잡음 ∝ 1/기준선²
- 판정 기준
  1. 1차 세트 검증 Θ RMS 가 위상 방식(0.018 ~ 0.020°)보다 작을 것
  2. 사진마다 |Θ 오차| ≤ 0.01° 통과율이 위상 방식보다 높을 것
  3. 2차 세트(다른 날, Y·Θ 동시 이동)에서도 성능 유지
  4. 같은 자세 3장 반복성 확인, 처리 시간 MFC 사용 가능 수준

## 2. 구현 (C++ / OpenCV 3.4.15)

| 파일 | 역할 |
|---|---|
| `ecc_align.hpp/.cpp` | ECC 정렬기 · 보정 모델 학습/추정 · 모델 yml 저장/읽기 |
| `ecc_eval.hpp/.cpp` | 1차/2차 세트 목록(한글 경로), 일괄 측정, CSV, 반복성 그림 |
| `result_plot.hpp` | MFC 앱과 같은 6칸 결과 그래프 |
| `alignment.hpp/.cpp` | `alignment_init()` / `alignment(cv::Mat&)` 인터페이스 (ECC 엔진 사용) |
| `main.cpp` | H2 검증 전체 실행 → `results/h2_ecc/`, `ecc_model.yml` |

처리 흐름 (한 장)
1. **거친 단계** : 기준 띠와 현재 띠의 `phaseCorrelate` → 정수 수준 이동 (Θ 2° ≈ 160 px 도 처리)
2. **정밀 단계 (심화 ECC, method 1)** : ECC 와 같은 ZNCC 기준을 원근 다항 워프로 직접 최적화
   - u = p0 + p1·x̂ + p2·x̂² + p3·ŷ + p4·x̂ŷ,  v = p5 + p6·ŷ + p7·x̂ + p8·x̂ŷ
   - QR 영역 마스크만 사용, double 정밀도 쌍삼차(Keys) 보간 + 해석적 미분, Gauss-Newton 3 ~ 4회 수렴
   - OpenCV `findTransformECC` 는 내부 보간이 1/32 px 로 양자화되어 배율 값이 반복 설정에 따라 0.005 ~ 0.01 흔들림 → Θ 신호(0.36 /°)의 1.5 ~ 3% 라 비교용(method 0, `--opencv-ecc`)으로만 둠
3. **특징** f = [tL, sL, tC, sC, tR, sR] (QR 3개의 가로 이동 px, 가로 배율 px/100px)
4. **추정** f = a·Y + b·Θ + q·Θ² + c, 잡음 공분산 Σ 로 GLS (Gauss-Newton)

처리 시간 : 약 80 ms/장 (측정만, -O2)

## 3. 사진 메타데이터 — 연속 촬영인가, 이동 후 촬영인가

- BMP 에는 EXIF 가 없음 (40 바이트 BITMAPINFOHEADER 만). 파일 시각과 txt 기록만으로는 판단 불가
  - txt(모터 값)는 (1)(2)(3) 이 같은 시각에 저장되거나 영상보다 먼저 저장된 경우가 있음 → 촬영마다 기록한 로그가 아니라 같은 모터 값 하나를 복사한 것 (분해능 0.01)
- 따라서 **영상 내용**으로 판정

| 구간 | 3장 사이 차이 | 판정 |
|---|---|---|
| Y+0.05 T+0.01 / 0.02 / 0.03 (10:47 ~ 10:54) | tC σ 0.008 px, Θ σ 0.003°, Y σ 18.5 µm | **연속 촬영 (이동 없음)** |
| Y+0.05 T+0.10 이후 16 자세 | (2) 가 일관되게 +0.2 ~ 0.39 px, (1)(3) 은 약 −0.1 px. 세로(vC)·원근(Δs) 은 그대로 | **매번 다시 이동해 촬영** — 접근 방향에 따른 위치 차(백래시 유사) 약 0.36 px ≈ Y 25 µm 또는 Θ 0.0045° |
| center1 / 2 / 3 | center2 −0.08 px, center3 −0.03 px | 같은 기준 자세 (재이동 수준 차) |

→ 정지 상태 측정 반복성은 **Θ σ ≈ 0.003°** 로 이미 0.01° 를 만족. 이동해서 찍은 묶음의 흩어짐(Θ σ 0.016°)은 측정 잡음이 아니라 **실제 자세 차이**가 섞인 것

| OpenCV ECC 호모그래피, 선형 모델 | 0.0284° (+0.013) | 0.0216° | 0.0264° | 0.0431° |

- **OpenCV 호모그래피는 큰 Θ(1 ~ 2°) 에서 치우침이 거의 없음** → 심화 ECC 의 큰 Θ 오차 상당 부분은 다항 워프(원근 근사)의 모델 한계. 대신 OpenCV 는 같은 자세 center2·3 오차 0.014° (심화 ECC 0.004 ~ 0.006°), 3장 반복성 Θ σ 0.018° (심화 ECC 0.016°), 처리 시간 1.3 s/장 (심화 ECC 0.08 s/장)
- 심화 ECC 의 2차 세트 Θ 오차는 Y·Θ 에 따라 커짐 : eT ≈ 0.0165·T + 0.0052·T² + 0.0525·Y·T + 0.0069 (잔차 sd 0.019°) → 축별 단독 학습 모델이 **동시 이동(상호작용)** 과 **세션 차이**를 설명하지 못함

| | 이동 tL/tC/tR | 배율 sL / sC / sR | Θ 단서 : 곡률 / 배율 차 |
|---|---|---|---|
| 위상 | 0.22 px | 0.012 | 0.0116 / 0.0103 |
| 심화 ECC | 0.22 px | **0.0063 / 0.0027 / 0.0060** | 0.0139 / 0.0108 |

## 5. 판정

**H2 기각** (기준 1, 2 불만족)

- 1차 세트 Θ RMS 는 위상 방식과 같거나(Y 단독) 더 나쁨(Θ 단독), ±0.01° 통과율도 증가하지 않음
- 다만 얻은 것
  - 2차 세트(다른 날·동시 이동) 일반화 : 위상 0.052° → 심화 ECC 선형 0.035° → OpenCV 호모그래피 0.023° — ECC 계열 모두 위상 방식보다 좋음
  - QR 별 배율 측정 잡음 2배 감소, 80 ms/장으로 MFC 적용 가능
  - 정지 자세 반복성 Θ σ ≈ 0.003° → **측정 자체는 0.01° 를 낼 수 있음**
- 0.01° 를 막는 것은 측정 잡음이 아니라
  1. 이동마다 생기는 실제 자세 차 (접근 방향 / 백래시, ≈ 0.0045°)
  2. 모델 계통 오차 : 워프 근사(큰 Θ 원근), Y·Θ 상호작용, Θ² 외삽, 세션(날짜) 차이
